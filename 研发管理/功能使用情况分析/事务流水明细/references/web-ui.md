# 事务流水明细 Web UI 功能描述

> 通用约束见[共享布局](../../references/page-structure.md#共享布局)，业务口径见[共享业务规则](../../references/business-rule.md)。原型见 [usage-events.html](../assets/web/usage-events.html)。

## 1. 事务流水明细（usage-events.html）

- **路由**：`/portal/usage-events`
- **权限码**：`devhubUsageEvents`
- **页面类型**：列表页

### 区块职责

| 区块 | 说明 |
|------|------|
| 顶部筛选条 | 接入系统（必选，记住上次选择） / 时间范围（默认近 24 小时，单一日期时间范围控件，跨度 ≤ 90 天） / 端（Web/App） / 用户（姓名或用户 ID 联想，支持直接输入） / 角色（下拉，取自近 90 天事件） / 路由关键词（前缀匹配） / 功能（下拉，取自功能目录启用项，含「未归类」） / 事件类型（浏览 / 点击 / 提交 / 停留） |
| 统计摘要 | 当前筛选条件下：事件总数、去重用户数、去重功能数、最近事件时间 |
| 表格列 | 端 \| 用户名 \| 角色 \| 手机号（脱敏） \| 页面（路由 + 页面标题） \| 功能（功能名称，未归类置灰） \| 事件类型（停留附时长） \| 时间 \| 操作（查看详情）；按事件时间倒序，每页默认 20，最大 200 |
| 右侧抽屉 | 点击行展开：事件详情（用户、角色、组织、功能名称与编码、路由、页面标题、元素文本、停留时长、终端、版本、来源页、会话与设备、IP、接收时间、自定义属性） + 近 7 日行为摘要（事件数、活跃天数、使用功能数、各事件类型次数、逐日柱状、TOP5 功能） + 该用户前后各 10 条相邻事件时间线（未登录按会话） |
| 导出 | 结果 ≤ 5 万行时按钮为「导出 CSV」直接下载；超过时按钮切换为「离线导出」，提交导入导出中心任务，完成后在任务列表下载 |

### 按钮权限码

- 导出 CSV：`devhubUsageEventsExport`
- 查看详情：受 `devhubUsageEvents` 进入页即授予，无独立按钮码
