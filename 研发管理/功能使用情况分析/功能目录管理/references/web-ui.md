# 功能目录管理 Web UI 功能描述

> 通用约束见[共享布局](../../references/page-structure.md#共享布局)，业务口径见[共享业务规则](../../references/business-rule.md)。

## 3. 功能目录管理

- **路由**：`/portal/usage-catalog`
- **权限码**：`MENU:RND:MANAGE:USAGE_CATALOG`
- **页面类型**：列表页

面向运营 / 管理员的功能注册表管理界面。**不提供新增 / 物理删除**（避免与埋点自动注册冲突），仅开放查询、编辑元数据、启停。

### 区块职责

| 区块 | 说明 |
|------|------|
| 筛选栏 | 关键词（模糊匹配功能编码 / 功能名称 / 路由路径）、状态（全部 / 启用 / 停用） |
| 工具栏提示 | 「埋点上报新功能时会自动注册到此表，运营可在此补全功能名称 / 排序 / 启停。」 |
| 表格列 | 账套 \| 功能编码 \| 功能名称 \| 路由路径 \| 所属菜单权限 \| 排序 \| 状态 \| 更新时间 \| 操作（编辑 / 启停） |
| 编辑弹窗 | 仅可修改功能名称（必填，最长 128 字）、所属菜单权限码、排序（0-9999）；功能编码与路由路径只读展示 |
| 启停 | 切换启用 / 停用；幂等（状态相同直接返回） |
| 分页 | 每页默认 20，最大 200 |

### 按钮权限码

- 编辑：`BTN:RND:MANAGE:USAGE_CATALOG:EDIT`
- 启停：`BTN:RND:MANAGE:USAGE_CATALOG:TOGGLE`
