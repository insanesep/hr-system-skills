# 功能目录管理 Web UI 功能描述

> 通用约束见[共享布局](../../references/page-structure.md#共享布局)，业务口径见[共享业务规则](../../references/business-rule.md)。

## 3. 功能目录管理

- **路由**：`/portal/usage-catalog`
- **权限码**：`MENU:RND:MANAGE:USAGE_CATALOG`
- **页面类型**：列表页

面向运营 / 管理员的功能注册表与接入系统管理界面，页面分「功能目录」「接入系统」两个页签。功能目录**不提供新增 / 物理删除**（避免与埋点自动注册冲突），仅开放查询、编辑元数据、启停。

### 区块职责

| 区块 | 说明 |
|------|------|
| 筛选栏 | 接入系统（默认全部）、关键词（模糊匹配功能编码 / 功能名称 / 路由路径）、状态（全部 / 启用 / 停用） |
| 工具栏提示 | 「埋点上报新功能时会自动注册到此表，运营可在此补全功能名称 / 排序 / 启停。」 |
| 表格列 | 接入系统 \| 功能编码 \| 功能名称（名称仍为编码占位时标记「待补全」） \| 路由路径 \| 所属菜单权限 \| 排序 \| 状态（开关） \| 更新时间 \| 操作（编辑）；按接入系统、排序、功能编码升序 |
| 编辑弹窗 | 仅可修改功能名称（必填，最长 128 字）、所属菜单权限码、排序（0-9999）；功能编码与路由路径只读展示 |
| 启停 | 切换启用 / 停用；幂等（状态相同直接返回） |
| 分页 | 每页默认 20，最大 200 |

### 接入系统页签

| 区块 | 说明 |
|------|------|
| 接入指引 | SDK 脚本地址与上报地址，均可一键复制；接入步骤指向[埋点接入 skill](../../../../../busyming-devhub-web/sdk/usage-tracker/SKILL.md) |
| 表格列 | 接入系统（名称 + 编码） \| AppKey（掩码展示，可复制完整值） \| 允许来源（空为不限） \| 负责人 \| 状态 \| 最近上报时间（未上报显示「未上报」） \| 操作（编辑 / 重置密钥 / 停用或启用） |
| 新增 / 编辑弹窗 | 系统编码（新增必填，2-32 位大写字母、数字或下划线且字母开头，全局唯一，创建后不可改）、系统名称（必填，最长 64 字）、允许来源域名（逗号或换行分隔，支持 `*.` 子域通配，不含路径）、负责人、备注；创建即生成 AppKey 并启用 |
| 重置密钥 | 二次确认后生成新 AppKey，旧值立即失效 |
| 停用 / 启用 | 停用需二次确认；停用后该系统全部上报被拒绝，历史数据保留可查 |

### 按钮权限码

- 编辑：`BTN:RND:MANAGE:USAGE_CATALOG:EDIT`
- 启停：`BTN:RND:MANAGE:USAGE_CATALOG:TOGGLE`
- 接入系统管理（新增 / 编辑 / 重置密钥 / 启停）：`BTN:RND:MANAGE:USAGE_CATALOG:APP`
