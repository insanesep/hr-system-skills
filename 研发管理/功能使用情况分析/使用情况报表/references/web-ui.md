# 使用情况报表 Web UI 功能描述

## 2. 使用情况报表（usage-report.html）

- **路由**：`/portal/usage-report`
- **权限码**：`devhubUsageReport`
- **页面类型**：看板页

> 页面级形态、KPI 卡类型、主显示文本、路由层级、三 Chart 排布、0 触发路由的产品向硬约束见 [SKILL.md §使用情况报表（产品向硬约束）](../SKILL.md#使用情况报表产品向硬约束)；视觉与组件硬约束以前端页面规范为准。原型见 [../assets/web/usage-report.html](../assets/web/usage-report.html)。

### 区块职责

| 区块 | 说明 |
|------|------|
| 顶部全局筛选 | 接入系统（必选，记住上次选择） / 时间范围（默认近 30 天，跨度 ≤ 90 天） / 端 / 角色 / 功能名称（二级，取自功能目录，含「未归类」） / 聚合粒度（日/周/月）。选中具体功能后，KPI、三 Chart、路由聚合表全部按该功能过滤 |
| KPI 4 卡 | 总事件（连续变化，面积折线 / 主色，副文日均） / 活跃功能（连续变化，面积折线 / 主色，副文目录启用数） / 活跃用户（离散周期对比，柱状 / 成功色，副文角色偏好功能数） / 不活跃功能（离散周期对比，柱状 / 警告色，副文占启用比例）；迷你图按聚合粒度切片，口径见[业务规则 §5.1](../../references/business-rule.md#51-kpi-卡) |
| 三 Chart 一排 | 按所选粒度的趋势折线（事件数与活跃用户数双轴） \| TOP 10 高频功能（标签为「功能名 · 二级路由」，前三名高亮） \| 角色偏好分布环形图（前 7 个角色，其余合并为「其他」，未上报角色为「未知角色」） |
| 路由聚合表 | 以功能目录全量启用项为基准关联周期内事件；列为路由（附页面标题）/ 功能数 / 事件数 / 用户数 / 占比 / 平均停留 / 状态 / 操作；事件数 / 用户数为 0 也呈现，打 `INACTIVE` 灰色标签；默认按事件数降序、0 触发置末尾；支持「仅未触发」筛选 |
| 功能下钻 | 点击行操作列「下钻」按钮或表格内置展开 / 收起按钮，在当前行下方展开嵌套二级表，显示该路由下的功能级汇总（功能编码 / 功能名称 / 事件数 / 用户数 / 三维标签），含零触发的启用功能；首次展开时异步加载数据，再次点击收起 |
| 功能打标清单 | 最近一期打标快照的功能清单（功能名称与编码 / 二级路由 / 周期事件数 / 周期用户数 / 三维徽章），显示快照周期；可按频次、人次、角色偏好筛选，点击徽章按该维度筛选；未生成时提示「尚未生成标签」 |
| 导出报表 | 按当前筛选导出「二级路由 × 功能」明细 CSV，含事件数、用户数与三维标签 |

### 按钮权限码

- 导出报表：`devhubUsageReportExport`
