# 使用情况报表

## 功能职责与入口

按全局筛选条件展示功能使用 KPI、趋势、TOP10、角色偏好与路由聚合，支持功能下钻、Tag 筛选和报表导出。路由下钻在当前行展开嵌套功能表，归本菜单，不另设页面入口。

- **菜单归属**：研发管理 → 功能使用情况分析 → 使用情况报表。
- **路由**：`/portal/usage-report`。
- **菜单权限**：`MENU:RND:MANAGE:USAGE_REPORT`。
- **按钮权限**：见 [Web UI §按钮权限码](references/web-ui.md#按钮权限码)；授权范围与账套隔离见[共享权限规则](../references/business-rule.md#7-权限与可见性)。

## 使用情况报表（产品向硬约束）

> - **顶部全局筛选**：接入系统 / 时间范围（默认近 30 天） / 端 / 角色 / **功能名称（二级，取自功能目录）** / 聚合粒度（日/周/月）。选中具体功能后，KPI、三 Chart、路由聚合表均按该功能过滤，为全局维度筛选而非列表局部筛选。
> - **KPI 卡类型**：4 等分卡统一使用「左文本 + 右迷你趋势图」布局；连续变化量（总事件、活跃功能）用面积折线，离散周期对比（活跃用户、不活跃功能）用柱状；上升是好事用主色 / 成功色，「不活跃功能数」用警告色。禁止使用纯文本 KPI 卡。
> - **页面明细统一按「功能名称」展示**：所有可视层一律以功能名称（中文）为主显示文本，功能编码仅用于定位与 CSV 导出列。
> - **路由统一到二级路由**：所有页面级聚合一律以「一级 / 二级」两段路由展示，不展开动态参数段与三级以下子路径；下钻明细才进入功能粒度。
> - **三 Chart 一排**：合并为单一分析面板，三列等宽呈现「按日趋势折线」「TOP 10 高频功能（标签为「功能名 · 二级路由」）」「角色偏好分布饼图」。
> - **路由聚合表必须含 0 触发路由**：以功能目录全量启用项为基准关联周期内事件，事件数 / 用户数为 0 也呈现并打 `INACTIVE` 灰色标签；默认按事件数降序、0 触发置末尾，支持「仅未触发」筛选。
