# Web 端 UI 描述（品牌成本报表）

> 页面通用硬约束以[分组 SKILL.md Prerequisites](../../SKILL.md#prerequisites)中「前端页面规范」为准，此处仅描述产品侧元信息。共享说明与页面导航见[分组 UI 索引](../../references/web-ui.md)。

## 页面清单

### 品牌成本报表

- **页面路径**：`/rnd/dev-cost/report`
- **权限编码**：
  - 路由：`MENU:RND:DEV_COST`
- **页面类型**：看板页（透视表）
- **区块职责**：
  - 工具栏：费用年月范围（月份范围，必填，默认近 12 个月，按覆盖区间相交命中单据）、费用科目多选（默认全部）、品牌多选（默认全部）、「叠加科目维度」勾选项（勾选后行 = 品牌 → 科目二级行）、查询 / 重置按钮；头部 hint「仅统计已审核单据 · 按费用开始~结束年月逐月均摊 · 单位：元」
  - KPI 卡片行（3 列）：期间费用总额（= 范围内各月分摊额之和，非单据全额）/ 分摊品牌数 / 涉及费用单数（按覆盖区间相交命中）
  - 主体区：透视表 —— 列 = 费用年月（横向升序）；行 = 品牌（勾选叠加时为 品牌 → 科目二级行，品牌行加粗小计）；交叉格 = 分摊金额（两位小数，无数据显示 `-`）；末列 = 行合计；末行 = 列合计；右下角 = 总计
- **布局引用**：参见原型 [cost-report.html](../assets/web/cost-report.html)

#### 导航关系

- 来源页：管理后台侧边菜单「研发管理 → 研发成本统计 → 品牌成本报表」；原型中可经顶部页面切换条与费用列表互跳
- 去向页：无（只读透视，无下钻）
- 返回行为：浏览器返回 / 面包屑返回上级菜单
- 面包屑：首页 / 研发管理 / 研发成本统计 / 品牌成本报表（由后台统一布局渲染，页面内不出现）

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询按钮 | 否 | 全页面板骨架屏 | 静默刷新 KPI 与透视表 → 停留本页 | 面板内错误提示条 + 重试按钮 |
| 重置 | 点击重置按钮 | 否 | 无 | 筛选恢复默认（近 12 个月 + 全部 + 不叠加科目）并自动重查 | 同查询失败 |
| 叠加科目维度 | 勾选 / 取消勾选 | 否 | 表格加载态 | 透视表行维度切换（品牌 ↔ 品牌 × 科目） | 同查询失败 |

#### 三态

- 加载态：KPI 卡片与透视表骨架屏
- 空态：范围内无已审核单据 → 透视表区居中「暂无成本数据」
- 错误态：查询失败 → 错误提示条 + 重试，不暴露内部细节
