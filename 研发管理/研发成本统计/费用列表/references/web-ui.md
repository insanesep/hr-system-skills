# Web 端 UI 描述（费用列表）

> 页面通用硬约束以[分组 SKILL.md Prerequisites](../../SKILL.md#prerequisites)中「前端页面规范」为准，此处仅描述产品侧元信息。费用明细是费用列表所属的非菜单独立操作页；共享说明与页面导航见[分组 UI 索引](../../references/web-ui.md)。

## 页面清单

### 费用列表

- **页面路径**：`/rnd/dev-cost/list`
- **权限编码**：
  - 路由：`MENU:RND:DEV_COST`
  - 按钮：`BTN:DEV_COST:CREATE`（新增 / 编辑 / 删除）、`BTN:DEV_COST:AUDIT`（审核 / 作废）
- **页面类型**：列表页
- **区块职责**：
  - 工具栏：筛选（费用年月范围、费用科目单选下拉、单据状态单选下拉、制单人输入框、流水号输入框）+ 查询 / 重置按钮；右侧「新增费用」主按钮
  - 主体区：费用单表格，列 = 流水号 / 费用科目 / 费用金额（右对齐，两位小数）/ 费用开始年月 / 费用结束年月 / 单据状态（标签胶囊：待审核 = 警示色、已审核 = 成功色、已作废 = 中性灰）/ 制单人 / 制单时间 / 审核人 / 审核时间 / 操作
  - 操作列按状态与权限渲染：待审核 = 查看 · 编辑 · 审核 · 删除；已审核 = 查看 · 作废；已作废 = 查看。制单人 = 当前登录人时「审核」禁用（规则见 [业务规则 §4](../../references/business-rule.md#4-权限与操作矩阵)）
- **布局引用**：参见原型 [cost-list.html](../assets/web/cost-list.html)

#### 导航关系

- 来源页：管理后台侧边菜单「研发管理 → 研发成本统计 → 费用列表」；原型中可经顶部页面切换条与品牌成本报表互跳
- 去向页：「新增费用」→ 费用明细（新增态）；操作列「查看 / 编辑」→ 费用明细（查看态 / 编辑态）
- 返回行为：浏览器返回 / 面包屑返回上级菜单
- 面包屑：首页 / 研发管理 / 研发成本统计 / 费用列表（由后台统一布局渲染，页面内不出现）

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询按钮 | 否 | 表格加载态 | 静默刷新表格 → 停留本页 | toast 错误提示 + 按钮恢复 |
| 重置 | 点击重置按钮 | 否 | 无 | 筛选恢复默认（近 12 个月 + 全部）并自动重查 | 同查询失败 |
| 新增费用 | 点击新增按钮 | 否 | 路由跳转 | → 费用明细（新增态） | — |
| 审核 | 待审核行点击「审核」 | 气泡确认「确认审核通过该费用单？」 | 按钮 loading | toast「审核成功」→ 行状态刷新为已审核 | toast 错误提示（如「单据状态已变更，请刷新」） |
| 作废 | 已审核行点击「作废」 | 气泡确认「作废后不可恢复、不再计入统计，确认？」 | 按钮 loading | toast「已作废」→ 行状态刷新为已作废 | toast 错误提示 + 按钮恢复 |
| 删除 | 待审核行点击「删除」 | 气泡确认「删除后不再展示，确认？」 | 按钮 loading | toast「已删除」→ 行移除 | toast 错误提示 + 按钮恢复 |

#### 三态

- 加载态：表格骨架屏
- 空态：筛选结果为空 → 表格区居中「暂无费用单据」
- 错误态：查询失败 → 面板内错误提示条 + 重试按钮

### 费用明细

- **页面路径**：`/rnd/dev-cost/create`（新增）、`/rnd/dev-cost/edit/:id`（编辑）、`/rnd/dev-cost/detail/:id`（查看）
- **权限编码**：
  - 路由：`MENU:RND:DEV_COST`
  - 按钮：`BTN:DEV_COST:CREATE`（保存）
- **页面类型**：表单页（新增 / 编辑 / 查看三态合一，查看态全只读）
- **区块职责**：
  - 单据信息区（只读，编辑态可见）：流水号、单据状态（标签胶囊）、制单人、制单时间、审核人、审核时间；新增态不渲染本区
  - 单据头表单：费用科目（单选下拉，7 项枚举）、费用金额（数字输入，两位小数）、费用开始年月（月份选择器）、费用结束年月（月份选择器，≥ 开始年月）；表单旁实时提示「覆盖 N 个月，月均 X 元/月」
  - 品牌分摊明细子表：列 = 品牌（下拉，已选互斥）/ 分摊比例 %（数字输入，末行只读倒算）/ 分摊金额（只读，系统计算）/ 操作（删除行）；子表底部「添加分摊品牌」按钮 +「均摊」快捷按钮；合计行 = 比例合计（须 = 100%，不等时标红）/ 金额合计（须 = 费用金额）
  - 底部操作条：保存（新增 / 编辑态）、返回
- **布局引用**：参见原型 [cost-detail.html](../assets/web/cost-detail.html)

#### 导航关系

- 来源页：费用列表「新增费用」/ 操作列「查看」「编辑」
- 去向页：保存成功 → 费用列表；「返回」→ 费用列表
- 返回行为：浏览器返回；表单有未保存修改时弹脏数据离开确认
- 面包屑：首页 / 研发管理 / 研发成本统计 / 费用明细（由后台统一布局渲染，页面内不出现）

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 添加分摊品牌 | 点击「添加分摊品牌」 | 否 | 无 | 子表追加一行（品牌下拉仅展示未选品牌）；已达 4 行时按钮禁用 | — |
| 均摊 | 点击「均摊」 | 否 | 无 | 已选品牌行等比填充比例，末行倒算兜底 | — |
| 删除明细行 | 行内点击「删除」 | 否 | 无 | 行移除，剩余末行重新倒算；仅剩 1 行时禁止删除 | — |
| 保存 | 点击保存 | 否 | 按钮 loading | toast「保存成功」→ 1s 后跳费用列表 | 表单顶部错误提示条 + 按钮恢复 |

#### 表单校验

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 费用科目 | 是 | 必选其一 | 失焦 | 请选择费用科目 | 否 |
| 费用金额 | 是 | > 0，两位小数 | 失焦 | 请输入大于 0 的金额（两位小数） | 否 |
| 费用开始年月 | 是 | 必选月份，且 ≤ 费用结束年月 | 选择变更 | 请选择费用开始年月 / 开始年月不能晚于结束年月 | 否 |
| 费用结束年月 | 是 | 必选月份，且 ≥ 费用开始年月 | 选择变更 | 请选择费用结束年月 / 结束年月不能早于开始年月 | 否 |
| 分摊品牌 | 是 | 每行必选且单内唯一 | 选择变更 | 请选择品牌 / 同一品牌只允许一行 | 否 |
| 分摊比例 | 是 | > 0 且 ≤ 100，两位小数；合计 = 100% | 失焦 / 保存 | 比例需大于 0 / 比例合计须等于 100%，当前差额 X% | 否 |
| 末行倒算 | 系统 | 末行倒算结果 ≤ 0 时阻断 | 保存 | 末行倒算比例小于等于 0，请调整前行比例 | 否 |

- 提交成功跳转：`/rnd/dev-cost/list`，延迟 1s
- 提交失败展示：表单顶部错误提示条
- 脏数据离开：确认弹窗「当前表单有未保存修改，确认离开？」
