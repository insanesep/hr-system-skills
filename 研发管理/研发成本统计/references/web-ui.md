# Web 端 UI 索引（研发成本统计）

> 页面通用硬约束以[分组 SKILL.md Prerequisites](../SKILL.md#prerequisites)中「前端页面规范」为准；本文件仅承载共享说明与页面导航，产品侧页面元信息由各叶功能的 UI 文档持有。

## 共享说明

- 菜单分组为「研发管理 → 研发成本统计」，下辖「费用列表」「品牌成本报表」两个菜单叶子。
- 费用明细的新增 / 编辑 / 查看是费用列表所属的非菜单独立操作页，不另设菜单。
- 单据状态、品牌分摊、权限与统计口径统一引用[业务规则](business-rule.md)；字段、实体关系与枚举统一引用[数据模型](data-model.md)。
