# Web 端 UI 描述（人员活跃看板）

> 仅描述产品侧元信息；判定与口径见 [business-rule.md](business-rule.md)，字段见 [data.md](data.md)。原型组件与样式约束按 PM 原型生成 prompt 执行。

## 页面清单

### 人员活跃看板

- **页面路径**：`/subapp/devhub/rnd/member-activity`；带 `?memberId=:id` 时打开后直接展开该人员的人员详情抽屉
- **权限编码**：
  - 路由：`devhubMemberActivity`
- **页面类型**：分析看板（读数与发现异常人员，下钻人员详情）
- **区块职责**：
  - 页头：标题「人员活跃看板」；副文案展示数据口径「按每日提交活动与 Qoder 用量超过 500 Credits 两类信号分级；产品在云效创建一条需求计一次提交」与数据更新时间（最近一次汇总时间）
  - 筛选卡：组织级联选择（中心起选，可选至小组，默认规则见 business-rule.md §2）、日期范围（默认本月 1 日至昨日，约束见 §3）、成员多选（支持搜索，收起后最多展示 3 个标签）；右侧「重置」「查询」
  - 降级提示条：外部效能平台不可用时在筛选卡下方展示「外部效能平台数据未取得，保留已取得活跃信号，不推测出勤」；无可见组织时展示「暂无可查看的组织，请联系管理员开通组织数据权限」并不渲染下方区域
  - KPI 网格（4 项）：统计人数（副文案：身份未登记 N 人 · 待核对 N 人）、组织活跃率（按等级着色）、人员等级分布（绿 / 黄 / 红人数 + 无应出勤人数 + 未取得人数）、不活跃人天；口径见 business-rule.md §10
  - 视图卡：页签「活跃甘特」「提交散点」「角色指标」，默认「活跃甘特」
  - 活跃甘特视图（规则见 business-rule.md §7）：
    - 卡头：图例（绿 · 提交 + 用量、黄 · 仅一项、红 · 应出勤无活跃、灰斜纹 · 数据未取得；背景：休息日、请假、考勤异常）与「全部展开」「全部收起」
    - 甘特主体：左侧固定列为组织分组头 / 人员姓名（身份未登记、身份待核对标签）；中部为日期列（日期 + 星期，休息日列头弱化）；右侧固定列仅为活跃天数、活跃率，无等级列
    - 首行「当日活跃人数」汇总行；分组头行展示节点名称、统计人数、组织活跃率、各日活跃人数，可折叠
    - 悬浮日期格的提示内容见 business-rule.md §7
    - 日期列超出宽度时横向滚动，左右固定列不随滚动
  - 提交散点视图（规则见 business-rule.md §7.1）：
    - 标题「提交次数与次均代码提交量」，说明「总次数 = Git 提交 + 产品云效需求创建；次均代码量 = Git 新增行数 ÷ Git 次数；仅表示数量，不作为绩效评价」
    - 范围信息：当前组织路径、起止日期；统计说明：已绘制 / 统计人数、无提交人数、仅需求提交人数、提交数据未取得人数
    - 主图：横轴「提交总次数（Git + 产品需求）」、纵轴「次均代码提交量（新增行 / Git 次）」、从 0 起的自适应线性刻度与网格；点颜色按周期等级，图例为绿、黄、红、未取得 / 无应出勤，不设置图内筛选
    - 点提示：姓名、组织路径、角色、提交总次数、Git 次数、产品云效需求创建次数、Git 新增 / 删除行数、次均代码量、周期等级；同坐标显示人数，提示内各人员姓名有详情入口
    - 悬浮或键盘聚焦展示提示，单人点点击或按 Enter / 空格打开人员详情；多人同坐标点点击展开提示，选择人员再下钻
    - 空态与排除人数说明同 business-rule.md §7.1，加载和失败复用当前视图区公共反馈；窄屏图表自适应，不出现整页横向滚动
  - 角色指标视图（规则见 business-rule.md §8）：
    - 顶部说明：「统计月份：YYYY 年 M 月 · 外部效能平台口径」
    - 角色页签：开发 N / 产品 N / 测试 N，页签栏右侧展示「未匹配角色 N 人」
    - 表格：共有列 + 当前角色列表指标列，不展示等级列（列清单见 business-rule.md §8 表）；行首展开按钮，展开后按角色分组卡片展示指标项；数值列可排序；分页 20 人 / 页
  - 人员详情抽屉（右侧，宽抽屉）：
    - 头部：姓名、组织路径、角色、周期等级标签、身份对应状态标签
    - 活跃概况：活跃天数、应出勤天数、活跃率、休息日活跃天数、数据未取得天数
    - 个人活跃日历：本人在筛选期间的单行甘特，着色与悬浮规则同活跃甘特
    - 提交活动：期间提交总次数、Git 次数、产品云效需求创建次数（仅产品显示）、Git 新增 / 删除行数；分来源展示未取得，不将需求创建折算为代码行数
    - Qoder 用量：期间 Credits、请求数、次均消耗、超过 500 Credits 天数
    - 排期卡片：领取数、完成数、进行中、延期数；下方卡片列表（编号、标题、状态、领取日期、完成日期），编号可点击
    - 考勤：出勤、请假、休息日、考勤异常天数
    - 角色指标：按角色分组卡片展示（与角色指标视图展开内容一致）；无角色时展示「暂无角色指标」
- **组件引用**：`busyming-skills-design/components/web/` 下的级联选择、日期范围、下拉多选、按钮、标签页、表格、分页、标签、抽屉、空状态、骨架屏、提示；甘特图和提交散点图暂无对应组件，按组件缺口临时补齐
- **编排标准**：`busyming-skills-design/shared/page-standards/web-dashboard.md`
- **布局引用**：参见原型 `assets/web/member-activity.html`

#### 导航关系

- 来源页：管理后台侧边菜单「研发管理 → 人员活跃看板」；带 `memberId` 的链接直达并打开人员详情抽屉
- 去向页：
  - 甘特人员姓名、提交散点单人点 / 提示内人员姓名或角色指标行「详情」→ 打开本页人员详情抽屉，地址追加 `memberId`
  - 抽屉内排期卡片编号 → 新标签页打开功能排期管理卡片详情
- 返回行为：抽屉右上角关闭或点击遮罩关闭抽屉并移除地址中的 `memberId`，回到看板原滚动位置；浏览器返回同样关闭抽屉；页面级返回由后台布局面包屑回到上级菜单
- 面包屑：首页 / 研发管理 / 人员活跃看板（由后台统一布局渲染）

#### 操作反馈清单

本页全部为只读查询，无写操作。

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 筛选校验通过后点击「查询」 | 否 | 查询按钮 loading + KPI、视图区骨架屏 | 静默刷新 KPI 与当前视图 → 停留本页，视图滚动回顶部 | 区块内错误提示「人员活跃数据加载失败」+「重试」，查询按钮恢复可用 |
| 重置 | 点击「重置」 | 否 | 同查询 | 筛选恢复默认并自动查询，BusyMessage.success「已恢复默认筛选」→ 停留本页 | 同查询失败 |
| 切换组织 | 级联选择变更 | 否 | 成员下拉 loading | 清空已选成员，成员可选清单按新组织刷新；需点「查询」刷新数据 | 成员下拉内展示「成员加载失败，点击重试」 |
| 切换视图 | 点击「活跃甘特」/「提交散点」/「角色指标」 | 否 | 散点读取同次查询汇总，无独立加载；首次进入角色指标时表格骨架屏 | 展示对应视图，保留组织、日期、成员筛选 → 停留本页 | 散点复用查询错误提示；角色指标区错误提示「角色指标加载失败」+「重试」 |
| 查看散点 | 悬浮或聚焦点；点击或 Enter / 空格 | 否 | 无 | 展示人员数据提示；单人点点击直接打开详情，多人同坐标选择姓名后打开详情 → 保留散点视图 | 同打开人员详情失败 |
| 切换角色页签 | 点击开发 / 产品 / 测试 | 否 | 表格 loading | 表格切换为对应角色列，页码回到第 1 页 | 同切换视图失败 |
| 折叠 / 展开分组 | 点击分组头或「全部展开」「全部收起」 | 否 | 无 | 对应分组行收起或展开 → 停留 | 无 |
| 展开指标行 | 点击行首展开按钮 | 否 | 无（随列表一次取得） | 行下方展开角色分组卡片 | 无 |
| 打开人员详情 | 点击人员姓名或「详情」，或带 `memberId` 进入 | 否 | 抽屉内骨架屏 | 抽屉展示该人员详情 | 抽屉内错误提示「人员详情加载失败」+「重试」；无权查看时 BusyMessage.error「无权查看该人员」并关闭抽屉 |
| 关闭人员详情 | 点击关闭、遮罩或浏览器返回 | 否 | 无 | 抽屉关闭 → 回到看板原位置 | 无 |
| 打开卡片详情 | 点击抽屉内卡片编号 | 否 | 无 | 新标签页打开功能排期管理卡片详情，本页保持 | 卡片不存在时由目标页提示 |

#### 表单校验

- 初态：组织默认当前登录人主职所在中心；日期范围默认本月 1 日至昨日（每月 1 日取上月整月）；成员为空（即全部）
| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 组织 | 是 | 必须选中可见范围内的中心或其下级节点 | change / 查询时 | 「请选择组织」 | 否 |
| 日期范围 | 是 | 起止日期均早于今天（今天及以后置灰不可选），跨度不超过 31 天 | change | 清空时「请选择日期范围」；超跨度「日期范围不能超过 31 天」；选到今天及以后「今天及以后的日期不可选」；校验失败恢复上一次有效范围 | 否 |
| 成员 | 否 | 仅可选当前组织下的统计人员 | — | — | 否 |

- 提交成功跳转：不跳转，停留本页刷新数据
- 提交失败展示：区块内错误提示与「重试」
- 脏数据离开：本场景不需要（筛选条件不保存）
