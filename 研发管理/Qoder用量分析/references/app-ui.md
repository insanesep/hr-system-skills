# App 端 UI 描述（Qoder 用量分析）

> 页面通用硬约束（含触控尺寸）以 busyming-skills-design 的 page-blueprint 页面生成提示词【2. 硬约束】为准，此处仅描述产品侧元信息。

产研团队筛选只读引用[产研人员管理 · 报告范围](../../产研人员管理/references/business-rule.md#report-scope)与[身份映射](../../产研人员管理/references/business-rule.md#identity)；「全部成员」仍为原 Qoder 组织范围。

## 页面清单

### Qoder 用量分析

- **页面路径**：`/rnd/qoder-usage`
- **权限编码**：
  - 菜单：`devhubAppQoderUsage`
  - 独占：`devhubAppQoderUsageM`
- **导航方式**：Push（首页工作台图标进入）
- **页面类型**：`dashboard`
- **页面元素与 Web 端保持一致**（区块集合同 web-ui.md，移动端仅做布局适配）：
  - 顶部导航栏：标题「用量分析」+ 左侧返回按钮
  - 公共筛选（驱动全部视图）：日期预设选择器（今日 / 昨日 / 前 7 天 / 近 30 天 / 自定义，默认「前 7 天」）+ 部门（单选：全部 / 数字化中心 / 创新业务部，默认全部）+ 统计范围（产研团队 / 全部成员，默认产研团队）+ 成员多选（默认当前部门与统计范围交集内全部成员）+ 查询（主色）/ 重置按钮；筛选元素与 Web 对齐，日期控件为预设形态（约束见 business-rule.md §1）
  - 产研团队范围下名单为空或名单内无 Qoder 成员时，筛选区下方展示提示「产研团队人员范围为空或名单内无 Qoder 成员，请到「产研人员管理」核对人员范围与身份映射」
  - KPI 统计卡片（5 卡，与 Web 一致）：总用量（Credits + 周环比）、总请求数（次 + 周环比）、次均消耗（Credits/次 + 周环比）、人均用量（Credits + 周环比）、活跃成员（人 + 周环比）；2 列网格，第 5 卡跨满一行
  - 日 Credits 消耗堆叠柱形图卡片：标题「日 Credits 消耗趋势」+ 各模型分类图例（换行排列）；每日一根堆叠柱按模型分段堆叠（分类归并与配色规则见 business-rule.md §6），Y 轴 0-1000 刻度，X 轴每日日期
  - Credits 用量透视表卡片：标题「Credits 用量透视表」+ hint「成员 × 日期 · Credits」；横向滚动表格、首列（成员）冻结，列 = 成员 | 日期列（按天升序，排序规则见 business-rule.md §3）| 合计；每成员一行 + 合计行
  - 模型用量透视表卡片：标题「模型用量透视表」+ hint「成员 × 模型等级 · Credits」；横向滚动表格，首列成员冻结，列 = 成员 | 模型等级列（前 5 个 + 其他模型，归并与排序规则见 business-rule.md §4）| 合计；每成员一行 + 合计行（合计行带列占比，格式见 business-rule.md §4）；数值两位小数
- **布局引用**：参见原型 `assets/app/qoder-usage-analysis.html`（页面类型 `dashboard`：整页范例 busyming-skills-design/mobile/templates/dashboard.html，DOM 依据 skeletons/app/dashboard-mobile.tsx.tpl；区块顺序：导航栏 → 筛选 → 统计卡片 → 图表与透视表卡片）

#### 导航关系

- 来源页：App 首页工作台「Qoder 用量分析」图标 Push 进入
- 去向页：无（只读单页）
- 返回行为：导航栏返回按钮 / 手势返回 → 首页工作台
- 手势返回：允许（只读页无脏数据）

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询按钮 | 否 | 全页面板骨架屏 | 静默刷新全部视图 → 停留本页 | 错误轻提示 + 下拉重试 |
| 重置 | 点击重置按钮 | 否 | 无 | 筛选恢复默认（前 7 天 + 部门=全部 + 产研团队 + 交集内全部成员）并自动重查 → 停留本页 | 同查询失败 |
| 切换部门 | 部门单选变更 | 否 | 成员清单刷新 | 清空已选成员，成员清单与全部视图按新部门重查 | 同查询失败 |
| 切换统计范围 | 统计范围变更 | 否 | 成员下拉刷新 | 清空已选成员，成员清单与全部视图按新范围重查 | 同查询失败 |
| 下拉刷新 | 列表顶部下拉 | 否 | 下拉刷新动效 | 静默刷新 → 停留本页 | 错误轻提示 |

#### 三态

- 加载态：品牌 Loading 动效（内嵌）
- 空态：筛选范围内无事件 → 图表与表格区「暂无用量数据」（文案口径见 business-rule.md §7）
- 错误态：错误结果页 + 重试按钮
