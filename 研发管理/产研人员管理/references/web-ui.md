# 产研人员管理 · Web 页面

<a id="pages"></a>
## 1. 页面与共用约定

本文件定义产品页面对象与地址约定，不宣称菜单或路由已部署。页面采用设计系统 `archive-list`、`archive-form`、`archive-detail` 模板；表格、选人、表单、确认与反馈复用公共组件和样式，不私建布局。页面按钮职责引用[权限规则](permission-rules.md#boundaries)。

| 页面 | 页面地址约定 | 类型 |
| --- | --- | --- |
| 人员列表 | `/rnd/members` | archive-list |
| 新人员资料编辑 | `/rnd/members/create?userId={集团人员标识}` | archive-form |
| 编辑人员 | `/rnd/members/:id/edit` | archive-form |
| 人员详情 | `/rnd/members/:id` | archive-detail |

页面均具有加载、完整空态、错误与重试状态；请求失败不能用空列表、零权限或零用量冒充完整结果。跨页仅传稳定人员标识，直达重新读身份和权限，不依赖列表内临时对象。

## 2. 人员列表

- 页头：产研人员管理；有维护权时显示新增人员。
- 查询区默认显示姓名或工号、域、项目、角色与业务状态，授权联动状态在展开筛选中；域与项目为级联筛选，选项引用同步清单。未选域时项目不可选，选域后只展示其一级目录项目；可只选域查询该域全部参与人员，也可继续选项目查询该项目参与人员。默认排除已删除，可切换历史范围。
- 表格：公共姓名与工号、报告展示名、角色、业务状态、参与域/项目、负责人身份、授权差异摘要、报告纳入状态、最近变更、查看/编辑/启禁/删除。
- 授权状态展示真实联动结果；权限已达目标和仍有继承权限分别显示，不以人员启用代替授权成功。
- 角色和状态只展示真源取值，定义见[人员规则](business-rule.md#identity)与[状态规则](state-machine.md#states)。

### 导航关系

来源为研发管理菜单；新增打开本页集团人员搜索弹窗，姓名精确查询、唯一勾选后点击下一步，携带所选集团人员标识进入资料编辑页。查看或点击人员名进入独立详情，已有人员编辑进入编辑表单。详情返回保留原查询条件；页头返回研发管理菜单入口，面包屑为研发管理 / 产研人员管理，不编造全门户导航。

### 表单校验

域切换或清空时清空项目并更新候选，保留姓名、角色、状态等其他条件；域下没有项目时项目不可选，明确提示仍可只按域查询。重新选择同一域不清空有效项目。只修改选项不立即改变列表，点击查询后按姓名、角色、状态与域项目条件取交集；项目必须属于当前域，非法组合拒绝查询并保留原结果，不产生空成功。查询回到第一页，重置清空域项目并恢复项目不可选；从详情返回时恢复已应用的有效级联条件。查询无未保存业务变更，不需要脏离开守卫。状态动作的确认表单校验原因与交接结果，提交失败保留输入。

新增搜索弹窗初始姓名为空，不显示集团全量名单，下一步禁用；姓名首尾空白去掉后按公共姓名精确匹配，不能按片段或别名检索。查询、姓名修改会清空已选人员，结果按稳定身份过滤已有档案，含禁用及已删除；同名不同标识分别展示工号和部门，单选互斥。只有唯一选择、姓名未变且人员仍可新增时下一步可执行。取消或关闭搜索不保存业务资料，无需未保存资料确认；查询失败保留姓名并允许重试，不能误报空名单。原型使用模拟集团人员，不证明生产姓名精确查询已接入。

## 3. 新增/编辑人员表单

- 基础区：从新增搜索弹窗带入集团人员，或读取已有档案的门户关联；姓名、工号、部门、公共状态和稳定标识始终只读，不在本页提供重新选人控件。报告展示名默认为所选集团姓名，业务角色和其他资料由本页维护。
- 身份映射区：按阿里云身份、Qoder身份、企业微信身份三个维度分别维护稳定账号标识；缺失显示未维护，核验状态独立呈现，不再使用混合来源账号或通用别名输入框。
- 参与关系区：从同步清单选择域/项目及参与身份，选项只能是人员基本业务角色。基本角色收窄使原参与身份不合法时清空并提示重新选择或解除关系，保存和启用均校验非空子集。负责人任命与项目上级只读，修改入口指向域及项目管理。
- 页尾保存、取消；业务状态不通过表单隐藏字段私改，启禁走明确状态动作。

### 导航关系

新人员资料编辑来源为搜索弹窗下一步，已有档案编辑来源为列表或详情编辑。保存后进入该人员详情；取消新建返回列表，不留下空档案，已有编辑返回来源页。面包屑研发管理 / 产研人员管理 / 人员资料编辑；地址分别携带集团人员标识或已有产研人员标识。

### 表单校验

初态：新增已由搜索弹窗唯一选择集团人员，页面地址携带集团人员标识，基础身份只读，报告展示名预填集团姓名，角色与归属为空，保存后的业务状态固定禁用；已有档案编辑读取保存值和最新公共状态。未携带有效集团标识或该人已有档案时不展示新增表单，提示返回搜索或维护原档案。

| 字段 | 必填 | 校验规则 | 时机 | 错误文案 | 异步 |
| --- | --- | --- | --- | --- | --- |
| 集团人员 | 是，只读 | 搜索下一步带入的稳定身份；有效且未建立档案，新建保存再次校验唯一性 | 页面加载、下一步及保存 | 该人员已有档案或集团身份已失效，请重新选择或维护原档案 | 是 |
| 报告展示名 | 是 | 非空，沿用公共名称作初值 | blur及提交 | 请填写报告展示名 | 否 |
| 角色 | 是 | 至少一个真源角色，任命资格仍满足 | change及提交 | 请选择角色；该变化不满足当前负责人资格 | 是 |
| 阿里云身份 | 产品授权核验前必填 | 同一来源账号唯一，不按姓名推断，登记后须真实核验 | blur及提交 | 阿里云身份已关联其他人员，请核对 | 是 |
| Qoder身份 | 否 | 按Qoder来源独立校验唯一，不能从其他来源补造 | blur及提交 | Qoder身份已关联其他人员，请核对 | 是 |
| 企业微信身份 | 否 | 按企业微信来源独立校验唯一，不能从其他来源补造 | blur及提交 | 企业微信身份已关联其他人员，请核对 | 是 |
| 参与对象与身份 | 选择参与对象后是 | 对象来源有效、域项目相符，参与身份是本人基本角色的非空子集 | change及提交、启用 | 参与身份必须属于基本身份，请重新选择或解除关系 | 是 |

提交定位首个错误字段；失败显示服务错误并保留输入；脏数据离开统一确认“有未保存的人员修改，是否放弃？”。

## 4. 人员详情

摘要显示公共身份、基本角色、业务状态、报告纳入状态；页签仅为参与项目、代码仓权限、身份映射。参与项目展示域、一级目录、项目业务/来源状态、本人的参与身份及对应域负责人上级，同人多项目多上级逐条呈现；不设置重复的责任上下级页签，不提供用户变更记录展示。必要后台审计与历史证据保留，不因页面简化删除。

身份映射页签按阿里云身份、Qoder身份、企业微信身份逐项展示稳定账号标识及各自核验状态；编辑人员使用同样三个维度。没有映射时显示未维护，不展示旧混合身份或自动推断为其他来源。

代码仓权限显示目标、远端实际权限及来源、联动状态、差异、核验时间；同步失败可重试，待管理员处理只展示明确治理事项，不能一键关闭整个共享组。未取得外部权限时显示未核验，不显示无权限。

### 导航关系

来源为人员列表、保存表单及其他功能选人查看；编辑进入人员表单；项目、域名称跳对应独立详情，修改责任进入域及项目管理。页头返回人员列表，保留可用查询条件；面包屑研发管理 / 产研人员管理 / 人员详情。

### 表单校验

本页没有可编辑基础资料表单；状态确认和原因校验复用列表声明。责任修改不在详情内另写上级名单，授权操作没有未保存人员资料，不需要额外脏离开守卫。

## 5. 离线原型入口

| 页面 | 资产 | 场景 |
| --- | --- | --- |
| 人员列表 | [member-list.html](../assets/web/member-list.html) | 查询、历史名单、分页、启禁删除和重置演示数据 |
| 新增/编辑表单 | [member-form.html](../assets/web/member-form.html) | 新建由搜索下一步携带集团标识进入，空地址要求先选择；已有档案按产研人员标识编辑 |
| 人员详情 | [member-detail.html](../assets/web/member-detail.html) | 按人员标识与页签打开，默认展示一条模拟产品人员记录 |

原型使用同源离线演示资料，状态保存在浏览器专属演示键，可从列表重置；数据不是生产人员、仓成员或报告结果。跨页责任与权限目标保持一致，模拟读取、保存或授权失败仍显示明确异常，不把模拟完成等同真实公共能力接入。只提供Web原型，不生成App配置页或总览index页面。
