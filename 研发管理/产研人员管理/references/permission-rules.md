# 产研人员管理 · 权限边界

<a id="boundaries"></a>
## 1. 职责与操作

| 职责权限 | 允许范围 |
| --- | --- |
| 人员查看 | 查看授权范围内业务档案、参与关系与项目上级；敏感身份标识按公共脱敏规范展示 |
| 人员维护 | 集团姓名精确检索、唯一选择后新增、角色与参与关系维护、身份核对 |
| 人员启禁删除 | 进行影响检查、交接确认、业务启禁与逻辑删除；恢复需同权限 |
| 仓授权核验与执行 | 查询联动结果、对已批准目标执行成员变更与核验；必须具有公共渠道写权限 |
| 管理员交接与权限收口 | 处理负责人替换、人工或继承授权收口；共享代码组变化须单独授权 |

职责组合不等于门户权限已登记；菜单、按钮及服务端权限映射均由公共权限体系配置。人员具有产品、研发等角色不等于持有本表维护权限，不能允许通过编辑本人角色取得管理权。

## 2. 边界

- 服务端校验操作身份与当前业务权限，不能仅靠按钮隐藏或前端只读字段防越权。
- 新增、恢复、授权均核验稳定公共身份。映射维护者可按三个来源登记对应标识，但登记不等于外部账号核验或权限开通，不允许通过修改他人映射扩权。
- 参与域项目职责必须满足人员基本角色子集约束；保存与启用在服务端复核，不能因页面选择器只展示合法选项就省略校验。
- 域项目负责人由对应功能维护，本页只读展示。不得通过人员页改上级而绕过责任任命校验。
- 产研业务禁用只收口对应人员的产研业务操作与统计参与；不会自动删除门户账号、无关工具或数据库授权。
- 仓权限政策见[仓授权规则](other-rule-authorization.md#policy)，不隐式授予保护分支、合并、发布、仓库管理、SLS、ARMS或数据库权限。
- Agent 调用仍以持有人身份及明确授权执行；产品文档中的自动联动目标不授予当前 Agent 生产写权限。
- 本功能不新增公共用户、组织、角色配置副本；实际身份和基础数据权限引用公共体系。
