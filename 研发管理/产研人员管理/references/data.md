# 产研人员管理 · 数据定义

<a id="entities"></a>
## 1. 实体关系

- 产研人员与公共门户用户对应一个稳定身份；人员角色、来源身份与参与关系从属于该人员。
- 人员与域、项目可多对多参与；域项目对象及负责人关系引用[域及项目数据](../../域及项目管理/references/data.md#entities)，本模块不建副本。
- 授权联动记录按人员与目标仓归集，仓只存稳定引用；一轮联动可含多个仓结果。
- 报告任务消费名单版本快照；历史报告、卡片与单据不因人员删除清除外部关联。

## 2. 人员档案

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 人员标识 | 产研业务身份 | 标识 | 是 | 系统生成，恢复沿用，不随姓名变化 |
| 门户用户 | 搜索选择后绑定的集团公共身份 | 引用 | 是 | 稳定标识只读；所有已建档身份不重复新增，删除后重用走原档案恢复 |
| 基础姓名、工号、部门、门户状态 | 公共身份展示 | 只读引用 | 是 | 由公共档案提供，不手写维护 |
| 报告展示名 | 人员分析使用名称 | 文本 | 是 | 默认为公共姓名，非唯一主键 |
| 业务角色 | 参与产研的职责集合 | 枚举集合 | 是 | 至少一项，角色语义见业务规则的人员与身份 |
| 业务状态 | 人员是否参与业务 | 枚举 | 是 | 见[state-machine.md](state-machine.md#states)，不替代门户状态 |
| 变更原因 | 本次维护说明 | 文本 | 禁用、删除及恢复时是 | 保留可解释的操作原因 |
| 创建、最后修改人及时间 | 审计信息 | 人员引用、时间 | 是 | 不因删除清除 |

## 3. 来源身份与参与关系

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 关联人员 | 身份及关系所属人 | 引用 | 是 | 引用人员档案 |
| 阿里云身份 | 阿里云及云效用户的稳定账号标识 | 来源身份标识 | 产品授权核验前是 | 按阿里云来源校验唯一，手工登记不代表已核验 |
| Qoder身份 | Qoder成员的稳定账号标识 | 来源身份标识 | 否 | 按Qoder来源校验唯一，未取得不能按姓名或阿里云账号补造 |
| 企业微信身份 | 企业微信人员的稳定账号标识 | 来源身份标识 | 否 | 按企业微信来源校验唯一，未取得明确展示 |
| 各维度核验结果 | 三个来源是否取得有效映射 | 判断结果 | 是 | 各自展示未维护、待核验或已核验；不同来源不共用结果 |
| 参与对象 | 域或项目 | 引用 | 是 | 对象类型和稳定标识共同定位 |
| 参与职责 | 该范围内工作身份 | 角色引用集合 | 是 | 必须是本人基本业务角色的非空子集，不自动任命负责人或扩展基本角色 |
| 关系有效性 | 是否用于当前参与范围 | 判断结果 | 是 | 结合人员、对象状态判定，失效关系留历史 |

## 4. 仓授权联动记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 联动标识、目标版本 | 一轮变更及最新目标 | 标识、版本 | 是 | 用于识别过期动作，不能用旧目标覆盖新目标 |
| 目标人员、目标仓 | 联动对象 | 引用 | 是 | 引用有效身份和稳定仓标识 |
| 目标权限 | 本轮应有权限 | 权限目标 | 是 | 只读引用[仓授权政策](other-rule-authorization.md#policy) |
| 实际有效权限及来源 | 已读取的远端事实 | 只读事实 | 否 | 区分直接、继承与其他授权；未取得显示未核验 |
| 联动状态 | 各仓执行结果 | 枚举 | 是 | 见状态规则的授权联动状态 |
| 差异与失败原因 | 未达到目标的原因 | 文本 | 异常时是 | 安全脱敏，不能泄露凭据 |
| 操作人与开始、结束、核验时间 | 执行证据 | 人员引用、时间 | 是 | 未结束的结束时间为空 |

## 5. 报告范围版本

名单版本保存任务创建时的有效人员、角色和已核验身份映射引用，生成方不另维护成员。报告创建、归档及版本结构归报告配置，人员范围判定唯一见[business-rule.md](business-rule.md#report-scope)。
