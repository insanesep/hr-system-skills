# 产研人员管理 · 状态规则

<a id="states"></a>
## 1. 人员状态

| 状态 | 含义 | 允许动作 |
| --- | --- | --- |
| 禁用 | 保留档案，不进入新产研业务和报告人员范围 | 编辑、启用、删除 |
| 启用 | 满足公共身份和业务条件时参与产研 | 编辑、禁用、删除 |
| 已删除 | 逻辑删除，不出现在默认名单，历史引用保留 | 查看历史、核验并恢复为禁用 |

- 搜索选择及下一步仅携带集团身份，不提前产生人员档案或状态；首次保存新增后进入禁用。启用前按[业务规则](business-rule.md#lifecycle)校验身份、角色和归属。
- 编辑人员的基本角色或参与范围时仍执行身份子集校验；新增、编辑和启用均拒绝空职责或越界职责，不把失效角色默认为另一角色。基本角色收窄后，参与职责须重新选择或解除关系；涉及负责人任命继续执行交接守卫。
- 禁用、删除的业务事实一经提交即作用于后续产研业务，不能因仓关闭失败恢复为启用；联动结果独立展示。
- 禁用、删除前执行负责人和在途交接守卫；公共账号已失效时即时拒绝业务操作并展示交接异常，不等管理员完成交接才收口。
- 并发修改按最新状态和目标版本校验，后到旧版本变更拒绝并提示刷新；已进入目标状态的重复请求不重复生成授权任务。

<a id="authorization-states"></a>
## 2. 各仓授权联动状态

| 状态 | 含义 | 后续动作 |
| --- | --- | --- |
| 待同步 | 最新权限目标已产生，尚未执行 | 使用最新目标执行 |
| 同步中 | 正在变更并核对远端权限 | 查询进度，不重复提交 |
| 已达目标 | 已验证实际有效权限满足本轮目标 | 保留证据，新变化产生新目标 |
| 同步失败 | 外部读取或写入失败，不能证明达到目标 | 展示原因，按最新目标重试 |
| 待管理员处理 | 仍有人工或继承权限、身份冲突或共享治理事项 | 经授权处理后重新核验 |

人员多仓联动逐仓报告结果；仅所有目标仓均已验证达成才显示全部完成。部分完成保留成功仓证据，不以总体进度代替逐仓关闭证明。

新目标产生时，旧任务必须停止使用旧目标执行；已执行的旧动作按当前目标重新核验与纠偏。重试不恢复旧业务状态、不绕过权限校验。
