# 域及项目管理 · 状态规则

<a id="states"></a>
## 1. 业务启停

| 状态 | 含义 | 允许动作 |
| --- | --- | --- |
| 停用 | 保留对象，不参与新业务范围 | 维护责任与映射、启用、同步 |
| 启用 | 来源及责任条件满足时参与业务 | 维护责任与映射、停用、同步 |

同步发现新对象默认停用。域启用需完整有效来源、唯一有效域负责人及特殊资格校验；项目启用需所属域有效、目录存在、至少一名有效负责人。域项目不提供业务删除动作。

域停用不会覆盖子项目原配置，但其有效业务范围关闭；恢复域不自动启用停用子项目，不恢复已失效来源和责任。正常停用须说明影响并检查引用；关闭新业务不清除历史。

## 2. 来源状态

| 状态 | 含义 | 消费方式 |
| --- | --- | --- |
| 已存在 | 完整结构读取确认对象存在 | 结合业务启停、责任与权限判断使用 |
| 已消失 | 已完成完整读取且确认来源不再存在 | 停止新范围消费并重算授权目标，保留历史 |
| 未核验 | 未取得完整结果或身份有歧义 | 展示未核验；不新增有效范围、不凭异常推断消失 |

业务启用不能覆盖来源已消失或未核验。失败读取可展示上一有效结果及其真实时间，但不伪造本轮存在性确认；外部访问应继续执行来源可达性及实际权限校验。

## 3. 同步任务结果

| 状态 | 含义 |
| --- | --- |
| 待执行 | 已提交，尚未读取 |
| 执行中 | 正在读仓资料及一级目录 |
| 全部成功 | 来源范围及全部目标仓完整读取并提交 |
| 部分失败 | 至少一仓完整成功，另有明确失败 |
| 失败 | 全局读取失败、全部仓失败或执行中断 |

逐仓结果与全局结果分别展示。只有完整来源范围读取才能确认域消失；只有该仓完整树读取才能确认项目消失。重复提交复用当前活动任务，任务终态后可按最新源范围重新同步；失败不刷新完整成功时间。
