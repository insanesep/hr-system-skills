# 域及项目管理 · 权限边界

<a id="boundaries"></a>
## 1. 职责权限

| 职责权限 | 允许操作 |
| --- | --- |
| 域项目查看 | 查询被授权的同步清单、责任人与来源结果 |
| 结构同步 | 在已批准接入范围内提交同步、查看逐仓结果与失败重试 |
| 责任与映射维护 | 任命负责人、维护备注和执行映射；不能修改远端结构 |
| 域项目启停 | 校验影响、来源与负责人资格后启停 |

菜单和按钮权限由公共体系登记；拥有域负责人职责不自动取得结构同步或维护全域权限。服务端核验实际操作权及数据范围，不接受前端传入的任意仓或新组织替换已批准范围。

## 2. 外部能力边界

- 同步仅查询仓资料与版本树，不创建、移动、删除或提交远端仓目录，不自动建立新代码仓。
- 普通人员不能通过自改角色或任命本人绕过负责人资格；任命候选引用人员真源的有效业务身份。
- 责任及启停变化触发人员模块重新计算授权目标，不直接代替公共仓成员管理；权限成功以该模块实际核验为准。
- 实现映射不产生额外个人仓权限、MCP工具许可、数据库权限或发布权限；生产写入继续按显式授权及发布流程执行。
- common与design公共资料的强制引用要求不因人员任命、域启停或仓关闭目标而被取消；实际共享仓访问治理需遵守批准的共享权限边界。
- 密码、令牌与组织凭据不作为本页可编辑业务字段，不回显、不写入文档或同步日志。
