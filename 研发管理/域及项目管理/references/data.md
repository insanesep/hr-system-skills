# 域及项目管理 · 数据定义

<a id="entities"></a>
## 1. 实体关系

域与稳定代码仓一一对应，域与一级目录项目一对多。域有唯一负责人，项目可有多名负责人；人员引用[人员档案](../../产研人员管理/references/data.md#entities)，不存第二份角色或公共身份。

项目与实现仓及确认路径多对多；同一实现仓多项目引用不生成多个仓对象。域项目及责任维护只在本功能进行，排期、报告与运维保留稳定引用和各自流程证据。

## 2. 域

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 域标识 | 稳定业务身份 | 标识 | 是 | 系统生成，不随仓名变化 |
| 来源与仓标识 | 唯一代码托管身份 | 只读引用 | 是 | 同步提供；来源和稳定仓标识共同唯一 |
| 域名称、仓名称、远端地址、默认分支 | 仓资料展示 | 只读引用 | 是 | 远端成功同步回显；地址不含凭据 |
| 域负责人 | 本域唯一责任人 | 人员引用 | 启用时是 | 资格见[business-rule.md](business-rule.md#responsibility) |
| 业务状态 | 管理启停 | 枚举 | 是 | 见[state-machine.md](state-machine.md#states) |
| 来源状态、最近完整核验时间 | 存在性与读取证据 | 枚举、时间 | 是 | 不与业务状态合并，来源枚举见状态规则 |
| 特殊责任资格关联 | common/design稳定仓身份规则 | 只读规则引用 | 特殊域是 | 精确识别和资格见业务规则，不由用户随意改域名解除 |
| 备注、维护人及时间 | 管理信息 | 文本、人员引用、时间 | 否 | 不反写仓资料，不含凭据 |

## 3. 项目

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 项目标识 | 稳定目录项目身份 | 标识 | 是 | 系统生成，历史引用保持 |
| 所属域 | 归属代码仓 | 引用 | 是 | 同步来源确定，不手改迁域 |
| 一级目录、项目名称 | 版本树一级目录展示 | 只读文本 | 是 | 由完整树同步提供；不是根文件或猜测名称 |
| 业务状态 | 项目启停 | 枚举 | 是 | 见状态规则 |
| 来源状态、最近完整核验时间 | 目录存在性证据 | 枚举、时间 | 是 | 读取失败不写已消失 |
| 负责人及本项目职责 | 项目责任集合 | 人员引用与角色引用 | 启用时是 | 至少一名，当前资格遵守业务规则 |
| 项目上级 | 各负责人的项目责任上级 | 只读派生 | 是 | 取所属域负责人，不另设可编辑上级 |
| 备注、维护人及时间 | 管理信息 | 文本、人员引用、时间 | 否 | 变更留痕 |

## 4. 执行映射与同步结果

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 关联项目 | 实现范围所属项目 | 引用 | 是 | 稳定项目引用 |
| 实现仓 | 承载实现事实的仓 | 只读引用 | 是 | 从同步域清单选择，允许跨项目重复引用同仓 |
| 确认实现范围 | 仓根或已核验目录范围 | 范围引用 | 是 | 必须取得对应结构事实，不以同名项目猜路径 |
| 维护人、时间与依据 | 映射责任证据 | 人员、时间、文本 | 是 | 不写源码或SQL |
| 同步标识、来源范围及分支 | 本轮同步边界 | 标识、只读引用 | 是 | 使用已批准接入范围，不手写新组织或凭据 |
| 同步结果、逐仓结果及差异 | 完整或部分读取结果 | 枚举与事实列表 | 是 | 见状态规则及[同步规则](other-rule-sync.md#sync) |
| 开始、结束与完整核验时间 | 来源时间证据 | 时间 | 是 | 未结束、未完整成功的对应时间不补造 |

字段定义不重复维护仓成员、报告key、报告分支策略、卡片状态或角色枚举；对应资料由各功能真源提供。
