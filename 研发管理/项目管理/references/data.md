# 项目管理 · 数据定义

<a id="entities"></a>
## 1. 实体关系

| 实体 | 关系 | 含义 |
| --- | --- | --- |
| 项目 → harness 工程 | 每项目一个仓 | 需求或文档来源，只存稳定仓引用 |
| 项目 → 代码服务仓 | 每项目零至多个仓 | 实现事实与完成 commit 候选；占用规则见业务规则 |
| 项目 → 项目成员关系 → 成员 | 项目与成员多对多 | 人员共用档案，参与状态在每个项目独立维护 |
| 项目 → 报告范围扩展 | 一对一 | 报告 key、分支策略及扩展启停只在报告配置维护 |
| 项目 → 本部署环境信息 | 每项目每部署环境一份 | 保存公共上下文和修订，不存个人凭据 |
| 成员与项目关系 → 生成名单快照 | 只读消费 | 随报告任务及版本保存当次统计依据 |

## 2. 项目

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 项目标识 | 稳定业务引用 | 标识 | 是 | 系统生成，不随名称变化 |
| 项目名称 | 展示名称 | 文本 | 是 | 1–12 字，启用项目之间唯一 |
| harness 工程 | 需求或文档真源仓 | 仓引用 | 是 | 从有效候选单选 |
| 代码服务仓 | 实现代码范围 | 仓引用集合 | 否 | 有效候选多选，同项目重复仓去重 |
| 标识色 | 项目归属展示 | 枚举 | 是 | 蓝、青、紫、金、品红、橙红；创建自动分配，之后固定 |
| 项目状态 | 是否参与当前归集与统计 | 枚举 | 是 | 启用 / 停用 |
| 备注 | 补充说明 | 文本 | 否 | 不包含凭据 |
| 创建、修改人及时间 | 维护证据 | 人员引用、时间 | 是 | 东八区；不因停用清除 |

<a id="repositories"></a>
## 3. 仓库

云效仓资料只读来自云效；以下配置字段只属于通用 Git，来源和稳定仓标识共同定位仓库，不以名称或地址作为业务引用。

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- |
| 仓库标识与来源 | 项目、卡片和报告的稳定引用 | 标识、枚举 | 是 | 来源为云效 / 通用 Git；系统提供稳定标识 |
| 名称 | 选仓与统计展示 | 文本 | 是 | 最多 256 字，通用 Git 名称不区分大小写判重 |
| 仓地址 | 远端克隆位置 | 地址 | 是 | HTTP / HTTPS，不含凭据；被项目引用后不可更换 |
| 访问账号 | Git 访问身份 | 文本 | 是 | 默认 git，最多 256 字 |
| 密码或令牌 | 访问凭据 | 敏感文本 | 新增是 | 加密保存；不回显，编辑留空沿用 |
| 凭据配置情况 | 是否已有保存凭据 | 只读判断 | 是 | 仅显示已配置 / 未配置，不输出凭据 |
| 默认分支 | 分支查询初始值 | 文本 | 否 | 留空使用远端默认分支 |
| 仓库状态 | 是否可作为新配置候选 | 枚举 | 是 | 启用 / 停用；启停与删除受项目引用保护 |

<a id="members"></a>
## 4. 成员与项目关系

| 实体 | 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- | --- |
| 成员 | 成员标识 | 跨项目统一身份 | 标识 | 是 | 系统生成，同人跨项目复用 |
| 成员 | 姓名 | 报告展示与匹配名称 | 文本 | 是 | 最多 64 字，全部成员唯一 |
| 成员 | 角色集合 | 人员职责 | 枚举集合 | 是 | 产品 / 研发 / UI / 架构，至少一项，可多选 |
| 成员 | 别名集合 | 跨来源人员匹配依据 | 文本集合 | 否 | 最多 50 条，每条最多 128 字，规范化后去重 |
| 成员 | 人员状态 | 人员整体统计参与 | 枚举 | 是 | 启用 / 停用，作用于该成员所有项目 |
| 项目成员关系 | 项目与成员引用 | 挂靠对象 | 稳定引用 | 是 | 每项目每成员一条；必须在项目内新增或关联 |
| 项目成员关系 | 关系状态 | 是否参与本项目 | 枚举 | 是 | 启用 / 停用，只作用于当前项目 |
| 两者 | 维护人及时间 | 配置证据 | 人员引用、时间 | 是 | 东八区，停用仍保留 |

有效成员、跨项目去重与身份冲突处理只在 [业务规则](business-rule.md#report-scope) 定义，不以源系统姓名或不同项目关系生成多个成员标识。

## 5. 范围快照与环境信息

| 数据 | 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
| --- | --- | --- | --- | --- | --- |
| 范围快照 | 项目、人员及关系引用 | 本次成员统计范围 | 稳定引用集合 | 是 | 保存任务创建时有效对象及人员所属项目 |
| 范围快照 | 角色与姓名、别名依据 | 当次计数和匹配证据 | 快照 | 是 | 当前配置变化不改旧版本 |
| 范围快照 | 取得时间及来源结果 | 区分空集合与未取得 | 时间、判断 | 是 | 失败不伪造零成员 |
| 环境信息 | 项目与部署环境 | 公共上下文归属 | 引用、只读枚举 | 是 | 部署环境来自当前服务，未知不可保存 |
| 环境信息 | 公共上下文 | 本环境接入和数据规则 | 业务资料 | 否 | 不含个人账号、密码和令牌 |
| 环境信息 | 修订及修改时间 | 防止并发覆盖 | 版本、时间 | 是 | 保存复核读取修订 |

报告任务、报告版本和 Qoder 自然日用量快照由对应模块维护，本功能不复制其实体。
