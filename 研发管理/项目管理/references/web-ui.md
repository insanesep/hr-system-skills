# 项目管理 · Web 页面

<a id="pages"></a>
## 1. 项目列表

- 菜单：研发管理 → 项目管理，独立入口；产品路由约定 `/rnd/projects`，微应用加宿主前缀；[交互原型](../assets/web/project-management.html)承载项目列表、成员抽屉、Git 仓库和环境信息。
- 页面形态：项目列表（默认）/ Git 仓库配置两个页签；成员管理是具体项目行内入口，不设无项目的全局成员维护页签。
- 组件和编排：[Web 组件](../../../../busyming-skills-design/components/web/SKILL.md) 与 [配置列表标准](../../../../busyming-skills-design/shared/page-standards/web-operation-list.md)；复用 BusyProTable、BusyDialog、BusyForm、BusyButton、BusyTag、BusyMessageBox，不另建私有组件。
- 权限：按 [权限规则](permission-rules.md#boundaries) 控制查看与各维护职责，配置权限不随排期或报告权限取得。
- 搜索：项目名称、项目状态（全部 / 启用 / 停用），查询与重置。
- 表格：项目名称、标识色、harness 工程、代码服务仓、有效成员数、状态、备注、操作。有效成员数按本项目人员和关系状态计数，不看 Git 提交。
- 操作：新建项目；行内编辑、成员管理、启用/停用、环境信息。项目名不依赖颜色区分；仓无权或不可达时保留引用并展示不可用，不提供删除项目。
- 请求态：加载中显示表格 loading；失败显示原因与重新加载；空态「暂无项目，请新建项目」，无维护权时只显示「暂无项目」。

### 导航关系

- 来源页：研发管理菜单「项目管理」；不从功能排期或报告配置提供重复配置入口。
- 去向页：行内「成员管理」打开指定项目成员抽屉；行内「环境信息」打开弹窗；切换页签打开 Git 配置。
- 返回行为：抽屉或弹窗关闭后回到原项目列表，保留查询条件；面包屑「首页」返回门户首页。
- 面包屑：首页 / 研发 / 研发管理 / 项目管理。
- 可直达：项目列表无需隐式参数；成员入口参数包含项目稳定标识，引用不存在时提示「项目不存在」，返回项目列表，不改选其他项目。

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
| --- | --- | --- | --- | --- | --- |
| 查询/重置 | 提交搜索条件 | 否 | 表格 loading | 刷新列表并回第一页 | 展示原因，保留条件，重新加载 |
| 新建/编辑项目 | 具有维护权且校验通过 | 否 | 保存按钮 loading | 「项目已保存」→ 关弹窗并刷新 | 字段错误与 BusyMessage 展示，保留草稿可重试 |
| 启用项目 | 名称、仓来源和占用校验通过 | 否 | 操作按钮 loading | 「项目已启用」→ 刷新项目状态 | 展示冲突项目或来源异常，原状态保留 |
| 停用项目 | 点击启用行停用 | 是，说明出卡、当前归属、报告和成员范围影响 | 确认按钮 loading | 「项目已停用，历史资料保留」→ 刷新列表 | 展示原因，原状态保留，可重试 |
| 打开成员/环境 | 有查看权且项目有效引用 | 否 | 抽屉/弹窗 loading | 加载指定项目，不切换项目 | 显示加载失败与重新加载 |

### 表单校验

项目编辑弹窗初态：新建为空，代码服务仓与备注选填；编辑回显现有配置，项目标识和自动标识色只读，不在本弹窗维护成员或报告 key。

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
| --- | --- | --- | --- | --- | --- |
| 项目名称 | 是 | 业务规则 §1 | blur/提交 | 「请输入 1–12 字项目名称」「该名称已被启用项目占用」 | 是（占用复核） |
| harness 工程 | 是 | 有效候选单选，复核仓占用 | change/提交 | 「请选择有效 harness 工程」「仓已被项目 {名称} 占用」 | 是 |
| 代码服务仓 | 否 | 有效候选多选，复核仓占用 | change/提交 | 「代码服务仓不可用或被其他启用项目占用」 | 是 |
| 备注 | 否 | 不含凭据 | 提交 | 「备注不能包含访问凭据」 | 否 |

保存成功关闭弹窗，无延迟跳转；失败保留字段、定位错误并恢复保存按钮；未保存变更时关闭提示「放弃项目修改？」。

<a id="members"></a>
## 2. 项目成员管理

- 指定项目抽屉，标题「成员管理 · {项目名称}」，项目名称、状态与稳定引用只读；停用项目标注「启用项目后可新增或关联成员」。
- 查询：姓名/别名、角色、人员状态、关系状态。表格：姓名、角色、别名、人员状态、本项目关系状态、其他参与项目、操作；一人只一行。
- 操作：新增成员、关联已有成员、编辑共享资料、启用/停用本项目关系、启用/停用人员。所有操作必须绑定当前项目，不允许在表单内手改挂靠项目或批量改变其他项目关系。
- 新增弹窗：姓名、至少一个角色、别名、人员状态及本项目关系状态；初态人员与关系为启用，保存一次提交两者。
- 关联弹窗：搜索已有成员，展示其角色、人员状态与参与项目，单选；已在当前项目的成员标记「已关联」，点击查看原关系；停用关系提供恢复，不重复关联。关联停用人员明确提示不会自动启用。
- 编辑共享资料弹窗：回显成员基础信息并列出所有受影响项目；当前项目关系状态另行操作，不与共享资料编辑混淆。
- 空态「该项目暂无成员」；失败和刷新不将未取得显示为 0 人。

### 导航关系

- 来源页：项目管理列表行「成员管理」，不设报告配置内的成员维护入口。
- 去向页：新增、关联和编辑均在当前项目抽屉上方弹窗完成；关闭子弹窗回到原项目成员列表。
- 返回行为：关闭抽屉回项目列表；保留项目查询条件，不把成员编辑变成独立菜单。
- 面包屑沿用项目管理；抽屉内始终显示当前项目。

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
| --- | --- | --- | --- | --- | --- |
| 新增成员 | 当前项目启用，具有成员维护权，校验通过 | 否 | 保存按钮 loading | 「成员已新增并关联本项目」→ 关弹窗刷新成员数 | 展示错误，保留草稿；不留孤立档案 |
| 关联已有成员 | 当前项目启用且唯一选中成员 | 否 | 确认按钮 loading | 「成员已关联本项目」→ 关弹窗刷新 | 展示错误，保留选择；重复关联打开原关系 |
| 编辑共享资料 | 基础字段校验通过 | 是，列出所有受影响项目 | 保存按钮 loading | 「成员共享资料已保存」→ 关弹窗刷新 | 展示错误，保留草稿，刷新冲突后重试 |
| 本项目关系启停 | 具有成员维护权 | 停用须确认「仅退出本项目统计，其他项目不受影响」 | 操作按钮 loading | 「本项目成员关系已启用/停用」→ 刷新 | 展示错误，原状态保留 |
| 人员启停 | 具有成员维护权 | 是，列出全部受影响项目 | 确认按钮 loading | 「人员已启用/停用」→ 刷新，关系原状态保留 | 展示错误，原状态保留 |

### 表单校验

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
| --- | --- | --- | --- | --- | --- |
| 当前项目 | 是 | 只读稳定项目，新增/关联复核启用 | 提交 | 「项目已停用，请刷新」 | 是 |
| 姓名 | 是 | 业务规则 §4 | blur/提交 | 「请输入不超过 64 字的姓名」「成员已存在，请关联已有成员」 | 是（成员唯一性） |
| 角色 | 是 | 产品 / 研发 / UI / 架构，至少一项 | change/提交 | 「请至少选择一个角色」 | 否 |
| 别名 | 否 | 业务规则 §4 | blur/提交 | 「别名最多 50 条，每条不超过 128 字」 | 否 |
| 已有成员 | 关联是 | 按稳定成员标识单选并复核关系 | 提交 | 「请选择成员」「已关联，请查看原关系」 | 是 |

成功即时关闭弹窗并刷新指定项目，不跳到其他项目；失败字段保留并展示 BusyMessage/字段错误，保存按钮恢复；脏数据离开提示「放弃成员修改？」；关联弹窗取消不保存。

## 3. Git 仓库配置

- 项目管理页内 Git 仓库配置页签，只有仓维护权才可进入；云效仓从项目选仓只读引用，不在此编辑。
- 列表：名称、仓地址、账号、默认分支、凭据已配置标记、状态、引用项目、编辑/启停/删除；凭据不回显。工具栏新建和刷新。
- 新建/编辑弹窗：名称、仓地址、账号、密码或令牌、默认分支、状态；编辑密码留空沿用，已引用仓地址只读；连接测试、取消和保存。
- 空态「暂无通用 Git 仓库」；读取失败展示原因和重试，不显示为暂无配置。

### 导航关系

- 来源页：项目管理切 Git 页签；项目选仓提示可跳到本页签，返回项目表单保留草稿。
- 去向页：新建/编辑弹窗；引用项目链接返回对应项目配置。
- 返回行为：关闭弹窗回仓列表；切项目页签回项目列表；面包屑沿用项目管理。

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
| --- | --- | --- | --- | --- | --- |
| 连接测试 | 地址和凭据校验通过 | 否 | 测试按钮 loading | 「连接成功，发现 N 个分支」→ 保留草稿，不保存 | 展示脱敏失败原因，草稿保留可重试 |
| 新建/编辑保存 | 字段及引用保护校验通过 | 否 | 保存按钮 loading | 「Git 仓库配置已保存」→ 关弹窗刷新 | 展示错误，草稿保留可重试 |
| 仓启停 | 引用保护允许 | 停用时确认 | 确认/操作按钮 loading | 「仓库已启用/停用」→ 刷新 | 展示引用项目或失败原因，状态回退 |
| 删除仓 | 无项目引用 | 是，说明只删除本地配置，不删除远端仓 | 确认按钮 loading | 「仓库配置已删除」→ 刷新 | 展示引用项目或失败原因，可解除引用后重试 |

### 表单校验

初态：新增账号默认 git，默认分支为空，状态启用；编辑回显非敏感字段，密码始终为空，提示留空沿用，地址按引用状态只读。

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
| --- | --- | --- | --- | --- | --- |
| 名称 | 是 | 业务规则 §3 | blur/提交 | 「请输入有效名称」「仓名称已存在」 | 是（重复复核） |
| 仓地址 | 是 | 业务规则 §3，项目引用保护 | blur/提交 | 「请输入不含凭据的 HTTP/HTTPS 仓地址」「仓地址已存在或被引用不可修改」 | 是 |
| 账号 | 是 | 业务规则 §3 | blur/提交 | 「请输入有效账号」 | 否 |
| 密码或令牌 | 新增是 | 业务规则 §3，编辑为空沿用 | 提交/测试 | 「请填写访问密码或令牌」 | 否 |
| 默认分支 | 否 | 业务规则 §3 | blur/提交 | 「请输入有效分支名称」 | 否 |

保存成功即时关弹窗；连接测试不关弹窗；失败保留填写内容、不回显旧密码；脏数据离开提示「放弃仓库配置修改？」。

<a id="environment"></a>
## 4. 环境信息

当前项目弹窗展示项目名称、只读部署环境、修订及更新时间，编辑公共上下文，不承载个人账号或凭据，规则见 [环境信息](business-rule.md#environment)。本环境未知时禁用保存并说明原因。

- 导航关系：项目列表「环境信息」打开，关闭返回该项目列表，面包屑沿用项目管理；不依赖先进入排期配置。
- 操作反馈清单：重新加载时内容 loading，成功回显当前修订，失败显示原因与重试；保存校验通过后按钮 loading，成功提示「项目环境信息已保存」并刷新修订，留在弹窗；失败保留草稿，修订冲突提示重新加载，不直接覆盖。
- 表单校验：初态读取本部署环境资料，没有资料显示明确空态；提交校验当前项目、已知部署环境、读取修订及公共资料不含个人凭据，错误就地提示；失败保持草稿，按钮恢复；未保存关闭提示「放弃环境信息修改？」。
