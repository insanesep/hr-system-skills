# 编制管理 · 业务规则

> 本文件描述当前生效的编制新增、台账、审批、在编缺额与编制规划规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。编制明细行是招聘需求发起时编制缺额的唯一来源，招聘侧只读引用。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 编制明细行 | 一条「部门—职位—职级」级岗位编制记录，含编制计划、职位编制起止、编制数量、组织、职位、职级、用工形式、在编人员与状态 |
| 编制计划 | 本次编制动作的属性：新增、保留、调出、划拨；仅新增与保留可发起招聘 |
| 在编人数 | 编制明细行下已确认入职、尚未离职的人员数量，由编制管理维护 |
| 招聘占用 | 同一编制明细行下「待审批」「招聘中」招聘需求的剩余人数合计，由招聘管理只读提供 |
| 可用缺额 | 编制数量减去在编人数与招聘占用后的可招聘人数；为负时表示超编 |
| 超编 | 在编人数与招聘占用合计超过编制数量，或招聘需求经超编审批后占用超过缺额 |
| 编制确认 | 编制管理员对招聘入职回写的在编记录核对组织、职位与职级后归档 |
| 编制调整 | 对已生效编制行调增、调减、延期、缩短、停用或启用的变更动作 |
| 备案编制 | 经公司备案的年度编制数，按组织、职位与职级、1–12 月登记，是编制规划的基期对照数据 |
| 定编标准 | 按标准职位登记的主要定位、职责、定编因素与标准值，只读；月度编制与在职人数为台账汇总参考 |
| 编制规划 | 按年度、组织与职级类别汇总的 3 月在职快照与 4–12 月月末编制快照；月度编制由编制明细自动生成 |
| 原编制数 | 本次规划对照的基期编制数，默认取备案编制同年 3 月值，可由规划维护人调整 |
| 本次调整数 | 12 月编制减去原编制数的差额 |
| 规划余量 | 12 月编制减当前在编人数与招聘占用后的可补员空间；负数表示超规划 |
| 数据截止日 | 查询编制数量、在编人数、招聘占用与可用缺额的统一时点，取当日 |

## 2. 功能边界

- 本功能承载编制明细行的新增、批量导入、调整、停用启用、编制确认与变更留痕，以及年度编制规划、定编标准与备案编制的查看和导入。
- 编制规划的 4–12 月编制由编制明细自动汇总，不提供逐月目标手工编辑；规划页只维护原编制数与调整原因。
- 不做：部门树与部门档案维护（归部门管理）、标准职位与职级档案维护（归岗位管理）、招聘需求与候选人推进（归招聘管理）、入职办理与员工档案维护（归入职管理与员工档案）、薪酬核算与劳动合同。
- 组织层级与组织状态只读引用部门管理；职位、职级与职级类别只读引用岗位管理。
- 在编人数由入职确认回写、[离职管理](../../../HR管理/离职管理/SKILL.md)确认离职后移出；招聘占用由招聘管理在途需求汇总；本功能不修改招聘需求与入职单。
- 编制行不提供物理删除，历史编制通过停用或结束保留；已停用与已结束编制不参与新增招聘缺额。
- 定编标准与备案编制在本功能内只读展示，通过模板批量导入更新，不提供逐条编辑。

## 3. 编制明细行规则

- 编制明细行由职位编制开始时间、结束时间、编制数量与组织、职位、职级共同定义；开始时间为空不合法。
- 组织归属取一至五级组织路径，三级组织（二级部门）必填，四级、五级可空；组织必须存在且为启用状态，停用部门不得新增编制。
- 职位必填，须存在于岗位管理标准职位；职级、职级类别、用工形式默认取职位口径，可在新增时调整并写入本行。
- 职级序列取管理序列（M）、专业序列（P）、业务序列（S）、操作序列（O）；职级类别取战略决策层、总监级、经理级、主管级、员工级，取值见 [岗位管理 · 职级矩阵](../../岗位管理/文档/数据模型.md#职级矩阵)；用工形式取全职-正式、实习生、劳务外包、兼职（PT）。
- 编制数量为非负整数，最大 9999；为 0 的编制行保留但不可招聘，用于占位或待启用。
- 职位编制结束时间为空表示长期有效；填写时不得早于开始时间，结束后不可再被招聘引用。
- 同一组织（三至五级组合）、职位、直线上级与职位编制开始时间相同的生效编制行不可重复；重复时提示已存在并可跳转已有行。
- 编制计划为新增或保留的编制行可被招聘引用；调出、划拨的编制行不可被招聘引用，划拨需在原行标记调出、在目标组织新增对应编制并以划拨批次关联。
- 编制行状态为待审批、生效中、已驳回、已停用、已结束；待审批与已驳回不参与编制合计、缺额与招聘可选范围。
- 结束时间早于数据截止日的生效中编制行展示为已结束，系统自动标记且不可被招聘选择；恢复须通过调整新的结束时间。

## 4. 编制新增与批量导入

### 单条新增

- 入口为编制台账页头「新增编制」；新增表单组织、职位、职位编制开始时间、编制数量、编制计划与职级类别为必填，直线上级、结束时间、办公地点、办公业态、原部门标签与备注选填。
- 表单默认带出所选部门的组织路径与职位库中的职级、职级类别、用工形式；组织与职位变更时重新带出默认值，已手工修改的字段不覆盖。
- 至少填写一级至三级组织；四级、五级留空时按所选三级组织落位，招聘快照中以「—」展示缺失层级。
- 提交后生成待审批编制行并向所属一级中心负责人发起审批；不直接占用编制与缺额。
- 连续新增时可选择「保存并继续」，保留组织与职级上下文，清空数量、时间与备注。

### 批量导入

- 使用「组织架构岗位编制明细导入模板」，模板代码 ESTABLISHMENT_DETAIL、版本 V1.0；仅支持 .xlsx，单文件不超过 20MB，单次不超过 10,000 行。
- 模板字段与《附件1-编制明细表》一致：编制计划、职位编制开始时间、职位编制结束时间、编制数量、一级至五级组织、职位、标准职位、直线上级、工号、姓名、职级、职级类别、用工形式、办公业态、办公地点、备注与原部门标签。
- 导入方式为增量补齐：不删除任何已有编制行；按编制计划分别处理，匹配不到的新增行生成编制明细。
- 保留行按组织、职位、直线上级与职级匹配已有编制行；匹配到则校验并补充结束时间与备注，不改变编制数量；匹配不到时按存量初始化生成生效中编制行，不进入审批。
- 新增行生成待审批编制行，按所属一级中心生成审批任务；调增的更新行同样进入待审批。调出、划拨行更新结束时间或组织归属即时生效并留痕，不进入审批。
- 保留行可填写工号与姓名用于匹配在编人员，导入只更新编制行下的在编记录，不新建员工档案、不修改员工主数据；工号与姓名均不参与新增行建编。
- 日期按 YYYY-MM-DD 填写，数量填写非负整数；不得修改字段名称或合并数据区单元格，不得包含宏与外部链接。
- 导入前完成校验并展示预览：保留匹配数、新增待审批数、调出划拨数、忽略数与失败行数；失败行不导入并列出「行号、失败原因、原行内容」，可下载失败回执后修正重导。
- 校验内容包括：模板与版本匹配、编制计划合法、必填缺失、组织存在且启用、职位存在、日期合法、数量为非负整数、同键是否重复、保留行工号是否存在。
- 导入结果为部分成功时，成功行正常生效或进入审批，失败行不落库；结果回执展示成功与失败明细。

## 5. 审批规则

- 审批范围为新增编制与调增编制；调减、延期、缩短结束时间、停用与启用不设审批，提交即生效并留痕。
- 审批人为编制行所属一级中心负责人；批量导入与批量新增按一级中心拆分审批任务，同一中心的待审批行合并为一条审批单。
- 待审批编制行不计入编制合计与缺额，不出现在招聘管理的编制明细行可选项中。
- 申请人可撤回待审批申请，撤回后编制行关闭或回到可编辑状态，不产生生效数据。
- 审批通过后编制行生效，生效时间取职位编制开始时间；开始时间早于审批通过日的，审批通过即生效。
- 审批驳回须填写驳回原因，编制行状态为已驳回，可修改后重新提交；驳回不占用编制与缺额。
- 审批期间组织或职位被停用、标准职位被删除时，审批任务标记异常并提示重新选择，不允许带失效组织或职位通过审批。

## 6. 编制调整规则

- 调增：填写调增数量与原因，提交后进入审批；审批通过前原编制数量继续生效，招聘缺额按原数量计算。
- 调减：填写调整后数量与原因，提交即生效；允许调减至低于在编人数，差额部分标记超编警示，并在招聘侧触发相关在途需求「编制变更待处理」。
- 延期：修改职位编制结束时间，提交即生效；延期不得早于开始时间，早于数据截止日的结束时间按已结束处理。
- 停用：须填写停用原因，提交即生效；停用后在编人员保留并可查看，但不可被招聘引用、不可发起新的招聘需求。
- 启用：仅已停用且结束时间未过期的编制行可启用，提交即生效；启用不改变原结束时间。
- 调整生效后刷新编制数量、在编人数、招聘占用与可用缺额，并写入编制变更记录，记录变更前后值、原因、操作人与时间。
- 调整失败时保留表单内容并提示原因；与他人在途调整冲突时提示数据已更新，刷新后重试，不静默覆盖。

## 7. 在编人数、招聘占用与可用缺额

- 在编人数按编制明细行下状态为在编的人员数量统计，包含待编制确认人员；离职人员不计入。
- 在编人员来源为招聘入职回写、存量初始化与编制管理员纠错；来源为招聘入职的记录状态为待编制确认，其余来源直接为已确认。
- 编制管理员核对组织、职位与职级后执行编制确认，确认后归档；确认不改变在编人数与可用缺额。
- [离职管理](../../../HR管理/离职管理/SKILL.md)确认离职后，对应在编人员标记已离职并记录离开日期，在编人数减一；已确认入职记录不回退招聘侧数据。
- 招聘占用由招聘管理提供，按同一编制明细行下待审批与招聘中需求的剩余人数合计，并叠加招聘台账在途预占；台账预占按需求编号同步，终止、放弃、淘汰或删除后释放。编制侧不手工修改。
- 可用缺额等于编制数量减在编人数与招聘占用（含台账预占）之和；可用缺额小于零时以超编警示展示，允许继续保存编制调整并提示处理超编。
- 可用缺额为编制行派生值，不单独存储；导出与统计按数据截止日重新计算。

## 8. 编制规划与参照数据规则

### 规划口径

- 编制规划按年度维护，行为「组织（系统架构）+ 二级部门 + 三级部门 + 职级类别」，一级中心（编制口径）取所属编制口径；组织与职级类别组合唯一。
- 规划基线为当年 3 月 31 日在职快照，列为 4–12 月月末编制快照；不再提供 1–12 月逐月目标的手工编辑。
- 4–12 月编制由编制明细汇总：目标月份的编制数取开始时间不晚于当月最后一天、结束时间为空或不早于当月第一天、状态为生效中或已结束、用工形式为全职-正式且职级序列为 M 或 P 的编制行数量合计。
- 待审批、已驳回、已停用编制行不计入月度汇总；已结束行按结束日期所在月自然退出，结束月份仍计入。
- 月末快照口径：开始日期所在月计入，结束日期所在月仍计入、次月起退出；如 4 月 1 日新增计入 4 月，6 月 30 日结束计入 6 月、不计入 7 月。季度评审节点为 4 月 1 日、7 月 1 日、10 月 1 日，非节点日期不阻断，按实际起止时间计入对应月份。
- 3 月在职人数为固定快照，只作对照，不随月度在编变化重算，也不参与 4–12 月编制汇总。
- 规划行「查看明细」列出生效中、待审批、已驳回与已停用等编制明细，并标注计入或排除原因，帮助核对月度汇总来源。

### 原编制、调整与占比

- 原编制数默认取备案编制同维度 3 月备案值；无备案时为 0，并允许规划维护人填写。保存后作为本次规划基线，不随备案重新导入自动覆盖。
- 本次调整数等于 12 月编制减去原编制数；调整数不为零时调整原因必填。
- 12 月各职级编制占比等于本行 12 月编制除以同一二级部门 12 月编制合计，展示一位小数百分比；分母为零时展示「—」。
- 规划页只允许维护原编制数与调整原因；4–12 月编制、调整数与占比均只读并随台账变化重新汇总。

### 达成对比

- 达成对比按 12 月编制对照当前在编人数与招聘占用：规划余量等于 12 月编制减在编人数与招聘占用，正数为可补员空间，负数为超规划。
- 在编人数与招聘占用取当前数据截止日口径，不按历史月份回溯；页面明确标注对照口径，避免与月度快照混用。
- 规划可导出当前筛选结果，含 3 月在职、4–12 月编制、占比、原编制数、调整数、调整原因与达成对比；导出不改变规划数据。

### 备案编制

- 备案编制按组织、职位与职级登记 1–12 月编制数，职位可为空；使用模板代码 ESTABLISHMENT_ARCHIVE 导入，导入后作为原编制默认值与规划对照数据，保留导入批次与操作记录。
- 备案编制为只读数据，导入按「年度 + 一级中心（编制口径）+ 二级部门 + 三级部门 + 职位 + 标签 + 职级类别」覆盖更新。

### 定编标准

- 定编标准按标准职位登记主要定位、核心职责、部门职责、职位职责、职务序列、职务标签、职级类别、定编因素与定编标准值，使用模板代码 ESTABLISHMENT_STANDARD 导入，只读展示。
- 定编标准中的 3 月在职与 4–12 月编制为同组织、同职位、同职级的台账汇总参考，不作为导入值，也不参与缺额计算。
- 定编标准导入为全量替换当前版本，保留导入批次记录；标准职位停用或删除时保留历史批次，不影响已生成编制行。

## 9. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 编制计划 | 新增、保留、调出、划拨 | 新增与保留为可用标签，调出与划拨为中性标签 |
| 编制行状态 | 待审批、生效中、已驳回、已停用、已结束 | 待审批与已驳回为警示，已停用与已结束为中性 |
| 审批状态 | 待审批、已通过、已驳回、已撤回 | 待审批为警示标签，其余为中性或成功标签 |
| 职级类别 | 战略决策层、总监级、经理级、主管级、员工级 | 文本 |
| 职级序列 | 管理序列（M）、专业序列（P）、业务序列（S）、操作序列（O） | 文本 |
| 用工形式 | 全职-正式、实习生、劳务外包、兼职（PT） | 文本 |
| 在编人员状态 | 在编、已离职 | 在编为主色标签，已离职为中性 |
| 编制确认状态 | 待编制确认、已确认 | 待编制确认为警示标签 |
| 变更类型 | 新增、调增、调减、延期、缩短、停用、启用、调出、划拨、导入更新、招聘入职、离职、初始化、纠错 | 变更记录文本 |

## 10. 空态与异常

- 编制台账无数据时展示「暂无编制明细」空态，有新增权限时提供「新增编制」入口；筛选无结果时展示「暂无符合条件的编制」。
- 规划所选年度无编制明细且无备案数据时展示「暂无规划数据，请先维护编制明细或导入备案编制」；仅有未备案组织时保留规划行并将原编制数展示为 0，附「未备案」提示。
- 台账、规划、定编标准与备案编制加载失败时在对应区块展示失败提示与「重试」，重试沿用失败时的筛选条件与年度。
- 新增、调整、导入、审批与确认失败时保留表单或弹窗内容，提示失败原因；组织或职位失效时提示重新选择。
- 导入文件格式错误、版本不匹配或超过行数上限时在弹窗内提示原因，不进入解析。
- 编辑期间数据被他人修改时提示已更新并刷新，不覆盖他人变更。
- 可用缺额为负、存在待审批调增、结束时间即将到期时，在台账行内以标签或角标提示。

## 11. 权限编码与数据范围

- 菜单权限编码：`MENU:HR:ESTABLISHMENT`；未授权不展示菜单入口。
- 按钮权限编码：新增编制 `BTN:HR_ESTABLISHMENT:CREATE`、批量导入 `BTN:HR_ESTABLISHMENT:IMPORT`、编辑 `BTN:HR_ESTABLISHMENT:EDIT`、调整 `BTN:HR_ESTABLISHMENT:ADJUST`、停用启用 `BTN:HR_ESTABLISHMENT:STATUS`、编制确认 `BTN:HR_ESTABLISHMENT:CONFIRM`、审批 `BTN:HR_ESTABLISHMENT:APPROVE`、导出 `BTN:HR_ESTABLISHMENT:EXPORT`、规划编辑 `BTN:HR_ESTABLISHMENT:PLAN_EDIT`、规划导出 `BTN:HR_ESTABLISHMENT:PLAN_EXPORT`、定编标准导入 `BTN:HR_ESTABLISHMENT:STANDARD_IMPORT`、备案编制导入 `BTN:HR_ESTABLISHMENT:ARCHIVE_IMPORT`、外包超编查看与备注 `BTN:HR_ESTABLISHMENT:OUTSOURCE`。
- 未授权按钮时不展示对应入口；因业务规则不可用（非新增或保留、已结束、待审批中）时保留入口并置灰，提示不可用原因。
- 数据范围按一级中心授权：编制管理员与人力资源负责人为全量，中心负责人为本中心，HRBP 与部门负责人按被授权组织只读；审批仅对所属中心范围内的待审批行可见。
- 台账与规划的筛选、统计、导出与审批均受数据范围限制，范围外数据不展示、不可通过链接直达查看。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 12. 外包超编

- 外包超编指用工形式为劳务外包且可用缺额小于零的编制行，以及该行下的在编人员；可用缺额 = 编制数量 − 在编人数 − 招聘占用。
- 编制台账提供「外包超编」页签，仅展示外包超编行；页签列包含组织路径、职位、职级、用工形式、编制数量、在编人数、超编人数、直线上级、编制备注与在编人员明细。
- 在编人员明细展示工号、姓名、职级、入职日期与超编处理备注；超编处理备注按人员维护，记录「10月离职不替补」「测试外包离职 1 HC 未替补」等处理意见。
- 超编人数 = max(在编人数 + 招聘占用 − 编制数量, 0)；招聘占用为在途外包需求的剩余人数。
- 外包超编不改变编制数量；由编制管理员与中心负责人按调增编制、人员退场或转签处理，处理结果写入备注与变更记录。
- 招聘侧只读引用外包超编结果，不在此处修改；外包需求仍需关联用工形式为劳务外包的编制明细行，无可用编制时按超编需求审批。
