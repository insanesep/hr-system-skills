# 编制管理 · 页面元素说明

> 字段口径见 [数据模型.md](数据模型.md)，新增审批、在编缺额、外包超编与规划规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，编制台账、外包超编与编制规划在同一原型内以 `#ledger` / `#outsource` / `#plan` 三视图互联；详情、新增、调整与导入均为抽屉或弹窗，不单独占菜单。

## 编制台账

- **页面路径**：`/hr/establishment/list`（产品页面约定）
- **原型**：[原型图/web/establishment.html#ledger](../原型图/web/establishment.html#ledger)
- **权限编码**：路由 `MENU:HR:ESTABLISHMENT`；按钮见「按钮权限码」
- **页面类型**：查询列表页（统计卡 + 筛选台账 + 抽屉与弹窗操作）
- **区块职责**：
  - 页头：标题「编制管理」+ 副标题「按职位维护编制明细，核对在编人数与可用缺额」；右侧「新增编制」「批量导入」「导出」与视图切换「编制台账 / 外包超编 / 编制规划」
  - 统计卡：编制数量合计、在编人数、招聘占用、可用缺额、待审批编制；招聘占用附注「含台账预占 N」；可用缺额为负时以警示色展示并附注「含 N 行超编」
  - 筛选卡：关键字（编制编号 / 组织 / 职位）、一级中心、二级部门、职级类别、编制计划、编制状态、职位编制开始时间区间；动作区「重置」「查询」
  - 结果卡：工具栏（结果条数、数据更新时间、刷新）+ 编制明细表格 + 空态 / 加载 / 加载失败三态 + 分页
- **统计卡口径**：编制数量合计、在编人数、招聘占用与可用缺额按数据权限范围统计生效中编制，不随关键字与组织筛选变化；待审批编制为独立计数。点击「待审批编制」将编制状态置为待审批并立即查询，点击「可用缺额」按升序排列以优先展示超编行
- **表格列**：编制编号、组织路径、职位（附标准职位）、直线上级、职级序列、职级 / 职级类别、用工形式、编制计划、职位编制起止、编制数量、在编人数、招聘占用（含台账预占）、可用缺额、编制状态、操作
- **职级口径**：职级、职级序列与职级类别按[岗位管理 · 职级矩阵](../../岗位管理/文档/数据模型.md#职级矩阵)取值；管理 M、专业 P、业务 S、操作 O 四序，战略决策层 / 总监级 / 经理级 / 主管级 / 员工级五类
- **展示规则**：
  - 组织路径按「一级中心 / 二级部门 / 三级部门 / 五级组织」展示，缺失层级以「—」展示；五级组织为空时不占位
  - 职位列主行展示职位，次行以弱化文本展示标准职位；两者相同时只展示职位
  - 职位编制起止以「开始日期 ~ 结束日期」展示，结束时间为空展示「长期」
  - 招聘占用展示需求占用与台账在途预占合计，含台账预占时追加「台账 N」标签；可用缺额按「编制数量 − 在编人数 − 招聘占用（含台账预占）」计算
  - 可用缺额为负时以警示色展示并追加「超编」标签；待编制确认人数大于零时在在编人数后附注「含 N 人待确认」
  - 编制状态为已结束的行整体弱化，编制计划为调出或划拨的行展示中性标签
- **默认排序**：按更新时间倒序；同时间按编制编号升序
- **行操作**：详情、编辑、调增、调减、延期、停用 / 启用、审批（待审批行）、确认（在编含待确认时）
  - 待审批行：详情、撤回、审批；不展示调增调减与停用
  - 已驳回行：详情、编辑、重新提交
  - 已停用与已结束行：详情；已停用且结束时间未过期时展示启用
  - 无对应按钮权限时不展示入口；规则不可用时置灰并提示原因
- **分页**：仅改变当前页数据，不改变筛选条件；支持每页 20 / 50 / 100 条
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyInput、PageableSelect、DatePicker、Tag、Table、Pagination、Message
- **编排标准**：`busyming-skills-design/shared/page-standards/web-operation-list.md`
- **布局引用**：参见原型 [原型图/web/establishment.html#ledger](../原型图/web/establishment.html#ledger)

### 新增编制抽屉

- **打开方式**：页头「新增编制」或空态入口（需新增权限）。
- **字段**：组织（一级中心 / 二级部门 / 三级部门级联，三级部门与五级组织可空，至少选择至二级部门）、职位（下拉搜索标准职位）、职位编制开始时间、职位编制结束时间、编制数量、编制计划（新增 / 保留 / 调出 / 划拨）、职级序列、职级、职级类别、用工形式、直线上级、办公业态、办公地点、标准职位、原部门标签、备注。
- **默认值**：组织取当前筛选条件；职位选定后带出标准职位、职级序列、职级、职级类别与用工形式；已手工修改的字段不随职位变更覆盖；职级与职级类别按[岗位管理 · 职级矩阵](../../岗位管理/文档/数据模型.md#职级矩阵)校验。
- **校验与提示**：必填项为空、数量非 0–9999 整数、结束时间早于开始时间、组织停用、职位不存在、同键重复时在字段下方提示并定位首个错误；提交按钮 loading。
- **操作**：底部「取消」「保存并继续」「提交审批」；提交成功提示「已提交审批」，抽屉关闭并在台账新增待审批行；「保存并继续」保留组织与职级，清空数量、时间与备注。
- **关闭行为**：有未保存内容时二次确认「放弃本次填写？」。

### 编辑编制抽屉

- **打开方式**：行操作「编辑」或已驳回行「编辑」。
- **待审批与已驳回行**：待审批行锁定编辑入口，可撤回后重新发起；已驳回行可修改全部字段并保存后重新提交审批，保存时展示驳回原因。
- **生效中行**：仅可修改标准职位、直线上级、办公业态、办公地点、原部门标签与备注；组织、职位、职级、编制数量与起止时间只读，数量与时间调整走调整弹窗。
- **反馈**：保存成功提示「已更新编制」；与他人修改冲突时提示已更新并刷新。

### 调整弹窗

- **打开方式**：行操作「调整」或「停用」；「停用」直接以停用类型打开，弹窗内可切换为调增、调减、延期、缩短、停用与启用。
- **调增**：填写调增数量、生效说明与原因；展示「审批通过后编制数量由 X 变为 Y」，提交后提示「调增已提交审批，当前按原编制数量生效」。
- **调减**：填写调整后数量与原因；调整后数量低于在编人数时提示「调整后将超编 N 人」，仍可提交；提交成功即时生效并提示已释放缺额。
- **延期 / 缩短**：修改职位编制结束时间；缩短至早于数据截止日时提示「调整后编制将立即结束」；提交即生效。
- **停用**：展示在编人数与「停用后不可发起招聘，在编人员保留」；须填写停用原因；二次确认后生效。
- **启用**：仅结束时间未过期的已停用行可用；二次确认后生效并提示可重新发起招聘。

### 批量导入弹窗

- **打开方式**：页头「批量导入」（需导入权限）。
- **弹窗内容**：模板说明区（模板名称「组织架构岗位编制明细导入模板」、代码 ESTABLISHMENT_DETAIL、版本 V1.0、.xlsx ≤ 20MB、单次 ≤ 10,000 行、增量补齐不删除已有编制行）、模板下载入口、文件选择区、导入说明。
- **流程**：选择文件后展示解析中；校验完成后展示「保留匹配 N 行、新增待审批 N 行、调出划拨 N 行、失败 N 行」的预览，失败行按「行号 / 失败原因 / 原行内容」列出并可下载失败回执；点击「导入」后新增行进入待审批，保留、调出与划拨行按规则即时更新。
- **提示**：文件格式错误、版本不匹配、超过行数或大小上限时在弹窗内阻断并提示原因；部分成功时分别展示成功与失败结果。
- **关闭行为**：已解析未导入时关闭需二次确认。

### 编制详情抽屉

- **打开方式**：行操作「详情」或点击编制编号。
- **概览区**：编制编号、编制状态、编制计划、组织路径、职位 / 标准职位、职级序列、职级 / 职级类别、用工形式、直线上级、编制数量、在编人数、招聘占用、可用缺额、职位编制起止、办公地点、备注、创建与更新时间。
- **页签**：
  - 在编人员：工号、姓名、职级、入职日期、来源、关联需求编号、关联入职单号、确认状态、在编状态、超编处理备注；待编制确认记录展示「确认」操作；已离职记录展示离开日期；外包超编人员展示处理备注编辑入口
  - 招聘占用：在途需求编号、需求人数、已到岗、剩余占用、需求状态、超编标记；只读，链接跳转招聘需求详情
  - 变更记录：变更类型、变更前后值、原因、审批状态、审批人、操作人与时间；按时间倒序，只读
- **操作区**：按权限与状态展示编辑、调增、调减、停用 / 启用、确认；不提供删除。
- **导航关系**：抽屉内链接跳转招聘需求与在编人员员工资料时新页签打开，关闭抽屉后保留台账筛选与页码。

### 审批弹窗

- **打开方式**：待审批行「审批」，或统计卡进入审批列表后逐条处理。
- **内容**：展示编制信息、变更类型、变更前后数量或结束时间、申请人、申请时间与变更原因。
- **操作**：通过、驳回；驳回必填驳回原因（不超过 200 字）；提交中按钮 loading。
- **反馈**：通过后行状态变为生效中并提示「已通过，编制已生效」；驳回后状态为已驳回并提示「已驳回，申请人可修改后重新提交」；失败保留弹窗内容并提示原因。

### 导航关系

- 来源页：菜单「人资管理 / 组织管理 / 编制管理」默认进入编制台账
- 去向页：页头视图切换进入编制规划 `/hr/establishment/plan`；新增、编辑、调整、导入、审批与详情为抽屉或弹窗，不改变路由
- 返回行为：从编制规划切回台账时保留台账筛选与页码；关闭抽屉不刷新整页
- 面包屑：首页 / 人资管理 / 组织管理 / 编制管理

| 重置 | 无 | 否 | 表格区加载态 | 清空条件并恢复默认列表 → 停留本页 | 同查询失败处理 |

| 编制确认 | 存在待确认在编记录 | 否 | 确认按钮 loading | 记录转为已确认并归档 → 停留本页 | 提示失败原因并可重试 |

## 外包超编

- **页面路径**：`/hr/establishment/outsource`（产品页面约定，编制台账视图切换）
- **原型**：[原型图/web/establishment.html#outsource](../原型图/web/establishment.html#outsource)
- **权限编码**：路由 `MENU:HR:ESTABLISHMENT`；按钮 `BTN:HR_ESTABLISHMENT:OUTSOURCE`
- **页面类型**：查询列表页（筛选 + 外包超编行 + 在编人员明细）
- **筛选**：一级中心、二级部门、职位、职级类别、直线上级、关键字（工号 / 姓名 / 职位）、是否仅看超编（默认是）
- **统计卡**：外包编制数量、外包在编人数、外包招聘占用、外包超编人数、超编行数
- **表格列**：组织路径、职位、职级序列、职级 / 职级类别、用工形式（劳务外包）、编制数量、在编人数、招聘占用、超编人数、直线上级、编制备注、操作
- **展示规则**：
  - 仅展示用工形式为劳务外包且可用缺额小于零的编制行；超编人数 = max(在编人数 + 招聘占用 − 编制数量, 0)
  - 超编人数以警示标签展示；编制备注展示整体处理意见
  - 行操作「详情」打开外包超编详情抽屉，展示在编人员明细：工号、姓名、职级、入职日期、超编处理备注与备注编辑入口
- **处理备注**：在编人员行内「编辑备注」保存超编处理说明（如「10月离职不替补」）；保存成功提示「处理备注已更新」并写入变更记录；无权限时只读
- **导出**：按当前筛选导出外包超编名单，含组织、职位、职级、编制数量、在编人数、超编人数、在编人员与处理备注
- **导航关系**：视图切换「编制台账 / 外包超编 / 编制规划」；详情为抽屉，关闭后保留筛选

## 编制规划

- **页面路径**：`/hr/establishment/plan`（产品页面约定）
- **原型**：[原型图/web/establishment.html#plan](../原型图/web/establishment.html#plan)
- **权限编码**：路由 `MENU:HR:ESTABLISHMENT`；规划编辑 `BTN:HR_ESTABLISHMENT:PLAN_EDIT`
- **页面类型**：编制汇总矩阵页（页签：规划视图 / 定编标准 / 备案编制）
- **区块职责**：
  - 页头：标题「编制规划」+ 副标题「3 月在职基线，4–12 月由编制明细自动汇总，对照原编制与当前在编」；右侧「返回编制台账」「导出规划」「保存规划」
  - 筛选卡：年度、一级中心（编制口径）、二级部门、三级部门、职级类别；动作区「重置」「查询」
  - 页签区：规划视图、定编标准、备案编制，默认「规划视图」
  - 规划视图：汇总提示（3 月在职、12 月编制、原编制、调整、规划余量）+ 季度节点提示 + 月度矩阵表 + 空态 / 加载失败三态
  - 定编标准：只读表格 + 导入批次时间 +「导出」「导入定编标准」
  - 备案编制：只读表格 + 导入批次时间 +「导出」「导入备案编制」
- **规划矩阵列**：组织路径与一级中心（编制口径）、职级类别、在职人数（3 月）、4–12 月编制、12 月各职级编制占比、原编制数、本次调整数、调整原因、操作（查看明细），以及达成对比（在编 / 招聘占用 / 可用缺额 / 规划余量）；组织路径按「组织（系统架构）/ 一级中心（系统架构）/ 二级部门 / 三级部门」分层展示。
- **月度汇总**：4–12 月编制为只读月末快照，由编制明细按开始时间不晚于当月最后一天、结束时间为空或不早于当月第一天、状态为生效中或已结束、用工形式为全职-正式且职级序列为 M 或 P 汇总；待审批、已驳回、已停用不计入。单元格不提供输入，台账生效变更后重新汇总。
- **编辑规则**：仅原编制数与调整原因可维护；原编制数默认取备案编制同年 3 月值，无备案显示 0 与「未备案」提示；本次调整数不为零时调整原因标红必填；保存后提示「规划已保存」并更新时间。月度编制、调整数与占比不可编辑。
- **查看明细**：行操作「查看明细」打开抽屉，列出构成该行的编制明细（编制编号、职位、编制计划、起止时间、编制数量、状态、计入或排除原因）；已结束行按结束月份计入并标注，排除行以中性标签标注待审批、已驳回、已停用或未计入范围。
- **季度节点**：4 月、7 月、10 月列头展示评审节点标识；新增与调出编制建议在 4 月 1 日、7 月 1 日、10 月 1 日生效，实际起止时间按月末快照计入。
- **定编标准表列**：一级中心、二级部门、三级部门、职位、标准职位、职务序列、职务标签、职级类别、定编因素、定编标准值、在职人数（3 月）、12 月编制、导入时间、操作（详情）
- **定编标准详情抽屉**：展示组织路径、主要定位、核心职责、部门职责、职位主要职责、职级类别、定编因素、定编标准值与 4–12 月编制来源；只读。

### 导入定编标准与备案编制

- **打开方式**：定编标准页签「导入定编标准」、备案编制页签「导入备案编制」。
- **内容**：模板说明（定编标准模板代码 ESTABLISHMENT_STANDARD；备案编制模板代码 ESTABLISHMENT_ARCHIVE）、模板下载、文件选择、校验预览（成功 / 失败行数）、失败回执下载。
- **定编标准内容**：组织、主要定位、二级部门、核心职责、三级部门、部门职责、职位、标准职位、职务序列、职务标签、职级类别、职位职责、定编因素与定编标准值；3 月在职与 4–12 月编制为台账汇总，不随模板导入。
- **备案编制内容**：一级中心（编制口径）、组织、一级中心（系统架构）、二级部门、三级部门、职位、标签、职级类别、在职人数与 1–12 月备案数；按年度与组织、职位、标签、职级类别覆盖更新。
- **反馈**：导入成功提示「已导入 N 行」，表格刷新并展示本次导入批次时间；部分成功时失败行不导入并提示原因。
- **影响**：备案编制导入只补充原编制默认值与对照数据，不覆盖已保存的规划原编制数；定编标准导入为全量替换当前版本，保留导入批次记录。

### 空态与异常

- 台账无数据展示「暂无编制明细」；筛选无结果展示「暂无符合条件的编制」。
- 规划年度无编制明细且无备案数据时展示空态「暂无规划数据，请先维护编制明细或导入备案编制」，有权限时提供导入入口；仅有未备案组织时保留规划行并将原编制数展示为 0。
- 矩阵、定编标准与备案编制加载失败时在对应区块展示失败与「重试」，重试沿用当前筛选与年度。
- 保存规划与他人修改冲突时提示数据已更新，刷新后重新编辑，不静默覆盖。
- 定编标准或备案编制导入失败时保留弹窗与解析结果，失败行可下载回执。

### 交互约定

- 台账与规划共用菜单与权限编码，视图切换不重新登录；两视图各自保留筛选与页码。
- 月度编制与只读字段使用只读样式；无规划编辑权限时隐藏原编制数与调整原因编辑入口，不置灰输入框。
- 矩阵横向可滚动；宽屏时组织列与职级列固定，窄屏取消固定并仅保留矩阵内部横向滚动，不产生整页横向溢出。
- 编制数量、规划余量与占比统一使用等宽数字展示，负值以警示色标记；月度编制单元格无边框输入态。

### 原型实现说明

- 原型为单文件静态 Mock，数据预置在页面内；台账、外包超编与规划以 `#ledger` / `#outsource` / `#plan` 互联，规划页签在视图内切换。
- 演示场景：台账含待审批新增、已驳回调增、超编行、待编制确认在编、已停用与已结束行；输入关键字 FAIL 演示台账加载失败与重试；规划矩阵的 4–12 月由台账行起止时间与状态计算，调整待审批行或结束时间后重新进入规划页可见月度变化；原编制或调整原因修改后保存，原因缺失时提示。
- 新增、编辑、调整、导入、审批与详情为原生抽屉与弹窗实现，未引入组件库运行时；样式与交互按公共组件口径编写。
- 页面声明组件：Button、BusyInput、PageableSelect、DatePicker、Tag、Table、Pagination、BusyTabs、Message。
