# 编制管理 · 数据模型

> 本文件为编制台账、编制规划与参照数据的字段口径。规则见 [业务规则.md](业务规则.md)，页面展示见 [页面元素.md](页面元素.md)。编制明细行与在编人员为一对多；规划、备案编制与定编标准为按维度独立的参照数据。

## 1. 编制明细行

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 编制标识 | 编制明细行唯一标识 | 文本 | 是 | 系统生成，页面不展示 |
| 编制编号 | 编制的业务编号 | 文本 | 是 | 系统生成，唯一，列表展示 |
| 编制计划 | 本次编制动作属性 | 枚举 | 是 | 新增、保留、调出、划拨；仅新增与保留可发起招聘 |
| 职位编制开始时间 | 到岗或入职的计划开始日期 | 日期 | 是 | 建议取季度首日；不得为空 |
| 职位编制结束时间 | 调出或离职的计划结束日期 | 日期 | 否 | 不得早于开始时间；为空表示长期有效 |
| 编制数量 | 本行核定编制人数 | 数值 | 是 | 0–9999 的非负整数 |
| 一级组织 | 组织路径第 1 级 | 引用 | 是 | 引用部门；由所选组织路径派生 |
| 二级组织（一级中心） | 组织路径第 2 级 | 引用 | 是 | 引用部门；由所选组织路径派生 |
| 三级组织（二级部门） | 组织路径第 3 级 | 引用 | 是 | 引用部门；须存在且启用 |
| 四级组织（三级部门） | 组织路径第 4 级 | 引用 | 否 | 引用部门；可为空 |
| 五级组织 | 组织路径第 5 级 | 引用 | 否 | 引用部门；可为空 |
| 组织路径 | 一级至五级组织名称串联 | 文本 | 是 | 名称以「 / 」连接，缺失层级不展示 |
| 职位 | 本行编制对应的职位 | 文本 | 是 | 取岗位管理标准职位；列表与筛选字段 |
| 标准职位 | 岗职分离后的标准职位 | 文本 | 否 | 默认同职位，可调整 |
| 直线上级 | 本行编制的直接汇报人 | 文本 | 否 | 在职员工姓名；为空表示未指定 |
| 职级序列 | 本行职级所属序列 | 枚举 | 是 | 管理序列（M）、专业序列（P）、业务序列（S）、操作序列（O）；默认取职位口径 |
| 职级 | 本行对应职级 | 文本 | 是 | 如 P4、P7；默认取职位口径，可调整；取值见[岗位管理 · 职级矩阵](../../岗位管理/文档/数据模型.md#职级矩阵) |
| 职级类别 | 职级归属类别 | 枚举 | 是 | 战略决策层、总监级、经理级、主管级、员工级；取值见[岗位管理 · 职级矩阵](../../岗位管理/文档/数据模型.md#职级矩阵) |
| 用工形式 | 本行编制对应的用工形式 | 枚举 | 是 | 全职-正式、实习生、劳务外包、兼职（PT） |
| 办公业态 | 办公场所类型 | 文本 | 否 | 如办公室、门店、仓储；为空表示未登记 |
| 办公地点 | 本行编制的办公地点 | 文本 | 否 | 如总部、分公司、研发中心等办公地点 |
| 原部门标签 | 编制调整前的所属部门 | 文本 | 否 | 用于划拨与组织调整对照 |
| 备注 | 编制补充说明 | 文本 | 否 | 不超过 200 字 |
| 编制状态 | 编制行当前状态 | 枚举 | 是 | 待审批、生效中、已驳回、已停用、已结束；已结束为结束时间早于数据截止日的派生状态 |
| 在编人数 | 本行在编人员数量 | 数值 | 是 | 派生；含待编制确认人员，不含已离职 |
| 招聘占用 | 在途招聘需求占用的剩余人数 | 数值 | 是 | 只读引用招聘管理；不手工维护 |
| 可用缺额 | 可继续招聘的人数 | 数值 | 是 | 派生：编制数量 − 在编人数 − 招聘占用；可为负 |
| 超编标记 | 是否处于超编 | 布尔 | 是 | 派生：可用缺额小于 0 或招聘需求超编审批占用 |
| 划拨批次 | 同一次编制划拨的批次号 | 文本 | 否 | 原行与目标行共享同一批次 |
| 来源 | 编制行的产生方式 | 枚举 | 是 | 单条新增、批量导入、招聘回写、存量初始化 |
| 创建人 | 创建或导入操作人 | 文本 | 是 | — |
| 创建时间 | 记录创建时间 | 日期时间 | 是 | 列表默认排序依据 |
| 更新时间 | 最近一次生效变更时间 | 日期时间 | 是 | — |

## 8. 实体关系

- 编制明细行与在编人员为一对多：一行编制可对应多名在编人员，一名员工同一时点只归属一条编制行。
- 编制明细行与编制变更记录为一对多：新增、调整、停用启用、招聘入职、离职与纠错均产生记录，记录只增不改。
- 编制规划行与编制明细行为月度汇总关系：按组织、职级类别与月末快照汇总，规划行不存储每月来源明细；查看明细按汇总口径回溯生效中与排除行。
- 备案编制行与编制规划行为基期对照关系：备案 3 月值作为原编制默认值，规划保存后不随备案导入覆盖；备案不直接生成规划行。
- 定编标准行为独立参照数据，按组织与标准职位登记，不参与在编与缺额计算；其月度编制为台账汇总参考。
- 招聘占用由招聘管理按编制明细行汇总，本功能不存储占用明细。

## 9. 统计与派生口径

- 在编人数：编制行下人员状态为在编的记录数，包含待编制确认。
- 招聘占用：招聘管理中编制行下待审批与招聘中需求的剩余人数合计。
- 可用缺额：编制数量减去在编人数与招聘占用，结果可为负，负值展示为超编。
- 已结束判定：职位编制结束时间早于数据截止日且状态为生效中的编制行，展示为已结束。
- 编制合计：所选范围下状态为生效中的编制行编制数量合计，不含待审批与已驳回。
- 4–12 月编制：目标月份取编制明细中开始时间不晚于当月最后一天、结束时间为空或不早于当月第一天、状态为生效中或已结束、用工形式为全职-正式且职级序列为 M 或 P 的数量合计；待审批、已驳回、已停用不计。
- 3 月在职人数：3 月 31 日在职快照，固定只读，不随台账月度变化重算。
- 12 月编制占比：本行 12 月编制 ÷ 同一二级部门 12 月编制合计；分母为零展示「—」。
- 本次调整数：12 月编制 − 原编制数。
- 规划余量：12 月编制 − 当前在编人数 − 招聘占用；正数为可补员空间，负数为超规划。
- 达成率：在编人数 ÷ 12 月编制；12 月编制为零时展示「—」。
