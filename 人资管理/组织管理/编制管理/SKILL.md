# 编制管理

## 模块概述

人资管理 → 组织管理下的编制入口，分为「编制台账」与「编制规划」两个菜单页面：

- **编制台账**：维护部门—职位—职级级编制明细行，覆盖单条新增、批量导入、调增调减、停用启用、编制确认与变更留痕；在编人数、招聘占用与可用缺额在同一行内呈现，是招聘需求发起时编制缺额的唯一来源；台账提供「外包超编」页签，按用工形式为劳务外包且可用缺额为负的编制行展示超编人数与人员处理备注。
- **编制规划**：按年度、组织与职级类别汇总 3 月在职快照与 4–12 月月末编制快照；月度编制由编制明细的起止时间、状态、用工形式与职级序列自动汇总，仅维护原编制数与调整原因，并按 12 月编制对照当前在编与招聘占用查看规划余量。同页提供定编标准与备案编制的只读参照及批量导入，职级与职级类别统一引用[岗位管理 · 职级矩阵](../岗位管理/文档/数据模型.md#职级矩阵)。

本功能不承载部门树维护、岗位档案维护、招聘过程推进、入职办理与员工档案维护。

## 端

- **web**：人资管理 → 组织管理 → 编制管理，仅桌面端管理后台，不提供 App 入口

## When to Use

- 新增一条岗位编制，或下载组织架构岗位编制明细模板批量导入
- 按组织、职位、职级类别、编制计划与状态查询编制明细
- 对编制行调增、调减、延期、停用或启用，并核对审批状态
- 查看编制行的在编人员、招聘占用（含招聘台账在途预占）与可用缺额，确认招聘入职回写结果
- 查看外包超编行、超编人数与在编人员处理备注
- 按 3 月在职基线与 4–12 月月末快照查看编制规划，维护原编制数与调整原因，导入备案编制与定编标准
- 复核职级矩阵、编制与招聘需求管理、入职管理的联动口径，或查询权限编码

## Tips

- 编制计划取「新增、保留、调出、划拨」；只有新增与保留且未结束的编制行可被招聘引用，可用缺额为零或为负时先处理超编
- 新增编制与调增提交后为待审批，审批人为所属一级中心负责人；待审批不占用缺额、不可被招聘选择；调减、停用、启用与延期提交即生效
- 可用缺额 = 编制数量 − 在编人数 − 招聘占用（含招聘台账在途预占）；在编人数由入职确认回写、离职事件移出，招聘侧只读引用
- 台账预占按需求编号同步：台账录入占用、终止/放弃/淘汰/删除释放，编制侧招聘占用与可用缺额即时联动
- 编制行不提供删除，只能停用或到期结束；结束日期早于今天的编制行展示为已结束且不可招聘
- 职级与职级类别统一按[岗位管理 · 职级矩阵](../岗位管理/文档/数据模型.md#职级矩阵)取值：管理 M、专业 P、业务 S、操作 O 四序，战略决策层 / 总监级 / 经理级 / 主管级 / 员工级五类
- 外包超编按用工形式为劳务外包且可用缺额为负的编制行统计，超编处理备注按在编人员维护；超编不改变编制数量
- 规划 4–12 月编制由台账自动汇总：仅全职正式且职级序列为 M/P 的生效中与已结束行按起止时间计入，待审批、已驳回、已停用不计；规划页只维护原编制数与调整原因
- 原编制数默认取备案编制同年 3 月值，保存后不随备案导入覆盖；调整数 = 12 月编制 − 原编制数，非零时原因必填
- 定编标准与备案编制在本功能内只读展示、按模板导入更新，不逐条编辑；定编标准的月度编制为台账汇总，不随模板导入
- 规则查找：新增审批与在编缺额看 文档/业务规则.md，字段口径看 文档/数据模型.md，页面元素看 文档/页面元素.md
- 原型为静态 Mock，台账、外包超编与规划在同一 HTML 内以 `#ledger` / `#outsource` / `#plan` 互联
