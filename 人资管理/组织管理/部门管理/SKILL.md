# 部门管理

## 模块概述

人资管理 → 组织管理下的组织架构维护入口：左侧部门树呈现公司五级组织，右侧展示选中部门的档案详情；在同一菜单内完成部门新增、编辑、删除、启用停用以及拖拽排序与上级调整。根节点「公司」由系统预置且唯一，不可新增同级、删除、停用或移动。本功能不承载员工任职调动、岗位与编制维护。

## 端

- **web**：人资管理 → 组织管理 → 部门管理，仅桌面端管理后台，不提供 App 入口

## When to Use

- 查看或搜索公司、中心、部门、小组、子小组构成的部门树
- 在指定部门下新增中心、部门、小组或子小组
- 编辑部门档案，调整负责人、编制人数、排序号、成立日期与备注
- 拖拽调整同级顺序，或将部门移动到新的上级
- 启用、停用或删除部门，核对删除与停用的前置条件
- 复核组织层级、编码唯一性、名称重名与权限编码口径

## Tips

- 层级由深度决定：公司 0 层、中心 1 层、部门 2 层、小组 3 层、子小组 4 层，子小组为最末层
- 变更上级仅通过拖拽完成，编辑弹窗不修改上级；移动后层级类型随新深度重新判定
- 删除仅限无下级且无在职员工的部门，其余情况只能停用
- 搜索状态下部门树只读，清除搜索后恢复维护能力
- 规则查找：层级与维护规则看 文档/业务规则.md，字段口径看 文档/数据模型.md，页面元素看 文档/页面元素.md
