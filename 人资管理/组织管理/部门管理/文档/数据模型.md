# 部门管理 · 数据模型

> 本文件为部门档案与组织关系的产品字段口径；维护规则见 [业务规则.md](业务规则.md)，页面展示见 [页面元素.md](页面元素.md)。

## 1. 部门

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 部门标识 | 部门的唯一标识 | 文本 | 是 | 系统生成，页面不展示 |
| 部门名称 | 组织节点名称 | 文本 | 是 | 1–30 个字符；同一上级下唯一（含停用部门） |
| 部门编码 | 组织的稳定编码 | 文本 | 是 | 2–32 个字符，大写字母、数字或下划线且以字母开头；全局唯一；创建后不可修改；删除后释放 |
| 上级部门 | 直接父节点 | 引用 | 是（根公司除外） | 引用部门标识；根公司无上级 |
| 层级类型 | 节点所处层级 | 枚举 | 是 | 公司、中心、部门、小组、子小组；由层级深度派生，不可人工修改 |
| 层级深度 | 距根公司的层数 | 数值 | 是 | 0–4，公司为 0；系统派生，页面以层级类型展示 |
| 部门路径 | 从公司到本部门的名称路径 | 文本 | 是 | 名称逐级以「 / 」连接；系统派生 |
| 负责人 | 部门负责人姓名 | 文本 | 否 | 最长 20 个字符 |
| 编制人数 | 部门核定编制 | 数值 | 否 | 0–9999 整数；为空表示尚未核定 |
| 在职人数 | 本部门在职员工数 | 数值 | 是 | 系统统计；不含下级部门；默认 0 |
| 下级部门数 | 直接下级数量 | 数值 | 是 | 系统统计；含停用部门；默认 0 |
| 排序号 | 同级展示顺序 | 数值 | 是 | 0–9999 整数；新增时默认同级末尾 |
| 状态 | 部门可用状态 | 枚举 | 是 | 启用、停用；新建默认启用；根公司恒为启用 |
| 成立日期 | 部门成立日期 | 日期 | 是 | 不得晚于当天 |
| 撤销日期 | 部门停用日期 | 日期 | 否 | 停用时写入当天，启用时清空；只读 |
| 备注 | 部门补充说明 | 文本 | 否 | 最长 200 个字符 |
| 创建时间 | 记录创建时间 | 日期时间 | 是 | 系统维护；同级排序号相同时用于升序 |
| 更新时间 | 最近修改时间 | 日期时间 | 是 | 系统维护；档案详情展示 |

## 2. 实体关系

- 部门与部门为父子自关联：每个非根部门有且仅有一个上级，一个部门可有多个直接下级，最深 5 层。
- 部门与员工任职为一对多只读引用：员工任职记录的部门归属由员工档案侧维护，本功能只按部门统计在职人数，不修改任职记录。
- 部门与岗位、编制为归属维度引用：岗位与编制的部门归属规则归各自功能，本功能不维护关联明细。

## 3. 统计与派生口径

- 在职人数：当前任职部门为本部门且在职状态为在职的员工数量，不包含下级部门员工。
- 下级部门数：直接上级为本部门的部门数量，包含停用部门；更深层节点不计入。
- 部门路径：按上级链从公司到本部门逐级取名称，以「 / 」连接。
- 层级类型：按层级深度映射，0 为公司、1 为中心、2 为部门、3 为小组、4 为子小组。
- 空叶子判定：下级部门数为 0 且在职人数为 0，是删除操作的前置条件。

## 4. 枚举

| 枚举 | 取值 | 说明 |
|---|---|---|
| 状态 | 启用、停用 | 停用节点在树中灰显并带状态标签 |
| 层级类型 | 公司、中心、部门、小组、子小组 | 由层级深度派生，随拖拽移动后的新深度重新判定 |

## 5. 唯一性与约束

- 部门编码全局唯一，创建后不可修改，部门删除后释放。
- 同一上级下部门名称唯一，停用部门同样占用名称。
- 根公司唯一且恒为启用状态，全树有且仅有一个。
- 子小组为最末层，不可再有下级；全树最深 5 层。
