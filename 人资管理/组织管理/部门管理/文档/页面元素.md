## 部门管理

- **页面路径**：`/hr/department/tree`（产品页面约定）
- **原型**：[原型图/web/department.html](../原型图/web/department.html)
- **权限编码**：路由 `MENU:HR:DEPARTMENT`；按钮权限见「按钮权限码」
- **页面类型**：组织树 + 部门档案复合页
- **区块职责**：
  - 页头：标题「部门管理」+ 副标题「维护公司五级组织架构与部门档案」；无页级操作
  - 左侧树面板：搜索与展开收起工具栏、部门树、空态 / 加载 / 加载失败三态
  - 右侧档案面板：部门标题区（名称、层级类型标签、状态标签、操作按钮）+ 档案描述列表
  - 新增 / 编辑部门弹窗、删除确认弹窗、停用 / 启用确认弹窗
- **树面板**：
  - 工具栏：搜索框（占位「搜索部门名称或编码」）与「展开 / 收起全部」
  - 节点：按层级缩进，展示名称与状态标签；停用节点灰显；选中节点高亮，保留展开箭头
  - 节点悬停：「新增下级」快捷入口；无权限或业务不可用时按规则隐藏或置灰
  - 仅公司时：展示空态「暂无下级部门」，有权限时提供「新增中心」入口
- **档案面板**：
  - 标题区：部门名称、层级类型标签、状态标签；操作区「新增下级」「编辑」「停用 / 启用」「删除」
  - 描述列表字段顺序：部门名称、部门编码、上级部门、部门路径、负责人、编制人数、在职人数、排序号、状态、成立日期、撤销日期、备注、更新时间
  - 根公司选中时：不展示「停用 / 启用」与「删除」，不可拖拽；「新增下级」为新增中心
- **新增 / 编辑弹窗**：
  - 标题「新增部门」或「编辑部门」，副标题展示上级部门路径与目标层级类型
  - 字段：部门名称、部门编码（编辑时只读）、上级部门（只读）、负责人、编制人数、排序号、成立日期、备注
  - 校验提示展示在字段下方，提交时定位首个错误字段，已填内容保留
  - 底部：取消、保存；保存中按钮 loading
- **删除确认弹窗**：展示部门名称、完整路径与不可恢复说明；确认按钮为危险样式
- **停用 / 启用确认弹窗**：停用展示在职人数与「停用后不可新增下级、不可承接新任职」；启用展示需上级为启用状态的要求

### 按钮权限码

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 新增下级 | `BTN:HR_DEPARTMENT:CREATE` | 树悬停快捷入口与档案面板入口 |
| 编辑 | `BTN:HR_DEPARTMENT:EDIT` | 档案面板入口与弹窗保存 |
| 删除 | `BTN:HR_DEPARTMENT:DELETE` | 删除入口与确认 |
| 拖拽维护 | `BTN:HR_DEPARTMENT:DRAG` | 同级排序与上级调整 |
| 启用 / 停用 | `BTN:HR_DEPARTMENT:STATUS` | 状态切换与确认 |

### 导航关系

- 来源页：菜单「人资管理 / 组织管理 / 部门管理」进入
- 去向页：无下级路由；新增、编辑、删除与启停确认均为弹窗，不改变路由
- 返回行为：本页为模块入口页，无页内返回；切换选中节点仅刷新右侧档案
- 面包屑：首页 / 人资管理 / 组织管理 / 部门管理

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 搜索 | 输入名称或编码 | 否 | 树区加载态 | 展示命中节点与祖先路径并自动展开 → 停留本页 | 树区展示失败与「重试」，按原关键字重试 |
| 展开 / 收起 | 节点存在下级 | 否 | 无（本地） | 展开或收起该节点 → 停留本页 | 无 |
| 展开 / 收起全部 | 非搜索状态 | 否 | 无（本地） | 全部节点展开或收起 → 停留本页 | 无 |
| 选中节点 | 无 | 否 | 档案区首次加载态 | 右侧刷新为所选部门档案，树内高亮 → 停留本页 | 档案区展示失败与「重试」，重试原选中节点 |
| 新增下级 | 选中非子小组且处于启用状态，非搜索状态 | 否 | 打开弹窗；保存按钮 loading | 展开上级并选中新部门，刷新树与档案 → 停留本页 | 校验失败定位字段；保存失败弹窗保留内容并可重试 |
| 编辑 | 已选中部门、非搜索状态 | 否 | 打开弹窗；保存按钮 loading | 刷新树与档案并保持选中 → 停留本页 | 同新增保存失败处理 |
| 拖拽排序 | 同父节点内、有拖拽权限、非搜索状态 | 否 | 树区加载态 | 更新同级顺序并保持选中 → 停留本页 | 回滚至操作前顺序并提示刷新重试 |
| 拖拽移动 | 目标合法、有拖拽权限、非搜索状态 | 层级类型变化时确认 | 树区加载态 | 更新上级与层级类型并保持选中展开 → 停留本页 | 回滚至原上级并提示刷新重试 |
| 停用 | 已启用、无启用下级，非根公司且非搜索状态 | 是 | 确认按钮 loading | 树与档案刷新为停用状态 → 停留本页 | 弹窗保留并展示失败原因，可重试 |
| 启用 | 已停用且上级启用，非搜索状态 | 是 | 确认按钮 loading | 树与档案刷新为启用状态 → 停留本页 | 同上 |
| 删除 | 空叶子且非根公司，非搜索状态 | 是 | 确认按钮 loading | 删除成功并选中上级部门 → 停留本页 | 弹窗保留并展示失败原因，可重试 |
| 重试 | 区块加载失败 | 否 | 区块加载态 | 按失败前的搜索条件与选中节点重新加载 → 停留本页 | 继续展示失败提示并允许再次重试 |

### 空态与异常

- 部门树无数据时展示「暂无下级部门」引导；搜索无命中展示「未找到匹配的部门」。
- 树或档案加载失败时在对应区块展示失败提示与「重试」，不阻塞另一区块的只读浏览。
- 保存、删除与启停失败时弹窗不关闭，已填内容与确认上下文保留。
- 数据被他人删除或修改时，提示已失效并刷新树与档案，不覆盖他人变更。

### 交互约定

- 搜索状态下树为只读，仅可选中查看；清除搜索后恢复搜索前的选中与展开状态。
- 新增保存后自动展开上级并选中新部门；删除后选中上级；启停后保持当前选中。
- 业务规则不可用的入口保留并置灰，悬停说明原因；无按钮权限时不展示入口。
- 本页仅提供桌面端布局，左树固定宽度、右侧档案自适应，不提供移动端布局。

### 原型实现说明

- 原型为单文件静态 Mock，数据在页面内预置；默认选中公司并展开至部门层。
- 演示场景：企业文化小组为空叶子可删除，基础架构组因在职员工不可删；数据部因存在启用下级不可停用，核算部可停用与重新启用；前端小组为停用样例；关键字输入 FAIL 演示树加载失败与重试。
- 部门树与新增、编辑、删除、启停及移动确认弹窗为原生实现，未使用组件库的 Tree 与 Dialog；文本输入沿用 BusyInput 结构，弹窗交互由页面内原生脚本完成。
- 页面声明组件：Button、BusyInput、Form、Tag、Descriptions。
- 样式引用 busyming-skills-design 的公共 tokens、runtime 与 templates；另带一层仅在公共样式缺省时生效的兜底样式，正常接入时以公共样式为准。
