# 岗位管理 · 业务规则

> 本文件描述职级体系、标准职位与岗位映射的生效规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。职级矩阵、岗位序列与标准职位被编制管理、招聘管理、绩效管理与员工资料只读引用。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 职级序列 | 职业发展通道：管理序列（M）、专业序列（P）、业务序列（S）、操作序列（O） |
| 职级 | 序列内的层级编码与名称，如 P5、M4；编码全局唯一，顺序固定 |
| 职级类别 | 职级归属的层级段：战略决策层、总监级、经理级、主管级、员工级 |
| 岗位序列 | 职位族，如产品经理、后端开发、测试、运维、安全，用于归并同类职位 |
| 标准职位 | 公司级职位档案，含名称、岗位序列、适用职级范围、默认职级、用工形式与职位要求 |
| 适用职级范围 | 标准职位允许覆盖的最低与最高职级，不得跨职级类别 |
| 命名规则 | 按职级段与岗位序列生成标准职位名称的命名约定 |
| 岗位映射 | 员工当前职位名称、岗位序列与职级到标准职位的匹配与切换记录 |
| 匹配结果 | 一致、命名不一致、职级错配、层级未建设、序列未建设、无法匹配 |
| 切换 | 将员工当前职位名称更正为标准职位名称并建立标准职位关联，不改变组织、职级与编制 |
| 职位版本 | 标准职位每次生效修改后的版本快照，用于历史引用追溯 |

## 2. 功能边界

- 本功能承载职级矩阵、职级类别、职级顺序、岗位序列、命名规则、标准职位与岗位映射的维护。
- 不做：部门树与部门档案维护、编制数量与在编人数维护、招聘需求与候选人推进、绩效评价与等级校准、员工档案日常维护、薪酬核算、劳动合同签订。
- 编制数量、在岗人数与招聘占用只读引用；岗位管理不修改编制明细行，不修改员工任职记录的组织与职级。
- 标准职位是职位主数据，不等于编制行；同一标准职位可被多条编制明细行引用。
- 岗位序列是职位族，不等同于职级序列；一个岗位序列可覆盖多个职级，但同一标准职位只归属一个岗位序列。

## 3. 职级体系规则

- 职级序列固定为 M、P、S、O 四序，不可增删；职级类别固定为战略决策层、总监级、经理级、主管级、员工级五类，不可增删。
- 职级编码全局唯一，编码规则为「序列字母 + 序号」，如 P5、M4、S3、O2；同一序列内序号连续，顺序不可跳号。
- 职级矩阵按「职级类别 × 职级序列」组织；每个职级必须且只能归属一个职级类别，跨类别的职级范围在引用时按取高归属。
- 职级名称、顺序、类别与管理岗标记可维护；已被标准职位、编制、招聘、绩效或员工资料引用的职级不可删除，只能停用。
- 停用职级不再出现在新建标准职位、编制与招聘的职级选项中；已引用记录保留原职级快照。
- 命名规则按职级段维护，至少覆盖员工级、主管级、经理级、总监级四段；管理序列按管理职责单独命名，不套用专业序列前缀。
- 命名规则只生成标准职位名称建议，不强制自动改名；标准职位名称可人工调整，但必须满足唯一性校验。

## 4. 岗位序列规则

- 岗位序列编码全局唯一，创建后不可修改；名称全局唯一。
- 岗位序列维护名称、定义、职责范围、职位名称后缀、建设状态、适用职级范围与排序。
- 建设状态为未建设、建设中、已启用、停用：
  - **未建设**：允许先建标准职位草稿，不允许被编制、招聘与员工异动引用；在岗映射标记为「序列未建设」。
  - **建设中**：允许维护并启用标准职位，不允许被编制、招聘新建引用；在岗映射标记为「层级未建设」或「序列建设中」。
  - **已启用**：标准职位可被编制、招聘与员工异动引用。
  - **停用**：不再新增标准职位与外部引用，已引用记录保留。
- 技术中心初始岗位序列为产品经理、产品运营、UED、PMO、后端开发、前端开发、测试、算法、数据研发、运维、实施&技术支持、安全；安全序列按未建设处理，允许先建标准职位再启用。
- 岗位序列建设状态切换为已启用前，须至少存在一个已启用标准职位；未建设与建设中序列只允许维护标准职位草稿或启用中的内部准备，不对外引用。
- 同一员工同一时点只归属一个岗位序列；岗位序列由当前标准职位或员工资料当前任职记录带出。
- 岗位序列停用不影响在岗人员与历史记录；新增标准职位、编制与招聘职位不可选择停用序列。

## 5. 标准职位规则

- 标准职位编码全局唯一，格式为「序列编码-四位序号」；创建后不可修改。
- 标准职位名称在同一岗位序列内唯一；不同序列可同名，但需在展示中带序列。
- 适用职级范围必须在同一职级类别内，且最低职级不高于最高职级；默认职级必须落在范围内。
- 标准职位必须关联已存在且未停用的岗位序列；岗位序列为建设中时允许保存，但状态为「待启用」，不可被外部引用。
- 标准职位维护职位定位、核心职责、任职要求、默认用工形式、默认职级、适用组织范围与生效日期。
- 标准职位状态为待启用、已启用、已停用；待启用不可被编制与招聘引用，已停用保留历史引用。
- 标准职位不提供物理删除；被编制、招聘职位、在岗员工或岗位映射引用时，删除入口不可用。
- 修改标准职位名称、适用职级范围、默认职级或默认用工形式时生成新版本；新版本只影响之后创建的引用，已创建编制、招聘职位与员工任职保留原快照。
- 管理职位与专业职位共用标准职位库，以「职位类型」区分；管理职位默认职级为 M 序列，专业职位默认职级为 P、S 或 O 序列。
- 标准职位的在岗人数与编制引用为只读派生值：在岗人数取员工资料当前任职且状态为在职的人数，编制引用取编制明细行关联该标准职位的行数与编制数量合计。

## 6. 岗位映射规则

### 6.1 映射来源与生成

- 映射数据来源为员工资料当前任职记录：员工、组织、当前职位名称、岗位序列、职级、直接上级与在职状态。
- 初始映射可通过「导入在岗人员岗位明细」生成；后续新增人员由入职管理、调岗晋升与转正管理写入后自动刷新。
- 系统按「岗位序列 + 职级」匹配标准职位：优先选择已启用、适用职级覆盖当前职级、适用组织覆盖员工组织的标准职位；存在多个候选时按默认职级匹配、再按生效日期最新、最后按职位编码升序取唯一结果。
- 员工岗位序列或职级为空、序列停用或标准职位候选不唯一时，匹配结果为无法匹配，须人工处理。

### 6.2 匹配结果

- **一致**：当前职位名称与建议标准职位名称一致，且职级落在适用范围。
- **命名不一致**：存在可用标准职位，但当前职位名称与标准职位名称不一致。
- **职级错配**：当前职位名称可映射到标准职位，但员工职级不在该标准职位适用范围内。
- **层级未建设**：岗位序列已启用，但当前职级没有可用标准职位。
- **序列未建设**：岗位序列未建设（如安全序列），或处于建设中且没有可用标准职位。
- **无法匹配**：缺少岗位序列、职级或员工当前任职记录，或候选标准职位不唯一。

### 6.3 切换规则

- 切换只更新员工当前任职记录的职位名称与标准职位关联，不改变组织、职级、直接上级、入职日期与编制归属。
- 切换不生成调岗、晋升或降职记录，不改变绩效名单的组织与职级，不改变编制在编人数。
- 单条切换须填写切换原因；批量切换按当前筛选结果或勾选行处理，逐行校验并生成成功与失败回执。
- 切换状态为待处理、待切换、已切换、无需切换、已忽略：
  - **待处理**：匹配结果不可直接切换，需补充标准职位、修正职级或处理序列建设。
  - **待切换**：匹配成功且存在建议标准职位，可执行切换。
  - **已切换**：已完成岗位名称更正。
  - **无需切换**：当前职位与建议标准职位一致。
  - **已忽略**：人工忽略，保留映射记录。
- 仅匹配结果为一致、命名不一致且存在建议标准职位、切换状态为待切换的记录可切换；职级错配、层级未建设、序列未建设与无法匹配进入待处理，不可直接切换。
- 切换成功后员工资料当前任职记录的职位名称更新为标准职位名称，并写入岗位变更记录；岗位映射状态变为已切换。
- 忽略须填写忽略原因，忽略后保留映射记录，不再进入待切换统计；标准职位或职级变化后重新计算并恢复为待处理。
- 映射统计中的「待切换」包含待处理与待切换两类，两者均未完成岗位名称治理。
- 批量导入在岗人员岗位明细使用统一模板，按工号匹配员工；工号不存在、组织停用、序列或职级为空的行进入失败回执，不写入映射。
- 岗位映射的生成、刷新、切换、忽略与导入均写入操作记录，记录操作人、时间、变更前后内容与来源。

| 枚举 | 取值 | 展示 |
|---|---|---|
| 职级序列 | 管理序列（M）、专业序列（P）、业务序列（S）、操作序列（O） | 文本 |
| 职级类别 | 战略决策层、总监级、经理级、主管级、员工级 | 文本 |
| 岗位序列状态 | 未建设、建设中、已启用、停用 | 已启用为主色标签，建设中与未建设为提示标签，停用为中性 |
| 标准职位状态 | 待启用、已启用、已停用 | 已启用为主色标签，待启用为提示标签，已停用为中性 |
| 职位类型 | 专业职位、管理职位 | 文本 |
| 匹配结果 | 一致、命名不一致、职级错配、层级未建设、序列未建设、无法匹配 | 一致为主色标签，命名不一致与职级错配为警示标签，其余为中性 |
| 切换状态 | 待处理、待切换、已切换、无需切换、已忽略 | 已切换为主色标签，待切换为提示标签，待处理为警示标签，无需切换与已忽略为中性 |
| 操作类型 | 新增、编辑、停用、启用、版本发布、映射生成、映射切换、映射忽略、导入 | 文本 |

- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 9. 与其他模块的联动

- **编制管理**：编制明细行选择标准职位后带出职级、职级类别、岗位序列与默认用工形式；标准职位停用或名称变更不回写已创建编制行。
- **招聘管理**：招聘需求与职位引用标准职位快照；岗位族与岗位类别仍由招聘维护，不与岗位序列混用。
- **绩效管理**：考核名单的职位、职级与序列取员工资料当前任职；岗位映射切换不改变绩效名单口径。
- **员工资料**：当前职位名称与标准职位关联由岗位映射或员工异动写入；员工资料只读展示，不在此维护。
- **员工成长记录**：岗位映射切换写入「岗位信息变更」事件，不生成调岗或晋升事件。
