# 岗位管理 · 数据模型

> 本文件为职级体系、岗位序列、标准职位与岗位映射的实体与字段口径。职级矩阵、职级序列与职级类别以本文件为唯一真源；编制、招聘、绩效与员工资料只读引用。规则见 [业务规则.md](业务规则.md)。

## 1. 职级序列

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 序列编码 | 职级序列唯一编码 | 文本 | 是 | M、P、S、O，创建后不可修改 |
| 序列名称 | 展示名称 | 文本 | 是 | 管理序列、专业序列、业务序列、操作序列 |
| 序列说明 | 序列适用人群与能力导向 | 文本 | 否 | 不超过 200 字 |
| 状态 | 是否可用 | 枚举 | 是 | 启用、停用 |
| 排序 | 展示顺序 | 数值 | 是 | 从 1 开始 |

## 2. 职级

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 职级编码 | 职级唯一编码 | 文本 | 是 | 序列字母 + 序号，如 P5、M4、S3、O2；全局唯一 |
| 职级名称 | 职级展示名称 | 文本 | 是 | 如高级专员、主管、经理、总监 |
| 所属序列 | 职级所属职级序列 | 枚举 | 是 | M、P、S、O |
| 职级类别 | 职级归属层级段 | 枚举 | 是 | 战略决策层、总监级、经理级、主管级、员工级 |
| 序号 | 序列内顺序 | 数值 | 是 | 同一序列内连续，数字越大层级越高 |
| 管理岗标记 | 是否管理岗位职级 | 布尔 | 是 | M 序列默认为是，其他序列默认为否 |
| 状态 | 是否可用 | 枚举 | 是 | 启用、停用 |
| 生效日期 | 职级生效日期 | 日期 | 是 | 不得晚于当前日期 |

## 3. 职级类别

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 类别编码 | 类别唯一编码 | 文本 | 是 | 固定编码，创建后不可修改 |
| 类别名称 | 展示名称 | 文本 | 是 | 战略决策层、总监级、经理级、主管级、员工级 |
| 排序 | 展示顺序 | 数值 | 是 | 战略决策层最高，员工级最低 |
| 说明 | 类别定义 | 文本 | 否 | 不超过 200 字 |

## 4. 岗位序列

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 序列编码 | 岗位序列唯一编码 | 文本 | 是 | 全局唯一，创建后不可修改 |
| 序列名称 | 职位族名称 | 文本 | 是 | 如产品经理、后端开发、测试、安全 |
| 序列定义 | 序列的业务定位与能力边界 | 文本 | 是 | 不超过 500 字 |
| 职责范围 | 该序列承担的典型职责 | 文本 | 否 | 不超过 500 字 |
| 职位名称后缀 | 生成标准职位名称时使用的角色后缀 | 文本 | 否 | 如工程师、设计师、专员；产品经理等可留空 |
| 建设状态 | 序列建设情况 | 枚举 | 是 | 未建设、建设中、已启用、停用 |
| 适用职级范围 | 序列覆盖的职级段 | 文本 | 是 | 如 P1-P11、M4-M8 |
| 排序 | 展示顺序 | 数值 | 是 | 从 1 开始 |
| 来源 | 数据来源 | 枚举 | 是 | 初始化、手工新增、导入 |

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 职位编码 | 标准职位唯一编码 | 文本 | 是 | 序列编码 + 四位序号，如 PM-0001；创建后不可修改 |
| 职位名称 | 标准职位展示名称 | 文本 | 是 | 同一岗位序列内唯一，不超过 50 字 |
| 职位类型 | 专业职位或管理职位 | 枚举 | 是 | 专业职位、管理职位 |

| 职级序列 | 适用职级序列 | 枚举 | 是 | M、P、S、O |
| 适用职级范围 | 可覆盖的职级范围 | 文本 | 是 | 如 P4-P6；不得跨职级类别 |
| 职级类别 | 范围归属类别 | 枚举 | 是 | 由适用职级范围派生并校验 |

| 职位定位 | 该职位的价值定位 | 文本 | 是 | 不超过 300 字 |
| 核心职责 | 主要职责清单 | 文本 | 否 | 不超过 1000 字 |
| 任职要求 | 学历、经验、能力要求 | 文本 | 否 | 不超过 1000 字 |

| 来源 | 数据来源 | 枚举 | 是 | 手工新增、批量导入、初始化 |

## 10. 实体关系

- 职级序列与职级为一对多：一个序列包含多个职级，一个职级只归属一个序列。
- 职级类别与职级为一对多：一个类别覆盖多个职级，一个职级只归属一个类别。
- 岗位序列与标准职位为一对多：一个岗位序列包含多个标准职位，一个标准职位只归属一个岗位序列。
- 标准职位与职位版本为一对多：每次生效修改生成一个版本，历史版本只读。
- 标准职位与编制明细行为一对多：一个标准职位可被多条编制行引用，编制行保留引用时的职位快照。
- 员工与岗位映射为一对一：一名员工同一时点只有一条有效岗位映射。
- 岗位映射与标准职位为多对一：多条映射可指向同一标准职位，标准职位停用不影响已切换记录。
