# 岗位管理 · 页面元素

> 字段口径见 [数据模型.md](数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，三个页签在同一菜单路由 `/hr/position/list` 下以 `#level`、`#standard`、`#mapping` 互联，不设独立菜单。原型见 [原型图/web/position-management.html](../原型图/web/position-management.html)。

## 页面清单

| 页面 | 锚点 | 页面类型 | 主要内容 |
|---|---|---|---|
| 职级体系 | `#level` | 主数据维护页 | 统计卡、职级矩阵、岗位序列、命名规则、编辑抽屉 |
| 标准职位 | `#standard` | 台账页 | 统计卡、筛选、标准职位表格、新建编辑抽屉、详情抽屉、导入弹窗 |

## 职级体系

### 页面结构

- **页头**：面包屑「首页 / 人资管理 / 组织管理 / 岗位管理」；页签「职级体系 / 标准职位 / 岗位映射」；页签右侧展示当前职级矩阵最后更新时间。
- **统计卡**：职级数量、岗位序列数量、已启用序列数量、标准职位数量、待切换映射数量。
- **职级矩阵**：按职级类别为行、职级序列为列的矩阵，单元格展示该类别下的职级编码与名称；管理序列列宽较大，支持横向滚动容器。
- **岗位序列列表**：列展示序列名称、序列定义摘要、建设状态、已有职级段、标准职位数、在岗人数、排序与操作；操作包含编辑、启停与查看标准职位。
- **命名规则**：按职级段展示名称前缀、名称主体、名称后缀与示例；支持编辑抽屉维护。
- **职级与类别说明**：展示职级序列、职级类别、职级顺序与管理岗标记的只读说明。
- **编辑抽屉**：职级编辑、岗位序列编辑、命名规则编辑分别使用右侧抽屉；抽屉底部为取消与保存。

### 交互

- 点击矩阵单元格打开该职级的编辑抽屉；点击岗位序列行打开序列编辑抽屉。
- 职级编码、序列编码与职级类别编码创建后只读；职级顺序调整时校验同一序列内连续。
- 岗位序列建设状态切换为已启用前，校验至少存在一个已启用标准职位；切换为停用前提示外部引用影响。
- 矩阵加载失败时在矩阵区域展示失败提示与「重试」，不影响其他区块。
- 职级或序列保存后局部刷新矩阵、统计卡与标准职位筛选项。

## 标准职位

### 页面结构

- **页头**：页签同一路由；页签右侧「新建标准职位」「批量导入」「导出」。
- **统计卡**：标准职位总数、已启用数量、待启用数量、已停用数量、在岗人数合计、被编制引用数量。
- **基础筛选**：关键字（职位名称 / 编码）、岗位序列、职级序列、职级类别、职位类型、状态。
- **高级筛选**：适用职级、默认用工形式、适用组织、是否被编制引用、是否有在岗人员、更新时间区间。
- **表格列**：职位编码、职位名称、职位类型、岗位序列、职级序列、适用职级范围、职级类别、默认职级、默认用工形式、在岗人数、编制引用数、状态、生效日期、操作。
- **行内操作**：查看详情、编辑、停用 / 启用；标准职位不提供物理删除。
- **批量操作**：批量停用、批量导出；批量停用逐行校验并生成结果回执。

### 新建与编辑抽屉

- **基本信息**：职位名称、职位类型、岗位序列、职级序列、适用职级范围、默认职级、职级类别（派生只读）、默认用工形式、适用组织范围、生效日期。
- **职位内容**：职位定位、核心职责、任职要求。
- **联动**：选择岗位序列后带出职位名称后缀与建议名称；选择职级范围后带出职级类别并校验不跨类别；默认职级必须落在范围内。
- **版本**：编辑已启用职位时展示「本次修改将生成新版本」提示，变更说明必填；名称、范围、默认职级与用工形式变化时标记影响引用范围。
- **底部**：取消、保存草稿、保存并启用。

### 详情抽屉

- **页签**：基本信息、职级映射、在岗人员、编制引用、变更记录。
- **基本信息**：展示全部标准职位字段与当前版本；提供编辑与启停入口。
- **职级映射**：展示适用职级范围、默认职级、职级类别与命名规则来源。
- **在岗人员**：按员工资料当前任职展示工号、姓名、组织、职级、入职日期与在岗状态；只读，支持跳转员工资料。
- **编制引用**：展示引用该标准职位的编制明细行、组织、编制数量、在编人数、招聘占用与可用缺额；只读，支持跳转编制管理。
- **变更记录**：按时间倒序展示版本与字段变更，字段、原值、新值、原因、操作人与时间。

### 批量导入

- 使用「标准职位导入模板」，单次不超过 500 行；支持 .xlsx，单文件不超过 20MB。
- 字段包含职位名称、职位类型、岗位序列、职级序列、适用职级范围、默认职级、默认用工形式、适用组织、职位定位、核心职责、任职要求、生效日期。
- 导入前展示预览：新增数、更新数、忽略数与失败行数；失败行不导入并生成失败回执。
- 校验岗位序列存在、适用职级不跨类别、默认职级在范围内、名称在同序列内唯一、编码未重复。

## 岗位映射

### 页面结构

- **页头**：页签同一路由；页签右侧「生成映射」「导入在岗明细」「批量切换」「导出」。
- **统计卡**：在岗员工数、一致数量、命名不一致数量、职级错配数量、层级未建设数量、序列未建设数量、待切换数量；待切换包含待处理与待切换两类。
- **基础筛选**：关键字（姓名 / 工号）、组织、岗位序列、职级、匹配结果、切换状态。
- **高级筛选**：当前职位名称、建议标准职位、是否有建议职位、更新时间区间、来源。
- **表格列**：工号、姓名、组织、当前职位名称、岗位序列、职级、建议标准职位、匹配结果、切换状态、来源、更新时间、操作。
- **行内操作**：查看、切换、忽略；不可切换时操作置灰并展示原因。
- **批量操作**：批量生成映射、批量切换、批量忽略、导出当前筛选结果。

### 切换抽屉

- **员工信息**：工号、姓名、组织、当前职位、岗位序列、职级、直接上级。
- **当前与建议**：左右对照展示当前职位名称与建议标准职位；展示匹配结果与不可切换原因。
- **切换内容**：切换原因必填，生效方式为立即更正；展示「仅更正职位名称，不改变组织、职级、直接上级与编制」的提示。
- **影响说明**：更新员工资料当前任职职位名称；写入岗位变更记录；不生成调岗晋升记录。
- **底部**：取消、确认切换。

### 生成与刷新

- **生成映射**：按当前组织、序列与职级范围重新计算；生成过程展示进度与成功、失败数量。
- **自动刷新**：员工入职、转正、调岗晋升、离职或标准职位变更后，相关映射按最新数据重新计算；已切换记录保留原切换结果。
- **忽略**：单条或批量忽略须填写原因；忽略记录保留，不进入待切换统计。

### 导入在岗明细

- 使用「在岗人员岗位明细导入模板」，字段包含工号、姓名、三级组织、四级组织、五级组织、当前职位名称、岗位序列、职级、入职日期、用工形式。
- 按工号匹配员工；工号不存在、组织停用、序列或职级为空的行进入失败回执。
- 导入只生成或刷新映射，不直接切换；导入完成后由 HR 复核并执行批量切换。

## 空态与异常

- 职级矩阵无数据时展示「暂无职级数据」；岗位序列为空时展示「暂无岗位序列」。
- 标准职位无数据时展示「暂无标准职位」；筛选无结果时展示「暂无符合条件的标准职位」。
- 岗位映射无数据时展示「暂无岗位映射，请先生成或导入在岗明细」。
- 加载失败时在对应区块展示失败提示与「重试」，重试沿用原筛选条件。
- 保存、导入、切换失败时保留表单或弹窗内容，提示失败原因；数据被他人修改时提示已更新并刷新。

## 导航与权限

- 三个页签共享菜单权限 `MENU:HR:POSITION`；未授权不展示菜单。
- 职级体系编辑、岗位序列编辑、标准职位新建 / 编辑 / 启停 / 导入、映射生成 / 切换 / 忽略 / 导入、导出分别按按钮权限展示；未授权时按钮不展示，业务不可用时置灰并提示原因。
- 数据权限按组织范围过滤：岗位管理员与人力资源负责人全量；HRBP 本中心；部门负责人本部门只读。
