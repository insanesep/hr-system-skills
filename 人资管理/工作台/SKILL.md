# 工作台

## 模块概述

人资管理一级工作台：按当前用户的角色与数据权限，汇总招聘、入职、转正、离职、调岗晋升、绩效、编制、岗位映射、合同与考勤的待办、预警、日程与数据概览。工作台不新造业务数据，所有卡片读取来源模块的实时口径，点击卡片进入对应模块列表并带出筛选条件；无权限的卡片不展示，来源模块无数据的卡片展示零值或空态。

本功能不承载业务办理、数据修正与报表分析；招聘过程另有招聘工作台，绩效、入职等模块各自保留办理入口，本工作台只做聚合与导航。

## 端

- **web**：人资管理 → 工作台，仅桌面端管理后台，不提供 App 入口

## When to Use

- 查看本人权限范围内的待审批、待处理、待确认与逾期事项
- 跟进招聘、入职、转正、离职、异动、绩效、编制、岗位映射、合同与考勤的待办
- 查看试用期到期、离职逾期、招聘超期、编制超编与异动冲突等预警
- 查看未来七天的面试、入职、离职、转正、异动与绩效节点日程
- 查看在编、缺额、在招需求、待入职、本月入职离职与转正等数据卡
- 通过快捷入口进入来源模块，或复核卡片口径与数据权限

## 待办

<a id="待办"></a>

- 待办按模块分组，每组展示可处理记录数与主要状态；数字只统计当前用户数据权限内、当前角色可处理的记录。
- 招聘：待处理简历、待安排初试、待发 Offer；入职：今日待入职、待确认入职、信息采集或材料待办；转正：待评估、已延期待重新评估、待审批；离职：待审批、待交接、待确认；异动：待审批、待生效、生效冲突；绩效：待自评、待评价、待通晒、待确认；编制：待审批、待编制确认；岗位映射：待处理/待切换；合同：待签订、即将到期、待解除；考勤：待审批假勤、待处理异常、待确认月度。
- 点击待办卡进入来源模块列表，自动带出状态、组织与负责人筛选；工作台不提供行内办理。
- 待办数字随来源模块状态变化实时刷新；来源模块不可用时卡片展示失败提示与重试，不影响其他卡片。

## 预警

<a id="预警"></a>

- 招聘超期：招聘需求招聘天数 ≥150 天或预警状态为需升级。
- 试用期到期：转正单在七天内到期或已逾期未完成评估。
- 离职逾期：最后工作日已过但未确认离职，或必备交接事项未完成。
- 编制风险：可用缺额为负、待编制确认超过阈值或编制变更待处理需求。
- 异动冲突：审批通过但生效校验失败的异动单。
- 合同到期：合同 30/7 天内到期，或待签订超期。
- 考勤异常：月度考勤待确认、异常待处理或假勤待审批超时。
- 绩效逾期：自评、上级评价或通晒节点逾期未完成。
- 预警按严重程度排序，点击进入来源列表并带出预警筛选；预警只提示，不替代来源模块处理。

## 日程

<a id="日程"></a>

- 展示今天起未来七天的面试、入职、离职、转正、异动生效、合同到期与绩效节点，按日期与时间升序。
- 面试与入职日程读取招聘与入职模块；离职取最后工作日；转正取试用期结束日期；异动取生效日期；绩效取周期节点。
- 支持按类型筛选与「仅看与我相关」；与我相关包含本人安排、本人审批、本人负责或本人团队成员。
- 日程只读，不在此改期或办理；点击进入来源详情或列表。

## 数据概览

<a id="数据概览"></a>

- 数据卡包含在编人数、可用缺额、在招需求、待入职、本月入职、本月离职、本月转正与待切换岗位映射；口径与来源模块一致。
- 数据卡按当前用户数据权限过滤组织范围；指标为当前时点快照，不做趋势分析。
- 点击数据卡进入来源模块列表或看板，带出对应筛选；工作台不重复计算来源模块已有指标。

## 快捷入口

<a id="快捷入口"></a>

- 提供招聘工作台、入职台账、转正台账、离职台账、异动台账、绩效通晒、编制台账、岗位管理、合同管理、考勤管理与员工资料入口。
- 快捷入口按菜单权限展示；未授权不展示；点击进入对应路由，保留来源模块默认筛选。
- 支持最近访问与常用入口排序，排序为个人视图，不改变他人配置。

## Tips

- 工作台是聚合层，卡片口径以来源模块为准；不在工作台修正数据与重复定义指标
- 待办数字是「当前用户可处理」的记录数，不是全量记录数；无权限的卡片不展示
- 招聘过程已有招聘工作台，本工作台只提供招聘待办汇总与跳转，不替代招聘工作台
- 预警只提示不阻断；来源模块处理完成后预警自动消失
- 日程默认未来七天，绩效节点、合同到期与月度考勤确认按来源模块日期展示
- 规则查找：卡片计数与权限看 [文档/业务规则.md](文档/业务规则.md)，指标口径看 [文档/数据模型.md](文档/数据模型.md)，页面布局看 [文档/页面元素.md](文档/页面元素.md)
