# 工作台 · 业务规则

> 本文件描述工作台待办、预警、日程、数据概览与快捷入口的聚合规则；指标口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。工作台不新造业务数据，所有口径以来源模块为准。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 待办 | 当前用户在当前角色与数据权限内可处理的来源模块记录 |
| 预警 | 超过来源模块阈值或存在风险、需要关注的记录 |
| 日程 | 今天起未来七天的面试、入职、离职、转正、异动、合同到期、考勤确认与绩效节点 |
| 数据卡 | 在编、缺额、在招、待入职、本月入职离职与转正等当前时点指标 |
| 快捷入口 | 进入来源模块的导航入口，不改变来源数据 |
| 与我相关 | 本人安排、本人审批、本人负责或本人团队成员 |
| 可处理 | 当前用户拥有对应按钮权限且记录处于可操作状态 |

## 2. 功能边界

- 本工作台承载跨模块待办、预警、日程、数据卡与快捷入口的聚合展示。
- 不做：业务办理、数据修正、报表分析、趋势预测与跨模块指标重算。
- 招聘过程已有招聘工作台，本工作台只汇总招聘待办与跳转，不替代招聘工作台。
- 来源模块的口径、状态与权限以各自 SKILL 与 `业务规则.md` 为准；工作台不复制业务规则，只引用。
- 工作台不产生新的审批、交接、评价或异动记录。

## 3. 卡片可见性与权限

- 工作台按当前用户的角色与数据权限渲染卡片；无菜单权限的模块卡片不展示，无数据权限的组织不计数。
- 角色卡片范围：
  - **HR 管理员 / 人力资源负责人**：全部待办、预警、日程与数据卡。
  - **HRBP**：本中心的招聘、入职、转正、离职、异动、绩效、编制、岗位映射、合同与考勤卡片。
  - **招聘负责人 / 招聘HR**：招聘待办、招聘预警、面试日程与相关入职待办；其他卡片按授权展示。
  - **合同负责人**：待签订、即将到期与待解除合同卡片。
  - **考勤管理员**：考勤异常、假勤审批与月度确认卡片。
  - **中心负责人**：本中心待审批、待确认、预警与数据卡；不展示招聘候选人明细。
  - **部门负责人**：本部门待审批、试用期评估、绩效评价与团队成员日程；不展示编制调整与招聘台账。
- 菜单权限、按钮权限与数据权限同时校验；卡片可见不代表可办理，点击后按来源模块权限决定可操作范围。
- 员工本人不提供本工作台入口；个人待办在入职、绩效或对应模块处理。

## 4. 待办计数规则

- 待办数字为当前用户可处理记录数，不是全量记录数；同一记录只计入一个待办卡，不跨模块重复计数。
- 招聘待办取招聘过程工作台口径：待处理简历、待安排初试、待发 Offer；内推与猎头作为待处理简历的子集，不重复计数。
- 入职待办取入职台账：今日待入职、待确认入职、信息采集未提交、必备材料未交齐、必备准备未完成；同一入职单可出现在多个条件中，但只计入一个入职待办卡，卡内按条件拆分。
- 转正待办取转正台账：待评估、已延期待重新评估、待审批与七天内到期；同一转正单只计入一个状态。
- 离职待办取离职台账：待审批、待交接、待确认；同一离职单只计入一个状态。
- 异动待办取异动台账：待审批、待生效、生效冲突；同一异动单只计入一个状态。
- 绩效待办取绩效管理：待自评、待评价、待通晒、待确认；按当前用户角色与考核表状态计数。
- 编制待办取编制台账：待审批、待编制确认；岗位映射待办取岗位映射中状态为待处理或待切换的记录。
- 合同待办取合同台账与离职管理：待签订、30 天内即将到期合同，以及离职触发且未完成的合同解除待办；同一合同只计入一个状态。
- 考勤待办取考勤台账：待审批假勤、待处理考勤异常与待确认月度汇总；同一对象只计入一个状态。
- 待办数字随来源模块状态变化即时刷新；来源模块不可用时卡片展示失败提示与重试，不阻断其他卡片。

## 5. 预警规则

- 招聘超期：需求招聘天数 ≥150 天、预警状态为需升级或期望到岗日期已过且缺口大于零；取招聘需求管理口径。
- 试用期到期：转正单试用期结束日期在七天内，或已过试用期结束日期且未完成评估或审批；取转正管理口径。
- 离职逾期：最后工作日已过但未确认离职，或必备交接事项未完成；取离职管理口径。
- 编制风险：可用缺额小于零、待编制确认超过阈值、编制变更待处理需求；取编制管理口径。
- 异动冲突：异动单审批通过但生效校验失败；取调岗晋升口径。
- 绩效逾期：自评、上级评价、通晒或确认节点已过但未完成；取绩效管理口径。
- 合同到期：合同 30/7 天内到期，或待签订超期；取合同管理口径。
- 考勤异常：月度考勤待确认、异常待处理或假勤待审批超时；取考勤管理口径。
- 预警按严重程度与到期时间排序；点击进入来源列表并带出预警筛选；预警只提示，不阻断来源模块操作。
- 同一记录同时命中多个预警时只展示最高严重程度，不重复计数。

## 6. 日程规则

- 日程窗口为今天起未来七天，按日期与时间升序；无具体时间的节点按当天 09:00 排序。
- 面试日程取招聘过程面试场次；入职日程取入职单计划入职日期；离职日程取最后工作日；转正日程取试用期结束日期；异动日程取生效日期；合同日程取合同到期日期；考勤日程取月度考勤确认截止日期；绩效日程取周期目标截止、自评截止、上级评价截止、团队通晒与中心通晒日期。
- 「仅看与我相关」筛选：面试为本人安排或本人为面试官；入职为本人负责或本人为招聘负责人；离职为本人审批或本人负责；转正为本人评估或本人审批；异动为本人审批或本人发起；绩效为本人考核表或本人负责评价。
- 日程只读，不在此改期或办理；点击进入来源详情或列表，按来源权限校验。

## 7. 数据概览规则

- 在编人数取编制管理当前生效编制行的在编人数合计；可用缺额取编制数量减在编人数与招聘占用，负值展示超编。
- 在招需求取招聘管理中状态为招聘中的需求数；待入职取招聘看板口径：Offer 已接受、计划入职日期不早于今天、未入职且未爽约。
- 本月入职取入职管理本月确认入职人数；本月离职取离职管理本月确认离职人数；本月转正取转正管理本月生效人数。
- 待切换岗位映射取岗位映射中状态为待处理或待切换的记录数。
- 数据卡按当前用户数据权限过滤组织范围；指标为当前时点快照，不提供环比、趋势与下钻分析。
- 点击数据卡进入来源模块列表或看板，带出对应筛选；工作台不重复计算来源模块已有指标。

## 8. 刷新与异常

- 工作台在进入页面、切换组织范围、从来源模块返回时刷新；待办、预警与数据卡按来源模块实时口径重新计算。
- 单个卡片加载失败时只在卡片内展示失败提示与「重试」，不影响其他卡片；重试沿用原筛选与组织范围。
- 来源模块数据更新后，工作台在下一次进入或手动刷新时更新；不提供实时推送。
- 卡片计数与来源列表数量不一致时，以来源模块列表为准；工作台展示错误时记录诊断信息但不展示内部报文。
- 工作台不缓存跨天数据；跨天后按新日期重新计算日程与预警。

## 9. 权限编码

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:WORKBENCH` | 未授权不展示菜单 |
| 查看待办 | `BTN:HR_WORKBENCH:TODO` | 未授权不展示待办区 |
| 查看预警 | `BTN:HR_WORKBENCH:ALERT` | 未授权不展示预警区 |
| 查看日程 | `BTN:HR_WORKBENCH:SCHEDULE` | 未授权不展示日程区 |
| 查看数据概览 | `BTN:HR_WORKBENCH:OVERVIEW` | 未授权不展示数据卡 |
| 导出 | `BTN:HR_WORKBENCH:EXPORT` | 未授权不展示导出按钮 |

- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应区域或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 10. 与其他模块的边界

- 工作台是只读聚合层；待办与预警的办理在来源模块完成，工作台不提供行内审批、交接、评价与确认。
- 招聘过程工作台与本文工作台并存：前者办理招聘过程，后者汇总招聘待办与跳转；两者数字口径一致。
- 数据卡不替代招聘数据看板、编制规划与绩效分析；分析类指标以各自看板为准。
- 合同与考勤已接入：合同待签订、即将到期与待解除，以及考勤假勤审批、异常与月度确认进入工作台卡片；口径以合同管理与考勤管理为准。
