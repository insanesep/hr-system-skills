# 工作台 · 数据模型

> 本文件为工作台待办、预警、日程、数据卡与快捷入口的口径定义；规则见 [业务规则.md](业务规则.md)。工作台不存储业务实体，所有指标派生自来源模块。

## 1. 待办卡

| 卡片 | 来源模块 | 计数口径 | 点击去向 |
|---|---|---|---|
| 招聘待办 | 招聘过程管理 | 当前用户负责职位下待处理简历、初筛通过未安排初试、审批通过未发送 Offer 的记录数 | 招聘工作台，带出状态与负责人筛选 |
| 入职待办 | 入职管理 | 今日待入职、待确认入职、信息采集未提交、必备材料未交齐、必备准备未完成的入职单数 | 入职台账，带出对应页签与状态 |
| 转正待办 | 转正管理 | 待评估、已延期待重新评估、待审批与七天内到期的转正单数 | 转正台账，带出状态与到期筛选 |
| 离职待办 | 离职管理 | 待审批、待交接、待确认的离职单数 | 离职台账，带出状态与交接筛选 |
| 异动待办 | 调岗晋升 | 待审批、待生效、生效冲突的异动单数 | 异动台账，带出状态筛选 |
| 绩效待办 | 绩效管理 | 当前用户为员工、上级、HRBP 或中心负责人时，待自评、待评价、待通晒、待确认的考核表数 | 绩效评价或绩效通晒，带出周期与状态 |
| 编制待办 | 编制管理 | 待审批编制行、待编制确认记录数 | 编制台账，带出审批或确认筛选 |
| 岗位映射待办 | 岗位管理 | 切换状态为待处理或待切换的记录数 | 岗位映射页签，带出待处理/待切换筛选 |
| 合同待办 | 合同管理 / 离职管理 | 待签订合同数、30 天内即将到期合同数与离职触发的待解除合同数 | 合同台账，带出待签订/即将到期；待解除进入离职合同解除待办 |
| 考勤待办 | 考勤管理 | 待审批假勤数、待处理考勤异常数与待确认月度汇总数 | 考勤台账，带出假勤审批/异常/月度确认筛选 |

## 2. 预警卡

| 预警 | 来源模块 | 触发口径 | 严重程度 |
|---|---|---|---|
| 招聘超期 | 招聘需求管理 | 招聘天数 ≥150 天、预警状态为需升级，或期望到岗日期已过且缺口大于零 | 高 |
| 试用期到期 | 转正管理 | 试用期结束日期在七天内，或已过试用期结束日期且未完成评估或审批 | 高 |
| 离职逾期 | 离职管理 | 最后工作日已过但未确认离职，或必备交接事项未完成 | 高 |
| 编制超编 | 编制管理 | 可用缺额小于零，或编制变更待处理需求 | 中 |
| 编制待确认 | 编制管理 | 招聘入职回写后状态为待编制确认超过阈值 | 中 |
| 异动生效冲突 | 调岗晋升 | 审批通过但生效校验失败且未处理 | 高 |
| 绩效逾期 | 绩效管理 | 自评、上级评价、通晒或确认节点已过但未完成 | 中 |
| 合同到期 | 合同管理 | 合同 30/7 天内到期，或待签订超期 | 高 |
| 考勤异常 | 考勤管理 | 月度考勤待确认、异常待处理或假勤待审批超时 | 中 |

## 3. 日程

| 日程类型 | 来源模块 | 日期字段 | 时间 |
|---|---|---|---|
| 面试 | 招聘过程管理 | 面试场次日期 | 场次开始时间 |
| 入职 | 入职管理 | 计划入职日期 | 默认 09:00 |
| 离职 | 离职管理 | 最后工作日 | 默认 18:00 |
| 转正 | 转正管理 | 试用期结束日期 | 默认 09:00 |
| 异动生效 | 调岗晋升 | 生效日期 | 默认 00:00 |
| 绩效节点 | 绩效管理 | 目标截止、自评截止、上级评价截止、团队通晒、中心通晒日期 | 默认 09:00 |
| 合同到期 | 合同管理 | 合同到期日期 | 默认 09:00 |
| 月度考勤确认 | 考勤管理 | 考勤组月度确认截止日 | 默认 18:00 |

## 4. 数据卡

| 数据卡 | 来源模块 | 口径 |
|---|---|---|
| 在编人数 | 编制管理 | 当前生效编制行在编人数合计，包含待编制确认 |
| 可用缺额 | 编制管理 | 编制数量 − 在编人数 − 招聘占用；负值展示超编 |
| 在招需求 | 招聘需求管理 | 状态为招聘中的需求数 |
| 待入职 | 招聘数据看板 / 招聘过程管理 | Offer 已接受、计划入职日期不早于今天、未入职且未爽约 |
| 本月入职 | 入职管理 | 本月确认入职人数 |
| 本月离职 | 离职管理 | 本月确认离职人数 |
| 本月转正 | 转正管理 | 本月转正生效人数 |
| 待切换岗位映射 | 岗位管理 | 切换状态为待处理或待切换的记录数 |

## 6. 角色与卡片范围

| 角色 | 可见范围 |
|---|---|
| HR 管理员 / 人力资源负责人 | 全部卡片与数据卡 |
| HRBP | 本中心招聘、入职、转正、离职、异动、绩效、编制、岗位映射、合同与考勤 |
| 招聘负责人 / 招聘HR | 招聘待办、招聘预警、面试日程与相关入职待办 |
| 合同负责人 | 待签订、即将到期与待解除合同卡片 |
| 考勤管理员 | 考勤异常、假勤审批与月度确认卡片 |
| 中心负责人 | 本中心待审批、待确认、预警与数据卡 |
| 部门负责人 | 本部门待审批、转正评估、绩效评价与团队成员日程 |

## 7. 派生与刷新

| 字段 | 说明 |
|---|---|
| 统计时点 | 工作台加载时的来源模块实时口径，不缓存跨天数据 |
| 组织范围 | 按当前用户数据权限过滤，切换组织后重新计算 |
| 排序 | 待办按模块固定顺序；预警按严重程度与到期时间；日程按日期与时间 |
| 刷新 | 进入页面、切换组织、从来源模块返回时刷新；支持手动刷新 |
| 失败态 | 单卡失败只影响该卡，展示失败提示与重试 |
