# 工作台 · 页面元素

> 指标口径见 [数据模型.md](数据模型.md)，聚合规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，单页承载待办、预警、日程、数据概览与快捷入口，不设独立详情路由。原型见 [原型图/web/hr-workbench.html](../原型图/web/hr-workbench.html)。

## 页面结构

- **页头**：面包屑「首页 / 人资管理 / 工作台」；左侧问候与当前日期；右侧组织范围选择、刷新与「导出」。
- **组织范围**：按当前用户数据权限展示可选组织；默认全部可见范围，切换后所有卡片重新计算。
- **待办区**：按招聘、入职、转正、离职、异动、绩效、编制、岗位映射、合同与考勤分组卡片；每卡展示标题、主数字、状态拆分与「去处理」。
- **预警区**：列表展示预警类型、对象、触发原因、严重程度、到期时间与「去处理」；高风险置顶。
- **日程区**：未来七天时间轴或按日分组列表，展示日期、时间、类型、对象、组织与负责人；支持类型筛选与「仅看与我相关」。
- **数据概览区**：八张数据卡，展示在编人数、可用缺额、在招需求、待入职、本月入职、本月离职、本月转正与待切换岗位映射。
- **快捷入口区**：招聘工作台、入职台账、转正台账、离职台账、异动台账、绩效通晒、编制台账、岗位管理、合同管理、考勤管理、员工资料；支持最近访问排序。

<a id="todos"></a>

## 待办卡

- 卡片标题展示模块名称与主数字；副行展示状态拆分，如「待处理简历 12 · 待安排初试 4 · 待发 Offer 2」。
- 主数字为当前用户可处理记录数；无权限的模块不展示卡片；有权限但无数据时展示 0 与「暂无待办」。
- 点击卡片或「去处理」进入来源模块列表，带出状态、组织、负责人筛选；不在工作台内打开审批或办理弹层。
- 卡片加载失败时展示失败提示与「重试」，不影响其他卡片。

<a id="alerts"></a>

## 预警

- 表格或列表列：预警类型、对象、组织、触发原因、严重程度、到期时间、负责人、操作。
- 严重程度为高、中、低；高风险使用警示样式，中风险使用提示样式，低风险为中性。
- 支持按预警类型、严重程度与组织筛选；默认按严重程度与到期时间升序。
- 点击对象进入来源详情；点击「去处理」进入来源列表并带出预警筛选。
- 无预警时展示「暂无预警」；预警处理完成后从列表移除。

<a id="schedule"></a>

## 日程

- 默认展示今天起未来七天；按日期分组，组内按时间升序。
- 每条日程展示时间、类型、对象、组织、负责人与状态；类型包括面试、入职、离职、转正、异动生效与绩效节点。
- 类型筛选为多选；「仅看与我相关」只展示本人安排、本人审批、本人负责或本人团队成员。
- 无日程时展示「未来七天暂无日程」；加载失败展示失败提示与「重试」。

<a id="overview"></a>

## 数据概览

- 数据卡以两行四列或响应式网格排列；每卡展示指标名称、数值、口径说明与跳转入口。
- 可用缺额为负时展示超编警示；待入职、本月入职离职与转正展示人数。
- 数据卡为当前时点快照，不展示环比、趋势与图表分析。
- 点击数据卡进入来源列表或看板，带出对应筛选；无权限的数据卡不展示。

<a id="shortcuts"></a>

## 快捷入口

- 以图标或文字按钮排列，按菜单权限展示；未授权入口不展示。
- 最近访问按个人视图排序，记录最近五次进入的模块；不改变他人视图。
- 点击进入对应路由，保留来源模块默认筛选。

## 空态与异常

- 待办无数据展示「暂无待办」；预警无数据展示「暂无预警」；日程无数据展示「未来七天暂无日程」；数据卡为 0 时正常展示。
- 单个区域加载失败时在该区域展示失败提示与「重试」，重试沿用当前组织范围与筛选。
- 组织范围切换失败时保留原范围并提示原因，不清空已有卡片。
- 页面刷新或从来源模块返回时重新计算；不提供跨天缓存与实时推送。

## 导航与权限

- 菜单权限 `MENU:HR:WORKBENCH`；待办、预警、日程、数据概览与导出分别按按钮权限展示。
- 卡片可见性按角色与数据权限控制：HR 管理员全量；HRBP 本中心；招聘负责人招聘相关；中心负责人本中心审批与数据；部门负责人本部门审批与团队日程。
- 点击卡片后的来源模块权限独立校验；工作台可见不代表来源模块可办理。
- 工作台不展示员工个人入口；员工个人待办在入职、绩效或对应模块处理。
