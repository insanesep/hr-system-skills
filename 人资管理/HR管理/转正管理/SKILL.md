# 转正管理

## 模块概述

人资管理 → HR管理下的试用期转正入口：入职确认后，系统按 Offer 约定的试用期生成转正单；在试用期结束前提醒直接上级评估，员工或 HR 可发起提前转正，评估不通过可延期或转离职。列表以「待评估 / 待审批 / 已转正 / 已延期 / 未通过 / 已撤销」六个页签组织台账，支持按组织、试用期结束日期、评估状态与转正类型筛选；详情集中呈现试用信息、评估表、审批记录、影响范围与操作记录。转正生效后补充员工资料转正日期、更新绩效名单人员状态与转正日期，并写入员工成长记录。

本功能只承载试用期评估、转正审批与生效，不承载招聘、入职办理、绩效评价、薪酬调整与劳动合同签订。

## 端

- **web**：人资管理 → HR管理 → 转正管理，仅桌面端管理后台，不提供 App 入口

## When to Use

- 查看待转正、待评估、待审批、已转正、已延期与未通过人员台账
- 发起或撤回提前转正，填写转正评估表并提交审批
- 审批转正、退回评估或要求补充材料
- 处理转正延期、转正不通过与离职衔接
- 批量提醒评估、导出转正名单或复核生效日期与权限编码

## 转正台账

<a id="转正台账"></a>

- 页签固定为待评估、待审批、已转正、已延期、未通过、已撤销；待评估包含试用期未到、临近到期与已逾期的转正单，已延期为延期后等待重新评估的转正单。
- 基础筛选：姓名 / 工号、组织、职位、职级、试用期结束日期区间、转正类型、单据状态。
- 高级筛选：评估人、HRBP、试用期时长、是否提前转正、是否延期、是否逾期、是否已关联离职。
- 统计卡展示待评估、待审批、本月应转正、已转正、已延期与未通过数量。
- 支持批量提醒评估、导出当前筛选结果；已转正与未通过记录只读。

## 转正评估与审批

<a id="转正评估与审批"></a>

- 转正单由入职确认自动生成；试用期结束前 30 天、7 天与到期日提醒直接上级与 HRBP。
- 直接上级填写评估表：工作业绩、专业能力、协作与价值观、出勤与纪律四个维度，给出通过、延期或不通过结论与评语。
- 评估提交后进入待审批，审批链为直接上级 → 部门负责人 → HRBP；经理级及以上增加中心负责人。
- 审批可退回评估补充；审批通过后按转正类型生效；延期须填写延期后试用期结束日期与原因，进入已延期队列继续评估。
- 提前转正须在试用期结束前发起，填写提前转正理由与期望生效日期；审批通过日生效，不受试用期结束日期限制。

## 转正不通过

<a id="转正不通过"></a>

- 转正不通过须填写客观原因与评估依据，单据进入未通过；员工仍处于试用期，直至离职管理确认离职。
- HR 可在未通过详情中发起离职，离职类型固定为试用期不通过并关联转正单；未发起离职前，员工在职状态不自动变更。
- 未通过为终态，不可改为已转正；确需重新评估的，由 HRBP 发起更正并重新生成转正单。

## 影响范围

- **员工资料**：转正生效后在职状态保持在职，补充转正日期；当前任职记录不新增，组织、职位与职级不变，历史保留。
- **绩效管理**：考核名单人员状态由试用改为正式，转正日期更新；不改变已生效绩效结果。
- **员工成长记录**：写入转正事件，包含转正类型、生效日期、评估结论与组织职位快照。
- **工作台**：待评估、待审批、临近到期与逾期数量进入工作台待办与预警。

## Tips

- 转正单由入职确认生成，不在本功能手工新建；无试用期员工不生成转正单
- 试用期结束日期取 Offer 约定试用期与入职日期，提前转正不改变原试用期结束日期
- 审批通过日晚于试用期结束日期时，实际转正日期取审批通过日，避免追溯生效
- 延期以一次为限；延期后进入已延期队列继续评估，延期到期仍未通过的按未通过处理
- 转正不通过不自动离职，须由 HR 在离职管理发起并确认
