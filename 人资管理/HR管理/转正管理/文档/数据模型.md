# 转正管理 · 数据模型

> 本文件为转正单、评估项、审批与操作记录的字段口径；规则见 [业务规则.md](业务规则.md)。一份入职单对应一张转正单，一张转正单包含多条评估项与审批记录。

<a id="1-转正单"></a>

## 1. 转正单

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 转正单号 | 转正单唯一标识 | 文本 | 是 | 全局唯一，按年月生成，如 RG20261123001 |
| 来源入职单 | 生成转正单的入职单 | 文本 | 是 | 一份入职单对应一张转正单 |
| 员工 | 转正员工 | 文本 | 是 | 引用员工资料 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 组织路径 | 员工所属组织快照 | 文本 | 是 | 一至五级组织 |
| 职位 | 当前职位快照 | 文本 | 是 | 引用标准职位或员工资料当前职位 |
| 职级 | 当前职级快照 | 文本 | 是 | 如 P5 |
| 岗位序列 | 当前岗位序列快照 | 文本 | 否 | 引用岗位管理 |
| 入职日期 | 员工入职日期 | 日期 | 是 | 取自入职单 |
| 试用期开始日期 | 试用期起算日期 | 日期 | 是 | 默认取入职日期 |
| 试用期结束日期 | 试用期到期日期 | 日期 | 是 | 由 Offer 约定试用期计算 |
| 试用期时长 | 试用期月数或天数 | 数值 | 是 | 按 Offer 约定 |
| 直接上级 | 评估人与团队负责人 | 文本 | 是 | 取自员工资料 |
| 招聘负责人 | 入职招聘负责人 | 文本 | 否 | 取自入职单快照 |
| 招聘HR | 入职招聘HR | 文本 | 否 | 取自入职单快照 |
| 转正类型 | 本次转正类型 | 枚举 | 是 | 按期转正、提前转正、延期转正、试用期不通过 |
| 期望生效日期 | 期望转正日期 | 日期 | 否 | 提前转正必填 |
| 评估结论 | 直接上级结论 | 枚举 | 否 | 通过、延期、不通过 |
| 评估总分 | 评估项加权总分 | 数值 | 否 | 1–5 分，保留一位小数 |
| 评估说明 | 评估总结 | 文本 | 否 | 不超过 1000 字 |
| 延期后试用期结束日期 | 延期后的到期日期 | 日期 | 否 | 延期时必填 |
| 延期原因 | 延期说明 | 文本 | 否 | 延期时必填 |
| 不通过原因 | 不通过客观原因 | 文本 | 否 | 不通过时必填 |
| 审批状态 | 审批结果 | 枚举 | 是 | 待审批、已通过、已驳回、已撤回 |
| 单据状态 | 转正单当前状态 | 枚举 | 是 | 待评估、待审批、已转正、已延期、未通过、已撤销 |
| 实际转正日期 | 生效后写入员工资料、绩效名单与成长记录的日期 | 日期 | 否 | 已转正时填写 |
| 是否逾期 | 是否超过试用期结束日期 | 布尔 | 是 | 派生字段 |
| 关联离职单 | 不通过后发起的离职单 | 文本 | 否 | 引用离职管理 |
| 备注 | 补充说明 | 文本 | 否 | 不超过 500 字 |
| 创建时间 | 生成时间 | 日期时间 | 是 | 入职确认时写入 |
| 更新时间 | 最近更新时间 | 日期时间 | 是 | — |

## 2. 转正评估项

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 评估项标识 | 评估项唯一标识 | 文本 | 是 | 从属于转正单 |
| 转正单号 | 所属转正单 | 文本 | 是 | — |
| 评估维度 | 评估分类 | 枚举 | 是 | 工作业绩、专业能力、协作与价值观、出勤与纪律 |
| 权重 | 维度权重 | 数值 | 是 | 四项合计 100%，默认 40/30/20/10 |
| 自评分 | 员工自评分 | 数值 | 否 | 1–5 分，选填 |
| 自评说明 | 员工自评说明 | 文本 | 否 | 不超过 500 字 |
| 上级评分 | 直接上级评分 | 数值 | 是 | 1–5 分 |
| 上级评语 | 直接上级评语 | 文本 | 是 | 不超过 500 字 |
| 代评原因 | 直接上级空缺时的代评说明 | 文本 | 否 | 代评时必填 |

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 审批记录标识 | 审批记录唯一标识 | 文本 | 是 | 从属于转正单 |
| 转正单号 | 所属转正单 | 文本 | 是 | — |

| 审批结果 | 审批结论 | 枚举 | 是 | 待审批、已通过、已驳回、已撤回 |
| 审批意见 | 审批意见 | 文本 | 否 | 驳回时必填 |
| 审批时间 | 审批时间 | 日期时间 | 否 | — |

## 4. 操作记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 记录标识 | 操作记录唯一标识 | 文本 | 是 | 只增不改不删 |
| 转正单号 | 所属转正单 | 文本 | 是 | — |
| 操作类型 | 操作分类 | 枚举 | 是 | 生成、评估、提交、退回、审批、撤回、延期、转正生效、未通过、发起离职、导出 |
| 操作内容 | 操作摘要 | 文本 | 是 | 包含变更前后内容与原因 |
| 操作人 | 操作人员 | 文本 | 是 | — |
| 操作时间 | 操作时间 | 日期时间 | 是 | 倒序展示 |

## 5. 实体关系

- 入职单与转正单为一对一：一份入职单生成一张转正单。
- 转正单与评估项为一对多：四个评估维度各一条。
- 转正单与审批记录为一对多：每个审批节点一条记录。
- 转正单与离职单为一对零或一：不通过后可发起一张离职单。
- 转正单与员工资料为多对一：员工可有多段试用期与多张转正单，历史记录保留。

## 6. 枚举

| 枚举 | 取值 |
|---|---|
| 转正类型 | 按期转正、提前转正、延期转正、试用期不通过 |
| 评估结论 | 通过、延期、不通过 |
| 评估维度 | 工作业绩、专业能力、协作与价值观、出勤与纪律 |
| 审批状态 | 待审批、已通过、已驳回、已撤回 |
| 单据状态 | 待评估、待审批、已转正、已延期、未通过、已撤销 |
| 操作类型 | 生成、评估、提交、退回、审批、撤回、延期、转正生效、未通过、发起离职、导出 |
