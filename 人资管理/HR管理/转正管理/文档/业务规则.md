# 转正管理 · 业务规则

> 本文件描述转正单从生成、评估、审批到生效的规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。转正结果回写员工资料、绩效管理与员工成长记录，不通过时衔接离职管理。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 转正单 | 一名试用期员工一次转正办理的记录，由入职确认自动生成 |
| 试用期 | Offer 与入职单约定的试用时间，自入职日期起算 |
| 转正类型 | 按期转正、提前转正、延期转正、试用期不通过 |
| 转正评估 | 直接上级按评估维度填写评分、评语与结论的过程 |
| 实际转正日期 | 转正生效后写入员工资料、绩效名单与成长记录的日期 |
| 延期 | 延长试用期并重新评估，延期以一次为限 |
| 逾期 | 试用期结束日期已过但未完成评估或审批 |
| 转正不通过 | 评估结论为不通过，员工仍处于试用期并衔接离职管理 |

## 2. 功能边界

- 本功能承载转正单生成、评估、审批、提前转正、延期、不通过记录与生效回写。
- 不做：招聘、入职办理、绩效评价与等级校准、薪酬调整、劳动合同签订、员工档案日常维护。
- 员工资料、绩效管理与离职管理只读引用或按生效结果回写；本功能不修改员工职级、职位与编制。
- 试用期时长与转正日期以 Offer 与入职单为准；本功能不重新约定试用期。

## 3. 转正单生成

- 入职管理确认入职后，系统按入职单的雇佣关系、试用期与入职日期生成转正单；一份入职单对应一张转正单。
- 全职-正式且试用期大于零的员工生成按期转正单；无试用期员工不生成转正单。
- 实习生转正按「实习转正」类型生成，须在入职单标记可转正；劳务、兼职与外包不生成转正单。
- 转正单带出入职单快照：员工、组织、职位、职级、岗位序列、入职日期、试用期开始与结束日期、直接上级、招聘负责人、招聘HR与试用期时长。
- 入职单后续变更组织、职位或直接上级时不自动改写已生成转正单；由 HRBP 在转正单中更正并记录原因。
- 同一员工同一时点仅允许一张进行中的转正单，同一入职单只生成一张；员工再入职按新入职单生成新转正单，已转正、未通过或已撤销的同一入职单不再重复生成。

## 4. 评估规则

- 转正单状态为待评估时，直接上级可填写评估表；员工可补充自评说明，自评不参与审批结论。
- 评估维度固定为工作业绩、专业能力、协作与价值观、出勤与纪律四项；评分范围 1–5 分，评语必填。
- 评估结论为通过、延期或不通过；选择延期须填写延期后试用期结束日期与原因，选择不通过须填写客观原因与评估依据。
- 评估提交后进入待审批，评估内容只读；审批退回后回到待评估，可修改后重新提交。
- 已延期状态的转正单可重新填写评估并提交审批；延期后再次评估仍不通过时按未通过处理。
- 试用期结束前 30 天、7 天与到期日生成提醒；逾期未评估的记录在台账与工作台标记逾期，不自动转正。
- 评估人为直接上级；直接上级空缺或离职时由部门负责人代评，须在评估表中记录代评原因。

## 5. 审批与生效

- 审批链：直接上级 → 部门负责人 → HRBP；经理级及以上、关键岗位或提前转正增加中心负责人审批。
- 审批通过后按转正类型生效：
  - **按期转正**：实际转正日期取试用期结束日期；审批通过日晚于试用期结束日期时，取审批通过日。
  - **提前转正**：实际转正日期取审批通过日；提前转正不改变原试用期结束日期记录。
  - **延期转正**：不立即转正，试用期结束日期更新为延期后日期，单据进入已延期队列继续评估；延期以一次为限。
- 审批驳回回到原评估状态并记录驳回原因；首次评估回待评估，延期后评估回已延期。申请人可在待审批阶段撤回，撤回后回到原评估状态。
- 转正生效为终态，不可撤销；确需更正时由 HRBP 发起更正并写入操作记录，不删除原转正单。
- 转正生效后：员工资料在职状态保持在职并补充转正日期；绩效名单人员状态与转正日期更新；写入员工成长记录转正事件。

## 6. 提前转正与延期

- 提前转正须在试用期结束前发起，填写提前转正理由、期望生效日期与直接上级意见；审批通过日生效。
- 提前转正不得早于入职后一个月；具体最短试用期按公司制度，参数由 HRBP 在发起时校验。
- 延期转正须填写延期后试用期结束日期与原因，延期以一次为限；延期后试用期结束日期不得晚于入职后六个月，超过时按不通过处理并转离职。
- 延期到期仍未完成评估或审批的，台账标记逾期；HRBP 可催办或按不通过处理。
- 延期期间员工仍处于试用期，绩效名单人员状态保持试用；延期不改变已生效绩效结果。

## 7. 转正不通过

- 不通过须由直接上级评估、部门负责人与 HRBP 审批确认；单据状态为未通过，员工仍处于试用期。
- HR 可在未通过详情发起离职，离职类型固定为试用期不通过并关联转正单；离职单按离职管理审批与确认。
- 未发起离职前，员工状态不自动变为离职，编制在编人数不变；离职确认后才回减编制。
- 未通过为终态，不可改为已转正；确需重新评估的，由 HRBP 发起更正并重新生成转正单，原单保留。
- 未通过记录进入员工成长记录，事件类型为转正未通过；员工成长记录展示最近一次转正结论。

## 8. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 转正单状态 | 待评估、待审批、已转正、已延期、未通过、已撤销 | 待评估与待审批为警示标签，已转正为主色标签，其余中性 |
| 审批状态 | 待审批、已通过、已驳回、已撤回 | 待审批为警示标签，已通过为主色 |
| 转正类型 | 按期转正、提前转正、延期转正、试用期不通过 | 文本 |
| 评估结论 | 通过、延期、不通过 | 通过为主色，延期为提示，不通过为警示 |
| 评估维度 | 工作业绩、专业能力、协作与价值观、出勤与纪律 | 文本 |
| 是否逾期 | 是、否 | 是为止损标签 |
| 是否已关联离职 | 是、否 | 文本 |

## 9. 权限编码与数据范围

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:REGULARIZATION` | 未授权不展示菜单 |
| 发起提前转正 | `BTN:HR_REGULARIZATION:EARLY` | 未授权不展示入口 |
| 评估填写 | `BTN:HR_REGULARIZATION:EVALUATE` | 直接上级与代评人可见 |
| 提交评估 | `BTN:HR_REGULARIZATION:SUBMIT` | 评估人可见 |
| 审批 | `BTN:HR_REGULARIZATION:APPROVE` | 按审批节点校验 |
| 退回评估 | `BTN:HR_REGULARIZATION:RETURN` | 审批人可见 |
| 撤回 | `BTN:HR_REGULARIZATION:WITHDRAW` | 评估人可见 |
| 转正不通过 | `BTN:HR_REGULARIZATION:FAIL` | 评估人与 HRBP 可见 |
| 发起离职 | `BTN:HR_REGULARIZATION:TO_OFFBOARD` | 未通过详情可见 |
| 批量提醒 | `BTN:HR_REGULARIZATION:REMIND` | 未授权不展示提醒入口 |
| 导出 | `BTN:HR_REGULARIZATION:EXPORT` | 未授权不展示导出按钮 |

- 数据权限：员工本人只读；直接上级本团队；部门负责人本部门；中心负责人与 HRBP 本中心；HR 管理员全量。
- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 10. 与其他模块的边界

- **入职管理**：转正单由入职确认生成；入职单撤销或取消时，未生效转正单同步取消并保留记录。
- **员工资料**：转正生效后补充转正日期并保持在职状态；不新增任职记录，员工组织、职位与职级不因转正改变。
- **绩效管理**：转正只更新考核名单人员状态与转正日期；绩效评价、等级与系数仍由绩效管理决定。
- **离职管理**：转正不通过可发起离职，离职单关联转正单；离职确认后回减编制。
- **工作台**：待评估、待审批、临近到期与逾期数量进入工作台待办与预警。
