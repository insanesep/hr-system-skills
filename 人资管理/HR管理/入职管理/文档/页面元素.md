# 入职管理 · 页面元素说明

> 字段口径见 [数据模型.md](数据模型.md)，办理规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，入职台账与入职详情在同一原型内以 `#list` / `#detail/{入职单号}` 双视图互联。

<a id="onboarding-list"></a>

## 入职台账

- **页面路径**：`/hr/onboarding/list`（产品页面约定）
- **权限编码**：路由 `MENU:HR:ONBOARDING`；按钮见 [业务规则.md §13](业务规则.md#13-权限编码)
- **页面类型**：操作列表页（页签台账 + 批量操作 + 弹层办理）
- **区块职责**：
  - 页头：标题「入职管理」与左侧图标；右侧操作区「提醒必备事项」「改期入职」「导出」；操作区下方为四个页签
  - 页签：待入职 / 今日待入职 / 已入职 / 未到岗，各页签展示记录数，当前页签高亮
  - 筛选区：基础筛选一行 +「高级筛选」展开入口 +「清空已选」
  - 表格区：表头复选框与列、行数据、行操作；表头右侧齿轮为列设置
  - 分页区：总数与页码切换
- **基础筛选**：姓名（输入框，输入后防抖即时查询）、待入职部门（下拉）、雇佣关系（下拉）、计划入职日期（日期区间）、入职状态（多选下拉，含「空（未填写）」「正常」「延期」）、招聘季度（下拉）、到岗结果（多选：待到岗 / 已到岗 / 未到岗（爽约）/ 已取消）；条件变更即时查询
- **高级筛选**：点击「高级筛选」向下展开，包含信息采集状态（多选）、入职材料状态（多选）、招聘负责人（下拉）、招聘HR（下拉）、Offer 发送人（下拉）、是否逾期（是 / 否）、爽约原因（多选：个人原因 / 薪酬 / 地点 / 家庭 / 其他）；再次点击收起，已生效条件在展开按钮旁以数量角标提示
- **清空已选**：清空基础与高级全部条件，恢复页签默认排序并回到第一页
- **表格列**（默认全部显示，列设置可隐藏）：
  - 固定列：复选框、姓名、操作
  - 可配置列：待入职部门、职位、职级、证件号码、招聘季度、招聘HR、计划入职日期、入职状态、到岗结果、爽约原因、职级差异、信息采集状态、招聘负责人、入职准备进度、入职材料状态、Offer 发送人
  - 展示规则：证件号码按脱敏结果展示；计划入职日期早于今天且未入职时以警示色展示；已入职页签的日期列展示实际入职日期，未到岗页签展示计划入职日期与爽约确认时间；招聘负责人、招聘HR与 Offer 发送人展示头像与姓名；入职准备进度展示「已完成 / 全部」；入职状态为「空（未填写）」时以中性文本展示；到岗结果为未到岗（爽约）时以警示标签展示；职级差异为低于 / 高于 Offer 时以警示标签展示
- **批量栏**：勾选记录后，在表格上方展示「已选 N 条」与「提醒必备事项」「改期入职」「标记未到岗」「取消选择」；未勾选时顶部对应按钮不可用；标记未到岗仅对计划日期已过的记录生效
- **行操作**：
  - 待入职 / 今日待入职：详情、提醒、改期、确认入职；计划日期已过时额外展示「标记未到岗」；不满足确认条件时「确认入职」置灰，悬停展示未满足项
  - 已入职：详情
  - 未到岗：详情；只读，不展示确认入职、改期与提醒
- **列设置**：齿轮打开列设置浮层，逐列勾选显示或隐藏并支持恢复默认；姓名与操作不可隐藏，设置按当前用户保留
- **导出**：点击「导出」展开下拉，默认按证件号码脱敏导出当前结果；勾选「含证件号码明文」后按明文导出，该项仅在具备敏感字段权限时展示，选择后二次确认并提示将记录导出审计
- **组件引用**：原生实现以页面内联样式与脚本为准，参照 `busyming-skills-design` 的 Button、BusyInput、PageableSelect、DatePicker、Tag、Checkbox、Popover、Table、Pagination、Message 交互口径
- **布局引用**：参见原型 [原型图/web/onboarding.html](../原型图/web/onboarding.html)

### 标记未到岗弹窗

- **打开方式**：行操作「标记未到岗」（单条）或批量栏「标记未到岗」（作用于勾选记录）。
- **前置校验**：仅计划入职日期早于今天且未确认入职、未标记未到岗的记录可标记；存在不满足条件的记录时逐条列出并阻断。
- **字段**：爽约原因（必填：个人原因、薪酬、地点、家庭、其他）、说明（选填，不超过 200 字）；展示「标记后将关闭对应 Offer 并释放职位名额，且不可撤销」。
- **反馈**：提交后按钮 loading；成功提示「已标记未到岗，招聘侧 Offer 已关闭」，记录移入未到岗页签；失败保留弹窗并提示原因。

### 改期入职弹窗

- **打开方式**：顶部「改期入职」（批量，作用于勾选记录）或行操作「改期」（单条）。
- **字段**：新计划入职日期（日期选择，必填，不得早于今天）、改期原因（多行文本，必填，不超过 200 字）。
- **批量提示**：批量改期时展示「将为 N 人设置新的计划入职日期」，并在确认前列出姓名。
- **反馈**：提交后按钮 loading；成功提示「已改期 N 人」，列表计划入职日期与入职状态即时更新；失败保留弹窗内容并提示原因。
- **关闭行为**：有未保存内容时二次确认「放弃本次改期？」。

### 提醒必备事项

- **打开方式**：顶部「提醒必备事项」（批量）或行操作「提醒」（单条）。
- **确认内容**：提示「将向 N 人发送必备事项提醒，含未完成的信息采集、未交齐的必备材料与未填写的入职状态」；24 小时内重复提醒的记录单独列出并需二次确认。
- **反馈**：成功提示「已发送提醒 N 人」；失败列出未送达人员与原因，可重试。

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 入职管理」
- 去向页：行操作「详情」进入入职详情；提醒、改期、导出、列设置为弹层，不跳转
- 返回行为：详情返回列表时保留页签、筛选条件、列设置与页码
- 面包屑：首页 / 人资管理 / HR管理 / 入职管理

## 入职详情

- **页面路径**：`/hr/onboarding/detail/{入职单号}`（非菜单页面）
- **权限编码**：与台账共用路由权限；按钮按 [业务规则.md §13](业务规则.md#13-权限编码) 组合展示
- **页面类型**：办理型详情页（概览 + 页签 + 沉底操作栏）
- **区块职责**：
  - 页头：返回列表、标题「入职详情」、入职状态与单据状态标签
  - 概览卡：姓名、入职单号、待入职部门、职位、职级、雇佣关系、计划入职日期、实际入职日期、招聘季度、招聘HR、招聘负责人、Offer 发送人、到岗结果、职级差异、爽约原因
  - 页签：信息采集 / 入职材料 / 入职准备 / Offer 信息 / 操作记录
  - 沉底操作栏：提醒必备事项、改期入职、确认入职（按条件启用）、标记未到岗（待入职且已逾期时启用）
- **信息采集页签**：
  - 状态卡：当前状态、首次发送时间、最近发送时间、暂存时间、提交时间、最近退回原因
  - 采集内容：按个人基本信息、联系方式、紧急联系人分组以只读描述列表展示；未提交时展示「候选人尚未提交」
  - 操作：未发送或已发送时展示「发送采集」「重新发送」；已暂存展示「重新发送」；已提交展示「退回重填」（须填写原因）；已入职后操作全部隐藏
- **入职材料页签**：
  - 汇总条：材料状态、必备材料已确认数 / 必备总数、预览权限提示
  - 材料清单表：材料名称、是否必备、状态、文件名、上传时间、确认人、确认时间、操作（预览、确认、退回）；退回时弹层填写原因
  - 操作按按钮权限展示；已入职后只保留预览
- **入职准备页签**：
  - 进度条：已完成事项数 / 全部事项数
  - 事项清单表：事项名称、是否必备、负责人、状态、完成时间、操作（标记完成 / 撤销完成）
  - 未授权维护权限时仅为只读表格
- **Offer 信息页签**：Offer 编号、Offer 发送人、发送时间、待入职部门、职位、职级、雇佣关系、计划入职日期；只读，链接指向招聘管理对应 Offer
- **操作记录页签**：按时间倒序展示操作类型、操作人、操作时间与说明；改期记录展示原计划日期与新计划日期
- **确认入职**：
  - 条件满足时按钮可用，点击后二次确认「确认入职后将写入员工档案且不可撤销，是否继续？」；成功后跳转已入职页签并提示「已确认入职，员工档案已生成」
  - 条件不满足时按钮置灰，按钮上方以提示条「暂不能确认入职」逐项列出未满足项，悬停按钮展示未满足原因

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 切换页签 | 具备菜单权限 | 否 | 表格区加载态 | 展示对应页签记录 → 停留本页 | 表格区展示加载失败与「重试」 |
| 发送采集 | 采集为未发送或已发送 | 否 | 行操作 loading | 提示「采集已发送」，状态为已发送 | 提示失败原因，可重试 |
| 退回重填 | 采集为已提交 | 是（须填写原因） | 详情按钮 loading | 提示「已退回」，状态回到已发送 | 保留原因并提示失败，可重试 |
| 材料确认 | 材料项为已提交 | 否 | 材料行 loading | 状态更新为已确认，汇总状态重算 | 提示失败原因，可重试 |
| 材料退回 | 材料项为已提交或已确认 | 是（须填写原因） | 材料行 loading | 状态更新为已退回，汇总状态重算 | 保留原因并提示失败，可重试 |
| 准备完成 / 撤销 | 具备准备维护权限 | 否 | 事项行 loading | 状态切换，进度条即时更新 | 回滚状态并提示失败 |
| 提醒必备事项 | 勾选待入职或今日待入职记录 | 24 小时内重复提醒需确认 | 顶部按钮 loading | 提示「已发送提醒 N 人」 | 列出未送达人员，可重试 |
| 改期入职 | 待入职或今日待入职 | 是 | 弹窗提交按钮 loading | 提示「已改期」，日期与状态更新，写入操作记录 | 保留弹窗内容并提示失败 |
| 标记未到岗 | 待入职且计划日期已过 | 是（终态操作） | 按钮 loading | 提示「已标记未到岗，招聘侧 Offer 已关闭」，记录移入未到岗 | 保留弹窗并提示失败 |
| 导出 | 具备导出权限 | 明文导出需确认 | 按钮 loading | 生成名单文件并下载 | 提示失败原因，可重试 |
| 确认入职 | 四项前置条件全部满足 | 是（终态操作） | 按钮 loading | 提示「已确认入职，员工档案已生成」，跳转已入职；存在职级差异时同时提示 | 保留详情并逐项提示未满足项 |
