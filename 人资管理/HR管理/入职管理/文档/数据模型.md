# 入职管理 · 数据模型

> 本文件为入职管理的实体与字段口径。一份入职单对应一份信息采集、一组入职材料、一组入职准备事项、多条改期记录与操作记录；确认入职后写入员工档案。规则见 [业务规则.md](业务规则.md)。

## 1. 入职单

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 入职单号 | 入职单的唯一标识 | 文本 | 是 | 全局唯一，列表与详情均展示 |
| 来源 Offer 编号 | 转入本入职单的 Offer | 文本 | 是 | 一份 Offer 对应一份入职单 |
| 姓名 | 待入职人员姓名 | 文本 | 是 | 取自 Offer 快照；姓名模糊查询的匹配字段 |
| 手机号码 | 候选人联系手机号 | 文本 | 是 | 脱敏展示，提醒送达依据 |
| 证件类型 | 身份证件类别 | 枚举 | 是 | 身份证、护照、其他 |
| 证件号码 | 身份证件号码 | 文本 | 是 | 脱敏展示；明文查看需敏感字段权限 |
| 雇佣关系 | 入职后的用工形式 | 枚举 | 是 | 全职、实习、兼职、劳务 |
| 待入职部门 | 入职后所属部门 | 文本 | 是 | 只读引用组织架构；列表筛选字段 |
| 职位 | 入职后岗位名称 | 文本 | 是 | 取自 Offer 快照 |
| 职级 | 入职后职级 | 文本 | 否 | 如 P4、P7；未填写展示「—」 |
| 计划入职日期 | 约定的入职日期 | 日期 | 是 | 可经改期调整；早于今天且未入职为逾期 |
| 实际入职日期 | 确认入职的日期 | 日期 | 否 | 确认入职时记为当天；未入职为空 |
| 入职状态 | 候选人对到岗计划的填写结果 | 枚举 | 是 | 空（未填写）、正常、延期；改期后为延期 |
| 到岗结果 | 候选人的实际到岗结果 | 枚举 | 是 | 待到岗、已到岗、未到岗（爽约）、已取消；待到岗包含今日与逾期 |
| 爽约原因 | 未到岗的原因 | 枚举 | 否 | 个人原因、薪酬、地点、家庭、其他；标记未到岗时必填 |
| 爽约确认人 | 标记未到岗的人员 | 文本 | 否 | 标记未到岗时记录 |
| 爽约确认时间 | 标记未到岗的时间 | 日期时间 | 否 | — |
| 职级差异标记 | 入职职级与 Offer 职级差异 | 枚举 | 否 | 无差异、低于 Offer、高于 Offer；确认入职时派生 |
| 招聘季度 | 入职人员归属季度 | 文本 | 是 | 取自 Offer 快照；确认入职后按实际入职日期所在季度更新 |
| 招聘HR | 负责本入职单的招聘人员 | 文本 | 是 | 取自 Offer 快照；人效归属按招聘侧招聘HR |
| 信息采集状态 | 信息采集的当前进度 | 枚举 | 是 | 未发送、已发送、已暂存、已提交 |
| 入职材料状态 | 材料交齐情况的汇总 | 枚举 | 是 | 未提交、未交齐、已交齐；由材料项推导 |
| 招聘负责人 | 负责本入职单的招聘人员 | 文本 | 是 | 取自 Offer 快照；列表筛选字段；人效归属以招聘HR为准 |
| Offer 发送人 | 发送 Offer 的人员 | 文本 | 是 | 取自 Offer 快照；列表筛选字段 |
| 单据状态 | 入职单的业务阶段 | 枚举 | 是 | 待入职、已入职、未到岗、已取消 |
| 写入员工工号 | 确认入职后生成的员工档案工号 | 文本 | 否 | 确认入职后回填，只读 |
| 创建时间 | 入职单生成时间 | 日期时间 | 是 | 由 Offer 转入时生成 |
| 更新时间 | 入职单最近一次变更时间 | 日期时间 | 是 | 提醒、改期、材料确认、准备完成与确认入职均更新 |

## 2. 信息采集

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 采集标识 | 采集记录的唯一标识 | 文本 | 是 | 从属于入职单 |
| 入职单号 | 所属入职单 | 文本 | 是 | — |
| 状态 | 采集的当前进度 | 枚举 | 是 | 未发送、已发送、已暂存、已提交 |
| 首次发送时间 | 首次发送采集的时间 | 日期时间 | 否 | 未发送为空 |
| 最近发送时间 | 最近一次发送或重发的时间 | 日期时间 | 否 | 重发不改变已提交状态 |
| 暂存时间 | 候选人最近一次暂存的时间 | 日期时间 | 否 | 仅暂存时更新 |
| 提交时间 | 候选人提交采集的时间 | 日期时间 | 否 | 提交后内容冻结 |
| 采集内容 | 候选人填写的入职登记信息 | 文本 | 否 | 含个人基本信息、联系方式与紧急联系人；按字段分组展示 |
| 最近退回原因 | 最近一次退回重填的说明 | 文本 | 否 | 退回时必填 |

## 3. 入职材料项

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 材料项标识 | 材料项的唯一标识 | 文本 | 是 | 从属于入职单 |
| 入职单号 | 所属入职单 | 文本 | 是 | — |
| 材料名称 | 材料项的展示名称 | 文本 | 是 | 来自统一材料清单 |
| 是否必备 | 是否属于必备材料 | 布尔 | 是 | 必备材料未全部确认时汇总为未交齐 |
| 状态 | 材料项的当前状态 | 枚举 | 是 | 未提交、已提交、已确认、已退回 |
| 文件名 | 已上传文件的展示名称 | 文本 | 否 | 未提交时为空 |
| 文件大小 | 已上传文件的体积 | 文本 | 否 | 以 KB / MB 展示 |
| 上传时间 | 候选人最近一次上传的时间 | 日期时间 | 否 | — |
| 确认人 | 核对材料的人员 | 文本 | 否 | 确认后记录 |
| 确认时间 | 材料确认的时间 | 日期时间 | 否 | — |
| 退回原因 | 材料不符合要求时的说明 | 文本 | 否 | 退回时必填 |

## 4. 入职准备事项

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 事项标识 | 准备事项的唯一标识 | 文本 | 是 | 从属于入职单 |
| 入职单号 | 所属入职单 | 文本 | 是 | — |
| 事项名称 | 准备事项的展示名称 | 文本 | 是 | 来自统一准备事项清单 |
| 是否必备 | 是否为确认入职的前置事项 | 布尔 | 是 | 必备事项全部完成方可确认入职 |
| 负责人 | 事项的办理人 | 文本 | 否 | 可为招聘负责人、HRBP 或部门对接人 |
| 状态 | 事项的当前状态 | 枚举 | 是 | 未完成、已完成 |
| 完成时间 | 事项标记完成的时间 | 日期时间 | 否 | 撤销完成时清空 |

## 5. 改期记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 记录标识 | 改期记录的唯一标识 | 文本 | 是 | 从属于入职单，只增不改 |
| 入职单号 | 所属入职单 | 文本 | 是 | — |
| 原计划日期 | 改期前的计划入职日期 | 日期 | 是 | — |
| 新计划日期 | 改期后的计划入职日期 | 日期 | 是 | 不得早于改期当天 |
| 改期原因 | 本次改期的说明 | 文本 | 是 | 不超过 200 字 |
| 操作人 | 执行改期的人员 | 文本 | 是 | — |
| 操作时间 | 改期发生时间 | 日期时间 | 是 | 详情按倒序展示 |

## 6. 操作记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 记录标识 | 操作记录的唯一标识 | 文本 | 是 | 只增不改不删 |
| 入职单号 | 所属入职单 | 文本 | 是 | — |
| 操作类型 | 发生的操作类别 | 枚举 | 是 | 发送采集、退回采集、提醒必备事项、改期入职、材料确认、材料退回、准备完成、撤销准备、确认入职、标记未到岗、取消入职 |
| 操作人 | 执行操作的人员 | 文本 | 是 | — |
| 操作时间 | 操作发生时间 | 日期时间 | 是 | 详情按倒序展示 |
| 说明 | 操作内容摘要 | 文本 | 否 | 改期记录起止日期、退回原因、提醒内容摘要等 |
