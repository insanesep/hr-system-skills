# 考勤管理 · 业务规则

> 本文件描述考勤记录、异常处理、假勤审批、考勤规则与月度汇总的规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。考勤结果进入工作台，不参与薪酬核算。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 考勤记录 | 一名员工某一天的出勤、打卡、假勤与异常汇总记录 |
| 考勤组 | 按组织范围绑定员工并引用班次的考勤规则集合；一名员工同一时点只归属一个考勤组 |
| 班次 | 上下班时间、打卡次数、弹性时间与跨天标记的规则 |
| 假勤申请 | 请假、加班、出差、补卡申请，经审批后回写考勤记录 |
| 异常 | 迟到、早退、缺卡、旷工等与班次规则不一致的考勤结果 |
| 补卡 | 对缺卡记录补充打卡时间的申请 |
| 月度汇总 | 按员工与月份聚合的应出勤、实际出勤、异常、假勤与加班汇总 |
| 待确认 / 已确认 / 已锁定 | 月度汇总的确认状态；锁定后更正须 HRBP 审批 |
| 考勤截止 | 员工离职日期后不再生成考勤记录 |

## 2. 功能边界

- 本功能承载日考勤、月考勤、假勤审批、异常处理与考勤规则。
- 不做：薪酬核算、奖金与扣款、请假制度设计、排班优化、外部考勤设备管理、打卡数据采集平台本身。
- 员工身份、组织、在职状态与入离职日期只读引用员工资料；本功能不修改员工档案。
- 假勤审批通过只更新考勤记录，不直接产生薪酬结果。
- 考勤规则变更不重算已确认或已锁定的月度考勤。

## 3. 考勤数据来源

- 考勤记录按员工入职日期生成，入职日期前不生成；离职确认后考勤截止到实际离职日期，之后不再生成。
- 考勤组按员工组织范围匹配；无匹配考勤组的员工不生成考勤记录，台账标记「未配置考勤组」。
- 打卡数据来源为外部考勤系统导入与手工补录；导入按员工工号与日期匹配，未匹配记录进入失败回执。
- 假勤审批通过后回写对应日期的请假、加班、出差状态；补卡通过后更新缺卡记录的打卡时间。
- 考勤记录以「员工 + 日期」唯一；重复导入同一员工同一天数据时按导入批次更新，保留操作记录。

## 4. 考勤匹配规则

- 考勤组引用的班次决定应打卡时间、工作日与休息日；节假日按考勤组配置。
- 出勤状态由打卡时间与班次规则匹配：
  - 正常：在班次允许范围内完成规定打卡。
  - 迟到：上班打卡晚于班次上班时间加迟到容差。
  - 早退：下班打卡早于班次下班时间。
  - 缺卡：应打卡但未打卡，且无有效补卡或假勤。
  - 旷工：工作日无打卡且无有效假勤或补卡。
  - 请假、加班、出差、外勤、休息：按假勤审批或班次规则标记。
- 同一记录可同时存在多个异常类型，例如迟到 + 缺卡；台账按主异常展示并支持查看全部。
- 考勤规则变更按生效日期生效，不重算历史已确认或已锁定月份。

## 5. 异常处理

- 员工或 HR 可对缺卡、迟到、早退等异常发起补卡或更正申请，填写原因与附件，进入假勤审批。
- 补卡申请仅针对缺卡记录；补卡时间须落在班次允许范围内，跨天班次按班次跨天标记处理。
- 更正申请可调整考勤状态或备注，须由 HRBP 审批；已锁定月份的更正须 HRBP 审批并保留原记录。
- 异常处理通过后更新考勤记录与月度汇总；驳回须填写原因，原异常保持。
- 异常状态为待处理、已处理、已忽略；忽略须填写原因，仍保留异常记录。
- 未处理异常进入工作台待办与预警，不自动关闭。

## 6. 假勤审批

- 假勤类型为请假、加班、出差、补卡；申请填写起止时间、时长、原因与附件。
- 审批链为直接上级 → HRBP；请假超过规定天数、跨中心或补卡跨月时增加中心负责人审批。
- 审批通过后回写日考勤与月度汇总；请假覆盖工作日时标记请假，加班按申请时长计入加班，出差覆盖日期标记出差，补卡更新缺卡。
- 审批驳回须填写原因；申请人可在待审批阶段撤回，撤回后不影响考勤记录。
- 同一员工同一时间段不允许重复请假、出差或加班申请；重叠申请阻断提交。
- 假勤申请不改变员工在职状态与编制；离职日期后的申请阻断。

## 7. 月度汇总与确认

- 月度汇总按员工与月份自动聚合日考勤、假勤与异常，展示应出勤、实际出勤、迟到、早退、缺卡、旷工、请假、加班、出差与考勤状态。
- 月度状态为待确认、已确认、已锁定；HRBP 或考勤管理员在考勤组「月度确认截止日」前确认，确认后锁定。
- 锁定后不再接受普通更正；确需更正时由 HRBP 发起更正审批，保留原记录与变更记录。
- 月度确认结果进入工作台待办与预警；未确认月份在月初提醒。
- 月度汇总可导出，导出字段与当前筛选一致；导出不改变考勤数据。
- 薪酬核算、奖金与扣款不在本功能范围，月度汇总只提供考勤结果。

## 8. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 日考勤状态 | 正常、迟到、早退、缺卡、旷工、请假、加班、出差、外勤、休息 | 正常为主色，迟到早退缺卡为提示，旷工为警示，其余中性 |
| 异常状态 | 待处理、已处理、已忽略 | 待处理为警示，已处理为主色，已忽略为中性 |
| 假勤类型 | 请假、加班、出差、补卡 | 文本 |
| 假勤审批状态 | 待审批、已通过、已驳回、已撤销 | 待审批为警示，已通过为主色，其余中性 |
| 月度状态 | 待确认、已确认、已锁定 | 待确认为提示，已确认为主色，已锁定为中性 |
| 考勤组状态 | 启用、停用 | 启用为主色，停用为中性 |
| 数据来源 | 外部导入、手工补录、假勤回写、系统生成 | 文本 |
| 考勤组匹配 | 已匹配、未配置考勤组 | 未配置为警示标签 |

## 9. 权限编码与数据范围

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:ATTENDANCE` | 未授权不展示菜单 |
| 日考勤查看 | `BTN:HR_ATTENDANCE:DAILY` | 未授权不展示日考勤 |
| 月考勤查看 | `BTN:HR_ATTENDANCE:MONTHLY` | 未授权不展示月考勤 |
| 假勤申请 | `BTN:HR_ATTENDANCE:APPLY` | 员工本人与 HRBP 可发起 |
| 假勤审批 | `BTN:HR_ATTENDANCE:APPROVE` | 按审批节点校验 |
| 异常处理 | `BTN:HR_ATTENDANCE:EXCEPTION` | 未授权不展示更正入口 |
| 考勤规则编辑 | `BTN:HR_ATTENDANCE:RULE_EDIT` | 未授权时规则只读 |
| 月度确认 | `BTN:HR_ATTENDANCE:CONFIRM` | 未授权不展示确认入口 |
| 导出 | `BTN:HR_ATTENDANCE:EXPORT` | 未授权不展示导出按钮 |

- 数据权限：HR 管理员与考勤管理员全量；HRBP 本中心；中心负责人与部门负责人按组织只读；员工本人只读本人考勤与假勤。
- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 10. 与其他模块的边界

- **员工资料**：员工身份、组织、在职状态与入离职日期只读引用；考勤不修改员工档案。
- **入职管理**：入职日期决定考勤起算；入职确认前不生成考勤记录。
- **离职管理**：离职确认后考勤截止到实际离职日期；离职日期后不再生成记录。
- **工作台**：待审批假勤、待处理异常与待确认月度进入工作台待办与预警。
- **薪酬管理**：不在本仓库范围；考勤结果可供下游薪酬核算使用，但本模块不计算薪资。
