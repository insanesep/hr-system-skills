# 考勤管理 · 数据模型

> 本文件为考勤记录、异常、假勤申请、考勤组、班次与月度汇总的字段口径；规则见 [业务规则.md](业务规则.md)。考勤记录按员工与日期唯一，月度汇总由日考勤与假勤自动聚合。

## 1. 考勤记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 考勤记录标识 | 考勤记录唯一标识 | 文本 | 是 | 员工 + 日期唯一 |
| 员工 | 员工姓名 | 文本 | 是 | 引用员工资料 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 组织路径 | 员工所属组织快照 | 文本 | 是 | 一至五级组织 |
| 考勤组 | 匹配的考勤组 | 文本 | 是 | 无匹配时标记未配置考勤组 |
| 日期 | 考勤日期 | 日期 | 是 | 员工入职日期至离职日期之间 |
| 班次 | 当日班次 | 文本 | 是 | 引用考勤组班次 |
| 上班时间 | 应上班时间 | 文本 | 是 | 如 09:00 |
| 下班时间 | 应下班时间 | 文本 | 是 | 如 18:00 |
| 上班打卡 | 实际上班打卡时间 | 日期时间 | 否 | 外部导入或补卡写入 |
| 下班打卡 | 实际下班打卡时间 | 日期时间 | 否 | 外部导入或补卡写入 |
| 日考勤状态 | 当日主状态 | 枚举 | 是 | 正常、迟到、早退、缺卡、旷工、请假、加班、出差、外勤、休息 |
| 异常类型 | 当日异常汇总 | 文本 | 否 | 多个类型以「、」分隔 |
| 异常状态 | 异常处理状态 | 枚举 | 否 | 待处理、已处理、已忽略 |
| 数据来源 | 记录来源 | 枚举 | 是 | 外部导入、手工补录、假勤回写、系统生成 |
| 考勤组匹配 | 是否匹配考勤组 | 枚举 | 是 | 已匹配、未配置考勤组 |
| 更正状态 | 是否已更正 | 枚举 | 是 | 未更正、更正中、已更正 |
| 备注 | 补充说明 | 文本 | 否 | 不超过 300 字 |
| 更新时间 | 最近更新时间 | 日期时间 | 是 | — |

|---|---|---|---|---|

## 3. 假勤申请

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 申请编号 | 假勤申请唯一标识 | 文本 | 是 | 全局唯一，按年月生成 |
| 员工 | 申请员工 | 文本 | 是 | 引用员工资料，须在职 |
| 假勤类型 | 申请分类 | 枚举 | 是 | 请假、加班、出差、补卡 |
| 开始时间 | 假勤开始时间 | 日期时间 | 是 | 请假、加班、出差必填 |

| 附件 | 证明材料 | 文本 | 否 | 仅记录附件标识，不存文件内容 |
| 关联考勤记录 | 关联的考勤记录 | 文本 | 否 | 补卡与更正时必填 |
| 审批状态 | 审批结果 | 枚举 | 是 | 待审批、已通过、已驳回、已撤销 |
| 审批人 | 当前审批人 | 文本 | 否 | — |
| 审批意见 | 审批意见 | 文本 | 否 | 驳回时必填 |
| 提交时间 | 提交时间 | 日期时间 | 是 | — |
| 更新时间 | 最近更新时间 | 日期时间 | 是 | — |

## 8. 实体关系

- 员工与考勤记录为一对多：一名员工每天一条考勤记录。
- 考勤记录与异常为一对多：一条日考勤可有多个异常类型。
- 假勤申请与考勤记录为多对零或多：请假、加班、出差、补卡通过后回写对应日期记录。
- 考勤组与员工为一对多：一个考勤组覆盖多名员工，一名员工同一时点只归属一个考勤组。
- 考勤组与班次为多对一：多个考勤组可引用同一班次。
- 员工与月度汇总为一对多：一名员工每月一条汇总。
