# 考勤管理 · 页面元素

> 字段口径见 [数据模型.md](数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端；四个页签在同一菜单路由 `/hr/attendance/list` 下以 `#daily`、`#monthly`、`#leave`、`#rules` 互联。原型见 [原型图/web/attendance-management.html](../原型图/web/attendance-management.html)。

<a id="attendance-daily"></a>

## 日考勤

### 页面结构

- **页头**：面包屑「首页 / 人资管理 / HR管理 / 考勤管理」；页头右侧「导入打卡数据」「导出」。
- **统计卡**：今日应出勤、正常出勤、异常待处理、请假/出差、未配置考勤组。
- **筛选**：日期或日期区间、组织、考勤组、员工姓名 / 工号、日考勤状态、异常状态。
- **表格列**：日期、姓名、工号、组织、考勤组、班次、上班打卡、下班打卡、日考勤状态、异常类型、数据来源、操作。
- **行内操作**：查看详情、处理异常、补卡；按异常状态与权限展示。
- **日考勤详情抽屉**：员工与考勤组信息、班次、打卡时间、异常列表、假勤记录、更正记录、操作记录；底部提供「处理异常」与「发起补卡」。

### 交互

- 默认今天，按日期倒序、组织与姓名排序；异常待处理置顶。
- 未配置考勤组的员工展示警示标签，不生成正常/异常判定。
- 筛选条件变更即时查询；空态展示「暂无考勤记录」；加载失败展示失败提示与「重试」。
- 导入打卡数据弹窗支持模板下载与文件上传，导入失败行生成回执。

## 月考勤

### 页面结构

- **统计卡**：本月应出勤人数、已确认人数、待确认人数、异常待处理、加班总时长。
- **筛选**：月份、组织、考勤组、员工姓名 / 工号、月度状态。
- **表格列**：姓名、工号、组织、月份、应出勤、实际出勤、迟到、早退、缺卡、旷工、请假、加班、出差、月度状态、操作。
- **行内操作**：查看月度明细、确认、导出；已锁定记录只读。
- **月度明细抽屉**：按日展示考勤状态与异常，展示假勤申请与更正记录；底部提供确认与导出。

### 交互

- 月份默认当前月；按组织与姓名排序，待确认与异常数量高的记录置顶。
- 确认前校验未处理异常与待审批假勤；存在未处理项时提示并列出清单。
- 锁定后更正入口置灰，由 HRBP 发起更正审批。
- 空态展示「暂无月度考勤」；加载失败展示失败提示与「重试」。

## 假勤审批

### 页面结构

- **统计卡**：待审批、本月已通过、请假天数、加班时长。
- **页签**：待审批、已通过、已驳回、已撤销。
- **筛选**：假勤类型、组织、申请人、开始日期区间、审批状态。
- **表格列**：申请编号、申请人、组织、假勤类型、开始时间、结束时间、时长、原因、审批状态、当前审批人、操作。
- **行内操作**：审批、查看、撤回。
- **审批抽屉**：申请人信息、假勤类型与时间、时长、原因、附件、审批链与意见；底部通过、驳回。

### 交互

- 待审批按提交时间升序；已通过按开始时间倒序；已驳回与已撤销按更新时间倒序。
- 驳回须填写意见；通过后回写日考勤与月度汇总，并提示影响日期。
- 申请时间与已有假勤重叠时阻断提交；离职日期后的申请阻断。
- 空态展示「暂无假勤申请」。

## 考勤规则

### 页面结构

- **统计卡**：考勤组数量、启用班次数量、覆盖员工数、未匹配考勤组员工数。
- **页签**：考勤组、班次、节假日。
- **考勤组表格列**：考勤组名称、组织范围、绑定员工、班次、工作日、休息日、迟到容差、状态、生效日期、操作。
- **班次表格列**：班次名称、上班时间、下班时间、打卡次数、弹性时间、跨天、状态、操作。
- **行内操作**：编辑、启用 / 停用、查看绑定员工。
- **编辑抽屉**：考勤组名称、组织范围、绑定员工、班次、工作日、休息日、节假日、迟到容差、生效日期与备注；班次编辑使用独立抽屉。

### 交互

- 规则变更只影响生效日期之后的考勤计算；已确认与已锁定月份不重算。
- 停用考勤组前提示影响员工数量与生效日期；停用不影响历史记录。
- 未配置考勤组的员工在日考勤与规则页签展示警示。
- 空态展示「暂无考勤组」或「暂无班次」。

## 空态与权限

- 日考勤、月考勤、假勤审批、考勤规则分别有独立空态与失败重试。
- 菜单权限 `MENU:HR:ATTENDANCE`；日考勤、月考勤、假勤申请、审批、异常处理、规则编辑、月度确认与导出分别按按钮权限展示。
- 数据权限：HR 管理员与考勤管理员全量；HRBP 本中心；中心负责人与部门负责人按组织只读；员工本人只读本人考勤与假勤。
