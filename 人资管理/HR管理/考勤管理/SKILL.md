# 考勤管理

## 模块概述

人资管理 → HR管理下的考勤入口：以「考勤台账」为主线，分为「日考勤」「月考勤」「假勤审批」「考勤规则」四个页签。系统按考勤组与班次匹配员工每日出勤，接收外部打卡数据或手工补录，聚合迟到、早退、缺卡、旷工、请假、加班、出差等结果；假勤申请经审批后回写考勤记录；月度考勤按员工汇总并确认锁定。

本功能只承载考勤记录、异常处理、假勤审批、考勤规则与月度汇总，不承载薪酬核算、请假制度设计、排班优化、外部考勤设备管理与考勤数据采集平台本身。

## 端

- **web**：人资管理 → HR管理 → 考勤管理，仅桌面端管理后台，不提供 App 入口

## When to Use

- 查看指定日期或日期区间的员工出勤、打卡与异常记录
- 处理迟到、早退、缺卡、旷工等考勤异常，发起补卡或更正
- 审批员工请假、加班、出差与补卡申请
- 维护考勤组、班次、工作日、休息日与节假日规则
- 生成月度考勤汇总，确认或锁定月度结果
- 复核考勤与员工入离职状态、工作台待办与预警的联动

## 日考勤

<a id="日考勤"></a>

- 默认展示今天、当前用户数据权限内的员工考勤；支持日期、日期区间、组织、考勤组、员工与考勤状态筛选。
- 每日记录展示员工、组织、考勤组、班次、应打卡时间、实际打卡时间、出勤状态、异常类型、数据来源与更正状态。
- 出勤状态为正常、迟到、早退、缺卡、旷工、请假、加班、出差、外勤、休息；同一记录可有多个异常类型汇总展示。
- 异常记录可发起补卡或更正，须填写原因；审批通过后回写日考勤并保留原记录。
- 员工入职日期前与离职日期后不生成考勤记录；离职确认后停止考勤统计。

## 月考勤

<a id="月考勤"></a>

- 按月与组织汇总员工应出勤天数、实际出勤天数、迟到次数、早退次数、缺卡次数、旷工天数、请假天数、加班时长、出差天数与考勤状态。
- 月度汇总由日考勤、假勤审批与考勤规则自动计算，不手工修改明细。
- 月度状态为待确认、已确认、已锁定；HRBP 或考勤管理员确认后锁定，锁定后更正须 HRBP 审批并留痕。
- 支持导出月度汇总；月度确认结果进入工作台待办与预警。

## 假勤审批

<a id="假勤审批"></a>

- 假勤申请类型为请假、加班、出差、补卡；申请人填写起止时间、时长、原因与附件，提交后进入待审批。
- 审批链为直接上级 → HRBP；请假超过规定天数、跨中心或补卡跨月时增加中心负责人审批。
- 审批通过后回写日考勤与月度汇总；驳回须填写原因；申请人可在待审批阶段撤回。
- 已通过的请假、加班、出差在考勤记录中展示对应状态；补卡通过后更新缺卡记录。

## 考勤规则

<a id="考勤规则"></a>

- 考勤组按组织范围绑定员工，维护班次、工作日、休息日、节假日、迟到容差与月度确认截止日；一名员工同一时点只归属一个考勤组。
- 班次维护上下班时间、打卡次数、弹性时间与跨天标记；考勤组可引用一个班次。
- 规则变更只影响生效日期之后的考勤计算；已确认或已锁定的月度考勤不被重算。
- 考勤组与班次可启用、停用；停用不影响历史考勤记录。

## Tips

- 考勤记录来源为外部打卡导入、手工补录与假勤审批回写；本功能不自建打卡设备
- 员工入职日期前、离职日期后不生成考勤；离职确认后停止排班与考勤统计
- 假勤审批通过只更新考勤记录，不直接计算薪酬；薪酬核算不在本模块范围
- 月度确认后锁定，锁定后更正须 HRBP 审批并留痕
- 考勤组与班次规则变更只影响生效日期之后的记录
- 规则查找：考勤匹配与异常规则看 [文档/业务规则.md](文档/业务规则.md)，字段口径看 [文档/数据模型.md](文档/数据模型.md)，页面元素看 [文档/页面元素.md](文档/页面元素.md)
