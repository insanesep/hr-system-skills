# 招聘过程管理 · App 页面说明

> 业务规则与状态机见 [../../文档/业务规则.md](../../文档/业务规则.md)，字段口径见 [../../文档/数据模型.md](../../文档/数据模型.md)。页面通用硬约束以 busyming-skills-design 的 page-blueprint 为准；本模块原型为自包含静态 Mock（零外部依赖），布局引用 [../原型图/app/recruitment-app.html](../原型图/app/recruitment-app.html)。

App 菜单编码 `devhubAppRecruitProcess`，独占编码 `devhubAppRecruitProcessM`；按钮权限沿用 Web 端 `BTN:HR_RECRUIT_PROCESS:*`、`BTN:HR_RECRUIT_OFFER:*` 与 `BTN:HR_RECRUIT:SENSITIVE`。面试官仅可见本人场次与候选人姓名、应聘职位、简历摘要、前轮评价摘要，不可见薪资与 Offer。手机号、证件号码、薪资、年包与涨幅默认脱敏。

App 只承载移动高频闭环；台账填写与批量导入、新建/编辑职位、批量导入简历、发起 Offer、台账导出、职位关闭、候选人重新激活与完整简历预览在 Web 端处理，App 内入口点击后提示「请至 Web 端处理」。

## 招聘工作台

- **页面路径**：`#/workbench`；**导航方式**：Push（App 首页工作台「招聘过程管理」图标进入）；**页面类型**：workbench
- **页面元素**：
  - 欢迎语与当前日期
  - 待处理五卡 2 列网格：待处理简历、待处理内推简历、待处理猎头简历、待安排初试、待发 Offer（第 5 卡跨行）
  - 招聘日程卡：未来 7 天场次数量、最近一场时间与候选人、「仅看我安排的面试」开关
  - 快捷宫格：职位、应聘者、面试、Offer、招聘台账，各带数量角标
  - 最近访问职位 5 条：职位名称、编号、组织、招聘负责人、在招与已入职人数
- **导航关系**：指标卡 Push 应聘者列表（带入投递状态或来源渠道筛选）或 Offer 列表（状态=待发送）；日程卡与「7 天 ›」Push 招聘日程；宫格 Push 各列表；最近职位 Push 职位详情；无返回（模块首页）。
- **操作反馈清单**：

| 操作名 | 触发条件 | 二次确认 | Loading | 成功反馈+去向 | 失败反馈+重试 |
| --- | --- | --- | --- | --- | --- |
| 进入待处理 | 点击指标卡 | 否 | 目标页骨架屏 | Push 目标列表并带入筛选 | 目标页错误态 + 重试 |
| 查看日程 | 点击日程卡 | 否 | 目标页骨架屏 | Push 招聘日程 | 同左 |
| 快捷入口 | 点击宫格 | 否 | 目标页骨架屏 | Push 对应列表 | 同左 |
| 最近职位 | 点击职位行 | 否 | 目标页骨架屏 | Push 职位详情 | 同左 |
| 仅看我安排的面试 | 切换开关 | 否 | 无 | 日程摘要按当前用户为安排人过滤 | 轻提示重试 |

- **三态**：加载态为分区骨架屏；空态「当前没有待处理事项」；错误态「加载失败 + 重试」。

## 招聘日程

- **页面路径**：`#/schedule`；**导航方式**：Push（工作台日程卡、面试列表「日程」）；**页面类型**：list
- **页面元素**：
  - 周条：七天日期、有面试日期下方圆点、今天高亮；左右切换上周/下周
  - 「仅看我安排的面试」开关
  - 按时间升序的场次卡：时间、轮次、候选人、应聘职位、面试官、方式、邀约状态、场次状态、评价进度

- **导航关系**：来源工作台或面试列表；去向面试详情、面试评价；返回工作台或面试列表；只读页无脏数据，直接返回。

| 操作名 | 触发条件 | 二次确认 | Loading | 成功反馈+去向 | 失败反馈+重试 |

| 切换周 | 点击上周/下周 | 否 | 无 | 周条与场次按新周刷新 | 轻提示重试 |
| 选择日期 | 点击周条日期 | 否 | 当日列表骨架屏 | 展示当日场次 | 错误态 + 重试 |
| 仅看我安排的面试 | 切换开关 | 否 | 无 | 列表按安排人过滤 | 轻提示重试 |
| 快捷通过/淘汰 | 点击本人待评价场次按钮 | 否 | 无 | 打开评价页并预选结论 | — |
| 查看详情 | 点击详情 | 否 | 无 | Push 面试详情 | — |

- **三态**：加载态列表骨架屏；空态「当日暂无面试安排」；错误态「加载失败 + 重试」。

## 安排与改期面试

- **页面路径**：`#/interviews/new`（安排）、`#/interviews/new/{id}`（改期）；**导航方式**：Push（面试列表、面试详情、应聘者详情）；**页面类型**：form
- **页面元素**：候选人只读卡（姓名、职位、状态）；面试日期、开始时间、时长（30/45/60/90 分钟）、轮次（初试/复试/终试）、面试方式（视频/现场/电话）、地点或会议链接；面试官多选 1–5 人；冲突说明；提交按钮。
- **导航关系**：返回来源页；有未提交内容时返回需二次确认「放弃填写？」。
- **操作反馈清单**：

| 操作名 | 触发条件 | 二次确认 | Loading | 成功反馈+去向 | 失败反馈+重试 |
| --- | --- | --- | --- | --- | --- |
| 提交安排 | 点击提交 | 否 | 按钮 loading | Toast「面试已安排，邀约已发送」并返回来源页 | Toast 校验失败原因，停留本页 |
| 保存改期 | 点击保存 | 否 | 按钮 loading | Toast「改期已保存，邀约已重新发送」，邀约置待确认 | 同左 |
| 面试官冲突 | 保存时同一面试官时段重叠 | 否 | 无 | 阻断并提示冲突面试官与时段 | 修改后重试 |
| 返回 | 导航栏返回/手势返回 | 有未保存内容时确认 | 无 | 放弃返回 | — |

- **校验**：日期、时间、地点必填；至少一名面试官；冲突校验按未取消场次与时长重叠判断。
- **三态**：加载态表单骨架屏；无数据时提示「未找到面试场次」；保存失败 Toast + 重试。

<a id="offer-detail"></a>

## Offer 详情

- **页面路径**：`#/offer/{id}`；**导航方式**：Push（Offer 列表、台账）；**页面类型**：detail
- **页面元素**：候选人头部与状态；Offer 信息（编号、招聘季度、计划入职日期、招聘负责人、发送时间）；审批链（节点、审批人、状态、意见、时间）；Offer 内容（月度固定、绩效基数、目标奖金月数、签字费、年度总包、涨幅、薪标上限，均按权限脱敏；超限标签）；有效期与备注；底部操作条。
- **操作可见性**：审批中显示通过/驳回（发起人另有撤回）；待发送显示发送与关闭；已发送未接受显示关闭；已接受未入职关闭需 HRBP 二次确认并提示取消入职单；已入职与已关闭只读。
- **导航关系**：返回 Offer 列表或台账；发起 Offer 在 Web。
- **操作反馈清单**：

| 操作名 | 触发条件 | 二次确认 | Loading | 成功反馈+去向 | 失败反馈+重试 |
| --- | --- | --- | --- | --- | --- |
| 通过 | 审批中且为当前节点审批人 | 是 | 按钮 loading | Toast「审批已通过」，状态转待发送 | 失败 Toast + 重试 |
| 驳回 | 审批中且为当前节点审批人 | 原因与说明必填 | 按钮 loading | Toast「已驳回」，状态回待发起 | 校验失败停留 |
| 撤回 | 审批中且为发起人 | 是 | 按钮 loading | Toast「已撤回」，状态回待发起 | 失败 Toast |
| 发送 | 状态为待发送 | 否（选择渠道） | 按钮 loading | Toast「Offer 已发送，有效期至 YYYY-MM-DD」，状态已发送 | 未选渠道提示 |
| 关闭 | 待发送或已发送未接受 | 原因与说明必填；已接受未入职需 HRBP 二次确认 | 按钮 loading | Toast「Offer 已关闭」，状态已关闭 | 校验失败停留 |

- **三态**：加载态详情骨架屏；无数据提示；错误态 + 重试。

## 招聘台账

- **页面路径**：`#/ledger`；**导航方式**：Push（工作台宫格）；**页面类型**：list
- **页面元素**：只读说明（新增、编辑、批量导入与导出请至 Web 端）；筛选抽屉（招聘季度、招聘HR、状态、岗位类别、放弃原因）；候选人级台账卡：姓名、部门、职位与职级、岗位类别、招聘季度、招聘HR、一面/二面/终面结果、Offer 状态、待入职日期、是否已入职、放弃原因、实际入职职级与「职级差异」、年包与涨幅（`****`）、超薪标/超涨幅标记、谈薪备注；右上「导出」。
- **数据来源**：与 Web 招聘台账填写读取同一投递记录；Web 端新增或导入后，刷新 App 台账即可看到最新数据。
- **导航关系**：点击台账卡进入应聘者详情（存在档案时）；本页不修改流程状态；台账填写、新增、编辑、批量导入与导出均提示至 Web。
- **操作反馈清单**：

| 操作名 | 触发条件 | 二次确认 | Loading | 成功反馈+去向 | 失败反馈+重试 |
| --- | --- | --- | --- | --- | --- |
| 筛选 | 抽屉确定/重置 | 否 | 列表骨架屏 | 刷新台账并展示筛选标记 | 错误态 + 重试 |
| 查看明细 | 点击台账卡 | 否 | 目标页骨架屏 | Push 应聘者详情 | 同左 |
| 导出 | 点击右上「导出」 | 否 | 无 | Toast「请至 Web 端处理」 | — |

- **三态**：加载态列表骨架屏；空态「暂无台账数据」；错误态「加载失败 + 重试」。
