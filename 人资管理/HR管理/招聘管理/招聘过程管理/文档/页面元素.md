# 招聘过程管理 · 页面元素说明

> 字段口径见 [../../文档/数据模型.md](../../文档/数据模型.md)，状态与联动规则见 [../../文档/业务规则.md](../../文档/业务规则.md)。本文件为页面元素说明，覆盖全部页面；App 页面见 [app-ui.md](app-ui.md)，App 仅承载高频操作，台账填写与批量导入、新建/编辑职位、批量导入简历、发起 Offer、台账导出、职位关闭、候选人重新激活与完整简历预览在 Web 处理。工作台与招聘日程在同一原型内以 `#workbench` / `#schedule` 双视图互联，其余页面按本文描述实现。

<a id="workbench"></a>

## 招聘工作台

- **页面路径**：`/hr/recruit/workbench`（产品页面约定）
- **权限编码**：路由 `MENU:HR:RECRUIT_PROCESS`；按钮见 [../../文档/业务规则.md §15](../../文档/业务规则.md#15-权限编码与数据范围)
- **页面类型**：个人工作台（指标卡 + 日程 + 快捷入口）
- **区块职责**：
  - 页头：欢迎语与当前日期；右侧「新建职位」
  - 待处理区：标题「待处理」与组织、时间范围下拉（默认为当前用户全部负责组织、近半年）；五张指标卡：待处理简历、待处理内推简历、待处理猎头简历、待安排初试、待发 Offer，各带口径说明图标
  - 台账同步卡：展示台账记录、待入职、已入职与放弃 Offer 数量，数据来自台账填写写入的同一投递记录；下方「BOSS直聘」状态行展示授权状态、最近同步时间与待确认数，点击「去处理」打开同步抽屉；「去填写」进入台账填写页
  - 招聘日程卡：页签「招聘日程 / 跟进日程」、勾选「仅看我安排的面试」、「面试日历」
  - 右侧栏：最近访问职位、快捷入口
- **指标卡交互**：点击卡片跳转到应聘者或 Offer 列表，并带入对应状态与来源渠道筛选；数字随处理进度即时刷新
- **最近访问职位**：展示最近查看的 5 个职位，含职位编号与名称；点击进入职位详情；「更多在招职位」进入职位列表
- **快捷入口**：未归档简历、我关注的职位、我关注的应聘者、已锁定的应聘者，各展示当前数量；点击进入对应列表并带入筛选
- **新建职位**：打开职位新建弹窗，字段与校验见 [§职位](#positions)
- **空态**：无待处理或无日程时，对应区块展示「当前没有待处理事项」与「暂无面试安排」
- **组件引用**：参照 `busyming-skills-design` 的 Button、Tag、Checkbox、Popover、Table、Message 交互口径

## 招聘日程

- **页面路径**：`/hr/recruit/workbench#schedule`，独立入口为面试列表的「日程视图」
- **页面类型**：日程列表页（周条 + 按日分组列表）
- **区块职责**：
  - 周条：展示本周七天与日期，有面试的日期下方显示圆点；左右箭头切换周，当前日期高亮
  - 列表区：按时间升序展示所选日期的面试场次
  - 工具条：勾选「仅看我安排的面试」、「面试日历」
- **场次行内容**：时间、轮次与面试官（多人以「、」连接）、安排人、面试方式、候选人姓名与应聘职位、邀约状态（已接受显示「接」标签）、评价状态（「N 个评价」链接）、快捷「通过」「淘汰」按钮
- **快捷评价**：面试官对本人已结束场次可见；点击「通过」或「淘汰」打开评价弹窗，结论预选对应值，评语必填；提交后行内展示结论标签与「已评价」
- **面试日历**：切换到日历视图，按周或月展示场次，可拖动改期（仅本人安排的场次）；改期留痕并重新发送邀约
- **筛选**：点击日期切换当天；「仅看我安排的面试」勾选状态按用户保留
- **导航关系**：点击候选人姓名打开应聘者详情抽屉；点击「面试日历」切换日历视图；点击「安排面试」打开面试安排弹窗
- **布局引用**：参见原型 [原型图/web/recruitment-workbench.html#schedule](../原型图/web/recruitment-workbench.html#schedule)

## 招聘台账填写

- **页面路径**：`/hr/recruit/ledger/entry`（产品页面约定）
- **权限编码**：入口 `BTN:HR_RECRUIT_PROCESS:LEDGER_ENTRY`；新增 / 编辑 / 导入 `BTN:HR_RECRUIT_PROCESS:LEDGER_EDIT`；未授权时只读
- **页面类型**：录入列表页（筛选 + 可编辑台账 + 抽屉表单 + 批量导入）
- **入口**：工作台快捷入口「台账填写」、只读招聘台账页头「去填写」；仅 Web，App 台账只读
- **页头**：标题「招聘台账填写」与说明「按候选人录入招聘过程与结果，数据同步至招聘台账、招聘过程与数据看板」；右侧「新增台账」「BOSS直聘同步」（带待确认徽标）「批量导入」「导出」
- **筛选**：招聘季度（下拉）、招聘HR（下拉）、部门（下拉，按二级部门）、录入来源（过程创建 / 台账填写 / 批量导入 / 渠道同步）、Offer 状态（下拉）
- **表格列**：
  - 固定列：招聘季度、招聘HR、姓名、操作
  - 可配置列：需求 / 职位、部门 / 岗位 / 职级、岗位类别、一面、二面、终面、Offer、待入职日期、是否已入职、放弃原因、实际入职职级、当前 / 期望 / 定薪年包、涨幅、薪标 / 涨幅标记、谈薪备注、录入来源
  - 展示规则：过程创建的投递在姓名后展示「流程派生」标签，摘要字段只读；台账填写、批量导入或渠道同步创建的投递展示「台账补录」标签，摘要字段可编辑；录入来源列同时展示「预占中 / 已释放」；薪酬、年包与涨幅默认脱敏；职级差异、超薪标与超涨幅以标签展示
- **行内编辑**：点击行内「填写」展开当前行的快速编辑区，支持更新一面 / 二面 / 终面、Offer 状态、待入职日期、是否已入职、放弃原因、实际入职职级、当前 / 期望 / 定薪年包与谈薪备注；保存后即时刷新台账与只读招聘台账，写入操作记录；过程创建的投递仅允许编辑谈薪备注与进展备注
- **终止与删除**：台账填写行提供「终止」与「删除」；终止、放弃、淘汰或删除后释放该记录占用的 1 个需求空缺，操作前二次确认；已释放记录只保留「删除」；过程创建的投递不提供终止与删除
- **新增 / 编辑抽屉**：
  - 基本信息：招聘季度、招聘HR、姓名、手机号、邮箱；部门 / 岗位 / 职级采用「二级部门 → 三级部门 → 招聘需求 / 职位 → 职级」四级联动，仅展示招聘中且剩余名额大于零的招聘需求；职级在所选需求的职级范围内选择；选择需求后带出组织路径、岗位类别、岗位族、工作性质、需求编号、剩余名额与对应薪标；无可用需求时阻断保存
  - 渠道同步来源：由渠道同步确认入库的记录展示只读的「来源渠道：招聘网站 / BOSS直聘」与「外部投递标识」；其余字段与校验不变
  - 预占提示：保存时按所选需求预占 1 个空缺；剩余名额 = 需求人数 − 已到岗 − 待入职 − 台账在途预占；终止、放弃、淘汰或删除后释放；同一需求可录入多名候选人，但预占总数不得超过剩余名额
  - 面试结果：一面 / 二面 / 终面（未进行、待定、通过、淘汰）；存在详细面试场次时只读并提示「以面试评价汇总为准」
  - Offer 与薪酬：Offer 状态（未发起、审批中、待发送、已发送、已接受、已拒绝、已失效、已关闭、已入职）、待入职日期、放弃原因、当前年包、期望年包、内部定薪年包、谈薪备注；涨幅、薪标与超限标记实时派生只读
  - 入职结果：是否已入职（是 / 否 / 未到岗）、实际入职职级；标记已入职时提示「台账补录只更新摘要，不写入员工档案与编制」
  - 校验：招聘需求必选且剩余名额大于零；姓名必填；候选人按手机号或邮箱查重；Offer 已接受或已入职时待入职日期必填；Offer 已拒绝时放弃原因必填；Offer 已入职时实际入职职级必填；金额为正数；年包与涨幅字段按薪资权限展示；编辑历史台账无可用需求时保留原快照，不允许改选已满需求
  - 操作：底部「取消」「保存」；保存成功提示「台账已保存」；同名同职位同季度重复时提示并更新原记录
- **批量导入**：
  - 模板列与 Excel 台账一致：招聘季度、招聘HR、姓名、手机号、邮箱、二级部门、三级部门、职位、职级、一面、二面、终面、Offer 状态、待入职日期、是否已入职、放弃原因、实际入职职级、当前年包、期望年包、内部定薪年包、谈薪备注
  - 单次不超过 200 行；校验二级部门 / 三级部门 / 职位 / 职级可匹配招聘中且有空缺的招聘需求、候选人可识别、日期合法、枚举合法与重复行；校验通过的行创建或更新投递摘要并标记来源批量导入，失败行生成失败回执
  - 导入完成展示成功行数、失败行数与「下载失败回执」；点击「确认导入」后刷新台账并提示
- **数据流**：保存直接写入投递记录的台账摘要字段，同时创建或关联应聘者与职位；不新建独立台账表；只读招聘台账、招聘进度、招聘HR人效与数据看板读取同一投递记录；详细面试、Offer、入职单产生后，摘要字段自动回写并变为只读；渠道同步确认入库写入同一投递记录，待确认池数据不进入台账与看板
- **导航关系**：从工作台或只读台账进入；「BOSS直聘同步」打开同步抽屉；「去查看」切换至只读招聘台账；新增 / 编辑与导入为抽屉或弹层；返回保留筛选

<a id="boss-sync"></a>

## BOSS直聘同步

- **页面路径**：使用招聘台账填写页的宽版抽屉，无独立路由；入口为台账填写页头「BOSS直聘同步」与工作台台账同步卡「去处理」
- **权限编码**：`BTN:HR_RECRUIT_PROCESS:CHANNEL_SYNC`；授权、频率与职位映射另需 `BTN:HR_RECRUIT_PROCESS:CHANNEL_SYNC_CONFIG`；未授权时不展示入口
- **页面类型**：非菜单同步抽屉（连接状态条 + 四页签）
- **公共区域**：
  - 连接状态条：企业名称、授权状态（未授权 / 已授权 / 已过期 / 已停用）、授权到期时间、凭证指纹、最近同步时间；未授权或过期时展示「重新授权」
  - 页签：待确认（默认）、职位映射、同步记录、同步设置；页签标题展示未映射与待确认数量徽标
  - 页脚：关闭；操作完成后局部刷新当前页签与工作台待确认数
- **待确认页签**：
  - 筛选：匹配结果（新候选人 / 已有应聘者 / 已有投递 / 职位未映射）、关键词（姓名或手机号）
  - 列表列：勾选、候选人（姓名 + 脱敏手机号 + 邮箱）、BOSS 职位、建议内部职位（含需求编号）、最近沟通进展、简历、匹配结果、名额校验（可确认 / 名额不足 / 不可用）、操作
  - 行操作：确认入库（更新类记录显示「确认更新」）、更换职位、忽略；职位未映射时确认置灰并提示先绑定映射；名额不足时确认拦截
  - 更换职位：仅可选择同一 BOSS 职位已映射且有剩余名额的内部职位；改选后重新校验名额
  - 批量操作：批量确认逐行校验并给出成功与失败回执；批量忽略统一填写原因
  - 忽略：必填原因，记录状态为已忽略，不写入台账、不占名额
  - 空态：未授权、无待确认、筛选无结果三种文案与对应指引
- **职位映射页签**：
  - 分组：待映射、冲突、已映射、已失效，标题展示数量
  - 列表列：BOSS 职位（名称 / ID）、城市、BOSS 状态、内部职位、所属需求、匹配方式、最近校验时间、操作
  - 操作：绑定、重新绑定、解除、重新自动匹配；待映射记录展示自动匹配建议与「采纳建议」
  - 说明：未映射或冲突职位的候选人可入池但不可确认；内部职位暂停、关闭或 BOSS 职位关闭时标记冲突或已失效
- **同步记录页签**：
  - 顶部：「立即同步」与最近同步结果
  - 列表列：批次号、触发方式、开始与结束时间、拉取 / 新增 / 更新 / 跳过 / 失败数、批次状态、错误摘要、操作
  - 进行中批次置顶并展示进度；部分失败或失败批次可重试，重试生成新批次
- **同步设置页签**（仅招聘管理员可编辑）：
  - 授权卡片：企业名称、授权状态、到期时间、凭证指纹、重新授权
  - 表单：同步频率（15 / 30 / 60 分钟或每天）、拉取范围（近 7 / 30 / 90 天）、待确认保留期、待确认提醒、启用状态
  - 保存写操作记录；停用需二次确认；未授权或过期时同步不执行，池内数据保留
  - 页脚说明：字段映射与接口能力以 BOSS直聘 官方开通结果为准，凭证不提供明文查看
- **数据流**：待确认池不占用需求名额、不进入台账与看板；确认入库后创建或关联应聘者与投递，按台账规则预占 1 个空缺，写入台账摘要并刷新工作台、只读台账与看板；更新摘要仅改进展备注与简历附件
- **导航关系**：从台账填写或工作台打开；关闭抽屉返回原页面并保留筛选；不提供独立面包屑与菜单

## 招聘台账

- **页面路径**：`/hr/recruit/ledger`（非菜单页面）
- **权限编码**：`BTN:HR_RECRUIT_PROCESS:LEDGER`
- **页面类型**：查询列表页（筛选 + 候选人级台账 + 导出）
- **入口**：工作台快捷入口「招聘台账」、应聘者列表页签「招聘台账」、台账填写页「去查看」；页头提供「去填写」进入台账填写页
- **筛选项**：招聘季度（2026Q3 / Q4 / 2027Q1）、招聘HR（下拉）、部门（下拉，按二级部门）、岗位类别（多选）、状态（待入职 / 已入职 / 已放弃 / 已终止 / 面试中 / 已淘汰）、是否已入职（是 / 否）、放弃原因（多选）
- **表格列**：招聘季度、招聘HR、姓名、部门 / 岗位 / 职级、岗位类别、一面、二面、终面、Offer、待入职日期、是否已入职、放弃原因、实际入职职级、当前 / 期望 / 定薪年包、涨幅、薪标 / 涨幅标记、谈薪备注、录入来源
- **展示规则**：
  - 招聘季度按入职季度归属：候选人默认继承需求季度，Offer 接受后按计划入职季度更新，确认入职后按实际入职季度更新；Q3 跟进、Q4 入职计入 Q4
  - 一面、二面、终面分别取初试、复试、终试的轮次汇总结果，展示通过 / 淘汰 / 待定 / —
  - Offer 列合并展示未发起、审批中、待发送、已发送、已接受、已放弃、已入职；待入职日期取 Offer 计划入职日期
  - 放弃原因取结构化枚举；实际入职职级与 Offer 职级不一致时追加「职级差异」标签
  - 当前 / 期望 / 定薪年包与涨幅默认脱敏，需薪资权限；超薪标与超涨幅以警示标签展示
  - 录入来源展示过程创建、台账填写、批量导入或渠道同步；台账填写与渠道同步的记录追加「台账补录」标签；关联需求的台账记录同时展示「预占中 / 已释放」
  - 行操作：查看应聘者详情、查看 Offer 详情、去填写（本人台账且有编辑权限）；不在此页面修改流程状态
- **导出**：按当前筛选导出候选人级台账，导出记录审计；薪资字段按权限脱敏或明文导出
- **导航关系**：面包屑 首页 / 人资管理 / HR管理 / 招聘管理 / 招聘台账；返回工作台保留筛选

## 职位

- **页面路径**：`/hr/recruit/position/list`（产品页面约定）
- **权限编码**：按钮 `BTN:HR_RECRUIT_PROCESS:POSITION`
- **页面类型**：查询列表页
- **筛选**：职位名称或编号（输入框）、所属需求（下拉）、需求一级组织（下拉）、招聘负责人（下拉）、职位状态（多选：在招、暂停、已关闭）
- **表格列**：职位编号、职位名称、所属需求、组织、职级、招聘负责人、在招人数、已入职人数、职位状态、更新时间、操作
- **行操作**：详情、编辑、暂停 / 恢复在招、关闭；关闭前须处理在途投递，未处理时阻断并提示「存在 N 名在途候选人，请先转移或终止」
- **新建 / 编辑职位弹窗**：
  - 关联需求（必填，仅可选招聘中需求）、职位名称（默认继承标准职位）、组织（继承需求，可调整办公地点）、职级与职级类别（继承需求）、用工形式、办公地点、招聘负责人、在招人数（正整数，展示需求剩余名额并校验）、职位描述（默认继承需求 JD）
  - 保存成功提示「职位已创建」或「职位已更新」
- **职位详情**：概览、在招人数与已入职、候选人列表（按状态筛选）、操作记录；候选人列表只读，操作进入应聘者详情
- **导航关系**：面包屑 首页 / 人资管理 / HR管理 / 招聘管理 / 职位；详情返回保留筛选

<a id="candidates"></a>

## 应聘者

- **页面路径**：`/hr/recruit/candidate/list`（产品页面约定）
- **权限编码**：按钮 `BTN:HR_RECRUIT_PROCESS:CANDIDATE`、`BTN:HR_RECRUIT_PROCESS:RESUME_IMPORT`、`BTN:HR_RECRUIT_PROCESS:LOCK`
- **页面类型**：查询列表页（页签 + 列表 + 抽屉详情）
- **页签**：全部应聘者、未归档简历、我关注的应聘者、已锁定的应聘者，各展示数量；切页签保留筛选
- **筛选**：姓名或手机号（输入框）、应聘职位（下拉）、来源渠道（下拉）、投递状态（多选）、招聘负责人（下拉）、锁定状态（下拉）、最近操作时间（日期区间）
- **表格列**：姓名（含手机号脱敏展示）、应聘职位、来源渠道、投递状态、当前轮次、招聘负责人、锁定状态、关注状态、最近操作时间、操作
- **行操作**：
  - 未锁定：初筛通过、淘汰、终止、锁定、关注；无应聘者维护权限时只读
  - 已锁定且非本人：详情、关注；操作按钮置灰并提示「该应聘者已被 XX 锁定，锁定期至 YYYY-MM-DD」
  - 已归档待办：未归档简历行展示「归档到职位」，选择职位后生成投递记录
- **导入简历弹窗**：支持单份或批量选择文件，上传后展示解析进度与结果；解析成功且未指定职位的记录进入未归档简历；解析失败列出文件与原因，可手工补录；重复手机号或邮箱命中时提示并默认合并到已有应聘者
- **初筛与终止**：初筛通过后投递状态变为初筛通过并进入待安排初试；淘汰与终止须选择原因并填写说明，确认后进入人才库；终止确认提示「终止后将进入人才库，可重新激活」
- **锁定**：确认后锁定 7 天，提示到期时间；本人可提前释放；锁定与释放写入操作记录
- **应聘者详情抽屉**：
  - 概览：姓名、联系方式（脱敏）、学历与院校、工作年限、当前公司职位、当前年包 / 期望年包（按权限）、薪酬备注、来源渠道与内推人 / 顾问、锁定信息
  - 投递信息：招聘季度、招聘HR、协同招聘HR、岗位类别、岗位族、进展备注；进展备注用于记录「谈薪中」「待入职」「收流水」等当前跟进摘要
  - 页签：简历预览、投递记录、面试记录、Offer 记录、操作记录
  - 操作：初筛通过、淘汰、终止、发起 Offer、安排面试、关注、锁定 / 释放
- **导航关系**：面包屑 首页 / 人资管理 / HR管理 / 招聘管理 / 应聘者；抽屉关闭保留筛选与页码

<a id="interviews"></a>

## 面试

- **页面路径**：`/hr/recruit/interview/list`（产品页面约定）
- **权限编码**：按钮 `BTN:HR_RECRUIT_PROCESS:INTERVIEW`、`BTN:HR_RECRUIT_PROCESS:EVALUATE`
- **页面类型**：查询列表页（列表视图 / 日历视图切换）
- **页签**：我的面试、全部面试；「我的面试」为当前用户作为面试官或安排人的场次
- **筛选**：候选人姓名、职位、轮次（多选）、面试官（下拉）、场次状态（多选）、面试日期（日期区间）
- **列表列**：面试时间、轮次、候选人、应聘职位、面试官、安排人、面试方式、邀约状态、场次状态、评价进度、操作
- **行操作**：详情、改期、取消、评价（本场面试官且已到结束时间）；已评价展示「查看评价」
- **安排面试弹窗**：
  - 候选人（只读）、职位（只读）、轮次（初试 / 复试 / 终试）、面试日期、开始时间、时长（30 / 45 / 60 / 90 分钟）、面试方式（视频 / 现场 / 电话）、地点或会议链接、面试官（1 至 5 人，下拉搜索）
  - 冲突校验：面试官在同一时段已有未取消场次时，提示冲突面试官与时段并阻断保存
  - 保存后自动发送邀约，提示「面试已安排，邀约已发送」，场次状态为待面试、邀约状态为待确认
- **改期与取消**：改期更新时间并留痕，重新发送邀约并置为待确认；取消须填写原因，候选人侧收到取消通知
- **评价弹窗**：结论（通过 / 淘汰 / 待定）、评语（必填，不超过 500 字）、优势、风险；展示面试结束时间与 24 小时提交时限；提交后写入评价记录并刷新评价进度
- **评价汇总**：轮次为待定时由招聘负责人裁决，选择通过或淘汰并填写原因；多人场次展示每位面试官结论与评语
- **导航关系**：面包屑 首页 / 人资管理 / HR管理 / 招聘管理 / 面试；日历视图与列表视图共享筛选

## Offer

- **页面路径**：`/hr/recruit/offer/list`（产品页面约定）
- **权限编码**：按钮 `BTN:HR_RECRUIT_OFFER:SUBMIT`、`BTN:HR_RECRUIT_OFFER:APPROVE`、`BTN:HR_RECRUIT_OFFER:SEND`、`BTN:HR_RECRUIT_OFFER:SALARY`、`BTN:HR_RECRUIT:SENSITIVE`
- **页面类型**：查询列表页（列表 + 审批抽屉）
- **页签**：待我审批、我发起的、全部 Offer；各展示数量
- **筛选**：候选人姓名、职位、需求一级组织、Offer 状态（多选）、招聘负责人、计划入职日期（日期区间）
- **表格列**：Offer 编号、候选人、应聘职位、组织、职级、招聘季度、岗位类别、计划入职日期、Offer 状态、当前审批节点、招聘负责人、发送时间、更新时间、操作
- **薪资列**：默认不展示；具备薪资权限时可作为可配置列展示，包括当前 / 期望 / 定薪年包、涨幅、超薪标、超涨幅与谈薪备注，且按脱敏规则显示
- **行操作**：详情、发送（待发送）、撤回（审批中且为发起人）、关闭（待发送 / 已发送未接受）、确认关闭（已接受未入职，需 HRBP）、去入职（已入职，跳转入职管理入职单）
- **发起 Offer 弹窗**：
  - 候选人信息（姓名、手机号脱敏、职位、组织、职级）只读
  - 表单：计划入职日期（不早于发送日）、月度固定薪资、月度绩效基数、年度目标奖金月数、签字费、内部定薪年包（选填，默认取年度总包）、谈薪备注、试用期月数、试用期薪资比例、Offer 有效期（3 至 15 天，默认 7）、招聘负责人、备注
  - 薪酬提示：实时展示年度总包、涨幅、薪标上限、超薪标与超涨幅标记；超限只提示不阻断，审批页同步展示
  - 名额校验：需求剩余名额不足时阻断并提示「需求剩余名额不足，请先确认到岗或调增需求人数」
  - 提交后进入审批，提示「Offer 已提交审批」，状态为审批中
- **审批抽屉**：展示审批链节点与状态、各节点审批人与意见、Offer 内容；审批人可「通过」「驳回」，驳回须填写原因；发起人审批中可「撤回」
- **发送 Offer**：确认发送内容与送达渠道（短信 / 邮件 / 站内信），发送后状态为已发送并提示「Offer 已发送，有效期至 YYYY-MM-DD」
- **接受与拒绝**：候选人接受后系统生成入职单，列表状态为已接受并展示入职单号；拒绝时须选择放弃原因（薪酬待遇不满足、选择其他平台、地理位置、转正周期过长、家里有事、其他）并可填写放弃说明，状态为已拒绝并释放名额
- **关闭 Offer**：填写关闭原因；已接受未入职须 HRBP 二次确认，提示将取消对应入职单；已入职不可关闭；招聘季度在 Offer 接受后按计划入职季度更新，确认入职后按实际入职季度更新
- **职级差异**：确认入职后展示实际入职职级；与 Offer 职级不一致时标记「职级差异」，不改变 Offer 审批结果
- **导航关系**：面包屑 首页 / 人资管理 / HR管理 / 招聘管理 / Offer；审批抽屉关闭保留页签与筛选
