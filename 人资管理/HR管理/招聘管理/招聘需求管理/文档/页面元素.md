# 招聘需求管理 · 页面元素说明

> 字段口径见 [../../文档/数据模型.md](../../文档/数据模型.md)，联动与状态规则见 [../../文档/业务规则.md](../../文档/业务规则.md)。本模块仅 Web 端，需求台账与需求详情在同一原型内以 `#list` / `#detail/{需求编号}` 双视图互联。

<a id="demand-list"></a>

## 招聘需求台账

- **页面路径**：`/hr/recruit/demand/list`（产品页面约定）
- **权限编码**：路由 `MENU:HR:RECRUIT_DEMAND`；按钮见 [../../文档/业务规则.md §15](../../文档/业务规则.md#15-权限编码与数据范围)
- **页面类型**：查询列表页（统计卡 + 页签 + 筛选台账 + 行内维护 + 弹层创建与批量操作）
- **区块职责**：
  - 页头：标题「招聘需求」与左侧图标；右侧操作区「新建需求」「关闭需求」「批量导入」「批量授权」
  - 统计卡：我的招聘需求、全部招聘需求、已完成、进行中、已关闭的招聘需求，各卡展示数量；进行中卡附注「待审批 + 招聘中」
  - 页签：正式需求 / 外包需求，各展示记录数；外包需求为用工形式为劳务外包且外包需求标记为是的需求
  - 筛选区：基础筛选一行 +「高级筛选」展开入口 +「清空已选」
  - 表格区：表头复选框与列、行数据、行操作；表头右侧齿轮为列设置；岗位分类字段支持行内编辑
  - 分页区：总数与页码切换
- **统计卡口径**：数值随筛选条件不变，按当前用户数据权限统计；点击卡片将对应状态写入高级筛选并立即查询，「我的招聘需求」与「全部招聘需求」卡片清空状态条件并切换统计范围
- **基础筛选**：需求名称（输入框，防抖即时查询）、招聘季度（下拉：2026Q2 / Q3 / Q4 / 2027Q1）、招聘原因（下拉）、岗位类别（下拉：关键岗位 / S1类岗位 / S2类岗位 / A类岗位）、需求一级组织（下拉）、需求二级组织（下拉）、业务终面人（下拉）；条件变更即时查询
- **高级筛选**：点击「高级筛选」向下展开，包含需求状态（多选）、招聘负责人（下拉）、需求对接人（下拉）、岗位族（下拉）、预警状态（多选：需升级 / 需关注 / 正常）、期望到岗日期（日期区间）、是否超期（是 / 否）、需求警示（多选：编制变更待处理、超编需求）；再次点击收起，已生效条件在展开按钮旁以数量角标提示
- **清空已选**：清空基础与高级全部条件，恢复默认排序并回到第一页
- **默认排序**：按创建时间倒序；同创建时间按需求编号倒序
- **表格列**（默认全部显示，列设置可隐藏）：
  - 固定列：复选框、需求名称、操作
  - 可配置列：招聘季度、需求二级组织、需求一级组织、招聘原因、岗位类别、岗位族、工作性质、需求人数、已到岗人数、待入职、在途预占、可用空缺、已发 Offer 数、已接受 Offer 数、到岗率、缺口、需求状态、期望到岗日期、招聘天数、≥150天、预警状态、需求对接人、协同招聘HR、在途进展、招聘负责人
  - 展示规则：在途预占与可用空缺来自招聘台账填写，按需求编号同步；可用空缺 = 需求人数 − 已到岗 − 待入职 − 在途预占；需求名称以主色链接展示，超编需求与编制变更待处理在名称后追加警示标签；岗位类别按 关键 > S1 > S2 > A 展示标签；到岗率按「已到岗 ÷ 需求人数」计算并展示整数百分比，需求人数为零时展示「—」；缺口按 max(需求人数 − 已到岗 − 待入职, 0) 计算；招聘天数未完成按今天减创建时间，已完成按完成时间减创建时间；≥150天仅对未完成需求展示警示；预警状态按需升级 / 需关注 / 正常展示；期望到岗日期早于今天且需求未完成时以警示色展示；在途进展展示最近一条进展备注与当前阶段，超出以省略号收起；招聘负责人展示头像与姓名
- **行内维护**：招聘季度、岗位类别、岗位族、工作性质、需求对接人与协同招聘HR支持在台账行内编辑；保存后更新对应列并写入操作记录；未补齐时需求名称后展示「岗位分类待补充」标签
- **批量栏**：勾选记录后，在表格上方展示「已选 N 条」与「关闭需求」「批量授权」「取消选择」；未勾选时顶部对应按钮不可用；已完成与已关闭需求可被授权，不可被关闭
- **行操作**：
  - 草稿、待审批、招聘中：详情、编辑、关闭；编辑按状态控制可改字段
  - 已完成、已关闭：详情
  - 无编辑权限时仅展示详情；无关闭权限时不展示关闭入口
- **列设置**：齿轮打开列设置浮层，逐列勾选显示或隐藏并支持恢复默认；需求名称与操作不可隐藏，设置按当前用户保留
- **空态与失败**：无数据展示「这里什么都没有…」空态；加载失败展示失败提示与「重试」，重试按原条件查询
- **组件引用**：原生实现以页面内联样式与脚本为准，参照 `busyming-skills-design` 的 Button、BusyInput、PageableSelect、DatePicker、Tag、Checkbox、Popover、Table、Pagination、Message 交互口径
- **布局引用**：参见原型 [原型图/web/recruitment-demand.html](../原型图/web/recruitment-demand.html)

### 新建需求弹窗

- **打开方式**：页头「新建需求」。
- **编制明细行选择**：按「部门 → 组 → 编制明细」逐级筛选后选择，仅列出编制计划为新增或保留、职位编制未结束且可用缺额大于零的编制行。部门下拉为二级部门（默认全部）；组下拉为三级组（默认全部），部门为全部时按部门分组展示全部组，选定部门后仅展示该部门的组；改动部门时原组不属于新部门则重置为全部。编制明细为普通下拉，仅列出同时满足部门与组筛选的编制行，每个选项展示「组织路径 / 标准职位 / 职级」，选中后在下方只读展示组织层级、标准职位、职级、职级类别、用工形式、办公地点、编制数量、在编人数、招聘占用与可用缺额；改动部门或组后清空已选编制行并恢复只读区占位提示。
- **表单字段**：需求名称（默认按「一级组织-职位-期望到岗月份」生成，可修改，不超过 60 字）、招聘原因（必填，选「其他」时出现说明输入）、需求人数（必填，正整数）、期望到岗日期（必填，不早于今天）、业务终面人（必填，下拉搜索）、招聘负责人（必填，下拉搜索）、优先级（高 / 中 / 低）、职位描述与任职要求（选填，不超过 2000 字）、备注（选填）。
- **岗位分类字段**：弹窗不新增招聘季度、岗位类别、岗位族、工作性质、需求对接人与协同招聘HR字段；招聘季度默认当前季度，其余字段按职位映射带出默认值，通过台账行内编辑或批量导入调整；无法映射时标记「岗位分类待补充」，提交审批前须确认。
- **校验与提示**：需求人数超过可用缺额时，输入框下方提示「超出可用缺额 N 人」并禁用「提交审批」；勾选「申请超编」后允许提交，提示「超编需求需中心负责人审批」；未选择编制明细行时提示「请先选择编制明细行」。
- **操作**：底部「取消」「保存草稿」「提交审批」；保存草稿成功提示「已保存草稿」，提交成功提示「已提交审批」并关闭弹窗，列表新增记录且状态为待审批。
- **关闭行为**：存在未保存内容时二次确认「放弃本次创建？」。

### 编辑需求弹窗

- **打开方式**：行操作「编辑」（草稿、待审批、招聘中）。
- **可改字段**：草稿与待审批可改全部字段；招聘中仅可改期望到岗日期、优先级、业务终面人、招聘负责人、职位描述与备注，以及调减或调增需求人数。
- **岗位分类字段**：招聘季度、岗位类别、岗位族、工作性质、需求对接人与协同招聘HR不在编辑弹窗中维护，统一在台账行内编辑或批量导入中调整；调整写入操作记录。
- **人数调整**：调减时新人数不得低于已到岗人数与已接受 Offer 人数之和，差额即时释放；调增时校验可用缺额，提交后进入变更审批，审批期间按原人数招聘。
- **反馈**：保存成功提示「已更新需求」；调增提交后提示「变更已提交审批，原人数继续招聘」。

### 关闭需求弹窗

- **打开方式**：页头「关闭需求」（批量，作用于勾选记录）或行操作「关闭」（单条）。
- **前置校验**：勾选记录中存在「审批中」「待发送」或「已发送未接受」的 Offer 时阻断关闭，逐条列出需求、Offer 编号与状态，并提供「去招聘过程管理处理」链接；存在已接受未入职的 Offer 时提示须由 HRBP 确认取消入职单。
- **表单字段**：关闭原因（必填：编制取消、转内部调配、需求合并、业务调整、其他）、关闭说明（选填，不超过 200 字）；展示「将终止 N 名在途候选人，取消 N 场待面试」与取消选择。
- **反馈**：提交后按钮 loading；成功提示「已关闭 N 条需求」，列表状态即时更新；失败保留弹窗内容并提示原因。
- **关闭行为**：有未保存内容时二次确认「放弃本次关闭？」。

### 批量导入需求

- **打开方式**：页头「批量导入」。
- **弹窗内容**：模板下载入口、文件选择区、导入说明（可匹配编制明细行、单次不超过 200 行、校验通过生成草稿）；模板列包含需求名称、编制明细行、招聘季度、招聘原因、岗位类别、岗位族、工作性质、需求对接人、协同招聘HR、需求人数、期望到岗日期、业务终面人、招聘负责人、优先级、职位描述与备注。
- **流程**：选择文件后展示解析中；完成校验后展示成功行数与失败行数，失败行列出「行号 / 失败原因 / 原行内容」，可下载失败回执；点击「导入 N 条」生成草稿并提示「已导入 N 条需求草稿，请提交审批」。
- **关闭行为**：已解析未导入时关闭需二次确认。

### 批量授权

- **打开方式**：页头「批量授权」（作用于勾选记录）。
- **弹窗内容**：提示「将为 N 条需求增加只读授权」；人员选择支持按姓名或组织搜索、多选；已授权人员置灰并标注授权时间。
- **反馈**：提交成功提示「已授权 N 人」；被授权人下次登录后可见对应需求，授权记录写入详情。
- **撤销授权**：在需求详情的授权名单中逐条撤销，撤销后立即失效。

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 招聘管理 / 招聘需求管理」
- 去向页：需求名称或「详情」进入需求详情；新建、编辑、关闭、导入与授权为弹层，不跳转；编制关联可跳转编制管理对应编制明细行（只读）
- 返回行为：详情返回列表时保留筛选条件、列设置与页码
- 面包屑：首页 / 人资管理 / HR管理 / 招聘管理 / 招聘需求管理

## 招聘需求详情

- **页面路径**：`/hr/recruit/demand/detail/{需求编号}`（非菜单页面）
- **权限编码**：与台账共用路由权限；按钮按 [../../文档/业务规则.md §15](../../文档/业务规则.md#15-权限编码与数据范围) 组合展示
- **页面类型**：只读详情页（概览卡 + 分块信息 + 操作区）
- **区块职责**：
  - 页头：返回列表、标题「招聘需求详情」、需求状态与警示标签
  - 概览卡：需求名称、需求编号、组织路径、标准职位、职级、职级类别、用工形式、办公地点、招聘原因、需求人数、期望到岗日期、优先级、业务终面人、招聘负责人、创建时间、审批通过时间
  - 岗位分类：招聘季度、岗位类别、岗位族、工作性质、需求对接人、协同招聘HR、部门负责人；岗位分类待补充时展示提示
  - 进度卡：已到岗 / 需求人数、待入职、在途预占、可用空缺、已发 Offer、已接受 Offer、缺口、预计到岗率、在途候选人
  - 时效与预警：招聘天数、≥150天标记、预警状态与原因；需升级 / 需关注时展示触发条件
  - 在途进展：最近 3 条在途候选人的姓名、当前阶段、进展备注与更新时间；只读
- **编制关联**：编制明细行链接、编制数量、在编人数、其他在途需求占用、本需求占用、可用缺额、编制计划与职位编制起止；可用缺额小于本需求剩余人数时以警示色提示「编制变更待处理」
- **招聘进展**：
  - 职位表：职位编号、职位名称、在招人数、已入职、职位状态；只读，链接指向招聘过程管理的职位详情
  - 候选人漏斗：简历收取、初筛通过、面试中、Offer 审批、已接受、已入职的数量与相对上一环节的转化率；只读
- **授权名单**：被授权人、所属部门、授权时间、操作人；有授权权限时展示「撤销」
- **操作记录**：按时间倒序展示操作类型、操作人、时间与说明；展示需求创建、提交审批、审批结果、变更前后内容、关闭与到岗核销
- **操作区**：按状态展示编辑与关闭；已完成与已关闭仅展示返回
- **导航关系**：返回列表保留筛选与页码；编制明细、职位与候选人链接在新页签打开，不丢失当前详情
