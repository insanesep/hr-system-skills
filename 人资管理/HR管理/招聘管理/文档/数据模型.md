# 招聘管理 · 数据模型

> 本文件为招聘管理分组的实体与字段口径。一条招聘需求对应多条授权与多个职位；一个职位对应多条投递；一条投递对应多场面试与评价；一份 Offer 对应一份入职单。职级序列与职级类别取值见[岗位管理 · 职级矩阵](../../../组织管理/岗位管理/文档/数据模型.md#职级矩阵)。规则见 [业务规则.md](业务规则.md)。

## 1. 招聘需求

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 需求编号 | 招聘需求的唯一标识 | 文本 | 是 | 全局唯一，按年月生成，列表与详情展示 |
| 需求名称 | 需求的展示名称 | 文本 | 是 | 默认按「一级组织-职位-期望到岗月份」生成，可修改，不超过 60 字 |
| 招聘季度 | 需求归属季度 | 文本 | 是 | 如 2026Q4；默认按期望到岗日期所在季度，可调整；需求指标按本字段归属 |
| 编制明细标识 | 关联的编制明细行 | 文本 | 是 | 引用编制管理；创建后保留快照，不随编制自动变更 |
| 一级至五级组织 | 需求所属组织快照 | 文本 | 是 | 取自编制明细行；一级组织用于筛选与统计 |
| 标准职位 | 需求招聘的标准职位 | 文本 | 是 | 取自编制明细行 |
| 职级序列 | 职级所属序列 | 枚举 | 是 | 管理序列（M）、专业序列（P）、业务序列（S）、操作序列（O）；取自编制明细行 |
| 职级 | 需求职级或职级范围 | 文本 | 是 | 如 P7、P7-8，取自编制明细行；取值见[岗位管理 · 职级矩阵](../../../组织管理/岗位管理/文档/数据模型.md#职级矩阵) |
| 职级类别 | 职级所属类别 | 枚举 | 是 | 战略决策层、总监级、经理级、主管级、员工级；职级范围跨类别时按取高归属并提示 |
| 岗位类别 | 岗位招聘紧急度分类 | 枚举 | 是 | 关键岗位、S1类岗位、S2类岗位、A类岗位；紧急度 关键 > S1 > S2 > A |
| 岗位族 | 岗位所属族 | 枚举 | 是 | 后端研发、前端、测试、产品经理、产品运营、运维、算法、数据研发、数据分析、UI、UX、PMO、数据安全、实习生、管培生、其他 |
| 工作性质 | 内勤或外勤（内外勤） | 枚举 | 是 | 内勤、外勤；默认内勤 |
| 用工形式 | 需求对应的用工形式 | 枚举 | 是 | 全职-正式、实习、兼职、劳务 |
| 办公地点 | 需求对应的办公地点 | 文本 | 是 | 取自编制明细行 |
| 招聘原因 | 发起招聘的原因 | 枚举 | 是 | 新增编制、离职替补、转岗替补、内部调配未到位、其他；其他须填写说明 |
| 需求人数 | 计划招聘人数 | 数值 | 是 | 正整数；不超过编制明细行可用缺额，超编须超编审批 |
| 已到岗人数 | 已确认入职人数 | 数值 | 是 | 由入职确认核销累加，只读 |
| 已发 Offer 数 | 已成功发送的 Offer 数 | 数值 | 是 | 含已接受、已拒绝、已失效与已入职，不含待发送与已关闭 |
| 已接受 Offer 数 | 候选人已接受的 Offer 数 | 数值 | 是 | 含已接受与已入职，只读 |
| 在途人数 | 流程中候选人数 | 数值 | 是 | 从属于本需求且未终止、未入职的投递数，只读 |
| 需求状态 | 需求当前阶段 | 枚举 | 是 | 草稿、待审批、招聘中、已完成、已关闭 |
| 需求警示 | 需求异常标记 | 枚举 | 否 | 无、编制变更待处理、超编需求 |
| 期望到岗日期 | 业务期望的到岗日期 | 日期 | 是 | 不得早于创建日；早于今天且未完成视为超期 |
| 优先级 | 需求紧急程度 | 枚举 | 是 | 高、中、低 |
| 业务终面人 | 需求的业务审批人与终面人 | 文本 | 是 | 须为该组织业务负责人或授权面试官 |
| 需求对接人 | 业务需求对接人 | 文本 | 是 | 与业务终面人可不同；列表筛选字段 |
| 部门负责人 | 需求所属部门负责人 | 文本 | 否 | 取自部门管理负责人，只读快照 |
| 招聘负责人 | 负责推进本需求的人员 | 文本 | 是 | 招聘角色；列表筛选字段；人效承接需求按本字段归属 |
| 协同招聘HR | 协同推进本需求的招聘人员 | 文本 | 否 | 多人以「、」分隔；人效只归属主招聘负责人 |
| 外包需求标记 | 是否外包需求 | 布尔 | 是 | 用工形式为劳务外包时自动置是；列表页签与筛选依据 |
| 职位描述与任职要求 | 需求对应的 JD 与任职条件 | 文本 | 否 | 不超过 2000 字，创建职位时继承 |
| 备注 | 补充说明 | 文本 | 否 | 不超过 500 字 |
| 关闭原因 | 需求关闭的原因 | 枚举 | 否 | 编制取消、转内部调配、需求合并、业务调整、其他；关闭时必填 |
| 关闭说明 | 关闭原因的补充说明 | 文本 | 否 | 关闭时选填，不超过 200 字 |
| 提交人 | 提交需求审批的人员 | 文本 | 是 | 创建人默认为提交人 |
| 提交时间 | 提交审批的时间 | 日期时间 | 否 | 草稿为空 |
| 审批通过时间 | 审批通过进入招聘的时间 | 日期时间 | 否 | 招聘周期起算点 |
| 完成时间 | 需求完成的时间 | 日期时间 | 否 | 自动完成或提前完成时记录 |
| 关闭时间 | 需求关闭的时间 | 日期时间 | 否 | — |
| 招聘天数 | 需求提报至今天的天数 | 数值 | 否 | 派生；未完成按今天、完成按完成时间计算；用于时效与 ≥150 天判断 |
| 预警状态 | 需求时效预警 | 枚举 | 否 | 派生：需升级、需关注、正常；阈值见业务规则 |
| 在途进展 | 在途候选人最新进展摘要 | 文本 | 否 | 派生自投递记录进展备注与当前阶段；详情展示最近 3 条 |
| 创建时间 | 需求创建时间 | 日期时间 | 是 | 需求指标归属时间；同时作为需求提报日期 |

### 5.1 台账摘要字段

> 台账填写是招聘人员的候选人级录入界面。台账摘要字段挂在投递记录上，不新建独立台账表：过程创建的投递由面试评价、Offer 与入职单派生；台账填写、批量导入或渠道同步确认入库创建的投递标记为台账补录，摘要字段可手工维护。台账填写必须关联招聘中且剩余名额大于零的招聘需求；组织、岗位、职级、岗位类别、岗位族、工作性质、招聘HR与需求编号取自所选需求快照。详细流程数据出现后，以详细流程数据为准并回写摘要。

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 台账录入来源 | 投递记录的录入方式 | 枚举 | 是 | 过程创建、台账填写、批量导入、渠道同步；默认过程创建 |
| 台账补录标记 | 是否由台账补录创建 | 布尔 | 是 | 台账填写、批量导入或渠道同步创建时为是；后续完成详细流程后保留标记 |
| 台账预占状态 | 是否占用招聘需求空缺 | 枚举 | 是 | 预占中、已释放；创建为预占中，终止、放弃、淘汰或删除为已释放，Offer 已接受或已入职仍为预占中 |
| 一面结果 | 初试轮次汇总结果 | 枚举 | 否 | 未进行、待定、通过、淘汰；过程创建时由面试评价汇总，台账补录时可手工维护 |
| 二面结果 | 复试轮次汇总结果 | 枚举 | 否 | 未进行、待定、通过、淘汰；过程创建时由面试评价汇总，台账补录时可手工维护 |
| 终面结果 | 终试轮次汇总结果 | 枚举 | 否 | 未进行、待定、通过、淘汰；过程创建时由面试评价汇总，台账补录时可手工维护 |
| 面试结果来源 | 轮次结果的来源 | 枚举 | 是 | 过程评价、台账填写；存在详细面试场次时为过程评价，摘要只读 |
| 台账 Offer 状态 | 候选人 Offer 摘要状态 | 枚举 | 是 | 未发起、审批中、待发送、已发送、已接受、已拒绝、已失效、已关闭、已入职；过程创建时由 Offer 派生，台账补录时可手工维护 |
