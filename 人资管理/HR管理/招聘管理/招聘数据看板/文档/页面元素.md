## 招聘数据看板

- **页面路径**：`/hr/recruit/dashboard`（产品页面约定）
- **权限编码**：路由 `MENU:HR:RECRUIT_DASHBOARD`；按钮见 [../../文档/业务规则.md §15](../../文档/业务规则.md#15-权限编码与数据范围)
- **页面类型**：分析看板（筛选 + 指标卡 + 七组分析 + 导出）
- **区块职责**：
  - 页头：标题「招聘数据看板」与左侧图标；右侧「渠道配置」「薪酬带宽」「人效配置」「导出」
  - 筛选区：时间范围、招聘季度、组织与岗位分类维度、招聘原因、渠道、刷新
  - 指标卡区：招聘需求数、在招需求、已完成需求、到岗人数、待入职、Offer 流失率、平均招聘周期、需求完成率、到岗率、超期需求
  - 分析区：招聘进度与时效、需求与编制、招聘漏斗、渠道效果、招聘HR人效、Offer 流失、薪酬涨幅七组
  - 台账同步：指标卡下方展示来自招聘台账填写的台账记录、待入职、已入职、放弃 Offer 数量与最近台账行，读取同一投递记录
  - 看板洞察：底部按招聘季度展示管理结论与下一阶段动作，具备编辑权限时可修改
- **筛选**：
  - 时间范围：本月、本季度、近半年、自定义；默认近半年，自定义不超过 24 个月
  - 招聘季度（下拉：2026Q2 / Q3 / Q4 / 2027Q1）：需求指标按需求招聘季度归属，候选人指标按投递记录招聘季度归属
  - 分组维度：一级组织（下拉）、二级组织（下拉，随一级组织联动）、职级类别（多选：战略决策层 / 总监级 / 经理级 / 主管级 / 员工级）、岗位类别（多选：关键 / S1 / S2 / A）、岗位族（多选）
  - 招聘原因（多选）、招聘小组（多选）、招聘HR（下拉）、渠道（多选，默认全部；影响渠道效果与漏斗来源筛选）
  - 「重置」恢复默认时间范围与全部维度；条件变更即时查询
- **指标卡**：
  - 招聘需求数：所选范围内创建的招聘需求数，附「超编需求 N 条」
  - 在招需求：当前为招聘中的需求数
  - 已完成需求：当前为已完成的需求数，附完成率
  - 到岗人数：所选范围内实际入职人数，附到岗率
  - 平均招聘周期：需求审批通过至完成的平均自然日，附「较上一周期 ±N 天」
  - 待入职：Offer 已接受、计划入职日期不早于今天、未入职且未爽约的人数；接入招聘台账，与台账填写同步
  - Offer 流失率：放弃 Offer ÷ (放弃 Offer + 已入职 + 待入职)，悬停展示口径；接入招聘台账
  - 到岗人数、待入职与 Offer 流失率优先使用招聘台账数据，台账无数据时使用过程数据
  - 需求完成率、到岗率、超期需求分别独立成卡，悬停展示口径说明
  - 数据为按当前筛选实时计算；无数据时展示「—」
- **招聘进度与时效**（新增，置于指标卡下方）：
  - 维度切换：三级组织 / 岗位名称（岗位族）/ 职级取高（职级类别）/ 岗位类别
  - 表格列：维度值、需求数、台账候选人、已入职、待入职、缺口、完成率、预计到岗率、平均招聘时长、最长招聘时长、≥150天数量、一面/二面/终面通过、接受 Offer、放弃 Offer、预警状态
  - 台账候选人：按当前招聘季度与维度归集招聘台账中的候选人数量，用于核对台账填写与需求进度
  - 计算口径：缺口 = max(需求数 − 已入职 − 待入职, 0)；完成率 = 已入职 ÷ 需求数；预计到岗率 = (已入职 + 待入职) ÷ 需求数；招聘天数未完成按今天减需求提报日期，已完成按完成时间减提报日期
  - 预警状态：需升级 / 需关注 / 正常，支持按状态筛选与下钻到需求列表
  - 表格支持排序与导出当前维度
- **需求与编制**：
  - 表格维度：按所选组织层级与职级类别分组；列为编制数、在编人数、招聘占用、可用缺额、预计到岗、达成率、预计达成率
  - 可用缺额为负时以警示色展示并标注「超编」；预计到岗为已接受未入职人数
  - 表格支持按达成率排序与导出当前分组
  - 需求状态分布：以横向条形展示草稿、待审批、招聘中、已完成、已关闭的需求数与占比
- **招聘漏斗与时效**：
  - 漏斗：简历收取、初筛通过、初试通过、复试通过、Offer 审批通过、Offer 已接受、已入职七个环节，展示人数、相对上一环节转化率与相对简历的总转化率；条形宽度按人数比例绘制
  - 环节停留：各环节平均停留自然日，以横向条形对比；超过阈值的环节以警示色标注
  - 周期卡：平均需求周期、平均到岗周期、超期需求数
- **渠道效果**：
  - 表格列：渠道、简历数、初筛通过率、Offer 数、入职数、入职转化率、渠道费用、单位入职成本
  - 渠道费用按渠道配置计算；未配置费用的渠道显示「—」并在表尾提示「N 个渠道未配置费用」
  - 支持按入职数与单位入职成本排序
- **面试官与招聘HR人效**：
  - 面试官表：面试官、所属组织、面试场次、已评价场次、评价及时率、通过率、平均评价时长
  - 招聘HR人效表：招聘小组、招聘HR、精力投入、投入月数、月度等效全职人力（FTE）、承接需求、已入职、待入职、在招池、一面/二面/终面通过、放弃 Offer、漏斗贡献分、单人月均产出、池→入职转化、Offer 流失率、折算完成率、季度环比、诊断标签
  - 计算口径：FTE = 精力投入 × 投入月数 ÷ 3；漏斗贡献分 = 一面×0.1 + 二面×0.2 + 终面×0.3 + 待入职×0.6 + 已入职×1.0；单人月均产出 = 精力投入 × (已入职 + 待入职) ÷ 投入月数；池→入职转化 = (已入职 + 待入职) ÷ 在招池；Offer 流失率 = 放弃 Offer ÷ (放弃 Offer + 已入职 + 待入职)；折算完成率 = (已入职 + 待入职) ÷ 承接需求
  - 人效归属：已入职、待入职、Offer、放弃 Offer、三面通过与在招池按候选人招聘HR归属；承接需求按需求招聘负责人归属；协同招聘HR不重复计入
  - 台账接入：按招聘HR归集招聘台账记录，更新已入职、待入职、放弃 Offer、在招池与阶段通过；台账新增 HR 追加一行并标记「台账同步」
  - 诊断标签：高效型、高量低转型、风险预警、观察期；阈值可在人效配置中调整
  - 表格按数值排序，支持点击姓名下钻到对应人员负责的面试场次、候选人台账或需求列表
- **Offer 流失**：
  - 按放弃原因展示放弃人数、占比与流失率；支持按组织、招聘HR、岗位类别交叉筛选；台账存在放弃原因时优先使用台账数据
  - 放弃原因取结构化枚举：薪酬待遇不满足、选择其他平台、地理位置、转正周期过长、家里有事、其他
  - 展示主要组织与代表岗位，支持下钻到招聘台账并带入筛选
- **薪酬涨幅**：
  - 按职级、岗位类别与组织展示样本数、平均当前年包、平均定薪年包、平均涨幅、超薪标人数、超涨幅人数与超限比例；台账存在年包数据时优先使用台账数据
  - 年度总包 = 月度固定×12 + 月度绩效基数×12 + 年度目标奖金月数×月度固定 + 签字费；内部定薪年包可覆盖
  - 仅具备薪资权限的用户可见；无数据时展示「—」
- **看板洞察**：
  - 位于看板底部，按所选招聘季度展示管理结论与下一阶段动作；内容由 HRBP 手工维护，不做自动生成
  - 右上「编辑洞察」打开弹窗，填写不超过 2000 字的季度洞察；保存后即时展示并提示「洞察已更新」，更新人与时间记录在弹窗底部
  - 仅具备 `BTN:HR_RECRUIT_DASHBOARD:INSIGHT` 权限的用户可编辑，其余用户只读
- **导出**：点击「导出」展开下拉，选择「汇总数据」或「明细数据」；按当前筛选与口径生成文件，导出成功提示并记录审计；无导出权限时不展示入口
- **刷新**：页头刷新按钮重新加载全部区块，展示最近刷新时间
- **失败与空态**：加载失败展示失败提示与「重试」，重试按原筛选查询；无数据区块展示空态而不隐藏区块
- **组件引用**：参照 `busyming-skills-design` 的 Button、PageableSelect、DatePicker、Tag、Checkbox、Popover、Table、Pagination、Message 交互口径
- **布局引用**：参见原型 [原型图/web/recruitment-dashboard.html](../原型图/web/recruitment-dashboard.html)

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 招聘管理 / 招聘数据看板」
- 去向页：渠道配置、薪酬带宽与人效配置以抽屉打开；指标卡与表格下钻到需求、候选人台账或面试列表并带入筛选；导出为下拉操作
- 返回行为：从下钻列表返回看板时保留筛选与时间范围
- 面包屑：首页 / 人资管理 / HR管理 / 招聘管理 / 招聘数据看板

## 渠道配置

- **页面路径**：`/hr/recruit/dashboard#channel`（非菜单页面，看板内抽屉）
- **权限编码**：`BTN:HR_RECRUIT_DASHBOARD:CHANNEL`
- **页面类型**：配置抽屉（列表 + 行内编辑）
- **区块职责**：
  - 抽屉头：标题「渠道配置」、关闭按钮
  - 说明条：费用口径说明（内推按人固定奖金，猎头与 RPO 按年薪比例或固定服务费，其余渠道按订单或不计费）
  - 渠道列表：渠道名称、类型、启用状态、计费方式、单价或比例、更新人、更新时间、操作
- **编辑**：行内「编辑」展开表单，字段含启用状态、计费方式（固定单价 / 年薪比例 / 不计费）、单价或比例、备注；保存校验必填并提示「渠道配置已更新」
- **停用**：停用须二次确认「停用后该渠道不可再被投递记录选择，历史数据保留原口径」；停用后列表置灰
- **新增**：支持新增自定义渠道（类型为其他），名称不得与现有渠道重复
- **变更留痕**：每次保存记录操作人、时间与变更前后内容，可在渠道行「变更记录」查看
- **导航关系**：关闭抽屉回到看板并保留筛选；配置变更后看板渠道费用即时刷新

## 薪酬带宽配置

- **页面路径**：`/hr/recruit/dashboard#salary-band`（非菜单页面，看板内抽屉）
- **权限编码**：`BTN:HR_RECRUIT_DASHBOARD:SALARY_BAND`
- **页面类型**：配置抽屉（职级带宽列表 + 行内编辑）
- **区块职责**：
  - 抽屉头：标题「薪酬带宽配置」、关闭按钮
  - 说明条：年薪标上限用于「超薪标」判断；涨幅预警上限默认 15%，用于「超涨幅」判断；配置仅影响标记，不阻断 Offer 审批
  - 列表列：职级、职级类别、年薪标上限、涨幅预警上限、更新人、更新时间、操作
- **编辑**：行内编辑年薪标上限与涨幅预警上限；保存校验金额为正数、涨幅为 0–100%，提示「薪酬带宽已更新」
- **变更留痕**：每次保存记录操作人、时间与变更前后内容；具备权限的用户可查看变更记录
- **导航关系**：关闭抽屉回到看板并保留筛选；配置变更后薪酬涨幅分析即时刷新

<a id="efficiency-config"></a>

## 人效配置

- **页面路径**：`/hr/recruit/dashboard#efficiency`（非菜单页面，看板内抽屉）
- **权限编码**：`BTN:HR_RECRUIT_DASHBOARD:EFFICIENCY`
- **页面类型**：配置抽屉（季度 + 招聘HR 列表 + 权重与阈值配置）
- **区块职责**：
  - 抽屉头：标题「人效配置」、季度选择、关闭按钮
  - 招聘HR列表：招聘小组、招聘HR、精力投入、投入月数、备注、更新人、更新时间、操作
  - 权重与阈值：漏斗贡献分权重（一面 / 二面 / 终面 / 待入职 / 入职）、Offer 流失率预警、转化率均值、≥150 天、完成率等诊断阈值
- **编辑**：行内维护招聘小组（高招组 / 社招组 / 攻坚组 / 其他）、精力投入（0–1）、投入月数（0–3）与备注；保存提示「人效配置已更新」
- **校验**：精力投入与投入月数须在范围内；同一季度同一招聘HR仅一条配置
- **导航关系**：关闭抽屉回到看板并保留筛选；配置变更后招聘HR人效即时刷新
