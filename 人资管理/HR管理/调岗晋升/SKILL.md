# 调岗晋升

## 模块概述

人资管理 → HR管理下的人事异动入口：以「异动单」为主线，承载调岗、晋升与降职三类场景。异动单对比原组织、职位、职级、职级类别、直接上级与编制行与目标信息，校验目标标准职位、目标编制可用缺额与晋升绩效依据；经原直接上级、目标直接上级、双方部门负责人、HRBP 与中心负责人审批后，在生效日自动生效。生效后结束原任职记录、新增任职记录，转移编制占用，更新绩效名单组织与职级，并写入员工成长记录。

本功能只承载员工组织、职位、职级与直接上级的异动，不承载招聘、入职、绩效评价、薪酬调整、劳动合同变更与员工档案日常维护。

## 端

- **web**：人资管理 → HR管理 → 调岗晋升，仅桌面端管理后台，不提供 App 入口

## When to Use

- 发起调岗、晋升或降职，选择目标组织、标准职位、职级与直接上级
- 校验目标标准职位是否适用、目标编制是否有可用缺额、目标组织是否启用
- 引用最近一次已生效绩效结果作为晋升依据，填写异动原因与生效日期
- 审批异动、查看原岗位与目标岗位对比、跟踪待生效记录
- 处理生效前的编制占用冲突、撤销未生效异动、发起更正异动
- 查看异动对员工资料、编制管理、绩效管理与成长记录的影响

## 异动台账

<a id="异动台账"></a>

- 页签固定为待审批、待生效、已生效、已驳回、已撤销；待生效包含审批通过但生效日期未到的记录；草稿记录在待审批页签通过状态筛选查看。
- 基础筛选：姓名 / 工号、原组织、目标组织、异动类型、目标职位、生效日期区间、单据状态。
- 高级筛选：原职级、目标职级、审批状态、是否晋升、是否跨部门、绩效依据、是否更正单。
- 统计卡展示待审批、待生效、本月已生效、晋升数量、降职数量与生效冲突数量。
- 支持批量导出；已生效与已撤销记录只读。

## 发起与审批

<a id="发起与审批"></a>

- 发起异动必须选择在职员工，带出原组织、职位、职级、职级类别、直接上级与编制行；目标信息由发起人选择。
- 异动类型由原职级与目标职级自动判定：目标职级高于原职级为晋升，低于为降职，相同为调岗；跨组织平级为调岗。
- 目标标准职位必须启用且适用目标职级；目标组织必须启用；目标直接上级必须为在职员工；目标编制行可用缺额须大于零，超编须按编制规则审批。
- 晋升须填写晋升理由，并引用最近一次已生效绩效结果；绩效结果缺失或未生效时提示补充说明，不自动阻断，由审批人判断。
- 审批链：原直接上级 → 目标直接上级 → 原部门负责人 → 目标部门负责人 → HRBP；晋升、降职、经理级及以上或跨中心增加中心负责人。
- 审批驳回后状态为已驳回，原单保留；可复制为新单修改后重新提交；审批通过后进入待生效。

## 生效管理

<a id="生效管理"></a>

- 生效日期不得早于提交日期；审批通过日晚于生效日期时，自动顺延至审批通过日。
- 审批通过且生效日期为今天或过去的，立即生效；生效日期为未来的，系统在生效日自动生效。
- 生效前系统再次校验目标组织、标准职位、目标编制与员工状态；校验失败时记录进入「生效冲突」，不自动生效并通知发起人与 HRBP。
- 待生效阶段可撤销；撤销须填写原因，审批记录保留；已生效不可撤销。
- 已生效异动需要更正时，由 HRBP 发起更正异动单，关联原异动单，按新异动重新审批与生效；原单保留。

## 影响范围

- **员工资料**：原任职记录结束日期取生效日前一天，新增目标组织、职位、职级与直接上级的任职记录；员工当前任职同步更新。
- **编制管理**：原编制行在编人数减一，目标编制行在编人数加一；同一编制行内调整不重复增减；目标行超编时标记超编警示。
- **绩效管理**：考核名单的组织、职位、职级、直接上级与序列更新为目标信息；已生效绩效结果保留。
- **招聘管理**：原岗位空缺可按「转岗替补」发起招聘需求，需人工发起，不自动创建。
- **员工成长记录**：写入调岗、晋升或降职事件，包含原目标快照、生效日期与异动原因。

## Tips

- 异动类型由职级变化自动判定，不由发起人手工选择；跨部门平级为调岗，晋升与降职必须带职级变化
- 目标编制行必须有可用缺额；无缺额或超编时按编制管理规则处理，不绕过编制校验
- 晋升绩效依据引用最近一次已生效结果，仅作审批参考，不自动阻断
- 生效日系统自动生效；生效前编制被占用或组织停用时进入生效冲突，不静默覆盖
- 已生效异动不可撤销，更正通过新的更正异动单完成
- 规则查找：异动规则看 [文档/业务规则.md](文档/业务规则.md)，字段口径看 [文档/数据模型.md](文档/数据模型.md)，页面元素看 [文档/页面元素.md](文档/页面元素.md)
