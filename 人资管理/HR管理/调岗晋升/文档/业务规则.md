# 调岗晋升 · 业务规则

> 本文件描述调岗、晋升与降职异动单的发起、审批、生效与回写规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。生效后回写员工资料、编制管理、绩效管理与员工成长记录。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 异动单 | 一名员工一次调岗、晋升或降职办理的记录 |
| 调岗 | 目标职级与原职级相同，目标组织、职位或直接上级发生变化 |
| 晋升 | 目标职级高于原职级 |
| 降职 | 目标职级低于原职级 |
| 原信息 | 异动前的组织、职位、职级、职级类别、直接上级与编制行快照 |
| 目标信息 | 异动后的组织、标准职位、职级、职级类别、直接上级与编制行 |
| 生效日期 | 异动正式生效的日期，任职记录与编制占用按该日期切换 |
| 生效冲突 | 审批通过后、生效前目标组织或职位停用、目标编制缺额被占用或员工状态变化，导致无法生效 |
| 更正异动 | 已生效异动需要更正时发起的反向或修正异动单，关联原单 |
| 转岗替补 | 员工调岗或晋升后原岗位空缺产生的招聘需求，按招聘管理规则创建 |

## 2. 功能边界

- 本功能承载异动发起、审批、待生效、自动生效、撤销与更正。
- 不做：招聘需求与候选人推进、入职办理、绩效评价与等级校准、薪酬调整与奖金核算、劳动合同变更、员工档案日常维护。
- 员工资料、编制、绩效、招聘与成长记录只读引用或按生效结果回写；本功能不直接修改编制数量、招聘需求人数与绩效结果。
- 异动不改变员工工号、入职日期与历史任职记录；历史任职记录只增加结束日期。

## 3. 异动类型与发起

- 异动类型由原职级与目标职级自动判定：目标职级高于原职级为晋升，低于原职级为降职，相同为调岗；发起人不可手工选择类型。
- 调岗包含同部门换岗、跨部门调动与直接上级变更；晋升与降职必须同时改变目标职级，目标职级须为目标标准职位适用范围内的职级。
- 发起异动必须选择在职员工；员工存在进行中的离职单、转正单或另一张进行中的异动单时，不可发起。
- 原信息取自员工资料当前任职与编制行，提交后为快照；员工资料后续变化不自动改写已提交异动单。
- 目标组织必须存在且启用；目标标准职位必须已启用且适用目标职级；目标直接上级必须为在职员工且不能是员工本人。
- 目标编制行必须存在且与目标组织、标准职位、职级匹配；可用缺额大于零方可直接发起；可用缺额为零或负时按编制管理超编规则处理，未获审批不可提交。
- 目标信息与原信息完全一致时不可提交；仅备注变化不构成异动。
- 晋升须填写晋升理由，并引用最近一次已生效绩效结果；绩效结果缺失、未生效或最近一次为 D 时提示补充说明，不自动阻断，由审批人判断。
- 降职须填写降职原因与改进安排；降职不自动触发绩效改进计划，相关安排由绩效管理或员工发展流程承接。
- 同一员工同一时点仅允许一张进行中的异动单；审批驳回或撤销后可重新发起。

## 4. 审批规则

- 审批链：原直接上级 → 目标直接上级 → 原部门负责人 → 目标部门负责人 → HRBP；以下情形增加中心负责人审批：
  - 晋升或降职；
  - 目标职级为经理级及以上；
  - 跨中心调动；
  - 目标编制行超编或可用缺额为零。
- 原直接上级与目标直接上级为同一人时合并为一个节点；原部门负责人与目标部门负责人为同一人时合并。
- 审批人可查看原目标对比、目标编制缺额、绩效依据与影响范围；驳回须填写意见。
- 审批通过后进入待生效；审批驳回后状态为已驳回，原单保留，可复制为新单修改后重新提交。
- 待审批阶段发起人可撤回；撤回后状态为已撤销，审批记录保留。
- 审批中目标组织、标准职位、编制或员工状态失效时，审批任务标记异常并提示重新选择，不允许带失效数据通过审批。

## 5. 生效规则

- 生效日期不得早于提交日期；审批通过日晚于生效日期时，生效日期自动顺延至审批通过日。
- 审批通过且生效日期为今天或过去的，审批通过后立即生效；生效日期为未来的，系统在生效日自动生效。
- 生效前系统再次校验：员工在职、目标组织启用、目标标准职位启用且适用、目标直接上级在职、目标编制可用缺额充足、无进行中离职单。
- 校验失败时进入「生效冲突」，不自动生效；通知发起人、HRBP 与目标部门负责人，由 HR 调整目标信息或撤销后重新发起。
- 待生效阶段可撤销，撤销须填写原因；已生效不可撤销。
- 已生效异动需要更正时，由 HRBP 发起更正异动单，关联原异动单；更正单按新异动审批与生效，原单保留。
- 同一异动单只生效一次；重复事件、重试与自动任务不重复写任职记录、不重复增减编制。

## 6. 回写规则

- **员工资料**：原任职记录结束日期取生效日前一天；新增任职记录，任职类型为调岗、晋升或降职，生效日期取异动生效日期，结束日期为空；员工当前组织、职位、职级、职级类别、岗位序列与直接上级更新为目标信息。
- **编制管理**：原编制行在编人数减一，目标编制行在编人数加一；同一编制行内调整不重复增减；目标行在编人数超过编制数量时标记超编警示，由编制管理员处理。
- **绩效管理**：考核名单的组织、职位、职级、直接上级与序列更新为目标信息；已生效绩效结果保留原快照；进行中周期的考核表按目标信息展示当前组织职级。
- **招聘管理**：原岗位空缺可按转岗替补发起招聘需求，需求关联异动单；不自动创建职位与需求。
- **员工成长记录**：写入调岗、晋升或降职事件，包含原目标组织、职位、职级、直接上级、生效日期、异动原因与绩效依据摘要。
- **工作台**：待审批、待生效与生效冲突数量进入工作台待办与预警。

## 7. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 异动类型 | 调岗、晋升、降职 | 晋升为主色标签，降职为警示标签，调岗为中性 |
| 单据状态 | 草稿、待审批、待生效、已生效、已驳回、已撤销 | 待审批与待生效为警示标签，已生效为主色，其余中性 |
| 审批状态 | 待审批、已通过、已驳回、已撤回 | 待审批为警示标签，已通过为主色 |
| 生效状态 | 未生效、待生效、已生效、生效冲突 | 生效冲突为警示标签，已生效为主色 |
| 任职类型 | 调岗、晋升、降职 | 与异动类型一致 |
| 绩效依据 | 最近一次已生效绩效结果 | 文本，展示周期与等级 |
| 是否更正单 | 是、否 | 是为主色弱标签 |
| 是否发起转岗替补 | 是、否 | 文本 |

## 8. 权限编码与数据范围

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:MOVEMENT` | 未授权不展示菜单 |
| 发起异动 | `BTN:HR_MOVEMENT:CREATE` | 未授权不展示发起入口 |
| 编辑异动 | `BTN:HR_MOVEMENT:EDIT` | 草稿与已驳回可编辑复制 |
| 提交审批 | `BTN:HR_MOVEMENT:SUBMIT` | 发起人可见 |
| 审批 | `BTN:HR_MOVEMENT:APPROVE` | 按审批节点校验 |
| 撤回 | `BTN:HR_MOVEMENT:WITHDRAW` | 发起人与 HRBP 可见 |
| 撤销待生效 | `BTN:HR_MOVEMENT:CANCEL` | 未授权不展示撤销入口 |
| 更正异动 | `BTN:HR_MOVEMENT:CORRECT` | 仅 HRBP |
| 发起转岗替补 | `BTN:HR_MOVEMENT:BACKFILL` | 未授权不展示入口 |
| 导出 | `BTN:HR_MOVEMENT:EXPORT` | 未授权不展示导出按钮 |

- 数据权限：员工本人只读；直接上级本团队；部门负责人本部门；中心负责人与 HRBP 本中心；HR 管理员全量。
- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 9. 与其他模块的边界

- **岗位管理**：目标标准职位、职级范围与岗位序列只读引用；异动不修改标准职位与职级矩阵。
- **编制管理**：异动按目标编制行转移在编人数；不修改编制数量、编制计划与招聘占用。
- **绩效管理**：异动更新考核名单的组织与职级；绩效评价、等级与系数仍由绩效管理决定。
- **离职管理**：存在进行中离职单时不可发起或生效异动；调岗后原岗位空缺可按转岗替补发起招聘。
- **员工成长记录**：异动生效写入调岗、晋升或降职事件，不重复写入入职或绩效事件。
