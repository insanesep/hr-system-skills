# 调岗晋升 · 数据模型

> 本文件为异动单、审批与操作记录的字段口径；规则见 [业务规则.md](业务规则.md)。一张异动单对应一名员工的一次调岗、晋升或降职，生效后写入员工资料任职记录。

<a id="1-异动单"></a>

## 1. 异动单

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 异动单号 | 异动单唯一标识 | 文本 | 是 | 全局唯一，按年月生成，如 MV20261123001 |
| 员工 | 异动员工 | 文本 | 是 | 引用员工资料，须为在职状态 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 异动类型 | 调岗、晋升或降职 | 枚举 | 是 | 由原职级与目标职级自动判定 |
| 原组织路径 | 异动前组织快照 | 文本 | 是 | 一至五级组织 |
| 原职位 | 异动前职位快照 | 文本 | 是 | 引用标准职位或员工资料当前职位 |
| 原职级 | 异动前职级 | 文本 | 是 | 如 P5 |
| 原职级类别 | 异动前职级类别 | 枚举 | 是 | 战略决策层、总监级、经理级、主管级、员工级 |
| 原岗位序列 | 异动前岗位序列 | 文本 | 否 | 引用岗位管理 |
| 原直接上级 | 异动前直接上级 | 文本 | 是 | 取自员工资料 |
| 原编制行 | 异动前编制明细行 | 文本 | 否 | 引用编制管理；无编制时为空 |
| 目标组织路径 | 异动后组织 | 文本 | 是 | 一至五级组织，须启用 |
| 目标标准职位 | 异动后标准职位 | 文本 | 是 | 引用岗位管理，须已启用且适用目标职级 |
| 目标职级 | 异动后职级 | 文本 | 是 | 必须在目标标准职位适用范围内 |
| 目标职级类别 | 异动后职级类别 | 枚举 | 是 | 由目标职级派生 |
| 目标岗位序列 | 异动后岗位序列 | 文本 | 是 | 由目标标准职位带出 |
| 目标直接上级 | 异动后直接上级 | 文本 | 是 | 须为在职员工，不可为本人 |
| 目标编制行 | 异动后编制明细行 | 文本 | 是 | 引用编制管理，须与目标组织、职位、职级匹配 |
| 目标可用缺额 | 目标编制行可用缺额快照 | 数值 | 是 | 提交时计算，生效前重算 |
| 异动原因 | 异动原因分类 | 枚举 | 是 | 业务需要、组织调整、个人发展、绩效改进、晋升、降职、其他 |
| 原因说明 | 异动原因补充 | 文本 | 是 | 不超过 500 字；晋升与降职必填 |
| 晋升理由 | 晋升依据说明 | 文本 | 否 | 晋升时必填 |
| 绩效依据 | 最近一次已生效绩效结果 | 文本 | 否 | 晋升时引用；缺失或未生效时在原因说明中补充 |
| 降职改进安排 | 降职后的改进安排 | 文本 | 否 | 降职时必填 |
| 生效日期 | 异动生效日期 | 日期 | 是 | 不得早于提交日期；审批通过日晚于该日期时顺延 |
| 审批状态 | 审批结果 | 枚举 | 是 | 待审批、已通过、已驳回、已撤回 |
| 单据状态 | 异动单当前状态 | 枚举 | 是 | 草稿、待审批、待生效、已生效、已驳回、已撤销 |
| 生效状态 | 生效执行状态 | 枚举 | 是 | 未生效、待生效、已生效、生效冲突 |
| 实际生效日期 | 实际执行生效的日期 | 日期 | 否 | 已生效时填写 |
| 是否更正单 | 是否为更正异动 | 布尔 | 是 | 默认否 |
| 原异动单 | 被更正的异动单 | 文本 | 否 | 更正单时填写 |
| 是否发起转岗替补 | 是否发起原岗位招聘 | 枚举 | 是 | 是、否；默认否 |
| 转岗替补需求号 | 关联招聘需求 | 文本 | 否 | 发起后写入 |
| 审批完成时间 | 最后审批通过时间 | 日期时间 | 否 | — |
| 备注 | 补充说明 | 文本 | 否 | 不超过 500 字 |
| 创建人 | 发起人 | 文本 | 是 | — |
| 创建时间 | 创建时间 | 日期时间 | 是 | — |
| 更新时间 | 最近更新时间 | 日期时间 | 是 | — |

## 2. 审批记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 审批记录标识 | 审批记录唯一标识 | 文本 | 是 | 从属于异动单 |
| 异动单号 | 所属异动单 | 文本 | 是 | — |
| 审批节点 | 审批环节 | 文本 | 是 | 原直接上级、目标直接上级、原部门负责人、目标部门负责人、HRBP、中心负责人 |
| 审批人 | 审批人 | 文本 | 是 | — |
| 审批结果 | 审批结论 | 枚举 | 是 | 待审批、已通过、已驳回、已撤回 |
| 审批意见 | 审批意见 | 文本 | 否 | 驳回时必填 |
| 审批时间 | 审批时间 | 日期时间 | 否 | — |

## 3. 生效校验记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 校验标识 | 生效校验唯一标识 | 文本 | 是 | 从属于异动单 |
| 异动单号 | 所属异动单 | 文本 | 是 | — |
| 校验时间 | 执行校验时间 | 日期时间 | 是 | 审批通过后与生效前各执行一次 |
| 校验结果 | 校验结论 | 枚举 | 是 | 通过、失败 |
| 失败原因 | 校验失败原因 | 文本 | 否 | 员工状态、组织停用、职位停用、编制不足、直接上级失效等 |
| 处理状态 | 冲突处理状态 | 枚举 | 是 | 未处理、处理中、已处理、已撤销 |

## 4. 操作记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 记录标识 | 操作记录唯一标识 | 文本 | 是 | 只增不改不删 |
| 异动单号 | 所属异动单 | 文本 | 是 | — |
| 操作类型 | 操作分类 | 枚举 | 是 | 创建、编辑、提交、审批、驳回、撤回、撤销、生效、生效冲突、更正、发起转岗替补、导出 |
| 操作内容 | 操作摘要 | 文本 | 是 | 包含变更前后内容与原因 |
| 操作人 | 操作人员 | 文本 | 是 | — |
| 操作时间 | 操作时间 | 日期时间 | 是 | 倒序展示 |

## 5. 实体关系

- 员工与异动单为一对多：一名员工可有多次调岗、晋升或降职，同一时点仅一张进行中异动单。
- 异动单与原编制行、目标编制行为多对一：异动单关联原编制行与目标编制行。
- 异动单与审批记录为一对多：每个审批节点一条记录。
- 异动单与生效校验记录为一对多：审批通过后与生效前各一条。
- 异动单与更正异动单为一对零或一：已生效异动可被一张更正单关联。
- 异动单与员工资料任职记录为一对一：生效后新增一条任职记录。

## 6. 枚举

| 枚举 | 取值 |
|---|---|
| 异动类型 | 调岗、晋升、降职 |
| 异动原因 | 业务需要、组织调整、个人发展、绩效改进、晋升、降职、其他 |
| 审批状态 | 待审批、已通过、已驳回、已撤回 |
| 单据状态 | 草稿、待审批、待生效、已生效、已驳回、已撤销 |
| 生效状态 | 未生效、待生效、已生效、生效冲突 |
| 审批节点 | 原直接上级、目标直接上级、原部门负责人、目标部门负责人、HRBP、中心负责人 |
| 生效失败原因 | 员工离职、组织停用、职位停用、编制不足、直接上级失效、存在进行中离职单、其他 |
