# 人才盘点九宫格

## 模块概述

人资管理 → HR管理 下的人才盘点入口：按盘点周期组织员工的人岗匹配度 × 潜力评估，形成九宫格分布用于人才校准与通晒。数据明细以员工为一行维护评估字段与后续管理动作；九宫格汇总以人岗匹配度为纵轴、潜力为横轴，先展示盘点范围整体分布，再按职级档、岗位或部门逐组展示 3×3 格位与人员名单。周期支持名单同步、Excel 导入导出、锁定与变更留痕；本模块不承载绩效评价、薪酬核算与人才观察记录。

## 端

- **web**：人资管理 → HR管理 → 人才盘点九宫格，仅桌面端管理后台，不提供 App 入口

## When to Use

- 按半年度或年度创建盘点周期，生成并同步纳入盘点的员工名单
- 为员工维护人岗匹配度、潜力及判断说明，记录价值观认同度与岗位职责
- 标记关键岗、重点培养对象与后续管理动作，形成盘点结论
- 按职级档、岗位或部门查看九宫格分布、组内占比与人员名单
- 从 Excel 批量导入评估、或导出含数据明细与九宫格的通晒版本
- 锁定盘点结果，查询评估变更记录与周期操作记录
- 复核职级档归并、部门层级分组、未评估口径与权限编码

## 数据明细

<a id="数据明细"></a>

- 周期创建后按组织范围内在职员工生成名单；进行中周期可同步名单，锁定后只读；周期、名单与快照规则见 [文档/业务规则.md §3](文档/业务规则.md#3-盘点周期与名单)。
- 台账以员工为一行，展示快照字段、参考绩效、评估字段与评估状态；默认未评估在前，按职级档从高到低排列。
- 编辑抽屉维护人岗匹配度、潜力、价值观认同度、是否关键岗、是否重点培养对象、岗位职责与后续管理动作；首次填写后的每次修改必须填写原因并留痕。
- 导入只覆盖评估字段，失败行生成回执；导出生成含「数据明细」与「九宫格」的通晒版本工作簿。
- 字段取值与校验见 [文档/数据模型.md](文档/数据模型.md)，页面元素见 [文档/页面元素.md §数据明细](文档/页面元素.md#detail)。

## 九宫格汇总

<a id="九宫格汇总"></a>

- 九宫格以人岗匹配度为纵轴、潜力为横轴，纵轴自上而下与横轴自左至右均为高、中、低；未评估员工不计入格位，离职员工不参与统计。
- 汇总页先展示「盘点范围整体」九宫格，再按所选分组展示分组九宫格卡；格位展示人数、组内占比与姓名，点击格位查看人员名单并下钻员工明细。
- 分组维度为按职级档、按岗位、按部门：职级档按职级矩阵合并 M / P 同级职级，按岗位以职位名称归并，按部门可选二级 / 三级 / 四级并默认三级。
- 分组规则、排序、特殊分组与统计口径见 [文档/业务规则.md §5–§6](文档/业务规则.md#5-九宫格与统计口径)，页面元素见 [文档/页面元素.md §九宫格汇总](文档/页面元素.md#summary)。

## 周期、留痕与权限

- 周期状态为进行中、已锁定；锁定需二次确认并对未评估人数提示，HR 管理员可填写原因取消锁定。
- 变更记录覆盖评估字段的每次修改；周期操作记录覆盖创建、同步名单、导入、锁定与取消锁定。
- 写入限 HRBP 本中心与 HR 管理员；中心负责人、部门负责人只读；员工本人与直接上级（非部门负责人）不可见。
- 菜单与按钮权限编码见 [文档/业务规则.md §10](文档/业务规则.md#10-权限编码)，数据权限与脱敏见 [§8](文档/业务规则.md#8-数据权限与脱敏)。

## Tips

- 九宫格的纵横轴取自参考工作簿：纵轴人岗匹配度、横轴潜力；不要与绩效等级、人才信息的盘点结果混用
- 职级档由职级矩阵派生，不在本模块维护职级与职级类别；岗位分组按职位名称归并，不依赖标准职位映射
- 参考绩效只读引用绩效管理最终等级；盘点评估不改变绩效、薪酬与编制
- 人才信息的「人才盘点」记录是另一套观察结论，本模块不写入人才信息、不写入员工成长记录
- 未评估员工不影响锁定，但会在统计卡与组头单独提示；锁定后参考绩效保留锁定时的结果
- 规则查找：周期、统计与分组看 [文档/业务规则.md](文档/业务规则.md)，字段口径看 [文档/数据模型.md](文档/数据模型.md)，页面元素看 [文档/页面元素.md](文档/页面元素.md)
