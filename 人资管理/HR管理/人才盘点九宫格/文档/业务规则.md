# 人才盘点九宫格 · 业务规则

> 本文件描述人才盘点九宫格的周期与名单、评估字段、九宫格统计、分组规则、锁定与导出口径；字段定义见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。职级矩阵以[岗位管理](../../../组织管理/岗位管理/文档/数据模型.md#职级矩阵)为唯一真源，人员与组织事实只读引用员工档案与组织架构。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 盘点周期 | 一次人才盘点的时间范围与人员范围配置，如「2026半年度盘点」 |
| 盘点范围 | 周期覆盖的组织范围与人员范围；人员范围为组织范围内的在职员工 |
| 盘点名单 | 周期内纳入盘点的员工集合，生成时快照组织、职位、职级、直接上级与人员状态 |
| 盘点明细 | 名单内一名员工在本周期的一条评估记录，含快照字段、评估字段与参考绩效 |
| 职级档 | 按职级矩阵归并的展示档：同一职级类别内管理序列（M）与专业序列（P）按序号从高到低对齐合并（如 P9/M6），业务（S）与操作（O）序列每个职级独立成档 |
| 九宫格 | 以人岗匹配度为纵轴、潜力为横轴的 3×3 分布，纵横轴均按高、中、低分档 |
| 格位 | 九宫格中的一个单元格，由「人岗匹配度等级 + 潜力等级」唯一确定，如「高匹配 · 高潜」 |
| 评估完成 | 一名员工的人岗匹配度与潜力均已选择等级 |
| 未评估 | 人岗匹配度或潜力任一未选择等级 |
| 基准日 | 计算司龄与现岗任职时长的截止日期，取盘点周期的结束日期 |
| 通晒版本 | 本模块导出的盘点工作簿，含「数据明细」与「九宫格」两个工作表 |
| 锁定 | 周期进入只读状态，评估字段、名单与导入均不可修改 |

## 2. 功能边界

- 本功能承载盘点周期与名单、评估字段维护、九宫格分布汇总、Excel 导入导出、锁定与变更留痕。
- 不做：绩效评价与绩效等级计算、薪酬核算、编制与组织职位维护、任职异动、人才观察记录。
- 参考绩效只读引用绩效管理已生效的最终等级，不参与九宫格计算，也不因盘点改变；绩效参与标记、评分与绩效后续计划不在本模块维护，按绩效管理对应功能查询。
- 人才信息的「人才盘点」记录是 HRBP 的观察结论（不胜任、胜任、高潜），与本模块的人岗匹配度 × 潜力评估是不同口径；本模块不自动写入人才信息，也不把格位换算为盘点结果。
- 不提供 App 入口、员工本人入口与直接上级（非部门负责人）入口。
- 评估说明与岗位职责不得包含薪酬、证件号码、手机号等敏感信息。

## 3. 盘点周期与名单

- 盘点周期由 HR 管理员创建，包含周期名称、起止日期、组织范围与参考绩效期；参考绩效期取绩效管理已生效的考核周期，最多 4 期。
- 同一组织范围内周期名称不可重复；结束日期不得早于开始日期。
- 周期创建后，按组织范围内在职员工生成盘点名单：生成时快照二级、三级、四级组织、直接上级、职位、职级、工作地、入职日期与人员状态。
- 进行中的周期可执行「同步名单」：纳入新入职员工、按最新员工资料刷新组织职位等快照、将离职员工标记为离职；已锁定的周期不可同步。
- 同一周期同一员工仅一条盘点明细；名单内员工不可手工删除。
- 离职员工保留明细并标记离职，不参与九宫格汇总与统计；同步名单后重新在职的员工恢复参与。
- 周期状态为进行中、已锁定；锁定的周期只读，HR 管理员可取消锁定，取消后恢复编辑并记录周期操作。

## 4. 评估字段与校验

| 字段 | 取值 | 必填 | 规则 |
|---|---|---|---|
| 人岗匹配度等级 | 高、中、低 | 评估完成时必填 | 九宫格纵轴依据 |
| 人岗匹配度说明 | 文本 | 否 | 不超过 300 字，记录能力与岗位要求的匹配依据 |
| 潜力等级 | 高、中、低 | 评估完成时必填 | 九宫格横轴依据 |
| 潜力说明 | 文本 | 否 | 不超过 300 字，记录成长性与可承担更大职责的依据 |
| 价值观认同度 | 高、中、低 | 否 | 仅展示与筛选，不进入九宫格 |
| 是否关键岗 | 是、否 | 否 | 按岗位关键性人工判断，不自动引用编制 |
| 是否重点培养对象 | 是、否、待观察 | 否 | 人工判断；为「是」时建议填写培养方向与预期 |
| 重点培养说明 | 文本 | 否 | 不超过 300 字 |
| 岗位职责 | 文本 | 否 | 不超过 500 字；默认带出员工当前标准职位的核心职责，可按人调整 |
| 后续管理动作 | 文本 | 否 | 不超过 200 字；提供常用短语辅助填入，不作枚举限制 |
| 参考绩效 | 只读 | — | 取周期配置的参考绩效期在绩效管理的最终等级 |

- 人岗匹配度与潜力等级均未填或只填其一时为未评估；两者均填后为已评估，未评估员工不进入任何格位。
- 各说明与后续管理动作可不填，不阻断保存与锁定。
- 首次填写评估字段无需填写原因；对已保存的字段再次修改时必须填写变更原因，并写入变更记录。
- 岗位职责按周期保存为快照，后续标准职位调整不回写已保存内容。
- 锁定后评估字段只读；取消锁定后修改继续留痕。
- Excel 导入只接受评估字段与说明列；工号必须在当前名单内，等级值必须为高、中、低，人员状态与组织职位快照不可导入。导入需填写本次导入说明；成功行覆盖对应评估字段并写入变更记录，失败行生成回执，格式为「行号 + 工号 + 失败原因」。
- 参考绩效缺失时展示「—」，不阻断评估。

## 5. 九宫格与统计口径

- 九宫格纵轴为人岗匹配度，自上而下为高、中、低；横轴为潜力，自左至右为高、中、低。
- 每个格位展示已评估人数与姓名列表；姓名按姓名排序，超过展示上限时折叠为「等 N 人」，点击格位查看完整名单。
- 汇总页顶部展示当前组织范围的「盘点范围整体」九宫格，其下按所选分组维度展示各组九宫格。
- 组内格位占比的分母为组内已评估人数；盘点范围整体格位占比的分母为范围内已评估人数。
- 未评估员工不计入格位与占比，在组头与统计卡单独计数；离职员工不计入盘点人数、格位与占比。
- 统计卡口径：盘点人数（不含离职）、已评估人数、未评估人数、高匹配高潜人数、评估覆盖率（已评估 / 盘点人数）。
- 汇总与明细同源；明细修改、导入或名单同步后，汇总与统计卡即时重算。
- 明细与汇总均按当前用户的数据权限过滤；按组织范围筛选只影响汇总展示，不改变名单与明细数据。

## 6. 分组规则

### 6.1 按职级档

- 职级档按[岗位管理 · 职级矩阵](../../../组织管理/岗位管理/文档/数据模型.md#职级矩阵)派生：同一职级类别内管理序列（M）与专业序列（P）按序号从高到低对齐合并为一档，如 P9/M6、P8/M5、P7/M4；无对应职级时独立成档；业务序列（S）与操作序列（O）每个职级独立成档。
- 档名由该档实际存在的职级编码组成，专业序列在前、管理序列在后，如「P9/M6」；仅一侧存在时只展示存在的职级编码。
- 无职级或职级不在启用矩阵内的员工归入「未定级」组，排在最后。
- 组顺序按职级类别从高到低、类别内按职级序号从高到低。

### 6.2 按岗位

- 以盘点明细快照的职位名称为组，同名合并；不做标准职位映射，不因命名不一致拆分或归并。
- 职位为空的员工归入「未设置岗位」组，排在最后。
- 组顺序按组内已评估人数降序，同人数按职位名称排序。

### 6.3 按部门

- 部门层级可选二级（中心）、三级（部门）、四级（小组），默认三级。
- 组为盘点范围内所选层级的组织节点，按明细快照的组织归属；对应层级为空的员工归入「未分配部门」组，排在最后。
- 组顺序按部门管理维护的部门树顺序。
- 盘点范围整体只统计周期组织范围内的人员；切换分组维度或部门层级只改变汇总展示，不改变名单、明细与评估数据。

## 7. 锁定与通晒版本导出

- 锁定需二次确认；存在未评估人员时提示未评估人数，不阻断锁定。
- 锁定后周期状态为已锁定，评估字段、名单同步与导入只读；导出、查询与取消锁定保留。
- 取消锁定仅 HR 管理员可操作，须填写原因，并记录周期操作；取消后周期回到进行中。
- 导出通晒版本生成一个工作簿：
  - 「数据明细」工作表：列与页面台账一致，含员工快照、参考绩效、评估字段与说明、评估状态。
  - 「九宫格」工作表：按导出时汇总页当前分组维度、部门层级与组织范围生成；逐组输出 3×3 姓名矩阵，并标注组名、盘点人数、已评估与未评估人数。
- 导出范围取当前用户数据权限与组织范围的交集；导出文件页脚标注「人才盘点敏感材料，仅限授权人员使用」。
- 导出不改变周期状态，不生成变更记录；未锁定周期也可导出，导出内容标注周期状态。

## 8. 数据权限与脱敏

- 写入：HRBP 按所对接中心、HR 管理员可创建周期、同步名单、编辑评估、导入、锁定与取消锁定。
- 只读：中心负责人本中心、部门负责人本部门可查看明细与汇总；不可编辑。
- 员工本人不可见；直接上级非部门负责人时不可见；员工资料不可见的员工，本模块同样不可见。
- 数据范围取员工资料数据权限与盘点周期组织范围的交集；无权限员工不出现在名单、汇总与导出。
- 页面与导出均不含薪酬、证件号码与手机号；评估说明与岗位职责按公司脱敏要求填写。

## 9. 修改留痕

- 适用范围：人岗匹配度、潜力、价值观认同度、是否关键岗、是否重点培养对象、重点培养说明、岗位职责与后续管理动作的变更。
- 每条变更记录包含：操作时间、操作人、员工、变更字段、原值、新值、变更原因与来源。
- 首次填写不生成变更记录；同一字段首次保存后的每次修改均生成记录。
- Excel 导入为每条被覆盖的记录生成变更记录，变更原因取本次导入说明。
- 变更记录只增不改不删，按时间倒序展示，支持按员工关键字、变更字段与时间区间筛选。
- 周期级操作另记周期操作：创建、同步名单、导入、锁定、取消锁定；记录操作人、操作时间与影响人数。

## 11. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 周期状态 | 进行中、已锁定 | 进行中为主色，已锁定为中性 |
| 评估状态 | 未评估、已评估 | 未评估为提示，已评估为成功 |
| 匹配度与潜力等级 | 高、中、低 | 高为成功、中为提示、低为警示 |
| 价值观认同度 | 高、中、低 | 文本标签 |
| 是否关键岗 | 是、否 | 是为提示标签，否为中性 |
| 是否重点培养对象 | 是、否、待观察 | 是为成功，待观察为提示，否为中性 |
| 人员状态 | 正式、试用、离职 | 离职为中性并置灰 |
| 分组维度 | 按职级档、按岗位、按部门 | 页签切换 |
| 部门层级 | 二级、三级、四级 | 仅按部门分组时展示 |
| 格位 | 高匹配·高潜、高匹配·中潜、高匹配·低潜、中匹配·高潜、中匹配·中潜、中匹配·低潜、低匹配·高潜、低匹配·中潜、低匹配·低潜 | 3×3 行列组合 |
| 特殊分组 | 未定级、未设置岗位、未分配部门 | 排在最后 |

## 12. 与其他模块的边界

- **员工资料**：员工身份、组织、职位、职级、工作地、入职日期与在职状态以员工资料为准；本模块只读并在名单生成或同步时快照。
- **部门管理**：组织层级、部门顺序与启停以部门管理为准；本模块的部门分组按所选层级与部门树顺序展示。
- **岗位管理**：职级矩阵、职级类别与标准职位以岗位管理为准；职级档由职级矩阵派生，岗位职责默认取标准职位核心职责。
- **绩效管理**：参考绩效取已生效周期的最终等级，只读展示；本模块不改变绩效等级、系数与名单。
- **人才信息**：人才盘点记录为 HRBP 观察结论，由人才信息维护并写入员工成长记录；本模块不写入成长记录，不自动生成人才盘点记录。
- **工作台**：本模块不新增待办与预警；周期锁定不触发审批。
- **入职、转正、调岗晋升、离职**：同步名单时读取最新员工事实，不反向回写业务单据。
