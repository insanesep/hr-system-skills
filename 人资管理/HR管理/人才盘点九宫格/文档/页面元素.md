# 人才盘点九宫格 · 页面元素说明

> 字段口径见 [数据模型.md](数据模型.md)，规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，一个菜单内以「数据明细」「九宫格汇总」两个页签承载，不设独立详情路由。职级档派生规则见[业务规则.md §6.1](业务规则.md#61-按职级档)，参考绩效取[绩效管理](../../绩效管理/SKILL.md)已生效结果。

## 数据明细

- **页面路径**：`/hr/talent-review/list#detail`
- **权限编码**：路由 `MENU:HR:TALENT_REVIEW`；按钮见 [业务规则.md §10](业务规则.md#10-权限编码)
- **页面类型**：操作工作台（周期条 + 统计卡 + 可编辑台账）
- **区块职责**：
  - 页头：标题「人才盘点九宫格」+ 副标题「按盘点周期维护人岗匹配度与潜力，形成九宫格分布」+ 周期选择 + 周期状态标签
  - 页签：数据明细 / 九宫格汇总，切换不改变周期与权限范围
  - 周期操作：新建周期、同步名单、导入、导出通晒版本、锁定盘点（已锁定时为取消锁定）、变更记录
  - 统计卡：盘点人数、已评估、未评估、高匹配高潜、评估覆盖率
  - 筛选区：关键字（姓名 / 工号）、组织、岗位、职级档、人岗匹配度、潜力、评估状态、人员状态；查询与重置
  - 台账区：结果条数与「刷新」+ 明细表 + 空态
  - 抽屉：编辑评估、查看明细、变更记录
  - 弹窗：新建周期、导入、同步名单确认、锁定确认、取消锁定
- **台账列**：工号、姓名、二级组织、三级组织、四级组织、直接上级、职位、职级、工作地、入职日期、司龄、上一次晋升时间、现岗任职时长、人员状态、是否关键岗、参考绩效（按周期配置展示 0–4 列）、人岗匹配度、潜力、价值观认同度、是否重点培养对象、后续管理动作、评估状态、操作
- **只读列**：工号、姓名、组织、直接上级、职位、职级、工作地、入职日期、司龄、人员状态、参考绩效与评估状态
- **默认排序**：未评估在前，其后按职级档从高到低，同档按工号升序
- **行内呈现**：人岗匹配度、潜力、价值观认同度以高 / 中 / 低标签展示；未评估员工在评估状态列展示「未评估」提示；离职员工整行置灰并在人员状态列展示「离职」
- **编辑态**：行操作「编辑」打开编辑抽屉；已锁定时编辑入口隐藏，抽屉与弹窗均为只读提示
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyInput、PageableSelect、BusyTabs、Table、Tag、Drawer、Form、Message、Modal、Popover、Import、DatePicker、OrgSelector
- **布局引用**：参见原型 [原型图/web/talent-nine-box.html#detail](../原型图/web/talent-nine-box.html#detail)

### 统计卡

- 盘点人数：当前周期名单内非离职员工数；已评估：人岗匹配度与潜力均已填的人数；未评估：盘点人数减已评估人数。
- 高匹配高潜：人岗匹配度为高且潜力为高的人数；评估覆盖率：已评估 / 盘点人数，保留整数百分比。
- 统计卡取当前周期与当前数据权限范围，不随台账筛选变化；筛选只影响台账行。

### 台账筛选与列

- 筛选条件之间为「且」关系；组织筛选按三级组织，岗位按职位名称，职级档按派生档名。
- 参考绩效列按周期配置的参考绩效期顺序展示；未配置时不展示绩效列。
- 后续管理动作超长时截断展示，悬停展示全文。
- 台账支持横向滚动，工号与姓名两列吸附左侧；行操作仅「查看」与「编辑」。
- 无匹配结果时展示空态「没有符合条件的盘点明细」与「重置筛选」。

### 编辑评估抽屉

- **打开方式**：台账行「编辑」。
- **抽屉头部**：员工姓名、工号、组织路径、职位与职级只读展示；展示最近更新人与更新时间。
- **表单字段**：
  - 人岗匹配度：高 / 中 / 低单选 + 说明（文本域，300 字）
  - 潜力：高 / 中 / 低单选 + 说明（文本域，300 字）
  - 价值观认同度：高 / 中 / 低单选
  - 是否关键岗：是 / 否单选
  - 是否重点培养对象：是 / 否 / 待观察单选 + 培养说明（文本域，300 字）
  - 岗位职责：文本域（500 字）
  - 后续管理动作：输入框（200 字）+ 常用短语快捷填入
  - 变更原因：文本域；已保存过评估字段的员工再次修改时展示且必填
- **校验**：说明非必填；变更原因为空时阻断保存并提示「请填写变更原因」；输入按各字段最大长度限制。
- **保存反馈**：保存后抽屉关闭，台账行与统计卡即时刷新；首次填写提示「已保存评估结果」，修改提示「已保存，并写入变更记录」。
- **锁定态**：抽屉内全部字段只读，底部展示「本周期已锁定」并隐藏保存按钮。

### 查看明细抽屉

- **打开方式**：台账行「查看」或汇总格位人员抽屉的「查看」。
- **内容**：员工快照（组织、直接上级、职位、职级、工作地、入职日期、司龄、上一次晋升时间、现岗任职时长、人员状态）、参考绩效、评估字段与说明、岗位职责、后续管理动作、重点培养说明、最近更新人与时间。
- **底部操作**：关闭；具备编辑权限且周期未锁定时提供「编辑」进入编辑抽屉。

### 变更记录抽屉

- **打开方式**：周期操作区「变更记录」。
- **内容**：按时间倒序的记录列表，每条展示操作时间、操作人、员工、变更字段、原值 → 新值、变更原因与来源。
- **筛选**：员工关键字、变更字段、时间区间。
- **空态**：展示「本周期暂无变更记录」。

### 新建周期弹窗

- **打开方式**：周期操作区「新建周期」。
- **字段**：周期名称、开始日期、结束日期、组织范围、参考绩效期（多选，最多 4 期；不勾选时不展示绩效列）、创建后同步名单说明。
- **校验**：名称必填且同组织范围内不重复；结束日期不得早于开始日期；组织范围必选。
- **反馈**：创建成功提示「盘点周期已创建，已按组织范围生成名单」，周期选择切到新周期。

### 导入弹窗

- **打开方式**：周期操作区「导入」。
- **内容**：模板下载入口、文件选择、导入说明（只接受评估字段与说明列，工号须在名单内）、本次导入说明（必填）、失败行回执说明。
- **反馈**：导入完成后提示「导入完成：成功 N 行，失败 M 行」，失败行以「行号 + 工号 + 失败原因」展示，可重新选择文件。
- **锁定态**：已锁定周期不展示导入入口。

### 同步名单确认弹窗

- **打开方式**：周期操作区「同步名单」。
- **内容**：说明将纳入新员工、刷新组织职位快照并将离职员工标记离职；展示预计新增人数与将标记离职人数。
- **反馈**：确认后提示「名单已同步：新增 N 人，更新 M 人，离职 K 人」，台账、统计卡与汇总即时刷新。

### 锁定与取消锁定

- **锁定确认**：展示未评估人数提示；确认后周期状态变为已锁定，页面提示「本周期已锁定」，评估编辑、导入与同步名单入口隐藏。
- **取消锁定**：仅 HR 管理员可见；弹窗必填取消原因；确认后周期回到进行中并记录周期操作。

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 人才盘点九宫格」进入数据明细；周期创建后停留本页。
- 去向页：无下级页面；九宫格汇总为同菜单页签；编辑、查看与变更为抽屉，新建、导入、同步与锁定为弹窗。
- 返回行为：关闭抽屉或弹窗回到原台账位置，保留周期、筛选与滚动位置。
- 面包屑：首页 / 人资管理 / HR管理 / 人才盘点九宫格。

## 九宫格汇总

- **页面路径**：`/hr/talent-review/list#summary`
- **权限编码**：路由 `MENU:HR:TALENT_REVIEW`；查看 `BTN:HR_TALENT_REVIEW:DETAIL`；导出 `BTN:HR_TALENT_REVIEW:EXPORT`
- **页面类型**：分析看板（整体分布 + 分组 3×3）
- **区块职责**：
  - 汇总工具条：组织范围选择、分组维度（按职级档 / 按岗位 / 按部门）、部门层级（仅按部门时展示）、导出通晒版本
  - 统计卡：盘点人数、已评估、未评估、高匹配高潜、评估覆盖率（与数据明细同一口径）
  - 整体九宫格：标题「盘点范围整体」+ 盘点人数与评估覆盖率 + 纵轴「人岗匹配度」与横轴「潜力」标注 + 3×3 格位 + 图例
  - 分组九宫格卡：按所选分组维度逐组展示，组头展示组名、盘点人数、已评估与未评估；每卡一个 3×3 格位矩阵
  - 抽屉：格位人员名单、员工明细查看
  - 空态：所选范围无数据时展示「当前范围暂无盘点数据」
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyTabs、Tag、Drawer、Message、Popover、PageableSelect
- **布局引用**：参见原型 [原型图/web/talent-nine-box.html#summary](../原型图/web/talent-nine-box.html#summary)

### 汇总工具条

- 组织范围：默认周期的组织范围；具备更大数据权限时可按二级、三级组织下钻筛选，只影响汇总展示。
- 分组维度：按职级档、按岗位、按部门三选一；切换后整体格不变，分组卡重算。
- 部门层级：按部门分组时展示，可选二级（中心）、三级（部门）、四级（小组），默认三级。
- 导出：按当前组织范围与分组维度导出通晒版本工作簿。

### 九宫格卡

- 纵轴自上而下为人岗匹配度的高、中、低；横轴自左至右为潜力的高、中、低；行列交叉为格位。
- 每个格位展示人数、组内占比与姓名列表；姓名最多展示 4 个，超出折叠为「等 N 人」。
- 格位可点击，打开该组该格位的人员名单抽屉；空格位不可点击并展示「0 人」。
- 整体卡下方展示图例：高 / 中 / 低标签与格位颜色说明。
- 分组卡按[业务规则.md §6](业务规则.md#6-分组规则)排序；特殊分组「未定级」「未设置岗位」「未分配部门」排在最后。
- 组头未评估人数大于零时展示提示标签，提示「N 人未评估，未计入格位」。
- 离职员工不出现在任何格位与人员名单中。

### 格位人员抽屉

- **打开方式**：点击整体卡或分组卡的格位。
- **标题**：`组名 · 匹配度等级 × 潜力等级`，如「大数据研发部 · 高匹配 × 高潜」。
- **内容**：该格位员工列表，展示姓名、工号、职位、职级、三级组织与「查看」；可点击查看打开员工明细抽屉。
- **空态**：该格位无员工时不打开抽屉（格位不可点击）。

### 导航关系

- 来源页：数据明细页签切换进入；菜单直接进入时默认展示数据明细。
- 去向页：无下级页面；格位人员与员工明细为抽屉。
- 返回行为：关闭抽屉回到汇总页，保留组织范围、分组维度、部门层级与滚动位置。
- 面包屑：首页 / 人资管理 / HR管理 / 人才盘点九宫格 / 九宫格汇总。
