# 人才盘点九宫格 · 数据模型

> 本文件为盘点周期、盘点明细、参考绩效、变更记录与九宫格汇总视图的字段口径；规则见 [业务规则.md](业务规则.md)。员工与组织事实引用员工资料与部门管理，职级引用[岗位管理 · 职级矩阵](../../../组织管理/岗位管理/文档/数据模型.md#职级矩阵)。

## 1. 盘点周期

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 周期标识 | 周期唯一标识 | 文本 | 是 | 系统内唯一，页面不展示 |
| 周期名称 | 周期展示名称 | 文本 | 是 | 如「2026半年度盘点」；同一组织范围内不重复 |
| 组织范围 | 周期覆盖的组织节点 | 文本 | 是 | 选择二级、三级或四级组织节点；名单取该节点及下级组织 |
| 开始日期 | 盘点区间开始日期 | 日期 | 是 | — |
| 结束日期 | 盘点区间结束日期 | 日期 | 是 | 不早于开始日期；同时作为基准日 |
| 参考绩效期 | 明细展示的绩效周期 | 文本 | 否 | 取绩效管理已生效周期，最多 4 期，按选择顺序展示 |
| 周期状态 | 周期当前状态 | 枚举 | 是 | 进行中、已锁定 |
| 创建人 | 创建周期的人员 | 文本 | 是 | HR 管理员 |
| 创建时间 | 周期创建时间 | 日期时间 | 是 | 系统写入 |
| 锁定人 | 执行锁定的人员 | 文本 | 否 | 已锁定时填写 |
| 锁定时间 | 周期锁定的时间 | 日期时间 | 否 | 已锁定时填写 |
| 盘点人数 | 名单内非离职员工数 | 数值 | 是 | 派生统计 |
| 已评估人数 | 人岗匹配度与潜力均已填的人数 | 数值 | 是 | 派生统计 |
| 未评估人数 | 盘点人数减已评估人数 | 数值 | 是 | 派生统计 |

## 2. 盘点明细

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 明细标识 | 明细唯一标识 | 文本 | 是 | 同一周期同一员工唯一 |
| 盘点周期 | 所属盘点周期 | 文本 | 是 | 引用盘点周期 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 姓名 | 员工姓名 | 文本 | 是 | 与员工资料一致 |
| 二级组织 | 员工所属中心 | 文本 | 是 | 名单生成或同步时的快照 |
| 三级组织 | 员工所属部门 | 文本 | 是 | 快照；按部门分组的默认层级 |
| 四级组织 | 员工所属小组 | 文本 | 否 | 快照；为空展示「—」 |
| 直接上级 | 员工直接上级姓名 | 文本 | 否 | 快照 |
| 职位 | 员工当前职位名称 | 文本 | 否 | 快照；按岗位分组的依据 |
| 职级 | 员工当前职级编码 | 文本 | 否 | 快照，如 P5、M6 |
| 职级档 | 由职级矩阵派生的展示档 | 文本 | 是 | 如 P9/M6、P6；无职级为「未定级」 |
| 工作地 | 员工办公地点 | 文本 | 否 | 快照 |
| 入职日期 | 员工首次入职日期 | 日期 | 是 | 快照 |
| 司龄 | 入职至基准日的时长 | 数值 | 是 | 派生，按年展示，不足一年保留一位小数 |
| 上一次晋升时间 | 最近一次晋升生效日期 | 日期 | 否 | 引用员工任职记录；无记录为空 |
| 现岗任职时长 | 当前职位任职至基准日的时长 | 数值 | 是 | 引用员工任职记录派生，按年展示 |
| 人员状态 | 员工在盘点时点的状态 | 枚举 | 是 | 正式、试用、离职；同步名单时更新 |
| 是否关键岗 | 是否关键岗位人员 | 枚举 | 否 | 是、否；人工判断 |
| 岗位职责 | 员工岗位职责说明 | 文本 | 否 | 不超过 500 字；默认取标准职位核心职责 |
| 人岗匹配度等级 | 人与岗位要求的匹配程度 | 枚举 | 否 | 高、中、低 |
| 人岗匹配度说明 | 匹配判断依据 | 文本 | 否 | 不超过 300 字 |
| 潜力等级 | 成长性与可承担更大职责的程度 | 枚举 | 否 | 高、中、低 |
| 潜力说明 | 潜力判断依据 | 文本 | 否 | 不超过 300 字 |
| 价值观认同度 | 价值观认同程度 | 枚举 | 否 | 高、中、低 |
| 是否重点培养对象 | 是否纳入重点培养 | 枚举 | 否 | 是、否、待观察 |
| 重点培养说明 | 培养方向与预期 | 文本 | 否 | 不超过 300 字 |
| 后续管理动作 | 盘点后的管理安排 | 文本 | 否 | 不超过 200 字；短语辅助输入 |
| 评估状态 | 是否完成评估 | 枚举 | 是 | 未评估、已评估；派生字段 |
| 最近更新人 | 最近一次保存评估的人员 | 文本 | 否 | 首次填写后记录 |
| 最近更新时间 | 最近一次保存评估的时间 | 日期时间 | 否 | 首次填写后记录 |

- 明细的快照字段只在生成名单与同步名单时更新，周期进行中的组织职位调整不自动回写已保存明细。
- 人员状态为离职的员工保留明细，但不计入盘点人数与九宫格汇总。

## 3. 参考绩效快照

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 明细标识 | 所属盘点明细 | 文本 | 是 | — |
| 考核周期 | 参考的绩效周期名称 | 文本 | 是 | 如 2025年Q4、2025年度；来自周期配置 |
| 最终等级 | 该周期绩效最终等级 | 枚举 | 否 | S、A、B、C、D；缺失展示「—」 |
| 排序 | 列展示顺序 | 数值 | 是 | 按周期配置的参考绩效期顺序 |

- 参考绩效只读引用绩效管理已生效结果；绩效结果更正后，未锁定周期的参考绩效按最新结果刷新，已锁定周期保留锁定时的结果。

## 4. 变更记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 记录标识 | 变更记录唯一标识 | 文本 | 是 | 只增不改不删 |
| 盘点周期 | 所属盘点周期 | 文本 | 是 | — |
| 员工 | 变更涉及员工 | 文本 | 是 | 引用盘点明细 |
| 变更字段 | 发生变更的字段 | 文本 | 是 | 一次记录一个字段 |
| 原值 | 变更前内容 | 文本 | 否 | 首次填写为空，不生成记录 |
| 新值 | 变更后内容 | 文本 | 是 | — |
| 变更原因 | 本次变更说明 | 文本 | 是 | 页面编辑必填；导入取本次导入说明 |
| 来源 | 变更发起方式 | 枚举 | 是 | 页面编辑、Excel 导入 |
| 操作人 | 执行变更的人员 | 文本 | 是 | — |
| 操作时间 | 变更发生时间 | 日期时间 | 是 | 系统写入，倒序展示 |

## 5. 周期操作记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 操作标识 | 操作记录唯一标识 | 文本 | 是 | 只增不改不删 |
| 盘点周期 | 所属盘点周期 | 文本 | 是 | — |
| 操作类型 | 本次操作类型 | 枚举 | 是 | 创建、同步名单、导入、锁定、取消锁定 |
| 操作说明 | 操作补充说明 | 文本 | 否 | 同步名单、导入、取消锁定记录影响说明 |
| 影响人数 | 本次操作影响的人数 | 数值 | 否 | 同步名单为新增与更新人数，导入为成功行数 |
| 操作人 | 执行操作的人员 | 文本 | 是 | — |
| 操作时间 | 操作发生时间 | 日期时间 | 是 | 倒序展示 |

## 6. 九宫格汇总视图

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 分组维度 | 当前汇总分组方式 | 枚举 | 是 | 职级档、岗位、部门 |
| 分组值 | 组名称 | 文本 | 是 | 职级档名、职位名称或部门名称；含特殊分组 |
| 盘点人数 | 组内非离职员工数 | 数值 | 是 | 含未评估 |
| 已评估人数 | 组内完成评估人数 | 数值 | 是 | — |
| 未评估人数 | 组内未完成评估人数 | 数值 | 是 | — |
| 格位编码 | 格位唯一标识 | 文本 | 是 | 「匹配度等级-潜力等级」，如「高-高」 |
| 格位人数 | 落入该格位的员工数 | 数值 | 是 | 仅已评估 |
| 格位占比 | 格位人数占组内已评估人数比例 | 数值 | 是 | 分母为 0 时为 0 |
| 姓名列表 | 格位内员工姓名 | 文本 | 是 | 按姓名排序 |

- 汇总视图为派生结果，不单独存储；明细、名单或评估变化后重新计算。

## 7. 实体关系

- 盘点周期与盘点明细为一对多：一个周期包含名单内的多条明细，同期同员工仅一条。
- 盘点明细与参考绩效快照为一对多：一条明细最多展示 4 期参考绩效。
- 盘点明细与变更记录为一对多：明细评估字段的每次修改生成一条记录。
- 盘点周期与周期操作记录为一对多：创建、同步名单、导入、锁定与取消锁定各生成一条记录。
- 九宫格汇总视图由盘点明细按分组维度派生，不单独存储。
- 盘点明细与员工为一对多：同一员工可参与多个盘点周期。

| 枚举 | 取值 |
|---|---|
| 周期状态 | 进行中、已锁定 |
| 评估状态 | 未评估、已评估 |
| 匹配度与潜力等级 | 高、中、低 |
| 价值观认同度 | 高、中、低 |
| 是否关键岗 | 是、否 |
| 是否重点培养对象 | 是、否、待观察 |
| 人员状态 | 正式、试用、离职 |
| 变更来源 | 页面编辑、Excel 导入 |
| 周期操作类型 | 创建、同步名单、导入、锁定、取消锁定 |
| 分组维度 | 职级档、岗位、部门 |
| 部门层级 | 二级、三级、四级 |
| 特殊分组 | 未定级、未设置岗位、未分配部门 |
