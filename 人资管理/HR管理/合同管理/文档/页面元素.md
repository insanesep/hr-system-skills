# 合同管理 · 页面元素

> 字段口径见 [数据模型.md](数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端；合同台账与合同详情在同一路由下互联，签订、续签与解除以抽屉或弹层承载。原型见 [原型图/web/contract-management.html](../原型图/web/contract-management.html)。

## 合同台账

### 页面结构

- **页头**：面包屑「首页 / 人资管理 / HR管理 / 合同管理」；页头右侧「新建合同」「批量提醒」「导出」。
- **统计卡**：待签订、待生效、生效中、即将到期、已到期 / 已续签、已解除；数字按当前用户数据权限统计。
- **页签**：待签订、待生效、生效中、即将到期、已到期 / 已续签、已解除。
- **基础筛选**：员工姓名 / 工号、组织、合同类型、合同状态、到期日期区间、合同负责人。
- **高级筛选**：签订日期、续签来源合同、电子签状态、是否有附件、是否已提醒、解除原因。
- **表格列**：合同编号、姓名、工号、组织、职位、合同类型、签订日期、生效日期、到期日期、合同状态、负责人、操作。
- **行内操作**：查看详情、签订、续签、解除、作废 / 删除；按状态与权限展示。
- **批量操作**：批量提醒续签、批量导出；已到期与已解除记录只读。

### 交互

- 待签订按创建时间升序；待生效按生效日期升序；生效中按到期日期升序；即将到期按到期日期升序；已到期按到期日期倒序；已解除按解除日期倒序。
- 到期日期在 30 天内的生效中记录展示「即将到期」标签；已到期未续签展示警示标签。
- 筛选条件变更即时查询；切换页签保留筛选并回到第一页。
- 空态展示「暂无合同记录」；加载失败展示失败提示与「重试」。

## 合同详情

### 页面结构

- **页头**：合同编号、员工姓名、当前状态；右侧操作按状态展示「签订」「续签」「解除」「作废 / 删除」「导出」。
- **概览卡**：员工、组织、职位、合同类型、签订日期、生效日期、到期日期、合同负责人、续签状态。
- **页签**：合同信息、签订附件、续签记录、解除记录、变更记录、操作记录。
- **合同信息**：展示 [数据模型.md §合同记录](数据模型.md#1-合同记录) 的全部字段；状态与到期提醒在顶部展示。
- **签订附件**：附件名称、类型、大小、上传人、上传日期与预览；只读，不提供下载。
- **续签记录**：展示原合同与续签合同编号、生效日期、到期日期、状态；可跳转续签合同详情。
- **解除记录**：展示解除日期、解除原因、说明、解除待办状态、关联离职单与操作人。
- **变更记录**：按时间倒序展示变更类型、字段、原值、新值、原因、操作人与时间。
- **操作记录**：按时间倒序展示创建、签订、续签、解除、提醒、作废与导出。

<a id="contract-sign"></a>

## 签订合同

- **抽屉结构**：员工与组织只读；合同类型、生效日期、到期日期、签订日期、合同负责人、试用期约定、电子签编号、附件上传与备注。
- **校验**：固定期限与任务期限必须填写到期日期；到期日期晚于生效日期；签订日期不得晚于生效日期；至少上传一份签订附件；同一员工不得存在另一份生效中合同。
- **底部**：取消、保存草稿、确认签订。
- **结果**：按生效日期进入待生效或生效中；写入合同签订事件；刷新工作台待办。

<a id="contract-renew-terminate"></a>

## 续签与解除

- **续签抽屉**：原合同信息只读；新合同类型、生效日期（不得早于原合同到期次日）、到期日期、签订日期、附件与备注；保存后原合同标记已续签，新合同按生效日期进入待生效或生效中。
- **解除弹层**：解除日期、解除原因、解除说明、是否关联离职单；解除日期不得早于合同生效日期；确认后合同状态为已解除，写入合同解除事件。
- **离职联动**：离职管理确认离职后生成合同解除待办，详情展示「处理合同解除」入口，带出离职单号与实际离职日期。
- **作废 / 删除**：仅待签订合同可操作，须填写原因；已签订合同只展示解除入口。

## 到期提醒

- 合同到期前 30 天与 7 天由系统生成提醒，工作台与合同台账展示；批量提醒向合同负责人发送。
- 无固定期限合同不进入到期提醒；已续签与已解除合同不提醒。
- 到期未续签自动转为已到期；不自动续签，不自动解除。

## 空态与权限

- 合同台账无数据展示「暂无合同记录」；合同附件为空展示「暂无附件」；续签记录为空展示「暂无续签记录」。
- 加载失败在对应区块展示失败提示与「重试」，重试沿用原筛选条件。
- 菜单权限 `MENU:HR:CONTRACT`；新建、编辑、签订、续签、解除、作废、提醒、导出与附件预览分别按按钮权限展示。
- 数据权限：HR 管理员全量；HRBP 本中心；中心负责人本中心只读；部门负责人本部门只读。
