# 合同管理 · 数据模型

> 本文件为合同记录、合同变更与提醒的字段口径；规则见 [业务规则.md](业务规则.md)。合同与员工、续签来源合同、离职单与成长事件关联。

<a id="1-合同记录"></a>

## 1. 合同记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 合同编号 | 合同唯一标识 | 文本 | 是 | 格式 HT-年份-员工工号-序号；全局唯一，创建后不可修改 |
| 员工 | 合同所属员工 | 文本 | 是 | 引用员工资料 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 组织路径 | 合同签订时组织快照 | 文本 | 是 | 一至五级组织 |
| 职位 | 合同签订时职位快照 | 文本 | 是 | 引用员工资料当前任职 |
| 职级 | 合同签订时职级快照 | 文本 | 否 | 如 P5 |
| 合同类型 | 合同期限类型 | 枚举 | 是 | 固定期限、无固定期限、以完成一定工作任务为期限 |
| 签订日期 | 双方签订日期 | 日期 | 签订时必填 | 不得晚于生效日期；补签须备注并审批 |
| 生效日期 | 合同开始日期 | 日期 | 是 | 不得早于入职日期；可晚于签订日期 |
| 到期日期 | 合同结束日期 | 日期 | 否 | 固定期限与任务期限必填且晚于生效日期；无固定期限为空 |
| 试用期约定 | 合同中的试用期说明 | 文本 | 否 | 记录约定，不参与考勤与薪酬计算 |
| 合同状态 | 合同当前状态 | 枚举 | 是 | 待签订、待生效、生效中、已续签、已到期、已解除 |
| 续签状态 | 当前合同的续签情况 | 枚举 | 否 | 未续签、已续签、待生效续签；派生字段 |
| 合同负责人 | 负责签订、续签与解除的 HR | 文本 | 是 | — |
| 来源类型 | 合同生成来源 | 枚举 | 是 | 入职生成、手工补录、续签生成、再入职生成 |
| 原合同编号 | 续签来源合同 | 文本 | 否 | 续签合同时必填，引用已生效或已到期合同 |
| 电子签编号 | 电子签平台合同编号 | 文本 | 否 | 仅记录编号，不接入平台 |
| 电子签状态 | 电子签办理状态 | 枚举 | 是 | 未使用、已发起、已完成、已失效；默认未使用 |
| 签订附件 | 签订扫描件或电子签文件 | 文本 | 已签订时必填 | 已签订合同至少一份；只在线预览 |
| 解除日期 | 合同解除日期 | 日期 | 否 | 状态为已解除时必填，不得早于生效日期 |
| 解除待办状态 | 离职触发但未完成的解除任务 | 枚举 | 否 | 未办理、办理中、已完成、不适用 |
| 解除原因 | 解除原因分类 | 枚举 | 否 | 员工离职、协商解除、公司单方解除、合同到期不续签、其他 |
| 解除说明 | 解除原因补充 | 文本 | 否 | 解除时必填；其他原因须说明 |
| 关联离职单 | 离职管理生成的离职单 | 文本 | 否 | 员工离职解除时关联 |
| 作废原因 | 待签订合同作废原因 | 文本 | 否 | 作废或删除时必填 |
| 备注 | 补充说明 | 文本 | 否 | 不超过 500 字 |
| 创建人 | 创建人 | 文本 | 是 | — |
| 创建时间 | 创建时间 | 日期时间 | 是 | — |
| 更新时间 | 最近更新时间 | 日期时间 | 是 | — |

## 2. 合同变更记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 变更记录标识 | 变更记录唯一标识 | 文本 | 是 | 只增不改不删 |
| 合同编号 | 所属合同 | 文本 | 是 | — |
| 变更类型 | 变更分类 | 枚举 | 是 | 编辑、签订、续签、解除、作废、补签、更正 |

| 新值 | 变更后内容 | 文本 | 是 | — |

| 操作人 | 操作人员 | 文本 | 是 | — |

## 3. 合同提醒

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 提醒标识 | 提醒唯一标识 | 文本 | 是 | 从属于合同 |
| 合同编号 | 所属合同 | 文本 | 是 | — |
| 提醒类型 | 提醒节点 | 枚举 | 是 | 到期前 30 天、到期前 7 天、已到期、待签订超期 |
| 提醒对象 | 接收提醒的负责人 | 文本 | 是 | 合同负责人或 HRBP |
| 提醒状态 | 提醒处理状态 | 枚举 | 是 | 未提醒、已提醒、已忽略 |
| 提醒时间 | 最近提醒时间 | 日期时间 | 否 | 已提醒时填写 |
| 操作人 | 执行提醒的人员 | 文本 | 否 | 系统或 HR |

## 4. 实体关系

- 员工与合同记录为一对多：一名员工可有多份历史合同与续签合同，同一时点最多一份生效中合同。
- 合同记录与续签来源合同为多对一或一对多：原合同可被一份续签合同关联，续签合同只关联一份原合同。
- 合同记录与变更记录为一对多：每次状态或字段变更生成一条记录。
- 合同记录与提醒为一对多：30 天、7 天与到期提醒分别记录。
- 合同记录与离职单为一对零或一：离职解除时关联离职单。
- 合同记录与成长事件为一对零或多：签订、续签、解除分别写入事件。
