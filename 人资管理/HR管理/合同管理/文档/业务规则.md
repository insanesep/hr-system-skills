# 合同管理 · 业务规则

> 本文件描述合同台账、签订、续签、到期与解除的规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。合同状态与签订结果回写员工资料、员工成长记录、离职管理与工作台。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 合同记录 | 一名员工一份劳动合同的台账记录，含类型、起止日期、签订日期、附件与状态 |
| 待签订 | 入职确认或手工补录生成、尚未完成签订的合同 |
| 待生效 | 已签订但生效日期未到的合同；续签合同常见 |
| 生效中 | 当前日期在合同生效日期与到期日期之间的合同 |
| 即将到期 | 生效中且到期日期在 30 天内的合同，为派生筛选，不单独存储状态 |
| 已续签 | 已被续签合同替代的原合同 |
| 已到期 | 到期日期已过且未续签的合同；无固定期限合同不进入已到期 |
| 已解除 | 因离职、协商或其他原因提前终止的合同 |
| 续签来源合同 | 续签合同关联的原合同 |
| 合同负责人 | 负责跟进签订、续签与解除的 HR |

## 2. 功能边界

- 本功能承载合同记录、签订、续签、到期、解除与合同提醒。
- 不做：入职办理、招聘流程、薪酬核算、社保公积金办理、劳动合同法务审查、电子签平台接入与合同模板设计。
- 员工资料合同页签只读引用本功能；离职管理发起解除待办，本功能记录解除结果。
- 合同不改变员工组织、职位、职级与编制；合同类型与期限由 HR 按公司制度维护。

## 3. 合同记录创建

- 入职管理确认入职后，系统按入职单生成待签订合同，带出员工、组织、职位、入职日期、合同起始日期与合同负责人；合同类型默认固定期限，HR 在签订前调整。
- 存量员工可由 HR 手工补录当前或历史合同；补录须填写合同编号、类型、起止日期、签订日期与附件说明。
- 续签由原合同发起，创建新合同并关联原合同；原合同标记为已续签。
- 离职管理确认离职后生成合同解除待办；合同管理完成解除后回写离职单合同解除状态。
- 合同记录创建后不修改员工组织、职位、职级与编制；员工信息为创建时快照。

## 4. 合同编号与唯一性

- 合同编号全局唯一，格式为「HT-年份-员工工号-序号」，创建后不可修改。
- 同一员工同一时点只允许一份生效中合同；存在待生效合同时，原合同到期后自动转为已续签。
- 同一员工合同起止日期不得重叠；续签合同生效日期不得早于原合同到期次日。
- 无固定期限合同到期日期为空，不参与到期提醒与已到期判定。
- 合同附件可上传多份，签订附件为必备；附件只在线预览，不提供下载与分享。
- 合同签订后不可删除；待签订合同可作废或删除，须记录原因。

## 5. 状态机

- 合同状态：待签订、待生效、生效中、已续签、已到期、已解除。
- 待签订：由入职确认或手工补录生成，尚未签订；可编辑、作废或删除。
- 待生效：已签订但生效日期晚于今天；到生效日期自动转为生效中。
- 生效中：当前日期在生效日期与到期日期之间；可续签或解除。
- 已续签：被续签合同替代；只读，保留原合同与附件。
- 已到期：到期日期早于今天且未续签；只读，可补签续签合同但原合同仍为已到期。
- 已解除：离职确认或人工解除；只读，保留解除日期与原因。
- 状态只向前推进，不回退；签订信息更正通过合同变更记录完成，不改变历史状态。

## 6. 签订规则

- 签订须填写合同类型、生效日期、到期日期、签订日期与合同负责人；固定期限与以完成一定工作任务为期限的合同必须有到期日期。
- 签订日期不得晚于生效日期；补签须在备注中说明原因，并由 HRBP 审批确认。
- 合同类型为固定期限、无固定期限或以完成一定工作任务为期限；类型变更须重新签订，不直接修改已生效合同。
- 签订成功后按生效日期确定状态：生效日期不晚于今天为生效中，晚于今天为待生效。
- 合同附件至少上传一份签订扫描件或电子签文件；电子签编号选填，仅记录平台编号，不接入电子签平台。
- 同一员工存在生效中合同时，新签订合同须为续签或先解除原合同，不得直接并存。

## 7. 续签与到期

- 续签由原合同发起，新合同必须关联原合同；原合同状态变为已续签，新合同按生效日期变为待生效或生效中。
- 续签合同生效日期不得早于原合同到期次日；允许提前创建，待生效期间原合同继续生效。
- 合同到期前 30 天与 7 天生成续签提醒，提醒合同负责人；到期未续签自动转为已到期，不自动续签。
- 无固定期限合同不生成到期提醒；以完成一定工作任务为期限的合同按项目结束日期到期。
- 已到期合同可补签续签合同，但原合同状态保持已到期；补签须记录原因。

## 8. 解除规则

- 解除须填写解除日期、解除原因与说明；解除日期不得早于合同生效日期。
- 离职管理确认离职后生成合同解除待办，合同保持生效中并标记解除待办状态；合同管理完成解除后回写离职单合同解除状态并转为已解除，解除日期取离职实际离职日期。
- 协商解除、公司单方解除与其他解除由 HR 手工发起，须关联离职单或说明依据。
- 已解除合同只读；确需更正由 HRBP 发起合同变更记录，不改变原状态。
- 合同解除不自动回减编制、不自动改变员工在职状态；离职管理负责员工状态与编制回写。

## 9. 联动规则

- **员工资料**：合同页签只读展示合同编号、类型、签订日期、生效日期、到期日期与合同状态；合同状态枚举与本功能一致。
- **员工成长记录**：签订写入合同签订事件，续签写入合同续签事件，解除写入合同解除事件；作废与删除不写入成长记录。
- **离职管理**：确认离职后生成合同解除待办，合同管理回写合同解除状态；离职单只读引用合同结果。
- **工作台**：待签订、即将到期与待解除合同进入工作台待办与预警；合同到期提醒按 30/7 天窗口。
- **入职管理**：确认入职后生成待签订合同；入职单撤销时未签订的合同同步作废或删除。

## 10. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 合同状态 | 待签订、待生效、生效中、已续签、已到期、已解除 | 待签订与待生效为警示标签，生效中为主色标签，已续签与已到期为提示标签，已解除为中性 |
| 合同类型 | 固定期限、无固定期限、以完成一定工作任务为期限 | 文本 |
| 续签状态 | 未续签、已续签、待生效续签 | 文本 |
| 解除原因 | 员工离职、协商解除、公司单方解除、合同到期不续签、其他 | 文本；其他补充说明 |
| 电子签状态 | 未使用、已发起、已完成、已失效 | 文本；未接入平台时默认未使用 |
| 提醒状态 | 未提醒、已提醒、已忽略 | 文本 |

## 11. 权限编码与数据范围

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:CONTRACT` | 未授权不展示菜单 |
| 新建合同 | `BTN:HR_CONTRACT:CREATE` | 未授权不展示新建入口 |
| 编辑待签订合同 | `BTN:HR_CONTRACT:EDIT` | 仅待签订可编辑 |
| 签订合同 | `BTN:HR_CONTRACT:SIGN` | 未授权不展示签订入口 |
| 续签合同 | `BTN:HR_CONTRACT:RENEW` | 未授权不展示续签入口 |
| 解除合同 | `BTN:HR_CONTRACT:TERMINATE` | 未授权不展示解除入口 |
| 作废 / 删除 | `BTN:HR_CONTRACT:VOID` | 仅待签订且未签订合同 |
| 批量提醒 | `BTN:HR_CONTRACT:REMIND` | 未授权不展示提醒入口 |
| 导出 | `BTN:HR_CONTRACT:EXPORT` | 未授权不展示导出按钮 |
| 敏感附件预览 | `BTN:HR_CONTRACT:ATTACHMENT` | 未授权不展示预览入口 |

- 数据权限：HR 管理员全量；HRBP 本中心；中心负责人本中心只读；部门负责人本部门只读；员工本人不提供合同台账入口。
- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。
