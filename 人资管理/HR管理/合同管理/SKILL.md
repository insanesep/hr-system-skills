# 合同管理

## 模块概述

人资管理 → HR管理下的劳动合同管理入口：以「合同记录」为主线，承接入职确认生成的待签订合同、存量员工补录与续签；完成签订后进入生效中，合同到期前提醒续签，离职确认或人工解除时终止合同。列表以「待签订 / 待生效 / 生效中 / 即将到期 / 已到期/已续签 / 已解除」六个页签组织台账，支持按组织、合同类型、合同状态、到期日期与负责人筛选，批量提醒续签、导出合同台账；单人详情集中呈现合同信息、签订附件、续签记录、解除记录与操作记录。

本功能只承载合同台账、签订、续签、到期与解除，不承载入职办理、招聘流程、薪酬核算、社保公积金办理、劳动合同法务审查与电子签平台本身。

## 端

- **web**：人资管理 → HR管理 → 合同管理，仅桌面端管理后台，不提供 App 入口

## When to Use

- 入职确认后跟进待签订合同，完善合同类型、起止日期与附件
- 为存量员工补录历史合同或当前合同
- 合同到期前发起续签，创建新合同并关联原合同
- 员工离职或协商解除时记录合同解除
- 查看员工合同台账、即将到期合同、已到期与已解除合同
- 批量提醒续签、导出合同台账或复核合同状态与权限编码

## 合同台账

<a id="合同台账"></a>

- 页签固定为待签订、待生效、生效中、即将到期、已到期/已续签、已解除；即将到期取生效中且到期日在 30 天内的合同，不单独存储状态。
- 基础筛选：员工姓名 / 工号、组织、合同类型、合同状态、到期日期区间、合同负责人。
- 高级筛选：签订日期、续签来源合同、电子签状态、是否有附件、是否已提醒、解除原因。
- 统计卡展示待签订、待生效、生效中、即将到期、已到期/已续签与已解除数量；数字按当前用户数据权限统计。
- 支持批量提醒续签、导出当前筛选结果；已到期与已解除记录只读，续签与解除入口按状态展示。

## 签订合同

<a id="签订合同"></a>

- 待签订合同由入职确认生成，带出员工、组织、职位、入职日期与合同起始日期；合同类型默认固定期限，HR 可在签订前调整。
- 签订须填写合同类型、生效日期、到期日期（无固定期限可为空）、签订日期与合同负责人；固定期限合同到期日期必填且晚于生效日期。
- 合同附件为签订扫描件或电子签文件，支持在线预览；电子签编号选填，仅记录平台编号，不接入电子签平台。
- 签订成功后合同状态按生效日期变为待生效或生效中；同一员工同一时点仅允许一份生效中合同。

## 续签与解除

<a id="续签与解除"></a>

- 续签以原合同为基础创建新合同，原合同标记为已续签，新合同关联原合同；新合同生效日期不得早于原合同到期次日，可提前创建为待生效。
- 续签合同可沿用或调整合同类型、期限与附件；续签不改变员工组织、职位、职级与编制。
- 合同到期前 30 天与 7 天提醒合同负责人；到期未续签自动转为已到期，不自动续签。
- 解除须填写解除日期、解除原因与说明；离职确认后由离职管理发起合同解除，合同管理记录解除并回写员工成长记录。
- 待签订合同可作废或删除；作废须记录原因，已签订合同不可删除，只能解除或到期。

## 影响范围

- **员工资料**：合同页签只读展示合同编号、类型、签订日期、生效日期、到期日期与合同状态。
- **员工成长记录**：签订写入合同签订事件，续签写入合同续签事件，解除写入合同解除事件。
- **离职管理**：确认离职后生成合同解除待办，合同管理完成解除后回写离职单合同解除状态。
- **工作台**：待签订、即将到期与解除待办进入工作台待办与预警。

## Tips

- 合同由入职确认生成待签订记录，不在本功能办理入职；存量员工可手工补录
- 固定期限合同必须有到期日期；无固定期限合同到期日期为空，不进入到期提醒
- 同一员工同一时点只允许一份生效中合同；续签合同与原合同关联，旧合同标记已续签
- 合同到期不自动续签，只提醒；解除须记录原因，离职确认后的解除以离职单为准
- 合同附件只在线预览，不提供下载与分享；电子签平台不接入，仅记录电子签编号
- 规则查找：合同状态与联动看 [文档/业务规则.md](文档/业务规则.md)，字段口径看 [文档/数据模型.md](文档/数据模型.md)，页面元素看 [文档/页面元素.md](文档/页面元素.md)
