# 绩效管理 · 数据模型

> 本文件为绩效管理分组的共享实体与字段口径。一个考核周期对应一份考核名单，名单内每名员工对应一张考核表；考核表由多个目标与评价项组成，目标与考核表均可产生变更记录。参数值不在本文件展开，见[绩效参数配置数据模型](../绩效参数配置/文档/数据模型.md)；规则见 [业务规则.md](业务规则.md)。

## 1. 考核周期

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 周期标识 | 周期的唯一标识 | 文本 | 是 | 系统内唯一，页面不展示 |
| 周期名称 | 周期的展示名称 | 文本 | 是 | 如「2026年Q3绩效—技术中心」 |
| 周期类型 | 周期的考核类型 | 枚举 | 是 | 季度、年度 |
| 所属中心 | 周期覆盖的二级组织 | 文本 | 是 | 只读引用组织架构 |
| 开始日期 | 考核区间的第一天 | 日期 | 是 | 与结束日期构成考核区间 |
| 结束日期 | 考核区间的最后一天 | 日期 | 是 | — |
| 目标截止日期 | 目标须确认生效的日期 | 日期 | 是 | 到期后不再新增目标 |
| 自评截止日期 | 员工自评截止日期 | 日期 | 是 | 逾期未提交在评价列表标识 |
| 上级评价截止日期 | 直接上级评价截止日期 | 日期 | 是 | — |
| 团队通晒日期 | 团队层级通晒会日期 | 日期 | 否 | 未安排时通晒功能不展示团队阶段 |
| 中心通晒日期 | 中心层级通晒会日期 | 日期 | 否 | 未安排时无法确认结果 |
| 当前阶段 | 周期所处阶段 | 枚举 | 是 | 目标设定、评价中、通晒中、已生效、已归档 |

## 2. 考核名单

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 名单标识 | 名单记录的唯一标识 | 文本 | 是 | 从属于周期 |
| 周期 | 所属考核周期 | 文本 | 是 | — |
| 员工 | 被考核员工 | 文本 | 是 | 同一周期内不重复 |
| 二级组织 | 员工所属中心 | 文本 | 是 | 通晒范围与统计维度 |
| 三级组织 | 员工所属部门 | 文本 | 是 | 部门维度统计依据 |
| 四级组织 | 员工所属组 | 文本 | 是 | 团队通晒范围依据 |
| 职位 | 员工当前职位 | 文本 | 是 | 只读引用员工档案 |
| 岗位序列 | 员工所属岗位序列 | 文本 | 是 | 只读引用员工档案与岗位管理；序列维度统计依据 |
| 职级 | 员工职级 | 文本 | 是 | 如 P3、P7；层级统计按职级区间归并 |
| 直线经理 | 员工直接上级 | 文本 | 是 | 评价与团队通晒的责任人 |
| 工作地点 | 员工办公地点 | 文本 | 否 | 通晒明细展示 |
| 入职日期 | 员工首次入职日期 | 日期 | 是 | 只读引用员工档案 |
| 转正日期 | 员工转正日期 | 日期 | 否 | 未转正展示「—」 |
| 司龄 | 自入职至周期结束的时长 | 数值 | 是 | 派生字段，用于司龄段统计 |
| 人员状态 | 周期结束时的人员状态 | 枚举 | 是 | 正式、试用、离职 |
| 是否纳入 | 是否参与本周期考核 | 布尔 | 是 | 不纳入不生成考核表 |
| 不纳入说明 | 不纳入的原因 | 文本 | 否 | 是否纳入为否时必填 |

## 3. 绩效目标

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 目标标识 | 目标的唯一标识 | 文本 | 是 | — |
| 周期 | 所属考核周期 | 文本 | 是 | — |
| 主体类型 | 目标的承担层级 | 枚举 | 是 | 个人、组、部门 |
| 主体标识 | 承担目标的员工或组织 | 文本 | 是 | 个人对应员工，组与部门对应组织节点 |
| 标题 | 目标名称 | 文本 | 是 | 用于考核表「名称」列 |
| 指标描述 | 目标要达成的业务结果 | 文本 | 是 | 用于考核表「指标描述」列 |
| 衡量标准 | 判定目标完成的量化或事实标准 | 文本 | 是 | 可分条填写，用于考核表「衡量标准」列 |
| 权重 | 目标在主体内的占比 | 数值 | 是 | 整数百分比，取值区间取本周期参数快照，同一主体同周期合计为 100% |
| 可见范围 | 目标的可见人群 | 枚举 | 是 | 选项与默认值取本周期参数快照 |
| 进度 | 目标的当前完成进度 | 数值 | 否 | 取值范围取本周期参数快照，仅供参考，不参与评分 |
| 对齐目标 | 本目标对齐的上级目标 | 文本 | 否 | 仅可关联已生效的组或部门目标 |
| 状态 | 目标当前状态 | 枚举 | 是 | 草稿、待确认、已生效、已归档 |
| 当前版本号 | 已生效目标的最新版本 | 数值 | 是 | 首次生效为 1，每次重新生效递增 |
| 创建人 | 目标拟定人 | 文本 | 是 | — |
| 更新时间 | 目标最近一次变更时间 | 日期时间 | 是 | 列表排序依据 |

## 4. 目标版本

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 版本标识 | 版本的唯一标识 | 文本 | 是 | 从属于目标 |
| 目标 | 所属绩效目标 | 文本 | 是 | — |
| 版本号 | 版本序号 | 数值 | 是 | 同一目标内递增 |
| 版本快照 | 生效时的目标内容 | 文本 | 是 | 记录标题、指标描述、衡量标准、权重、可见范围 |
| 变更说明 | 本次变更的原因 | 文本 | 是 | 必填 |
| 提交人 | 发起变更的人员 | 文本 | 是 | — |
| 提交时间 | 变更提交时间 | 日期时间 | 是 | — |
| 生效时间 | 版本生效时间 | 日期时间 | 是 | 确认通过的时间 |

## 5. 考核表

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 考核表标识 | 考核表的唯一标识 | 文本 | 是 | — |
| 周期 | 所属考核周期 | 文本 | 是 | — |
| 员工 | 被考核员工 | 文本 | 是 | 与考核名单一致 |
| 部门链路 | 员工所属中心 / 部门 / 组 | 文本 | 是 | 通晒与统计展示 |
| 职级 | 员工职级 | 文本 | 是 | 层级统计依据 |
| 直线经理 | 直接上级 | 文本 | 是 | 上级评价责任人 |
| 目标数 | 参与评价的目标数量 | 数值 | 是 | 只统计已生效目标 |
| 自评总分 | 员工自评的加权总分 | 数值 | 否 | 未自评时为空 |
| 上级总分 | 上级评分的加权总分 | 数值 | 否 | 小数位取本周期参数快照 |
| 建议等级 | 按上级总分映射的等级 | 枚举 | 否 | S、A、B、C、D；按本周期参数快照的分数下限映射 |
| 最终等级 | 通晒确认后生效的等级 | 枚举 | 否 | S、A、B、C、D |
| 绩效系数 | 与最终等级绑定的系数 | 数值 | 否 | 取本周期参数快照中最终等级对应的系数 |
| 后续计划 | 对员工下一阶段的安排 | 文本 | 否 | 通晒维护，快捷短语取本周期参数快照 |
| 非 B 原因 | 最终等级非 B 时的客观说明 | 文本 | 否 | 最终等级为 S、A、C、D 时必填 |
| 状态 | 考核表当前状态 | 枚举 | 是 | 未开始、自评中、待上级评价、待通晒、已校准、已生效 |
| 自评提交时间 | 员工提交自评的时间 | 日期时间 | 否 | — |
| 上级提交时间 | 上级提交评价的时间 | 日期时间 | 否 | — |
| 通晒确认时间 | 中心通晒确认的时间 | 日期时间 | 否 | — |

## 6. 评价项

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 评价项标识 | 评价项的唯一标识 | 文本 | 是 | 从属于考核表 |
| 考核表 | 所属考核表 | 文本 | 是 | — |
| 目标 | 对应的绩效目标 | 文本 | 是 | — |
| 权重 | 目标的权重快照 | 数值 | 是 | 取目标生效版本的权重 |
| 自评分 | 员工自评分数 | 数值 | 否 | 评分范围与精度取本周期参数快照 |
| 自评说明 | 员工补充的产出与证据 | 文本 | 否 | 必填性取本周期参数快照 |
| 上级评分 | 直接上级评分 | 数值 | 否 | 评分范围与精度取本周期参数快照 |
| 上级评语 | 直接上级的评分依据 | 文本 | 否 | 必填性取本周期参数快照 |

## 7. 变更记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 记录标识 | 变更记录的唯一标识 | 文本 | 是 | 只增不改不删 |
| 对象类型 | 变更对象类别 | 枚举 | 是 | 目标、考核表 |
| 对象标识 | 变更对象标识 | 文本 | 是 | 指向目标或考核表 |
| 变更字段 | 发生变化的字段名称 | 文本 | 是 | 一次记录一个字段 |
| 原值 | 变更前的值 | 文本 | 否 | 首次设置时为空 |
| 新值 | 变更后的值 | 文本 | 是 | — |
| 变更原因 | 本次变更的说明 | 文本 | 是 | 不可为空 |
| 操作人 | 执行变更的人员 | 文本 | 是 | — |
| 操作时间 | 变更发生时间 | 日期时间 | 是 | 倒序展示 |
| 来源页面 | 变更发生的功能 | 枚举 | 是 | 绩效目标管理、绩效评价、绩效通晒 |

## 8. 分布汇总（派生视图）

| 字段名 | 业务含义 | 取值规则 |
|---|---|---|
| 统计维度 | 分组方式 | 中心、部门、职级层级、序列、司龄段 |
| 维度值 | 具体分组 | 如部门名称、职级层级档位或司龄段档位；具体分档取本周期参数快照 |
| 等级 | 绩效等级 | S、A、B、C、D |
| 人数 | 该等级人数 | 仅统计已纳入且已有最终等级的考核表 |
| 占比 | 该等级占该维度总人数的比例 | 小数位取本周期参数快照，分母不含「/」与不纳入人员 |
| 基线 | 该等级的配置基线 | 引用本周期参数快照中的基线参数 |
| 偏差状态 | 与基线的比较结果 | 高于基线、低于基线、偏离参考、正常 |
