# 绩效管理 · 共享业务规则

> 本文件是绩效管理分组内跨功能的共享规则真源：周期与阶段、角色、考核名单、参数消费机制、留痕与权限。评级与系数、比例基线、目标与评价规则、通晒短语等参数值见[绩效参数配置](../绩效参数配置/文档/业务规则.md)，本文件不复制参数值。字段口径见 [数据模型.md](数据模型.md)。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 考核周期 | 一次绩效考核的时间范围与阶段配置，以季度为主，年度周期复用同一流程 |
| 考核名单 | 周期启动时确定的参与考核人员范围，决定是否生成考核表 |
| 考核主体 | 承担绩效目标与考核结果的层级单位：个人、组（四级组织）、部门（三级组织） |
| 绩效目标 | 考核周期内为考核主体设定的 OKR，含指标描述、衡量标准与权重 |
| 考核表 | 一名员工在一个周期内的目标、评分、总分与最终结果的集合 |
| 团队通晒 | 以直接上级（TL）为组织者、在其所辖团队范围内校准绩效等级的会议环节 |
| 中心通晒 | 以中心为组织者、在中心全量范围内校准并确认绩效等级的会议环节 |
| 最终等级 | 中心通晒确认后生效的 S / A / B / C / D 等级 |
| 绩效系数 | 与最终等级绑定的系数值，供下游薪酬与激励参考 |

## 2. 角色与职责

| 角色 | 数据范围 | 职责 |
|---|---|---|
| 被考核员工 | 本人 | 拟定个人目标、更新目标进度、提交自评、查看本人结果 |
| 直接上级 | 直接下级 | 确认或退回下辖目标、逐项评分与评语、主持团队通晒、维护后续计划与非 B 原因 |
| 部门负责人 | 本部门（三级组织） | 查看本部门目标与结果、参与部门层级通晒、核对部门分布 |
| 中心负责人 | 本中心（二级组织） | 主持中心通晒、调整等级、确认结果生效 |
| HRBP | 本中心 | 配置周期、生成与调整考核名单、催办、查看全中心、发起结果更正 |
| 系统管理员 | 全局 | 维护并发布绩效参数版本，覆盖周期与名单、目标、评价、评级与系数、分布基线、通晒规则 |

同一自然人可以同时具备多个角色，以实际数据范围交集为准；直接上级不可评价本人。

## 3. 考核周期与阶段

- 周期类型为季度或年度；年度周期沿用同一目标、评价与通晒流程。
- 周期阶段依次为：目标设定 → 目标已生效 → 自评中 → 上级评价中 → 团队通晒 → 中心通晒 → 结果已生效 → 已归档。
- 阶段由周期配置的时间节点驱动：目标截止、自评截止、上级评价截止、团队通晒日期、中心通晒日期。
- 阶段只向前推进，不回退；已提交内容的修正通过评价功能的退回或通晒中的变更完成，并留痕。
- 周期归档后全部数据只读，仅支持查询与导出。

## 4. 考核名单

- 周期启动时由 HRBP 按组织范围生成考核名单，名单内员工生成考核表。
- 试用期员工、协商离职人员与不纳入原因的纳入规则取[绩效参数配置](../绩效参数配置/文档/业务规则.md)的周期与名单参数；名单本身仍由 HRBP 维护。
- 名单中的「不纳入」情形按参数配置的原因字典选择；不纳入人员不生成考核表，台账展示「/」，不计入任何分布统计。
- 名单调整截止取参数配置；截止后名单只读，已提交评价的员工移出名单需 HRBP 确认并留痕。

## 5. 目标、评价与通晒的关系

- 只有目标已生效的员工才能开始自评；未生效目标不进入考核表评分。
- 评价阶段的自评分与上级评分只记录过程，不直接成为最终结果。
- 评价完成后，系统按上级评分计算加权总分与建议等级；通晒环节在建议等级基础上校准，形成最终等级。
- 通晒调整不修改评分与评语；最终等级、后续计划与原因是通晒的可编辑字段。

## 6. 评级与绩效系数

- 等级固定为 S、A、B、C、D 五级，顺序固定，不可增删或调整。
- 建议等级按[绩效参数配置](../绩效参数配置/文档/业务规则.md)中各级分数下限从高到低匹配；区间连续覆盖 0–100，最高等级无上限。
- 总分按考核表内各目标「上级评分 × 权重」求和后除以 100 计算；小数位与舍入方式取参数配置。
- 等级名称、分数下限、绩效系数与标签样式均取参数配置；绩效系数随最终等级绑定。
- 最终等级以中心通晒确认为准，可与建议等级不同；差异不改变总分，只影响最终等级与系数。
- 绩效系数在本分组只展示与导出，不作为计算口径直接驱动薪酬。

## 7. 比例分布基线与预警

- 各等级基线类型、基线值与参考容差取[绩效参数配置](../绩效参数配置/文档/业务规则.md)；实际执行以周期参数快照为准，本分组不固化比例数值。
- 统计维度固定为中心整体、部门（三级组织）、职级层级、序列、司龄段；职级层级与司龄段的分档边界取参数配置。
- 偏差判定：上限型超过基线提示「高于基线」；下限型低于基线提示「低于基线」；参考型与参考值相差达到容差提示「偏离参考」；其余为正常。
- 占比分母为该维度下已纳入考核且已有最终等级的人数；不纳入人员与「/」不计入。
- 占比小数位取参数配置；人数与占比同时呈现。
- 基线偏差只做提示，不阻断保存、提交与确认；由主持人结合团队实际情况判断。

## 8. 状态流转

| 对象 | 状态 | 说明 |
|---|---|---|
| 绩效目标 | 草稿、待确认、已生效、已归档 | 退回后回到草稿并展示退回原因；已生效目标可发起变更并生成新版本 |
| 考核表 | 未开始、自评中、待上级评价、待通晒、已校准、已生效 | 自评提交进入待上级评价；上级提交进入待通晒；中心确认后已生效并锁定 |
| 考核周期 | 目标设定、评价中、通晒中、已生效、已归档 | 随各节点日期与操作推进 |

## 9. 修改留痕

- 适用场景：已生效目标的变更、通晒中的等级 / 后续计划 / 原因调整、结果生效后的更正。
- 每条记录包含：操作时间、操作人、对象（目标或员工）、变更字段、原值、新值、变更原因、来源页面。
- 变更原因必填，且不可为空提交。
- 记录只增不改不删，按时间倒序查询，随结果一并导出。
- 自评与上级评价在提交前可反复保存，不生成变更记录；提交后再修改视为更正并留痕。
- 绩效参数的版本与变更记录归[绩效参数配置](../绩效参数配置/SKILL.md)，不复用本节的业务变更记录。

## 10. 权限编码

| 功能 | 菜单权限 | 按钮权限 |
|---|---|---|
| 绩效目标管理 | `MENU:HR:PERFORMANCE_TARGET` | 编辑 `BTN:HR_PERFORMANCE_TARGET:EDIT`、提交确认 `BTN:HR_PERFORMANCE_TARGET:SUBMIT`、确认或退回 `BTN:HR_PERFORMANCE_TARGET:CONFIRM`、历史版本 `BTN:HR_PERFORMANCE_TARGET:VERSION` |
| 绩效评价 | `MENU:HR:PERFORMANCE_REVIEW` | 自评填报 `BTN:HR_PERFORMANCE_REVIEW:SELF`、上级评价 `BTN:HR_PERFORMANCE_REVIEW:MANAGER`、提交 `BTN:HR_PERFORMANCE_REVIEW:SUBMIT`、退回 `BTN:HR_PERFORMANCE_REVIEW:RETURN`、催办 `BTN:HR_PERFORMANCE_REVIEW:REMIND` |
| 绩效通晒 | `MENU:HR:PERFORMANCE_CALIBRATION` | 校准编辑 `BTN:HR_PERFORMANCE_CALIBRATION:EDIT`、变更记录 `BTN:HR_PERFORMANCE_CALIBRATION:LOG`、导出 `BTN:HR_PERFORMANCE_CALIBRATION:EXPORT`、确认结果 `BTN:HR_PERFORMANCE_CALIBRATION:CONFIRM` |
| 绩效参数配置 | `MENU:HR:PERFORMANCE_CONFIG` | 编辑 `BTN:HR_PERFORMANCE_CONFIG:EDIT`、发布 `BTN:HR_PERFORMANCE_CONFIG:PUBLISH`、恢复默认 `BTN:HR_PERFORMANCE_CONFIG:RESET`、版本历史与变更记录 `BTN:HR_PERFORMANCE_CONFIG:LOG` |

- 菜单权限与数据权限同时校验：菜单权限决定入口可见性，数据权限决定可见与可操作的人员范围。
- 未授权菜单权限不展示入口；未授权按钮权限时，对应操作不展示。
- 功能权限接入用户权限中心，具体能力以公共契约为准，本分组不复述接口定义。

## 11. 与其他模块的边界

- 员工资料「绩效」页签只读引用本分组的最终生效结果，不在本分组维护员工档案。
- [员工成长记录](../../../员工档案/员工成长记录/SKILL.md)中的绩效事件引用本分组结果，事件流水归员工成长记录。
- 参数值的定义、默认值、版本与周期快照归[绩效参数配置](../绩效参数配置/SKILL.md)；本分组只描述参数的消费机制，不复制参数值。
- 薪酬核算、奖金发放、晋升调薪决策不在本分组范围。
- 组织层级、岗位、汇报关系只读引用组织管理与员工档案，不在本分组维护。
