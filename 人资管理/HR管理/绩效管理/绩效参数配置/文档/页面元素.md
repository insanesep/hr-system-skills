# 绩效参数配置 · 页面元素说明

> 字段口径见 [数据模型.md](数据模型.md)，参数规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，单个配置页承载六类参数、版本发布、版本历史与变更记录，不设独立详情路由。

<a id="param-config"></a>

## 参数配置页

- **页面路径**：`/hr/performance/config`
- **权限编码**：路由 `MENU:HR:PERFORMANCE_CONFIG`；按钮见 [业务规则.md §7](业务规则.md#7-权限编码)
- **页面类型**：配置表单页（左侧分类导航 + 右侧参数表单 + 底部操作栏）
- **区块职责**：
  - 页头：标题「绩效参数配置」+ 副标题「集中维护绩效规则参数，发布后对后续周期生效」
  - 版本状态条：当前生效版本、适用周期范围、草稿状态、最近发布人与时间；右侧「版本历史」「变更记录」
  - 左侧分类导航：周期与名单、目标规则、评价规则、评级与系数、分布基线、通晒规则；有未保存修改的分类展示圆点
  - 参数区：分类标题、参数说明、影响功能标签、参数表单、行内校验提示
  - 底部操作栏：左侧「恢复默认」；右侧「保存草稿」「发布」
  - 抽屉：版本历史抽屉、变更记录抽屉
  - 弹窗：发布确认弹窗、恢复默认确认弹窗、离开页面确认弹窗
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyInput、PageableSelect、InputNumber、Tag、Table、Drawer、Form、Message、Confirm、Popover；参数开关使用原生 checkbox 实现，未引用未登记组件
- **布局引用**：参见原型 `原型图/web/performance-params.html`

### 版本状态条

- 当前生效版本展示版本号、发布人与发布时间；尚未发布时展示「系统默认」。
- 适用周期范围展示「YYYY 年 QN 及之后创建的周期」，并提示进行中与已归档周期使用各自快照。
- 草稿状态展示「无未发布修改」或「有未发布修改」，后者以警示色提示。
- 「版本历史」与「变更记录」按 `BTN:HR_PERFORMANCE_CONFIG:LOG` 控制展示。

### 周期与名单

- 参数项：试用期员工纳入、协商离职人员处理、不纳入原因字典、名单调整截止、团队通晒日期必填、中心通晒日期必填。
- 不纳入原因为标签式列表，支持新增、编辑、删除与排序；删除前二次确认，至少保留一项。
- 协商离职处理提供下拉选项，选择「不纳入」时在参数下方提示「该人群不计入任何分布」。
- 影响功能标签：考核名单、绩效评价、绩效通晒。

### 目标规则

- 参数项：单目标权重下限与上限、建议目标个数、可见范围选项与默认值、目标进度下限与上限、截止后变更窗口。
- 权重、进度与建议个数使用数值输入，成对展示下限与上限；失焦时即时校验大小关系。
- 可见范围选项固定展示三项，仅允许调整默认值；页面提示「选项集合固定，不支持增删」。
- 影响功能标签：绩效目标管理。

### 评价规则

- 参数项：评分下限与上限、评分精度、自评说明必填、上级评语必填、总分小数位、总分舍入方式、逾期允许补填、自评总分展示。
- 评分范围成对展示；精度选择「整数」或「一位小数」。
- 必填性与展示项使用开关；关闭时在参数下方提示对应影响，例如关闭上级评语必填后上级可不填评语直接提交。
- 影响功能标签：绩效评价、绩效通晒、员工档案。

### 评级与系数

- 以五级表格展示：等级、名称、分数下限、绩效系数、标签样式、说明；等级与顺序固定，不支持增删与拖动。
- 表格上方提示「等级数量与顺序固定，仅可调整名称、分数下限、系数与标签样式」。
- 分数下限失焦后校验严格递减且 D 级为 0；系数失焦后校验非负且从 S 到 D 不递增。
- 标签样式为下拉选择，保存后在表格内以对应样式预览。
- 影响功能标签：绩效评价、绩效通晒、员工档案、[员工成长记录](../../../../员工档案/员工成长记录/SKILL.md)。

### 分布基线

- 上方为五级基线表：等级、基线类型、基线值、容差；上限型与下限型不展示容差输入，参考值类型展示容差。
- 中间展示统计维度固定清单：中心整体、部门、职级层级、序列、司龄段；附「维度种类固定，不支持增删」提示。
- 下方为职级层级分档与司龄段分档：展示档位名称与边界输入，末档标注「向上开放」；边界必须严格递增。
- 占比小数位使用数值输入，范围 0–2。
- 影响功能标签：绩效通晒、员工档案。

### 通晒规则

- 参数项：历史绩效回溯期数、后续计划短语库、非 B 原因必填等级。
- 短语库为可编辑标签列表：支持新增、编辑、删除与排序，单条不超过 30 字，内容不重复。
- 非 B 原因必填等级展示五个等级复选，S、A、C、D 默认勾选且不可取消，B 可选填。
- 影响功能标签：绩效通晒。

### 发布确认弹窗

- **打开方式**：底部「发布」。
- **内容**：
  - 变更摘要表：参数分类、参数项、原值、新值、影响功能；未变化的参数不展示
  - 发布说明：多行文本，必填，不超过 200 字
  - 校验结果：错误清单阻断发布；提示清单可勾选「已知悉并继续发布」
  - 生效说明：「发布后仅对之后创建的考核周期生效，进行中与已归档周期保持原参数快照」
- **底部操作**：取消、确认发布；确认按钮在存在错误、发布说明为空、存在未勾选知悉的提示或参数与当前生效版本一致时禁用。
- **成功反馈**：版本号递增，状态条更新为当前生效版本，草稿状态变为无修改，提示「参数已发布」。
- **失败反馈**：保留弹窗内容并提示失败原因，可重试。

### 版本历史抽屉

- **打开方式**：版本状态条「版本历史」。
- **内容**：版本号、状态、发布人、发布时间、适用周期数、发布说明；当前生效版本置顶并带标签。
- **操作**：查看快照、以此版本创建草稿。
- **查看快照**：在抽屉内展开该版本全部参数值，只读；系统默认版本展示默认参数。
- **以此版本创建草稿**：二次确认后，以该版本参数覆盖当前草稿并提示「已创建草稿，发布后生成新版本」；不改写历史版本。
- **空态**：仅系统默认时展示「尚未发布过参数版本，当前使用系统默认参数」。

### 变更记录抽屉

- **打开方式**：版本状态条「变更记录」。
- **内容**：按时间倒序展示操作时间、操作人、版本号、参数分类、参数项、原值 → 新值、发布说明。
- **筛选**：参数分类、参数项关键字、操作人、时间区间。
- **空态**：无发布记录时展示「暂无参数变更记录」。
- **导出**：支持导出当前筛选结果为 Excel，文件名包含版本号与导出时间。

### 校验与定位

- 校验错误在对应参数分类内汇总展示，相关字段标红；发布确认弹窗同步展示错误清单。
- 错误清单按参数分类归属展示，切换分类后可查看并修正具体参数。
- 保存草稿不执行跨参数校验；发布执行全量校验。
- 发布时存在错误不允许提交；存在提示时需勾选知悉后才能提交。

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 绩效管理 / 绩效参数配置」进入
- 去向页：无下级页面；版本历史与变更记录为抽屉，发布与恢复默认为弹窗
- 返回行为：切换分类保留未保存内容；关闭页面或切换菜单时如有未保存修改，二次确认后离开
- 面包屑：首页 / 人资管理 / HR管理 / 绩效管理 / 绩效参数配置
