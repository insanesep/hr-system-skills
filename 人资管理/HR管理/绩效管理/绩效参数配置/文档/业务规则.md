# 绩效参数配置 · 业务规则

> 本文件是绩效管理全部可配置参数的真源：参数目录、版本发布、周期快照、校验、权限与留痕。周期阶段、角色与状态流转见[绩效管理共享业务规则](../文档/业务规则.md)，字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。

## 1. 功能边界

- 本模块承载绩效管理参数的维护、校验、版本发布、周期快照与变更记录。
- 不做：考核周期创建、考核名单办理、目标拟定与确认、自评与上级评分、等级校准、薪酬与奖金计算。
- 绩效目标管理、绩效评价、绩效通晒与员工档案绩效页签只消费参数，不复述具体数值；同一参数只在本模块定义一次。

## 2. 参数分类与目录

参数分为六类：周期与名单、目标规则、评价规则、评级与系数、分布基线与统计、通晒规则。每个参数项包含名称、定义、默认值、取值规则与影响功能；页面按分类组织，变更记录按参数项留痕。

### 2.1 周期与名单

| 参数项 | 默认值 | 取值规则 | 影响功能 |
|---|---|---|---|
| 试用期员工纳入 | 是 | 是 / 否；为是时试用期员工与正式员工同口径评价 | 考核名单、绩效评价、绩效通晒 |
| 协商离职人员处理 | 纳入并按 D 记录 | 纳入并按 D 记录 / 纳入但不指定等级 / 不纳入；选择不纳入时不计入任何分布 | 考核名单、绩效通晒 |
| 不纳入原因字典 | 新入职、离职、长期不在岗 | 可增删改与排序，至少保留 1 项，名称不重复，单项不超过 20 字 | 考核名单 |
| 名单调整截止 | 周期归档前 | 目标截止 / 自评截止 / 上级评价截止 / 通晒前 / 归档前 | 考核名单 |
| 团队通晒日期必填 | 否 | 是 / 否；为否时未安排团队通晒日期不展示团队阶段 | 考核周期、绩效通晒 |
| 中心通晒日期必填 | 否 | 是 / 否；为否时未安排中心通晒日期不允许确认结果 | 考核周期、绩效通晒 |

- 考核名单本身仍由 HRBP 按周期生成与调整；本模块只定义名单的纳入与排除规则，不维护人员名单。
- 名单调整截止之后，名单只读；已提交评价的人员移出名单仍需 HRBP 确认并留痕，该规则不受参数影响。

### 2.2 目标规则

| 参数项 | 默认值 | 取值规则 | 影响功能 |
|---|---|---|---|
| 单目标权重下限 | 1 | 1–100 的整数，且小于权重上限 | 绩效目标管理 |
| 单目标权重上限 | 100 | 1–100 的整数，且大于权重下限 | 绩效目标管理 |
| 建议目标个数 | 3–6 个 | 下限与上限均为 1–20 的整数，下限不大于上限；仅作页面提示，不设硬性上限 | 绩效目标管理 |
| 可见范围选项 | 本人可见、上级可见、中心内可见 | 选项集合固定，不可增删 | 绩效目标管理 |
| 默认可见范围 | 中心内可见 | 从可见范围选项中单选 | 绩效目标管理 |
| 目标进度下限 | 0 | 0–100 的整数，且小于进度上限 | 绩效目标管理 |
| 目标进度上限 | 100 | 0–100 的整数，且大于进度下限 | 绩效目标管理 |
| 截止后变更窗口 | 允许 | 允许 / 不允许；为允许时 HRBP 可在目标截止后开启变更窗口并留痕 | 绩效目标管理 |

- 同一主体同周期目标权重合计必须为 100%，属于结构口径，不随参数变化。
- 目标标题在同一主体同周期内不重复，属于业务不变量，不随参数变化。

### 2.3 评价规则

| 参数项 | 默认值 | 取值规则 | 影响功能 |
|---|---|---|---|
| 评分下限 | 0 | 0–100，且小于评分上限 | 绩效评价 |
| 评分上限 | 100 | 0–100，且大于评分下限 | 绩效评价 |
| 评分精度 | 整数 | 整数 / 一位小数 | 绩效评价 |
| 自评说明必填 | 否 | 是 / 否 | 绩效评价 |
| 上级评语必填 | 是 | 是 / 否；为是时上级评分后必须填写评语 | 绩效评价 |
| 总分小数位 | 1 | 0–2 位 | 绩效评价、绩效通晒、员工档案 |
| 总分舍入方式 | 四舍五入 | 四舍五入 / 向上取整 / 向下取整 | 绩效评价、绩效通晒、员工档案 |
| 逾期允许补填 | 是 | 是 / 否；为是时逾期未提交仍可补填并保留逾期标识 | 绩效评价 |
| 自评总分展示 | 是 | 是 / 否；为是时考核表同时展示员工自评总分供对照 | 绩效评价 |

- 加权总分公式固定为各评价项「上级评分 × 权重」之和除以 100，不随参数变化；精度与舍入取本模块配置。
- 自评分与上级评分使用同一评分范围与精度；自评总分只用于对照，不参与最终等级映射。

### 2.4 评级与系数

等级数量固定为 5 级，顺序固定为 S、A、B、C、D，不可增删或调整顺序；名称、分数下限、绩效系数与标签样式可配置。

| 等级 | 默认名称 | 默认分数下限 | 默认绩效系数 | 默认标签样式 |
|---|---|---|---|---|
| S | 杰出 | 98 | 2.0 | 主色 |
| A | 优秀 | 95 | 1.5 | 主色 |
| B | 良好 | 85 | 1.0 | 中性 |
| C | 有待改进 | 70 | 0.5 | 警示 |
| D | 不合格 | 0 | 0 | 危险 |

- 建议等级按分数下限从高到低匹配：总分达到某级下限且未达到更高等级下限时命中该等级；最高等级无上限，最低等级覆盖 0 分至其上一级下限以下。
- 标签样式可选主色、成功、中性、警示、危险，只影响展示，不影响计算。
- 最终等级以中心通晒确认为准，可与建议等级不同；绩效系数随最终等级绑定。
- 绩效系数在本分组只展示与导出，不作为薪酬计算口径直接驱动薪酬。

### 2.5 分布基线与统计

| 等级 | 默认基线类型 | 默认基线值 | 默认容差 |
|---|---|---|---|
| S | 上限 | 15% | 不适用 |
| A | 上限 | 20% | 不适用 |
| B | 参考值 | 50% | 5 个百分点 |
| C | 参考值 | 10% | 5 个百分点 |
| D | 下限 | 5% | 不适用 |

| 参数项 | 默认值 | 取值规则 | 影响功能 |
|---|---|---|---|
| 基线类型 | 上限 / 参考值 / 下限 | 每个等级固定一种类型，可调整类型与数值 | 绩效通晒 |
| 参考容差 | 5 个百分点 | 0–100 的数值；仅参考值类型使用 | 绩效通晒 |
| 统计维度 | 中心整体、部门、职级层级、序列、司龄段 | 维度种类固定，不可增删；每类维度均参与分布展示 | 绩效通晒 |
| 职级层级分档 | P1-P3 / P4-P6 / P7-P8 / P9 及以上 | 分档名称可维护，边界为正整数且严格递增，末档向上开放 | 绩效通晒 |
| 司龄段分档 | 不足 0.5 年 / 0.5-1 年 / 1-2 年 / 2-3 年 / 3 年以上 | 分档名称可维护，边界为正数且严格递增，首档从 0 开始，末档向上开放 | 绩效通晒 |
| 占比小数位 | 1 | 0–2 位 | 绩效通晒、员工档案 |

- 占比分母固定为该维度下已纳入考核且已有最终等级的人数；「/」与不纳入人员不计入。
- 偏差判定规则：上限型超过基线提示「高于基线」；下限型低于基线提示「低于基线」；参考型与参考值相差达到容差提示「偏离参考」；其余为正常。
- 分布偏差只提示，不阻断保存、提交与确认。

### 2.6 通晒规则

| 参数项 | 默认值 | 取值规则 | 影响功能 |
|---|---|---|---|
| 历史绩效回溯期数 | 3 | 1–10 的整数；取最近已归档周期的最终等级，按周期由远及近展示 | 绩效通晒 |
| 后续计划短语库 | 维持原岗位工作职责、扩大工作职责、提名晋升、调薪或奖金倾斜 | 可增删改与排序，至少保留 1 条、最多 20 条，单条不超过 30 字，内容不重复 | 绩效通晒 |
| 非 B 原因必填等级 | S、A、C、D | 必填集合必须包含 S、A、C、D；B 可选填，不强制 | 绩效通晒 |

- 本期等级、后续计划与非 B 原因的每次变更必须填写变更原因并生成记录，属于业务不变量，不随参数变化。
- 团队确认与中心确认的顺序、中心确认后锁定、变更记录只增不改不删，属于流程不变量，不随参数变化。

### 2.7 不进入参数的结构口径

以下内容固定，不在本模块开放配置，避免改变流程结构或产生不可比口径：

- 同一主体同周期的目标权重合计为 100%
- 加权总分公式为「上级评分 × 权重」之和除以 100
- 等级数量为 5 级、顺序为 S / A / B / C / D
- 统计维度种类为中心整体、部门、职级层级、序列、司龄段
- 团队通晒与中心通晒的两级顺序及中心确认后锁定
- 变更原因必填、变更记录只增不改不删
- 菜单权限、按钮权限与数据权限编码
- 导出格式为 Excel，台账固定列与只读列口径

## 3. 参数版本与发布

- 参数版本状态为草稿、已发布、历史。同一时间最多存在一份草稿与一份已发布版本。
- 已发布版本只读；需要调整时从已发布版本或历史版本派生草稿，修改后重新发布。
- 发布前执行全量校验；校验错误阻断发布，提示类问题经确认后可以发布。
- 发布必须填写发布说明并二次确认；发布成功后生成新版本号，原已发布版本转为历史。
- 参数与当前生效版本一致时不可发布，避免生成内容相同的版本。
- 未发布的草稿修改不生效；保存草稿不生成正式变更记录。
- 恢复默认将草稿全部参数恢复为系统默认值，需二次确认；只影响草稿，不影响已发布版本与周期快照。
- 从历史版本创建草稿视为回滚起点，发布后生成新的版本号，不改写历史版本。

## 4. 周期参数快照

- 考核周期创建时，系统对当前已发布版本生成参数快照；尚无已发布版本时使用系统默认参数。
- 快照包含参数版本号、全部参数值与快照时间，生成后只读。
- 目标、评价、通晒与员工档案绩效页签按所属周期的参数快照执行，不读取运行时的最新版本。
- 参数发布只影响发布之后创建的周期；进行中与已归档周期保持原快照，不提供改绑入口。
- 版本历史展示每个版本被哪些周期使用，便于复核与审计。

## 5. 参数校验

### 5.1 通用校验

- 数值参数必须在取值范围内，且满足下限小于上限的大小关系。
- 名称类参数不得为空、不得重复、不得超过约定长度。
- 字典与短语库至少保留一条，排序值唯一。
- 所有参数项在发布前必须完成，不得留空。

### 5.2 分类校验

| 分类 | 校验规则 |
|---|---|
| 目标规则 | 权重下限小于上限，均在 1–100；进度下限小于上限，均在 0–100；建议目标个数下限不大于上限，均在 1–20 |
| 评价规则 | 评分下限小于上限，均在 0–100；总分小数位为 0–2；舍入方式在允许值内 |
| 评级与系数 | 五级分数下限严格递减，D 级下限为 0，S 级下限大于 0 且小于 100；绩效系数非负，且从 S 到 D 不递增；名称不重复 |
| 分布基线 | 基线与容差均在 0–100；上限型基线小于 100，下限型基线大于 0；参考值减容差不小于 0、加容差不大于 100 |
| 统计分档 | 职级边界为正整数且严格递增；司龄边界为正数且严格递增，首档从 0 开始；分档名称不重复 |
| 通晒规则 | 历史回溯期数为 1–10；短语库为 1–20 条且不重复；非 B 原因必填等级必须包含 S、A、C、D |

### 5.3 错误与提示

- 格式错误、越界、断档、重名、必填缺失为错误，阻断发布并在对应参数分类内展示。
- 基线合计与 100% 存在明显偏离、短语库超过 15 条、历史回溯超过 6 期等情形为提示，二次确认后可以发布。
- 校验结果在发布确认弹窗与对应参数分类内汇总；错误项随分类展示，便于定位。

## 6. 生效顺序与优先级

- 参数取值优先级从低到高依次为：系统默认参数、已发布版本、周期参数快照。
- 周期创建后以快照为准，不再读取系统默认或最新已发布版本。
- 全部参数为全局口径，不按中心或部门分别维护，保证跨中心分布可比。
- 参数变更不追溯调整已生效结果；需要更正绩效结果的，按绩效通晒的更正流程处理。

## 7. 权限编码

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:PERFORMANCE_CONFIG` | 未授权不展示菜单 |
| 编辑草稿 | `BTN:HR_PERFORMANCE_CONFIG:EDIT` | 系统管理员可见 |
| 发布 | `BTN:HR_PERFORMANCE_CONFIG:PUBLISH` | 系统管理员可见 |
| 恢复默认 | `BTN:HR_PERFORMANCE_CONFIG:RESET` | 系统管理员可见 |
| 版本历史 / 变更记录 | `BTN:HR_PERFORMANCE_CONFIG:LOG` | 系统管理员与 HRBP 可见 |

- 数据权限：系统管理员全局可编辑与发布；HRBP 全局只读；其他角色无入口。
- 菜单权限与按钮权限同时校验；未授权操作不展示，接口层同样拒绝越权修改。

## 8. 变更留痕

- 每次发布生成一条版本记录与若干参数变更记录；保存草稿不生成正式记录。
- 参数变更记录包含：操作时间、操作人、参数版本、参数分类、参数项、原值、新值、发布说明。
- 记录只增不改不删，按时间倒序查询，支持按分类、参数项、操作人与时间区间筛选，并支持从变更记录导出。
- 周期快照与版本记录长期保留，已归档周期仍可追溯到当时使用的参数口径。

## 9. 与其他模块的边界

- 绩效目标管理消费权重、进度、可见范围与变更窗口参数；目标内容与确认流程仍归该功能。
- 绩效评价消费评分范围与精度、必填性、总分精度与评级阈值；评分过程仍归该功能。
- 绩效通晒消费基线、容差、统计分档、历史回溯期数、短语库与非 B 原因规则；校准与确认仍归该功能。
- 员工档案绩效页签只读引用最终等级、绩效系数与后续计划，不提供参数入口。
- [员工成长记录](../../../../员工档案/员工成长记录/SKILL.md)的绩效事件引用最终结果，事件流水归员工成长记录。
- 考核周期创建、名单生成、薪酬核算、奖金发放与晋升调薪决策不在本模块范围。
