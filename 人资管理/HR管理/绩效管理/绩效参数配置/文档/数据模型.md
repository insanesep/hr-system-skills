# 绩效参数配置 · 数据模型

> 本文件定义绩效参数配置的参数版本、参数项、等级与基线参数、统计分档、字典项、周期快照与变更记录字段口径。参数语义与校验规则见 [业务规则.md](业务规则.md)。

## 1. 参数版本

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 版本标识 | 参数版本的唯一标识 | 文本 | 是 | 系统内唯一，页面不展示 |
| 版本号 | 参数的版本序号 | 数值 | 是 | 从 1 开始递增，按发布顺序生成 |
| 版本状态 | 版本当前状态 | 枚举 | 是 | 草稿、已发布、历史 |
| 参数快照 | 该版本全部参数值的集合 | 文本 | 是 | 发布时固化，发布后只读 |
| 来源版本 | 草稿派生自哪个版本 | 文本 | 否 | 新建草稿时为空；从已发布或历史版本派生时记录来源版本 |
| 发布说明 | 本次发布的原因与影响 | 文本 | 是 | 发布时必填，不超过 200 字 |
| 创建人 | 草稿创建人 | 文本 | 是 | — |
| 创建时间 | 草稿创建时间 | 日期时间 | 是 | — |
| 发布人 | 版本发布人 | 文本 | 否 | 草稿状态为空 |
| 发布时间 | 版本发布时间 | 日期时间 | 否 | 草稿状态为空 |
| 适用周期数 | 使用该版本快照的考核周期数量 | 数值 | 是 | 派生字段，按周期快照统计 |
| 当前生效 | 是否为当前已发布版本 | 布尔 | 是 | 同一时间仅一个版本为是 |

## 2. 参数项

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 参数标识 | 参数项的唯一标识 | 文本 | 是 | 系统内唯一 |
| 参数名称 | 参数的展示名称 | 文本 | 是 | 同一分类内不重复 |
| 所属分类 | 参数所属类别 | 枚举 | 是 | 周期与名单、目标规则、评价规则、评级与系数、分布基线与统计、通晒规则 |
| 值类型 | 参数的取值形态 | 枚举 | 是 | 文本、数值、布尔、枚举、区间、字典、等级表、基线表、分档表 |
| 当前值 | 草稿或已发布版本的取值 | 文本 | 是 | 按取值规则校验 |
| 默认值 | 系统默认取值 | 文本 | 是 | 恢复默认时使用，只读 |
| 取值规则 | 参数的取值范围与约束 | 文本 | 是 | 与业务规则中的参数目录一致 |
| 是否可编辑 | 是否允许在页面上修改 | 布尔 | 是 | 结构口径为否，普通参数为是 |
| 影响功能 | 消费该参数的功能 | 文本 | 是 | 绩效目标管理、绩效评价、绩效通晒、员工档案等 |
| 最近修改人 | 草稿中最后一次修改人 | 文本 | 否 | 未修改时为空 |
| 最近修改时间 | 草稿中最后一次修改时间 | 日期时间 | 否 | 未修改时为空 |
| 排序 | 分类内的展示顺序 | 数值 | 是 | 同一分类内唯一 |

## 3. 等级参数

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 等级 | 绩效等级标识 | 枚举 | 是 | S、A、B、C、D，固定不可增删 |
| 顺序 | 等级的展示与比较顺序 | 数值 | 是 | 1–5，S 为 1、D 为 5，固定 |
| 等级名称 | 等级的中文名称 | 文本 | 是 | 不超过 10 字，五级不重复 |
| 分数下限 | 命中该等级的最低总分 | 数值 | 是 | 0–100；S 级大于 0 且小于 100；D 级为 0；从 S 到 D 严格递减 |
| 绩效系数 | 与等级绑定的系数 | 数值 | 是 | 非负，从 S 到 D 不递增 |
| 标签样式 | 等级的展示样式 | 枚举 | 是 | 主色、成功、中性、警示、危险 |
| 说明 | 等级口径补充说明 | 文本 | 否 | 页面展示用 |

## 4. 基线参数

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 基线标识 | 基线的唯一标识 | 文本 | 是 | 每个等级一条 |
| 等级 | 对应的绩效等级 | 枚举 | 是 | S、A、B、C、D |
| 基线类型 | 基线的比较方式 | 枚举 | 是 | 上限、参考值、下限 |
| 基线值 | 基线的比例数值 | 数值 | 是 | 0–100；上限型小于 100，下限型大于 0 |
| 容差 | 参考值的允许偏离 | 数值 | 否 | 0–100；仅参考值类型使用 |
| 排序 | 展示顺序 | 数值 | 是 | 与等级顺序一致 |

## 5. 分档参数

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 分档标识 | 分档项的唯一标识 | 文本 | 是 | — |
| 维度 | 分档所属统计维度 | 枚举 | 是 | 职级层级、司龄段 |
| 档位名称 | 分档的展示名称 | 文本 | 是 | 同一维度内不重复 |
| 下限 | 档位起点 | 数值 | 是 | 职级为整数，司龄为年数；首档从 0 开始 |
| 上限 | 档位终点 | 数值 | 否 | 末档为空并向上开放 |
| 是否开放上界 | 是否包含上限之外的值 | 布尔 | 是 | 仅末档为是 |
| 排序 | 档位的展示顺序 | 数值 | 是 | 同一维度内唯一 |

## 8. 参数变更记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 记录标识 | 变更记录的唯一标识 | 文本 | 是 | 只增不改不删 |
| 参数版本 | 变更所属的参数版本 | 文本 | 是 | 指向发布后的版本 |
| 参数分类 | 变更参数的所属分类 | 枚举 | 是 | 六类之一 |
| 参数项 | 发生变化的参数名称 | 文本 | 是 | 一次记录一个参数项 |
| 原值 | 发布前的值 | 文本 | 否 | 首次发布或新增参数时为空 |
| 新值 | 发布后的值 | 文本 | 是 | — |
| 发布说明 | 本次发布的原因与影响 | 文本 | 是 | 与版本记录的发布说明一致 |
| 变更类型 | 变更的来源 | 枚举 | 是 | 发布、恢复默认后发布、历史版本派生后发布 |
| 操作人 | 执行发布的人员 | 文本 | 是 | — |
| 操作时间 | 发布发生时间 | 日期时间 | 是 | 倒序展示 |
| 来源页面 | 变更发生的功能 | 枚举 | 是 | 绩效参数配置 |

## 9. 实体关系

- 一个参数版本包含多个参数项、五个等级参数、五条基线参数与若干分档、字典项。
- 一个考核周期对应一份周期参数快照，一份快照指向一个参数版本；系统默认参数没有发布版本。
- 一次发布生成一个参数版本与若干参数变更记录；历史版本不因新版本发布而改写。
- 绩效目标、考核表与通晒结果只引用周期快照，不直接引用参数版本。
