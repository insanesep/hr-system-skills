# 绩效通晒 · 业务规则

> 本功能描述团队与中心通晒的操作规则；参数消费机制、评级与权限总表见[共享业务规则](../../文档/业务规则.md)，字段口径见[共享数据模型](../../文档/数据模型.md)，基线、分档、回溯期数与短语库见[绩效参数配置](../../绩效参数配置/文档/业务规则.md)，页面元素见 [页面元素.md](页面元素.md)。

## 1. 功能边界

- 本功能承载通晒范围确定、绩效台账查看、等级校准、后续计划与非 B 原因维护、分布统计与预警、修改留痕、导出与结果确认。
- 不做：目标拟定与确认、自评与上级评分、考核名单维护、周期配置、薪酬与奖金计算。
- 通晒只校准最终等级与说明，不修改评分与评语；最终等级可与建议等级不同。

## 2. 通晒范围与组织者

- **团队通晒**：以四级组织为范围，由该组直接上级主持，覆盖该组考核名单内全部人员；TL 本人由其上级在其所属团队通晒。
- **中心通晒**：以二级组织为范围，由中心负责人主持，覆盖中心内全部部门与团队，包含各部门 TL。
- 部门负责人参与本部门的通晒讨论，可查看本部门全量明细；编辑权限归该组成员的直接上级，中心负责人与 HRBP 具备中心范围编辑权限。
- 通晒范围按考核名单生成；不纳入人员展示「/」并标注原因，不参与等级调整与分布统计。

## 3. 台账数据来源与列

- 人员、组织、职位、职级、工作地点、入职日期、转正日期、司龄、人员状态来自考核名单。
- 历史绩效回溯期数取[绩效参数配置](../../绩效参数配置/文档/业务规则.md)，取最近已归档周期的最终等级，按周期由远及近展示；无历史结果展示「/」。
- 建议等级取考核表上级评价的加权总分映射结果；最终等级默认等于建议等级，可在通晒中调整。
- 台账固定列：工号、姓名、二级组织、三级组织、四级组织、职位、直线经理、职级、工作地点、入职日期、人员状态、历史绩效、本期绩效、后续计划、非 B 原因；中心视图额外展示转正日期与司龄。
- 人员、组织、职级、历史绩效与建议等级均只读。

## 4. 可编辑字段与校验

| 字段 | 编辑方式 | 校验 |
|---|---|---|
| 本期绩效（最终等级） | 下拉选择 S / A / B / C / D，并提供「恢复建议等级」 | 调整时必须填写变更原因；同一员工同一时刻仅一人编辑 |
| 后续计划 | 文本输入，提供绩效参数配置中的常用短语快捷选择 | 变更时记录前后值与原因 |
| 非 B 原因 | 多行文本，弹窗编辑 | 必填等级取绩效参数配置；未在必填集合内的等级可选填 |

- 未完成评价的考核表以「待补评」标识，本期等级不可调整；中心确认前需完成评价或由 HRBP 将该人员移出本期通晒范围并留痕。
- 调整等级后，建议等级仍保留展示，便于对照；最终等级以调整值为准。
- 保存时如发现同一记录已被他人修改，提示「该员工等级已被更新，请刷新后重试」，避免互相覆盖。

## 5. 分布统计与基线

- 统计维度固定为中心、部门（三级组织）、职级层级、序列、司龄段；职级层级与司龄段的分档取绩效参数配置。
- 每个维度按 S / A / B / C / D 展示人数、占比与合计；占比小数位取参数配置。
- 与周期参数快照中的基线比对：上限型、参考值与下限型的判定见[共享业务规则](../../文档/业务规则.md)；偏差分为「高于基线」「低于基线」「偏离参考」「正常」。
- 分布随等级调整实时重算；偏差只提示，不阻断保存与确认。
- 团队通晒展示本团队与所属部门的对应层级分布；中心通晒展示中心整体与各部门分布。

## 6. 修改留痕

- 本期等级、后续计划与非 B 原因的每次变更均生成一条变更记录，包含：操作时间、操作人、员工、变更字段、原值、新值、变更原因、来源范围（团队 / 中心）。
- 变更原因必填；等级调整的原因为必填项，未填写不允许保存。
- 变更记录按时间倒序展示，可按员工与字段筛选，并与通晒结果一同导出。
- 记录只增不改不删；确认结果后继续保留，用于复盘与审计。

## 7. 确认与生效

- 团队通晒完成后由主持人在团队视图点击「确认本团队」，团队状态变为已校准；团队确认不锁定数据，仍可在中心通晒中调整。
- 团队确认前校验最终等级命中必填等级人员的非 B 原因是否填写完整，存在未填写时不允许确认并定位到对应人员；确认后在团队视图继续调整，团队状态回到通晒中，需重新确认。
- 中心通晒完成后由中心负责人点击「确认中心结果」，二次确认后本期全部最终等级生效，台账锁定，不可再编辑。
- 中心确认前要求中心内全部团队完成确认，存在未确认团队时不允许生效并提示未确认名单。
- 确认生效后，最终等级、绩效系数、后续计划同步至员工档案绩效页签与[员工成长记录](../../../../员工档案/员工成长记录/SKILL.md)的绩效事件。
- 生效后如需更正，由 HRBP 发起更正并填写原因，系统生成变更记录并更新员工档案；已归档周期的结果不可更正。

## 8. 特殊情形

- 协商离职（有赔偿）人员在通晒中按 D 记录；绩效扣除规则由薪酬制度决定，本功能不计算扣款。
- 不纳入考核的人员展示「/」，不计入任何分布；不纳入原因在人员行内提示。
- 周期内转正人员正常参与；试用期人员与正式员工同口径。
- 未完成评价人员在中心确认前必须处理：完成评价、移出范围或由 HRBP 记录例外说明。

## 9. 导出

- 支持导出当前范围与当前筛选的台账、分布汇总与变更记录，格式为 Excel。
- 导出文件以「周期名称 + 范围 + 版本」命名，包含导出时间与操作人。
- 导出不改变任何数据与状态；未确认的数据导出标注「未生效」。

## 10. 权限编码

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:PERFORMANCE_CALIBRATION` | 未授权不展示菜单 |
| 校准编辑 | `BTN:HR_PERFORMANCE_CALIBRATION:EDIT` | 团队上级本团队；中心负责人与 HRBP 中心范围 |
| 变更记录 | `BTN:HR_PERFORMANCE_CALIBRATION:LOG` | 有查看权限的角色均可查看记录 |
| 导出 | `BTN:HR_PERFORMANCE_CALIBRATION:EXPORT` | 团队上级、部门负责人、中心负责人、HRBP |
| 确认结果 | `BTN:HR_PERFORMANCE_CALIBRATION:CONFIRM` | 团队确认为直接上级；中心确认为中心负责人 |

- 数据权限：直接上级本团队；部门负责人本部门只读；中心负责人与 HRBP 本中心可编辑；其他角色无入口。
- 菜单权限与数据权限同时校验；未授权时对应按钮不展示，接口层同样拒绝越权修改。
