# 绩效通晒 · 页面元素说明

> 字段口径见[共享数据模型](../../文档/数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，单个通晒工作台承载团队与中心两种范围，不设独立详情路由。基线、分档、回溯期数与短语库取[绩效参数配置](../../绩效参数配置/文档/业务规则.md)，页面按周期参数快照展示。

<a id="calibration-workbench"></a>

## 通晒工作台

- **页面路径**：`/hr/performance/calibration`
- **权限编码**：路由 `MENU:HR:PERFORMANCE_CALIBRATION`；按钮见 [业务规则.md §10](业务规则.md#10-权限编码)
- **页面类型**：操作工作台（汇总 + 可编辑台账）
- **区块职责**：
  - 页头：标题「绩效通晒」+ 副标题「校准本期绩效等级，修改全程留痕」+ 周期选择
  - 范围切换：团队通晒 / 中心通晒；团队模式提供团队选择（四级组织），中心模式展示全中心
  - 状态条：范围名称、纳入人数、已确认进度、通晒状态、「变更记录」「导出」「确认结果」
  - 基线提示：按周期参数快照展示各级基线；偏差仅提示不拦截
  - 汇总区：维度切换（职级层级 / 部门 / 序列 / 司龄）+ 分布表（等级人数、占比、合计、偏差标签）
  - 台账区：工具栏（筛选：关键字、部门、等级、后续计划；结果条数；「刷新」）+ 明细表 + 空态 / 加载失败
  - 抽屉：变更记录抽屉
  - 弹窗：等级调整原因、后续计划调整原因、非 B 原因编辑、确认结果二次确认
- **台账列**：工号、姓名、二级组织、三级组织、四级组织、职位、直线经理、职级、工作地点、入职日期、人员状态、历史绩效（期数取参数配置）、本期绩效（下拉）、后续计划（输入 + 参数配置短语快捷选择）、非 B 原因（弹窗编辑）；中心范围额外展示转正日期与司龄
- **只读列**：人员、组织、职位、职级、工作地点、入职日期、人员状态、历史绩效
- **编辑态**：本期绩效下拉默认取建议等级；调整后行内展示「建议 A → 最终 B」对照。必填等级的非 B 原因未填时行内以警示色提示「待补充」
- **锁定态**：中心确认后全部编辑控件变为文本，顶部展示「结果已生效」标签与生效时间
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyInput、PageableSelect、Table、Tag、Drawer、Form、Message、Confirm、Popover
- **布局引用**：参见原型 `原型图/web/performance-calibration.html`

### 汇总区

- 维度切换：职级层级、部门、序列、司龄，切换只改变汇总分组，不改变台账数据。
- 部门维度在团队模式下展示所属部门全部人员按职级层级的分组，在中心模式下按三级组织分组。
- 分布表列为：维度值、S 人数 / 占比、A、B、C、D、合计、偏差提示。
- 偏差提示：高于基线与低于基线为警示标签，偏离参考为提示标签，正常不展示标签。
- 汇总分母为当前范围下已纳入且有最终等级的人数；待补评与「/」不计入。
- 调整等级后汇总即时重算；汇总行与台账使用同一数据口径。

### 变更记录抽屉

- **打开方式**：状态条「变更记录」。
- **内容**：按时间倒序的记录列表，每条展示操作时间、操作人、员工、字段、原值 → 新值、变更原因、来源范围。
- **筛选**：员工关键字、变更字段、时间区间。
- **空态**：本期尚无调整时展示「本期暂无调整记录」。

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 绩效管理 / 绩效通晒」进入；评价完成后从评价列表提示进入
- 去向页：无下级页面；变更记录为抽屉，确认结果与原因填写为弹窗
- 返回行为：抽屉与弹窗关闭回到工作台，保留范围、筛选与滚动位置
- 面包屑：首页 / 人资管理 / HR管理 / 绩效管理 / 绩效通晒

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 切换范围 / 团队 | 具备对应数据权限 | 否 | 汇总与台账加载态 | 展示对应范围数据 → 停留本页 | 区域展示加载失败与「重试」 |
| 切换统计维度 | 无 | 否 | 汇总区加载态 | 按新维度重算分布 → 停留本页 | 汇总区展示加载失败与「重试」 |
| 调整本期等级 | 记录可编辑且未锁定 | 是（弹窗填写变更原因） | 保存按钮 loading | 行内等级更新，汇总重算，生成变更记录 | 恢复原等级并提示失败原因 |
| 恢复建议等级 | 最终等级与建议等级不同 | 是（弹窗填写变更原因） | 保存按钮 loading | 等级恢复为建议值，汇总重算并留痕 | 恢复原等级并提示失败 |
| 修改后续计划 | 记录可编辑且未锁定 | 是（弹窗确认并填写原因） | 保存按钮 loading | 行内更新并留痕 | 恢复原值并提示失败 |
| 编辑非 B 原因 | 最终等级命中必填等级或主动补充 | 否 | 弹窗保存按钮 loading | 原因保存，行内警示消失并留痕 | 保留弹窗内容并提示失败原因 |
| 变更记录 | 无 | 否 | 抽屉内容加载态 | 展示记录列表 → 停留本页 | 抽屉内展示加载失败与「重试」 |
| 导出 | 当前范围有数据 | 否 | 按钮 loading | 下载 Excel 并提示「已导出（未生效数据将标注）」 | 提示失败原因，可重试 |
| 确认本团队 | 团队模式且必填等级的非 B 原因填写完整 | 是 | 按钮 loading | 提示「本团队已确认」，状态为已校准 | 提示未完成项，定位到待补评或非 B 原因缺失人员 |
| 确认中心结果 | 中心模式且全部团队已确认 | 是（提示结果将锁定） | 按钮 loading | 提示「结果已生效」，台账锁定并同步员工档案 | 提示未完成项，定位到未确认团队 |
