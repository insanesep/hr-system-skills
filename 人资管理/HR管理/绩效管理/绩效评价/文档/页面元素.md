# 绩效评价 · 页面元素说明

> 字段口径见[共享数据模型](../../文档/数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，列表与详情在同一原型内以 `#list` / `#detail/工号` 双视图互联。评分范围与精度、必填性与评级阈值取[绩效参数配置](../../绩效参数配置/文档/业务规则.md)。

<a id="review-list"></a>

## 评价列表

- **页面路径**：`/hr/performance/review`
- **权限编码**：路由 `MENU:HR:PERFORMANCE_REVIEW`；按钮见 [业务规则.md §8](业务规则.md#8-权限编码)
- **页面类型**：操作列表页
- **区块职责**：
  - 页头：标题「绩效评价」+ 副标题「完成员工自评与直接上级评价」+ 周期选择
  - 视图切换：待我评价 / 我的考核表 / 中心考核表，按数据权限展示
  - 筛选卡：关键字（姓名 / 工号）、所属部门、考核状态；动作区「重置」「查询」
  - 结果卡：工具栏（结果条数、逾期条数、「刷新」）、评价表格、空态 / 加载 / 加载失败、分页
- **表格列**：工号、姓名、所属部门、职级、直线经理、自评分、上级总分、建议等级、考核状态、更新时间、操作
- **状态标签**：未开始（中性）、自评中（主色）、待上级评价（警示）、待通晒（主色）、已校准（成功）、已生效（成功）、逾期未自评 / 逾期未评价（危险）
- **行内操作**：查看（只读）或 去自评 / 去评价（按当前用户的角色与状态）
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyInput、PageableSelect、Table、Tag、Pagination、Message
- **布局引用**：参见原型 `原型图/web/performance-review.html#list`

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 绩效管理 / 绩效评价」
- 去向页：行内「查看」「去自评」「去评价」→ 考核表详情 `/hr/performance/review/detail/:工号`
- 返回行为：详情页「返回列表」回到本页，保留视图、筛选条件与页码
- 面包屑：首页 / 人资管理 / HR管理 / 绩效管理 / 绩效评价

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 切换视图 | 具备对应数据权限 | 否 | 表格区加载态 | 展示对应范围考核表 → 停留本页 | 表格区展示加载失败与「重试」 |
| 查询 / 重置 | 无 | 否 | 表格区加载态 | 刷新结果并回到第一页 → 停留本页 | 同加载失败处理 |
| 查看 / 去自评 / 去评价 | 行内存在且权限满足 | 否 | 无 | 跳转考核表详情 | 无权限时不展示操作 |
| 催办 | 中心视图且存在逾期考核表 | 是 | 按钮 loading | 提示「已发送催办提醒」 | 提示失败原因，可重试 |

## 考核表详情

- **页面路径**：`/hr/performance/review/detail/:工号`
- **权限编码**：路由 `MENU:HR:PERFORMANCE_REVIEW`；操作按钮按角色展示
- **页面类型**：详情页（表单型）
- **区块职责**：
  - 页头：「返回列表」+ 标题「考核表详情」+ 活动名称（如「2026年Q3绩效—技术中心」）+ 考核状态标签
  - 员工概览条：姓名、工号、所属部门 / 组、职级、直线经理
  - 页签区：流程信息 / 考核表详情，默认「考核表详情」
  - 评级规则说明卡：按周期参数快照展示 S/A/B/C/D 分数区间与绩效系数，默认展开，可收起
  - 目标评价表：列固定为 名称、权重、指标描述、衡量标准、员工本人、直接上级
  - 汇总条：员工自评总分（展示开关取参数配置）、上级加权总分、建议等级、绩效系数
  - 底部操作栏：保存草稿、提交、退回自评、返回列表（按角色与状态组合）
- **流程信息页签**：周期与考核区间、名单确认时间、目标生效时间、自评提交时间、上级提交时间、团队通晒日期、中心通晒日期、结果生效时间；每项展示状态与操作人
- **考核表详情页签**：
  - 每行一个目标，权重列展示百分比；指标描述与衡量标准为只读文本
  - 员工本人列：员工视角为数字输入 + 自评说明；上级视角只读展示，未填自评时展示「未提交」
  - 直接上级列：上级视角为数字输入 + 评语输入；员工视角只读展示，未评价时展示「待评价」
  - 评分输入范围与精度取绩效参数配置；评语必填性取绩效参数配置
  - 汇总条随输入实时更新；建议等级与系数按周期参数快照映射
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyTabs、InputNumber、Table、Tag、Form、Message、Confirm
- **布局引用**：参见原型 `原型图/web/performance-review.html#detail/L16520`

### 导航关系

- 来源页：评价列表行内查看 / 去自评 / 去评价
- 去向页：无下级页面；退回自评为弹窗，不跳转
- 返回行为：「返回列表」回到评价列表，保留视图与筛选；有未保存评分时二次确认
- 面包屑：首页 / 人资管理 / HR管理 / 绩效管理 / 绩效评价 / 考核表详情

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 保存草稿 | 当前用户为员工本人或直接上级，状态允许编辑 | 否 | 底部按钮 loading | 提示「已保存」，保留页面 | 保留输入并提示失败原因，可重试 |
| 提交（自评） | 全部目标已有有效自评分 | 是（提交后只读，可撤回） | 底部按钮 loading | 提示「自评已提交」，状态变为待上级评价 | 定位缺项并提示，可重试 |
| 提交（上级评价） | 全部目标已有上级评分与评语 | 是（提交后进入通晒） | 底部按钮 loading | 提示「评价已提交，进入待通晒」，返回列表 | 定位缺项并提示，可重试 |
| 退回自评 | 当前用户为直接上级且状态为待上级评价 | 是（必须填写退回原因） | 弹窗按钮 loading | 提示「已退回自评」，状态回到自评中 | 提示失败原因，可重试 |
| 撤回自评 | 当前用户为员工本人且上级未提交 | 是 | 底部按钮 loading | 提示「已撤回到草稿」，进入可编辑 | 提示失败原因，可重试 |
| 查看流程信息 | 无 | 否 | 页签内容加载态 | 展示节点时间与状态 → 停留本页 | 页签内展示加载失败与「重试」 |
| 展开 / 收起评级规则 | 无 | 否 | 无 | 规则卡展开或收起 | 无 |
