# 绩效评价 · 业务规则

> 本功能描述自评与上级评价的操作规则；周期、评级机制与权限总表见[共享业务规则](../../文档/业务规则.md)，字段口径见[共享数据模型](../../文档/数据模型.md)，评分范围、必填性、总分精度与评级阈值见[绩效参数配置](../../绩效参数配置/文档/业务规则.md)，页面元素见 [页面元素.md](页面元素.md)。

## 1. 功能边界

- 本功能承载员工自评、直接上级评价、自评退回与撤回、评价进度查看与催办。
- 不做：目标拟定与确认、最终等级校准、考核名单维护、周期配置、薪酬与激励计算。
- 评价结果提交后进入绩效通晒待校准；本功能不修改通晒后的最终等级。

## 2. 列表与数据范围

- 列表按角色提供三个视图：**我的考核表**（员工本人）、**待我评价**（直接上级）、**中心考核表**（中心负责人与 HRBP）。
- 筛选条件：考核周期、考核状态、所属部门、关键字（姓名 / 工号）；条件之间为「且」关系。
- 默认按考核状态与逾期情况排序：待评价与逾期在前，其余按部门、职级、姓名字典序。
- 「我的考核表」只含本人一张表；「待我评价」只含直接下级中状态为待上级评价的考核表；「中心考核表」覆盖本中心全部考核表，含不纳入人员（展示「/」并标注原因）。
- 考核表详情仅对上述范围内人员开放；越权访问按无权限处理。

## 3. 自评规则

- 自评入口在「我的考核表」中，考核表状态为未开始或自评中时开放。
- 自评内容包括：每个目标的自评分与自评说明；评分范围与精度、自评说明必填性取[绩效参数配置](../../绩效参数配置/文档/业务规则.md)。
- 考核表存在未生效目标时，提示「目标尚未全部生效，暂不能自评」；目标全部生效后自动进入自评中。
- 自评可多次保存草稿，草稿不参与进度统计；提交后状态变为待上级评价，自评列只读。
- 上级尚未提交评价前，员工可撤回自评重新填写；上级已提交后不可撤回，如需调整走更正并留痕。
- 自评截止后未提交的考核表标记「逾期未自评」；逾期是否允许补填取绩效参数配置，允许时员工仍可补填；HRBP 可在中心视图查看逾期清单。

## 4. 上级评价规则

- 上级评价入口在「待我评价」中，考核表状态为待上级评价时开放；自评逾期不影响上级评价开展。
- 上级可查看员工自评分与自评说明，逐项填写上级评分与上级评语；评分范围与精度、上级评语必填性取绩效参数配置。
- 评价可保存草稿；提交后状态变为待通晒，评分与评语只读。
- 上级可退回自评，退回时必须填写原因；退回后考核表回到自评中，员工补充后重新提交。
- 提交前如发现员工自评明显缺失，上级可仅退回自评而不修改评分。
- 评价截止后未提交的考核表标记「逾期未评价」，由 HRBP 催办；催办只产生提醒，不改变状态。

## 5. 总分、建议等级与系数

- 加权总分 = 各评价项「上级评分 × 权重」之和 ÷ 100；小数位与舍入方式取绩效参数配置。
- 总分与建议等级在上级评分过程中实时预览，提交后固化；提交后总分不可改写。
- 建议等级按绩效参数配置中的各级分数下限映射，具体阈值与系数以周期参数快照为准。
- 建议等级与系数仅供通晒参考，最终等级以中心通晒确认为准。
- 按参数配置完成全部必填评分与评语后，才允许提交；存在缺项时提交按钮禁用并提示缺项。
- 员工自评总分单独计算；是否展示取绩效参数配置，用于与上级评分对照，不参与最终等级映射。

## 6. 流程信息

- 考核表详情「流程信息」页签展示：周期名称与考核区间、考核名单确认时间、目标确认生效时间、自评提交时间、上级评价提交时间、团队通晒与中心通晒日期、最终结果生效时间。
- 每个节点展示状态（已完成 / 进行中 / 未开始）与操作人；未到达节点展示「未开始」。
- 流程信息只读，不提供跳转与操作。

## 7. 周期与状态衔接

- 周期进入评价阶段后，考核表按名单批量生成，状态为未开始；目标全部生效后转为自评中。
- 周期进入通晒阶段后，未提交的考核表按逾期处理，仍保留在待评价列表并提示 HRBP。
- 周期归档后考核表只读；未提交的考核表标记「未完成评价」，不生成最终等级。

## 8. 权限编码

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:PERFORMANCE_REVIEW` | 未授权不展示菜单 |
| 自评填报 | `BTN:HR_PERFORMANCE_REVIEW:SELF` | 员工本人可见 |
| 上级评价 | `BTN:HR_PERFORMANCE_REVIEW:MANAGER` | 直接上级可见 |
| 提交 | `BTN:HR_PERFORMANCE_REVIEW:SUBMIT` | 自评提交与上级提交共用，按状态区分 |
| 退回 | `BTN:HR_PERFORMANCE_REVIEW:RETURN` | 直接上级可见 |
| 催办 | `BTN:HR_PERFORMANCE_REVIEW:REMIND` | 中心负责人与 HRBP 可见 |

- 数据权限：员工仅本人考核表；直接上级仅直接下级；部门负责人本部门只读；中心负责人与 HRBP 本中心，HRBP 具备催办权限。
- 菜单权限与数据权限同时校验；越权进入详情按无权限处理，不展示评分与评语。
