# 绩效目标管理

## 模块概述

人资管理 → HR管理 → 绩效管理下的考核起点：在考核周期内为个人、组（四级组织）、部门（三级组织）拟定 OKR 目标，逐项维护指标描述、衡量标准与权重；同一主体同周期的目标权重合计必须为 100%。目标经直接上级确认后「已生效」，已生效目标的每次变更需再次确认并生成新版本，历史版本可查可对比。目标进度由本人维护，仅作过程参考，不参与评分。

## 端

- **web**：人资管理 → HR管理 → 绩效管理 → 绩效目标管理，仅桌面端管理后台，不提供 App 入口

## When to Use

- 员工在周期内拟定个人 OKR，填写指标描述、衡量标准与权重
- 组负责人、部门负责人维护本组或本部门的团队目标
- 检查同一主体的目标权重合计是否为 100%，处理权重校验提示
- 提交目标给直接上级确认，或作为上级确认、退回下辖目标
- 将个人目标对齐到已生效的组目标或部门目标
- 查看已生效目标的历史版本，对比版本间的内容差异
- 在周期内更新目标进度

## Tips

- 权重校验以同一周期、同一考核主体的全部目标为口径，合计未达 100% 不能提交确认
- 单目标权重与进度范围、建议目标个数、可见范围默认值、截止后变更窗口取[绩效参数配置](../绩效参数配置/SKILL.md)，本模块不复述数值
- 目标状态为草稿或待确认时可编辑；已生效目标修改需再次确认并生成新版本
- 对齐关系只指向已生效的组目标或部门目标；上级目标后续变更不自动改写已对齐的个人目标
- 周期到达目标截止日期后不再接受新增目标与权重调整，仅可更新进度
- 规则查找：目标操作规则看 文档/业务规则.md，字段口径看分组 文档/数据模型.md
