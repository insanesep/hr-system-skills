# 绩效目标管理 · 页面元素说明

> 字段口径见[共享数据模型](../../文档/数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，单个工作台承载目标列表、编辑与历史版本，不设独立详情路由。权重与进度范围、可见范围选项与默认值取[绩效参数配置](../../绩效参数配置/文档/业务规则.md)。

<a id="target-workbench"></a>

## 目标工作台

- **页面路径**：`/hr/performance/target`
- **权限编码**：路由 `MENU:HR:PERFORMANCE_TARGET`；按钮见 [业务规则.md §9](业务规则.md#9-权限编码)
- **页面类型**：操作列表页（卡片列表 + 抽屉编辑）
- **区块职责**：
  - 页头：标题「绩效目标管理」+ 副标题「拟定并确认本周期 OKR 目标」+ 周期选择入口
  - 周期概览卡：周期名称、阶段标签、目标截止日期、当前主体目标个数、权重合计、剩余待确认数
  - 视图切换：我的目标 / 团队目标 / 部门目标，按数据权限展示可切换项
  - 目标区：工具栏（目标个数、权重合计提示、「新建目标」）+ 目标卡片列表 + 空态
  - 抽屉：目标编辑抽屉、历史版本抽屉
- **目标卡片元素**：状态标签（草稿 / 待确认 / 已生效）、标题、权重、进度条、可见范围、对齐目标、指标描述、衡量标准（分条）、最近更新时间、操作区；被退回的草稿在卡片顶部展示退回原因提示条
- **操作区按钮**：编辑、提交确认、撤回、历史版本、确认、退回（按状态与权限组合展示）
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、BusyInput、PageableSelect、InputNumber、Tag、Progress、Drawer、Message、Confirm
- **布局引用**：参见原型 `原型图/web/performance-targets.html`

### 目标编辑抽屉

- **打开方式**：新建目标、点击目标的「编辑」，抽屉从右侧滑出，宽度约 560px。
- **字段**：标题（输入框，必填）、权重（数字输入，取值范围取绩效参数配置，必填）、可见范围（下拉，选项与默认值取绩效参数配置）、对齐目标（下拉，选填，仅列已生效上级目标）、指标描述（多行文本，必填）、衡量标准（多行文本，必填，按行分条）。
- **校验反馈**：
  - 必填缺失时字段标红并提示，提交动作被拦截
  - 权重合计不为 100% 时，抽屉底部展示「当前权重合计 90%，还差 10%」并拦截「提交确认」
  - 标题与同主体已有目标重复时提示「目标标题已存在」
- **底部操作**：取消、保存草稿、提交确认（草稿状态）；已生效目标展示「保存并重新提交确认」，并在变更说明输入框中要求填写原因。
- **关闭行为**：关闭抽屉后丢弃未提交的修改，重新打开以已保存内容为准。

### 历史版本抽屉

- **打开方式**：目标卡片或编辑抽屉中的「历史版本」。
- **内容**：
  - 版本列表：版本号、生效时间、提交人、变更说明，按版本号倒序
  - 版本快照：选中版本的标题、指标描述、衡量标准、权重、可见范围、对齐目标
  - 版本对比：选择两个版本后，逐字段展示「旧值 → 新值」，无变化的字段不展示
- **空态**：目标尚未生效过时展示「暂无历史版本，目标首次生效后生成版本」。

### 导航关系

- 来源页：菜单「人资管理 / HR管理 / 绩效管理 / 绩效目标管理」进入；周期切换器切换历史周期
- 去向页：无下级页面；编辑与历史版本均为抽屉，不跳转
- 返回行为：抽屉关闭回到目标工作台，保留当前视图、周期与滚动位置
- 面包屑：首页 / 人资管理 / HR管理 / 绩效管理 / 绩效目标管理

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 切换视图 | 具备对应数据权限 | 否 | 目标区加载态 | 展示对应范围目标 → 停留本页 | 目标区展示加载失败与「重试」 |
| 新建目标 | 周期处于目标设定阶段且有编辑权限 | 否 | 无 | 打开编辑抽屉 | 无权限时按钮不展示 |
| 保存草稿 | 标题、指标描述、衡量标准、权重已填写 | 否 | 抽屉底部按钮 loading | 提示「已保存草稿」，卡片状态为草稿 | 保留抽屉内容并提示失败原因，可重试 |
| 提交确认 | 权重合计为 100% 且必填完整 | 是（提交后不可编辑，需撤回） | 抽屉底部按钮 loading | 提示「已提交，等待上级确认」，卡片状态为待确认 | 保留抽屉内容并提示具体校验项 |
| 撤回 | 目标为待确认 | 是 | 卡片操作 loading | 提示「已撤回」，状态回到草稿 | 提示失败原因，可重试 |
| 确认 | 当前用户为直接上级且目标为待确认 | 是 | 卡片操作 loading | 提示「目标已生效」，状态为已生效并生成版本 | 提示失败原因，可重试 |
| 退回 | 当前用户为直接上级且目标为待确认 | 是（必须填写退回原因） | 卡片操作 loading | 提示「已退回」，状态回到草稿并展示原因 | 提示失败原因，可重试 |
| 历史版本 | 目标已生效过 | 否 | 抽屉内容加载态 | 展示版本列表与快照 | 抽屉内展示加载失败与「重试」 |
| 更新进度 | 目标已生效且周期未进入通晒 | 否 | 无 | 进度条即时更新并提示「进度已更新」 | 回滚到原进度并提示失败 |
