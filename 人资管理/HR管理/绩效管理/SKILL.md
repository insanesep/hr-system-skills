# 绩效管理

## 模块概述

人资管理 → HR管理 下的绩效考核分组，按「目标 → 评价 → 通晒」三个阶段组织一个考核周期：

- **绩效目标管理**：员工拟定个人 OKR，组与部门负责人维护团队目标；直接上级确认后生效，变更保留历史版本。
- **绩效评价**：员工自评，直接上级逐项评分并填写评语，系统按目标权重合成分数，自动映射绩效等级与绩效系数。
- **绩效通晒**：团队与中心两层通晒会，会上校准绩效等级、维护后续计划与原因，按部门、层级、序列、司龄查看分布与基线偏差，修改全程留痕，中心确认后结果生效。
- **绩效参数配置**：独立参数模块，集中维护周期与名单、目标、评价、评级与系数、分布基线、通晒六类参数；参数按版本发布，考核周期创建时生成快照，三个过程功能与员工档案按快照执行。

本分组只承载考核过程、结果与规则参数，不承载薪酬核算、奖金发放与晋升调薪决策。

## 端

- **web**：人资管理 → HR管理 → 绩效管理 → 绩效目标管理 / 绩效评价 / 绩效通晒 / 绩效参数配置，仅桌面端管理后台，不提供 App 入口

## When to Use

- 员工在周期内拟定、调整个人 OKR，或上级确认、退回下辖目标
- 组负责人、部门负责人维护团队目标并查看与上级目标的对齐关系
- 员工提交自评，直接上级完成逐项评分与评语
- TL 主持团队通晒，中心负责人或 HRBP 主持中心通晒并校准等级
- 查看中心、部门、层级、序列、司龄维度的绩效分布与基线偏差
- 查询通晒中的每一次修改记录，或导出通晒结果
- 维护绩效参数版本，调整评级阈值与系数、分布基线、目标与评价规则、通晒短语
- 复核考核周期阶段、考核名单与权限编码，或查询某周期实际使用的参数快照

## Tips

- 三个过程功能共用同一考核周期与同一份考核名单；周期阶段决定各功能当前可操作的范围
- 评级阈值、绩效系数、比例基线、目标与评价规则、通晒短语等参数统一在[绩效参数配置](绩效参数配置/SKILL.md)维护，子功能只消费不复述
- 参数按版本发布，考核周期创建时生成参数快照；进行中与已归档周期口径不变，新版本只影响之后创建的周期
- 自评与上级评分属于评价过程数据；通晒只校准最终等级、后续计划与原因，不回写评分
- 绩效系数仅展示与导出，薪酬核算不在本分组范围
- 员工资料「绩效」页签只读引用本分组最终生效结果，不提供办理入口
