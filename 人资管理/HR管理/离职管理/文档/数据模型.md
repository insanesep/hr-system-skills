# 离职管理 · 数据模型

> 本文件为离职单、交接事项、审批与操作记录的字段口径；规则见 [业务规则.md](业务规则.md)。离职单与员工、编制明细行、离职替补需求为一对一或一对多关联。

<a id="1-离职单"></a>

## 1. 离职单

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 离职单号 | 离职单唯一标识 | 文本 | 是 | 全局唯一，按年月生成，如 OB20261123001 |
| 员工 | 离职员工 | 文本 | 是 | 引用员工资料，须为在职状态 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 组织路径 | 离职时组织快照 | 文本 | 是 | 一至五级组织，取自发起时员工任职 |
| 职位 | 离职时职位快照 | 文本 | 是 | 引用标准职位或员工资料当前职位名称 |
| 职级 | 离职时职级快照 | 文本 | 是 | 如 P5 |
| 岗位序列 | 离职时岗位序列快照 | 文本 | 否 | 引用岗位管理 |
| 入职日期 | 员工入职日期 | 日期 | 是 | 取自员工资料当前任职 |
| 直接上级 | 离职时直接上级 | 文本 | 是 | 取自员工资料 |
| 编制明细标识 | 员工当前编制明细行 | 文本 | 否 | 引用编制管理；无编制时为空 |
| 离职类型 | 离职分类 | 枚举 | 是 | 主动离职、协商离职、公司单方解除、合同到期不续签、试用期不通过、退休、其他 |
| 离职原因 | 离职原因分类 | 枚举 | 是 | 个人发展、薪酬待遇、家庭原因、身体原因、组织调整、绩效不达标、严重违纪、合同到期、其他 |
| 原因说明 | 原因补充说明 | 文本 | 否 | 不超过 500 字；其他原因时必填 |
| 最后工作日 | 员工最后工作日 | 日期 | 是 | 不得早于发起日期；实际离职日期取本字段 |
| 发起日期 | 离职单创建日期 | 日期 | 是 | 系统写入 |
| 提交时间 | 提交审批时间 | 日期时间 | 否 | 草稿为空 |
| 审批状态 | 审批结果 | 枚举 | 是 | 待审批、已通过、已驳回、已撤回 |
| 单据状态 | 离职单当前状态 | 枚举 | 是 | 草稿、待审批、待离职、待确认、已离职、已撤销 |
| 确认日期 | HR 确认离职的日期 | 日期 | 否 | 已离职时填写，不替代最后工作日 |
| 实际离职日期 | 写入员工档案的离职日期 | 日期 | 否 | 取最后工作日 |
| 交接状态 | 交接整体状态 | 枚举 | 是 | 未开始、进行中、已完成、有逾期 |
| 是否发起离职替补 | 是否创建离职替补需求 | 枚举 | 是 | 是、否；默认否 |
| 离职替补需求号 | 关联招聘需求 | 文本 | 否 | 发起后写入，引用招聘管理 |
| 离职替补状态 | 招聘需求状态 | 枚举 | 否 | 未发起、已发起、已关闭 |
| 绩效处理状态 | 绩效名单处理结果 | 枚举 | 否 | 未处理、已移出、已保留 |
| 合同解除状态 | 合同解除办理状态 | 枚举 | 否 | 未办理、办理中、已完成、不适用 |
| 协商补偿说明 | 协商离职补偿方案说明 | 文本 | 否 | 协商离职时填写，不记录金额计算 |
| 关联转正单 | 试用期不通过关联的转正单 | 文本 | 否 | 由转正管理发起时写入 |
| 关联异动单 | 进行中的调岗晋升单 | 文本 | 否 | 确认前校验为空 |
| 备注 | 补充说明 | 文本 | 否 | 不超过 500 字 |
| 创建人 | 发起人 | 文本 | 是 | — |
| 创建时间 | 创建时间 | 日期时间 | 是 | — |
| 更新时间 | 最近更新时间 | 日期时间 | 是 | — |

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|

| 完成时间 | 实际完成时间 | 日期时间 | 否 | 已完成时填写 |
| 备注 | 补充说明 | 文本 | 否 | 不超过 300 字 |
| 操作人 | 最近更新人 | 文本 | 是 | — |
| 更新时间 | 最近更新时间 | 日期时间 | 是 | — |

## 6. 实体关系

- 员工与离职单为一对多：一名员工可有多段任职与多次离职，同一时点仅一张进行中离职单。
- 离职单与交接事项为一对多：一张离职单生成多条交接事项。
- 离职单与审批记录为一对多：每个审批节点生成一条记录。
- 离职单与离职面谈为一对一或一对多：至少一次面谈记录，可为空。
- 离职单与离职替补需求为一对零或一：发起后关联一条招聘需求。
- 离职单与编制明细行为多对一：离职单关联员工当前编制行，确认后回减该行在编人数。
