# 离职管理 · 页面元素

> 字段口径见 [数据模型.md](数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端；离职台账与离职详情在同一路由下以列表与详情视图互联，发起、审批与确认以抽屉或弹层承载，不单独占菜单。原型见 [原型图/web/offboarding.html](../原型图/web/offboarding.html)。

## 离职台账

### 页面结构

- **页头**：面包屑「首页 / 人资管理 / HR管理 / 离职管理」；页头右侧「发起离职」「批量提醒」「导出」。
- **统计卡**：待审批、待离职、待确认、本月已离职、交接未完成；数字按当前用户数据权限统计。
- **页签**：待审批、待离职、待确认、已离职、已撤销；待离职为审批通过且最后工作日未到，待确认为最后工作日已到且未确认离职；页签展示记录数，切换保留筛选并回到第一页。
- **基础筛选**：姓名 / 工号、组织、离职类型、最后工作日区间、交接状态、离职状态。
- **高级筛选**：离职原因、审批状态、是否发起离职替补、绩效处理状态、合同解除状态、是否逾期。
- **表格列**：离职单号、姓名、工号、组织、职位、职级、离职类型、最后工作日、交接进度、审批状态、单据状态、是否逾期、操作。
- **行内操作**：查看详情、审批、编辑、撤回、确认离职、发起离职替补；按状态与权限展示。
- **批量操作**：批量提醒交接、批量导出；已离职记录只读。

### 交互

- 筛选条件之间为「且」关系；条件变更即时查询，不设独立查询按钮。
- 待离职按最后工作日升序，待确认按最后工作日升序并突出逾期；已离职按实际离职日期倒序，已撤销按撤销时间倒序。
- 最后工作日早于今天且未确认的记录在日期列以警示色标识；交接未完成展示「有逾期」标签。
- 查询结果为空时展示「暂无离职记录」；加载失败展示失败提示与「重试」。
- 切换页签与筛选条件写入 URL 查询参数，刷新后保留。

## 发起离职

- **抽屉结构**：
  - 员工信息：员工选择器、工号、组织、职位、职级、入职日期、直接上级、编制明细行；选择员工后只读带出。
  - 离职信息：离职类型、离职原因、原因说明、最后工作日、协商补偿说明、备注。
  - 交接安排：交接负责人、计划完成日期、是否发起离职替补。
  - 关联信息：关联转正单、关联合同到期信息；由对应入口进入时只读带出。
- **校验**：员工须在职；最后工作日不得早于今天；离职原因与类型必填；选择其他原因须填写说明；协商离职须填写补偿说明。
- **底部**：取消、保存草稿、提交审批。
- **保存结果**：草稿可在台账「待审批」页签的草稿筛选中查看；提交后进入待审批并生成交接清单。

## 审批

- **审批抽屉**：展示离职单摘要、员工信息、离职类型与原因、最后工作日、交接计划、审批链与当前节点。
- **操作**：通过、驳回、撤回（发起人）、转交（可选）。
- **规则**：驳回须填写意见；通过后进入待离职；当前节点非本人时仅展示只读。
- **反馈**：审批成功后局部刷新区列表与统计卡；失败保留内容并提示原因。

## 离职详情

### 页面结构

- **页头**：离职单号、员工姓名、当前状态、逾期标记；右侧操作按状态展示「编辑」「提交」「撤回」「审批」「确认离职」「发起离职替补」「导出」。
- **概览卡**：员工、组织、职位、职级、入职日期、最后工作日、离职类型、直接上级、交接进度。
- **页签**：离职信息、交接事项、审批记录、影响范围、离职面谈、操作记录。
- **离职信息**：展示 [数据模型.md §离职单](数据模型.md#1-离职单) 的全部字段；金额与补偿计算不展示。
- **交接事项**：表格展示事项类型、名称、是否必备、负责人、计划完成日期、状态、完成时间与备注；行内可标记完成、撤销完成、标记不适用；支持批量提醒。
- **审批记录**：按时间正序展示节点、审批人、结果、意见与时间；当前节点高亮。
- **影响范围**：分组展示员工资料、编制管理、招聘管理、绩效管理、合同管理与员工成长记录的回写结果或待办状态；只读。
- **离职面谈**：展示面谈记录，HRBP 可新增或编辑；面谈不阻断流程。
- **操作记录**：按时间倒序展示操作类型、内容、操作人与时间。

## 确认离职

- **确认弹层**：展示最后工作日、审批状态、必备交接完成情况、进行中异动单校验结果、回写影响清单。
- **前置条件**：最后工作日不晚于今天、审批已通过、全部必备交接事项已完成、无进行中的调岗晋升单。
- **不满足时**：逐项列出未满足条件与处理入口；确认按钮置灰。
- **确认后**：弹层切换为结果态，展示员工资料、编制、绩效、合同与成长记录的回写结果；离职单进入已离职并只读。

## 撤销与逾期

- **撤销**：待审批与待离职阶段展示撤销入口；撤销须填写原因；已确认离职不展示撤销。
- **逾期**：最后工作日已过但未确认的记录在台账与详情展示逾期标签；不自动确认、不自动关闭。
- **异常**：员工被调岗、组织停用或审批节点失效时，在详情顶部提示并阻止提交或确认。

## 空态与权限

- 台账无数据展示「暂无离职记录」；交接事项为空展示「暂无交接事项」；审批记录为空展示「暂无审批记录」。
- 加载失败在对应区块展示失败提示与「重试」，重试沿用原筛选条件。
- 菜单权限 `MENU:HR:OFFBOARDING`；发起、编辑、提交、审批、撤回、交接、确认、提醒、导出与敏感字段分别按按钮权限展示。
- 数据权限按组织范围过滤：HR 管理员全量，HRBP 本中心，中心负责人本中心只读，招聘负责人本人负责，部门负责人本部门只读。
