# 离职管理 · 业务规则

> 本文件描述离职单从发起到确认离职的规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。确认离职后回写员工资料、编制管理、招聘管理、绩效管理与员工成长记录。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 离职单 | 一名员工一次离职办理的记录，是审批、交接、确认离职与回写的最小单位 |
| 离职类型 | 主动离职、协商离职、公司单方解除、合同到期不续签、试用期不通过、退休、其他 |
| 最后工作日 | 员工在公司的最后一个工作日，离职日期以该日期为准 |
| 实际离职日期 | 确认离职后写入员工档案的离职日期，取最后工作日 |
| 交接事项 | 离职前须完成的工作交接、资产归还、账号权限停用、财务借款、合同文件与其他事项 |
| 必备事项 | 确认离职前置的交接事项，未完成不可确认 |
| 确认离职 | HR 或 HRBP 核对最后工作日与交接结果后，将员工状态置为离职并触发回写的终态操作 |
| 离职替补 | 因员工离职产生的招聘需求，按招聘管理规则创建，关联离职单 |
| 离职面谈 | HR 或 HRBP 与离职员工进行的面谈记录，选填，不阻断流程 |
| 离职逾期 | 最后工作日已过但未确认离职，或必备交接事项未完成 |

## 2. 功能边界

- 本功能承载离职申请、审批、交接、确认离职、撤销与导出。
- 不做：招聘流程推进、入职办理、绩效评价与等级校准、薪酬结算、社保公积金核算、劳动合同签订与解除审批、员工档案日常维护。
- 员工资料、编制、招聘、绩效与合同只读引用或按确认结果回写；离职单不直接修改编制数量与招聘需求人数。
- 离职面谈与离职原因用于记录与分析，不改变薪酬结算口径。

## 3. 离职类型与发起

- 离职类型固定为主动离职、协商离职、公司单方解除、合同到期不续签、试用期不通过、退休、其他；选择其他须填写说明。
- 发起离职必须选择在职员工，带出组织、职位、职级、入职日期、直接上级与当前编制明细行；上述字段为快照，员工异动后不自动改写已提交离职单。
- 最后工作日不得早于发起日期；最后工作日为空的离职单不可提交。
- 试用期不通过由转正管理发起时，离职类型固定为试用期不通过，并关联转正单。
- 合同到期不续签由[合同管理](../../合同管理/SKILL.md)或 HR 发起，关联合同记录与离职单。
- 协商离职须填写补偿方案说明与协商日期；补偿金额与支付不在本功能计算。
- 离职原因按原因字典选择，支持补充说明；原因字典包含个人发展、薪酬待遇、家庭原因、身体原因、组织调整、绩效不达标、严重违纪、合同到期、其他。

## 4. 状态机与审批

- 离职单状态：草稿、待审批、待离职、待确认、已离职、已撤销。
- 审批状态：待审批、已通过、已驳回、已撤回；审批状态与单据状态分别记录。
- 发起后可保存草稿或直接提交；提交后进入待审批，草稿不生成交接清单、不改变员工状态。
- 审批链：直接上级 → 部门负责人 → HRBP；经理级及以上、关键岗位、协商离职或公司单方解除增加中心负责人审批。
- 审批通过后进入待离职并生成交接清单；审批驳回回到草稿并记录驳回原因。
- 待审批阶段申请人可撤回；撤回后回到草稿，可修改后重新提交。
- 待离职阶段可在最后工作日前撤销离职；撤销须填写原因，已通过的审批记录保留，重新发起后按新离职单处理。
- 已确认离职后不可撤销；最后工作日已到但未确认的，撤销须由 HRBP 确认员工仍在职并记录原因，不删除原离职单。
- 同一员工同一时点仅允许一张进行中的离职单；存在待审批、待离职或待确认离职单时，不可重复发起。
- 员工存在进行中的调岗晋升单时，须先完成或撤销异动单，再提交离职；离职确认前系统再次校验。

## 5. 交接规则

- 交接清单统一包含工作交接、资产归还、账号权限停用、财务借款、合同文件与其他事项；每项可标记是否必备，默认工作交接、资产归还、账号权限停用为必备。
- 交接事项状态为未完成、已完成、不适用；不适用须填写原因，计入已完成口径但不计入完成数量。
- 每项维护负责人、计划完成日期、完成时间与备注；负责人可为直接上级、HRBP、IT、财务或行政。
- 招聘负责人、HRBP 或事项负责人可标记完成或撤销完成；每次变更写入操作记录。
- 最后工作日已到后，离职单进入待确认；必备事项未完成时在待确认标记交接逾期，由 HR 跟进；交接未完成不阻止进入待确认，但阻止确认离职。
- 离职单审批驳回或撤回时，已完成的交接记录保留，不删除；重新提交后沿用原交接清单并允许调整。

## 6. 确认离职与回写

- 确认离职须同时满足：审批状态为已通过、最后工作日不晚于今天、全部必备交接事项已完成、无进行中的调岗晋升单。
- 确认后单据状态为已离职，实际离职日期取最后工作日；确认日期单独记录，不替代实际离职日期。
- 确认离职为终态，不可撤销；确需更正时按员工档案更正流程处理，并保留原离职单与操作记录。
- 回写员工资料：在职状态改为离职，当前任职记录结束日期取实际离职日期，新增离职记录；员工工号与档案保留。
- 回写编制管理：对应编制明细行在编人数减一，写入变更类型「离职」与离职单号；审批通过阶段不回减。
- 回写绩效管理：考核名单按实际离职日期标记离职，未开始的考核表移出本期名单；已完成评价与已生效结果保留。
- 回写员工成长记录：写入离职事件，包含离职类型、离职原因、最后工作日、组织、职位与职级快照。
- 回写[合同管理](../../合同管理/SKILL.md)：生成合同解除待办并关联离职单，合同管理完成解除后回写离职单合同解除状态；解除日期取实际离职日期。
- 离职替补：确认离职后可选择发起离职替补招聘需求，需求关联离职单与编制明细行，招聘原因固定为离职替补；需求创建后按招聘管理审批，不自动发布职位。
- 同一离职单只回写一次；重复确认、重试或重复事件不重复减编制、不重复写成长记录。
- 离职后重新入职走入职管理，员工资料保留历史任职记录，新增任职记录标记再入职；原离职单不回退。

## 7. 逾期、异常与撤销

- 最后工作日已过但未确认离职时为待确认逾期，工作台与离职台账展示逾期标记；系统不自动确认、不自动减编制。
- 员工最后工作日前决定留下时，HR 在待离职阶段撤销离职；已进入待确认的，由 HRBP 确认员工仍在职后撤销并记录原因。
- 员工未办理交接离场时，HR 可标记交接事项「不适用」并填写原因，或由负责人补录完成；必备事项未完成不得确认。
- 员工失联或旷工达到公司自动离职条件的，离职类型选择公司单方解除或其他，离职原因记录事实依据；本功能不判断违纪。
- 离职单审批中组织或职位被停用、员工被调岗或离职时，审批任务标记异常并提示重新核对，不允许带失效数据通过审批。
- 导入或批量操作失败时保留原数据，失败行生成回执，不部分写入。

| 枚举 | 取值 | 展示 |
|---|---|---|
| 离职单状态 | 草稿、待审批、待离职、待确认、已离职、已撤销 | 待审批与待确认为警示标签，已离职为主色标签，其余中性 |
| 审批状态 | 待审批、已通过、已驳回、已撤回 | 待审批为警示标签，已通过为主色，其余中性 |
| 离职类型 | 主动离职、协商离职、公司单方解除、合同到期不续签、试用期不通过、退休、其他 | 文本 |
| 交接事项状态 | 未完成、已完成、不适用 | 已完成为主色，未完成为警示，不适用为中性 |
| 交接事项类型 | 工作交接、资产归还、账号权限停用、财务借款、合同文件、其他 | 文本 |
| 离职原因 | 个人发展、薪酬待遇、家庭原因、身体原因、组织调整、绩效不达标、严重违纪、合同到期、其他 | 文本；其他补充说明 |
| 是否发起离职替补 | 是、否 | 文本 |
| 离职替补状态 | 未发起、已发起、已关闭 | 已发起为主色，未发起为中性 |

## 9. 权限编码与数据范围

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:OFFBOARDING` | 未授权不展示菜单 |
| 发起离职 | `BTN:HR_OFFBOARDING:CREATE` | 未授权不展示发起入口 |
| 编辑离职单 | `BTN:HR_OFFBOARDING:EDIT` | 草稿与待审批可编辑 |
| 提交审批 | `BTN:HR_OFFBOARDING:SUBMIT` | 发起人可见 |
| 审批 | `BTN:HR_OFFBOARDING:APPROVE` | 按审批节点校验 |
| 撤回 | `BTN:HR_OFFBOARDING:WITHDRAW` | 发起人与 HRBP 可见 |
| 交接维护 | `BTN:HR_OFFBOARDING:HANDOVER` | 事项负责人、HRBP 与招聘负责人可见 |
| 确认离职 | `BTN:HR_OFFBOARDING:CONFIRM` | 未授权不展示确认入口 |
| 批量提醒 | `BTN:HR_OFFBOARDING:REMIND` | 未授权不展示提醒入口 |
| 导出 | `BTN:HR_OFFBOARDING:EXPORT` | 未授权不展示导出按钮 |
| 敏感字段查看 | `BTN:HR_OFFBOARDING:SENSITIVE` | 手机号、证件号码与离职原因明文查看 |

- 数据权限：招聘负责人可见本人负责的离职单；HRBP 本中心；中心负责人本中心只读；HR 管理员全量；部门负责人本部门只读。
- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 10. 与其他模块的边界

- **招聘管理**：离职单只提供离职替补需求来源与关联，不创建职位、候选人与 Offer。
- **编制管理**：确认离职后回减在编人数；离职单不修改编制数量、编制计划与招聘占用。
- **绩效管理**：离职单标记考核名单离职状态；绩效评价、等级与系数仍由绩效管理决定。
- **员工档案**：员工资料只读展示离职结果；档案更正与再入职不在本功能办理。
- **工作台**：待审批、待交接、待确认与逾期数量进入工作台待办与预警，口径以本功能为准。
