# 离职管理

## 模块概述

人资管理 → HR管理下的离职办理入口：以「离职单」为主线，承接员工主动离职、协商离职、公司单方解除、合同到期不续签与试用期不通过等场景；从发起、审批到交接与确认离职，完成员工状态变更、编制在编回减、招聘离职替补、绩效名单移出与员工成长记录写入。列表以「待审批 / 待离职 / 待确认 / 已离职 / 已撤销」五个页签组织台账，支持按组织、离职类型、最后工作日、交接状态与离职状态筛选，批量提醒交接、导出名单；单人详情集中呈现离职信息、交接事项、审批记录、影响范围与操作记录。

本功能只承载离职申请、审批、交接与确认离职，不承载招聘流程、入职办理、绩效评价、薪酬结算、社保公积金核算与劳动合同签订。

## 端

- **web**：人资管理 → HR管理 → 离职管理，仅桌面端管理后台，不提供 App 入口

## When to Use

- 员工主动提出离职，由 HR 或员工发起离职单并提交审批
- 审批离职单，查看审批链、当前节点与审批意见
- 跟进工作交接、资产归还、账号权限停用、财务借款与合同文件
- 调整最后工作日、离职类型或离职原因，或撤销未生效的离职
- 确认离职，回写员工档案、编制在编、招聘离职替补、绩效名单与成长记录
- 批量提醒交接事项、导出离职台账或复核权限编码

## 离职台账

<a id="离职台账"></a>

- 页签固定为待审批、待离职、待确认、已离职、已撤销；待离职为审批通过且最后工作日未到的记录，待确认为最后工作日已到且未确认离职的记录。
- 基础筛选包含姓名 / 工号、组织、离职类型、最后工作日区间、交接状态、离职状态；高级筛选包含离职原因、审批状态、招聘替补状态、绩效处理状态与是否逾期。
- 统计卡展示待审批、待离职、待确认、本月已离职与交接未完成数量；数字只统计当前用户数据权限内可处理的记录。
- 支持批量提醒未完成交接事项、导出当前筛选结果；导出字段按当前显示列生成，证件号码与手机号默认脱敏。

## 发起与审批

<a id="发起与审批"></a>

- 发起离职必须选择在职员工，填写离职类型、离职原因、最后工作日、交接负责人与是否发起离职替补；最后工作日不得早于发起日期。
- 离职单提交后进入待审批，审批链为直接上级 → 部门负责人 → HRBP；经理级及以上、关键岗位或协商解除增加中心负责人审批。
- 审批通过后进入待离职并生成交接清单；审批驳回回到草稿并记录驳回原因；申请人可在待审批阶段撤回。
- 待离职阶段可在最后工作日前撤销离职；撤销须填写原因并记录，审批记录保留，重新发起按新离职单处理。最后工作日已到但未确认的，撤销须 HRBP 确认员工仍在职并记录原因；已确认离职不可撤销。
- 同一员工同一时点仅允许一张进行中的离职单；存在进行中调岗晋升或转正单时，须先处理或明确终止。

## 交接事项

- 交接清单统一包含工作交接、资产归还、账号权限停用、财务借款、合同文件与其他事项；每项维护负责人、是否必备、状态与完成时间。
- 交接状态为未完成、已完成、不适用；必备事项未完成时不可确认离职，不适用须填写原因。
- 招聘负责人、HRBP 或事项负责人可标记完成或撤销完成；每次变更写入操作记录。
- 最后工作日已到但交接未完成时，记录进入待确认并标记逾期，由 HR 跟进；不自动取消离职。

## 确认离职

<a id="确认离职"></a>

- 确认离职须同时满足：最后工作日不晚于今天、审批已通过、全部必备交接事项已完成、无进行中的调岗晋升单。
- 确认后：员工在职状态变为离职、当前任职记录结束、实际离职日期取最后工作日、编制在编人数减一、绩效名单标记离职、生成合同解除待办、写入员工成长记录。
- 确认离职为终态操作，不可撤销；确需更正时按员工档案更正流程处理，不回退离职单。
- 确认离职后可选择发起离职替补招聘需求，需求关联离职单并在招聘管理按离职替补原因创建；是否发起不影响离职生效。

## 影响范围

- **员工资料**：在职状态改为离职，当前任职记录结束日期取实际离职日期，新增离职记录；员工档案保留历史任职与绩效。
- **编制管理**：确认离职后对应编制明细行在编人数减一，释放招聘占用；离职单审批通过不提前释放。
- **招聘管理**：离职替补需求按招聘规则创建与审批；离职单只提供关联，不直接生成职位或候选人。
- **绩效管理**：考核名单按离职日期标记离职；已生效绩效结果保留，未完成评价按绩效管理规则处理。
- **员工成长记录**：写入离职事件，包含离职类型、最后工作日、组织与职位快照。
- **合同管理**：确认离职后生成合同解除待办并关联离职单；合同管理完成解除后回写合同解除状态。

## Tips

- 最后工作日不等于确认日期：实际离职日期取最后工作日，确认日期用于记录 HR 办理时间
- 审批通过只进入待离职，不提前减少编制在编；确认离职才回写编制与招聘
- 待离职阶段可撤销；已确认离职不可撤销，也不回退编制与招聘计数
- 离职替补需求不自动创建，由 HR 在确认离职后按业务需要发起
- 证件号码、手机号与离职原因默认脱敏或按敏感字段权限展示
- 规则查找：状态机与回写规则看 [文档/业务规则.md](文档/业务规则.md)，字段口径看 [文档/数据模型.md](文档/数据模型.md)，页面元素看 [文档/页面元素.md](文档/页面元素.md)
