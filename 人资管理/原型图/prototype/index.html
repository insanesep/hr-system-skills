示例集团 · 人资管理 / 新增模块原型 静态 Mock · 10 个模块

人资管理 · 新增模块原型

岗位管理、离职管理、转正管理、调岗晋升、人才信息、员工成长记录、合同管理、考勤管理与人才盘点九宫格；均为单页静态 Mock，可直接打开体验页签、抽屉与弹层。

按依赖顺序

1 · 岗位管理

职级体系 / 标准职位 / 岗位映射

已启用
职级矩阵、12 个岗位序列、标准职位库与在岗映射切换；职级矩阵为唯一真源。

2 · 离职管理

申请 / 审批 / 交接 / 确认

已启用
五页签台账、离职详情、交接清单、确认离职与编制/招聘/绩效回写。

3 · 转正管理

评估 / 审批 / 延期 / 不通过

已启用
六页签台账、四维评估抽屉、转正详情与不通过转离职。

4 · 调岗晋升

调岗 / 晋升 / 降职

已启用
五页签台账、原目标对比、发起异动、审批与自动生效、生效冲突。

5 · 人才信息

关键信息 / 访谈&沟通 / 述职 / 会议观察 / 人才盘点

HRBP 记录
人才观察记录维护与版本更正；保存后写入员工成长记录事件，员工本人不可见。

6 · 员工成长记录

员工列表 / 事件时间线

只读
入职、转正、晋升、绩效、人才盘点、访谈沟通、述职、会议观察、关键信息与离职事件时间线。

7 · 合同管理

签订 / 续签 / 到期 / 解除

已启用
六页签合同台账、待签订、待生效、即将到期、续签与解除；员工资料与成长记录联动。

8 · 考勤管理

日考勤 / 月考勤 / 假勤 / 规则

已启用
日/月考勤、异常处理、假勤审批、考勤组与班次规则；月度确认与工作台联动。

9 · 工作台

待办 / 预警 / 日程 / 数据

聚合
按角色聚合 10 个模块待办、合同与考勤预警、未来七天日程与 8 个数据卡。

10 · 人才盘点九宫格

数据明细 / 九宫格汇总

人才盘点
人岗匹配度 × 潜力评估台账；按职级档、岗位、部门分组查看 3×3 分布、格位名单与通晒版本导出。
