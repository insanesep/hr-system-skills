# 人才信息

## 模块概述

人资管理 → 员工档案下的人才信息入口：HRBP 按员工维护关键信息、访谈&沟通、述职、会议观察与人才盘点五类记录，形成员工的人才观察档案。记录保存即生效，并由本模块写入员工成长记录事件；记录更正生成新版本，撤销保留历史。本功能只承载人才观察记录的维护与查询，不承载员工基础信息、组织职位、绩效结果、异动与薪酬的办理，也不重新计算绩效、编制与薪酬。

## 端

- **web**：人资管理 → 员工档案 → 人才信息，仅桌面端管理后台，不提供 App 入口

## When to Use

- 按员工维护关键信息、访谈&沟通、述职、会议观察与人才盘点记录
- 按组织、最近盘点结果与最近记录时间定位员工人才档案
- 查看某员工的五类记录、述职报告附件与盘点应用建议
- 追溯记录写入成长记录的事件与版本
- 复核人才信息的填写路径、可见范围与权限编码

## 员工列表

<a id="员工列表"></a>

- 列表以员工为一行，展示工号、姓名、组织、当前职位、职级、在职状态、最近盘点结果、最近记录类型、最近记录日期与操作；按最近记录日期倒序，无记录员工按入职日期倒序排后。
- 支持按姓名 / 工号、组织、最近盘点结果与最近记录时间筛选；筛选条件之间为「且」关系。
- 行内操作仅「查看人才档案」；无批量操作。
- 员工范围取员工资料数据权限与人才信息数据权限的交集；员工本人与直接上级（非部门负责人）不在列表中展示。

## 人才档案

<a id="人才档案"></a>

- 页头展示员工概览：姓名、工号、组织、当前职位、职级、在职状态、入职日期与司龄；展示「仅 HRBP 与管理者可见」提示。
- 页签包含关键信息、访谈&沟通、述职、会议观察与人才盘点；各页签按记录时间倒序展示，最近记录置顶。
- 每个页签提供「新增记录」；记录行提供查看、编辑与撤销；人才盘点同一周期仅一条有效记录，重复新增时提示。
- 述职记录支持上传述职报告附件并在线预览；个人简历归员工资料附件，不在本模块重复上传。
- 记录保存即生效并写入员工成长记录；保存成功提示「已保存，并同步写入员工成长记录」。
- 记录编辑生成新版本，原版本只读；撤销需二次确认，撤销后记录与成长记录事件均标记已撤销，不删除历史。

## 记录类型与写入

| 记录类型 | 关键字段 | 写入事件 |
|---|---|---|
| 关键信息 | 记录时间、记录内容、记录人 | 关键信息 |
| 访谈沟通 | 沟通时间、沟通类型、沟通关键信息、记录人 | 访谈沟通 |
| 述职 | 述职时间、述职类型、述职关键信息、管理者反馈、BP 观察、述职报告附件、记录人 | 述职 |
| 会议观察 | 观察时间、会议场景、观察记录、记录人 | 会议观察 |
| 人才盘点 | 盘点周期、盘点结果、应用建议、盘点人、确认时间 | 人才盘点 |

- 同一员工同一盘点周期仅一条有效盘点记录；其余记录类型可多条。
- 事件按「记录编号 + 版本号 + 事件类型」幂等写入；重复保存不重复生成。
- 记录更正时成长记录新增更正事件并将原事件标记已更正；记录撤销时原事件标记已撤销。
- 盘点结果取不胜任、胜任、高潜；盘点不改变绩效等级、系数与薪酬，绩效以绩效管理通晒结果为准。

## 权限与可见范围

- 写入：HRBP（本中心）与 HR 管理员可新增、编辑与撤销记录；中心负责人与部门负责人只读。
- 可见：HRBP 本中心、部门负责人本部门、中心负责人本中心、HR 管理员全量；员工本人与直接上级（非部门负责人）不可见。
- 菜单与按钮按权限编码校验：菜单 `MENU:HR:TALENT`；新增 `BTN:HR_TALENT:RECORD_CREATE`；编辑 / 更正 `BTN:HR_TALENT:RECORD_EDIT`；撤销 `BTN:HR_TALENT:RECORD_REVOKE`；查看详情 `BTN:HR_TALENT:DETAIL`；附件预览 `BTN:HR_TALENT:ATTACHMENT_PREVIEW`。
- 记录内容不含薪酬、证件号码与手机号；附件仅在线预览，不提供下载。

## 与员工成长记录的联动

- 五类记录保存、更正与撤销时由本模块写入成长记录事件；成长记录只读展示，不提供手工新增、编辑与删除。
- 人才信息事件在成长记录中按「来源模块限定」控制可见范围；员工本人与直接上级不因成长记录获得可见性。
- 成长记录事件保留记录编号、记录时间、记录人、记录摘要与当时组织职位快照；来源跳转回人才档案对应页签，按人才信息权限校验。

## Tips

- 人才信息是 HRBP 记录的写入口，员工资料与员工成长记录均为只读消费
- 记录内容属于敏感观察信息，仅 HRBP 与管理者可见，不进入员工资料档案
- 盘点结果与管理标签、绩效等级是不同口径：盘点不改绩效，管理标签由组织职位信息推导
- 规则查找：记录写入与可见规则看 [文档/业务规则.md](文档/业务规则.md)，字段口径看 [文档/数据模型.md](文档/数据模型.md)，页面元素看 [文档/页面元素.md](文档/页面元素.md)
