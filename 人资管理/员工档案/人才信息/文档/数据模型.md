# 人才信息 · 数据模型

> 本文件为人才信息记录、版本与附件的字段口径；规则见 [业务规则.md](业务规则.md)。记录由本模块维护，并写入员工成长记录事件。

## 1. 人才档案派生视图

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 员工 | 员工姓名 | 文本 | 是 | 引用员工资料 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 组织 | 当前组织路径 | 文本 | 是 | 引用员工资料 |
| 当前职位 | 当前职位名称 | 文本 | 是 | 引用员工资料 |
| 职级 | 当前职级 | 文本 | 是 | 引用员工资料 |
| 在职状态 | 在职、离职 | 枚举 | 是 | 引用员工资料 |
| 最近盘点结果 | 最新有效盘点结果 | 枚举 | 否 | 不胜任、胜任、高潜；无盘点展示「未盘点」 |
| 最近盘点周期 | 最新有效盘点所属周期 | 文本 | 否 | 如 2026H2 |
| 最近记录类型 | 最近一条有效记录的类型 | 枚举 | 否 | 五类记录类型之一 |
| 最近记录日期 | 最近一条有效记录的记录时间 | 日期 | 否 | 按记录时间与创建时间倒序 |
| 记录总数 | 有效记录条数 | 数值 | 是 | 不含已更正版本与已撤销记录 |

## 10. 实体关系

- 员工与人才信息记录为一对多：一名员工可有多条记录。
- 记录与记录版本为一对多：每次保存生成一个版本，历史版本只读。
- 记录版本与记录附件为一对多：述职记录可上传多份述职报告。
- 记录与操作记录为一对多：新增、更正与撤销均写入操作记录。
- 人才档案为派生视图，不单独存储。
- 人才信息记录与成长事件为一对多：同一记录的不同版本可分别产生事件。
- 记录编号按类型前缀加年度流水生成：关键信息 KI、访谈沟通 IV、述职 RP、会议观察 OB、人才盘点 TR。
