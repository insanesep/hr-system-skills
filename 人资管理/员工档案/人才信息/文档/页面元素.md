# 人才信息 · 页面元素

> 字段口径见 [数据模型.md](数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，员工列表与人才档案同菜单下互联；记录新增、编辑与撤销以抽屉与弹窗承载。原型见 [原型图/web/talent-info.html](../原型图/web/talent-info.html)。

<a id="talent-list"></a>

## 员工列表

### 页面结构

- **页面路径**：`/hr/talent/list`。
- **权限编码**：菜单 `MENU:HR:TALENT`；查看人才档案 `BTN:HR_TALENT:DETAIL`。
- **页头**：面包屑「首页 / 人资管理 / 员工档案 / 人才信息」；标题「人才信息」+ 副标题「维护 HRBP 人才观察记录，自动写入员工成长记录」；无页级操作。
- **可见范围提示**：列表上方提示「人才信息仅 HRBP、部门负责人、中心负责人与 HR 管理员可见，员工本人不可见」。
- **筛选**：姓名 / 工号、组织、最近盘点结果（全部、不胜任、胜任、高潜、未盘点）、最近记录时间区间。
- **表格列**：工号、姓名、组织、当前职位、职级、在职状态、最近盘点结果、最近记录类型、最近记录日期、操作。
- **行内操作**：查看人才档案；无批量操作与写操作。
- **排序**：按最近记录日期倒序；无记录员工排后，按入职日期倒序。
- **组件引用**：`Button`、`Table`、`Tag`、`Pagination`、`Message`。

### 交互

- 筛选条件之间为「且」关系，条件变更即时查询。
- 点击员工行或「查看人才档案」进入人才档案，保留列表筛选与页码。
- 空态展示「暂无人才信息记录」；加载失败展示失败提示与「重试」。
- 员工本人与直接上级（非部门负责人）不在列表中展示。

## 人才档案

### 页面结构

- **页面路径**：`/hr/talent/detail/:id`（非菜单页面）。
- **权限编码**：查看 `BTN:HR_TALENT:DETAIL`；新增 `BTN:HR_TALENT:RECORD_CREATE`；编辑 `BTN:HR_TALENT:RECORD_EDIT`；撤销 `BTN:HR_TALENT:RECORD_REVOKE`；附件预览 `BTN:HR_TALENT:ATTACHMENT_PREVIEW`。
- **页头**：返回员工列表；员工姓名、工号、在职状态；右侧「仅 HRBP 与管理者可见」标签。
- **员工概览**：组织、当前职位、职级、入职日期、司龄、最近盘点结果、最近记录。
- **页签**：关键信息 / 访谈&沟通 / 述职 / 会议观察 / 人才盘点，默认「关键信息」。
- **页签工具栏**：记录条数、记录时间区间筛选、「新增记录」按钮（按权限展示）。
- **记录表格**：
  - 关键信息：记录编号、记录时间、记录内容摘要、记录人、状态、操作。
  - 访谈&沟通：记录编号、沟通时间、沟通类型、沟通关键信息摘要、记录人、状态、操作。
  - 述职：记录编号、述职时间、述职类型、述职关键信息摘要、管理者反馈摘要、附件、记录人、状态、操作。
  - 会议观察：记录编号、观察时间、会议场景、观察记录摘要、记录人、状态、操作。
  - 人才盘点：记录编号、盘点周期、盘点结果、应用建议摘要、盘点人、确认时间、状态、操作。
- **行内操作**：查看、编辑、撤销；已撤销记录只保留查看。
- **组件引用**：`Button`、`Tabs`、`Table`、`Tag`、`Drawer`、`Modal`、`Message`。

### 交互

- 切换页签只切换记录区，员工概览不变。
- 记录按记录时间倒序，同时间按创建时间倒序；最近盘点结果取最新有效盘点。
- 无记录时展示「暂无记录，点击新增记录开始沉淀」；无编辑权限时隐藏新增、编辑与撤销入口。
- 加载失败在记录区展示失败提示与「重试」，重试沿用当前页签与筛选。

## 新增 / 编辑记录抽屉

- **抽屉结构**：标题「新增记录 · 记录类型」或「编辑记录 · 记录类型」；副标题展示员工与当前版本号。
- **通用字段**：记录时间（关键信息）、沟通时间（访谈沟通）、述职时间（述职）、观察时间（会议观察）、确认时间（人才盘点）；记录人取当前登录人，只读展示。
- **分类字段**：
  - 关键信息：记录内容（多行文本，必填，≤1000 字）。
  - 访谈沟通：沟通类型（下拉，必选六类）、沟通关键信息（多行文本，必填，≤1000 字）。
  - 述职：述职类型（下拉，必选四类）、述职关键信息（多行文本，必填，≤1000 字）、管理者反馈（多行文本，选填，≤1000 字）、BP 观察（多行文本，选填，≤1000 字）、述职报告附件（上传，可多份）。
  - 会议观察：会议场景（下拉，必选四类）、观察记录（多行文本，必填，≤1000 字）。
  - 人才盘点：盘点周期（文本，必填，如 2026H2）、盘点结果（下拉，必选不胜任 / 胜任 / 高潜）、应用建议（多行文本，选填，≤500 字）。
- **编辑态**：回填当前有效版本；底部展示「本次保存将生成新版本，并同步写入员工成长记录」；须填写更正原因。
- **校验**：必填项为空、文本超长、盘点周期重复时阻止保存并提示；同一员工同一盘点周期仅一条有效记录。
- **底部操作**：取消、保存；保存成功提示「已保存，并同步写入员工成长记录」，抽屉关闭并刷新记录表格。
- **附件**：上传后展示文件名、大小、上传人、上传日期与预览入口；预览失败展示失败提示。

## 记录详情抽屉

- **记录信息**：记录编号、记录类型、记录时间、记录人、记录状态、当前版本号。
- **内容信息**：按记录类型展示关键信息全文、沟通类型与正文、述职类型与正文、管理者反馈、BP 观察、会议场景与观察记录、盘点周期 / 结果 / 应用建议。
- **附件信息**：附件名称、类型、大小、上传人、上传日期、预览入口；无附件展示「无附件」。
- **版本与操作记录**：版本号、操作类型、操作人、操作时间、更正 / 撤销原因；按操作时间倒序。
- **只读**：详情抽屉不提供编辑、删除与重新写入；编辑从记录行进入编辑抽屉。

## 撤销记录确认

- 点击「撤销」打开确认弹窗，展示员工、记录类型、记录时间与记录编号。
- 弹窗说明「撤销后记录与成长记录事件将标记为已撤销，历史保留且不可恢复；同一盘点周期撤销后可重新新增」。
- 须填写撤销原因；确认后记录状态变为已撤销，成长记录事件同步标记已撤销，提示「已撤销，成长记录事件已标记为已撤销」。
- 取消关闭弹窗，不改变记录状态。

## 导出

- 本模块不提供导出；需要事件清单时在员工成长记录按筛选导出。

## 空态与权限

- 员工列表无数据展示「暂无人才信息记录」；人才档案页签无记录展示「暂无记录」。
- 加载失败在对应区块展示失败提示与「重试」，重试沿用原筛选条件。
- 菜单权限、按钮权限与数据权限同时校验；员工本人与直接上级（非部门负责人）不可见。
- 数据权限：HRBP 本中心、部门负责人本部门、中心负责人本中心、HR 管理员全量；写入仅 HRBP 与 HR 管理员。
