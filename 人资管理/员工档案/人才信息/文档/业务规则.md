# 人才信息 · 业务规则

> 本文件描述人才信息记录的类型、写入、版本、更正撤销与可见规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。本功能承载 HRBP 人才观察记录的维护，记录由本模块写入员工成长记录。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 人才信息记录 | HRBP 对员工的一次人才观察记录，包含关键信息、访谈沟通、述职、会议观察与人才盘点五类 |
| 记录版本 | 一次记录保存形成的版本；首次保存为版本 1，每次更正版本号递增 |
| 记录状态 | 有效、已更正、已撤销 |
| 盘点周期 | 人才盘点所属周期，如 2026H1、2026H2 |
| 盘点结果 | 不胜任、胜任、高潜 |
| 应用建议 | 基于盘点结果给出的使用与培养建议，纯文本 |
| 记录时间 | 记录对应的业务发生时间：关键信息为记录时间，访谈沟通为沟通时间，述职为述职时间，会议观察为观察时间，人才盘点为确认时间 |

## 2. 功能边界

- 本功能承载关键信息、访谈&沟通、述职、会议观察与人才盘点记录的维护、查询、更正与撤销。
- 不做：员工基础信息、组织职位、绩效等级与系数、异动、合同、编制与薪酬的办理；不重新计算绩效、编制与薪酬。
- 员工资料、员工成长记录、绩效管理与岗位管理均为只读引用，本功能不修改其业务结果。
- 人才信息记录不进入员工资料只读档案；员工成长记录只读消费本模块写入的事件。
- 不提供导出、批量导入与移动端入口。

## 3. 记录类型与写入

| 记录类型 | 关键字段 | 写入事件 | 事件日期 |
|---|---|---|---|
| 关键信息 | 记录时间、记录内容、记录人 | 关键信息 | 记录时间 |
| 访谈沟通 | 沟通时间、沟通类型、沟通关键信息、记录人 | 访谈沟通 | 沟通时间 |
| 述职 | 述职时间、述职类型、述职关键信息、管理者反馈、BP 观察、附件、记录人 | 述职 | 述职时间 |
| 会议观察 | 观察时间、会议场景、观察记录、记录人 | 会议观察 | 观察时间 |
| 人才盘点 | 盘点周期、盘点结果、应用建议、盘点人、确认时间 | 人才盘点 | 确认时间 |

- 记录保存即生效，由本模块写入员工成长记录事件；记录人取当前保存人。
- 同一员工同一盘点周期仅一条有效盘点记录；其余记录类型可多条。
- 事件按「记录编号 + 版本号 + 事件类型」幂等写入；同一版本重复保存不重复生成事件。
- 记录的更正与撤销同步写入成长记录：更正新增更正事件并将原事件标记已更正；撤销将原事件标记已撤销。
- 述职记录可上传述职报告附件，附件随记录版本保存；个人简历由入职管理采集，归员工资料附件。
- 盘点结果不改变绩效等级、绩效系数、绩效名单与薪酬；绩效结果以绩效管理通晒确认结果为准。

## 4. 更正与撤销

- 记录编辑保存生成新版本，版本号在记录内递增；原版本只读，保留版本内容、操作人、操作时间与原因。
- 更正须填写更正原因；更正不修改员工资料、绩效结果与组织职位信息。
- 记录撤销须二次确认并填写撤销原因；撤销后记录状态为已撤销，记录与历史版本保留，不删除。
- 已撤销记录不计入记录总数与最近记录，不参与最近盘点结果计算。
- 同一盘点周期记录撤销后，可重新新增该周期盘点记录。
- 更正与撤销只由具备编辑或撤销权限的角色发起；成长记录不提供手工改正或置为撤销。

## 5. 展示与排序

- 员工列表以员工为一行，按最近记录日期倒序；无记录员工排在有记录员工之后，按入职日期倒序。
- 最近记录取全部有效记录中记录时间最新的一条；已更正版本不参与最近记录。
- 人才档案页签按记录时间倒序，同时间按创建时间倒序；页面展示当前有效版本内容。
- 列表最近盘点结果取该员工最新有效盘点记录的盘点结果；无盘点展示「未盘点」。
- 记录内容摘要过长时截断，详情抽屉展示全文；附件展示文件名、大小、上传人与上传日期。
- 页签筛选与排序只影响当前页签，不改变员工概览。

## 6. 数据权限与脱敏

- 写入：HRBP 按所对接中心、HR 管理员可新增、编辑与撤销记录。
- 可见：HRBP 本中心、部门负责人本部门、中心负责人本中心、HR 管理员全量。
- 员工本人不可见；直接上级非部门负责人时不可见；员工资料不可见的员工，人才信息同样不可见。
- 记录内容与附件不得包含薪酬、证件号码、手机号与绩效评语等敏感信息；确需引用时按公司脱敏要求处理。
- 附件仅在线预览，不提供下载与外链分享；无预览权限时不展示预览入口。
- 记录内容仅对具备人才信息数据权限的角色展示；成长记录不扩大该可见范围。

## 7. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 记录状态 | 有效、已更正、已撤销 | 有效为主色，已更正为提示，已撤销为中性 |
| 记录类型 | 关键信息、访谈沟通、述职、会议观察、人才盘点 | 文本 |
| 沟通类型 | 绩效沟通、反馈沟通、转正沟通、离职沟通、日常访谈、其他 | 文本 |
| 述职类型 | 转正述职、晋升述职、年度述职、其他 | 文本 |
| 会议场景 | 经营分析会、项目评审会、部门例会、其他 | 文本 |
| 盘点结果 | 不胜任、胜任、高潜 | 高潜为主色，胜任为成功，不胜任为警示 |
| 操作类型 | 新增、更正、撤销 | 文本 |

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:TALENT` | 未授权不展示菜单 |
| 查看人才档案与记录详情 | `BTN:HR_TALENT:DETAIL` | 未授权不展示查看入口 |
| 新增记录 | `BTN:HR_TALENT:RECORD_CREATE` | 未授权不展示新增入口 |
| 编辑 / 更正记录 | `BTN:HR_TALENT:RECORD_EDIT` | 未授权不展示编辑入口 |
| 撤销记录 | `BTN:HR_TALENT:RECORD_REVOKE` | 未授权不展示撤销入口 |
| 附件预览 | `BTN:HR_TALENT:ATTACHMENT_PREVIEW` | 未授权不展示预览入口 |

- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 9. 与其他模块的边界

- **员工资料**：员工身份、组织、职位、职级、在职状态与简历附件以员工资料为准；人才信息只读引用，不回写档案。
- **员工成长记录**：本模块是人才信息事件的唯一来源；成长记录只读展示，不新增、编辑或删除事件。
- **绩效管理**：绩效沟通可引用考核周期与结果摘要；人才盘点不改变绩效等级、系数、名单与薪酬。
- **岗位管理**：组织、职位、职级与管理标签以岗位管理与部门管理为准；人才信息不维护组织职位信息。
- **入职管理**：个人简历由入职信息采集产生，归员工资料附件；述职报告由本模块述职记录上传。
- **工作台**：本模块不新增工作台待办；人才信息记录不作为待办或预警来源。

## 10. 敏感信息与附件

- 人才信息记录属于 HRBP 观察信息，默认按数据权限限制可见范围，员工本人不可见。
- 记录正文避免写入薪酬、证件号码、手机号与家庭住址等敏感信息；确需记录时按公司脱敏要求处理。
- 附件类型包含述职报告与其他材料；附件随记录版本保存，撤销记录后附件仍保留可追溯。
- 附件预览失败时展示文件信息与失败提示，可重新预览；不提供下载与外链分享。
