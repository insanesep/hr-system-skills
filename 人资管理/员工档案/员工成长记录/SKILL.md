# 员工成长记录

## 模块概述

人资管理 → 员工档案下的员工成长事件流水入口：以员工为主线，汇总入职、转正、调岗、晋升、降职、绩效、岗位信息变更、离职、合同与人才信息事件，按时间倒序形成可追溯的成长时间线。事件由各来源模块在业务生效时写入，本功能只读展示，不手工新增、编辑或删除；每条事件保留来源单据、事件日期、组织、职位、职级与操作人快照，来源单据更正或撤销时事件标记状态并保留历史。

人才信息记录（人才盘点、访谈沟通、述职、会议观察、关键信息）由人才信息模块写入，按来源模块限定可见范围。本功能只承载事件流水的汇总与查看，不承载入职、转正、异动、绩效、岗位、人才信息与离职的办理，也不重新计算绩效、编制与薪酬。

## 端

- **web**：人资管理 → 员工档案 → 员工成长记录，仅桌面端管理后台，不提供 App 入口

## When to Use

- 按员工查看成长时间线，了解入职、转正、异动、绩效、人才观察与离职轨迹
- 按事件类型、组织、时间与来源模块筛选事件
- 查看事件详情、来源单据与事件发生时的组织职位快照
- 追溯绩效结果、岗位信息变更、人才盘点或离职事件的来源
- 按权限查看 HRBP 人才盘点、访谈沟通、述职、会议观察与关键信息事件
- 导出员工成长记录，或复核事件可见范围与脱敏规则

## 员工列表

<a id="员工列表"></a>

- 列表以员工为一行，展示工号、姓名、组织、当前职位、职级、在职状态、事件总数、最近事件类型与最近事件日期；按最近事件日期倒序，无事件员工排后。
- 支持按姓名 / 工号、组织、职位、在职状态、事件类型与最近事件时间筛选；筛选条件之间为「且」关系。
- 行内操作仅「查看时间线」；无批量操作与写操作。
- 员工范围与员工资料数据权限一致；越权员工不在列表中展示。

## 员工时间线

<a id="员工时间线"></a>

- 页头展示员工概览：姓名、工号、组织、当前职位、职级、在职状态、入职日期与司龄。
- 时间线按事件日期倒序展示，同日期按事件创建时间倒序；每条事件展示事件类型、标题、摘要、事件日期、来源模块与当时组织 / 职位快照。
- 支持按事件类型、来源模块与时间区间筛选；筛选后时间线只展示匹配事件，员工概览不变。
- 事件类型包含入职、转正、转正延期、转正未通过、调岗、晋升、降职、绩效、人才盘点、访谈沟通、述职、会议观察、关键信息、岗位信息变更、离职、合同签订、合同续签、合同解除、其他；合同事件由合同管理写入，人才信息事件由人才信息写入。
- 事件卡片可打开详情抽屉；详情展示来源单据号、来源模块、事件日期、组织职位快照、操作人与事件状态。
- 时间线只读，不提供新增、编辑、删除与手工排序；导出按当前筛选生成员工事件清单。

## 事件详情

<a id="事件详情"></a>

- **事件信息**：事件编号、员工、事件类型、事件日期、标题、摘要、状态（有效、已更正、已撤销）。
- **来源信息**：来源模块、来源单据号、来源单据状态；可跳转来源模块详情，跳转按来源模块权限校验。人才信息事件展示记录类型、记录时间、记录人与记录摘要，跳转人才档案对应页签。
- **快照信息**：事件发生时的组织路径、职位、职级、职级类别、岗位序列与直接上级。
- **操作记录**：事件创建、更正与撤销记录，包含时间、操作人与原因。

## 事件来源与写入

- 入职确认写入入职事件；转正生效、延期与不通过写入对应转正事件；异动生效写入调岗、晋升或降职事件；绩效最终结果生效写入绩效事件；岗位映射切换写入岗位信息变更事件；离职确认写入离职事件。
- 人才信息记录保存写入人才盘点、访谈沟通、述职、会议观察与关键信息事件；记录更正生成新版本并写入更正事件，记录撤销将原事件标记已撤销。
- 每条事件按「来源单据 + 来源单据版本 + 事件类型」幂等写入；人才信息记录按版本写入，其他来源无版本时来源单据版本为空，同一单据重复事件不重复生成。
- 来源单据更正时新增更正事件并将原事件标记已更正；来源单据撤销时原事件标记已撤销，不删除。
- 事件快照在写入时固化，来源员工后续组织、职位与职级变化不回写历史事件。

## Tips

- 成长记录是只读事件流水，不替代员工资料、绩效档案与异动台账
- 事件由来源模块写入，本功能不提供手工新增与编辑；需要补录时由来源模块更正
- 事件可见范围同时受员工资料数据权限与来源模块权限约束，本功能不扩大可见范围
- 人才信息事件按「来源模块限定」可见：仅 HRBP、部门负责人、中心负责人与 HR 管理员可见，员工本人与直接上级（非部门负责人）不可见
- 绩效事件只在最终结果生效后写入；建议等级、过程评分与通晒调整不单独生成事件
- 人才盘点事件只记录盘点结果与应用建议，不改变绩效等级、系数与薪酬
- 岗位信息变更事件只记录岗位名称切换，不生成调岗或晋升事件
- 规则查找：事件写入与可见规则看 [文档/业务规则.md](文档/业务规则.md)，字段口径看 [文档/数据模型.md](文档/数据模型.md)，页面元素看 [文档/页面元素.md](文档/页面元素.md)
