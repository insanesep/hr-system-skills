# 员工成长记录 · 数据模型

> 本文件为成长事件与事件快照的字段口径；规则见 [业务规则.md](业务规则.md)。事件由来源模块写入，本功能只读。

## 1. 成长事件

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 事件编号 | 事件唯一标识 | 文本 | 是 | 全局唯一，按事件生成 |
| 员工 | 事件所属员工 | 文本 | 是 | 引用员工资料 |
| 工号 | 员工工号 | 文本 | 是 | 与员工资料一致 |
| 事件类型 | 事件分类 | 枚举 | 是 | 入职、转正、转正延期、转正未通过、调岗、晋升、降职、绩效、人才盘点、访谈沟通、述职、会议观察、关键信息、岗位信息变更、离职、合同签订、合同续签、合同解除、其他 |
| 事件日期 | 事件实际发生日期 | 日期 | 是 | 入职日期、转正生效日、异动生效日、绩效生效日、盘点确认日、沟通 / 述职 / 观察时间、离职日期等 |
| 标题 | 事件标题 | 文本 | 是 | 如「转入职」「晋升为 P6」「2026Q3 绩效 A」 |
| 摘要 | 事件摘要 | 文本 | 是 | 不超过 300 字；不含薪酬、证件号码、手机号与绩效评语；人才信息事件摘要仅在来源模块可见范围内展示 |
| 来源模块 | 产生事件的模块 | 枚举 | 是 | 入职管理、转正管理、调岗晋升、绩效管理、人才信息、岗位管理、离职管理、合同管理、其他 |
| 来源单据号 | 来源业务单据 | 文本 | 是 | 入职单、转正单、异动单、考核表、盘点记录、沟通记录、述职记录、观察记录、关键信息记录、岗位映射记录、离职单、合同记录 |
| 来源单据状态 | 来源单据当前状态 | 文本 | 是 | 只读引用来源模块 |
| 事件状态 | 事件当前状态 | 枚举 | 是 | 有效、已更正、已撤销 |
| 操作人 | 写入事件的操作人 | 文本 | 是 | 来源单据操作人或系统 |
| 事件创建时间 | 事件写入时间 | 日期时间 | 是 | 系统写入 |
| 更正原因 | 更正或撤销原因 | 文本 | 否 | 已更正或已撤销时填写 |
| 可见范围 | 事件可见人群 | 枚举 | 是 | 员工本人、直接上级、部门、中心、全量、来源模块限定；取来源模块与员工资料交集；人才信息事件取来源模块限定 |

## 2. 事件快照

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 快照标识 | 快照唯一标识 | 文本 | 是 | 从属于事件 |
| 事件编号 | 所属事件 | 文本 | 是 | — |
| 组织路径 | 事件发生时组织 | 文本 | 是 | 一至五级组织名称快照 |
| 职位 | 事件发生时职位 | 文本 | 是 | 标准职位或员工当时职位名称 |
| 职级 | 事件发生时职级 | 文本 | 是 | 如 P5 |
| 职级类别 | 事件发生时职级类别 | 枚举 | 是 | 战略决策层、总监级、经理级、主管级、员工级 |
| 岗位序列 | 事件发生时岗位序列 | 文本 | 否 | 引用岗位管理 |
| 直接上级 | 事件发生时直接上级 | 文本 | 是 | — |
| 原信息 | 事件涉及的原组织 / 职位 / 职级 | 文本 | 否 | 调岗、晋升、降职与岗位信息变更时填写 |
| 目标信息 | 事件涉及的目标组织 / 职位 / 职级 | 文本 | 否 | 调岗、晋升、降职时填写 |

## 3. 事件来源记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 来源记录标识 | 来源记录唯一标识 | 文本 | 是 | 从属于事件 |
| 事件编号 | 所属事件 | 文本 | 是 | — |
| 来源模块 | 业务模块 | 枚举 | 是 | 同事件来源模块 |
| 来源单据号 | 来源单据唯一标识 | 文本 | 是 | 与事件一致 |
| 来源单据链接 | 来源详情入口 | 文本 | 否 | 按来源模块权限校验后展示 |
| 来源单据版本 | 来源单据版本或状态快照 | 文本 | 否 | 用于追溯；人才信息记录取记录版本号 |
| 写入时间 | 来源模块写入时间 | 日期时间 | 是 | — |
| 幂等键 | 防止重复写入的唯一键 | 文本 | 是 | 来源单据号 + 来源单据版本 + 事件类型；无版本口径时来源单据版本为空，不对外展示 |

## 4. 员工时间线派生视图

| 字段名 | 业务含义 | 取值规则 |
|---|---|---|
| 员工 | 员工姓名与工号 | 引用员工资料 |
| 组织 | 当前组织 | 引用员工资料 |
| 当前职位 | 当前职位名称 | 引用员工资料 |
| 当前职级 | 当前职级 | 引用员工资料 |
| 在职状态 | 在职、离职 | 引用员工资料 |
| 事件总数 | 该员工全部事件数 | 含已更正与已撤销事件 |
| 有效事件数 | 状态为有效的事件数 | 不含已更正与已撤销 |
| 最近事件类型 | 最近一条事件类型 | 按事件日期与创建时间倒序 |
| 最近事件日期 | 最近一条事件日期 | 同上 |

## 5. 实体关系

- 员工与成长事件为一对多：一名员工有多条事件。
- 成长事件与事件快照为一对一：每条事件固化一份组织职位快照。
- 成长事件与来源记录为一对一：每条事件关联一个来源单据与幂等键。
- 成长事件与来源单据为多对一：同一来源单据可产生多条不同类型事件。
- 员工时间线为派生视图，不单独存储。
