# 员工成长记录 · 页面元素

> 字段口径见 [数据模型.md](数据模型.md)，操作规则见 [业务规则.md](业务规则.md)。本模块仅 Web 端，员工列表与员工时间线在同一路由下互联；事件详情以抽屉承载，不设独立菜单。原型见 [原型图/web/employee-growth.html](../原型图/web/employee-growth.html)。

<a id="growth-list"></a>

## 员工列表

### 页面结构

- **页头**：面包屑「首页 / 人资管理 / 员工档案 / 员工成长记录」；页头右侧「导出」。
- **筛选**：姓名 / 工号、组织、当前职位、在职状态、事件类型（含人才盘点、访谈沟通、述职、会议观察、关键信息）、最近事件时间区间。
- **表格列**：工号、姓名、组织、当前职位、职级、在职状态、事件总数、最近事件类型、最近事件日期、操作。
- **行内操作**：查看时间线；无批量操作与写操作。
- **排序**：按最近事件日期倒序；无事件员工排后，按入职日期倒序。

### 交互

- 筛选条件之间为「且」关系，条件变更即时查询。
- 点击员工行或「查看时间线」进入时间线视图，保留列表筛选与页码。
- 空态展示「暂无成长记录」；加载失败展示失败提示与「重试」。

## 员工时间线

### 页面结构

- **页头**：返回员工列表；员工姓名、工号、在职状态；右侧「导出」。
- **员工概览**：组织、当前职位、职级、入职日期、司龄、事件总数、最近事件。
- **筛选**：事件类型、来源模块（含人才信息）、时间区间；筛选只影响时间线，不改变员工概览。
- **时间线**：按事件日期倒序展示事件卡片；同日期按事件创建时间倒序。
- **事件卡片**：左侧事件类型标签与日期；右侧标题、摘要、来源模块、当时组织 / 职位快照与状态标签；点击打开详情抽屉。人才盘点与述职为主色标签，访谈沟通、会议观察与关键信息为中性标签。
- **状态展示**：已更正与已撤销事件保留位置并展示状态标签；已撤销事件不影响有效事件统计。

### 交互

- 时间线只读，不提供新增、编辑、删除、拖动排序。
- 筛选后无匹配事件时展示「暂无符合条件的事件」；清空筛选恢复全部事件。
- 事件卡片摘要过长时截断，详情抽屉展示全文。
- 返回列表保留进入前的筛选条件与页码。

## 事件详情

- **抽屉结构**：
  - 事件信息：事件编号、事件类型、事件日期、标题、摘要、事件状态。
  - 来源信息：来源模块、来源单据号、来源单据状态、跳转入口；人才信息事件增加来源记录区，展示记录类型、记录时间、记录人、记录摘要与附件数量，跳转人才档案对应页签。
  - 快照信息：组织路径、职位、职级、职级类别、岗位序列、直接上级；异动类事件展示原信息与目标信息。
  - 操作记录：事件创建、更正与撤销的时间、操作人与原因。
- **跳转**：来源单据跳转按来源模块权限校验；无权限时只展示单据号并提示「无来源单据查看权限」。
- **只读**：抽屉不提供编辑、删除与重新写入。

## 导出

- 导出范围为当前筛选条件下的员工事件清单；员工列表导出每人一行汇总，时间线导出事件明细。
- 导出字段包含员工、组织、事件类型、事件日期、标题、摘要、来源模块、来源单据号、事件状态与快照信息；人才信息事件仅对具备人才信息数据权限的角色导出。
- 导出不包含薪酬、证件号码、手机号与绩效评语；导出记录操作人与时间，写入审计。

## 空态与权限

- 员工列表无数据展示「暂无成长记录」；时间线无事件展示「暂无成长事件」。
- 加载失败在对应区块展示失败提示与「重试」，重试沿用原筛选条件。
- 菜单权限 `MENU:HR:GROWTH`；查看时间线、事件详情与导出分别按按钮权限展示。
- 数据权限：员工本人、直接上级本团队、部门负责人本部门、中心负责人与 HRBP 本中心、HR 管理员全量；与来源模块权限取交集。
- 人才信息事件按「来源模块限定」过滤：仅 HRBP、部门负责人、中心负责人与 HR 管理员可见；员工本人与直接上级（非部门负责人）不展示该事件。
