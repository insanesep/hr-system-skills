# 员工成长记录 · 业务规则

> 本文件描述员工成长事件的来源、写入、更正、撤销与可见规则；字段口径见 [数据模型.md](数据模型.md)，页面元素见 [页面元素.md](页面元素.md)。本功能只读展示，不承载业务办理。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 成长事件 | 员工在任职期间发生的一次关键事件，如入职、转正、调岗、晋升、降职、绩效、人才盘点、访谈沟通、述职、会议观察、关键信息、岗位信息变更、离职 |
| 事件来源 | 产生事件的业务模块与来源单据 |
| 事件快照 | 事件发生时的组织、职位、职级、职级类别、岗位序列与直接上级 |
| 事件状态 | 有效、已更正、已撤销 |
| 更正事件 | 来源单据更正后新增的事件，原事件保留并标记已更正 |
| 事件流水 | 按员工与事件日期组织的事件集合，只增不改不删 |
| 人才信息记录 | HRBP 在人才信息模块维护的人才盘点、访谈沟通、述职、会议观察与关键信息记录 |
| 来源模块限定 | 事件可见范围由来源模块数据权限决定，仅授权角色可见 |

## 2. 功能边界

- 本功能承载成长事件的汇总、筛选、时间线展示、详情与导出。
- 不做：入职、转正、调岗、晋升、降职、绩效、人才信息、岗位与离职的办理；不重新计算绩效等级、编制在编与薪酬。
- 不手工新增、编辑、删除事件；来源模块更正或撤销时由来源模块写入事件状态。
- 人才信息记录由人才信息模块维护、更正与撤销；成长记录只读消费记录版本事件。
- 不扩大来源模块的数据权限；员工资料不可见的员工，成长记录同样不可见。
- 事件摘要与快照只读，不能修改历史事实。

## 3. 事件来源与写入

| 事件类型 | 来源模块 | 来源单据 | 写入时机 |
|---|---|---|---|
| 入职 | 入职管理 | 入职单 | 确认入职后 |
| 转正 | 转正管理 | 转正单 | 转正生效后 |
| 转正延期 | 转正管理 | 转正单 | 延期审批通过后 |
| 转正未通过 | 转正管理 | 转正单 | 未通过确认后 |
| 调岗 | 调岗晋升 | 异动单 | 异动生效后 |
| 晋升 | 调岗晋升 | 异动单 | 异动生效后 |
| 降职 | 调岗晋升 | 异动单 | 异动生效后 |
| 绩效 | 绩效管理 | 考核表 / 周期结果 | 中心通晒确认生效后 |
| 人才盘点 | 人才信息 | 盘点记录 | 盘点确认后 |
| 访谈沟通 | 人才信息 | 沟通记录 | 记录保存生效后 |
| 述职 | 人才信息 | 述职记录 | 记录保存生效后 |
| 会议观察 | 人才信息 | 观察记录 | 记录保存生效后 |
| 关键信息 | 人才信息 | 关键信息记录 | 记录保存生效后 |
| 岗位信息变更 | 岗位管理 | 岗位映射记录 | 岗位名称切换后 |
| 离职 | 离职管理 | 离职单 | 确认离职后 |
| 合同签订 | 合同管理 | 合同记录 | 合同签订生效后 |
| 合同续签 | 合同管理 | 合同记录 | 续签生效后 |
| 合同解除 | 合同管理 | 合同记录 | 合同解除生效后 |

- 事件按「来源单据 + 来源单据版本 + 事件类型」幂等写入；同一来源单据重复触发、重试或重复事件不重复生成。无版本口径的来源模块，来源单据版本为空。
- 事件写入时固化员工、组织、职位、职级、职级类别、岗位序列、直接上级与来源单据快照。
- 人才信息记录按版本写入事件：记录首次保存写入事件，更正生成新版本并写入更正事件，撤销将原事件标记已撤销；盘点结果不改变绩效等级、系数与薪酬。
- 绩效事件只在最终等级与绩效系数生效后写入；建议等级、评价过程与通晒调整不单独生成事件。
- 岗位信息变更事件只在岗位映射切换时写入；调岗、晋升与降职由异动单写入，不重复记录。
- 入职、转正、异动与离职事件必须关联来源单据；来源单据号为空时不得写入。

## 4. 更正与撤销

- 来源单据更正时，新增更正事件并将原事件标记已更正；原事件保留，不修改原快照与摘要。
- 来源单据撤销时，原事件标记已撤销；已撤销事件仍可在时间线查看，不参与有效事件统计。
- 事件状态只由来源模块写入；成长记录不提供手工置为已更正或已撤销。
- 事件更正不改变员工资料与业务结果；业务结果以来源模块为准。
- 人才信息记录更正时，按新版本新增更正事件并将上一版本事件标记已更正；记录撤销时原事件标记已撤销，历史版本事件保留。
- 同一来源单据可产生多条事件，如转正延期后再次转正；事件按实际发生的日期与类型分别记录。

## 5. 展示与排序

- 员工列表以员工为一行，按最近事件日期倒序；无事件员工排在有事件员工之后，按入职日期倒序。
- 时间线按事件日期倒序，同日期按事件创建时间倒序；已撤销事件保留原位置并展示状态标签。
- 事件卡片展示标题、摘要、事件日期、来源模块与当时组织 / 职位快照；摘要过长时截断，详情展示全文。
- 时间线筛选支持事件类型、来源模块与时间区间；筛选条件之间为「且」关系。
- 员工概览展示当前信息，不随筛选变化；事件卡片展示事件时快照，两者不得混淆。
- 事件详情中的来源单据跳转按来源模块权限校验；无来源权限时只展示单据号，不提供跳转。

## 6. 数据权限与脱敏

- 员工本人可见本人事件；直接上级可见直接下级；部门负责人可见本部门；中心负责人与 HRBP 可见本中心；HR 管理员可见全量。
- 成长记录可见范围取员工资料数据权限与来源模块数据权限的交集；任一不满足时不展示事件。
- 人才信息事件按「来源模块限定」过滤：仅 HRBP 本中心、部门负责人本部门、中心负责人本中心与 HR 管理员可见；员工本人与直接上级（非部门负责人）不因成长记录获得可见性。
- 事件摘要与快照不包含薪酬、证件号码、手机号与绩效评语；如来源单据包含敏感信息，只写入非敏感摘要。
- 导出按当前筛选与当前权限生成，记录导出审计；导出不包含来源单据的敏感字段。
- 合同事件按合同数据权限过滤，不扩大可见范围。

## 7. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 事件类型 | 入职、转正、转正延期、转正未通过、调岗、晋升、降职、绩效、人才盘点、访谈沟通、述职、会议观察、关键信息、岗位信息变更、离职、合同签订、合同续签、合同解除、其他 | 晋升、转正、人才盘点与述职为主色标签，降职与转正未通过为警示标签，访谈沟通、会议观察、关键信息与离职为中性 |
| 事件状态 | 有效、已更正、已撤销 | 有效为主色，已更正为提示，已撤销为中性 |
| 来源模块 | 入职管理、转正管理、调岗晋升、绩效管理、人才信息、岗位管理、离职管理、合同管理、其他 | 文本 |
| 排序方式 | 事件日期倒序、事件日期正序 | 默认倒序 |

## 8. 权限编码

| 操作 | 权限编码 | 说明 |
|---|---|---|
| 菜单入口 | `MENU:HR:GROWTH` | 未授权不展示菜单 |
| 查看时间线 | `BTN:HR_GROWTH:TIMELINE` | 未授权不展示查看入口 |
| 事件详情 | `BTN:HR_GROWTH:DETAIL` | 未授权不展示详情入口 |
| 导出 | `BTN:HR_GROWTH:EXPORT` | 未授权不展示导出按钮 |

- 菜单权限、按钮权限与数据权限同时校验；任一不满足时不展示对应入口或数据。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。

## 9. 与其他模块的边界

- **员工资料**：员工身份、当前组织职位与在职状态以员工资料为准；成长记录只读展示事件快照。
- **人才信息**：人才盘点、访谈沟通、述职、会议观察与关键信息事件由人才信息模块写入；记录更正与撤销同步更新事件状态，成长记录不修改记录与版本。
- **入职 / 转正 / 调岗晋升 / 绩效 / 岗位 / 离职**：事件由各模块写入；成长记录不修改来源单据与业务结果。
- **合同管理**：合同签订、续签与解除事件由合同管理写入；事件类型与合同状态保持一致。
- **工作台**：成长记录不进入工作台待办；员工动态可作为工作台展示入口，不改变事件口径。
