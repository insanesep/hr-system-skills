# 员工资料 · 数据定义

> 本文件为员工档案查询视图的产品字段口径。员工与四类明细为从属关系：一个员工对应多条任职记录、绩效记录、合同与附件；删除与新增不在本功能发生。

## 1. 员工

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 员工标识 | 员工的唯一标识 | 文本 | 是 | 系统内唯一，页面不展示 |
| 工号 | 员工在企业的编号 | 文本 | 是 | 唯一，列表与明细均展示 |
| 姓名 | 员工姓名 | 文本 | 是 | 关键字模糊查询的匹配字段之一 |
| 性别 | 员工性别 | 枚举 | 否 | 男、女；未登记展示「—」 |
| 出生日期 | 员工出生日期 | 日期 | 否 | 仅明细展示 |
| 手机号码 | 员工联系手机号 | 文本 | 否 | 脱敏展示，见 [business-rule.md §6](business-rule.md#6-脱敏与权限) |
| 电子邮箱 | 员工联系邮箱 | 文本 | 否 | 仅明细展示 |
| 身份证号码 | 员工身份证件号 | 文本 | 否 | 脱敏展示，仅明细展示 |
| 所属部门 | 当前任职部门名称 | 文本 | 是 | 列表筛选与展示字段 |
| 岗位 | 当前任职岗位名称 | 文本 | 是 | 列表筛选与展示字段 |
| 直属上级 | 当前汇报对象姓名 | 文本 | 否 | 仅明细展示 |
| 工作地点 | 当前主要办公地点 | 文本 | 否 | 仅明细展示 |
| 入职日期 | 员工首次入职日期 | 日期 | 是 | 列表默认排序与区间筛选字段 |
| 在职状态 | 员工当前在职情况 | 枚举 | 是 | 在职、离职 |

## 2. 任职记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 任职记录标识 | 一条任职经历的唯一标识 | 文本 | 是 | 从属于员工 |
| 部门 | 该次任职的部门名称 | 文本 | 是 | 与员工当前部门可不同 |
| 岗位 | 该次任职的岗位名称 | 文本 | 是 | 与员工当前岗位可不同 |
| 任职类型 | 该次任职的变动性质 | 枚举 | 是 | 新入职、调岗、晋升、降职 |
| 生效日期 | 该次任职开始日期 | 日期 | 是 | 列表按该日期倒序 |
| 结束日期 | 该次任职结束日期 | 日期 | 否 | 当前任职为空，展示「至今」 |
| 是否当前任职 | 是否为当前有效任职 | 布尔 | 是 | 同一员工至多一条为真 |

## 3. 绩效记录

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 绩效记录标识 | 一条考核结果的唯一标识 | 文本 | 是 | 从属于员工 |
| 考核周期 | 结果所属考核周期 | 文本 | 是 | 按周期倒序展示，如年度、季度 |
| 考核等级 | 周期考核等级 | 枚举 | 是 | A、B、C、D |
| 得分 | 周期考核分数 | 数值 | 否 | 0–100，未评分展示「—」 |
| 评定人 | 考核结果评定人姓名 | 文本 | 否 | — |
| 评定日期 | 考核结果评定日期 | 日期 | 是 | — |

## 4. 合同

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 合同标识 | 一份合同的唯一标识 | 文本 | 是 | 从属于员工 |
| 合同编号 | 合同台账编号 | 文本 | 是 | 同一员工下不重复 |
| 合同类型 | 劳动合同期限类型 | 枚举 | 是 | 固定期限、无固定期限、以完成一定工作任务为期限 |
| 签订日期 | 合同签订日期 | 日期 | 是 | 列表按该日期倒序 |
| 生效日期 | 合同生效日期 | 日期 | 是 | — |
| 到期日期 | 合同到期日期 | 日期 | 否 | 无固定期限合同为空，展示「—」 |
| 合同状态 | 合同当前状态 | 枚举 | 是 | 生效中、已到期、已解除 |

## 5. 附件

| 字段名 | 业务含义 | 类型 | 必填 | 取值规则 |
|---|---|---|---|---|
| 附件标识 | 一个附件的唯一标识 | 文本 | 是 | 从属于员工 |
| 附件名称 | 文件展示名称，含扩展名 | 文本 | 是 | 预览区标题同名 |
| 附件类型 | 附件归属类别 | 枚举 | 是 | 简历、证件、其他 |
| 文件大小 | 附件体积 | 文本 | 是 | 以 KB / MB 展示 |
| 上传人 | 附件上传人姓名 | 文本 | 否 | — |
| 上传日期 | 附件上传日期 | 日期 | 是 | — |
| 预览内容 | 附件在线预览的文件内容 | 文件 | 是 | 仅在线预览，不保存到本地 |
