## 员工列表

- **页面路径**：`/hr/employee/list`
- **权限编码**：路由 `MENU:HR:EMPLOYEE`；按钮「查看明细」`BTN:HR_EMPLOYEE:DETAIL`
- **页面类型**：操作列表页（档案查询）
- **区块职责**：
  - 页头：标题「员工资料」+ 副标题「查询员工人事档案，查看明细与附件」；无页级操作
  - 筛选卡：关键字（姓名 / 工号）、所属部门、岗位、在职状态、入职日期区间；动作区为「重置」「查询」
  - 结果卡：工具栏（列表标题「员工列表」+ 结果条数 + 数据更新时间 +「刷新」）、员工表格、空态 / 加载 / 加载失败三态、分页
- **表格列**：工号、姓名、性别、所属部门、岗位、在职状态（标签）、入职日期、手机号码（脱敏）、操作（查看明细）
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 BusyInput、PageableSelect、DatePicker、Form、Table、Pagination、Tag、Button、Message
- **编排标准**：`busyming-skills-design/shared/page-standards/web-operation-list.md`
- **布局引用**：参见原型 `assets/web/employee-list.html`

### 导航关系

- 来源页：菜单「人资管理 / 员工档案 / 员工资料」进入；员工明细点击「返回列表」回到本页
- 去向页：行内「查看明细」→ 员工明细 `/hr/employee/detail/:id`
- 返回行为：本页为模块入口页，无页内返回；从明细返回时保留原筛选条件与页码
- 面包屑：首页 / 人资管理 / 员工档案 / 员工资料

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 无（允许空条件） | 否 | 表格区加载态，查询按钮 loading | 列表展示查询结果并回到第一页 → 停留本页 | 表格区展示加载失败与「重试」，按钮恢复；重试按原条件重新查询 |
| 重置 | 无 | 否 | 表格区加载态 | 清空全部条件并恢复默认列表 → 停留本页 | 同查询失败处理 |
| 刷新 | 无 | 否 | 表格区加载态 | 按当前条件与页码刷新，更新时间戳 → 停留本页 | 同查询失败处理 |
| 查看明细 | 当前行存在 | 否 | 无 | 跳转员工明细 → `/hr/employee/detail/:id` | 无（页面跳转） |
| 分页 | 结果数大于一页 | 否 | 表格区加载态 | 展示目标页数据，筛选条件不变 → 停留本页 | 同查询失败处理 |

## 员工明细

- **页面路径**：`/hr/employee/detail/:id`
- **权限编码**：路由 `MENU:HR:EMPLOYEE`；按钮「附件预览」`BTN:HR_EMPLOYEE:ATTACHMENT_PREVIEW`
- **页面类型**：详情页（档案型）
- **区块职责**：
  - 页头：「返回列表」+ 标题「员工明细」+ 在职状态标签；无编辑等操作
  - 概览卡：姓名、工号、在职状态、所属部门、岗位、入职日期
  - 页签区：基本信息 / 任职记录 / 绩效 / 合同信息 / 附件资料，默认「基本信息」
  - 附件预览区：附件资料页签内，展示当前预览附件名称与内容，可收起
- **页签内容**：
  - 基本信息：只读描述列表（姓名、工号、性别、出生日期、手机号码、电子邮箱、身份证号码、入职日期、在职状态、所属部门、岗位、直属上级、工作地点）
  - 任职记录：部门、岗位、任职类型、生效日期、结束日期，当前任职带「当前」标识
  - 绩效：考核周期、考核等级、得分、评定人、评定日期；无记录时展示空态
  - 合同信息：合同编号、合同类型、签订日期、生效日期、到期日期、合同状态
  - 附件资料：附件名称、附件类型、文件大小、上传人、上传日期、操作（预览）；无附件时展示空态
- **组件引用**：`busyming-skills-design/components/web/docs/` 下 Button、Tag、Descriptions、BusyTabs、Table、Message
- **编排标准**：`busyming-skills-design/shared/page-standards/web-detail.md`
- **布局引用**：参见原型 `assets/web/employee-list.html#detail`（与列表同文件双视图）

### 导航关系

- 来源页：员工列表行内「查看明细」
- 去向页：无下级页面；附件预览为页内展开，不跳转
- 返回行为：页头「返回列表」→ 员工列表 `/hr/employee/list`，保留来源列表的筛选条件与页码
- 面包屑：首页 / 人资管理 / 员工档案 / 员工资料 / 员工明细

### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 切换页签 | 无 | 否 | 无（本地数据） | 展示目标页签内容，概览不变 → 停留本页 | 无 |
| 预览附件 | 当前附件存在且有预览权限 | 否 | 预览区加载态 | 页签内展开预览区并展示附件内容 → 停留本页 | 预览区展示文件信息与失败提示，可重新点击「预览」重试 |
| 收起预览 | 预览区已展开 | 否 | 无 | 关闭预览区 → 停留附件资料页签 | 无 |
| 返回列表 | 无 | 否 | 无 | 返回员工列表并保留筛选与页码 → `/hr/employee/list` | 无 |
