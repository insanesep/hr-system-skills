# 员工资料 · 业务规则

> 本功能只描述当前生效的档案查询与查看规则；字段口径见 [data.md](data.md)，页面元素见 [web-ui.md](web-ui.md)。

## 1. 名词约定

| 名词 | 定义 |
|---|---|
| 员工资料 | 一个员工的人事档案全集，由基本信息、任职记录、绩效、合同信息与附件资料构成 |
| 任职记录 | 员工在组织内的一次任职经历，含部门、岗位与生效日期；当前有效的一条为当前任职 |
| 绩效记录 | 员工某一考核周期的考核结果，仅呈现结果，不含考核过程 |
| 合同信息 | 员工已签订劳动合同的台账记录 |
| 附件资料 | 员工档案关联的文件，以简历为主，兼含证件与其他材料 |

## 2. 功能边界

- 本功能提供员工档案的**列表查询与明细查看**，全部页面只读。
- 不做：员工新增、编辑、删除、停用等档案维护，合同签订 / 续签 / 解除，绩效评定与考核流程，附件上传、删除与保存到本地。
- 绩效页签只呈现历史考核结果；合同页签只呈现合同台账；二者均不提供办理入口。
- 附件仅支持在线预览，预览失败时展示文件信息，不提供保存到本地与外链分享。

## 3. 列表查询规则

- 关键字为单输入框模糊查询，匹配员工姓名或工号；部门、岗位、在职状态为精确筛选；入职日期为闭区间筛选。
- 各条件之间为「且」关系；「查询」按当前条件刷新表格并回到第一页，「重置」清空全部条件并恢复默认列表。
- 默认不附带筛选条件，列表按入职日期倒序排列，同日期按工号升序。
- 表格列固定为：工号、姓名、性别、所属部门、岗位、在职状态、入职日期、手机号码、操作；行内操作仅「查看明细」。
- 列表无页级操作按钮，无批量选择与批量操作；分页仅改变当前页数据，不改变筛选条件。
- 查询结果为空时展示「暂无符合条件的员工」空态；加载失败时展示失败提示并提供重试，重试按原条件重新查询。

## 4. 明细展示规则

- 明细页由员工概览与五个页签组成：基本信息、任职记录、绩效、合同信息、附件资料；进入时默认打开「基本信息」。
- 概览展示姓名、工号、在职状态、所属部门、岗位、入职日期，跨页签保持可见，不随页签切换变化。
- 页签切换仅替换内容区，不重新加载员工概览；同一员工的各页签数据以同一员工为口径。
- 基本信息以只读描述列表呈现个人与任职相关字段，不使用输入框。
- 任职记录按生效日期倒序排列，当前任职置顶并标识「当前」；每条记录展示部门、岗位、任职类型、生效日期与结束日期，未结束的结束日期展示为「至今」。
- 绩效按考核周期倒序排列，展示考核周期、考核等级、得分、评定人与评定日期；无绩效记录时展示空态。
- 合同信息按签订日期倒序排列，展示合同编号、合同类型、签订日期、生效日期、到期日期与合同状态；生效中的合同以状态标签突出。
- 附件资料展示附件清单（附件名称、附件类型、文件大小、上传人、上传日期），操作仅「预览」。
- 附件预览在当前页签内展开预览区，同一时刻只预览一个附件；再次点击其他附件切换预览对象，点击「收起」关闭预览区。
- 返回列表时保留进入明细前的筛选条件与页码。

## 5. 状态与枚举

| 枚举 | 取值 | 展示 |
|---|---|---|
| 在职状态 | 在职、离职 | 在职为主色标签，离职为中性标签 |
| 任职类型 | 新入职、调岗、晋升、降职 | 文本 |
| 考核等级 | A、B、C、D | 文本标签，得分单列展示 |
| 合同类型 | 固定期限、无固定期限、以完成一定工作任务为期限 | 文本 |
| 合同状态 | 生效中、已到期、已解除 | 生效中为主色标签，其余为中性标签 |
| 附件类型 | 简历、证件、其他 | 文本 |

## 6. 脱敏与权限

- 手机号码与身份证号码为敏感字段，列表与明细均只展示脱敏结果：手机号码保留前三位与后四位，身份证号码保留前六位与后四位，其余以 `*` 替代。
- 本功能不提供明文查看入口，不因查看明细、预览附件而展示完整敏感信息。
- 菜单权限编码：`MENU:HR:EMPLOYEE`；按钮权限编码：查看明细 `BTN:HR_EMPLOYEE:DETAIL`、附件预览 `BTN:HR_EMPLOYEE:ATTACHMENT_PREVIEW`。
- 未授权菜单权限时不展示菜单入口；未授权对应按钮权限时，列表不展示「查看明细」、附件清单不展示「预览」。
- 功能权限校验接入用户权限中心，具体能力以公共契约为准，本模块不复述接口定义。
