# 项目成本管理 数据模型

> 产品侧数据模型：定义实体、核心字段语义与实体间关系；物理表结构、索引等实现细节以代码仓为准，不内嵌。

## 实体关系

```text
研发费用单 1 ─── N 品牌分摊明细
```

- 品牌分摊明细从属于费用单，随单据级联保存 / 删除，无独立生命周期
- 报表不建实体，按上述两个实体实时聚合（口径见 business-rule.md §5）

## 实体 1：研发费用单

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 流水号 | 单据唯一编号 | 文本 | 是（系统生成） | 「FY」+ 制单日期（年月日 8 位数字）+ 4 位日内序号；全局唯一，生成后不可改，软删除单据的号码不复用 |
| 费用科目 | 费用归属科目 | 枚举（单选） | 是 | 人员 / Token / 系统采购 / 弱电 / 硬件 / 差旅 / 福利 |
| 费用金额 | 单据总金额 | 金额 | 是 | > 0，两位小数（精确到分） |
| 费用开始年月 | 费用归属期间起点 | 年月 | 是 | 粒度到月；≤ 费用结束年月 |
| 费用结束年月 | 费用归属期间终点 | 年月 | 是 | 粒度到月；≥ 费用开始年月；与开始相等即单月费用 |
| 单据状态 | 流转状态 | 枚举 | 是（系统维护） | 待审核 / 已审核 / 已作废；状态机见 business-rule.md §1 |
| 制单人 | 创建人 | 人员 | 是（系统写入） | 取当前登录人 |
| 制单时间 | 创建时间 | 时间 | 是（系统写入） | 精确到秒 |
| 审核人 | 审核操作人 | 人员 | 否 | 审核时写入，此后不再变化 |
| 审核时间 | 审核操作时间 | 时间 | 否 | 审核时写入，此后不再变化 |

## 实体 2：品牌分摊明细

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 所属费用单 | 关联费用单 | 引用 | 是 | 指向所属研发费用单 |
| 行号 | 明细顺序 | 序号 | 是 | 从 1 递增；末行 = 行号最大者，承担倒算（规则见 business-rule.md §3） |
| 品牌 | 分摊主体 | 枚举（单选） | 是 | 鸣鸣很忙 / 有点推荐 / 满气食品 / 数字化中心；同单内唯一 |
| 分摊比例 | 分摊占比 | 百分比 | 是 | > 0% 且 ≤ 100%，两位小数；同一单据内合计 = 100% |
| 分摊金额 | 该品牌承担金额 | 金额 | 是（系统计算） | 前行 = 费用金额 × 比例（四舍五入到分）；末行 = 费用金额 − 前行之和 |

## 枚举清单汇总

| 枚举 | 取值（编码） |
|------|------|
| 单据状态 | 待审核 `PENDING`、已审核 `AUDITED`、已作废 `VOID` |
| 费用科目 | 人员 `PERSONNEL`、Token `TOKEN`、系统采购 `SYSTEM_PURCHASE`、弱电 `WEAK_CURRENT`、硬件 `HARDWARE`、差旅 `TRAVEL`、福利 `WELFARE` |
| 品牌 | 鸣鸣很忙 `SNACK`、有点推荐 `YDTJ`、满气食品 `MQ`、数字化中心 `DC` |
