# 功能排期 · Web 端 UI 描述

> 页面元素与交互声明以本文件为准，原型见 `assets/web/feature-schedule.html`（研发排期工作台）与 `assets/web/feature-schedule-detail.html`（卡片详情页），两页共用 `assets/web/feature-schedule-data.js` 的演示数据。视觉统一取设计系统组件与状态语义，本文件不定义私有颜色与布局；业务规则只引用、不复述。

## 页面间导航

| 源页面 | 触发动作 | 目标页面 | 返回路径 | 面包屑 |
|--------|---------|---------|---------|-------|
| Portal 菜单「功能排期管理」 | 点击菜单 | 研发排期工作台 | — | 首页 / 研发 / 研发管理 / 功能排期管理 |
| 研发排期工作台 | 点击卡片、列表行，日详情弹层与非需求改动弹层中的卡片，或右键「查看详情」 | 卡片详情页 | 「返回」或面包屑「功能排期管理」，恢复进入前的视图、期、筛选与搜索 | 首页 / 研发 / 研发管理 / 功能排期管理 / 卡片详情 |
| 研发排期工作台 | 新建卡片时所选 commit 已有卡片 | 该卡片的卡片详情页 | 同上 | 同上 |
| 卡片详情页 | 子卡明细点击子卡，或子卡点击「查看合并卡」 | 对应卡片的卡片详情页 | 「返回」回到研发排期工作台 | 同上 |
| 卡片详情页 | 删除卡片或解散合并成功 | 研发排期工作台 | — | 首页 / 研发 / 研发管理 / 功能排期管理 |
| 需求管理 · 需求详情页 | 点击关联卡片编号（新标签页） | 卡片详情页 | 关闭标签页 | 首页 / 研发 / 研发管理 / 功能排期管理 / 卡片详情 |

- 无孤儿页面：工作台为模块入口，卡片详情页经工作台任一卡片一步到达

## 页面清单

### 研发排期工作台

- **页面路径**：`/subapp/devhub/feature-schedule`
- **权限编码**：
  - 路由：`devhubFeatureSchedule`
  - 按钮：`devhubFeatureScheduleEdit`、`devhubFeatureScheduleDelete`、`devhubFeatureScheduleMarkDone`、`devhubFeatureScheduleReleaseDay`，控制范围见 [permission-rules.md §1](permission-rules.md#1-权限编码)
- **页面类型**：`order-list`
- **埋点**：页面浏览由 SDK 自动上报；点击埋点的功能编码前缀为 `RND.MANAGE.FEATURE_SCHEDULE`，命名与登记规则见 [功能使用情况管理 business-rule §1.4](../../../成本管理/功能使用情况管理/references/business-rule.md#14-功能编码命名规范)
- **区块职责**：
  - 工具栏：单行指挥栏，承载时间导航、本月进度、搜索、视图切换、筛选、新建卡片与更多菜单
  - 主体区：月视图 / 周视图 / 列表三种视图，展示当前期的排期卡片
  - 侧边栏：待排期池，展示未排期卡片，可收起，池内独立滚动
- **布局引用**：`参见原型 assets/web/feature-schedule.html`（DOM 结构依据：page-blueprint `patterns/web` 区块装配，page-root + dual-pane + table-card；参考骨架 `skeletons/web/list-page.vue.tpl`）

**H. 键盘与本机记忆**

- 快捷键：← / → 切换上一期 / 下一期；T 回到今天或本周；Esc 分层关闭，顺序为右键菜单 → 气泡确认 → 二次确认 → 弹层 → 年月选择、进度浮层、更多菜单 → 筛选抽屉 → 多选态；输入框聚焦时不响应，弹层打开时 ← / → / T 失效，页面处于后台页签时不响应
- 本浏览器记忆：当前视图、显示密度、待排期池收起状态；筛选与搜索不记忆，仅在从卡片详情页返回时恢复进入前的状态

**I. 布局**

- 页面身份由 Portal 面包屑与页签承担，业务区不渲染页面大标题
- 指挥栏在宽屏与中小屏下均保持单行；搜索框宽度随屏宽分档收缩，不挤压核心操作
- 待排期池固定宽度，视图区自适应剩余宽度
- 页面本身不滚动，视图区内部滚动，指挥栏始终可见；低高度屏压缩指挥栏纵向间距
- 窄屏（非目标桌面场景）保底为纵向堆叠布局
- 浮层默认右对齐，触发器位于左半屏时自动左对齐，均不超出视口

#### 导航关系

- 来源页：Portal 菜单「研发 / 研发管理 / 功能排期管理」进入，本页为模块入口页；卡片详情页经「返回」、面包屑，或删除卡片、解散合并成功后回到本页
- 去向页：卡片详情页（点击卡片、列表行，日详情弹层与非需求改动弹层中的卡片，右键「查看详情」，新建卡片命中已有卡片）；其余操作均在本页浮层内完成
- 返回行为：面包屑「首页」返回 Portal 首页；各浮层经关闭按钮、遮罩或 Esc 回到工作台；从卡片详情页返回时恢复进入前的视图、期、筛选与搜索，刷新页面仍按默认值
- 面包屑：首页 / 研发 / 研发管理 / 功能排期管理
- 页面可直达：路径无参数即可打开；视图、显示密度与池收起状态从本浏览器记忆恢复

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 拖拽排期 | 待排期池卡片拖入今天或之后的日期格，卡片未锁定 | 否 | 卡片加载态 | 「已排期到 MM-DD」→ 停留，卡片出现在目标日期 | toast error 显示原因 → 卡片回到原位，可重新拖拽；缺业务对接人时不报错，弹出补录业务对接人弹窗 |
| 拖拽改期 | 日历格卡片拖到另一可放置日期格 | 否 | 卡片加载态 | 「已改期到 MM-DD」→ 停留 | toast error → 卡片回到原日期，可重新拖拽；缺业务对接人时弹出补录业务对接人弹窗 |
| 拖回待排期 | 日历格卡片拖入待排期池（含落到池内卡片上，此时不触发合并） | 否 | 卡片加载态 | 「已移回待排期」→ 停留，卡片出现在池顶 | toast error → 卡片回到原日期 |
| 右键改期 | 右键菜单选「改期到今天 / 明天」 | 否 | 卡片加载态 | 「已改期到 MM-DD」→ 关闭菜单，停留 | toast error → 卡片保持原日期，可再次操作；缺业务对接人时弹出补录业务对接人弹窗 |
| 右键移回待排期 | 右键菜单选「移回待排期」 | 否 | 卡片加载态 | 「已移回待排期」→ 关闭菜单，停留 | toast error → 卡片保持原日期 |
| 补录并排期 | 补录业务对接人弹窗已填写对接人 | 否 | 「保存并排期」按钮 loading，随后卡片加载态 | 「已补录业务对接人，排期到 MM-DD」，改期时为「改期到 MM-DD」→ 关闭弹窗，卡片出现在目标日期 | 弹窗顶部 AcAlert，保留输入，按钮恢复；取消则卡片保持原位 |
| 切换发版日 | 点击可放置日期格的空白处 | 否 | 日期格加载态 | 「已标记 MM-DD 为发版日」或「已取消 MM-DD 的发版日标记」→ 停留 | toast error → 标记恢复原状，可再次点击 |
| 合并卡片 | 多选态已选 ≥2 张同模块卡片点「确认合并」，或拖到同模块卡片上 | 合并标题弹窗 | 确定按钮 loading | 「已生成合并卡 {编号}」→ 关闭弹窗、退出多选态 | 弹窗顶部 AcAlert 显示原因，按钮恢复 |
| 批量移入非需求 | 批量多选态已选 ≥1 张 | AcModal「将 N 张卡片移入非需求改动？移入后清空排期、开发人与完成 commit」 | 确认按钮 loading | 「已移入 N 张，失败 M 张」→ 关闭弹窗、退出多选态 | 失败卡保留勾选，toast error 提示失败数，可再次确认 |
| 行内领取 | 列表视图待开发行 | AcPopconfirm「确认领取开发？」 | 按钮 loading | 「已领取开发」→ 停留列表并刷新该行 | toast error，按钮恢复 |
| 行内完成 | 列表视图开发中行 | AcPopconfirm「确认标记完成？完成 commit 可稍后在卡片详情页补录」 | 按钮 loading | 「已标记完成」→ 停留列表并刷新该行 | toast error，按钮恢复 |

| 新建卡片 | 已选代码仓与一条 commit | 否 | 确认按钮 loading | 「已生成卡片 {编号}，落入待排期池」→ 关闭弹窗；commit 已有卡片时进入该卡片详情页并提示「该 commit 已有卡片 {编号}，已为你打开」 | 弹窗顶部 AcAlert，按钮恢复 |
