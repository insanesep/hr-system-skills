# 功能排期 · 权限规则

> 权限编码以 system 菜单管理的生效数据为准，本文件只说明各编码控制的操作与入口表现；角色与人员授予以 system 角色配置为准，本模块不维护角色清单。

## 1. 权限编码

| 类型 | 编码 | 名称 | 控制的操作 |
|------|------|------|-----------|
| 菜单 | `devhubFeatureSchedule` | 功能排期管理 | 访问研发排期工作台与卡片详情页；菜单位于「研发 / 研发管理」，路由 `/subapp/devhub/feature-schedule` |
| 按钮 | `devhubFeatureScheduleEdit` | 功能排期编辑 | 拖拽排期与改期、右键快捷改期、详情页编辑卡片信息与调整排期、移回待排期、领取与取消领取、开发完成后关联与移除完成 commit、移入与恢复非需求改动、批量移入、合并与解散、新建卡片、项目配置维护 |
| 按钮 | `devhubFeatureScheduleDelete` | 功能排期删除 | 删除卡片，含删除合并卡 |
| 按钮 | `devhubFeatureScheduleMarkDone` | 功能排期标记完成 | 标记完成、回退，以及列表视图行内快捷操作（领取 / 完成 / 回退） |
| 按钮 | `devhubFeatureScheduleReleaseDay` | 功能排期切换发版日 | 点击日历空白处切换发版日标记 |

## 2. 授予原则

- 菜单授予超级管理员、产品与研发负责人；研发成员按需授予；运营、门店类角色不授予
- 按钮权限按职责最小授予，持有菜单不代表持有全部按钮权限

## 3. 无权限时的入口表现

| 缺少的权限 | 表现 |
|-----------|------|
| 编辑 | 卡片不可拖拽，右键菜单仅「查看详情」可用；不展示新建卡片、合并卡片、批量、项目配置维护入口；卡片详情页不展示编辑、调整排期、移回待排期、领取开发、取消领取、关联与移除完成 commit、移入非需求改动、恢复为待开发与解散合并 |
| 删除 | 卡片详情页不展示删除 |
| 标记完成 | 卡片详情页不展示标记完成与回退；列表视图不展示行内快捷操作 |
| 切换发版日 | 点击日历空白处不切换发版日 |

- 写操作入口按权限编码控制显隐；服务端按同一编码校验，入口可见不代表服务端放行
