# 排期管理

产研交付链路的排期子域：从需求进入到发布上线，各环节以卡片为载体自动生成与跟踪。

## 下辖功能

| 功能 | 目录 | 服务对象 | 说明 |
| ---- | ---- | -------- | ---- |
| 需求管理 | [`需求管理/`](需求管理/SKILL.md) | 业务、实施、运维 | 生成需求变更的 Qoder 会话；bug 走黑灯工厂自动化修复 |
| 功能排期 | [`功能排期/`](功能排期/SKILL.md) | PM、研发 | 根据 git 提交自动生成卡片（脑图「排期管理 for pm,dev」节点） |
| 实施管理 | [`实施管理/`](实施管理/SKILL.md) | 实施 | 根据功能排期完成情况汇总生成卡片 |
| 发布管理 | [`发布管理/`](发布管理/SKILL.md) | — | 根据代码仓提交自动生成卡片 |
