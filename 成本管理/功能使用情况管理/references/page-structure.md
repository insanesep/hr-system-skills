# 功能使用情况分析 页面结构（UI 功能描述）

> 本文件**只描述 3 个子页面的 UI 功能**：路由 / 权限码、区块职责、字段与列、交互行为、按钮权限码。
>
> 前端页面通用硬约束（设计 Token、骨架、卡片化拓扑、面包屑、三态、图标、KPI、日期范围控件等）统一以前端页面规范为准，本文件不复述。
>
> 原型产物位于 [../asset/](../asset/)。

---

## 1. 事务流水明细（usage-events.html）

- **路由**：`/portal/usage-events`
- **权限码**：`MENU:RND:MANAGE:USAGE_EVENTS`
- **页面类型**：列表页

### 区块职责

| 区块 | 说明 |
|------|------|
| 顶部筛选条 | 时间范围（默认近 24 小时，单一日期范围控件） / 端（Web/App） / 用户（输入联想） / 角色（下拉） / 路由关键词 / 功能（下拉，取自功能目录） / 事件类型 |
| 统计摘要 | 当前筛选条件下：事件总数、去重用户数、去重功能数、最近事件时间 |
| 表格列 | 端 \| 用户名 \| 角色 \| 手机号 \| 页面（路由） \| 功能 \| 事件类型 \| 时间 \| 操作（查看详情） |
| 右侧抽屉 | 点击行展开：事件详情 + 该用户近期相邻事件时间线 + 近 7 日行为摘要 |
| 导出 | 支持导出 CSV，最多 5 万行；超量引导至离线导出 |

### 按钮权限码

- 导出 CSV：`BTN:RND:MANAGE:USAGE_EVENTS:EXPORT`
- 查看详情：受 `MENU:RND:MANAGE:USAGE_EVENTS` 进入页即授予，无独立按钮码

## 2. 使用情况报表（usage-report.html）

- **路由**：`/portal/usage-report`
- **权限码**：`MENU:RND:MANAGE:USAGE_REPORT`
- **页面类型**：看板页

> 页面级形态、KPI 卡类型、主显示文本、路由层级、三 Chart 排布、0 触发路由的产品向硬约束见 [SKILL.md §页面结构](../SKILL.md#页面结构)；视觉与组件硬约束以前端页面规范为准。原型见 [../asset/usage-report.html](../asset/usage-report.html)。

### 区块职责

| 区块 | 说明 |
|------|------|
| 顶部全局筛选 | 时间范围（默认近 30 天） / 端 / 角色 / 功能名称（二级，取自功能目录） / 聚合粒度（日/周/月）。选中具体功能后，KPI、三 Chart、路由聚合表全部按该功能过滤 |
| KPI 4 卡 | 总事件（连续变化，面积折线 / 主色） / 活跃功能（连续变化，面积折线 / 主色） / 活跃用户（离散周期对比，柱状 / 成功色） / 不活跃功能（离散周期对比，柱状 / 警告色） |
| 三 Chart 一排 | 按日趋势折线 \| TOP 10 高频功能（标签为「功能名 · 二级路由」） \| 角色偏好分布饼图 |
| 路由聚合表 | 以功能目录全量启用项为基准关联周期内事件；事件数 / 用户数为 0 也呈现，打 `INACTIVE` 灰色标签；默认按事件数降序、0 触发置末尾；支持「仅未触发」筛选 |
| 功能下钻 | 点击行操作列「下钻」按钮或表格内置展开 / 收起按钮，在当前行下方展开嵌套二级表，显示该路由下的功能级汇总（功能编码 / 功能名称 / 事件数 / 用户数）；展开时异步加载数据，再次点击收起 |

### 按钮权限码

- 导出报表：`BTN:RND:MANAGE:USAGE_REPORT:EXPORT`

## 3. 功能目录管理

- **路由**：`/portal/usage-catalog`
- **权限码**：`MENU:RND:MANAGE:USAGE_CATALOG`
- **页面类型**：列表页

面向运营 / 管理员的功能注册表管理界面。**不提供新增 / 物理删除**（避免与埋点自动注册冲突），仅开放查询、编辑元数据、启停。

### 区块职责

| 区块 | 说明 |
|------|------|
| 筛选栏 | 关键词（模糊匹配功能编码 / 功能名称 / 路由路径）、状态（全部 / 启用 / 停用） |
| 工具栏提示 | 「埋点上报新功能时会自动注册到此表，运营可在此补全功能名称 / 排序 / 启停。」 |
| 表格列 | 账套 \| 功能编码 \| 功能名称 \| 路由路径 \| 所属菜单权限 \| 排序 \| 状态 \| 更新时间 \| 操作（编辑 / 启停） |
| 编辑弹窗 | 仅可修改功能名称（必填，最长 128 字）、所属菜单权限码、排序（0-9999）；功能编码与路由路径只读展示 |
| 启停 | 切换启用 / 停用；幂等（状态相同直接返回） |
| 分页 | 每页默认 20，最大 200 |

### 按钮权限码

- 编辑：`BTN:RND:MANAGE:USAGE_CATALOG:EDIT`
- 启停：`BTN:RND:MANAGE:USAGE_CATALOG:TOGGLE`
