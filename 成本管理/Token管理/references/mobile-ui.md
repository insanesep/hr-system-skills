# App 端 UI 描述（qoder-usage）

## 页面清单

### Qoder 用量分析

- **页面路径**：`/rnd/qoder-usage`
- **权限编码**：
  - 菜单：`MENU:RND:MANAGE:QODER_USAGE_M`
- **导航方式**：Push（首页工作台图标进入）
- **页面类型**：看板页
- **页面元素与 Web 端保持一致**（区块集合同 web-ui.md，移动端仅做布局适配）：
  - 顶部导航栏：标题「用量分析」+ 左侧返回按钮
  - 公共筛选（驱动全部视图）：日期预设选择器（今日 / 昨日 / 前 7 天 / 近 30 天 / 自定义，默认「前 7 天」）+ 成员多选（默认「全部成员」）+ 查询（主色）/ 重置按钮；筛选元素与 Web 对齐，日期控件为预设形态（约束见 business-rule.md §1）
  - KPI 统计卡片（5 卡，与 Web 一致）：总用量（Credits + 周环比）、总请求数（次 + 周环比）、次均消耗（Credits/次 + 周环比）、人均用量（Credits + 周环比）、活跃成员（人 + 周环比）；2 列网格，第 5 卡跨满一行
  - 日 Credits 消耗堆叠柱形图卡片：标题「日 Credits 消耗趋势」+ 图例 6 个模型分类（Ultimate / Kimi K3 / GLM 5.3 / DeepSeek V4 Pro / Qwen3.8 Max / 其他，换行排列）；每日一根堆叠柱按模型分段堆叠（分类归并口径与 -4 浅色阶配色映射见 business-rule.md §6），Y 轴 0-1000 刻度，X 轴每日日期
  - Credits 用量透视表卡片：标题「Credits 用量透视表」+ hint「日期 × 成员 · Credits」；横向滚动表格、首列冻结，列 = 日期 | 成员列（排序规则见 business-rule.md §3）| 合计；每日期一行 + 合计行
  - 模型用量透视表卡片：标题「模型用量透视表」+ hint「成员 × 模型等级 · Credits」；横向滚动表格，首列成员冻结，列 = 成员 | 模型等级列（示例数据列名：Auto、Ultimate、Performance、Efficient、Lite；排序与空值规则见 business-rule.md §4）| 合计；每成员一行 + 合计行；数值两位小数
- **布局引用**：`参见原型 assets/app/qoder-usage-analysis.html`（DOM 结构依据：`page-blueprint/skeletons/app/dashboard-mobile.tsx.tpl` 通用骨架约定：Header → 筛选 → StatsGrid → ChartList；HTML 原型根挂 `.tpl-page` + 卡片 `.tpl-panel`）

#### 导航关系

- 来源页：App 首页工作台「Qoder 用量分析」图标 Push 进入
- 去向页：无（只读单页）
- 返回行为：导航栏返回按钮 / 手势返回 → 首页工作台
- 手势返回：允许（只读页无脏数据）

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询按钮 | 否 | 全页面板骨架屏 | 静默刷新全部视图 → 停留本页 | AcToast error + 下拉重试 |
| 重置 | 点击重置按钮 | 否 | 无 | 筛选恢复默认（前 7 天 + 全部成员）并自动重查 → 停留本页 | 同查询失败 |
| 下拉刷新 | 列表顶部下拉 | 否 | 下拉刷新动效 | 静默刷新 → 停留本页 | AcToast error |

#### 三态

- 加载态：品牌 Loading 动效（inline）
- 空态：筛选范围内无事件 → AcResult empty「当日暂无数据」
- 错误态：AcResult error + 重试按钮
