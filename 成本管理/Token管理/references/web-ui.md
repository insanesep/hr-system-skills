# Web 端 UI 描述（qoder-usage）

> 硬约束（Token 纪律 / 卡片化拓扑 / 三态 / 工具栏）见 page-gen.prompt.md，此处仅产品侧元信息。

## 页面清单

### Qoder 用量分析

- **页面路径**：`/rnd/qoder-usage`
- **权限编码**：
  - 路由：`MENU:RND:MANAGE:QODER_USAGE`
- **页面类型**：看板页
- **区块职责**：
  - 筛选区（公共筛选，驱动全部视图）：日期范围选择器（单个 range 控件，默认「2026-06-25 ~ 2026-07-01（前7天）」，跨度上限见 business-rule.md §1）、成员多选下拉（默认「全部成员」）、查询按钮（主色）、重置按钮
  - KPI 卡片行（5 列）：总用量（Credits + 周环比）、总请求数（次 + 周环比）、次均消耗（Credits/次 + 周环比）、人均用量（Credits + 周环比）、活跃成员（人 + 周环比）
  - 日 Credits 消耗堆叠柱形图：面板标题「日 Credits 消耗趋势」，头部右侧图例为 6 个模型分类（Ultimate / Kimi K3 / GLM 5.3 / DeepSeek V4 Pro / Qwen3.8 Max / 其他）；每日一根堆叠柱、按模型分段堆叠（分类归并口径与 -4 浅色阶配色映射见 business-rule.md §6），Y 轴刻度 0-1000，X 轴为筛选期内每日日期
  - Credits 用量透视表：列 = 日期 | 成员列（示例数据列名：周义潇、苏浩宇、王芳、李明、赵敏；排序规则见 business-rule.md §3）| 合计；7 行日期数据 + 合计行
  - 模型用量透视表：面板标题「模型用量透视表」，头部 hint「成员 × 模型等级 · 单位 Credits（保留两位小数） · 复用顶部公共筛选」；列 = 成员 | 模型等级列（示例数据列名：Auto、Ultimate、Performance、Efficient、Lite；排序与空值规则见 business-rule.md §4）| 合计；每成员一行 + 合计行；数值两位小数
- **布局引用**：`参见原型 assets/web/qoder-usage-analysis.html`（DOM 结构依据：`page-blueprint/skeletons/web/dashboard-multi.vue.tpl` 通用骨架约定：`.tpl-page` 根 + `.tpl-panel` 卡片 + `.tpl-panel__head`；信息架构以本模块功能视图为准）

#### 导航关系

- 来源页：管理后台侧边菜单「研发管理 → Qoder 用量分析」点击进入
- 去向页：无（只读单页，无下钻跳转）
- 返回行为：浏览器返回 / 顶栏面包屑返回上级菜单
- 面包屑：首页 / 研发管理 / Qoder 用量分析（由 Layout 渲染，页面内不出现）

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询按钮 | 否 | 全页面板骨架屏 | 静默刷新全部视图 → 停留本页 | 面板内 AcAlert error + 重试按钮 |
| 重置 | 点击重置按钮 | 否 | 无 | 筛选恢复默认（前 7 天 + 全部成员）并自动重查 → 停留本页 | 同查询失败 |

#### 三态

- 加载态：各面板骨架屏
- 空态：筛选范围内无事件 → 图表与表格区居中「暂无用量数据」
- 错误态：上游调用失败 → AcAlert error + 重试，不暴露内部细节
