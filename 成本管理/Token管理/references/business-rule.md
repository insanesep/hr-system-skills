# 业务规则字典（qoder-usage）

> 本模块业务规则唯一真源。SKILL.md 仅导航，不复述本文定义。

## 1. 公共筛选与日期约束

- Web 筛选区：日期范围选择器（单个 range 控件）+ 成员多选 + 查询 / 重置按钮
- App 筛选区：日期预设选择器（今日 / 昨日 / 前 7 天 / 近 30 天 / 自定义）+ 成员多选 + 查询 / 重置按钮（筛选元素与 Web 对齐，日期控件为预设形态）
- 默认范围：前 7 天（不含今天，T-7 ~ T-1）
- 范围上限：遵循 qoder-api.md 的时间范围硬约束；前端对超范围查询拦截并提示「日期范围不能超过 7 天」
- 成员筛选为空 = 全部成员
- 所有视图（KPI / 柱状图 / 两张透视表）随公共筛选联动刷新，单视图不设独立筛选

## 2. KPI 计算口径

| 指标 | 公式 | 精度 |
|------|------|------|
| 总用量 | SUM(events.credits) | 整数展示 |
| 总请求数 | COUNT(events) | 整数 |
| 次均消耗 | 总用量 / 总请求数 | 1 位小数 |
| 人均用量 | 总用量 / 活跃成员数 | 整数 |
| 活跃成员 | COUNT(DISTINCT 成员 WHERE credits > 0) | 整数 |

周环比 = (本期值 − 上周同期值) / |上周同期值| × 100%；上周同期 = 本期 startDate/endDate 各减 7 天。上周同期值为 0 时环比记 0%（避免除零）。正值 ↑、负值 ↓、0 为 —。

## 3. 日期 × 成员透视表

- 行维度：日期（按天，升序）
- 列维度：成员，按选定期间成员 Credits 合计**降序从左往右**排列
- 单元格：该成员当日 SUM(credits)
- 行合计：当日全员之和；列合计：该成员期间之和；末行末列为总计

## 4. 模型用量透视表（成员 × 模型等级）

- 行维度：成员名（不展示用户 ID）
- 列维度：模型等级，取选定期间实际出现的取值动态生成，按该列合计降序排列
- 空值处理：模型等级为空的事件归入「未标注」列，排在最后
- 单元格：该成员该模型等级 SUM(credits)，**保留两位小数**（汇总后四舍五入到分位，避免浮点累加误差）
- 行合计 / 列合计 / 总计同为两位小数
- 负向 Credits 照常参与汇总

## 5. 负向 Credits 与活跃成员

- 上游事件的 credits 可为负数（退款 / 冲正），聚合照常参与 SUM
- 活跃成员判定仅统计 credits > 0 的记录
- 负值不在界面单独标色（透视表仅展示汇总值）

## 6. 日消耗堆叠柱形图（按模型分类）

- 每日一根堆叠柱：当日 Credits 合计按模型分类分段堆叠，柱高 = 当日全员 Credits 合计（= 日期×成员透视表行合计）
- 模型分类归并口径（按上游事件的模型标识归并，共 6 类）：
  - `Ultimate`：极致模型
  - `Kimi K3`：Kimi 系列（含 K3、K2.7-Code 等）
  - `GLM 5.3`：GLM 系列
  - `DeepSeek V4 Pro`：DeepSeek-V4 系列
  - `Qwen3.8 Max`：Qwen3.x 系列
  - `其他`：其余模型取值及模型标识为空的事件
- 堆叠顺序（自下而上）：Ultimate → Kimi K3 → GLM 5.3 → DeepSeek V4 Pro → Qwen3.8 Max → 其他；图例同色展示于面板头部右侧
- 分桶配色取 -4 浅色阶（柱体大面积填充，-6 过深，-4 柔和且色相可辨），双端一致：

| 模型桶 | Token | 色值 |
|--------|-------|------|
| Ultimate | `primary-4` | #F98981 |
| Kimi K3 | `palette-purple-4` | #A871E3 |
| GLM 5.3 | `info-4` | #6AA1FF |
| DeepSeek V4 Pro | `palette-cyan-4` | #5EDFD6 |
| Qwen3.8 Max | `warning-4` | #FFB65D |
| 其他 | `palette-gray-4` | #C9CDD4 |
- 周环比对比不在本图呈现，由 KPI 卡片区统一承担（见 §2）
- 实现映射（2026-09-14 落地）：`GET /busyming-devops/api/v1/qoder/daily-model-credits`（devops `QoderUsageController`），归并函数 `QoderUsageServiceImpl.classifyModelFamily`（trim+小写，`ultimate` 精确匹配，`kimi`/`glm`/`deepseek`/`qwen` 前缀，其余含空值→其他）；数据源为 `qoder_usage_daily.tier_credits` 快照 JSON（历史数据无需重刷）

## 7. 三态与空态

- 加载态：Web 面板骨架屏 / App 品牌 Loading 动效
- 空态：筛选范围内无事件时，图表与表格区显示「暂无用量数据」
- 错误态：上游调用失败显示错误提示 + 重试按钮，不暴露内部细节
