# dev-cost-statistics 业务规则字典

> 本文件为多品牌研发成本统计模块的规则真源。SKILL.md 仅做导航，规则细节全部在此。

---

## 1. 单据状态机

| 状态 | 含义 | 可用动作 |
|------|------|---------|
| 待审核 | 制单完成待审核（新增保存后即为该状态） | 查看、编辑、删除、审核 |
| 已审核 | 审核通过，计入报表统计 | 查看、作废 |
| 已作废 | 单据终止，保留痕迹，不计入任何统计 | 查看（只读） |

流转规则：

```text
新增保存 → 待审核
待审核 --审核--> 已审核
已审核 --作废--> 已作废
待审核 --删除--> 软删除（列表不再展示）
```

- **无反审核**：已审核单据不可退回待审核，唯一终止路径是作废（来源：需求确认 2026-09-11 v1.3）
- **作废仅限已审核单据**：待审核单据不允许作废，错误单据直接删除；已审核单据作废后自作废生效起不再计入报表
- **删除仅限待审核**：软删除，列表不再展示；已审核 / 已作废单据不可删除
- 已作废为终态，不可恢复、不可再编辑
- 已审核单据内容有误需修改时：只能作废后重新制单（原单保留痕迹），不支持编辑或退回
- 审核 / 作废 / 删除均需二次确认（弹窗）

## 2. 字段与枚举

### 2.1 费用科目（单选，固定 7 项）

人员、Token、系统采购、弱电、硬件、差旅、福利

- 每张费用单仅可选一个科目；科目为固定枚举，本模块不提供科目维护入口

### 2.2 品牌（固定 4 个）

零食王国、有点推荐、满气食品、数字化中心

- 品牌为固定枚举，本模块不提供品牌维护入口

### 2.3 流水号

- 规则：`FY` + 制单日期 `yyyyMMdd` + 4 位日内序号（如 `FY202609110001`）
- 新增保存时由系统生成，全程不可修改；软删除单据的流水号不复用

### 2.4 费用金额

- 必填，> 0，保留两位小数（精确到分）
- 「待审核」状态可修改；审核后金额冻结

### 2.5 费用开始年月 / 费用结束年月

- 两个字段均必填，粒度到月（`yyyy-MM`）；**开始年月 ≤ 结束年月**
- 开始 = 结束 即单月费用；允许补录历史月份、预录当前及未来月份
- 两字段共同决定报表归集：费用在覆盖区间内**逐月均摊**（口径见 §5）
- 「待审核」状态可修改

## 3. 品牌分摊规则

每张费用单必须包含至少 1 条品牌分摊明细，规则如下：

| # | 规则 | 说明 |
|---|------|------|
| 1 | 比例合计 = 100% | 所有明细行分摊比例之和必须等于 100%，否则禁止保存 / 审核 |
| 2 | 同品牌唯一 | 同一品牌在同一张单据中只允许出现一行（下拉选项已选互斥） |
| 3 | 单行比例范围 | 每行比例 > 0% 且 ≤ 100%，支持两位小数 |
| 4 | 末行倒算防尾差 | 明细最后一行的比例与金额由系统倒算：末行比例 = 100% − 前行比例之和；末行分摊金额 = 费用金额 − 前行分摊金额之和。末行比例 / 金额字段只读 |
| 5 | 分摊金额计算 | 前行分摊金额 = 费用金额 × 比例，四舍五入到分；末行倒算兜底，保证各品牌分摊金额之和 = 费用金额（无尾差） |
| 6 | 行数上限 | 明细行数 ≤ 品牌总数（4 行） |
| 7 | 快捷分摊 | 提供「均摊」快捷操作：按已选品牌数等比填充比例，末行倒算兜底 |

- 费用金额修改后，全部分摊金额按上述规则实时重算
- 前行比例修改导致末行倒算结果 ≤ 0 时，该行校验不通过并给出提示

## 4. 权限与操作矩阵

制单与审核职责分离，拆分为独立权限点（来源：需求确认 2026-09-11）：

| 权限编码 | 覆盖操作 |
|---------|---------|
| `MENU:RND:DEV_COST` | 菜单路由（列表 / 明细 / 报表三页共用入口分组） |
| `BTN:DEV_COST:CREATE` | 新增费用、编辑、删除 |
| `BTN:DEV_COST:AUDIT` | 审核、作废 |

- **制单人不可审核本人单据**：当前登录人 = 制单人时，「审核」按钮禁用（来源：业务常识，职责分离兜底）
- 无对应按钮权限时按钮不渲染
- 报表页只读，无额外按钮权限点

## 5. 报表统计口径

| 项 | 规则 |
|---|------|
| 统计范围 | 仅「已审核」状态费用单；待审核 / 已作废不计入 |
| 归属期间 | 单据覆盖 [费用开始年月, 费用结束年月] 的**每个月**均计入；当月某品牌分摊额 = 该品牌分摊金额 ÷ 覆盖月数；尾差由最后一个覆盖月倒算兜底，保证同一单据同一品牌各月分摊额之和 = 品牌分摊金额 |
| 行维度 | 品牌（固定一级行）；勾选「科目」后叠加为品牌 → 科目二级行 |
| 列维度 | 费用年月，按筛选范围内月份横向升序展开 |
| 汇总值 | 交叉格 = 该品牌（× 科目）在该月的分摊额合计，单位元，两位小数 |
| 合计 | 行合计 = 该品牌（× 科目）全期间分摊额合计；列合计 = 该月全部品牌分摊额合计；右下角为总计 |
| 勾稽等式 | 任一月份列合计 = 当月全部已审核费用单的当月分摊额之和；单张单据所有覆盖月分摊额之和 = 该单费用金额；品牌合计行之和 = 总计 |
| 筛选命中 | 费用年月范围筛选按「单据覆盖区间与筛选区间相交」命中 |
| 期间费用总额 | KPI「期间费用总额」= 筛选范围内各月分摊额之和（**非**单据全额，跨年单据仅计落在范围内的月份） |

- 筛选条件：费用年月范围（必填，默认近 12 个月）、费用科目多选（默认全部）、品牌多选（默认全部）
- 无数据月份列照常展开，交叉格显示 `-`

## 6. 边界与异常

| 场景 | 处理 |
|------|------|
| 保存时分摊比例合计 ≠ 100% | 阻断保存，子表合计行标红并提示差额 |
| 费用开始年月晚于结束年月 | 阻断保存，字段级提示「开始年月不能晚于结束年月」 |
| 审核并发（两人同时审同一单） | 以后端状态校验为准，后到请求失败并提示「单据状态已变更，请刷新」 |
| 待审核单据再次编辑 | 允许，金额 / 科目 / 起止年月 / 分摊明细均可改，改后需审核 |
| 已审核单据内容有误 | 不支持编辑或退回，只能作废后重新制单（原单保留痕迹） |
| 已审核单据被作废 | 报表自作废生效起不再计入该单 |
