# 项目成本管理

## 模块概述

研发费用单据化管理：按「费用科目 + 费用开始/结束年月」录入费用单，单据内维护品牌分摊比例明细（比例合计 = 100%），单据审核后按覆盖月份**逐月均摊**计入「品牌 × 年月（可叠加科目）」成本透视报表，支撑鸣鸣很忙 / 有点推荐 / 满气食品 / 数字化中心四个主体的研发成本归集、分摊与月度复盘。

## 端

| 端 | 场景 | 目标用户 |
|---|---|---|
| Web | 费用制单、审核、作废、成本透视报表 | 研发财务接口人（制单）、研发主管（审核）、管理层（报表） |

## When to Use

- 需要登记一笔研发费用（人员 / Token / 系统采购 / 弱电 / 硬件 / 差旅 / 福利）并按品牌拆分分摊比例
- 需要对费用单执行审核 / 作废（制单与审核职责分离，无反审核，详见权限矩阵与状态机）
- 需要按品牌 × 年月透视查看研发成本，或叠加费用科目做二级行维度分析
- 需要追溯某张费用单的品牌分摊金额构成

## Tips

- 报表仅统计「已审核」单据，按费用开始~结束年月覆盖的每个月逐月均摊计入（尾差末月倒算兜底），详见 [references/business-rule.md §5](references/business-rule.md#5-报表统计口径)
- 分摊比例尾差由末行倒算兜底，前端展示与后端落库口径必须相同，详见 [references/business-rule.md §3](references/business-rule.md#3-品牌分摊规则)
- 制单人不可审核本人单据（职责分离），详见 [references/business-rule.md §4](references/business-rule.md#4-权限与操作矩阵)
