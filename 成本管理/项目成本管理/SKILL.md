# 项目成本管理

> 对应脑图「项目成本管理」节点：费用；人员（工资成本、差旅成本、Token 成本）。

面向研发财务接口人与管理层的成本归集工具：费用单据化录入 → 主体分摊 → 审核入账 → 多维透视，支撑研发成本的归集、分摊与月度复盘。

## 服务对象与端

- **服务对象**：研发财务接口人（制单）、研发主管（审核）、管理层（报表）
- **仅 Web 端**

## 核心逻辑

### 费用单

- 单据头：费用科目（单选）+ 金额 + 费用开始/结束年月（相等即单月）
- 分摊明细子表：按主体（品牌/项目）多行分摊——**比例合计 = 100%、同主体唯一、末行倒算防尾差**，实时显示分摊金额
- 科目体系覆盖：人员工资、差旅、Token/系统用量、系统采购、硬件、福利等；**人员成本三类来源**（对应脑图）：工资成本（薪酬分摊导入）、差旅成本（差旅费用单）、Token 成本（联动 `成本管理/Token管理` 周期用量按单价折算，折算口径可配）

### 状态机与权限

- `待审核 → 已审核`；已审核仅允许**作废**（无反审核、不可编辑退回），作废后不再计入报表；待审核允许删除、不允许作废
- **职责分离**：制单人不可审核本人单据（后端强制）

### 成本透视报表

- 仅统计**已审核**单据；按费用开始~结束年月覆盖的每个月**逐月均摊**计入（尾差末月倒算兜底）
- 行 = 主体（可叠加科目作二级行维度），列 = 费用年月横向展开，值 = 分摊金额合计，含行/列合计
- 列表的年月筛选与报表同口径（覆盖区间相交）

## 页面功能概览（仅列职责，UI 风格与原型暂不产出）

| 页面 | 职责 |
| ---- | ---- |
| 费用列表 | 分页查询与多维筛选（年月范围/科目/状态/制单人/流水号），行内按状态与权限提供操作，顶部新增入口 |
| 费用明细 | 新增/编辑/查看三态合一：单据头 + 分摊明细子表（比例合计校验与尾差倒算） |
| 成本报表 | 主体 × 年月透视（可叠加科目），行列合计 |

## 关键约束

- 分摊尾差末行倒算，前端展示与后端落库口径必须一致
- 主体与科目落库存代码值，中文名由常量映射
- Token 成本折算为周期任务或手工汇入，需防重复入账（幂等键 = 期间 + 来源）
