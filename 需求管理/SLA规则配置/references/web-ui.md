# SLA规则配置 · Web 端 UI 描述

> 本文件承载本功能页面正文；全局约定与跨页导航见 [需求管理 · Web 共享 UI](../../references/web-ui.md)，业务与权限规则见 [功能入口](../SKILL.md)。正文定义产品交互要求；原型见本功能资产目录，仅作视觉参考。

### SLA 配置页

- **菜单名称**：SLA规则配置（与需求SLA看板同级，侧边栏各占一行）
- **页面路径**：`/requirement/sla-config`；筛选条件须同步至页面地址
- **route.name**：`devhubRequirementSlaConfig`；`/subapp/devhub` 仅为部署 base
- **权限编码**：
  - 菜单资源码：`devhubRequirementSlaConfig`
  - 按钮：无独立按钮码；全部读写接口均携带 `devhubRequirementSlaConfig` 请求头由服务端按管理员口径校验，前端不按角色隐藏写操作按钮（[permission-rules.md §1](../../references/permission-rules.md#1-权限编码)）
- **页面类型**：`archive-list`
- **页面定位**：审批超时催办阈值维护——一屏回答「哪类需求多久没审就催、多久就升级」；规则见 [other-rule-sla.md §3](../../references/other-rule-sla.md#3-差异化配置)
- **区块职责**：
  - 顶部提示条（常驻，可关闭）：「SLA 配置管「多久没审就催」，审批链配置管「谁来审」，二者相互独立；🚨 修改后立即对在途需求生效，不做快照」+ inline「前往审批链配置」链接
  - 筛选区：产品线（下拉单选）/ 审批级次（下拉单选 L1 / L2 / L3）/ 状态（启用 / 停用）/ 查询 / 重置；🚨 筛选为纯前端过滤（配置列表一次全量返回，「查询」不发请求，「重置」清空即生效）
  - 操作区：新增配置（主按钮）/ 初始化默认规则 / 刷新
  - 主体区：配置表格（系统预置默认配置，首次进入不是空态），列定义如下

| 列名 | 取值说明 |
|------|---------|
| 产品线 | 产品线 Tag，无 `*` 通配 |
| 优先级 | 优先级 Tag 或 `*`（显示「* 全部」通配标签） |
| 审批级次 | `L1 业务线审批` / `L2 实施确认` / `L3 产品确认` |
| 催办阈值 | 「N 小时」（≥ 48h 附「（≈N 天）」） |
| 升级阈值 | 同上格式 |
| 去重窗口 | 「N 小时」（默认 24），气泡提示「同一需求同一级次在一个窗口内仅催一次」 |
| 状态 | 启用 / 停用开关；停用行不参与 SLA 计算 |
| 最后修改 | 最后修改人 + 修改时间 |
| 操作 | 编辑 / 删除 |

- **匹配优先级提示**（表格上方 inline）：「命中顺序：产品线必须等值命中（不降级）→ 优先级精确 → 优先级 `*` 通配 → 均未命中则走系统默认 48h/72h/24h，命中即止」
- **默认阈值参考**（表格下方只读说明卡）：展示 [other-rule-sla.md §3](../../references/other-rule-sla.md#3-差异化配置) 的默认阈值矩阵（P0 24h/48h、P1 48h/72h、P2 48h/72h、P3 72h/120h），脚注「三个级次默认共用同一套阈值，可按级次单独调整；去重窗口系统默认 24 小时。」
- **缺配提示**：某产品线已配置部分级次、但仍有未被任何配置行覆盖的级次时，顶部黄色警示条「{产品线} L{N} 级无 SLA 配置，将按系统默认 48h/72h 催办」；🚨 仅提示、不阻断催办，与审批链缺级直接拒绝提交的红色告警严格区分
- **分页**：默认 20 条/页
- **布局引用**：参见原型 [requirement-sla-config.html](../assets/web/requirement-sla-config.html)（整页范例 `busyming-skills-design/web/templates/archive-list.html`；DOM 结构依据 `busyming-skills-design/.skills/page-blueprint/skeletons/web/list-page.vue.tpl`）

#### 导航关系

- 来源页：侧边菜单「需求管理 / SLA规则配置」；SLA 仪表盘右上「SLA 配置」
- 去向页：新增与编辑在本页弹窗内完成，不跳页；提示条「前往审批链配置」跳审批链配置页
- 返回行为：面包屑「需求管理」返回需求列表页；由 SLA 仪表盘进入时面包屑「需求SLA看板」返回仪表盘
- 产品目标面包屑：首页 / 研发 / 需求管理 / SLA规则配置

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 / 重置 | 无 | 否 | 表格区加载指示 | 表格按前端过滤刷新 → 停留 | —（纯前端过滤） |
| 新增配置 | 无（服务端按管理员口径校验） | 否 | 弹窗确认按钮 loading | AcMessage.success「SLA 配置已保存，已对在途需求生效」→ 关闭弹窗，刷新表格 | 弹窗顶部 AcAlert（前端唯一性预检或服务端返回「该产品线 / 优先级 / 级次已存在配置，请直接编辑」时原样展示）+ 输入保留 + 按钮恢复 |
| 编辑配置 | 无（服务端按管理员口径校验） | 否 | 弹窗确认按钮 loading | AcMessage.success「SLA 配置已保存，已对在途需求生效」→ 关闭弹窗，刷新表格 | 弹窗顶部 AcAlert + 输入保留 + 按钮恢复 |
| 删除配置 | 无（服务端按管理员口径校验） | AcPopconfirm「删除后该条件将按系统默认 48h/72h 催办，确认删除？」 | 按钮 loading | AcMessage.success「配置已删除」→ 停留并刷新表格 | AcMessage.error + 按钮恢复 |
| 启用 / 停用 | 行内开关切换 | 停用时 AcPopconfirm「停用后该条件回退至系统默认阈值，确认停用？」 | 开关 loading | AcMessage.success「配置已启用」/「配置已停用」→ 停留并刷新 | AcMessage.error + 开关回滚原值 |
| 初始化默认规则 | 点「初始化默认规则」 | 否 | 按钮 loading | AcMessage.success「已初始化 N 条默认规则」→ 停留并刷新表格 | AcMessage.error + 按钮恢复 |

#### 表单校验

**配置弹窗（新增 / 编辑）**

- 初态：新增时催办阈值 48、升级阈值 72、去重窗口 24，其余为空；编辑时回填，产品线、优先级、审批级次只读

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 产品线 | 是 | 下拉单选（鸣鸣很忙 / 有点推荐），🚨 不提供 `*` | change | 「请选择产品线」 | 否 |
| 优先级 | 是 | 下拉单选（P0 / P1 / P2 / P3 + `*` 全部） | change | 「请选择优先级或全部通配」 | 否 |
| 审批级次 | 是 | 下拉单选（L1 / L2 / L3） | change | 「请选择审批级次」 | 是（产品线 + 优先级 + 级次唯一性校验） |
| 催办阈值 | 是 | 1–720 整数（小时） | change | 「催办阈值需为 1–720 的整数（小时）」 | 否 |
| 升级阈值 | 是 | 1–720 整数（小时），🚨 必须大于催办阈值 | change（与催办阈值联动校验） | 「升级阈值必须大于催办阈值」 | 否 |
| 去重窗口 | 否 | 1–168 整数（小时） | change | 「去重窗口需为 1–168 的整数（小时）」 | 否 |
| 配置说明 | 否 | 不超过 256 字 | blur | 「配置说明不超过 256 字」 | 否 |

- 弹窗底部常驻灰字：「保存后**立即对在途需求生效**（SLA 不做快照），与审批链配置「仅对新提交生效」不同」
- 提交成功跳转：关闭弹窗，停留本页并刷新表格，无延迟
- 提交失败展示：弹窗顶部 AcAlert，字段值保留
- 脏数据离开：弹窗内有修改时关闭 → AcModal「您有未保存的配置修改，确认关闭？」

#### 表格三态

- **空态**（仅在配置被全部删除后出现）：空状态插图 +「尚未配置 SLA 阈值，当前全部需求按系统默认 48h 催办 / 72h 升级」+「新增配置」（管理员）
- **加载态**：表格骨架屏（5 行占位）
- **错误态**：错误插图 +「点击重试」
