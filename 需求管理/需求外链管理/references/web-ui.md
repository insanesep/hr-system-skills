# 需求外链管理 · Web 端 UI 描述

> 本文件承载本功能页面正文；全局约定与跨页导航见 [需求管理 · Web 共享 UI](../../references/web-ui.md)，业务与权限规则见 [功能入口](../SKILL.md)。正文定义产品交互要求；原型见本功能资产目录，仅作视觉参考。

### 外链管理页

- **菜单名称**：需求外链管理
- **页面路径**：`/requirement/public-link`；筛选条件与页码须同步至页面地址
- **route.name**：`devhubRequirementPublicLink`；`/subapp/devhub` 仅为部署 base
- **权限编码**：
  - 菜单资源码：`devhubRequirementPublicLink`
  - 按钮：`devhubRequirementLinkCreate`（生成外链）、`devhubRequirementLinkRevoke`（撤销），控制范围见 [permission-rules.md §1](../../references/permission-rules.md#1-权限编码)
  - 「看全部 / 只看本人」与「可否撤销他人链接」按管理员口径判定，不另发权限码
- **页面类型**：`order-list`
- **页面定位**：向外采集有点推荐需求的外链台账——一屏回答「发给了谁、对方看了没、有没有提交」；规则见 [other-rule-public-link.md](other-rule-public-link.md)
- **区块职责**：
  - 顶部提示条（常驻，可关闭）：「外链仅用于采集**有点推荐**需求；链接为定向发放，默认仅可提交 1 次，提交结果不向外部回传，请自行告知对方」
  - 筛选区：链接状态（下拉：待使用 / 已提交 / 已过期 / 已撤销）/ 邀约对象（模糊搜索邀约对象备注，回车触发）/ 生成时间（日期范围，按所选区间筛选）/ 查询 / 重置
  - 操作区：生成外链（主按钮，打开生成弹窗）
  - 主体区：台账表格，列定义如下

| 列名 | 取值说明 |
|------|---------|
| 邀约对象 | 邀约对象备注（公司 / 联系人），超长省略 + 气泡提示 |
| 链接状态 | 外链状态标签（彩色圆点：待使用 蓝 / 已提交 绿 / 已过期 灰 / 已撤销 红） |
| 提交进度 | 已提交次数 / 提交次数上限（如 `1/1`），达上限时数字为成功色 |
| 访问情况 | 访问次数 + 首次访问时间；从未访问展示灰字「未访问」 |
| 有效期至 | 到期时间；待使用且剩余 ≤ 3 天时追加「即将过期」Tag |
| 生成人 | 生成人姓名 |
| 生成时间 | 生成时间 |
| 操作 | 撤销 |

- **操作列可见性**：仅「待使用」行渲染操作列，其余状态展示 `—`；撤销由服务端按生成人本人或管理员口径校验；**不提供复制链接、二维码与删除**——完整链接仅在生成结果态展示一次，台账为溯源证据只能撤销
- **排序**：默认按生成时间倒序；**分页**：默认 20 条/页，页大小档位取分页组件默认集
- **布局引用**：参见原型 [requirement-public-link.html](../assets/web/requirement-public-link.html)（整页范例 `busyming-skills-design/web/templates/order-list.html`；DOM 结构依据 `busyming-skills-design/.skills/page-blueprint/skeletons/web/list-page.vue.tpl`）

#### 导航关系

- 来源页：侧边菜单「需求管理 / 需求外链管理」；需求详情页（外部单）点「来源外链」
- 去向页：生成与撤销均在本页弹窗内完成，不跳页
- 返回行为：面包屑「需求管理」返回需求列表页；由需求详情页进入时面包屑「需求详情」返回该详情页
- 产品目标面包屑：首页 / 研发 / 需求管理 / 需求外链管理

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 / 重置 | 无 | 否 | 表格区加载指示 | 表格刷新，信息条展示「共 N 条」→ 停留 | AcMessage.error「外链台账加载失败，请重试」+ 表格错误态「点击重试」 |
| 生成外链 | 具生成权限 | 否（表单本身即确认） | 弹窗确认按钮 loading | 弹窗就地切换为生成结果态（链接全文只读输入框 + 复制链接按钮 +「链接仅此时完整展示一次」提示 +「我已复制，关闭」），AcMessage.success「外链已生成，请复制发送给邀约对象」；关闭弹窗后刷新表格 | 弹窗顶部 AcAlert（服务端返回「有点推荐尚未配置审批链，无法生成外链，请联系管理员」时原样展示）+ 字段保留 + 按钮恢复 |
| 复制链接 | 生成结果态点「复制链接」 | 否 | 按钮 loading（复制完成即恢复） | AcMessage.success「链接已复制」→ 停留结果态 | AcMessage.error「复制失败，请手动选中链接文本」 |
| 撤销 | 行状态为待使用 + 生成人本人或管理员（服务端校验） | 撤销原因弹窗（必填 10–256 字）+ 提示「撤销后对方打开链接将看到已失效提示，且无法恢复」 | 弹窗确认按钮 loading | AcMessage.success「外链已撤销」→ 关闭弹窗，停留并刷新表格，行状态置已撤销 | 弹窗顶部 AcAlert（服务端返回「链接已被提交，不可撤销」时同步刷新行状态）+ 原因保留 + 按钮恢复 |

#### 表单校验

**生成外链弹窗**

- 初态：产品线固定展示「有点推荐」且只读（仅有点推荐开放外链）；需求类型默认值为新功能；有效期 30 天；提交次数上限 1；邀约对象备注为空

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 邀约对象备注 | 是 | 2–128 字；提示「建议填「公司 + 联系人」，仅内部可见，用于台账识别」 | blur | 「请填写邀约对象备注（2–128 字）」 | 否 |
| 需求类型默认值 | 是 | 下拉单选（5 类，不提供 `*` 通配），外部人可在 H5 重选 | change | 「请选择需求类型默认值」 | 否 |
| 有效期 | 是 | 单选组（7 / 15 / 30 / 60 / 90 天），下方展示换算后的到期日期 | change | 「请选择有效期」 | 否 |
| 提交次数上限 | 是 | 1–10 整数；气泡提示「默认仅可提交 1 次；超过上限后链接仍可打开但不再受理提交」 | change | 「提交次数上限需为 1–10 的整数」 | 否 |

- 提交成功跳转：弹窗**不关闭**，就地切换为生成结果态（链接全文只读输入框 + 复制链接按钮 + 提示「链接仅此时完整展示一次」+「我已复制，关闭」），避免用户没拿到链接就关窗；结果态只展示一次，关闭后无法再次取得完整链接（不重新生成、台账不展示），未复制只能撤销后重新生成
- 提交失败展示：弹窗顶部 AcAlert，字段值全部保留
- 脏数据离开：表单态有修改时关闭弹窗 → AcModal「您有未提交的外链信息，确认关闭？」；结果态关闭不确认

**撤销原因弹窗**

- 初态：撤销原因为空；弹窗内提示「撤销后对方打开链接将看到已失效提示，且无法恢复」

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 撤销原因 | 是 | 10–256 字 | blur | 「请填写撤销原因（10–256 字）」 | 否 |

- 提交成功跳转：关闭弹窗，停留本页并刷新表格，无延迟
- 提交失败展示：弹窗顶部 AcAlert，原因保留
- 脏数据离开：已输入内容时关闭弹窗 → AcModal「放弃已填写的撤销原因？」

#### 表格三态

- **空态**：当前筛选无数据 → 空状态插图 +「暂无外链记录」+「生成外链」引导按钮（有权限时）
- **加载态**：表格骨架屏（10 行占位）
- **错误态**：表格区错误插图 +「点击重试」

#### 交互约束

- 台账列表不展示完整链接凭证，完整链接仅在生成结果态展示一次，避免截屏外泄
- 已过期为服务端按到期时间实时判定的展示态，前端不自行比对时间
- 生成操作幂等：重复点击「确认生成」不产生多条外链，按钮点击后立即 disabled 直至返回
