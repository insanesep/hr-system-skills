审批链配置
默认链（兜底） 指定产品经理
默认链仅承接外部提交与防御兜底（内部单只能选本归属有专属链的产品经理）；为产品经理配置专属链后，提交给他的需求走专属链。提交对象为手填维护，不使用人员选择器，也不与提交页的提交对象候选集联动。
匹配优先级：提交需求时按提交对象匹配专属链（内部单必中专属链，不回退默认链；外部提交走默认链）；同一链内按 类型+优先级精确 → 类型精确+优先级通配 → 类型通配+优先级精确 → 全通配 降级，命中即止。
