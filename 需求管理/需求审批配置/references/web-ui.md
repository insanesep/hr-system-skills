# 需求审批配置 · Web 端 UI 描述

> 本文件承载本功能页面正文；全局约定与跨页导航见 [需求管理 · Web 共享 UI](../../references/web-ui.md)，业务与权限规则见 [功能入口](../SKILL.md)。正文定义产品交互要求；原型见本功能资产目录，仅作视觉参考。

### 审批链配置页

- **菜单名称**：需求审批配置（管理员操作由服务端校验；standalone 侧栏不按管理员自动过滤菜单）
- **页面路径**：`/requirement/config`；一级、二级 Tab 选择须同步至页面地址
- **route.name**：`devhubRequirementConfig`；`/subapp/devhub` 仅为部署 base
- **权限编码**：
  - 菜单资源码：`devhubRequirementConfig`
  - 按钮：`devhubRequirementConfigCreate`、`devhubRequirementConfigEdit`、`devhubRequirementConfigDelete`、`devhubRequirementConfigChatSet`（群消息配置），控制范围见 [permission-rules.md §1](../../references/permission-rules.md#1-权限编码)
- **页面类型**：`archive-list`
- **页面定位**：按归属维护审批链与群消息映射，并查看该归属的审批统计；规则见 [business-rule.md §3](../../references/business-rule.md#3-审批链配置规则)
- **区块职责**：
  - 一级 Tab（产品线）：鸣鸣很忙 / 有点推荐
  - 二级 Tab（业务线，仅鸣鸣很忙下渲染）：运营 / 财务 / 供应链 / 数字化，各二级 Tab 独立配置互不影响；切至有点推荐时不渲染二级 Tab，顶部 inline 说明「有点推荐不区分业务线」
  - 当前 Tab 内自上而下三个卡片：
    - **群消息配置**：当前归属的企微群名称 + 脱敏后的 Webhook Key，点「设置」inline 编辑（Key 输入框为空不回填脱敏值，需输入完整 Key；群名称默认「{归属}需求审批群」）；保存时服务端校验机器人有效性，绑定后群消息按归属推送（提交待审 / 通过 / 驳回）；未配置时警示条「该归属未配置企微群，群消息将静默跳过，不影响审批流转」
    - **审批链配置**：
      - **先选提交对象**：单选「默认链（兜底）」或「指定产品经理」+ 手填姓名与门户用户 ID（数字）；🚨 提交对象为手填维护，不使用人员选择器，也不与提交页的提交对象候选集联动（[business-rule.md §3.2](../../references/business-rule.md#32-专属链与默认链)）；填入后下方表格展示该对象在当前归属下的配置行；inline 说明「默认链仅承接外部提交与防御兜底（内部单只能选本归属有专属链的产品经理）；为产品经理配置专属链后，提交给他的需求走专属链」
      - 表格上方 inline 说明匹配优先级：「提交需求时按提交对象匹配专属链（内部单必中专属链，不回退默认链；外部提交走默认链）；同一链内按 类型+优先级精确 → 类型精确+优先级通配 → 类型通配+优先级精确 → 全通配 降级，命中即止」
      - 操作区：新增配置（主按钮）
      - 配置表格，列定义如下
    - **审批统计**（当前 Tab 底部）：统计范围跟随当前产品线、业务线 Tab，近 30 天按提交时间过滤

| 列名 | 取值说明 |
|------|---------|
| 需求类型 | 精确类型名或 `*`（显示「* 全部类型」通配标签） |
| 优先级 | `P0` / `P1` / `P2` / `P3` 或 `*`（显示「* 全部」通配标签） |
| 审批级次 | 该行覆盖的级次集合标签（如「L1+L2+L3」「L2+L3」「仅 L3」）；默认链展示完整级次 |
| 各级审批人 | 按级次分组展示审批人姓名（形如 `L1 张三/李四 · L2 王五`），多人即或签 |
| 状态 | 启用 / 停用开关；停用行不参与快照匹配 |
| 操作 | 编辑 / 删除 |

| 统计项 | 取数说明 |
|--------|---------|
| 受理量 | 近 30 天该归属已提交需求条数（不含草稿），附内部 / 外部条数构成脚注 |
| 通过率 | 全级审批通过（待关联排期 + 已关联排期）条数 ÷ 受理量 |
| 驳回率 | 驳回条数 ÷ 受理量，附 L1 / L2 / L3 分级占比脚注 |
| 平均审批时长 | 提交至末级通过的时长均值，展示为「N 小时 M 分」 |

- 各统计卡带「?」口径悬浮说明；区间内无数据时各统计项展示 `—`
- **分页**：配置表格默认 20 条/页
- **布局引用**：参见原型 [requirement-config.html](../assets/web/requirement-config.html)（整页范例 `busyming-skills-design/web/templates/archive-list.html`；DOM 结构依据 `busyming-skills-design/.skills/page-blueprint/skeletons/web/list-page.vue.tpl`）

#### 导航关系

- 来源页：standalone 侧边菜单「需求管理 / 需求审批配置」（侧栏不自动过滤；管理员操作由服务端校验）
- 去向页：新增与编辑在本页弹窗内完成，不跳页
- 返回行为（产品目标）：面包屑「需求管理」返回需求列表页
- 产品目标面包屑：首页 / 研发 / 需求管理 / 需求审批配置

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| Tab 切换 | 点击一级或二级 Tab | 否 | 表格加载指示 | 加载该归属配置、群消息映射与统计；切一级 Tab 时二级 Tab 重置为首项 → 停留 | AcMessage.error「加载失败，请重试」+ 保留原 Tab |
| 新增配置 | 具新增权限 | 否 | 弹窗确认按钮 loading | AcMessage.success「配置已更新，仅对新提交需求生效」→ 关闭弹窗，刷新表格 | 弹窗顶部 AcAlert（同条件同级次审批人重复时提示「该条件下已存在相同审批人配置」）+ 输入保留 + 按钮恢复 |
| 编辑配置 | 具编辑权限 | 否 | 弹窗确认按钮 loading | AcMessage.success「配置已更新，仅对新提交需求生效」→ 关闭弹窗，刷新表格 | 弹窗顶部 AcAlert + 输入保留 + 按钮恢复 |
| 删除配置 | 具删除权限 | AcPopconfirm「删除后该条件下新提交需求将无法匹配审批链，确认删除？」 | 按钮 loading | AcMessage.success「配置已删除」→ 停留并刷新表格 | AcMessage.error（默认链缺级校验失败时提示「删除后该归属默认链将缺少 L{N} 级审批人」；专属链不受限）+ 按钮恢复 |
| 启用 / 停用 | 具编辑权限，行内开关切换 | 停用时 AcPopconfirm「停用后该配置不参与审批链匹配，确认停用？」 | 开关 loading | AcMessage.success「配置已启用」/「配置已停用」→ 停留并刷新 | AcMessage.error + 开关回滚原值 |
| 设置企微群 | 具群消息配置权限，点「设置」后保存 | 否 | 保存按钮 loading | AcMessage.success「{归属}企微群已绑定」→ 退出编辑态，刷新群消息配置 | 输入框下方错误文案「Webhook Key 无效或机器人已移出群」+ 输入保留 + 按钮恢复 |

#### 表单校验

**配置弹窗（新增 / 编辑）**

- 初态：产品线、业务线跟随当前 Tab 自动带入且只读（有点推荐时业务线整行隐藏）；提交对象跟随审批链配置卡当前所选（「默认链」或具体产品经理）自动带入且只读；新增时其余字段为空，编辑时回填该行配置
- 前置校验（新增指定产品经理专属链）：「请先填写产品经理姓名与门户用户 ID」「门户用户 ID 需为数字」

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 需求类型 | 是 | 下拉单选（5 类 + `*` 全部） | change | 「请选择需求类型或全部通配」 | 否 |
| 优先级 | 是 | 下拉单选（P0 / P1 / P2 / P3 + `*` 全部） | change | 「请选择优先级或全部通配」 | 否 |
| 审批级次 | 是 | 多选组（L1 业务线审批 / L2 实施确认 / L3 产品确认），至少勾一级 | change | 「请至少勾选一个审批级次」 | 否 |
| 各级审批人 | 是 | 按勾选级次动态渲染审批人行（姓名 + 门户用户 ID），每级至少 1 行不可删，多人即或签 | change | 「请选择 L{N} 级至少一名审批人」「L{N} 级审批人需同时填写姓名与数字用户 ID」 | 是（同条件同级次审批人唯一性校验） |
| 配置说明 | 否 | 不超过 256 字 | blur | 「配置说明不超过 256 字」 | 否 |

- 提交成功跳转：关闭弹窗，停留本页并刷新表格，无延迟
- 提交失败展示：弹窗顶部 AcAlert，输入保留
- 脏数据离开：弹窗内有修改时关闭 → AcModal「您有未保存的配置修改，确认关闭？」

**群消息配置（inline 编辑）**

- 初态：展示群名称与脱敏 Key；点「设置」进入编辑态，Key 输入框为空

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| Webhook Key | 是 | 非空；保存时服务端校验机器人有效性 | 保存时 | 「请输入 Webhook Key」/「Webhook Key 无效或机器人已移出群」 | 是（有效性校验） |

- 提交成功跳转：退出编辑态，停留本页，无延迟
- 提交失败展示：输入框下方错误文案，输入保留
- 脏数据离开：本场景不需要（点「取消」即放弃，不产生持久化数据）

#### 表格三态

- **空态**：未填提交对象时「请输入产品经理姓名与门户用户 ID 以查看其专属链配置」；当前所选提交对象暂无配置 → 空状态插图 + 文案（默认链：「该归属默认链尚未配置，外部提交与防御兜底不可用」；指定产品经理：「该产品经理尚未配置专属链，不能被选为提交对象」）+「新增配置」
- **加载态**：表格骨架屏（5 行占位）
- **错误态**：错误插图 +「点击重试」
