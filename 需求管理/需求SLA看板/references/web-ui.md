# 需求SLA看板 · Web 端 UI 描述

> 本文件承载本功能页面正文；全局约定与跨页导航见 [需求管理 · Web 共享 UI](../../references/web-ui.md)，业务与权限规则见 [功能入口](../SKILL.md)。正文为产品目标要求，不以代码缺口删减；原型见本功能资产目录。

### SLA 仪表盘页

- **菜单名称**：需求SLA看板
- **页面路径**：`/requirement/sla-dashboard`；筛选条件不入页面地址
- **route.name**：`devhubRequirementSlaDashboard`；`/subapp/devhub` 仅为部署 base
- **权限编码**：
  - 菜单资源码：`devhubRequirementSlaDashboard`；指标卡与滞留需求表复用需求列表接口资源码（`devhubRequirementList`）
  - 按钮：无独立按钮码；「手动催办」无前端权限点，由服务端按管理员口径拦截
- **页面类型**：`report`
- **页面定位**：审批时效全景——一屏回答「哪条业务线审得慢、卡在哪一级、有没有在变好」；指标口径见 [other-rule-sla.md §6](../../references/other-rule-sla.md#6-sla-仪表盘指标)
- **区块职责**（自上而下）：
  - 页头：右上「SLA 配置」文字链接（跳 SLA 配置页）+「刷新」（重载全部区块）
  - 筛选栏：产品线（下拉单选）/ 业务线（下拉单选，产品线为有点推荐时置灰清空）/ 提交时间（日期范围，**默认近 90 天**）/ 聚合粒度（按周 / 按月，默认按周，切换即刷新图表）
  - 统计卡区（4 张横排，复用需求列表口径）：审批中（已提交 + 业务线审批中 + 实施确认中 + 产品确认中四态合计）/ 当前滞留条数（实时值，不受时间区间筛选影响；整卡可点击，下钻至需求列表「滞留需求」视角并携带当前产品线、业务线筛选）/ 已关联排期 / 已驳回
  - 审批时效统计区（标题注明「按提交时间过滤，默认近 90 天」）：
    - 平均审批耗时：L1 / L2 / L3 各级等待时长均值的再平均，脚注展示各级分项（形如 `L1 xh · L2 xh · L3 xh`）
    - 端到端平均周期：自首次提交起至已关联排期，单位「天」；仅统计已达已关联排期的需求，在途需求不入分母
    - 超时率：超催办阈值节点数 ÷ 受理需求数，副行「N / M 条」；**整卡可点击，下钻至需求列表「滞留需求」视角**（带当前产品线、业务线筛选）
    - 受理需求：区间内非草稿需求条数
  - 图表一 · 各业务线平均审批耗时（分组柱状图）：X 轴为业务线，每组三根柱对应 L1 业务线审批 / L2 实施确认 / L3 产品确认；注明「有点推荐不区分业务线，不参与本图」
  - 图表二 · 趋势图（双折线：平均耗时（小时）/ 超时率（%））：🚨 X 轴严格按日期正序（最早在左）；区间内无数据的周 / 月**不补 0 值点**，注明「无数据区间不补 0」
  - 滞留需求表（标题「滞留需求（超 SLA 未审批）」）：列：需求编号（链接进详情）/ 标题 / 优先级 / 当前状态 / 滞留级次 / 停留时长 / 提交人（外部单展示手填姓名）/ 提交时间 / 操作（「手动催办」，规则与文案同需求列表滞留视角）；空态「很好，当前没有超时未处理的需求」
- **布局引用**：参见原型 [requirement-sla-dashboard.html](../assets/web/requirement-sla-dashboard.html)（整页范例 `busyming-skills-design/web/templates/report.html`；DOM 结构依据 `busyming-skills-design/.skills/page-blueprint/skeletons/web/dashboard-multi.vue.tpl`）

#### 导航关系

- 来源页：侧边菜单「需求管理 / 需求SLA看板」
- 去向页：需求列表页「滞留需求」视角（点超时率卡或当前滞留条数卡）；SLA 配置页（点右上「SLA 配置」）；需求详情页（点滞留需求表编号）
- 返回行为：面包屑「需求管理」返回需求列表页
- 产品目标面包屑：首页 / 研发 / 需求管理 / 需求SLA看板

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 筛选条件变更 | 修改任一筛选项 | 否 | 指标卡与图表区各自局部加载指示 | 指标与图表按新条件刷新，无提示 → 停留 | 各区块 inline「加载失败，点击重试」，区块间互不影响 |
| 聚合粒度切换 | 点击按周 / 按月 | 否 | 趋势图区加载指示 | 趋势图重绘 → 停留 | 趋势图区 inline「加载失败，点击重试」 |
| 刷新 | 点页头「刷新」 | 否 | 各区块局部加载指示 | 全部区块重载 → 停留 | 同筛选变更 |
| 手动催办 | 滞留需求表行内点「手动催办」 | AcPopconfirm「将向当前审批人发送企微催办消息，确认催办？」 | 按钮 loading + disabled | AcMessage.success「已向当前审批人发送催办」→ 停留 | 去重窗口命中时 AcMessage.warning「去重窗口内已催办过，本次未重复发送」；其余失败 AcMessage.error + 按钮恢复 |

#### 图表三态

- **空态**：区间内无数据 → 图表区空状态插图 +「当前筛选下暂无审批数据」
- **加载态**：指标卡骨架屏（四张占位）+ 图表区骨架屏
- **错误态**：各区块独立错误态 +「点击重试」，不整页报错

#### 交互约束

- 所有阈值比较以服务端返回的命中阈值为准，前端不写死 48 / 72 小时
- 滞留需求表是本页唯一写入口（手动催办），与需求列表「滞留需求」视角同规则、同去重窗口；本页不提供审批或配置写操作
- 取数受角色可见范围裁剪（服务端完成），非管理员看到的是其可见范围内的聚合值
