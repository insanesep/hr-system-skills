# 需求管理 · Web 端 UI 描述

> 本文件仅承载五个功能共用的全局约定、跨页导航与正文索引；页面元素和交互正文、原型分别归各叶子功能的 `references/` 与 `assets/web/`。组件白名单、Token 纪律、卡片化拓扑、三态等硬约束见 [设计入口](../../../busyming-skills-design/SKILL.md)、[平台规范](../../../busyming-skills-design/shared/platform-guidelines.md) 与 [页面标准](../../../busyming-skills-design/shared/page-standards/)，交互三维度按 [interaction-spec.md](../../../busyming-skills-common/workflow/PM/references/interaction-spec.md) 填写。业务规则只引用、不复述，规则入口见 [SKILL.md](../SKILL.md) Prerequisites；公开 H5 三页见 [外链 H5 正文](../需求外链管理/references/app-ui.md#公开-h5)。

## 全局约定

### 状态与标签

视觉色值以设计系统的状态语义与 Tag 色板为准，本文件只声明语义，不定义私有颜色。

| 状态 | 标签文案 | 状态语义 |
|------|---------|---------|
| `DRAFT` | 草稿 | default |
| `SUBMITTED` | 已提交 | processing |
| `BU_REVIEWING` | 业务线审批中 | processing |
| `IMPL_REVIEWING` | 实施确认中 | processing |
| `PM_REVIEWING` | 产品确认中 | processing |
| `PM_SUBMITTED` | 待关联排期（缺陷修复单为「待转黑灯工厂」） | warning |
| `LINKED` | 已关联排期（缺陷修复单为「已转黑灯工厂」） | success |
| `REJECTED` | 已驳回 | danger |

- 瞬时态不展示为独立状态与独立节点，筛选下拉与状态标签均不出现，见 [state-machine.md §3](state-machine.md#3-级次递进)
- 优先级 Tag：`P0 紧急` 红 / `P1 高` 橙 / `P2 中` 蓝 / `P3 低` 灰
- 业务线 Tag：运营 蓝 / 财务 紫 / 供应链 绿 / 数字化 橙，全模块复用同一映射
- 产品线 Tag：鸣鸣很忙 红 / 有点推荐 紫；有点推荐行的业务线位置展示 `—`
- 提交来源：内部不展示标签；外部展示黄「外部提交」Tag，全模块统一
- 外链状态：待使用 processing / 已提交 success / 已过期 default / 已撤销 danger
- 排期开发状态：待开发 default / 开发中 processing / 开发完成 success / 待澄清 warning
- 枚举取值以 [data.md §12](data.md#12-枚举) 为准；有点推荐的业务线占位值不进入任何下拉选项与展示

### 附件展示

| 类型 | 图标 | 扩展名 |
|------|------|-------|
| 图片 | 图片图标 | jpg / jpeg / png / webp / gif |
| 文档 | 文档图标 | pdf / docx / xlsx / pptx / txt |
| 视频 | 视频图标 | mp4 / mov |

- 上传限制与存储规则见 [other-rule-attachment.md](other-rule-attachment.md)；**Web 端不提供上传、追加与删除入口**，附件来源为公开 H5 外部提交上传的图片，Web 端只读展示
- 附件对有权查看该需求的用户一律可见，不展示审核状态
- 审批中追加的附件额外渲染「审批中追加」标签
- 不区分预览与下载入口：点击文件名获取签名链接新窗口打开，链接有效期 1 小时，每次点击重新获取

### SLA 滞留程度

滞留时长相对命中阈值的展示口径，滞留需求视角与 SLA 仪表盘复用：

| 滞留程度 | 判定 | 状态语义 |
|---------|------|---------|
| 正常 | 滞留时长 < 催办阈值 | default |
| 已催办 | 催办阈值 ≤ 滞留时长 < 升级阈值 | warning |
| 已升级 | 滞留时长 ≥ 升级阈值 | danger |

- 阈值按产品线 × 优先级 × 审批级次逐行取（[other-rule-sla.md §3](other-rule-sla.md#3-差异化配置)），**前端不写死 48 / 72 小时**，一律以服务端返回的命中阈值为准
- 滞留时长展示为「N 小时」，≥ 48h 时换算为「N 天 M 小时」

### 通用约定

- 列表与详情的可见范围由服务端按角色裁剪，见 [permission-rules.md §3](permission-rules.md#3-数据可见范围)，前端不做兜底过滤
- 页面不触发任何推送：企微个人消息与群消息由服务端在操作成功后异步发出，页面只用 AcMessage 反馈业务结果
- 路由层不做权限码拦截，侧边菜单不做权限过滤：按钮以权限指令（`v-permission`）隐藏，全部接口携带权限编码请求头由服务端鉴权；列表行操作由前端按视角与状态推导展示，服务端仍二次校验
- 外部提交人姓名、部门为手填自由文本，不关联组织架构，页面不提供人员或部门详情链接

## 页面间导航

实际应用菜单路径为「需求管理 / 功能菜单」，五个菜单同级；详情与提交为需求工单管理的非菜单路由。应用路由与 route.name 以 [路由配置](../../../busyming-devhub-web/src/router/index.ts) 为准，`/subapp/devhub` 只作为部署 base 拼接访问地址。

下表定义跨页导航、返回恢复与完整面包屑要求；各页「导航关系」中的面包屑返回、地址同步与恢复规则须一致执行。独立运行由 [standalone 布局](../../../busyming-devhub-web/src/layouts/PortalLayout.vue)承载侧栏与页头，微应用外壳由门户提供；两种模式均遵循本表的功能归属与导航规则。

| 源页面 | 触发动作 | 目标页面 | 返回路径（目标） | 产品目标面包屑 |
|--------|---------|---------|------------------|----------------|
| 侧边菜单「需求工单管理」 | 点击菜单 | 需求列表页 | — | 首页 / 研发 / 需求管理 / 需求工单管理 |
| 需求列表页 | 点击「新增需求」 | 需求提交页 | 面包屑「需求工单管理」 | 首页 / 研发 / 需求管理 / 需求工单管理 / 新增需求 |
| 需求列表页 | 点击编号或行「查看详情」 | 需求详情页 | 面包屑「需求工单管理」 | 首页 / 研发 / 需求管理 / 需求工单管理 / 需求详情 |
| 需求列表页 | 点击行「编辑」 | 需求提交页（编辑态） | 面包屑「需求工单管理」 | 首页 / 研发 / 需求管理 / 需求工单管理 / 编辑需求 |
| 需求详情页 | 点击「重新提交」 | 需求提交页（重提态） | 面包屑「需求详情」 | 首页 / 研发 / 需求管理 / 需求工单管理 / 编辑需求 |
| 需求详情页 | 点击关联卡片编号 | 功能排期卡片详情页（页内跳转） | 面包屑「需求详情」 | 首页 / 研发 / 研发管理 / 功能排期管理 / 卡片详情 |
| 需求详情页（外部单） | 点击「来源外链」 | 外链管理页（在台账中按提交进度反查，不定位高亮） | 面包屑「需求详情」 | 首页 / 研发 / 需求管理 / 需求外链管理 |
| 需求提交页 | 暂存草稿、提交审批或取消 | 需求列表页 | — | 首页 / 研发 / 需求管理 / 需求工单管理 |
| 侧边菜单「需求外链管理」 | 点击菜单 | 外链管理页 | 面包屑「需求管理」 | 首页 / 研发 / 需求管理 / 需求外链管理 |
| 侧边菜单「需求审批配置」 | 点击菜单 | 审批链配置页 | 面包屑「需求管理」 | 首页 / 研发 / 需求管理 / 需求审批配置 |
| 侧边菜单「需求SLA看板」 | 点击菜单 | SLA 仪表盘页 | 面包屑「需求管理」 | 首页 / 研发 / 需求管理 / 需求SLA看板 |
| SLA 仪表盘页 | 点击「超时率」或「当前滞留条数」指标卡 | 需求列表页「滞留需求」视角（带当前产品线、业务线筛选） | 面包屑「需求SLA看板」 | 首页 / 研发 / 需求管理 / 需求工单管理 |
| SLA 仪表盘页 | 点击右上「SLA 配置」 | SLA 配置页 | 面包屑「需求SLA看板」 | 首页 / 研发 / 需求管理 / SLA规则配置 |
| 侧边菜单「SLA规则配置」 | 点击菜单 | SLA 配置页 | 面包屑「需求管理」 | 首页 / 研发 / 需求管理 / SLA规则配置 |

- 面包屑「需求管理」返回需求列表页；七个页面均支持直达：详情页凭需求标识加载全量数据，提交页编辑态以 `?id=` 携带需求标识；列表页支持以地址参数带入视角（view）与产品线、业务线（供 SLA 看板下钻），其余筛选不入地址
- 无孤儿页面：需求列表页为模块入口，可经有限步骤到达其余 6 页；外链管理、审批链配置、SLA 仪表盘、SLA 配置另有侧边菜单直达
- SLA 配置与审批链配置同级、不合并为同一页的 Tab：审批链管「谁审」，SLA 管「多久没审就催」
- 公开 H5 三页免登录、无侧边菜单与面包屑，不在本表
