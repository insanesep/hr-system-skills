# 报告配置

研发报告子域的共享机制与配置模块：托管子域规则真源（报告类型与命名、周期归属与周/日索引、触发生成入库、版本、渲染、权限矩阵、异常场景），并承载两个配置页（报告项目配置、报告触发配置）。各报告模块（人员产出 / 文档一致性 / 项目进度）只承载本类型的生成规范与查阅页面，共享机制一律以本模块 references 为真源。

## 服务对象与端

- **服务对象**：PM、研发负责人（配置页）；各报告模块与服务端生成流程（共享规则）
- **Web 管理端**：报告项目配置、报告触发配置两页；无 App 端

## 子域共享规则（真源）

- 报告类型枚举与文件命名、周期归属与周/日索引、触发生成与入库（服务端生成 / 推送上报 / 手动补传）、版本、Markdown 渲染、权限矩阵、异常场景：全部见 [`references/business-rule.md`](references/business-rule.md)
- 实体定义（报告项目扩展 / 触发配置 / 生成任务 / 报告主表 / 报告版本）：见 [`references/data.md`](references/data.md)
- 排期双卡 MCP 调用口径、容错口径、推送上报旁路契约：见 [`references/data-source-api.md`](references/data-source-api.md)

## 报告项目配置（映射扩展）

- 项目基础映射（项目 ↔ harness 工程 / 代码服务仓 / 启停）唯一真源为 [`排期管理/功能排期`](../../排期管理/功能排期/SKILL.md) 的项目配置，本模块只读引用，不复制、不另建
- 本模块为每个启用项目维护报告侧扩展：**项目 key**（报告文件命名与报告项标识）与**分支策略**（统计基准分支），规则真源见 [`references/business-rule.md` §3](references/business-rule.md#3-报告项目配置)
- 扩展随功能排期启用项目自动成行，不可手工新增或删除；扩展启停联动触发配置行

## 报告触发配置

- 每个报告项（报告类型 + 项目标识）一条触发配置：触发方式（定时 / 手动）、定时规则、类型参数、启停，规则真源见 [`references/business-rule.md` §4](references/business-rule.md#4-报告触发配置)
- 支持「立即生成」手动触发与生成记录查看、失败重试；生成任务状态机与并发约束见 [`references/business-rule.md` §5.2](references/business-rule.md#52-服务端生成主通道)

## 页面功能概览（仅列职责）

| 端 | 页面 | 职责 |
| -- | ---- | ---- |
| Web | 报告项目配置（见 [`references/web-ui.md`](references/web-ui.md)，原型见 `assets/web/project-config.html`） | 启用项目自动成行；维护项目 key 与分支策略；扩展启停并联动触发配置行 |
| Web | 报告触发配置（同上，原型见 `assets/web/report-trigger-config.html`） | 全部报告项的触发方式、定时规则、类型参数与启停；立即生成；生成记录与失败重试 |
