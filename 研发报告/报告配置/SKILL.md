# 报告配置

研发报告分组的共享机制与配置模块：托管类型、命名、周期、生成入库、版本、渲染与权限规则；配置页面仅有触发配置、报告范围配置两个页签。项目、仓库及人员范围的维护统一归「研发管理 → 项目管理」，成员必须在具体项目内新增或关联，一人可参与多个项目；本功能只读消费，不保留人员维护页签或平行名单。各报告保留本类型口径，共享机制以本模块 references 为真源。

## 服务对象与端

- **服务对象**：PM、研发负责人（配置页）；各报告模块与服务端生成流程（共享规则）
- **Web 管理端**：「研发报告 → 报告配置」单页两 Tab（触发配置（默认）/ 报告范围配置）；无 App 端

## 子域共享规则（真源）

- 报告类型枚举与文件命名、周期归属与周/日索引、触发生成与入库（服务端生成 / 推送上报 / 手动补传）、版本、Markdown 渲染、权限矩阵、异常场景：全部见 [`references/business-rule.md`](references/business-rule.md)
- 实体定义（报告项目扩展 / 触发配置 / 生成任务 / 报告主表 / 报告版本）：见 [`references/data.md`](references/data.md)
- 功能排期卡片 MCP 调用口径、容错口径、推送上报旁路契约：见 [`references/data-source-api.md`](references/data-source-api.md)

## 报告范围配置（映射扩展）

- 项目、harness 工程和代码服务仓只读引用 [`项目管理`](../../研发管理/项目管理/SKILL.md)，与功能排期共用同一稳定项目标识；范围消费见其 [`business-rule.md#consumption`](../../研发管理/项目管理/references/business-rule.md#consumption)
- 扩展关联稳定项目引用，维护全局唯一且首次保存锁定的 **key**、分支策略与扩展启停；范围类报告沿用各组 key，项目进度报告仅使用 `_all` 并按组展示，详见 [`references/business-rule.md` §3](references/business-rule.md#3-报告项目配置)
- 启用项目自动成行，本页不增删基础项目；key、分支策略齐备并启用才联动报告；项目停用停止生成，保留归档；仓源失败明确标「未取得」，不作为零事实

## 报告触发配置

- 每个报告项（报告类型 + 项目标识）一条触发配置：触发方式（定时 / 手动）、定时规则、类型参数、启停；项目进度报告的周报与月报各一条独立 `_all` 配置，可同时调度，不按项目组新增，规则真源见 [`references/business-rule.md` §4](references/business-rule.md#4-报告触发配置)
- 支持「立即生成」手动触发与生成记录查看、失败重试；生成任务状态机与并发约束见 [`references/business-rule.md` §5.2](references/business-rule.md#52-服务端生成主通道)

## 统计人员范围

- 唯一真源为 [`项目管理`](../../研发管理/项目管理/SKILL.md) 的项目成员管理，人员只能在项目内新增或关联；参与关系见 [`#membership`](../../研发管理/项目管理/references/business-rule.md#membership)，有效范围和快照见 [`#report-scope`](../../研发管理/项目管理/references/business-rule.md#report-scope)，身份匹配见 [`#identity`](../../研发管理/项目管理/references/business-rule.md#identity)
- 周报、日报和 Qoder 产研团队名单使用全部启用项目有效成员的去重并集，不按项目另生成人员产出报告；项目进度报告各组使用该项目有效成员，不由 Git 提交决定团队资格，同人多项目和多角色在全量汇总只计一人
- 生成时冻结成员与项目关系快照，名单外不计入人员维度、不点名，历史版本不按当前名单改写；人员产出报告空名单拒绝生成；无 Qoder 账号或源缺失标「未取得」，不补 0

## 页面功能概览（仅列职责）

| 端 | 页面 | 职责 |
| -- | ---- | ---- |
| Web | 触发配置页签（见 [`references/web-ui.md`](references/web-ui.md)，原型见 `assets/web/report-trigger-config.html`） | 全部报告项的触发方式、定时规则、类型参数与启停；立即生成；生成记录与失败重试；工具栏手动补传 |
| Web | 报告范围配置页签（同上） | 启用项目自动成行；只维护 key、分支策略与报告扩展启停 |

两个页签统一菜单入口，人员范围仅提供只读来源说明；不设人员维护页签、表单、权限项或项目管理快捷入口，成员配置统一从研发管理菜单进入。
