# 报告配置 · 数据定义

> 面向产品视角定义研发报告子域实体、字段语义与实体关系；表结构以代码仓为准，不在此描述。
> 业务规则真源见 [business-rule.md](business-rule.md)。

---

## 1. 实体关系

```text
域/项目（域及项目管理，只读引用） 1 ──── 1 报告范围扩展
报告触发配置 1 ──── N 报告生成任务
研发报告 1 ──── N 报告版本
报告生成任务（成功时） N ──── 1 报告版本（产出版本）
产研人员管理自动报告范围 ──── 生成名单快照（只读引用，随报告版本留档）
```

- 启用有效域/项目自动派生「报告范围扩展」，类型与稳定实体只读引用 [域及项目管理实体](../../../研发管理/域及项目管理/references/data.md#entities)；扩展 key 供报告命名与归档引用，仍兼容既有「项目标识」字段名
- 报告项（报告类型 + 项目标识）对应一条「触发配置」，驱动定时 / 手动「生成任务」
- 一般报告由（报告类型 + 项目标识 + 发报日）唯一确定；项目进度报告由（报告类型 + `_all` + 统计周期类型 + 统计区间）唯一确定，每个自然周或自然月仅一份，同唯一键重复入库产生新「版本」，报告默认指向最新版本

## 2. 报告范围扩展

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 扩展 ID | 报告专属扩展标识 | 标识 | 是 | 系统生成，不作为域/项目实体 ID |
| 范围类型 | 基础实体类别 | 枚举 | 是 | 域 / 项目，只读派生 |
| 稳定实体引用 | 关联真源域/项目 | 引用 | 是 | 只读引用域及项目管理；类型 + 稳定引用唯一，不按名称匹配 |
| key（兼容项目 key） | 报告文件命名与报告项标识 | 文本 | 启用前必填 | 小写字母 / 数字 / 连字符，全局唯一；首次保存锁定，沿用历史 key |
| 分支策略 | 统计基准分支 | 枚举 | 启用前必填 | `master` / 最近 `release/*` 且防回退落后主干 |
| 启停状态 | 报告扩展启停 | 枚举 | 是 | 基础实体停用或远端确认缺失停止生成并联动停用触发；历史归档不删除 |
| 创建时间 / 更新时间 | 审计字段 | 时间 | 是 | 东八区 |

域、项目与 N:N 执行映射字段只在 [真源实体](../../../研发管理/域及项目管理/references/data.md#entities) 定义，不在报告复制。范围快照须留存主仓、限定目录、确认执行映射及来源核验状态，消费规则见 [#consumption](../../../研发管理/域及项目管理/references/business-rule.md#consumption)。

## 3. 报告触发配置

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 配置 ID | 主键 | 标识 | 是 | 系统生成 |
| 报告类型 | 五类报告之一 | 枚举 | 是 | `WEEKLY_DEV` / `DAILY_DEV` / `CONSISTENCY` / `DOC_HEALTH` / `PROJECT_PROGRESS`，见 [business-rule.md §1](business-rule.md#1-报告类型与文件命名) |
| 项目标识 | 项目维度 | 文本 | 项目维度类型必填 | 范围类报告关联「报告范围扩展」启用数据的项目 key；`PROJECT_PROGRESS` 固定 `_all`，仅内置一条配置行，不随项目组扩展联动 |
| 定时触发开关 | 是否参与定时调度 | 开关 | 是 | 与手动触发开关至少启用一种 |
| 定时规则 | 调度周期 | 结构化文本 | 定时开关启用时必填 | 周期（每日 / 每周 / 每月）+ 星期或号（每日无需）+ 时间（东八区） |
| 手动触发开关 | 是否允许「立即生成」 | 开关 | 是 | — |
| 类型参数 | 报告类型差异参数 | 结构化文本 | 否 | 一致性校验：回看天数；产品文档健康度：无（每周全量评估）；项目进度报告：统计周期（周 / 月） |
| 启停状态 | 配置整体启停 | 枚举 | 是 | 停用即不再定时触发且手动禁用；历史数据保留 |
| 最近生成任务 ID | 最近一次任务 | 标识 | 否 | 冗余展示字段 |
| 创建时间 / 更新时间 | 审计字段 | 时间 | 是 | 东八区 |

## 4. 报告生成任务

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 任务 ID | 主键 | 标识 | 是 | 系统生成 |
| 触发配置 ID | 归属配置 | 标识 | 是 | 外键关联报告触发配置 |
| 触发来源 | 任务来源 | 枚举 | 是 | `SCHEDULED`（定时到点）/ `MANUAL`（手动立即生成） |
| 范围快照引用 | 本次范围与确认映射 | 引用 | 范围类必填 | 范围类型 + 稳定实体引用；`PROJECT_PROGRESS` 固定 `_all`，保存全部启用项目组的去重并集快照 |
| 生成名单快照引用 | 本次人员统计依据 | 引用 | 人员产出报告、项目进度报告必填 | 来自产研人员管理；人员产出报告空名单或未取得拒绝生成，项目进度报告按项目组参与关系取数 |
| 统计区间起 / 止 | 本次统计窗口 | 日期 | 是 | 按报告类型口径计算后随任务入参下发 |
| 状态 | 任务状态 | 枚举 | 是 | `RUNNING`（生成中）/ `SUCCESS`（成功）/ `FAILED`（失败） |
| 失败原因 | 失败说明 | 文本 | 否 | 失败时必填 |
| 产出报告版本 ID | 生成产物 | 标识 | 否 | 成功时关联报告版本 |
| 重试来源任务 ID | 重试链 | 标识 | 否 | 重试产生新任务并关联原任务 |
| 操作人 | 触发者 | 文本 | 是 | 手动触发记操作人姓名；定时记「定时调度」 |
| 开始时间 / 结束时间 | 执行耗时 | 时间 | 是 | 东八区；结束时间为终态时间 |

**关系约束：**

- 同一报告项同时刻仅允许一个 `RUNNING` 任务（见 [business-rule.md §5.2](business-rule.md#52-服务端生成主通道)）
- 任务记录不允许删除（审计留痕）

## 5. 研发报告（主表）

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 报告 ID | 主键 | 标识 | 是 | 系统生成 |
| 报告类型 | 五类报告之一 | 枚举 | 是 | `WEEKLY_DEV` / `DAILY_DEV` / `CONSISTENCY` / `DOC_HEALTH` / `PROJECT_PROGRESS`，见 [business-rule.md §1](business-rule.md#1-报告类型与文件命名) |
| 项目标识（兼容 key） | 报告范围命名标识 | 文本 | 范围类必填 | 范围类报告关联报告范围扩展 key；`PROJECT_PROGRESS` 固定 `_all`，项目组仅作正文分组 |
| 范围类型 / 稳定实体引用 | 基础范围关联 | 枚举 / 引用 | 单范围类必填 | 只读引用域及项目管理，不因历史停用而删除关联；`PROJECT_PROGRESS` 改存全部启用项目组快照，无单组关联 |
| 报告标题 | md 首个一级标题 | 文本 | 是 | 缺失时以「类型名 + 发报日」兜底 |
| 发报日 | 报告生成日期 | 日期 | 是 | 服务端生成时由任务给定；推送与补传取自文件名 `yyyyMMdd`，不可晚于今天 |
| 所属周起 | 发报日所在自然周周一 | 日期 | 是 | 东八区，冗余存储用于周索引 |
| 所属周止 | 发报日所在自然周周日 | 日期 | 是 | 同上 |
| 统计区间起 | 报告统计窗口起点 | 日期 | 否 | 仅 `WEEKLY_DEV`、`DAILY_DEV` 与 `PROJECT_PROGRESS`，从正文解析，失败为空 |
| 统计区间止 | 报告统计窗口终点 | 日期 | 否 | 同上 |
| 统计周期类型 | 周期报告的时间粒度 | 枚举 | `PROJECT_PROGRESS` 必填 | 周 / 月；与 `_all`、统计区间共同确定唯一周期报告 |
| 当前版本号 | 最新版本序号 | 数值 | 是 | 从 1 起递增 |
| 来源 | 最近版本的入库通道 | 枚举 | 是 | `GENERATED`（服务端生成）/ `PUSH`（推送上报）/ `MANUAL`（手动补传） |
| 创建时间 / 更新时间 | 审计字段 | 时间 | 是 | 东八区 |

## 6. 报告版本（从表）

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 版本 ID | 主键 | 标识 | 是 | 系统生成 |
| 报告 ID | 归属主表 | 标识 | 是 | 外键关联研发报告 |
| 版本号 | 版本序号 | 数值 | 是 | 主表内从 1 递增 |
| 范围 / 名单快照引用 | 当次生成范围与人员依据 | 引用 | 按报告类型必填 | 与任务同源留档；外部会话随产物关联，不按当前实体或名单改写历史 |
| 原始文件名 | 入库时的文件名 | 文本 | 是 | 原样保留，沿用既有 key 与 `_all` 命名 |
| 文件存储键 | 原始 .md 的对象存储位置 | 文本 | 是 | 只存键不存内容 |
| 渲染产物存储键 | md 渲染后 HTML 的对象存储位置 | 文本 | 是 | 入库时生成，见 [business-rule.md §6](business-rule.md#6-markdown-渲染规则) |
| 大纲目录 | 从渲染产物提取的章节目录 | 结构化文本 | 否 | h2/h3 锚点列表，正文为空时为空 |
| 文件哈希 | 内容指纹 | 文本 | 是 | 推送上报幂等判重依据 |
| 文件大小 | 原始文件字节数 | 数值 | 是 | ≤ 2MB |
| 来源 | 本版本入库通道 | 枚举 | 是 | `GENERATED` / `PUSH` / `MANUAL` |
| 操作人 | 入库触发者 | 文本 | 是 | 服务端生成记「生成服务」；推送上报记外部生成方标识；手动补传记上传人姓名 |
| 入库时间 | 版本创建时间 | 时间 | 是 | 东八区 |

**关系约束：**

- 版本从属于报告，删除报告版本不被允许（审计留痕）
- 报告的「来源 / 当前版本号」始终跟随最新版本，属冗余展示字段
- 生成任务成功时必须关联其产出版本；一个版本至多被一个生成任务引用

## 7. 报告统计人员范围

只读引用 [产研人员管理 #report-scope](../../../研发管理/产研人员管理/references/business-rule.md#report-scope) 的自动范围与生成名单快照；身份引用 [#identity](../../../研发管理/产研人员管理/references/business-rule.md#identity)，参与关系引用 [#membership](../../../研发管理/产研人员管理/references/business-rule.md#membership)。本模块不保留独立人员实体、名单维护字段或归一冲突规则副本。

名单快照随人员产出报告、项目进度报告任务与版本留档，服务端、外部会话及 Qoder 数据包共同引用，不按当前人员状态重写历史；同人多角色只计一次，名单外不计入。人员产出报告空名单或真源未取得仍拒绝生成；项目进度报告按项目组参与关系取数，产品与研发人数展示生成时当前状态。无账号或源缺失标「未取得」，不补零；需求吞吐与仓库清单保持对应范围全量口径。
