# Web 端 UI 描述 · 报告配置

> 硬约束（组件白名单 / Token / 三态）详见 page-gen.prompt.md【2. 硬约束】A-L，此处仅填产品侧元信息。
> 本模块为研发报告子域统一配置入口；各报告模块列表页仅保留本类型的「立即生成」快捷入口。
> 页面形态：单页两 Tab——**触发配置（默认）/ 报告范围配置**；人员范围只读引用产研人员管理，不设人员页签或维护操作。以下为已确认产品目标；既有 HTML 本次不修改，不作为新目标已实现证据。整页报告配置写操作仍由服务端校验 `devhubReportTriggerConfig`。

### 报告范围配置

- **页面路径**：`/subapp/devhub/report/trigger-config`（报告配置页内「报告范围配置」页签）
- **权限编码**：
  - 路由：`devhubReportTriggerConfig`
  - 按钮：`devhubReportTriggerConfig`（编辑报告扩展 / 启停）
- **页面类型**：列表页（配置表格 + 编辑弹窗）
- **区块职责**：
  - 常驻提示：域/项目清单与 N:N 执行映射只读来自 [域及项目管理](../../../研发管理/域及项目管理/SKILL.md)，清单同步获得，本页不手工增删基础实体。新范围仅自动成行；key、分支策略齐备且启用才联动报告。停用或远端确认缺失停止生成，归档保留
  - 工具栏：范围类型（全部 / 域 / 项目）、状态（已配置 / 待配置 / 已停用 / 待核对）、关键词（key / 名称）、查询 / 重置
  - 主体表格：范围类型、名称、稳定实体引用、key（缺失标「待配置」）、主仓及限定目录、确认执行仓与路径映射、真源状态、分支策略、报告扩展启停、关联触发配置、编辑。基础信息只读；关联触发列跳「触发配置」并按该稳定范围过滤，仅文档一致性与产品文档健康度按组联动；项目进度报告展示「共享 `_all` 周期配置」，不按组生成配置行
  - 范围摘要：域为整个主仓及确认执行映射；项目为对应一级目录及该项目确认执行映射，根文件与跨项目提交消费见 [#consumption](../../../研发管理/域及项目管理/references/business-rule.md#consumption)。不叠加域及子项目重复指标
  - 编辑弹窗：范围类型、名称、稳定引用、主仓、限定目录、确认映射及核验状态只读；仅编辑全局 key（首次保存后锁定）、分支策略与扩展启停，保留 `_all` 为项目进度报告唯一标识，不可占用
  - 真源停用或远端确认缺失时禁止启用与生成；恢复后保留旧 key，核验后再启用。历史旧整体项目扩展仅显式核对到对应域，未核对标「待核对」，不猜测或复制到子项目
  - 空态：AcEmpty「暂无启用有效域/项目」
- **布局引用**：`参见原型 ../assets/web/project-config.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl`）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 报告配置」，页内切至「报告范围配置」页签
- 去向页：「触发配置」页签（关联触发配置列点击跳页签并按该项目过滤）

### 报告触发配置

- **页面路径**：`/subapp/devhub/report/trigger-config`（报告配置页默认页签）
- **权限编码**：
  - 路由：`devhubReportTriggerConfig`
  - 按钮：`devhubReportTriggerConfig`（编辑配置 / 启停 / 立即生成 / 失败重试）、`devhubReportUpload`（工具栏「手动补传」）
- **页面类型**：列表页（配置表格 + 编辑弹窗 + 生成记录抽屉）
- **区块职责**：
  - 工具栏（筛选 panel）：报告类型（既有五类）、报告范围（单选，有效且扩展已配置启用的域/项目，标签「类型 · 名称 · key」；项目进度报告固定 `_all`「全部项目组」）、状态（全部 / 启用 / 停用）、查询 / 重置；右侧「手动补传」与「刷新」
  - 主体表格：报告类型、范围类型/名称/key、触发方式、定时规则、原类型参数、启停、最近生成、编辑 / 立即生成 / 生成记录。范围稳定引用只读，不随名称匹配；无范围类显示 —，`PROJECT_PROGRESS` 仅一行 `_all`，不按项目组新增。范围停用、远端确认缺失或配置未齐时禁止新生成但保留记录；人员产出报告与项目进度报告显示本次人员真源名单快照引用与人数，不提供名单维护
  - 弹窗：**编辑配置弹窗**（标题「编辑配置 · {报告类型 · 项目}」）：报告项只读（项目维度配置行附注「项目维度配置行随报告范围配置联动，报告类型与项目只读」；项目进度报告附注「每周期仅一份 `_all` 总报告，项目组仅在正文分组」）、触发方式勾选（定时 / 手动，至少一种）、定时规则（勾选定时时渲染：周期单选每日 / 每周 / 每月，每周默认周日、每月默认 1 日，时间输入 `HH:mm`（东八区）；附注「计划点短暂不可用时，恢复后在下一计划点之前补跑最近一次」）、类型参数（一致性校验：回看天数，打开时缺省默认 7；产品文档健康度：显示「该报告类型无类型参数，每周全量评估」；项目进度报告：统计周期周 / 月，默认周；研发周报与研发日报显示「该报告类型无类型参数」）、启停（附注「停用即不再定时触发，手动触发同步禁用；历史报告与生成记录保留」）
  - 抽屉：**生成记录抽屉**（标题「生成记录 · {报告项}」）：任务表格，列：触发来源（定时 / 手动（操作人），重试任务追加「 · 重试」）、状态（生成中 / 成功 / 失败）、统计窗口、开始时间、耗时（形如「41 秒」「6 分 12 秒」，未结束显示 —）、失败原因、产出版本（🚨 固定显示 —：任务仅回传产物版本标识，无法定位报告版本，查阅报告请前往对应模块列表）、操作（失败行可「重试」，重试即新建任务并关联原任务）；**存在生成中任务时每 3 秒静默轮询，全部到达终态后自动停止**；空态「暂无生成记录」
  - 空态：AcEmpty「暂无触发配置」
- **布局引用**：`参见原型 ../assets/web/report-trigger-config.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl`）

## 手动补传弹窗（报告模块共用）

> 手动补传弹窗为各报告列表页（人员产出 / 文档一致性 / 项目进度）与本页工具栏共用的同一组件，统一在此登记，各模块不再复述；类型相关差异（预置类型、是否含项目字段）在各模块 web-ui 描述。产品文档健康度报告不提供手动补传。

- **打开方式**：各报告列表页工具栏「手动补传」（类型按当前页固定）/ 索引缺失行或当日行「补传」（类型固定 + 预填项目与发报日）/ 报告触发配置工具栏「手动补传」（类型不固定，弹窗内下拉选择）
- **权限编码**：`devhubReportUpload`
- **表单字段**：报告类型（固定时展示 Tag，选择文件后按识别结果为准）、报告范围（仅范围类显示，类型=域/项目 + 稳定实体引用，候选为有效已配置启用范围，展示「类型 · 名称 · key」；项目进度报告不显示该字段，固定 `_all`）、发报日（不可晚于今天，识别后回填）、报告文件（UTF-8 .md，单文件 ≤2MB，重复选择替换）。范围类报告沿用各组 key；项目进度报告仅使用 `_all` 文件名；人员报告产物关联采用的人员真源名单快照
- **文件名识别**：命中命名规范（`weekly_dev_yyyyMMdd.md` / `daily_dev_yyyyMMdd.md` / `consistency_yyyyMMdd_项目key.md` / `progress_yyyyMMdd__all.md`）自动回填类型 / 发报日 / 项目并展示成功提示条「已按文件名识别：…」；未命中提示「文件名无法识别，请手动指定…（命名规范：consistency_yyyyMMdd_项目key.md）」；项目进度报告使用单组 key 不再识别为新报告，缺口行进入时提示「已从缺口带入：…」
- **操作反馈**：提交按钮 loading；成功 toast「补传成功，已生成 v{N}」→ 关弹窗并刷新来源列表；重复内容提示「内容重复，与现有版本一致，未产生新版本」；失败 toast error + 弹窗保留、字段值不丢
- **脏数据离开**：已选择文件或已填写发报日时关闭 → 确认「已选择文件或已填写发报日，放弃本次补传？」
