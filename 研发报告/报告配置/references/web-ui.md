# Web 端 UI 描述 · 报告配置

> 硬约束（组件白名单 / Token / 三态）详见 page-gen.prompt.md【2. 硬约束】A-L，此处仅填产品侧元信息。
> 本模块为研发报告子域统一配置入口；各报告模块列表页仅保留本类型的「立即生成」快捷入口。
> 页面形态：单页三 Tab——**触发配置（默认）/ 项目配置 / 人员范围**，菜单「报告配置」统一入口；整页写操作均携带 `devhubReportTriggerConfig` 权限编码由服务端校验。

## 页面清单

### 报告项目配置

- **页面路径**：`/subapp/devhub/report/trigger-config`（报告配置页内「项目配置」页签）
- **权限编码**：
  - 路由：`devhubReportTriggerConfig`
  - 按钮：`devhubReportTriggerConfig`（编辑扩展 / 启停）
- **页面类型**：列表页（配置表格 + 编辑弹窗）
- **区块职责**：
  - 顶部常驻提示条（警示样式）：「联动规则：扩展「启用」即在「报告触发配置」页自动生成该项目维度报告的配置行（默认定时每周）；扩展「停用」同步停用关联配置行，历史报告保留可查。基础映射的新增与启停在功能排期维护，本页只读。」
  - 工具栏（筛选 panel）：状态（已配置 / 待配置 / 已停用）、关键词（项目 key / 名称模糊）、查询 / 重置
  - 主体区（配置表格 panel）：标题「报告项目配置」+ 元说明「项目基础映射（harness 工程 / 代码仓）只读引用自「研发管理 / 功能排期管理」项目配置 · 行随启用项目自动成行，不可手工新增或删除」；列：项目名称、项目 key（未配置显示黄 Tag「待配置」）、harness 工程（只读，来自功能排期项目映射）、代码仓清单（只读，「N 个」数量徽标，悬停展示完整仓名清单）、分支策略（master / 最近 release 且防回退落后主干）、启停开关、关联触发配置（未联动（待配置）/「N 行 · 已同步停用」/「N 行 · 定时每周、每月」或「手动」，**点击跳触发配置页签并按该项目过滤**）、操作（编辑）
  - 行生成：功能排期启用项目自动成行，不可手工新增或删除；行状态判定优先级：已停用（停用且留有 key / 分支策略）> 待配置（key 或分支策略缺失）> 已配置；待配置项目不参与项目维度报告
  - 弹窗：**编辑扩展弹窗**：项目名称 / harness 工程 / 代码仓清单（只读展示，附注「基础映射只读，来自功能排期项目配置」）、项目 key（首次设置后锁定不可改；小写字母 / 数字 / 连字符；附注「报告文件命名与报告项标识锚点，首次保存后不可改；保留值 _all 为全部项目汇总标识，不可占用」）、分支策略（单选：master / 最近 release 且防回退落后主干）、启停
  - 空态：AcEmpty「暂无启用项目」
- **布局引用**：`参见原型 ../assets/web/project-config.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl`）

### 报告触发配置

- **页面路径**：`/subapp/devhub/report/trigger-config`（报告配置页默认页签）

  - 弹窗：**编辑配置弹窗**（标题「编辑配置 · {报告类型 · 项目}」）：报告项只读（项目维度配置行附注「项目维度配置行随报告项目配置联动，报告类型与项目只读」）、触发方式勾选（定时 / 手动，至少一种）、定时规则（勾选定时时渲染：周期单选每日 / 每周 / 每月，每周默认周日、每月默认 1 日，时间输入 `HH:mm`（东八区）；附注「计划点短暂不可用时，恢复后在下一计划点之前补跑最近一次」）、类型参数（一致性校验：回看天数，打开时缺省默认 7；产品文档健康度：显示「该报告类型无类型参数，每周全量评估」；项目进度报告：统计周期周 / 月，默认周；研发周报与研发日报显示「该报告类型无类型参数」）、启停（附注「停用即不再定时触发，手动触发同步禁用；历史报告与生成记录保留」）
  - 抽屉：**生成记录抽屉**（标题「生成记录 · {报告项}」）：任务表格，列：触发来源（定时 / 手动（操作人），重试任务追加「 · 重试」）、状态（生成中 / 成功 / 失败）、统计窗口、开始时间、耗时（形如「41 秒」「6 分 12 秒」，未结束显示 —）、失败原因、产出版本（🚨 固定显示 —：任务仅回传产物版本标识，无法定位报告版本，查阅报告请前往对应模块列表）、操作（失败行可「重试」，重试即新建任务并关联原任务）；**存在生成中任务时每 3 秒静默轮询，全部到达终态后自动停止**；空态「暂无生成记录」
  - 空态：AcEmpty「暂无触发配置」
- **布局引用**：`参见原型 ../assets/web/report-trigger-config.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl`）

## 手动补传弹窗（报告模块共用）

> 手动补传弹窗为各报告列表页（人员产出 / 文档一致性 / 项目进度）与本页工具栏共用的同一组件，统一在此登记，各模块不再复述；类型相关差异（预置类型、是否含项目字段）在各模块 web-ui 描述。产品文档健康度报告不提供手动补传。

- **打开方式**：各报告列表页工具栏「手动补传」（类型按当前页固定）/ 索引缺失行或当日行「补传」（类型固定 + 预填项目与发报日）/ 报告触发配置工具栏「手动补传」（类型不固定，弹窗内下拉选择）
- **权限编码**：`devhubReportUpload`
- **表单字段**：报告类型（固定时展示 Tag + 说明「进入时按当前类型 Tab 预置；选择文件后按文件名识别结果为准」）、项目（仅项目维度类型渲染，必选，选项 = 启用项目 + 项目进度报告的「全部项目汇总（_all）」）、发报日（必选，不可晚于今天；文件名可识别时自动回填、可改）、报告文件（拖拽或点选，仅 .md（UTF-8），单文件 ≤2MB，重复选择替换）
- **文件名识别**：命中命名规范（`weekly_dev_yyyyMMdd.md` / `daily_dev_yyyyMMdd.md` / `consistency_yyyyMMdd_项目key.md` / `progress_yyyyMMdd_项目key.md`，汇总为 `progress_yyyyMMdd__all.md`）自动回填类型 / 发报日 / 项目并展示成功提示条「已按文件名识别：…」；未命中提示「文件名无法识别，请手动指定…（命名规范：consistency_yyyyMMdd_项目key.md）」；缺口行进入时提示「已从缺口带入：…」
- **操作反馈**：提交按钮 loading；成功 toast「补传成功，已生成 v{N}」→ 关弹窗并刷新来源列表；重复内容提示「内容重复，与现有版本一致，未产生新版本」；失败 toast error + 弹窗保留、字段值不丢
- **脏数据离开**：已选择文件或已填写发报日时关闭 → 确认「已选择文件或已填写发报日，放弃本次补传？」
