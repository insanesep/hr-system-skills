# Web 端 UI 描述 · 报告配置

> 硬约束（组件白名单 / Token / 三态）详见 page-gen.prompt.md【2. 硬约束】A-L，此处仅填产品侧元信息。
> 本模块为研发报告子域统一配置入口；各报告模块列表页仅保留本类型的「立即生成」快捷入口。

## 页面清单

### 报告项目配置

- **页面路径**：`/rnd-report/project-config`
- **权限编码**：
  - 路由：`devhubReportTriggerConfig`
  - 按钮：`devhubReportTrigger`（编辑扩展 / 启停）
- **页面类型**：列表页（配置表格 + 编辑弹窗）
- **区块职责**：
  - 工具栏（筛选 panel）：状态（全部 / 已配置 / 待配置 / 已停用）、关键词（项目 key / 名称模糊）、查询 / 重置
  - 主体区（配置表格 panel）：列：项目名称、项目 key（未配置显示「待配置」橙显）、harness 工程（只读，来自功能排期项目映射）、代码仓清单（只读，数量徽标，悬停展示完整清单）、分支策略（master / 最近 release 且防回退）、启停开关、关联触发配置（项目维度配置行状态 + 定时规则摘要）、操作（编辑）
  - 行生成：功能排期启用项目自动成行，不可手工新增或删除；扩展未配置的项目标「待配置」，不参与项目维度报告
  - 弹窗：**编辑扩展弹窗**：项目名称 / harness 工程 / 代码仓清单（只读展示）、项目 key（首次设置后不可改；小写字母 / 数字 / 连字符）、分支策略（单选：master / 最近 release 且防回退）、启停
  - 联动提示：扩展启用后「报告触发配置」页自动生成 / 更新项目维度配置行（默认定时每周）；停用扩展时同步停用关联配置行
  - 空态：AcEmpty「暂无启用项目」
- **布局引用**：`参见原型 ../assets/web/project-config.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl`）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 报告配置 → 报告项目配置」
- 去向页：「报告触发配置」页（关联触发配置列点击跳转）
- 返回行为：浏览器返回回到来源页
- 面包屑：首页 / 研发 / 研发报告 / 报告配置 / 报告项目配置

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 筛选条件变更后点查询 | 否 | 表格 loading | 列表刷新，停留 | toast error + 按钮恢复 |
| 编辑扩展提交 | 弹窗内必填项齐备 | 否 | 提交按钮 loading | toast「扩展已保存」→ 关弹窗并刷新表格 | toast error（key 重复 / 格式非法 / 分支策略未选）+ 弹窗保留 |
| 启停切换 | 点启停开关 | 是（停用提示「停用后不再生成该项目维度报告，历史报告保留」；启用需扩展已配置） | 开关 loading | 开关态切换，联动同步触发配置行 | toast error + 开关回退 |

#### 表单校验（编辑扩展弹窗）

- 初态：基础映射（项目名称 / harness 工程 / 代码仓清单）只读展示；已设置过项目 key 的编辑模式下项目 key 只读；分支策略与启停回显当前生效值

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 项目 key | 启用前必填 | 小写字母 / 数字 / 连字符 | blur | 「项目 key 仅支持小写字母、数字与连字符」 | 是（全局唯一性，重复提示「项目 key 已存在」） |
| 分支策略 | 启用前必填 | 二选一：master / 最近 release 且防回退 | change | 「请选择分支策略」 | 否 |

- 提交成功：toast「扩展已保存」→ 关弹窗并刷新表格（弹窗场景无路由跳转）
- 提交失败展示：表单顶部 AcAlert + 对应字段红显
- 脏数据离开：弹窗场景，关闭即放弃，无需守卫

### 报告触发配置

- **页面路径**：`/rnd-report/trigger-config`
- **权限编码**：
  - 路由：`devhubReportTriggerConfig`
  - 按钮：`devhubReportTrigger`（编辑配置 / 启停 / 立即生成 / 失败重试）
- **页面类型**：列表页（配置表格 + 编辑弹窗 + 生成记录抽屉）
- **区块职责**：
  - 工具栏（筛选 panel）：报告类型（单选：全部 / 研发周报 / 研发日报 / 文档一致性校验 / 项目进度报告）、项目（单选，选项 = 扩展已启用的项目，来自「报告项目配置」生效数据）、状态（全部 / 启用 / 停用）、查询 / 重置
  - 主体区（配置表格 panel）：列：报告类型（Tag）、项目（无项目维度显示 —）、触发方式（定时 / 手动 双 Tag）、定时规则（如「每周日 20:00」）、类型参数（如「回看 7 天」「周期：周」）、启停开关、最近生成（状态 + 时间，失败红显，点击开生成记录抽屉）、操作（编辑 / 立即生成 / 生成记录）
  - 弹窗：**编辑配置弹窗**：触发方式勾选（定时 / 手动，至少一种）、定时规则（周期：每日 / 每周 / 每月；周期为每周选星期、每月选号、每日仅选时间；东八区）、类型参数（一致性校验：回看天数；项目进度报告：统计周期周 / 月；研发周报与研发日报无类型参数）、启停；项目维度报告类型（一致性校验 / 项目进度报告）的配置行随「报告项目配置」联动生成，不可手工新增或删除，仅可编辑
  - 抽屉：**生成记录抽屉**：任务表格，列：触发来源（定时 / 手动）、状态（生成中 / 成功 / 失败）、统计窗口、开始时间、耗时、失败原因、产出版本（成功时链接到对应模块的报告详情）、操作（失败可「重试」）；重试即新建任务并关联原任务
  - 空态：AcEmpty「暂无触发配置」
- **布局引用**：`参见原型 ../assets/web/report-trigger-config.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl`）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 报告配置 → 报告触发配置」；各报告模块列表页「立即生成」成功反馈跳转
- 去向页：生成记录抽屉「产出版本」→ 对应模块报告详情页
- 返回行为：浏览器返回回到来源页
- 面包屑：首页 / 研发 / 研发报告 / 报告配置 / 报告触发配置

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 编辑配置提交 | 弹窗内必填项齐备 | 否 | 提交按钮 loading | toast「配置已保存」→ 关弹窗并刷新表格 | toast error（定时规则缺失 / 未选触发方式）+ 弹窗保留 |
| 启停切换 | 点启停开关 | 是（停用提示「停用后不再定时生成」） | 开关 loading | 开关态切换，表格刷新 | toast error + 开关回退 |
| 立即生成 | 行内点「立即生成」 | 是（确认报告项与统计窗口） | 按钮 loading | toast「已创建生成任务」→ 打开生成记录抽屉 | toast error（存在进行中任务 / 配置停用 / 无权限）+ 按钮恢复 |
| 失败重试 | 生成记录抽屉失败行点「重试」 | 否 | 按钮 loading | toast「已创建重试任务」，抽屉刷新 | toast error + 按钮恢复 |

#### 表单校验（编辑配置弹窗）

- 初态：回显当前生效的触发方式、定时规则、类型参数与启停；项目维度配置行的报告类型与项目只读

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 触发方式 | 是 | 定时 / 手动至少勾选一种 | change | 「请至少选择一种触发方式」 | 否 |
| 定时规则 | 勾选定时时必填 | 周期（每日 / 每周 / 每月）+ 星期或号（每日无需）+ 时间齐备 | change | 「请补全定时规则」 | 否 |
| 类型参数 | 否 | 一致性校验：回看天数为正整数；项目进度报告：周 / 月二选一 | blur | 「类型参数格式不正确」 | 否 |

- 提交成功：toast「配置已保存」→ 关弹窗并刷新表格（弹窗场景无路由跳转）
- 提交失败展示：表单顶部 AcAlert + 对应字段红显
- 脏数据离开：弹窗场景，关闭即放弃，无需守卫
