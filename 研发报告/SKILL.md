# 研发报告

产研过程的报告类资产子域：周期报告的触发、生成、归档与查阅，以及故障的复盘闭环管理。

## 下辖功能模块

| 功能 | 目录 | 说明 |
| ---- | ---- | ---- |
| 人员产出报告 | `人员产出报告/` | 人员维度产出（提交/完成/时效/延期），服务端 Qoder SDK 挂载内置 dev-report skill 生成，仅管理层可见 |
| 文档一致性报告 | `文档一致性报告/` | 分项目校验文档↔代码一致性，服务端生成 |
| 项目进度报告 | `项目进度报告/` | 分项目生成（项目↔harness 工程/代码仓映射可维护），汇总排期进度、延期分布与需求吞吐 |
| 故障报告 | `故障报告/` | 故障登记→复盘→闭环，关联运维证据，仅 Web 端 |

## 子域级共享资产

| 资产 | 路径 | 说明 |
| ---- | ---- | ---- |
| 业务规则字典 | `references/business-rule.md` | 报告类型与命名、周期归属与周索引、触发生成与入库、版本、渲染、权限、异常场景的唯一真源 |
| 数据模型 | `references/data-model.md` | 报告 / 版本 / 触发配置 / 生成任务实体定义 |
| 数据源与推送契约 | `references/data-source-api.md` | 排期双卡 MCP 调用口径、容错口径、推送上报旁路契约 |
| 报告触发配置页 | `references/web-ui-trigger-config.md` + `assets/web/report-trigger-config.html` | 子域统一配置页：全部报告项的触发方式（定时/手动）、定时规则、类型参数、启停、立即生成、生成记录与失败重试；不归属任何单一报告模块 |

## 关键约定

1. 各报告模块只承载本类型的生成规范、页面描述与原型；归档、触发、版本、渲染等共享机制一律以子域 `references/` 为真源，模块内不复制
2. 报告产物统一落库归档（服务端生成为主通道，推送上报为旁路、手动补传为兜底），按发报日自然周索引，版本递增可溯
3. 报告落库即页面可查，子域不做主动通知
