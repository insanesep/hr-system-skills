# 研发报告

产研过程与结果的报告子域：面向项目管理沉淀各类周期性报告。

## 下辖功能

| 功能 | 目录 | 说明 |
| ---- | ---- | ---- |
| 项目进度报告 | [`项目进度报告/`](项目进度报告/SKILL.md) | 周/月汇总排期执行进度、延期分布与需求吞吐，归档查阅 + 版本回溯 |
| 人员产出报告 | [`人员产出报告/`](人员产出报告/SKILL.md) | 人员维度产出（提交/完成/时效/延期），仅管理层可见 |
| 文档一致性报告 | [`文档一致性报告/`](文档一致性报告/SKILL.md) | AI 校验产出的文档↔代码一致性报告归档查阅 |
| 故障报告 | [`故障报告/`](故障报告/SKILL.md) | 故障登记→复盘→闭环，关联错误日志与黑灯工厂证据 |
