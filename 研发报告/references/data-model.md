# 研发报告 数据模型

> 产品视角的数据模型：定义实体、字段语义与业务关系，不含 DDL / 索引 / 分库分表等研发细节。
> 表为研发域自有新表，不依赖 `依赖文档/数据库/` 下任何外部系统 DDL 真源。

---

## 1. 实体关系

```text
报告触发配置（dev_report_trigger）1 ──── N 报告生成任务（dev_report_task）
研发报告（dev_report） 1 ──── N 报告版本（dev_report_version）
报告生成任务（成功时） N ──── 1 报告版本（产出版本）
```

- 报告项（报告类型 + 项目标识）对应一条「触发配置」，驱动定时 / 手动「生成任务」
- 一份「报告」由（报告类型 + 项目标识 + 发报日）唯一确定
- 同唯一键重复入库产生新「版本」，报告默认指向最新版本

---

## 2. 报告触发配置

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 配置 ID | 主键 | 标识 | 是 | 系统生成 |
| 报告类型 | 三类报告之一 | 枚举 | 是 | `WEEKLY_DEV` / `CONSISTENCY` / `PROJECT_PROGRESS`，见 [business-rule.md §1](business-rule.md#1-报告类型与文件命名) |
| 项目标识 | 项目维度 | 文本 | 项目维度类型必填 | 关联「项目映射配置」生效数据的项目 key；配置行随映射启用/停用联动生成与停用 |
| 定时触发开关 | 是否参与定时调度 | 开关 | 是 | 与手动触发开关至少启用一种 |
| 定时规则 | 调度周期 | 结构化文本 | 定时开关启用时必填 | 周期（每周 / 每月）+ 星期或号 + 时间（东八区） |
| 手动触发开关 | 是否允许「立即生成」 | 开关 | 是 | — |
| 类型参数 | 报告类型差异参数 | 结构化文本 | 否 | 一致性校验：回看天数；项目进度报告：统计周期（周 / 月） |
| 启停状态 | 配置整体启停 | 枚举 | 是 | 停用即不再定时触发且手动禁用；历史数据保留 |
| 最近生成任务 ID | 最近一次任务 | 标识 | 否 | 冗余展示字段 |
| 创建时间 / 更新时间 | 审计字段 | 时间 | 是 | 东八区 |

## 3. 报告生成任务

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 任务 ID | 主键 | 标识 | 是 | 系统生成 |
| 触发配置 ID | 归属配置 | 标识 | 是 | 外键关联报告触发配置 |
| 触发来源 | 任务来源 | 枚举 | 是 | `SCHEDULED`（定时到点）/ `MANUAL`（手动立即生成） |
| 统计区间起 / 止 | 本次统计窗口 | 日期 | 是 | 按报告类型口径计算后随任务入参下发 |
| 状态 | 任务状态 | 枚举 | 是 | `RUNNING`（生成中）/ `SUCCESS`（成功）/ `FAILED`（失败） |
| 失败原因 | 失败说明 | 文本 | 否 | 失败时必填 |
| 产出报告版本 ID | 生成产物 | 标识 | 否 | 成功时关联报告版本 |
| 重试来源任务 ID | 重试链 | 标识 | 否 | 重试产生新任务并关联原任务 |
| 操作人 | 触发者 | 文本 | 是 | 手动触发记操作人姓名；定时记「定时调度」 |
| 开始时间 / 结束时间 | 执行耗时 | 时间 | 是 | 东八区；结束时间为终态时间 |

**关系约束：**

- 同一报告项同时刻仅允许一个 `RUNNING` 任务（见 [business-rule.md §3.2](business-rule.md#32-服务端生成主通道)）
- 任务记录不允许删除（审计留痕）

## 4. 研发报告（主表）

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 报告 ID | 主键 | 标识 | 是 | 系统生成 |
| 报告类型 | 三类报告之一 | 枚举 | 是 | `WEEKLY_DEV` / `CONSISTENCY` / `PROJECT_PROGRESS`，见 [business-rule.md §1](business-rule.md#1-报告类型与文件命名) |
| 项目标识 | 项目维度 | 文本 | 项目维度类型必填 | 关联「项目映射配置」生效数据的项目 key |
| 报告标题 | md 首个一级标题 | 文本 | 是 | 缺失时以「类型名 + 发报日」兜底 |
| 发报日 | 报告生成日期 | 日期 | 是 | 服务端生成时由任务给定；推送与补传取自文件名 `yyyyMMdd`，不可晚于今天 |
| 所属周起 | 发报日所在自然周周一 | 日期 | 是 | 东八区，冗余存储用于周索引 |
| 所属周止 | 发报日所在自然周周日 | 日期 | 是 | 同上 |
| 统计区间起 | 报告统计窗口起点 | 日期 | 否 | 仅 `WEEKLY_DEV` 与 `PROJECT_PROGRESS`，从正文解析，失败为空 |
| 统计区间止 | 报告统计窗口终点 | 日期 | 否 | 同上 |
| 当前版本号 | 最新版本序号 | 数值 | 是 | 从 1 起递增 |
| 来源 | 最近版本的入库通道 | 枚举 | 是 | `GENERATED`（服务端生成）/ `PUSH`（推送上报）/ `MANUAL`（手动补传） |
| 创建时间 / 更新时间 | 审计字段 | 时间 | 是 | 东八区 |

## 5. 报告版本（从表）

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
|--------|---------|----------------|------|---------|
| 版本 ID | 主键 | 标识 | 是 | 系统生成 |
| 报告 ID | 归属主表 | 标识 | 是 | 外键关联研发报告 |
| 版本号 | 版本序号 | 数值 | 是 | 主表内从 1 递增 |
| 原始文件名 | 入库时的文件名 | 文本 | 是 | 原样保留 |
| 文件存储键 | 原始 .md 的对象存储位置 | 文本 | 是 | 只存键不存内容 |
| 渲染产物存储键 | md 渲染后 HTML 的对象存储位置 | 文本 | 是 | 入库时生成，见 [business-rule.md §4](business-rule.md#4-markdown-渲染规则) |
| 大纲目录 | 从渲染产物提取的章节目录 | 结构化文本 | 否 | h2/h3 锚点列表，正文为空时为空 |
| 文件哈希 | 内容指纹 | 文本 | 是 | 推送上报幂等判重依据 |
| 文件大小 | 原始文件字节数 | 数值 | 是 | ≤ 2MB |
| 来源 | 本版本入库通道 | 枚举 | 是 | `GENERATED` / `PUSH` / `MANUAL` |
| 操作人 | 入库触发者 | 文本 | 是 | 服务端生成记「生成服务」；推送上报记外部生成方标识；手动补传记上传人姓名 |
| 入库时间 | 版本创建时间 | 时间 | 是 | 东八区 |

**关系约束：**

- 版本从属于报告，删除报告版本不被允许（审计留痕）
- 报告的「来源 / 当前版本号」始终跟随最新版本，属冗余展示字段
- 生成任务成功时必须关联其产出版本；一个版本至多被一个生成任务引用
