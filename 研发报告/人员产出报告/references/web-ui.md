## 页面清单

### 报告列表

- **页面路径**：`/rnd-report/member-output/list`
- **权限编码**：
  - 路由：`devhubMemberOutputReport`（仅授管理层与研发负责人）
  - 按钮：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面类型**：列表页（顶部类型 Tab：研发周报（默认）/ 研发日报；各类型 Tab 内双视角：按周（日）索引 / 报告明细）
- **区块职责**：
  - 工具栏（筛选 panel）：发报日期范围（RangePicker）、关键词（标题模糊）、查询 / 重置；作用于当前类型 Tab
  - 类型 Tab（主体区顶部）：研发周报（默认）/ 研发日报；切换时视角 Tab 重置为索引视角、筛选与页码重置
  - KPI 区（筛选后 / 表格前，口径随类型 Tab 切换）：周报 = 本周已入库（x/1）；日报 = 今日已入库（x/1）；共用 = 累计报告（当前类型）、最近发报日、历史版本总数
  - 主体区（表格 panel，视角 Tab 形态）：
    - 研发周报 Tab：
      - **视角1 按周索引**（默认）：周分组手风琴，按所属周倒序（本周行仅周日当天起展示，周中最晚只到上周）；每周一行组头（周标签 `2026 年第 36 周（08-31 ~ 09-06）` + 齐全度徽标 `1/1` 或 `0/1 待补`）；组内一行研发周报：报告标题、发报日、来源（服务端生成 / 推送上报 / 手动补传）、版本号、文件大小、入库时间、操作（查看 / 获取原件）；未入库行灰显「未入库」+ 操作「立即生成」（仅持有触发权限可见）/「补传」（仅持有上传权限可见）
      - **视角2 报告明细**：平铺表格，列：发报日期、所属周、报告标题、来源、版本、文件大小、入库时间、操作（查看 / 获取原件）；空态 AcEmpty「该条件下暂无报告」
    - 研发日报 Tab：
      - **视角1 按日索引**（默认）：按发报日倒序逐日行，**当日行固定置顶展示（未入库也成行）**；每行：日期标签（`2026-10-20 周二`）+ 齐全度徽标（已入库 `1/1` / 缺失 `0/1 待补` / 当日未入库 `0/1`）+ 已入库报告（报告标题、来源、版本号、文件大小、入库时间、操作：查看 / 获取原件）；未入库日灰显「未入库」+ 操作「立即生成」/「补传」（权限同周报）；**当日行无论是否已入库，操作列均保留「立即生成」/「补传」**（权限同周报；触发配置停用时按停用规则不可用），已入库时重复生成或补传按版本递增产生新版本；当日未入库不标「待补」（当日实时窗口，数据持续产生中），昨日及更早缺失日标 `0/1 待补`
      - **视角2 报告明细**：平铺表格，列：发报日期、报告标题、来源、版本、文件大小、入库时间、操作（查看 / 获取原件）；空态 AcEmpty「该条件下暂无报告」
  - 弹窗：**手动补传弹窗**：文件选择（仅 .md，≤2MB，拖拽或点选）、发报日（DatePicker，不可晚于今天）、识别结果提示条；类型进入时按当前类型 Tab 预置展示，选择文件后按文件名（`weekly_dev_` / `daily_dev_` 前缀 + yyyyMMdd）自动识别，识别成功以文件名识别结果为准（提示条「已按文件名识别：研发日报 · 发报日 2026-10-20」），识别失败保持预置类型并提示「文件名无法识别，请手动指定发报日」
- **布局引用**：`参见原型 assets/web/report-list.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl` 可选 Tab 形态）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 人员产出报告」
- 去向页：行内「查看」→ `/rnd-report/member-output/detail/:id`；缺失行「补传」→ 手动补传弹窗（发报日预填）；缺失行「立即生成」→ 直接创建生成任务
- 返回行为：浏览器返回回到列表并保持类型 Tab、视角 Tab 与筛选条件
- 面包屑：首页 / 研发 / 研发报告 / 人员产出报告

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 筛选条件变更后点查询 | 否 | 表格 loading | 列表刷新，停留 | toast error + 按钮恢复 |
| 切换类型 Tab | 点击类型 Tab | 否 | 表格 loading | 切换报告类型，视角重置为索引视角，筛选与页码重置 | — |
| 切换视角 Tab | 点击视角 Tab | 否 | 表格 loading | 切换视角，页码重置为 1 | — |
| 手动补传提交 | 弹窗内文件与必填项齐备 | 否 | 提交按钮 loading | toast「补传成功，已生成 v{N}」→ 关弹窗并刷新列表 | toast error（格式 / 大小 / 未来日期）+ 弹窗保留 |
| 立即生成 | 未入库行或当日行点「立即生成」 | 是（确认统计窗口：周报为周窗口，日报为当日 00:00 至当前） | 按钮 loading | toast「已创建生成任务」→ 跳转报告触发配置页生成记录 | toast error（存在进行中任务 / 无权限）+ 按钮恢复 |
| 获取原件 | 行内点「获取原件」 | 否 | 按钮 loading | 浏览器下载原始 .md | toast error + 按钮恢复 |

#### 表单校验（手动补传弹窗）

- 初态：类型按当前类型 Tab 预置；从索引行（缺失行或当日行）进入时发报日预填（周报预填该周周日，日报预填该日）；从工具栏进入时发报日为空；文件为空；无编辑模式

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 报告文件 | 是 | 仅 .md 且 ≤2MB；选择后按文件名识别类型与发报日并回填 | change | 「仅支持 .md 文件，且不超过 2MB」 | 否 |
| 发报日 | 是 | 不可晚于今天；文件名可识别时自动回填、可改 | change | 「发报日不可晚于今天」 | 否 |

- 提交成功去向：toast「补传成功，已生成 v{N}」→ 关弹窗并刷新列表（见操作反馈清单）
- 提交失败展示：toast error（格式 / 大小 / 未来日期）+ 弹窗保留、字段值保留可改
- 脏数据离开：已选文件或已填发报日时关闭弹窗 → AcModal「放弃本次补传？」

### 报告详情

- **页面路径**：`/rnd-report/member-output/detail/:id`
- **权限编码**：
  - 路由：`devhubMemberOutputReport`
- **页面类型**：详情页（阅读型）
- **区块职责**：
  - 元信息头（首个 panel）：报告标题（h1 级）、报告类型 Tag（研发周报 / 研发日报）、发报日、所属周、统计区间（缺失显示 —；日报为当日 00:00 至生成时）、来源（服务端生成 / 推送上报 / 手动补传）、当前版本（`v2 · 共 3 版`，多版时可下拉切换历史版本）、文件大小、入库时间、操作（获取原件 / 返回列表）
  - 阅读区（左主体 panel）：Markdown 渲染正文（标题层级、表格横滚、代码块等宽字体）。Web 端为前端实时渲染：按 mdUrl 拉取原始 md，marked(GFM) 渲染 + DOMPurify 白名单过滤 + GitHub 风格样式内联展示（图片替换占位「[图片已移除]」，与服务端口径一致）；服务端渲染的 HTML 产物仅 App 端 WebView 消费，见子域 business-rule.md §6
  - 侧边栏（右侧大纲 panel，≥1200px 展示，窄屏折叠为顶部「大纲」按钮弹抽屉）：h2/h3 锚点目录，当前阅读章节高亮，点击平滑滚动定位
  - 版本切换：元信息头版本下拉选择历史版本 → 正文整体切换为该版本渲染产物（只读，URL 带 `?v=N` 可分享）
- **布局引用**：`参见原型 assets/web/report-detail.html`（DOM 结构依据：`page-blueprint/skeletons/web/detail-page.vue.tpl`）

#### 导航关系

- 来源页：报告列表行内「查看」（周报 / 日报均进入本页）
- 去向页：无下游页面
- 返回行为：面包屑「人员产出报告」/ 浏览器返回 → 报告列表（保持原类型 Tab、视角 Tab 与筛选）
- 面包屑：首页 / 研发 / 研发报告 / 人员产出报告 / 报告详情
