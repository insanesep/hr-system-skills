# Web 端 UI 描述 · 人员产出报告（研发周报 / 研发日报）

> 视觉样式消费 [PC 设计 Token](../../../../busyming-skills-design/assets/runtime/prototype/pc-tokens.css)；品牌蓝用于主操作、链接、选中态与导航，成功、警告、错误使用各自语义色，不以主色代替状态色。
> 人员范围、指标与计数纪律以 [`business-rule.md`](business-rule.md) 为真源；归档、触发、版本、渲染与权限以子域共享规则为真源。

## 报告列表

- **页面路径**：`/subapp/devhub/report/member-output`
- **路由权限**：`devhubMemberOutputReport`，仅授权管理层与研发负责人
- **按钮权限**：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面职责**：在同一入口切换研发周报与日报，查阅索引和明细，处理缺失周期并获取原件

### 页面结构与交互

- 页头说明报告用途与敏感数据可见范围，并提供「手动补传」主操作
- 概览区随报告类型切换：周报展示本周已入库，日报展示今日已入库；同时展示累计报告、最近发报日和历史版本数
- 「研发周报 / 研发日报」类型 Tab 默认周报；切换后回到索引视角并重置筛选。周报提示双端可查，日报提示仅 Web 可查且统计前一自然日
- 筛选区包含发报开始日、发报结束日和标题关键词；默认近 90 天，支持查询、回车查询、重置和日期先后校验
- 索引视角默认展开分组，展示周期、统计窗口、齐全状态、报告标题、发报日、来源、版本与操作；可切换为平铺报告明细
- 周报按所属周倒序，本周仅在周日发报后展示；日报按发报日倒序，当日行固定置顶
- 缺失周期以待补色标识，提供「立即生成」与「补传」；生成前确认周期和统计窗口，成功后停留本页并提示生成记录入口
- 日报当日行无论是否入库均保留立即生成和补传；当日未入库不标待补，昨日及更早缺失标待补
- 已入库报告可查看或获取当前版本 Markdown；无原始内容时明确提示
- 周报索引展示近 8 周，日报索引展示近 14 天，明细最多 200 条，不分页；无结果时可清除筛选
- 从详情返回时保持报告类型、视角和筛选条件

### 手动补传

- 共用规则见 [`报告配置 · 手动补传弹窗`](../../报告配置/references/web-ui.md#手动补传弹窗报告模块共用)
- 类型按当前 Tab 预置，选择文件后以文件名识别结果为准；发报日不可晚于今天，从周期行进入时自动预填
- 支持点击与拖入 UTF-8 Markdown 文件，单文件不超过 2MB；识别失败时保留手动指定发报日能力
- 错误就近提示，重复内容不生成新版本；已选择文件或填写日期后关闭需二次确认
- 成功后关闭弹窗并同步索引、明细和概览

## 报告详情

- **页面路径**：`/subapp/devhub/report/member-output/detail/:id`
- **路由名称**：`devhubMemberOutputReportDetail`
- **所属菜单权限**：`devhubMemberOutputReport`
- **页面职责**：阅读周报或日报静态归档正文，定位章节，回溯版本并获取原件

### 页面结构与交互

- 页头提供返回列表、报告标题、类型、可见范围和「获取原件」；窄屏提供大纲按钮
- 元信息区展示发报日、所属周、统计区间、来源、版本、文件大小和入库时间；日报起止同日并明确到 00:00 ~ 24:00
- 版本通过下拉切换，URL 携带版本号可分享；历史版本展示只读提示和最新版本号，切换时正文显示加载状态并同步更新元信息
- 正文采用服务端渲染 HTML 产物，前端只提供排版样式；关键统计与正文口径一致，不展示贡献度分值或名次
- 每人保留代码产出总计、功能排期卡片与 Qoder 三项；多项目人员的代码产出内以项目小标题展示次数、增删行数、主要工作和涉及仓库，单项目人员保持简洁。未归属提交及项目归属未取得按业务规则明确呈现，项目小节不重复卡片或分摊 Qoder 用量；历史版本仅展示原归档内容，不按当前项目配置回填
- 宽屏右侧常驻大纲并随阅读位置高亮，窄屏改为抽屉；顶部阅读进度用于指示当前位置
- 宽表横向滚动，正文为空时展示「报告内容为空」；获取原件失败时明确提示当前版本无原始内容
