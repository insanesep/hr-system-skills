## 页面清单

### 报告列表

- **页面路径**：`/subapp/devhub/report/member-output`
- **权限编码**：
  - 路由：`devhubMemberOutputReport`（仅授管理层与研发负责人）
  - 按钮：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面类型**：列表页（顶部类型 Tab：研发周报（默认）/ 研发日报；各类型 Tab 内双视角：按周（日）索引 / 报告明细）
- **区块职责**：
  - 工具栏（筛选 panel）：发报日期范围（RangePicker，默认近 90 天）、关键词（报告标题模糊，回车即查）、查询 / 重置；作用于当前类型 Tab
  - 类型 Tab（主体区顶部）：研发周报（默认）/ 研发日报；切换时视角 Tab 重置为索引视角、筛选与页码重置
  - KPI 区（筛选后 / 表格前，口径随类型 Tab 切换）：周报 = 本周已入库（x/1；周中窗口提示「周中窗口，本周报告将于周日发报后展示」）；日报 = 今日已入库（x/y，y = 启用的日报触发配置数；脚注「统计前一自然日，当日数据持续产生中」）；共用 = 累计报告（当前类型，按报告项 × 发报日计，不含历史版本）、最近发报日、历史版本总数（Σ（当前版本-1)，附注「重复入库版本递增，旧版本保留可查，详情页可回溯」）
  - 主体区（表格 panel，视角 Tab 形态；**全部表格不分页**：按周索引取近 8 周、按日索引取近 14 天、报告明细上限 200 条，发报日期区间为前端过滤）：
    - 研发周报 Tab：
      - **视角1 按周索引**（默认）：周分组手风琴，按所属周倒序（本周行仅周日当天起展示，周中最晚只到上周），默认全展开；每周一行组头（周标签 `2026 年第 36 周（08-31 ~ 09-06）` + 齐全度徽标：到齐绿 `1/1`，未齐橙 `0/1 待补`）；组内一行研发周报：报告标题（链接，缺失行为灰文案）、发报日、来源（服务端生成 / 推送上报 / 手动补传）、版本号（vN）、操作（查看 / 获取原件）；未入库行灰显「未入库」+ 操作「立即生成」（仅持有触发权限可见）/「补传」（仅持有上传权限可见）
      - **视角2 报告明细**：平铺表格，列：发报日期、所属周（「第 N 周」）、报告标题、来源、版本、操作（查看 / 获取原件）；空态 AcEmpty「该条件下暂无报告」
    - 研发日报 Tab：
      - **视角1 按日索引**（默认）：按发报日倒序逐日行，**当日行固定置顶展示（未入库也成行）**；每行：日期标签（`2026-10-20 周二`）+ 齐全度徽标（已入库 `1/1` / 缺失 `0/1 待补` / 当日未入库 `0/1`）+ 已入库报告（报告标题、来源、版本号、操作：查看 / 获取原件）；未入库日灰显「未入库」+ 操作「立即生成」/「补传」（权限同周报）；**当日行无论是否已入库，操作列均保留「立即生成」/「补传」**（触发配置停用时按停用规则不可用），已入库时重复生成或补传按版本递增产生新版本；当日未入库不标「待补」（当日行统计窗口为当日 00:00 ~ 24:00，数据持续产生中），昨日及更早缺失日标 `0/1 待补`
      - **视角2 报告明细**：平铺表格，列：发报日期、报告标题、来源、版本、操作（查看 / 获取原件）；空态 AcEmpty「该条件下暂无报告」
  - 弹窗：**手动补传弹窗**（共用组件，通用字段与交互见 [报告配置 · 手动补传弹窗](../../报告配置/references/web-ui.md#手动补传弹窗报告模块共用)）：本模块类型按当前类型 Tab 预置固定（周报 / 日报）、发报日（不可晚于今天）；选择文件后按文件名（`weekly_dev_` / `daily_dev_` 前缀 + yyyyMMdd）自动识别，识别成功以文件名识别结果为准（提示条「已按文件名识别：研发日报 · 发报日 2026-10-20」），识别失败保持预置类型并提示「文件名无法识别，请手动指定发报日」；从索引行（缺失行或当日行）进入时发报日预填（周报预填该周周日，日报预填该日），并提示「已从缺口带入：发报日 X」
- **布局引用**：`参见原型 assets/web/report-list.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl` 可选 Tab 形态）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 人员产出报告」
- 去向页：行内「查看」→ `/subapp/devhub/report/member-output/detail/:id`；缺失行「补传」→ 手动补传弹窗（发报日预填）；缺失行「立即生成」→ 直接创建生成任务
- 返回行为：浏览器返回回到列表并保持类型 Tab、视角 Tab 与筛选条件
- 面包屑：首页 / 研发 / 研发报告 / 人员产出报告

### 报告详情

- **页面路径**：`/subapp/devhub/report/member-output/detail/:id`
- **路由名称**：`devhubMemberOutputReportDetail`，为人员产出报告的非菜单详情页
- **权限编码**：
  - 所属菜单资源：`devhubMemberOutputReport`，不等同于详情路由名称
- **页面类型**：详情页（阅读型）
- **区块职责**：
  - 顶部：返回链接「‹ 返回人员产出报告」；报告标题 + 报告类型 Tag（研发周报 / 研发日报）+ info Tag「仅管理层与研发负责人可见」
  - 历史版本警示（查看历史版本时，黄色警示条）：「当前查看历史版本 v{N}（只读），最新版本为 v{M}；切换版本不改变归档内容。」
  - 元信息头（首个 panel）：发报日、所属周、统计区间（缺失显示 —；日报起止同日展示为「YYYY-MM-DD 00:00 ~ 24:00」）、来源（服务端生成 / 推送上报 / 手动补传）、当前版本（`v2 · 共 3 版`，多版时可下拉切换历史版本；附注「重复入库版本递增，历史版本只读可查，URL 带 ?v=N 可分享」）、文件大小、入库时间；右上操作（获取原件 / 返回列表）
  - 阅读区（左主体 panel）：🚨 Web 端展示**服务端渲染的 HTML 产物**（页内直出，前端仅提供排版样式，不做 Markdown 实时渲染）；切换版本时加载文案「正在加载所选版本内容…」；内容为空时展示「报告内容为空」
  - 侧边栏（右侧大纲 panel，≥1200px 展示，窄屏折叠为顶部「大纲」按钮弹抽屉）：h2/h3 锚点目录（数据来自服务端产物大纲），当前阅读章节高亮，点击平滑滚动定位
  - 版本切换：元信息头版本下拉选择历史版本 → 正文整体切换为该版本渲染产物（只读，URL 带 `?v=N` 可分享）
- **布局引用**：`参见原型 assets/web/report-detail.html`（DOM 结构依据：`page-blueprint/skeletons/web/detail-page.vue.tpl`）

#### 导航关系

- 来源页：报告列表行内「查看」（周报 / 日报均进入本页）
- 去向页：无下游页面
- 返回行为：返回链接「‹ 返回人员产出报告」/ 浏览器返回 → 报告列表（保持原类型 Tab、视角 Tab 与筛选）
- 面包屑：首页 / 研发 / 研发报告 / 人员产出报告 / 报告详情
