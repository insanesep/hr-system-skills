# App 端 UI 描述 · 人员产出报告（研发周报）

> 视觉样式消费 [移动端设计 Token](../../../../busyming-skills-design/assets/runtime/prototype/mobile-tokens.css)；品牌橙用于主操作、链接、选中态与导航，成功、警告、错误使用各自语义色，不以主色代替状态色。
> 人员范围、指标与计数纪律以 [`business-rule.md`](business-rule.md) 为真源；归档、版本、渲染与权限以子域共享规则为真源。App 仅提供研发周报，不提供研发日报、生成或补传。

## 报告列表

- **页面路径**：`/rnd-report/member-output/home`
- **菜单权限**：`devhubAppMemberOutputReport`，仅授权管理层与研发负责人
- **导航方式**：从 App 工作台 Push 进入；返回工作台
- **页面职责**：按周查找并阅读研发周报，了解报告是否归档

### 页面结构与交互

- 顶部导航栏展示「研发周报」、返回与刷新；下拉刷新和刷新按钮均更新列表，加载时使用骨架屏
- 顶部摘要说明最近周报的归档情况、本周发报时机和可见范围
- 搜索框常驻，按已入库报告标题模糊匹配；未入库周期不参与关键词匹配，支持一键清除与无结果恢复
- 周报按所属周倒序分组；周标题展示日期范围、入库状态和齐全度
- 已入库卡片展示报告标题、发报日、来源和当前版本，整卡可点进入详情
- 未入库周展示待补状态，不提供点击；说明需在 Web 管理端生成或补传
- 「加载更早周次」追加历史分组，全部加载后展示结束提示
- 从详情返回时保持搜索词、已加载周次和滚动位置

## 报告详情

- **页面路径**：`/rnd-report/member-output/detail`
- **菜单权限**：`devhubAppMemberOutputReport`
- **导航方式**：从周报列表 Push 进入；返回列表

### 页面结构与交互

- 顶部导航栏提供返回和大纲入口，顶部轻量进度条表示阅读位置
- 元信息卡默认展示标题、发报日、类型与当前版本；所属周、统计区间、来源、文件大小和入库时间可展开查看
- 版本入口始终可见，点击后从底部弹出版本列表；历史版本只读，切换时展示正文骨架屏并同步更新元信息
- 正文使用服务端渲染且经 XSS 白名单过滤的产物；关键统计、人员分析、表格和口径说明采用适合长文阅读的层级，宽表支持横向滑动
- 不展示贡献度分值或名次，不将缺失数据补零；统计口径与报告正文一致
- 大纲从底部弹出，包含章节与人员条目；点击后关闭并定位到对应内容
- 历史版本提示说明最新版本号；正文为空时展示「报告内容为空」
- 弹层打开时返回手势优先关闭弹层，其余情况返回列表
