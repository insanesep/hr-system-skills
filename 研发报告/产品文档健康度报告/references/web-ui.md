# Web 端 UI 描述 · 产品文档健康度报告

> 归档、版本、渲染与异常口径以 [`../../报告配置/references/business-rule.md`](../../报告配置/references/business-rule.md) 为真源；报告内容章节以 [`health-report.md`](health-report.md) 输出模板为真源。
> 范围类型、名称与 key 只读消费 [项目管理](../../../研发管理/项目管理/references/business-rule.md#consumption)。域整仓、项目一级目录及各自确认映射参与评估，根文件不计项目，固定排除 common/design；跨范围指标按稳定标识去重，不重复相加。

## 使用原则

- 首屏先回答“本周是否齐全、哪里需要关注”，再提供完整指标与历史明细。
- 客观评分、硬门禁与 AI 诊断始终分区表达；AI 固定标识「不计分」。
- 问题与对应的证据、影响、修复位置、修复动作和复核点放在一起阅读，避免在多个章节间来回查找。
- 报告与业务仓全程只读；不提供手动补传、自动修复或自动提交入口。

## 页面清单

### 报告列表

- **页面路径**：`/subapp/devhub/report/doc-health`
- **权限编码**：路由 `devhubDocHealthReport`；按钮 `devhubReportTrigger`（立即生成）
- **页面类型**：列表页（按周索引 / 全部报告）
- **布局引用**：[`assets/web/report-list.html`](../assets/web/report-list.html)
- **区块职责**：
  - 页头：模块名称、最近发报日与「每周全量只读评估」说明。
  - 本周概览：本周已入库、最近一期仓库平均综合分、模块 FAIL 数、全量自校未通过数；关注事项以简短文字直接说明。
  - 筛选工具栏：范围（全部及启用的域/项目）、发报日期、标题或范围关键词；支持查询、重置与 Enter 查询。
  - 快捷筛选：全部、需关注、未入库；「需关注」包括未入库、存在模块 FAIL 或全量自校未通过的报告。
  - 按周索引：周分组倒序，默认展开最近周；组内显示齐全度，报告行展示范围、综合分、较上期差值、模块 FAIL、自校、来源、版本与操作。
  - 全部报告：平铺表格，增加发报日与所属周；保留同一套筛选条件和行操作。
  - 缺失报告：在行内说明未入库；有权限时可「立即生成」，确认后显示任务已创建状态，不提供手动补传。
- **导航关系**：侧边菜单「研发报告 → 产品文档健康度报告」进入；「查看」进入 `/subapp/devhub/report/doc-health/detail/:id`；返回后保留视角、筛选与周分组展开状态。
- **操作反馈**：查询与视角切换使用局部加载；无结果时说明当前条件并提供重置；获取原件显示下载反馈；立即生成失败时保留当前页并说明原因。

### 报告详情

- **页面路径**：`/subapp/devhub/report/doc-health/detail/:id`
- **权限编码**：路由 `devhubDocHealthReport`
- **页面类型**：详情页（任务分区 + 完整报告阅读）
- **布局引用**：[`assets/web/report-detail.html`](../assets/web/report-detail.html)
- **区块职责**：
  - 页头：返回列表、范围与发报日、版本切换、获取原件；历史版本显示只读提示。
  - 评分摘要：仓库平均综合分及环比、模块 FAIL、文件覆盖率、全量自校；摘要只使用当前归档版本数据。
  - 报告信息：默认折叠，展开后查看范围类型/key、所属周、规则版本、上期基线、可比性、各仓 commit、来源、文件名与入库时间。
  - 问题与修复：默认视图；按客观问题 / AI 诊断、A/B/C 优先级和新增 / 持续状态组合筛选。每项以手风琴展示问题证据、影响、真源修复位置、修复动作与复核点；AI 项固定「不计分」。
  - 模块评分：按仓库、变化状态和模块目录筛选；展示本次、上次、差值、硬门禁与问题变化，六维得分按需展开。
  - 仓库与覆盖：展示仓库 M/G/R、环比、治理状态、文件覆盖自校、各仓 commit，以及新增、移除、未评估与检查失败模块。
  - 完整报告：展示服务端安全渲染的 HTML 产物与 h2/h3 大纲；大纲支持定位，正文不在 Web 前端重新渲染 Markdown。
- **导航关系**：从列表进入；分区切换只改变当前阅读视图，不修改归档；返回列表保持列表筛选与滚动位置。
- **操作反馈**：版本切换显示正文加载状态，失败回退当前版本；筛选无结果时提供恢复全部条件；大纲定位平滑滚动。

## 状态与可用性

- 所有筛选均可组合，重置恢复「全部范围、近 90 天、全部报告、按周索引」。
- 表格在窄屏下保留横向滚动，操作列不覆盖正文；主要按钮、页签、手风琴与弹窗支持键盘操作和清晰焦点。
- 加载使用局部骨架或遮罩，空态说明原因并给出下一步；失败保留已阅读内容，不用空白页替换。
- 分数使用等宽数字；颜色同时配合文字或图标表达，不以颜色作为唯一状态依据。
