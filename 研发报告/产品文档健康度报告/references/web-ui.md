# Web 端 UI 描述 · 产品文档健康度报告

> 归档、版本、渲染与异常口径以子域 [`../../报告配置/references/business-rule.md`](../../报告配置/references/business-rule.md) 为真源；报告内容章节以 [`health-report.md`](health-report.md) 输出模板为真源。

## 页面清单

### 报告列表

- **页面路径**：`/subapp/devhub/report/doc-health`
- **权限编码**：路由 `devhubDocHealthReport`；按钮 `devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面类型**：列表页（按周索引 / 报告明细双视角）
- **区块职责**：
  - 工具栏：项目（全部 + 启用项目）、发报日期范围（默认近 90 天）、关键词（报告标题）、查询/重置；右侧按权限展示「手动补传」
  - KPI 区：本周已入库（x/y）、最近发报日、最近一期仓库平均综合分、模块 FAIL 总数、全量自校未通过报告数
  - 按周索引：周分组按倒序，组内每项目一行，展示报告标题、项目、发报日、仓库平均综合分、模块 FAIL 数、来源、版本与操作（查看/获取原件）；未入库行按权限提供「立即生成/补传」
  - 报告明细：平铺表格，列为发报日、所属周、项目、报告标题、仓库平均综合分、模块 FAIL 数、全量自校结果、来源、版本、操作
  - 手动补传：共用组件，类型固定为产品文档健康度，项目必选，发报日不可晚于今天；文件名规范 `doc_health_yyyyMMdd_项目key.md`
- **导航关系**：侧边菜单「研发报告 → 产品文档健康度报告」进入；「查看」进入 `/subapp/devhub/report/doc-health/detail/:id`；返回保留视角与筛选
- **操作反馈**：查询、补传、立即生成与获取原件复用共享报告反馈；立即生成需校验联动配置、手动开关与进行中任务，失败保留当前页并提示原因

### 报告详情

- **页面路径**：`/subapp/devhub/report/doc-health/detail/:id`
- **权限编码**：路由 `devhubDocHealthReport`
- **页面类型**：详情页（评分与阅读结合）
- **区块职责**：
  - 顶部：返回链接、报告标题、项目与类型 Tag；历史版本时展示只读警示
  - 元信息：项目、发报日、所属周、规则版本、各仓 commit、上期发报日/版本、可比性、来源、当前版本、文件名、入库时间；操作含获取原件与版本切换
  - 覆盖摘要：文件覆盖率、未判定数、检查失败数、自校结果；自校未通过时以警示样式置顶
  - 仓库评分：仓库综合分 R、模块子分 M、治理子分 G、模块 FAIL、治理状态及环比；支持按下降、新增阻断、检查失败筛选
  - 模块评分：本次/上次/差值/变化状态/硬门禁/问题变化；支持按模块、仓库、提升/下降/新增 FAIL 筛选；维度得分可展开
  - 治理问题与结构外文件：文件路径、客观依据、辅助内容角色、严重程度、计分位置、变化状态；AI 角色标注与客观扣分依据分开展示
  - AI 辅助诊断：独立章节并固定「不计分」标识，按闭环/一致性、问题类型、严重程度筛选；每条展示真源与相关证据
  - 修复建议：按 A/B/C 优先级展示问题证据、影响、修复对象、修复动作与复核点；只读，不提供自动修复按钮
  - 正文阅读：按共享规则由 Web 前端获取原始 md 并安全渲染，提供 h2/h3 大纲定位；版本切换只读，不改变归档
- **导航关系**：列表进入；无自动跳转业务仓或自动治理页面；返回列表保持筛选
- **操作反馈**：版本切换与获取原件复用共享反馈；大纲定位平滑滚动；筛选失败保留当前内容并提示

## 表单校验

- 手动补传通用校验见 [`../../报告配置/references/web-ui.md`](../../报告配置/references/web-ui.md)；本模块文件名按 `doc_health_yyyyMMdd_项目key.md` 识别
- 报告筛选不需要表单提交；项目、日期、变化状态与门禁筛选条件可组合，重置后恢复默认条件
