# App 端 UI 描述 · 产品文档健康度报告

> App 为只读查阅端，不提供配置、补传或自动修复。归档、版本与渲染规则以 [`../../报告配置/references/business-rule.md`](../../报告配置/references/business-rule.md) 为准。

## 页面清单

### 报告列表

- **页面路径**：`/rnd-report/doc-health/home`
- **权限编码**：菜单 `devhubAppDocHealthReport`
- **导航方式**：Push（工作台入口进入）
- **页面类型**：列表页（周分组卡片流）
- **区块职责**：
  - 顶部导航栏：标题「产品文档健康度报告」，右侧搜索图标按报告标题匹配
  - 项目筛选：全部 + 启用项目 chip 单选，切换即刷新
  - 周分组卡片：按所属周倒序，展示周标签与齐全度；每项目卡片展示报告标题、发报日、仓库平均综合分、模块 FAIL 数、全量自校结果、来源与版本；未入库为不可点灰卡
  - 空态与加载：空筛选展示「该条件下暂无报告」；支持下拉刷新与更早周追加分页
- **导航关系**：点报告卡片 Push `/rnd-report/doc-health/detail`；返回工作台或上级列表，保留项目筛选与滚动位置
- **操作反馈**：搜索、项目筛选、下拉刷新与追加分页使用骨架屏或对应加载态，失败 Toast 并保留重试入口

### 报告详情

- **页面路径**：`/rnd-report/doc-health/detail`
- **权限编码**：菜单 `devhubAppDocHealthReport`
- **导航方式**：Push
- **页面类型**：详情页（阅读型）
- **区块职责**：
  - 顶部导航栏：标题 + 大纲图标，点击从底部弹出章节目录
  - 元信息折叠卡：项目、发报日、规则版本、可比性、来源、版本；多版本通过 ActionSheet 切换历史版本，只读
  - 评分摘要：仓库平均综合分、模块 FAIL、覆盖率与自校结果；点击大纲可定位到对应仓库或模块明细
  - 正文：使用服务端安全渲染产物，按报告模板展示仓库/模块评分、治理问题、AI 诊断与修复建议；表格支持横向滚动
  - AI 辅助诊断章节固定展示「不计分」；修复建议只读，不提供自动处理操作
  - 空态：正文为空时展示「报告内容为空」
- **导航关系**：无下游编辑页面；返回列表保持筛选与滚动位置，大纲抽屉展开时返回优先关闭抽屉
- **操作反馈**：版本切换显示正文骨架屏，失败回退当前版本；大纲点击收起抽屉并定位
