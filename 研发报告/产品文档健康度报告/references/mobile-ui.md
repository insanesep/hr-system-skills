# App 端 UI 描述 · 产品文档健康度报告

> App 为只读查阅端，不提供配置、手动补传或自动修复。归档、版本与渲染规则以 [`../../报告配置/references/business-rule.md`](../../报告配置/references/business-rule.md) 为准。
> 范围类型、名称与 key 只读引用 [域及项目管理](../../../研发管理/域及项目管理/SKILL.md)。有效且已配置启用范围才形成报告项；停用或远端确认缺失停止生成但不删除归档。健康度固定排除 common/design，不叠加域和子项目重复评分。

## 使用原则

- 优先展示范围、分数、环比和待关注问题，不在卡片重复完整报告标题。
- 使用纵向信息行替代多列表格；仅完整报告中的原始数据表允许横向滚动。
- 概览、问题与完整正文分视图阅读，减少长页跳转；AI 诊断始终标识「不计分」。

## 页面清单

### 报告列表

- **页面路径**：`/rnd-report/doc-health/home`
- **权限编码**：菜单 `devhubAppDocHealthReport`
- **导航方式**：Push（工作台入口进入）
- **页面类型**：列表页（周分组卡片流）
- **布局引用**：[`assets/app/report-list.html`](../assets/app/report-list.html)
- **区块职责**：
  - 顶部导航：标题「文档健康度」，左侧返回工作台，右侧搜索；搜索支持报告标题、范围名称与 key。
  - 范围筛选：全部及启用范围 chip 单选，切换即刷新。
  - 周分组：按所属周倒序，显示周日期与入库齐全度。
  - 报告卡片：以范围名称为主标题，展示仓库平均分、较上期差值、模块 FAIL、自校结果、发报日、来源与版本；点击任意卡片区域进入详情。
  - 未入库卡片：置灰并说明「本周报告未入库」，不可点击，不提供生成入口。
  - 加载与空态：筛选和刷新使用骨架屏；无结果时提供清除筛选；支持加载更早周次与下拉刷新。
- **导航关系**：点报告卡片 Push `/rnd-report/doc-health/detail`；返回列表保留范围筛选、搜索词与滚动位置。
- **操作反馈**：搜索即时筛选；加载更早周次与刷新显示状态反馈，失败 Toast 并保留重试入口。

### 报告详情

- **页面路径**：`/rnd-report/doc-health/detail`
- **权限编码**：菜单 `devhubAppDocHealthReport`
- **导航方式**：Push
- **页面类型**：详情页（摘要、问题与正文分视图）
- **布局引用**：[`assets/app/report-detail.html`](../assets/app/report-detail.html)
- **区块职责**：
  - 顶部导航：标题「报告详情」、返回与大纲按钮；大纲从底部弹出，选择后进入完整正文并定位。
  - 报告头部：范围、发报日、来源与当前版本；版本通过 ActionSheet 切换，历史版本只读并提示。
  - 评分摘要：仓库平均综合分及环比、模块 FAIL、覆盖率与自校结果。
  - 概览：本期变化摘要、仓库综合分、模块变化和覆盖完整性；报告元信息默认折叠。
  - 问题：按全部 / A / B 级筛选；每项以手风琴展示证据、影响、修复对象、修复动作与复核点；AI 项固定「不计分」。
  - 完整正文：使用服务端安全渲染产物，按报告模板展示全部章节；原始表格支持横向滚动，正文为空时显示「报告内容为空」。
- **导航关系**：无下游编辑页面；返回列表保持筛选与滚动位置，大纲或版本抽屉展开时返回优先关闭抽屉。
- **操作反馈**：版本切换显示局部骨架，失败回退当前版本；大纲点击收起抽屉并定位；筛选无结果显示恢复入口。
