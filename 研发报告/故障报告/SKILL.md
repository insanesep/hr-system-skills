# 故障报告

面向研发与运维的故障管理工具：生产故障从发现登记到复盘闭环的全程留痕——时间线、影响面、根因、处置动作、改进项跟踪，并关联错误日志指纹与黑灯工厂工单作为证据，沉淀可检索的故障档案。

## 服务对象与端

- **服务对象**：研发、运维、技术负责人（复盘与改进项跟踪）
- **仅 Web 端**：管理后台运维/研发域

## 核心逻辑

### 故障登记

- 故障单字段：标题、级别（沿用运维 P1/P2/P3 分级）、发现时间、影响面（受影响功能/用户范围/时长）、现象描述
- 来源双通道：人工登记 + 监控/黑灯工厂重大事件一键转故障单（引用原始证据，不重复采集）

### 复盘闭环

- 状态机：`已登记 → 复盘中 → 已闭环`；已闭环需满足：根因明确、处置完成、改进项全部落实或转出
- 复盘内容：时间线（发现 → 止血 → 恢复 → 复盘）、根因分类（代码缺陷 / 配置 / 容量 / 依赖方 / 数据）、处置动作清单、改进项（负责人 + 截止日 + 完成状态）
- **证据关联**：单向引用错误日志管理的异常指纹与黑灯工厂管理的工单；证据只读不回写

### 统计

- 按周期统计故障数、分级分布、MTTR（发现 → 恢复时长）、复发故障（同根因再发）占比
- 故障档案支持按级别/根因分类/时间范围检索

## 页面功能概览（仅列职责，UI 风格与原型暂不产出）

| 页面 | 职责 |
| ---- | ---- |
| 故障列表 | 分级/状态/时间筛选，KPI（周期故障数/MTTR/复发率） |
| 故障详情 | 故障单全量信息 + 时间线 + 证据关联区（异常指纹/工单只读引用）+ 改进项清单跟踪 |
| 故障统计 | 周期分布、根因分类透视、复盘完成率 |

## 待定口径（评审清单）

- 故障分级标准与运维 P1/P2/P3 的对齐关系
- 「一键转故障单」的触发源范围（服务器监控快照？黑灯工厂 P1 工单？）
- 改进项是否接入排期管理形成卡片闭环

## 关联模块

| 模块 | 关系 |
| ---- | ---- |
| `运维管理/错误日志管理` | 故障证据（异常指纹）引用源 |
| `运维管理/黑灯工厂管理` | 故障证据（工单）与转单来源 |
| `运维管理/服务器监控` | 服务器异常快照证据引用源 |
