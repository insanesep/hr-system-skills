# 故障报告 · 数据定义

> 产品语义的数据定义：实体、字段口径与实体关系；不含 DDL / 索引等研发细节。

## 1. 实体关系

- 故障单 1 ── N 运维证据关联
- 故障单 1 ── N 复盘记录（打回后重提递增）
- 复盘记录 1 ── N 改进措施

## 2. 故障单（主实体）

| 字段 | 业务含义 | 类型 | 必填 | 取值规则 |
| ---- | -------- | ---- | ---- | -------- |
| 标题 | 故障简述 | 文本 | 是 | ≤ 50 字 |
| 现象描述 | 故障表现、报错信息、受影响的功能链路 | 多行文本 | 是 | — |
| 影响范围 | 受影响的业务 / 门店 / 用户范围 | 多行文本 | 否 | — |
| 定级 | 故障严重度 | 枚举 | 是 | P1 / P2 / P3 / P4，默认 P3；口径见 [business-rule.md §3](business-rule.md#3-定级) |
| 发生时间 | 故障发生时间 | 时间 | 是 | 不晚于当前时间 |
| 发现时间 | 故障被发现时间 | 时间 | 否 | 不早于发生时间 |
| 恢复时间 | 故障恢复时间 | 时间 | 否 | 未恢复显示 —；由「标记已恢复」写入 |
| 负责人 | 故障处理负责人 | 人员 | 否 | — |
| 关联项目 | 故障归属的项目 | 单选 | 否 | — |
| 状态 | 生命周期状态 | 枚举 | 系统 | 处理中 / 待复盘 / 复盘中 / 已闭环；流转见 [business-rule.md §4](business-rule.md#4-状态机) |
| 登记人 / 登记时间 | 登记操作留痕 | 人员 / 时间 | 系统 | 不可改 |

## 3. 运维证据关联（从属故障单）

| 字段 | 业务含义 | 类型 | 必填 | 取值规则 |
| ---- | -------- | ---- | ---- | -------- |
| 证据类型 | 证据来源模块 | 枚举 | 是 | 错误日志指纹报表项 / 服务器监控快照 / 黑灯工厂工单 |
| 证据标识 | 证据在来源模块的标识或链接 | 文本 | 是 | 只读引用，不复制内容、不回写状态 |
| 备注 | 证据与故障的关联说明 | 文本 | 否 | — |

## 4. 复盘记录（从属故障单）

| 字段 | 业务含义 | 类型 | 必填 | 取值规则 |
| ---- | -------- | ---- | ---- | -------- |
| 时间线 | 发生 → 发现 → 处置 → 恢复四段 | 结构 | 提交复盘时必填 | 各段含时间与说明 |
| 根因分析 | 故障根因 | 多行文本 | 提交复盘时必填 | — |
| 处置回顾 | 处置过程回顾 | 多行文本 | 否 | — |
| 提交人 / 提交时间 | 复盘提交留痕 | 人员 / 时间 | 系统 | — |
| 打回记录 | 打回原因与时间 | 文本 | 打回时必填 | 曾被打回的复盘展示打回记录与原因 |

## 5. 改进措施（从属复盘记录）

| 字段 | 业务含义 | 类型 | 必填 | 取值规则 |
| ---- | -------- | ---- | ---- | -------- |
| 内容 | 改进项描述 | 文本 | 是 | — |
| 负责人 | 改进负责人 | 人员 | 是 | — |
| 期限 | 完成期限 | 日期 | 是 | 逾期未完成高亮，见 [business-rule.md §5](business-rule.md#5-时限与高亮) |
| 状态 | 完成标记 | 枚举 | 系统 | 未完成 / 已完成 |
| 完成时间 | 标记完成时间 | 时间 | 系统 | 勾选完成时写入 |
