## 页面清单

<a id="report-list"></a>
### 报告列表

- **页面路径**：`/report/project-progress`
- **权限编码**：
  - 菜单：`devhubProjectProgressReport`
  - 按钮：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面类型**：列表页（周 / 月索引，每周期一行两形态）
- **区块职责**：
  - 筛选卡：发报日期范围（默认近 90 天）、关键词（报告标题模糊查询，回车执行）；查询 / 重置。不提供域筛选，域只在报告详情内查看。
  - 结果卡统计（当前查询口径，不参与筛选）：本期已入库（0/2、1/2 或 2/2）、累计报告（按统计周期计，不含历史版本）、最近发报日、历史版本总数。
  - 结果卡工具栏：左侧「手动补传」（持上传权限可见）；右侧「刷新」。
  - 周 / 月索引表格：每周期一行，展示统计周期（齐全度）、报告标题、完整版、简化版与周期操作；两形态分别显示发报日、来源、当前版本及「查看 / 获取原件」，缺失形态为「未入库」。齐全度为 0/2、1/2、2/2，不计历史版本；已有形态正常可查，单次「立即生成两份」统一生成，不提供单形态生成。
  - 分页：按自然周计数，默认 20 条/页，可切换 20 / 50 / 100 条；查询或重置后回到第 1 页。
  - 数据区状态：加载中显示表格骨架；无结果显示「该条件下暂无报告」；加载失败显示「报告列表加载失败」与「重试」，重试保留当前筛选与页码。
  - 手动补传弹窗：类型固定项目进度报告、范围固定 `_all`，增加完整版 / 简化版形态选择；旧文件名 `progress_yyyyMMdd__all.md` 识别为完整版，`progress_yyyyMMdd__all_simple.md` 为简化版，回填形态与发报日。文件名与选择冲突拒绝提交；按正文完整统计区间归档，发报日不决定周期，单文件只修正对应形态、另一份不变、不伪造配对批次。
- **组件引用**：[Button](../../../../busyming-skills-design/components/web/docs/Button/spec.md)、[BusyInput](../../../../busyming-skills-design/components/web/docs/BusyInput/spec.md)、[DatePicker](../../../../busyming-skills-design/components/web/docs/DatePicker/spec.md)、[ProTable](../../../../busyming-skills-design/components/web/docs/ProTable/spec.md)、[Pagination](../../../../busyming-skills-design/components/web/docs/Pagination/spec.md)、[Tag](../../../../busyming-skills-design/components/web/docs/Tag/spec.md)、[Message](../../../../busyming-skills-design/components/web/docs/Message/spec.md)、[MessageBox](../../../../busyming-skills-design/components/web/docs/MessageBox/spec.md)、[Dialog](../../../../busyming-skills-design/components/web/docs/Dialog/spec.md)、[Upload](../../../../busyming-skills-design/components/web/docs/Upload/spec.md)。
- **编排标准**：[Web 操作列表页](../../../../busyming-skills-design/shared/page-standards/web-operation-list.md)；页面无批量业务，不设置勾选列与批量操作。
- **布局引用**：[assets/web/report-list.html](../assets/web/report-list.html)。

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 项目进度报告」。
- 去向页：已入库行「查看」→ `/report/progress/detail/:id`；缺失行「补传」→ 手动补传弹窗；「立即生成」成功 → 报告配置页对应报告项的生成记录。
- 返回行为：从详情返回时恢复原筛选条件、页码与滚动位置；面包屑「项目进度报告」停留当前页。
- 面包屑：首页 / 研发 / 研发报告 / 项目进度报告。

#### 表单校验（手动补传弹窗）

- 初态：报告类型固定为「项目进度报告」、报告项固定为 `_all` 且只读，形态必选；从工具栏进入时发报日默认为空，从缺失行进入时按缺口预填；无编辑模式。

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 报告形态 | 是 | 完整版 / 简化版；文件名与选择不一致拒绝 | change | 「文件名与报告形态不一致」 | 否 |
| 发报日 | 是 | 不可晚于今天；文件名识别成功时自动回填 | change | 「发报日不可晚于今天」 | 否 |
| 报告文件 | 是 | 单个 UTF-8 Markdown 文件，扩展名为 .md，大小不超过 2MB；重复选择替换前次文件 | change | 「仅支持不超过 2MB 的 UTF-8 Markdown 文件」 | 否 |

- 提交成功跳转：无路由跳转；关闭弹窗并刷新来源列表。
- 提交失败展示：BusyMessageBox 展示服务端错误详情；字段错误显示在对应字段下方，已填内容与文件保留。
- 脏数据离开：已选择文件或已填写发报日时关闭，BusyMessageBox 确认「已选择文件或已填写补传信息，放弃本次补传？」。

<a id="report-detail"></a>
### 报告详情

- **页面路径**：`/report/progress/detail/:id`
- **路由名称**：`devhubProjectProgressReportDetail`，为项目进度报告的非菜单详情页。
- **权限编码**：
  - 所属菜单资源：`devhubProjectProgressReport`，不等同于详情路由名称。
  - 关联数据权限：点击人员姓名查看周报须具备 `devhubMemberOutputReport`；打开健康度报告须具备 `devhubDocHealthReport`。无对应权限时姓名仅作文本、健康度操作列为「无查看权限」，不发起数据请求。
- **页面类型**：详情页（阅读型）。
- **区块职责**：
  - 页头：保留返回链接「‹ 返回报告列表」、面包屑、报告标题、「项目进度报告」Tag 与「全部域」Tag；完整版右侧保留「导出为图片（分页 PNG）/ 导出为HTML / 获取原件」，不重复设置「返回列表」按钮。 简化版右侧仅「导出为图片（PNG）/ 获取原件」，不提供独立 HTML；公共形态导航可切换同周期另一份最新版本，不能沿用当前历史 v。
  - 历史版本警示：仅查看历史版本时展示「当前查看历史版本 v{N}（只读），最新版本为 v{M}；切换版本不改变归档内容。」
  - 元信息概览：全部域及组数、发报日、所属周、统计区间（历史归档缺少可解析区间时显示「—」，不代表新报告允许缺失统计区间）、来源、当前版本、文件大小、入库时间；使用公共 `tpl-overview__meta` 自动响应式多列网格，不固定行数、不使用四行 Descriptions。文件大小与入库时间使用公共次要文字样式保留，不删除；当前版本使用公共 PageableSelect 下拉，多版可切换，辅助文案为「历史版本只读可查，URL 带 ?v=N 可分享」。 两形态各自显示形态、生成批次与当前版本；同批次引用两个实际版本，不以同版本号推定配对，单形态补传显示无配对批次。
  - 本期概览：两形态分别读取当前版本四张公共 KPI 卡及其较上期快照，顺序为功能排期（完成率 / 延期率）、活跃人数、Qoder 用量、代码提交行数（+ / -）；不跨角色相加、不累加域行、不借另一形态值。完整版保留原配置成员与次均指标说明，简化版按提交挂靠统计并仅展示概览角色 Qoder 及覆盖人数；历史缺失为「-」，读取异常为「未取得」，不重新计算。
  - 本期概览 · 较上期：四卡均设置「较上期」展示增减值与增减百分比，数据及逐角色 `br` 换行与原件五列表一致。完成率、延期率增减值使用「个百分点」，活跃人数卡按产品、研发、架构分别比较对应角色去重人数并以「人」为单位，不跨角色求和；Qoder 卡按产品、研发、架构逐角色展示总 Credits 的增减值及百分比；代码卡逐角色分别展示新增行、删除行的增减值及百分比，增减值采用「新增 ↑ +X 行；删除 ↓ -Y 行」，百分比为对应双值，不跨角色求和或新增删除互抵。正值用公共成功色、负值用公共危险色、零值用公共中性色，不仅以颜色表达方向；上期无概览时，消费生成侧按同冻结范围回看事实后归档的对比，并展示其来源说明；Qoder 按各期各角色实际取得的汇总直接比较，不校验两期人员名单或匹配集合是否一致，不筛名单交集；完整与部分覆盖均展示环比，并保留两期覆盖人数、未匹配名单和「非全量」说明。确无可用归档或回看事实时才显示「-」；查询失败、已有 current version 缺失或格式破损时显示「未取得」并说明原因，均不标涨跌。上期基线、计算公式、零基线及缺失规则以 [完整版本期概览](progress-report-full.md#本期概览) 与 [简化版本期概览](progress-report-simple.md#本期概览) 为单源，前端不计算；上期不是历史版本 v-1，版本切换只读各版本自身归档快照。
  - 阅读区：只读当前形态在入库时保存的 HTML，不实时生成 Markdown。完整版仍为项目核心进展 / 团队人员 / 功能排期 / 代码提交 / Qoder 使用 / harness文档健康度六章，域列及角色双层表头沿用原规则；域名称只读引用项目管理中的项目名称，以稳定项目标识关联，名称快照随版本归档，更名不改历史。简化版为项目总览 / 项目进展 / harness文档健康度，每个域下仅结论、关键指标、本期交付、风险与阻塞四块，无人员名单或明细；交付开发人仍在状态列后。数值、列表、角色、核心进展和健康度全部见各形态内容规范，不隐藏指标、不重计。正文全宽无大纲，横滚仅表格容器、首列固定、数值右对齐。
  - 完整版人员周报弹窗：本期新增人员在姓名旁以公共 `u-success` 文字样式展示「（新）」，不使用 Tag 边框、底色或额外标签留白，即其在该项目该角色的首次有效提交落在统计窗口内且窗口开始前无同项目同角色有效提交；全量按人员稳定 ID 去重，任一参与项目符合即保留标记。生成侧复用 Git 采集与身份校验结果并随版本快照归档，不按成员加入时间或页面猜测；Markdown 与 PNG 以「姓名（新）」表示，标签不改变团队人数、人员周报来源或点击行为。具备人员产出报告权限时，团队人员中的姓名渲染为可点击按钮；点击后打开公共 Dialog，标题为「{姓名} · 本周研发周报」，展示统计区间、来源报告及版本，以及该人员在「按人员综合分析」下的完整小节。姓名点击与 PNG 导出均重新读取同周最新入库的当前周报版本，不复用先前弹窗或导出的旧来源内容。加载中显示局部状态；成功读取后无同周周报或人员小节时显示「-」；读取失败、已有 current version 缺失、身份未匹配或格式破损时显示「未取得」并说明原因，不推测内容。弹窗提供「查看完整周报」与「关闭」，关闭后焦点返回原姓名；切换进度报告版本前关闭弹窗。Markdown 原件与 Web 正文中姓名保持纯文本；PNG 在正文后追加「人员工作明细」附录，按去重人员展示同周研发周报个人小节，无权限显示「无查看权限」，成功读取后无同周周报或人员小节显示「-」，读取异常或身份未知显示「未取得」并说明原因。 简化版不展示独立人员名单或个人周报弹窗。
  - 版本切换：选择历史版本后，元信息、四张概览卡与正文整体同步切换，较上期仅读取所选版本自身的对比快照；加载期间概览与正文使用公共骨架及「正在加载所选版本内容…」，不显示跨版本组合数据，成功后 URL 写入 `?v=N`；失败时停留原版本并保留原元信息、概览及正文。版本加载期间禁用导出；PNG 导出期间禁用版本下拉，禁止混版。 导出或版本加载期间也禁用形态导航，目标形态未入库时置灰提示，不创建空报告；切形态打开其自身最新版本。
  - 完整版分页 PNG 导出：点击「导出为图片（分页 PNG）」固定以普通分辨率 1600×2000 像素分页，不提供分辨率选择、不接异步导出中心；导出当前版本标题、统计区间、本期概览、六章、所有项目及仓库行和「人员工作明细」附录，不截取视口或横向滚动可见列，不裁掉指标。表头按词换行、数值对齐与健康度语义色沿用归档结果及公共样式；概览仅消费当前版本归档值与对比快照，「较上期」数据及成功 / 危险 / 中性色与 HTML 一致，附录继续按既有同周来源与权限读取。
  - 分页连续性：普通表格行不得跨页截断，剩余高度不足时整行移至下一页；续页重复对应章节，Qoder 同时保留「产品与研发」或「架构」小标题，并重复对应表格的完整表头，角色表必须重复上层角色及下层全部指标（首列跨两行）。单元格超出单页可用高度时仅按完整文本行续写，保留项目 / 仓库或人员标识与续写关系，不切字、不遗漏或重复正文；其他单层表头也完整重复。每页底部显示页码「第 p 页 / 共 P 页」，人员附录续页保留附录标题与人员标识。
  - 下载与防混版：原件文件名去扩展名为 basename，所有分页 PNG 按页序打包为 `basename_vN_png.zip` 一次下载，包内文件为 `basename_vN_p01.png`、`basename_vN_p02.png` 等，页号至少两位且按总页数补齐以保持排序。导出开始时冻结当前进度报告版本及其元信息、概览、正文和人员快照，禁用版本切换；附录本次读取完成后用于全部页，不能逐页重新读取造成混版。按钮 loading + disabled，全部分页与 ZIP 完成后才发起一次下载；失败保留当前版本和归档数据，不下载残缺包，恢复按钮与版本下拉后可重试；重试仍按既有规则重新读取同周最新归档人员小节并在本次导出内固定。
  - 完整版独立 HTML 导出：点击「导出为HTML」下载当前版本完整报告和「人员工作明细」附录，包含标题、元信息、统计区间、本期概览、六个固定章节、全部域与仓库行；使用与分页 PNG 相同的版本和人员快照，不重新计算指标或跨版本补值。导出为单文件 `basename_vN.html`，内联公共样式，可离线打开；移除脚本、弹窗、版本切换、页面操作按钮及外部资源依赖，人员姓名与来源链接转为静态文本，不保留交互行为。权限与详情查看一致，空正文禁止导出。 仅适用于完整版，不扩展到简化版或其它报告。
  - 简化版 PNG 导出：下载本形态当前版本的完整单张 PNG，宽 1600 像素、高度随全部内容，超出单图上限整体降低像素密度保证完整；不分页、不打包、不附加个人周报，文件 `basename_vN.png`。包括标题、区间、四卡、总览、全部域的四块进展与末章健康度，展开全部表格列；导出时冻结形态、版本与数据，失败保留原归档、不下载残缺图片。
  - 异常空态：报告 ID 不存在或对应报告尚未入库时，显示「报告不存在或尚未入库」，元信息显示「—」，禁用版本切换、PNG 导出、HTML 导出与获取原件，仅保留返回列表。

#### 导航关系

- 来源页：报告列表两形态各自「查看」，路径由该形态报告 ID 确定，历史版本参数仅作用于当前报告；切形态不沿用 v。
- 去向页：健康度「查看报告」→ `/subapp/devhub/report/doc-health/detail/{本周报告 ID}`；人员周报弹窗「查看完整周报」→ `/subapp/devhub/report/member-output/detail/{周报报告 ID}`。「导出为图片（分页 PNG）」一次下载当前版本完整报告及人员附录的分页 PNG 压缩包 `basename_vN_png.zip`；「导出为HTML」下载同版本含人员附录的独立离线文件 `basename_vN.html`；「获取原件」下载当前展示版本 Markdown。
- 返回行为：页头「‹ 返回报告列表」或面包屑「项目进度报告」→ 报告列表，并恢复原筛选条件、页码与滚动位置；右侧无重复返回按钮。
- 面包屑：首页 / 研发 / 研发报告 / 项目进度报告 / 报告详情。
