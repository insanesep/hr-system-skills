## 页面清单

### 报告列表

- **页面路径**：`/rnd-report/progress/list`
- **权限编码**：
  - 路由：`devhubProjectProgressReport`
  - 按钮：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面类型**：列表页（Tab 双视角：按周索引 / 按项目分组）
- **区块职责**：
  - 工具栏（筛选 panel）：项目（单选：全部 / 启用项目清单）、统计周期（全部 / 周 / 月）、发报日期范围（RangePicker）、关键词（报告标题模糊）、查询 / 重置
  - KPI 区（筛选后 / 表格前）：本周已入库（x/y，y = 启用项目数）、累计报告、最近发报日、历史版本总数
  - 主体区（表格 panel，Tab 形态）：
    - **Tab1 按周索引**（默认）：周分组手风琴，按所属周倒序（本周行仅周日当天起展示，周中最晚只到上周）；组头 = 周标签（`2026 年第 36 周（08-31 ~ 09-06）`）+ 齐全度徽标（`已入库份数 / 启用项目数`，缺项标「待补」）；组内每个启用项目一行（按项目 key 字典序）：报告标题（前置「项目进度」徽标）、项目、统计周期（周 / 月）、发报日、来源（服务端生成 / 推送上报 / 手动补传）、版本、文件大小、入库时间、操作（查看 / 获取原件）；未入库项目行灰显「未入库」+ 操作「立即生成」（仅持有触发权限可见）/「补传」（仅持有上传权限可见）
    - **Tab2 按项目分组**：项目手风琴（组头 = 项目名称 + 项目 key + 报告份数徽标），组内按发报日倒序列报告行（列同 Tab1，缺「项目」列）；空态 AcEmpty「该条件下暂无报告」
  - 弹窗：**手动补传弹窗**：项目（必选，单选启用项目）、发报日（DatePicker，不可晚于今天）、报告文件（仅 .md，≤2MB，拖拽或点选）、识别提示条（按文件名 `progress_yyyyMMdd_<项目key>.md` 自动识别项目与发报日：「已按文件名识别：项目 &lt;项目名&gt; · 发报日 2026-08-31」；识别失败提示「文件名无法识别，请手动指定项目与发报日」）
- **布局引用**：`参见原型 assets/web/report-list.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl` 可选 Tab 形态）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 项目进度报告 → 报告列表」
- 去向页：行内「查看」→ `/rnd-report/progress/detail/:id`；缺失行「补传」→ 手动补传弹窗（项目与发报日预填）；缺失行「立即生成」→ 直接创建生成任务
- 返回行为：浏览器返回回到列表并保持 Tab 与筛选条件
- 面包屑：首页 / 研发 / 研发报告 / 项目进度报告

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 筛选条件变更后点查询 | 否 | 表格 loading | 列表刷新，停留 | toast error + 按钮恢复 |
| 切换视角 Tab | 点击 Tab | 否 | 表格 loading | 切换视角，停留 | — |
| 手动补传提交 | 弹窗内项目 / 发报日 / 文件齐备 | 否 | 提交按钮 loading | toast「补传成功，已生成 v{N}」→ 关弹窗并刷新列表 | toast error（项目未选 / 格式 / 大小 / 未来日期）+ 弹窗保留 |
| 立即生成 | 未入库行点「立即生成」 | 是（确认统计窗口） | 按钮 loading | toast「已创建生成任务」→ 跳转报告触发配置页生成记录 | toast error（存在进行中任务 / 无权限）+ 按钮恢复 |
| 获取原件 | 行内点「获取原件」 | 否 | 按钮 loading | 浏览器下载原始 .md | toast error + 按钮恢复 |

### 报告详情

- **页面路径**：`/rnd-report/progress/detail/:id`
- **权限编码**：
  - 路由：`devhubProjectProgressReport`
- **页面类型**：详情页（阅读型）
- **区块职责**：
  - 元信息头（首个 panel）：报告标题（h1 级，前置「项目进度」徽标）、项目、统计周期（周 / 月）、发报日、所属周、统计区间（从正文首部引用块解析，失败显示 —）、来源（服务端生成 / 推送上报 / 手动补传）、当前版本（`v1 · 共 1 版`，多版时可下拉切换历史版本）、文件大小、入库时间、操作（获取原件 / 返回列表）
  - 阅读区（左主体 panel）：Markdown 渲染正文（章节顺序：统计概览 / 进度总览 / 需求吞吐 / 实施进度 / 延期清单 / 发版回顾；正文首部含 `> 统计区间：YYYY-MM-DD ~ YYYY-MM-DD` 引用块）。Web 端为前端实时渲染：按 mdUrl 拉取原始 md，marked(GFM) 渲染 + DOMPurify 白名单过滤 + GitHub 风格样式内联展示（图片替换占位「[图片已移除]」，与服务端口径一致），见子域 business-rule.md §4
  - 侧边栏（右侧大纲 panel，≥1200px 展示，窄屏折叠为顶部「大纲」按钮弹抽屉）：h2/h3 锚点目录，当前阅读章节高亮，点击平滑滚动定位
  - 版本切换：元信息头版本下拉选择历史版本 → 正文整体切换为该版本渲染产物（只读，URL 带 `?v=N` 可分享）
- **布局引用**：`参见原型 assets/web/report-detail.html`（DOM 结构依据：`page-blueprint/skeletons/web/detail-page.vue.tpl`）

#### 导航关系

- 来源页：报告列表行内「查看」
- 去向页：无下游页面
- 返回行为：面包屑「项目进度报告」/ 浏览器返回 → 报告列表（保持原 Tab 与筛选）
- 面包屑：首页 / 研发 / 研发报告 / 项目进度报告 / 报告详情
