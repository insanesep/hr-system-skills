# 项目进度报告

面向管理层、PM 与项目负责人的**项目维度**周期性进度报告：每个项目独立生成一份周期报告，汇总该项目「计划了什么、完成了什么、延期了什么」，替代人工汇总与全量混排的大周报。

## 服务对象与端

- **服务对象**：管理层、PM、项目负责人
- **Web 管理端**：报告索引、在线阅读、手动补传与版本回溯
- **App 查阅端**：按项目分组浏览与阅读

## 分项目生成（核心）

- 报告按「范围类型（域/项目）+ 稳定实体引用 × 周期（周/月）」生成，一有效范围一份；报告范围配置只维护 key、分支策略与报告扩展，不另建基础实体
- 域范围=整个主仓及确认执行映射；项目范围=主仓对应一级目录及该项目确认执行映射，根文件不计入项目，跨项目同名实现不混入
- **全部项目汇总**：保留 `_all` 与既有文件名，取全部可生成范围并集；域、卡片稳定 ID 与源仓稳定 ID + commit SHA 去重，不叠加域和子项目重复数据，明细视图不直接相加为汇总。触发配置仍内置唯一，详见 [`报告配置规则`](../报告配置/references/business-rule.md#3-报告项目配置)

## 项目配置（外部真源）

- 基础实体、清单与 N:N 执行映射只读引用 [`域及项目管理`](../../研发管理/域及项目管理/SKILL.md)，范围、根文件与跨项目提交去重遵守 [`#consumption`](../../研发管理/域及项目管理/references/business-rule.md#consumption)
- key（全局唯一、首次保存锁定）、分支策略、扩展启停归 [`报告配置`](../报告配置/SKILL.md) 的报告范围配置。启用有效域/项目仅自动成行，配置齐备启用后才联动报告
- 范围停用或远端确认缺失停止生成、不删归档；历史旧整体项目报告只显式核对到对应域，不猜测或复制到各项目，保留旧 key、文件名与版本。以上为已确认产品目标，不表示生产上线

## 生成方式：触发配置 + 服务端生成

1. 触发方式在 [`报告配置`](../报告配置/SKILL.md) 模块「报告触发配置」页维护：每个有效已配置启用的域/项目范围一条配置行（随报告范围扩展联动生成），支持定时规则（每周 / 每月）与手动「立即生成」；统计窗口按周期口径计算后随任务下发
2. 触发后服务端通过 **Qoder SDK** 创建生成会话，携带域及项目管理的范围类型、稳定引用与确认映射快照，以及报告扩展 key、分支策略与统计窗口；生成逻辑真源为 [`references/progress-report.md`](references/progress-report.md)，依其执行采集与生成。卡片与流水仍从功能排期管理取得，不因基础映射迁出改换事实来源
3. 产出报告由服务端直接落库归档（渲染、版本递增、周索引），不经过推送；外部生成会话产出可经推送上报旁路入库（兜底见手动补传）
4. 仓库操作只允许落在生成会话的约定工作区内，严禁使用本机其它位置的同名开发者副本
5. 生成任务全程留痕（触发来源 / 状态 / 耗时 / 失败原因），失败可在生成记录中重试

## 报告内容（口径）

- **进度总览**：区间内功能排期卡片完成率（完成 / 在制 / 待开发 / 延期分布），按功能分组
- **需求吞吐**：提交 → 审批通过 → 已排期 → 已完成各环节数量与端到端周期
- **延期清单**：逾期未完成的功能排期卡片明细（负责人、排期日、延期天数）
- **发版回顾**：区间内的发版日与发布内容摘要（联动发布管理）

## 归档与查阅

- **项目 × 自然周（周一为起点）双维索引**；同项目同周期重复入库走版本递增而非覆盖，历史版本可溯
- 报告为静态产物：归档后只做渲染呈现（Markdown → HTML + 大纲锚点导航），不重新计算指标；指标口径问题回溯生成侧
- 归档、触发与生成规则真源见 [`../报告配置/references/business-rule.md`](../报告配置/references/business-rule.md)，数据模型见 [`../报告配置/references/data.md`](../报告配置/references/data.md)

## 关键约束

- 数据源唯一：报告指标全部由研发管理中功能排期管理的卡片事实与映射代码仓的 git 事实计算，不接受手工填报
- 映射真源唯一：基础实体与执行映射以域及项目管理为准，报告侧扩展以报告配置为准；外部配置仅传递同真源引用及快照，不维护第二份实体或映射
- 原始报告文件单文件直接获取，不接入批量异步导出中心；报告落库即页面可查，本子域不做主动通知
- 项目停用只影响此后的生成，不删除历史报告
