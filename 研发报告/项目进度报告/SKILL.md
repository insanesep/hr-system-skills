# 研发周报

> App 功能图标：[dev-weekly-report.html](../../../../设计/app/icons/resources/dev-weekly-report.html)（App 工作台「研发周报」入口图标真源，120×120 统一版式动效 HTML，自包含）


ai-checker 周报体系的**归档与查阅中枢**：ai-checker 每周产出三类 Markdown 报告（研发周报、零食王国文档一致性校验、有点推荐文档一致性校验），本模块负责统一接收入库（自动上报 + 手动补传）、按自然周建索引、将 Markdown 渲染为 HTML 供在线阅读，解决「周报散落在本地目录、找历史周次要翻文件名、md 原文阅读体验差」三个问题。

## 端

**Web 管理后台 + App 双端**：

- **Web 管理后台**（「研发」分组下）：按周索引与报告明细双视角查询、在线阅读（大纲锚点导航）、手动补传与历史版本回溯，为主操作端
- **App 端**：按周分组浏览、报告在线阅读，面向管理层移动查阅；不提供手动补传与版本管理

## When to Use

- 管理层 / 研发负责人需要查阅某一周的研发周报（提交统计、AI 分析、人员分析、功能进展）
- 产品经理需要查阅某一周的文档一致性校验报告（零食王国 / 有点推荐），跟进文档与代码偏差
- 管理员发现某周报告缺失（ai-checker 未上报或上报失败），需要手动补传 md 文件
- 需要对比同一周期报告的历史版本（报告修正重发后保留旧版溯源）

## 页面功能概览

### Web 管理后台（2 页）

| 页面 | 功能概述 |
|------|---------|
| 报告列表 | 双视角：「按周索引」按自然周倒序分组，每周展示三类报告齐全度与缺失快捷补传；「报告明细」平铺表格多维筛选（类型 / 发报日期 / 关键词）；顶部 KPI 呈现本周入库进度与累计报告数 |

## Tips

- 报告为 ai-checker 生成的**静态产物**，内容自包含：本模块只做归档与呈现，数据完全来自上传的 md 文档，不重新计算报告内任何指标，也不关联任何数据源模块；指标口径问题回溯 ai-checker 生成侧处理
- 本模块的「一致性」特指 ai-checker 产出的**文档一致性校验报告**（文档与代码对齐检查），与 [`公共数据/数据一致性`](../../../依赖文档/公共数据/数据一致性/SKILL.md) 的销售 / 库存金额口径对账无关，不引用该真源
- 报告原始文件为单文件直接获取，非批量 Excel 场景，**不接入** [`公共功能/导出接入`](../../../依赖文档/公共功能/导出接入/SKILL.md) 异步导出中心
- 报告发布后的告知由 ai-checker 侧既有机制承担，本模块不做消息通知，不接入企微消息
- 周索引按**发报日所在自然周（周一为起点）**归组，与研发周报内部的统计区间（上一自然周）是两个字段，详见 [references/business-rule.md §2](references/business-rule.md#2-周期归属与周索引)
- 同类型同发报日重复入库走**版本递增**而非覆盖，历史版本可追溯，详见 [references/business-rule.md §3](references/business-rule.md#3-入库与版本规则)
