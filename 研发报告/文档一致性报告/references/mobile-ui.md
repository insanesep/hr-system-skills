# App 端 UI 描述 · 文档一致性报告

> 视觉样式消费 [移动端设计 Token](../../../../busyming-skills-design/assets/runtime/prototype/mobile-tokens.css)；品牌橙用于主操作、链接、选中态与导航，成功、警告、错误使用各自语义色，不以主色代替状态色。
> 归档、版本、渲染与异常口径以子域 [`../../报告配置/references/business-rule.md`](../../报告配置/references/business-rule.md) 为真源。范围与齐全度使用有效且已配置启用的域/项目，停用或远端确认缺失时保留历史、停止生成。

## 报告列表

- **页面路径**：`/rnd-report/consistency/home`
- **菜单权限**：`devhubAppConsistencyReport`
- **导航方式**：从 App 工作台 Push 进入；返回工作台
- **页面职责**：按周查找并阅读已归档报告，识别未入库项目；App 不提供生成或补传操作

### 页面结构与交互

- 顶部导航栏展示页面标题、返回与刷新；下拉刷新和刷新按钮均更新列表，加载时使用骨架屏，失败保留原列表并提示重试
- 本周摘要直接展示已入库数与待补项目，并说明可前往 Web 管理端处理
- 搜索框常驻，按报告标题模糊匹配，支持清除与无结果恢复；项目筛选使用单选 chip，默认全部项目
- 报告按所属周倒序分组；周标题展示日期范围、已入库数和齐全状态。筛选后仍保留周分组
- 已入库卡片展示范围类型、名称与 key、报告标题、发报日、来源和当前版本；整卡可点并进入详情
- 未入库卡片使用明确的待补状态，不提供点击；说明需在 Web 管理端生成或补传
- 「加载更早周次」追加分组，加载中禁用按钮；全部加载后展示结束提示
- 空态说明可调整关键词或项目，并提供清除筛选
- 从详情返回时保持项目筛选、搜索词、已加载周次和滚动位置

## 报告详情

- **页面路径**：`/rnd-report/consistency/detail`
- **菜单权限**：`devhubAppConsistencyReport`
- **导航方式**：从报告列表 Push 进入；返回列表

### 页面结构与交互

- 顶部导航栏提供返回和大纲入口，阅读进度在顶部以轻量进度条呈现
- 元信息卡默认展示报告标题、发报日、项目与当前版本；其余所属周、来源、文件大小和入库时间可展开查看
- 当前版本始终可直接触达，点击后从底部弹出版本列表；历史版本标识只读，切换时正文展示骨架屏，元信息与正文同步更新
- 正文使用服务端渲染且经 XSS 白名单过滤的产物；章节、列表与表格保持清晰阅读层级，宽表支持横向滑动
- 大纲从底部弹出，包含 h2/h3 条目；点击后关闭并定位到对应章节
- 历史版本提示说明最新版本号；正文为空时展示「报告内容为空」
- 大纲或版本弹层打开时，返回手势优先关闭弹层；其余情况返回列表
