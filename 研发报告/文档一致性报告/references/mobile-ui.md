## 页面清单

### 报告列表

- **页面路径**：`/rnd-report/consistency/home`
- **权限编码**：
  - 菜单：`devhubAppConsistencyReport`
- **导航方式**：Push（工作台入口进入）
- **页面类型**：列表页（分组卡片流）
- **区块职责**：
  - 顶部导航栏：标题「文档一致性报告」+ 右侧搜索图标（点击展开搜索输入框，按标题模糊匹配）
  - 项目筛选（导航栏下 chip 组，单选）：全部 + 各启用项目（来自「报告范围配置」生效数据），默认全部，切换即刷新列表
  - 主体区：按所属周倒序的周分组卡片流（本周行仅周日当天起展示，周中最晚只到上周，与 Web 同口径由后端 week-index 统一收口）。每组：周标签（`第 36 周 · 08-31~09-06`）+ 齐全度徽标（`2/2` 绿色 / `1/2` 橙色，分母 = 有效且已配置启用的报告范围项数）；组内每报告项一张卡片：项目徽标独占一行 + 报告标题整行（最多 2 行）、发报日、来源（服务端生成 / 推送上报 / 手动补传）、版本号；未入库项灰显「未入库」占位卡（不可点）
  - 空态：筛选无结果时展示空态插画 + 「该条件下暂无报告」
- **布局引用**：`参见原型 assets/app/report-list.html`（DOM 结构依据：`page-blueprint/skeletons/app/list-page.tsx.tpl`）

#### 导航关系

- 来源页：App 工作台「文档一致性报告」入口图标 → Push 进入本页
- 去向页：点报告卡片 → Push `/rnd-report/consistency/detail`
- 返回行为：导航栏返回按钮 / 手势返回 → 工作台
- 手势返回：允许

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 标题搜索 | 搜索框输入并确认 | 否 | 列表骨架屏 | 展示匹配结果（跨周分组保留） | AcToast error |
| 项目筛选 | 点项目 chip | 否 | 列表骨架屏 | 列表刷新为所选项目 | AcToast error |
| 下拉刷新 | 列表顶部下拉 | 否 | 下拉刷新指示器 | 列表刷新至最新 | AcToast error |
| 上拉加载 | 滚动到底部且仍有更早周次 | 否 | 底部加载指示器 | 追加更早周分组 | AcToast error + 保留重试入口 |

### 报告详情

- **页面路径**：`/rnd-report/consistency/detail`
- **权限编码**：
  - 菜单：`devhubAppConsistencyReport`
- **导航方式**：Push
- **页面类型**：详情页（阅读型）
- **区块职责**：
  - 顶部导航栏：标题「文档一致性报告」+ 右侧「大纲」图标（点击从底部弹出大纲抽屉）
  - 元信息区（顶部折叠卡，默认展开首行）：项目类型徽标、报告标题、项目、发报日、所属周、来源、文件大小、入库时间、当前版本（`v1 · 共 1 版`，多版时点版本行弹 ActionSheet 切换历史版本，只读）；折叠态仅保留标题 + 发报日
  - 主体区：Markdown 渲染正文（本次检查范围明细 / 统计概览 / 文档三件套对齐表 / 功能覆盖度分析 / 总体摘要；表格横滚）。WebView 加载服务端渲染产物（已 XSS 白名单过滤），产物本身无样式，GitHub 风格排版在内容加载前注入（幂等无闪烁，锚点 h-{seq} 不受影响）
  - 大纲抽屉：底部弹出 h2/h3 锚点目录，当前章节高亮，点击跳转并收起抽屉
  - 空态：正文为空时展示「报告内容为空」
- **布局引用**：`参见原型 assets/app/report-detail.html`（DOM 结构依据：`page-blueprint/skeletons/app/detail-page.tsx.tpl`）

#### 导航关系

- 来源页：报告列表点报告卡片 Push 进入
- 去向页：无下游页面
- 返回行为：导航栏返回按钮 / 手势返回 → 报告列表（保持项目筛选与滚动位置）
- 手势返回：允许（大纲抽屉展开时优先关闭抽屉）
