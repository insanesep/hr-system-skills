## 页面清单

### 报告列表

- **页面路径**：`/rnd-report/consistency/list`
- **权限编码**：
  - 路由：`devhubConsistencyReport`
  - 按钮：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面类型**：列表页（Tab 双视角：按周索引 / 报告明细）
- **区块职责**：
  - 工具栏（筛选 panel）：项目（单选：全部 + 各启用项目，选项来自「报告项目配置」生效数据，默认全部）、发报日期范围（RangePicker）、关键词（标题模糊）、查询 / 重置
  - KPI 区（筛选后 / 表格前）：本周已入库（x/y，y = 启用项目数）、累计报告、最近发报日、历史版本总数
  - 主体区（表格 panel，Tab 形态）：
    - **Tab1 按周索引**（默认）：周分组手风琴，按所属周倒序（本周行仅周日当天起展示，周中最晚只到上周）；每周一行组头（周标签 `2026 年第 36 周（08-31 ~ 09-06）` + 齐全度徽标 `2/2` 或 `1/2 待补`）；组内按启用项目逐行成行（按项目 key 字典序），行展示：报告标题、项目（徽标）、发报日、来源（服务端生成 / 推送上报 / 手动补传）、版本号、文件大小、入库时间、操作（查看 / 获取原件）；未入库行灰显「未入库」+ 操作「立即生成」（仅持有触发权限可见）/「补传」（仅持有上传权限可见）
    - **Tab2 报告明细**：平铺表格，列：发报日期、所属周、项目、报告标题、来源、版本、文件大小、入库时间、操作（查看 / 获取原件）；空态 AcEmpty「该条件下暂无报告」
  - 弹窗：**手动补传弹窗**：项目（必选，单选启用项目，按文件名识别成功时自动带入）、发报日（DatePicker，不可晚于今天）、报告文件（仅 .md，≤2MB，拖拽或点选）、识别结果提示条（「已按文件名识别：项目 &lt;项目名&gt; · 发报日 2026-08-31」/「文件名无法识别，请手动指定项目与发报日」）
- **布局引用**：`参见原型 assets/web/report-list.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl` 可选 Tab 形态）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 文档一致性报告」
- 去向页：行内「查看」→ `/rnd-report/consistency/detail/:id`；缺失行「补传」→ 手动补传弹窗（项目与发报日预填）；缺失行「立即生成」→ 直接创建生成任务
- 返回行为：浏览器返回回到列表并保持 Tab 与筛选条件
- 面包屑：首页 / 研发 / 研发报告 / 文档一致性报告

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 筛选条件变更后点查询 | 否 | 表格 loading | 列表刷新，停留 | toast error + 按钮恢复 |

| 立即生成 | 未入库行点「立即生成」 | 是（确认报告项与回看天数） | 按钮 loading | toast「已创建生成任务」→ 跳转报告触发配置页生成记录 | toast error（存在进行中任务 / 无权限）+ 按钮恢复 |
| 获取原件 | 行内点「获取原件」 | 否 | 按钮 loading | 浏览器下载原始 .md | toast error + 按钮恢复 |

#### 表单校验（手动补传弹窗）

- 初态：项目与发报日默认空；按文件名识别成功时自动带入（识别提示条同步展示）；从缺失行「补传」进入时预填该项目与当周周日为发报日；报告文件默认空

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 项目 | 是 | 单选启用项目 | change | 「请选择项目」 | 否 |
| 发报日 | 是 | 不可晚于今天（东八区） | change | 「发报日不可晚于今天」 | 否 |
| 报告文件 | 是 | 仅 .md（UTF-8），≤2MB | 选择后即时 | 「仅支持 Markdown 文件」/「文件不可超过 2MB」 | 否 |

- 提交成功去向：toast「补传成功，已生成 v{N}」→ 关闭弹窗并刷新列表（见操作反馈清单）
- 提交失败展示：toast error + 弹窗保留已填内容
- 脏数据离开：已选文件或改动必填项后点取消/关闭 → AcPopconfirm「已填写的内容将丢弃，确认放弃补传？」

### 报告详情

- **页面路径**：`/rnd-report/consistency/detail/:id`
- **权限编码**：
  - 路由：`devhubConsistencyReport`
- **页面类型**：详情页（阅读型）
- **区块职责**：
  - 元信息头（首个 panel）：报告标题（h1 级，如「一致性检查报告（{项目名}） - 2026-08-31」）、项目（徽标）、发报日、所属周、来源（服务端生成 / 推送上报 / 手动补传）、当前版本（`v1 · 共 1 版`，多版时可下拉切换历史版本）、文件大小、入库时间、操作（获取原件 / 返回列表）
  - 阅读区（左主体 panel）：Markdown 渲染正文（章节口径：本次检查范围明细 / 统计概览 / 文档三件套对齐表 / 功能覆盖度分析 / 总体摘要；表格横滚、代码块等宽字体）。Web 端为前端实时渲染：按 mdUrl 拉取原始 md，marked(GFM) 渲染 + DOMPurify 白名单过滤 + GitHub 风格样式内联展示（图片替换占位「[图片已移除]」，与服务端口径一致）；服务端渲染的 HTML 产物仅 App 端 WebView 消费，见子域 business-rule.md §4
  - 侧边栏（右侧大纲 panel，≥1200px 展示，窄屏折叠为顶部「大纲」按钮弹抽屉）：h2/h3 锚点目录，当前阅读章节高亮，点击平滑滚动定位
  - 版本切换：元信息头版本下拉选择历史版本 → 正文整体切换为该版本渲染产物（只读，URL 带 `?v=N` 可分享）
- **布局引用**：`参见原型 assets/web/report-detail.html`（DOM 结构依据：`page-blueprint/skeletons/web/detail-page.vue.tpl`）

#### 导航关系

- 来源页：报告列表行内「查看」
- 去向页：无下游页面
- 返回行为：面包屑「文档一致性报告」/ 浏览器返回 → 报告列表（保持原 Tab 与筛选）
- 面包屑：首页 / 研发 / 研发报告 / 文档一致性报告 / 报告详情
