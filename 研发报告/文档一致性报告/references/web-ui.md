# Web 端 UI 描述 · 文档一致性报告

> 视觉样式消费 [PC 设计 Token](../../../../busyming-skills-design/assets/runtime/prototype/pc-tokens.css)；品牌蓝用于主操作、链接、选中态与导航，成功、警告、错误使用各自语义色，不以主色代替状态色。
> 归档、版本、渲染与异常口径以子域 [`../../报告配置/references/business-rule.md`](../../报告配置/references/business-rule.md) 为真源；报告内容章节口径以 [`consistency-check.md`](consistency-check.md) 为真源。范围筛选、列表与补传均使用范围类型、名称、key 和稳定实体引用。

## 报告列表

- **页面路径**：`/subapp/devhub/report/consistency`
- **路由权限**：`devhubConsistencyReport`
- **按钮权限**：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面职责**：总览入库情况，按周或明细查找报告，处理缺失报告并获取原件

### 页面结构与交互

- 页头展示模块名称、用途说明与「手动补传」主操作；侧边导航保持研发报告家族入口一致
- 概览区展示本周已入库、累计报告、最近发报日和历史版本数；累计、最近发报日与历史版本随筛选结果更新，本周齐全度始终按该周全部有效且已配置启用的报告范围计算，不随项目或关键词筛选缩小分母
- 筛选区包含项目单选、发报开始日、发报结束日和报告标题关键词；默认近 90 天，支持查询、回车查询、重置和日期先后校验
- 默认「按周索引」，周分组倒序且默认展开；组头展示日期范围、已入库数、待补数和启用项目数，可折叠
- 已入库行展示报告标题、项目、发报日、来源、版本与操作；标题和「查看」进入详情，「获取原件」下载当前版本 Markdown
- 未入库行以待补色标识，说明可立即生成或补传；「立即生成」二次确认报告项、周期和回看天数，成功后停留本页并提示生成记录入口
- 「报告明细」以平铺表格展示发报日期、所属周、项目、标题、来源、版本与操作
- 按周索引展示近 8 周，报告明细最多 200 条，不分页；无结果时提供清除筛选
- 从详情返回时保持视角和筛选条件

### 手动补传

- 共用规则见 [`报告配置 · 手动补传弹窗`](../../报告配置/references/web-ui.md#手动补传弹窗报告模块共用)
- 报告类型固定为文档一致性校验；项目单选启用范围，发报日不可晚于今天；从缺失行进入时预填项目和当周周日
- 支持点击与拖入 UTF-8 Markdown 文件，单文件不超过 2MB；按文件名识别项目和发报日，识别失败时保留手动指定能力
- 必填、格式、大小和未来日期错误在对应字段就近提示；重复内容不生成新版本
- 已选择文件或修改字段后关闭需二次确认；成功后关闭弹窗并同步列表、齐全度和概览

## 报告详情

- **页面路径**：`/subapp/devhub/report/consistency/detail/:id`
- **路由名称**：`devhubConsistencyReportDetail`
- **所属菜单权限**：`devhubConsistencyReport`
- **页面职责**：阅读静态归档正文，定位章节，回溯版本并获取当前展示版本原件

### 页面结构与交互

- 页头提供返回列表、报告标题、项目、来源、发报日和「获取原件」；窄屏提供大纲按钮
- 元信息区展示发报日、所属周、版本、文件大小、入库时间和文件名；版本使用下拉选择，URL 携带版本号可分享
- 历史版本展示只读提示和最新版本号；切换时正文显示加载状态，正文与元信息同步切换，失败时停留原版本并提示
- 正文采用服务端渲染 HTML 产物，前端只提供排版样式；章节包含检查范围、统计概览、三件套对齐、功能覆盖分析和总体摘要
- 宽屏右侧常驻大纲并随阅读位置高亮，窄屏改为抽屉；顶部阅读进度用于指示当前阅读位置
- 宽表横向滚动，正文为空时展示「报告内容为空」；获取原件失败时明确提示当前版本无原始内容
