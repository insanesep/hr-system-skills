## 页面清单

### 报告列表

- **页面路径**：`/subapp/devhub/report/consistency`
- **权限编码**：
  - 路由：`devhubConsistencyReport`
  - 按钮：`devhubReportUpload`（手动补传）、`devhubReportTrigger`（立即生成）
- **页面类型**：列表页（Tab 双视角：按周索引 / 报告明细）
- **区块职责**：
  - 工具栏（筛选 panel）：项目（单选：全部 + 各启用项目，选项来自「报告项目配置」生效数据，标签「项目名 · key」，默认全部）、发报日期范围（RangePicker，默认近 90 天）、关键词（报告标题模糊，回车即查）、查询 / 重置；右侧「手动补传」（持上传权限可见）
  - KPI 区（筛选后 / 表格前）：本周已入库（x/y，y = 启用项目数）、累计报告（按报告项 × 发报日计，不含历史版本）、最近发报日、历史版本总数
  - 主体区（表格 panel，Tab 形态；**全部表格不分页**：按周索引取近 8 周、报告明细上限 200 条，发报日期区间为前端过滤）：
    - **Tab1 按周索引**（默认）：周分组手风琴，按所属周倒序（本周行仅周日当天起展示，周中最晚只到上周），默认全展开；每周一行组头（周标签 `2026 年第 36 周（08-31 ~ 09-06）` + 齐全度徽标：到齐绿 `2/2`，未齐橙 `1/2 待补`）；组内按启用项目逐行成行（按项目 key 字典序），行展示：报告标题（链接，缺失行为灰文案）、项目（徽标，「项目名 · key」）、发报日、来源（服务端生成 / 推送上报 / 手动补传）、版本号（vN）、操作（查看 / 获取原件）；未入库行灰显「未入库」+ 操作「立即生成」（仅持有触发权限可见）/「补传」（仅持有上传权限可见）
    - **Tab2 报告明细**：平铺表格，列：发报日期、所属周（「第 N 周」）、项目、报告标题、来源、版本、操作（查看 / 获取原件）；空态 AcEmpty「该条件下暂无报告」
  - 弹窗：**手动补传弹窗**（共用组件，通用字段与交互见 [报告配置 · 手动补传弹窗](../../报告配置/references/web-ui.md#手动补传弹窗报告模块共用)）：本模块类型固定为文档一致性校验、项目（必选，单选启用项目，按文件名识别成功时自动带入）、发报日（不可晚于今天）；识别结果提示条（「已按文件名识别：项目 \<项目名\> · 发报日 2026-08-31」/「文件名无法识别，请手动指定项目与发报日（命名规范：consistency_yyyyMMdd_项目key.md）」）；从缺失行「补传」进入时预填该项目与当周周日为发报日，并提示「已从缺口带入：项目 X · 发报日 Y」
- **布局引用**：`参见原型 assets/web/report-list.html`（DOM 结构依据：`page-blueprint/skeletons/web/list-page.vue.tpl` 可选 Tab 形态）

#### 导航关系

- 来源页：研发分组侧边菜单「研发报告 → 文档一致性报告」
- 去向页：行内「查看」→ `/subapp/devhub/report/consistency/detail/:id`；缺失行「补传」→ 手动补传弹窗（项目与发报日预填）；缺失行「立即生成」→ 直接创建生成任务
- 返回行为：浏览器返回回到列表并保持 Tab 与筛选条件
- 面包屑：首页 / 研发 / 研发报告 / 文档一致性报告

|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 筛选条件变更后点查询 | 否 | 表格 loading | 列表刷新，停留 | toast error + 按钮恢复 |
| 切换视角 Tab | 点击 Tab | 否 | 表格 loading | 切换视角，页码重置为 1 | — |

| 立即生成 | 未入库行点「立即生成」 | 是（「确认为报告项「文档一致性校验 · {项目}」创建生成任务？类型参数：回看 N 天。」） | 按钮 loading | toast「已创建生成任务，进度见「报告配置 › 报告触发配置 · 生成记录」」→ 停留本页（不跳转） | toast error（「未找到联动触发配置，请先到「报告配置」页检查」/ 存在进行中任务 / 无权限）+ 按钮恢复 |
| 获取原件 | 行内点「获取原件」 | 否 | 按钮 loading | 浏览器下载当前版本原始 .md，toast「已开始下载 {文件名}」 | toast error（无内容时「该报告无原始 Markdown 内容」）+ 按钮恢复 |

#### 表单校验（手动补传弹窗）

- 通用字段、校验规则与脏数据守卫见 [报告配置 · 手动补传弹窗](../../报告配置/references/web-ui.md#手动补传弹窗报告模块共用)；本模块差异：类型固定为文档一致性校验；项目必选（单选启用项目，校验「请选择项目」）；项目与发报日默认空，按文件名识别成功时自动带入，从缺失行「补传」进入时预填该项目与当周周日为发报日

### 报告详情

- **页面路径**：`/subapp/devhub/report/consistency/detail/:id`
- **权限编码**：
  - 路由：`devhubConsistencyReport`
- **页面类型**：详情页（阅读型）
- **区块职责**：
  - 顶部：返回链接「‹ 返回报告列表」；报告标题 + 报告类型 Tag（文档一致性校验）+ 项目 Tag
  - 历史版本警示（查看历史版本时，黄色警示条）：「当前查看历史版本 v{N}（只读），最新版本为 v{M}；切换版本不改变归档内容。」
  - 元信息头（首个 panel）：项目（徽标）、发报日、所属周、来源（服务端生成 / 推送上报 / 手动补传）、当前版本（`v1 · 共 1 版`，多版时可下拉切换历史版本；附注「重复入库版本递增，历史版本只读可查，URL 带 ?v=N 可分享」）、文件大小、入库时间、文件名（本类型独有）；右上操作（获取原件 / 返回列表）
  - 阅读区（左主体 panel）：🚨 Web 端展示**服务端渲染的 HTML 产物**（页内直出，前端仅提供排版样式，不做 Markdown 实时渲染；章节口径：本次检查范围明细 / 统计概览 / 文档三件套对齐表 / 功能覆盖度分析 / 总体摘要）；切换版本时加载文案「正在加载所选版本内容…」；内容为空时展示「报告内容为空」
  - 侧边栏（右侧大纲 panel，≥1200px 展示，窄屏折叠为顶部「大纲」按钮弹抽屉）：h2/h3 锚点目录（数据来自服务端产物大纲），当前阅读章节高亮，点击平滑滚动定位
  - 版本切换：元信息头版本下拉选择历史版本 → 正文整体切换为该版本渲染产物（只读，URL 带 `?v=N` 可分享）
- **布局引用**：`参见原型 assets/web/report-detail.html`（DOM 结构依据：`page-blueprint/skeletons/web/detail-page.vue.tpl`）

#### 导航关系

- 来源页：报告列表行内「查看」
- 去向页：无下游页面
- 返回行为：返回链接「‹ 返回报告列表」/ 浏览器返回 → 报告列表（保持原 Tab 与筛选）
- 面包屑：首页 / 研发 / 研发报告 / 文档一致性报告 / 报告详情
