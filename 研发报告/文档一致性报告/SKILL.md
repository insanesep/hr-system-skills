# 文档一致性报告

AI 文档一致性校验产物的归档与查阅中枢：校验 agent 周期性产出「文档（需求/接口/数据模型）与代码实现是否对齐」的 Markdown 报告，本模块统一接收入库、按周索引、渲染在线阅读，解决报告散落本地、历史难翻、原文阅读体验差的问题。

## 服务对象与端

- **服务对象**：PM（跟进文档与代码偏差）、研发负责人
- **Web 管理端**：按周索引与明细查询、在线阅读、手动补传与版本回溯
- **App 查阅端**：分组浏览与阅读

## 核心规则

- **校验内容**：需求文档 ↔ 代码实现的功能点覆盖核对、接口契约 ↔ 端点实现核对、数据模型文档 ↔ 实际 DDL 核对；偏差按「文档缺失 / 实现缺失 / 口径不一致」分类呈现
- **静态产物**：报告内容自包含，本模块只做归档与呈现，不重新执行校验、不重算任何指标；偏差修复回溯校验 agent 侧
- **周期归属**：按发报日所在自然周（周一为起点）建索引，与报告内部统计区间是两个字段
- **入库与版本**：agent 自动上报 + 管理员手动补传缺失周期；同类型同发报日重复入库走版本递增，旧版可溯
- **术语边界**：「文档一致性」专指文档与代码对齐检查，与销售/库存金额口径对账类「数据一致性」无关

## 页面功能概览（仅列职责，UI 风格与原型暂不产出）

| 端 | 页面 | 职责 |
| -- | ---- | ---- |
| Web | 报告列表 | 按周索引（每周各项目报告齐全度 + 缺失快捷补传）+ 明细平铺筛选 |
| Web | 报告详情 | 元信息 + 渲染正文 + 大纲锚点导航 + 版本切换 |
| App | 列表 / 详情 | 按周分组浏览、渲染阅读 |

## 关键约束

- 多项目（多代码仓）时按项目分报告归档，索引同周并置
- 原始 .md 单文件直接获取，不接入批量异步导出中心；发布告知由校验 agent 侧承担
