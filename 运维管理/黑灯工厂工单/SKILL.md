# 黑灯工厂工单

黑灯工厂三个 agent(错误日志 / 大SQL结果集修复 / 服务端bug扫描)每 3 小时按项目执行一轮巡检，产出的 P1/P2 条目统一收口为工单。**默认仅提工单**：agent 只读分诊，不修改代码、不提交推送；确为缺陷的按代码负责人进入「待认领/已指派」，业务确认类「知会留痕」。仅当项目显式开启自动修复后，符合安全边界的修复才可提交推送并进入「待复核」。研发在 Web 端完成认领 → 处理 → 复核 → 关闭的闭环。**通知默认关闭**，黑灯工厂全局与项目通知开关同时开启后才走企微应用消息按人提醒；群机器人仅保留采集/建单失败简报，同样受通知开关控制。

三个 agent 均**运行于服务端，由 Qoder SDK 创建定时调度会话驱动**。每轮复用功能排期的项目、harness 工程与代码服务仓映射拆分项目执行单元，支持按项目配置执行、自动修复与通知开关；仅维护 harness 工程、未配置代码服务仓的项目直接跳过，单项目失败不阻塞其他项目。配置与凭证由服务端按项目注入会话上下文，详见 business-rule §1.1。

其中「服务端bug扫描」agent 在报错分诊之上叠加**需求口径对照**：从 SLS 日志提取错误后，读取当前项目的 harness 工程与业务代码，评估「是不是缺陷、能不能直接修」。默认只提交待判断工单及修复建议；项目开启自动修复后，能安全修复的才直接改代码进待复核，需人为确认的仍按待判断/业务确认建单（手册见 [references/agent-bug-scan.md](references/agent-bug-scan.md)，口径见 business-rule §10）。

**人工报 bug 入口**不在本模块：任何人发现 bug 走「需求管理」提交需求类型=缺陷修复的单据，审批通过后自动向本模块建单分流（来源 `reqdefect`），本模块不提供手工新建。

> 与「错误日志管理」(日志异常报表)分工:报表 = 每日全量异常指纹聚合趋势(只读分析 + 手工标记);工单 = agent 已分诊定级定人的问题**流程闭环**(自动建单 + 状态机 + SLA)。同一指纹可能两边都出现,互相引用不重复展开。

## 端

仅 **Web 端**(管理后台,运维管理菜单)。App 端不做。

| 端 | 范围 | 目标用户 |

## 菜单与路由

菜单归属为「运维管理 → 黑灯工厂工单」，应用路由为 `/blacklight/tickets`；route.name 与菜单权限码均为 `MENU:RND:OPS:BLACKLIGHT_TICKET`，以[前端路由](../../../busyming-devhub-web/src/router/index.ts#L86)为准。详情、处理与项目配置以抽屉或弹窗承载，不额外登记菜单。

## When to Use

- 黑灯工厂 agent 每轮巡检产出需要落库跟踪,而不是发完群消息就沉底
- 服务端 bug 扫描需要对照项目 harness 与业务代码评估 SLS 错误是否为缺陷,默认仅建单,并在项目开启自动修复后按「直接修复 / 人为确认」分流
- 人工发现的 bug 经需求管理缺陷分流审批后自动建单,需要与 agent 巡检产出同一套闭环跟踪
- 待判断问题需要明确到具体研发负责人,跟踪认领与处理时长(SLA)
- 已自动修复的 commit 需要负责人复核确认或打回
- 业务确认类问题需要留痕,避免同一问题每轮重复告警
- 统计黑灯工厂的修复率、响应时长、复发率等运营指标

## Tips

- 服务端定时巡检总开关默认关闭，需显式启用；启用后可执行项目默认「执行开启、自动修复关闭、通知关闭」，三个 agent 默认只读分诊、仅提工单且不发送通知；自动修复与通知须显式开启，规则见 business-rule.md §1.1
- 每轮按项目独立执行，项目与仓库映射直接复用功能排期；仅维护 harness 工程、未配置代码服务仓的项目跳过，单项目失败不阻塞其他项目
- 工单建单来源四类:三个 agent(错误日志/大SQL结果集修复/服务端bug扫描,经内部上报工具建单)+ 需求管理缺陷分流(`reqdefect`,需求类型=缺陷修复审批通过后自动建单);Web 端不提供手工新建——**人工报 bug 走「需求管理」提交缺陷修复单据**
- 只 P1/P2 建单;P3/噪声维持 agent 侧仅计数,不进工单,防刷屏
- 同一问题(同指纹/同 mapper/同需求编号)未关闭前**不重复建单**,只追加出现轮次与最新证据;已关闭后同源复发则原单重新打开并累计复发次数,不另开新单
- 项目开启自动修复后，已自动修复项建单即「待复核」状态并带 commit 哈希,复核通过才关闭,打回则重新打开
- 通知默认关闭;黑灯工厂全局与项目通知开关同时开启后才走企微应用消息按人提醒,群机器人仅保留采集失败/建单失败简报,详见 business-rule.md §6/§8
- 工单负责人由 agent 侧判定、服务端匹配在职研发及其企微账号后落单,Web 端支持改派
