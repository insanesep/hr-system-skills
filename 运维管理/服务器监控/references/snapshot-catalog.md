# 快照采集项明细

> 归属：运维管理 / 服务器监控。本文件定义各组件快照项的采集维度（产品语义口径）；具体 OpenAPI 接口、字段映射与取值窗口以代码仓及阿里云官方文档为准，不内嵌。

## 通用口径

1. 采集窗口：触发时点近 N 分钟，窗口长度以代码仓配置为准；所有指标保留云侧返回的原始数据时点
2. 采集内容以结构化指标集合落库，展示层按组件渲染；新增采集项只需扩展清单，不改主流程
3. 敏感字段（连接串 / 账号 / 密钥）不采集；每项指标标注单位与口径来源
4. 多实例按实例清单逐项采集，实例间互不影响

## RocketMQ（云消息队列 RocketMQ 版）

| 采集维度 | 采集项 |
| ---- | ---- |
| 实例 | 运行状态、实例规格、地域 |
| 消费堆积 | Group 维度堆积消息量、最早未消费消息时间 |
| 消费能力 | 消费 TPS、消费延迟、消费失败量 |
| 异常消息 | 死信消息量、重试中消息量 |
| 订阅关系 | Group 与 Topic 订阅关系一致性（不一致时列明差异 Group） |

## Redis（云数据库 Redis 版）

| 采集维度 | 采集项 |
| ---- | ---- |
| 资源水位 | 已用内存与内存使用率、已用连接数与连接数使用率、CPU 使用率 |
| 流量 | QPS、网络进出流量 |
| 健康度 | 命中率、窗口内慢日志条数、Key 总量 |
| 实例 | 运行状态、引擎版本、架构形态（标准 / 集群）、地域 |

## RDS（云数据库 RDS）

| 采集维度 | 采集项 |
| ---- | ---- |
| 资源水位 | CPU 使用率、内存使用率、磁盘使用率、IOPS |
| 会话 | 当前连接数、活跃连接数、锁等待数 |
| SQL 健康 | 窗口内慢 SQL 条数与样例（样例脱敏截断） |
| 高可用 | 主备复制延迟、备库状态 |
| 实例 | 运行状态、实例规格、地域 |

## Pod（容器服务 ACK）

| 采集维度 | 采集项 |
| ---- | ---- |
| 工作负载 | Deployment / StatefulSet 期望副本数、可用副本数、滚动更新状态 |
| Pod 实例 | 应用维度 Pod 列表与状态（Running / Pending / CrashLoopBackOff 等）、各 Pod 重启计数、异常 Pod 最近日志尾部（截断） |
| 集群事件 | 窗口内 K8s Warning 事件 |
| 弹性伸缩 | HPA 当前副本 / 期望副本与指标水位 |
| 节点 | 节点 CPU / 内存水位、NotReady 节点清单 |
