# 服务器监控

> 对应脑图「服务器监控」节点：服务器异常快照；节假日监控快照；错误及黑灯工厂关联快照。

面向运维与研发的服务器状态留痕工具：把「巡检 agent 看一眼就过」的瞬时检查升级为**可回溯的快照档案**——日常异常自动留存快照、节假日保障期加密留存、重大异常时自动打包关联证据（同时窗错误日志指纹 + 黑灯工厂工单）。

## 服务对象与端

- **服务对象**：运维、研发负责人
- **仅 Web 端**：管理后台运维域

## 核心逻辑

### 三类快照（对应脑图）

| 快照 | 触发 | 内容 |
| ---- | ---- | ---- |
| 服务器异常快照 | 巡检命中阈值即留存 | 内存水位 / OOMKilled 重启 / CPU / 磁盘 / 慢查询清单等巡检项原始值 + 判定结论 |
| 节假日监控快照 | 节假日/大促等特殊保障期，按更密频率定时留存 | 全量巡检项定期快照（无论是否异常），供保障期回看曲线 |
| 错误及黑灯工厂关联快照 | 重大异常（如 OOM、错误率突增）发生时自动打包 | 服务器快照 + 同时间窗错误日志指纹清单 + 黑灯工厂工单引用，三位一体证据包 |

### 通用规则

- 快照为**只追加**留痕：生成后不可编辑，只读查阅；保留期可配，过期独立任务清理
- 巡检项与阈值收口配置（服务清单、内存水位线、慢查询阈值等），不因单服务硬编码
- 命中重大异常时联动 `运维管理/黑灯工厂管理` 建单（引用关联快照为证据，不重复采集）
- 告警走按人提醒；节假日保障期可配置额外通知对象

## 页面功能概览（仅列职责，UI 风格与原型暂不产出）

| 页面 | 职责 |
| ---- | ---- |
| 快照列表 | 类型/服务/时间筛选；异常级标识；关联证据包入口 |
| 快照详情 | 巡检项原始值与结论 + 趋势对比（同服务历史快照）+ 关联区（错误指纹/工单只读引用） |
| 保障期配置 | 节假日日历与加密频率、巡检项与阈值、通知对象 |

## 待定口径（评审清单）

- 快照数据结构：各巡检项原始值的统一 schema（随巡检 agent 演进）
- 节假日日历来源：手工维护 vs 对接节假日服务
- 与黑灯工厂建单联动的触发条件白名单

## 关联模块

| 模块 | 关系 |
| ---- | ---- |
| `运维管理/错误日志管理` | 关联快照的异常指纹来源 |
| `运维管理/黑灯工厂管理` | 关联快照的工单来源与重大异常建单去向 |
| `研发报告/故障报告` | 故障证据引用源 |
