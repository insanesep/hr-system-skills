# 服务器监控

> 归属：运维管理

## 目标

事故与异常发生的当下，自动对核心依赖组件（阿里云 RocketMQ / Redis / RDS / ACK Pod）抓取一份**运行现场快照**落库，替代「故障时临时登控制台截图、事后现场丢失」的取证方式，为故障定位、复盘改进与值守巡检提供可回溯的结构化证据。

- 告警触发：服务器与中间件告警命中时，自动留存触发时点前后窗口的现场快照
- 节假日 / 大促值守：按排定时点自动巡检快照，预防性留痕
- 关联取证：错误日志命中阈值、黑灯工厂建单、故障登记时，关联同窗口快照作为证据附件
- Web 端查阅快照详情、跳转云控制台深挖、导出归档

## 端

仅 **Web 端**（管理后台）。App 端不做。

| 端 | 范围 | 目标用户 |
|---|---|---|
| Web | 运维管理 → 服务器监控：快照列表 + 快照详情 + 手动触发弹窗 | 研发、运维、技术负责人 |

## Prerequisites

- [产研人员管理 · 身份](../../../研发管理/产研人员管理/references/business-rule.md#identity)及[权限边界](../../../研发管理/产研人员管理/references/permission-rules.md#boundaries)：产研职责身份只读引用，不替代菜单、手动采集与导出权限，不回写历史经办快照。
- [域及项目管理 · 清单](../../../研发管理/域及项目管理/references/business-rule.md#source)及[执行映射](../../../研发管理/域及项目管理/references/business-rule.md#execution-mapping)：已确认归属对照，无项目证据只域级；实例、应用、命名空间及云监控坐标仍按原采集配置，不能由参与关系扩大云访问。

## 名词约定

| 名词 | 定义 |
|---|---|
| 快照 | 一次触发产生的现场留存记录，含触发信息与全部组件采集项 |
| 快照项 | 快照内单个组件实例的一份采集结果（结构化指标集合 + 采集状态） |
| 触发源 | 产生快照的来源：告警触发 / 关联触发 / 定时巡检 / 手动补抓 |
| 采集窗口 | 快照指标取值的时间窗口（触发时点近 N 分钟），窗口长度以代码仓配置为准 |
| 证据封存 | 被故障报告或黑灯工单引用的快照进入封存态，不随保留期清理 |

## 业务流程

**采集链路（系统）**：触发源命中 → 生成快照主记录 → 按实例清单并行采集各组件快照项 → 落库（单项失败不阻塞整体）→ 整体状态收口（成功 / 部分失败 / 失败）→ 命中关联场景时在来源单（故障单 / 黑灯工单）证据区登记引用 → 采集执行留痕。采集任务参数与实现细节以代码仓为准，不内嵌。

**使用链路（研发 / 运维）**：Web「运维管理 → 服务器监控」→ 筛选（触发源 / 组件 / 状态 / 时间窗）→ 命中行 → 详情按组件分 Tab 查看快照项 → 跳转云控制台深挖 → 复盘时在故障报告关联快照 → 需要时导出归档。

## 业务规则

1. **云厂商基线**：阿里云。组件映射：云消息队列 RocketMQ 版、云数据库 Redis 版、云数据库 RDS、容器服务 ACK；节点与基础水位取云监控。采集通道为阿里云 OpenAPI 与 ACK API，具体接口、字段口径以代码仓及阿里云官方文档为准，不内嵌
2. **实例清单配置化**：采集对象以配置登记的实例清单为准（组件类型 + 实例标识 + 归属应用 / 命名空间 + 地域），支持多实例、多地域；清单变更即时生效，不在文档枚举
3. **触发源四类**：
   - 告警触发：服务器与中间件告警事件命中（如 Pod 反复重启、节点水位超阈值、消息堆积超阈值、RDS 水位超阈值），自动生成事故现场快照
   - 关联触发：错误日志报表命中阈值、黑灯工厂建单、故障登记时，触发或直接引用同窗口快照作为证据
   - 定时巡检：节假日与大促值守窗口按排定的时点自动生成快照
   - 手动补抓：Web 端对指定应用 / 组件手动触发，用于事后补取证
4. **防抖幂等**：同一触发源对同一对象在去重窗口内只生成一份快照；窗口内重复触发只追加引用关系，不重复采集
5. **失败收口**：单快照项采集失败（限流 / 超时 / 权限不足）不阻塞其他项，快照整体标记「部分失败」并逐项记录失败原因；整体失败打 ERROR 日志并标记可重试；严禁吞异常
6. **只读与封存**：快照一经生成只读，不允许编辑与删除；被故障报告 / 黑灯工单引用的快照自动进入证据封存，不受保留期清理
7. **保留期**：未封存快照保留 90 天，超期由独立清理任务每日删除（禁止与采集任务串联）
8. **敏感信息脱敏**：连接串、账号、密钥等敏感信息不进入快照内容；采集字段白名单制，展示层对疑似敏感字段脱敏
9. **租户与权限**：运维内部能力，不挂租户字段；页面访问受「运维管理」菜单权限控制
10. **数据时点标注**：快照详情必须标注采集窗口与云侧返回的数据时点，避免把监控数据延迟误判为真实现场

## 快照内容

各组件采集项明细见 [references/snapshot-catalog.md](references/snapshot-catalog.md)；指标口径与取值窗口以代码仓及阿里云官方文档为准，不内嵌。概览：

| 组件 | 采集概览 |
| ---- | ---- |
| RocketMQ | 实例状态、Group 消费堆积量与消费延迟、消费 TPS、死信 / 重试中消息量、订阅关系一致性 |
| Redis | 内存使用率、连接数使用率、QPS、CPU 使用率、命中率、窗口内慢日志、Key 总量 |
| RDS | CPU / 内存 / 磁盘 / IOPS 水位、连接数、锁等待、窗口内慢 SQL 统计、主备复制延迟 |
| Pod | 应用维度 Pod 状态与重启计数、期望 / 可用副本、K8s Warning 事件、HPA 状态、节点水位 |

## AC 验收清单

### 技术冒烟

- [ ] 告警事件命中后自动生成快照，各组件快照项落库完整
- [ ] 单组件采集失败时整体标记「部分失败」并留失败原因，其余项不受影响
- [ ] 同一触发源对同一对象在去重窗口内重复告警只生成一份快照
- [ ] 定时巡检快照按排定时点生成
- [ ] 超保留期未封存快照被独立清理任务删除，已封存快照保留
- [ ] 阿里云 OpenAPI 限流 / 超时场景有退避重试且全程可观测

### 业务验收（按角色）

运维 / 研发：

- [ ] 进入「运维管理 → 服务器监控」能看到快照列表与统计卡
- [ ] 详情页按组件分 Tab 展示指标，标注采集窗口与数据时点
- [ ] 能对指定应用手动触发快照并实时查看结果
- [ ] 故障报告与黑灯工单中能关联快照并跳转溯源
- [ ] 导出内容与列表筛选一致

无权限角色：

- [ ] 菜单不可见
- [ ] 直接访问路由走 403

### 可观测性

- [ ] 每次采集留痕（触发源 / 快照项数 / 成功数 / 失败数 / 耗时）
- [ ] 操作日志覆盖手动触发 / 导出

## 风险与边界

| 风险 | 控制措施 |
|---|---|
| OpenAPI 限流导致采集失败 | 单快照项失败隔离 + 限流退避重试 + 部分失败可见可重抓 |
| 实例清单与实际资源漂移（漏采） | 清单集中登记并定期核对；告警事件按实例标识匹配清单，匹配不到时记录并告警 |
| 故障期间阿里云管控面不可用 | 接受该窗口采集失败并留痕，事后手动补抓；快照非唯一证据源（另有日志与链路数据） |
| 云监控数据延迟导致快照「不像现场」 | 详情标注采集窗口与云侧数据时点，指标以云侧返回时点为准 |
| 快照夹带敏感信息 | 采集字段白名单 + 展示脱敏；评审时强制核对 |
| 大促告警风暴产生快照洪峰 | 去重窗口 + 单对象并发上限 + 队列削峰 |

## 反模式

- ❌ 用实时查询代替落库快照（事后现场丢失，失去取证意义）
- ❌ 允许编辑 / 删除快照（证据失真）
- ❌ 单组件采集失败拖垮整体或静默吞掉（必须失败隔离 + 留痕）
- ❌ 被引用的快照随保留期清理（证据封存豁免）
- ❌ 文档内嵌 API 报文 / SQL / 采集脚本（实现细节以代码仓为准，见根 AGENTS.md 内容红线）
