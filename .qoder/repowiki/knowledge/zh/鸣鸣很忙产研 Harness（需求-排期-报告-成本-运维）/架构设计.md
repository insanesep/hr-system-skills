仓库按二级子域（排期管理、研发报告、成本管理、运维管理）划分，每个三级功能模块独立成目录并自带 `SKILL.md`；跨子域的共享契约集中在对应子域的 `references/` 或报告配置中心，避免在功能间互相复制。

- 文档层：所有自然语言描述统一放在 `SKILL.md` / `AGENTS.md` / `references/` / `assets/`，代码、SQL、接口报文等实现细节不内嵌，仅以链接指向外部仓。
- 数据/流程耦合点：排期管理通过 git 提交驱动功能卡片与发布；研发报告复用排期的项目↔代码仓映射生成多维报告；成本管理中的 Token 用量与人员范围与报告配置共用人员名单；运维管理的黑灯工厂与错误日志可被研发报告的故障报告关联，形成「采集→取证→工单→复盘」的证据链。
- 权限与渲染：报告类能力统一由研发报告子域的报告配置中心提供类型定义、触发生成、版本、渲染与权限模型，其他子域仅消费该契约。
