- 业务规则与页面结构分离：`SKILL.md` 仅给出高层概览与产品背景，具体判定口径下沉到 `references/business-rule.md`，UI 细节下沉到 `references/page-structure.md`，卡片不复述枚举值而是指向真源。
- 权限编码采用三段式命名：父权限 `MENU:RND:MANAGE` 派生 `USAGE_EVENTS` / `USAGE_REPORT` / `USAGE_CATALOG` 子权限，按钮级权限使用 `BTN:RND:MANAGE:<PAGE>:<ACTION>` 格式。
- 功能编码遵循「模块.页面.动作」三段全大写命名，App 端统一加 `APP` 前缀，并在 `business-rule.md` 中集中登记本模块三条编码与其他模块示例。
- 阈值类常量（频次 50/500、人次 3/20、角色占比 0.70、统计周期 WEEK）在 `SKILL.md` 与 `business-rule.md` 两处保持一致，变更需发版而非运行时配置。
- 页面原型与文档双向锚定：每个 HTML 原型在 `page-structure.md` 中以表格形式列出路由、权限码、区块职责、字段列与按钮权限码，新增页面需同时补齐三类文件。
