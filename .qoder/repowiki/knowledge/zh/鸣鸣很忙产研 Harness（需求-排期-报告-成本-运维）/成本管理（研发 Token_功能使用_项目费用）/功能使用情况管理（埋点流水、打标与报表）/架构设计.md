本模块为纯文档型 SKILL，定义「成本管理」域下功能使用情况管理的业务契约与页面原型，不承载实现代码。
- 入口与总纲：`SKILL.md` 作为唯一对外契约，声明端（仅 Web 管理后台）、4 个实体（事件流水 / 功能目录 / 打标结果快照 / 菜单聚合快照）、3 个子页面路由与权限码、自动注册机制与打标阈值。
- 真源分层：`references/business-rule.md` 沉淀后端判定口径（埋点上报规则、三维度打标算法、聚合周期、重算策略、报表计算、流水查询边界、权限与账套隔离、未归类处理、异常降级、SDK 接入与紧急熄火、铺点优先级），是业务规则的权威来源；`references/page-structure.md` 仅描述 3 个 HTML 原型的区块职责、字段列与按钮权限码，视觉细节统一引用前端页面规范。
- 原型资产：`assets/usage-events.html`、`usage-report.html`、`_shell.css` 提供事务流水明细、使用情况报表的原型产物，由 `page-structure.md` 逐项对齐。
- 依赖方向：本 SKILL → references（规则真源）→ assets（原型）；实现代码不在本目录，所有接口契约、数据模型、索引以 busyming-portal 代码仓为准，本模块只引用不内嵌。
