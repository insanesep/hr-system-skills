- 页面原型统一使用 page-blueprint v3.4.0 的 Ac* 组件类名（AcCard / AcStatistic / AcFilterBar / AcTable / AcDrawer / AcModal）与 tpl-toolbar 三层结构组织布局。
- 所有颜色、字号、间距、圆角等视觉值仅通过 --ac-* CSS 自定义属性声明，禁止在样式中直接写裸色值或裸像素。
- 可操作按钮通过 `data-permission="OPS_LOG_ERROR_REPORT_<ACTION>"` 标注权限码，由上层 v-permission 指令控制可见性。
- 业务状态以三态标签呈现：is-pending（待处理）、is-resolved（已处理）、is-ignored（已忽略），并在 KPI 统计卡与行内 ac-tag 上同步映射。
- 对外部系统（统一导出中心、企微告警、SLS 日志控制台）的调用在原型中以 toast 占位提示，真实逻辑下沉到后端与公共能力层。
