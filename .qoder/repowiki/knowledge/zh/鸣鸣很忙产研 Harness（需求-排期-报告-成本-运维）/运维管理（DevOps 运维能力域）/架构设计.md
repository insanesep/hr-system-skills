本模块是 DevOps 技能集下的运维管理子域，三个子模块按「发现→取证→处置」分工协作：
- 错误日志管理：每日定时扫描 ERROR/FATAL 日志，按指纹聚合为只读异常报表，提供标记处理与阈值告警。
- 服务器监控：在告警/关联触发/定时巡检/手动补抓时抓取阿里云 RocketMQ/Redis/RDS/ACK 的运行现场快照并落库，作为故障取证证据。
- 黑灯工厂管理：三个 agent（错误日志修复/大SQL结果集修复/服务端bug扫描）每轮产出的 P1/P2 问题自动建单，走认领→处理→复核→关闭的流程闭环。

跨模块关联契约：
- 错误日志报表命中阈值 → 触发服务器监控快照关联；
- 黑灯工厂建单 → 关联同窗口快照作为工单证据附件；
- 服务器监控快照被故障报告/黑灯工单引用后进入「证据封存」，豁免保留期清理。
三者共享「仅 Web 端」「运维管理菜单权限」「统一导出中心接入」「企微应用消息通知」等横切约定，但各自维护独立的 references 真源（snapshot-catalog.md / wecom-alert.md / business-rule.md + data-model.md + web-ui.md），不互相复述枚举值。
