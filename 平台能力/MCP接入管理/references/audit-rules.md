# MCP接入管理 · 审计规则

> 本文件为调用记录内容、调用结果与拒绝原因枚举、可见范围、汇总指标、保留期与导出、授权变更记录的唯一真源。
> 授权判定顺序见 [permission-rules.md §3](permission-rules.md#3-调用时授权判定)；记录字段定义见 [调用记录](data.md#8-调用记录) 与 [授权变更记录](data.md#11-授权变更记录)。

---

## 1. 记录范围

- 每一次经平台网关的 MCP 工具调用均产生一条调用记录，无论成功、拒绝或失败；工具清单拉取等握手动作不记录
- 通用记录内容为调用时间、令牌名称与前缀、持有人、客户端、领域、实际工具、目标对象、摘要、调用结果与原因、耗时；无效令牌仅保留提交令牌的前 8 位前缀，不记录明文，也不补造持有人
- 研发工具领域按 SLS 或 ARMS 工具族区分实际工具，定向查询的目标是完整 appName；工具族标识只说明调用能力，不是单应用授权项。目录调用记录实际采用的 group 与目录范围，不伪装成某个应用的查询
- 观测业务域记录调用时由 Skills 提供且经服务器配置验证后实际采用的 group；不从项目配置、Nacos discovery group 或失败目标猜测，能力未执行时不补造业务域
- 观测查询摘要记录实际工具、诊断场景（适用时）与实际采用的起止时间，包括采用默认窗口的调用；SLS 使用秒级时间，ARMS 使用毫秒级时间。目录调用只记录目录摘要，没有检索时间窗
- 返回条数与截断标记取本次能力实际返回的授权结果；Trace 详情只统计目标应用可验证归属的 Span 子集，不记录其他应用 Span 或数量；空结果、缺指标、不完整或截断均不代表全量无异常
- 数据库领域额外记录目标实例 / 库 / 表、语句摘要、返回行数、是否截断、是否命中脱敏字段
- 数据库语句摘要中的字面量替换为占位符；观测摘要不保存日志关键字、Trace 正文、指标样本或告警原文。日志与指标结果均只读并脱敏，不能因未显示数据库脱敏标记而认定观测内容未经脱敏
- 调用参数与返回内容不入审计记录，仅记录摘要信息；尚未取得的时间、条数或截断证据不补造为已执行查询
- 记录依据见 [网关调用审计](../../../../code/02-devops/busyming-devhub/busyming-devhub-service/src/main/java/io/busyming/basic/devhub/service/mcp/impl/McpGatewayServiceImpl.java)、[观测工具执行](../../../../code/02-devops/busyming-devhub/busyming-devhub-service/src/main/java/io/busyming/basic/devhub/service/mcp/support/McpObservabilityTools.java) 与 [调用记录定义](../../../../code/02-devops/busyming-devhub/busyming-devhub-domain/src/main/java/io/busyming/basic/devhub/domain/entity/mcp/McpCallRecordEntity.java)；能力证据口径遵循公共 [SLS 契约](../../../../busyming-skills-common/agent/MCP/sls/references/mcp-tools.md) 与 [ARMS 契约](../../../../busyming-skills-common/agent/MCP/arms/references/mcp-tools.md)

## 2. 调用结果与拒绝原因

| 调用结果 | 含义 |
| ---- | ---- |
| 成功 | 调用完成并返回结果，不等于取得全量观测证据 |
| 拒绝 | 平台在调用条件校验或授权判定阶段拒绝，未执行目标查询 |
| 失败 | 目标执行出错（目标不可用、超时、业务系统报错）；观测还包括该项能力所需凭据或精确指标标识解析失败，不代表已取得观测结果 |

| 拒绝原因 | 对应判定 |
| ---- | ---- |
| 令牌无效 | 令牌不存在、已过期或已吊销 |
| 超出调用频率 | 超过单令牌每分钟 60 次上限；观测另受持有人每分钟 60 次共享上限约束，观测限流服务不可用也拒绝调用 |
| 工具不可用或不受支持 | 目标工具未注册、已下线或当前不可执行；具体原因以实际调用记录为准 |
| 超出令牌授权范围 | 目标不在令牌显式勾选范围；观测工具族未被令牌勾选，或持有人相应工具分配已失效 |
| 超出分配范围 | 数据库目标不在持有人当前分配内、分配到期或库表关闭开放；观测目标不在当前云效仓成员与项目仓关系派生的范围内、应用已删除或该项能力未就绪 |
| 业务系统拒绝 | 业务系统功能 / 数据权限校验未通过 |
| 查询条件超限 | 观测查询时间不合法、跨度超过对应工具上限或条件不符合公共 [SLS 契约](../../../../busyming-skills-common/agent/MCP/sls/references/mcp-tools.md) 与 [ARMS 契约](../../../../busyming-skills-common/agent/MCP/arms/references/mcp-tools.md)；不套用所有 ARMS 能力统一时间窗 |
| 不支持的观测参数 | 调用方传入服务、独立环境、PID、地域、凭据、物理资源或工具契约之外的过滤条件；group 本身按明确代码配置和服务器白名单校验 |
| MCP 路由不匹配 | 完整应用名后缀不属于当前生产 / 非生产连接，或服务器无法确定连接身份；后缀仅用于路由，不是授权维度 |
| 应用映射不可信 | appName 前缀未匹配当前成员代码仓，或存在同名仓、多项目引用冲突；不得选择首项或切换目标兜底 |
| 观测依赖缺失 | Skills 提供的 group 未配置，或该项能力所需资源、监控依赖不可用；只影响依赖该项的能力，不将无 PID 等同于全部 ARMS 能力不可用 |
| 非只读语句 | 违反数据库只读约束 |
| 引用未授权表 | 查询引用了不可见的表 |

| 失败原因 | 说明 |
| ---- | ---- |
| 目标不可用 | 服务端、阿里云或数据库实例不可达；观测认证、只读权限或凭据依赖不可用时记录能力失败，不返回空成功 |
| 查询超时 | 超过数据源超时上限 |
| ARMS 指标标识不可用 | JVM 原始指标或 JVM 诊断兜底未取得精确唯一 PID；仅该指标能力失败，Trace、告警与已有 Prometheus 证据不受影响 |
| ARMS 应用重名 | 依赖 PID 的查询按完整应用名与地域命中多个应用，拒绝选取 PID；不能据此替换目标 |
| 目标执行错误 | 目标系统返回错误，非观测错误文案原样记录；观测错误仅记录安全的能力失败说明，不透出凭据或原始响应 |

- 工具分配收回或到期不吊销令牌本身；下一次受影响工具调用记录为拒绝，令牌中其他有效范围继续按原规则执行
- 单令牌限流服务异常沿用放行并告警规则；观测持有人限流不可用则拒绝，不能把两者混写为统一放行或统一拒绝

## 3. 可见范围

- 令牌使用者：仅在令牌详情页查看本人该令牌的调用记录，近 30 天
- 权限管理员、MCP 管理员、数据源管理员：在调用审计页查看全量记录；权限点见 [permission-rules.md §1](permission-rules.md#1-权限点矩阵)

## 4. 汇总指标

调用审计页按当前筛选条件汇总：

| 指标 | 口径 |
| ---- | ---- |
| 调用次数 | 筛选范围内调用记录条数 |
| 成功率 | 结果为「成功」的条数 ÷ 调用次数 |
| 拒绝次数 | 结果为「拒绝」的条数 |
| 活跃令牌数 | 筛选范围内有调用记录的令牌去重数 |
| 数据库查询次数 | 领域为数据库的调用条数 |

## 5. 保留期与导出

- 调用记录保留 180 天，到期自动清理；记录不可编辑、不可删除
- 导出按当前筛选条件生成，走导入导出中心异步任务，单次上限 10 万行，超出提示缩小时间范围；导出文件不含语句摘要以外的查询内容

## 6. 授权变更记录

- 每次分配、收回、到期自动收回、账号停用自动收回均产生一条授权变更记录
- 记录内容：变更时间、操作人（系统自动收回记「系统」）、被分配人、变更类型（分配 / 收回 / 到期收回 / 停用收回）、对象描述（领域、对象名称与粒度）、有效期、分配理由；以实际保存的变更记录展示
- 研发工具对象描述为 SLS 日志或 ARMS 应用监控工具族，不包含业务域、环境限定或完整应用名；记录只说明工具分配变化，不表示对某个应用的人工授权。数据库保持实例 / 库 / 表对象描述与原有有效期、理由规则
- 云效仓成员与项目仓关系同步只改变动态应用范围，不产生管理员工具分配，不伪装为逐应用授权变更；已注册业务工具默认可选，无需账号预分配，令牌勾选不记作管理员分配
- 工具分配收回或到期不记作令牌吊销；相关工具在令牌详情显示不可用或已超出分配范围，下一次调用拒绝，其他有效范围不变
- 存量停用范围仅限旧 DEVTOOL 资源授权，不自动升级为 SLS / ARMS 工具族分配或扩充既有令牌；数据库与 SYSTEM 业务工具范围不受影响，不将存量资源授权表现为新的工具分配
- 授权变更记录保留 3 年，不可编辑、不可删除
- 权限管理员在权限分配页按人员查看；本人可在「我的令牌」页查看本人的分配与变更
- 对象描述与变更内容依据见 [权限分配与变更记录](../../../../code/02-devops/busyming-devhub/busyming-devhub-service/src/main/java/io/busyming/basic/devhub/service/mcp/impl/McpGrantServiceImpl.java)
