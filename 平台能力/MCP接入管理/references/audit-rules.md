# MCP接入管理 · 审计规则

> 本文件为调用记录内容、调用结果与拒绝原因枚举、可见范围、汇总指标、保留期与导出、授权变更记录的唯一真源。
> 授权判定顺序见 [permission-rules.md §3](permission-rules.md#3-调用时授权判定)；记录字段定义见 [data.md §6](data.md#6-调用记录) 与 [data.md §13](data.md#13-授权变更记录)。

---

## 1. 记录范围

- 每一次经平台网关的 MCP 调用均产生一条调用记录，无论成功、拒绝或失败；工具清单拉取等握手动作不记录
- 研发工具领域额外记录业务域、目标资源（SLS 日志库 / ARMS 应用）、检索时间跨度、返回条数
- 数据库领域额外记录目标实例 / 库 / 表、语句摘要、返回行数、是否截断、是否命中脱敏字段
- 语句摘要与日志检索关键字中的字面量值替换为占位符，避免审计记录本身泄露数据
- 调用参数与返回内容不入审计记录，仅记录摘要信息

## 2. 调用结果与拒绝原因

| 调用结果 | 含义 |
| ---- | ---- |
| 成功 | 调用完成并返回结果 |
| 拒绝 | 平台在授权判定阶段拒绝，未触达目标系统 |
| 失败 | 已触达目标系统但执行出错（目标不可用、超时、业务系统报错） |

| 拒绝原因 | 对应判定 |
| ---- | ---- |
| 令牌无效 | 令牌不存在、已过期或已吊销 |
| 超出调用频率 | 超过单令牌频率上限 |
| 服务或工具已停用 | 目标服务 / 工具停用或已下线 |
| 超出令牌授权范围 | 目标不在令牌授权范围内 |
| 超出分配范围 | 目标已不在持有人当前权限分配范围内、分配已到期，或资源 / 库表已关闭开放 |
| 业务系统拒绝 | 业务系统功能 / 数据权限校验未通过 |
| 查询条件超限 | 日志检索或调用链查询的时间跨度、保留期超出 [devtool-rules.md](devtool-rules.md) 限制 |
| 非只读语句 | 违反数据库只读约束 |
| 引用未授权表 | 查询引用了不可见的表 |

| 失败原因 | 说明 |
| ---- | ---- |
| 目标不可用 | 服务端、阿里云或数据库实例不可达 |
| 查询超时 | 超过数据源超时上限 |
| 目标执行错误 | 目标系统返回错误，错误文案原样记录 |

## 3. 可见范围

- 令牌使用者：仅在令牌详情页查看本人该令牌的调用记录，近 30 天
- 权限管理员、MCP 管理员、数据源管理员：在调用审计页查看全量记录；权限点见 [permission-rules.md §1](permission-rules.md#1-权限点矩阵)

## 4. 汇总指标

调用审计页按当前筛选条件汇总：

| 指标 | 口径 |
| ---- | ---- |
| 调用次数 | 筛选范围内调用记录条数 |
| 成功率 | 结果为「成功」的条数 ÷ 调用次数 |
| 拒绝次数 | 结果为「拒绝」的条数 |
| 活跃令牌数 | 筛选范围内有调用记录的令牌去重数 |
| 数据库查询次数 | 领域为数据库的调用条数 |

## 5. 保留期与导出

- 调用记录保留 180 天，到期自动清理；记录不可编辑、不可删除
- 导出按当前筛选条件生成，走导入导出中心异步任务，单次上限 10 万行，超出提示缩小时间范围；导出文件不含语句摘要以外的查询内容

## 6. 授权变更记录

- 每次分配、收回、到期自动收回、账号停用自动收回均产生一条授权变更记录
- 记录内容：变更时间、操作人（系统自动收回记「系统」）、被分配人、变更类型（分配 / 收回 / 到期收回 / 停用收回）、对象（领域 + 对象名称 + 粒度）、环境限定、有效期、分配理由
- 授权变更记录保留 3 年，不可编辑、不可删除
- 权限管理员在权限分配页按人员查看；本人可在「我的令牌」页查看本人的分配与变更
