# MCP接入管理 · 业务规则

> 本文件为模块通用规则真源：角色边界、接入领域与服务目录、令牌规则、MCP 配置生成、异常场景。
> 令牌状态流转见 [state-machine.md](state-machine.md)；权限点、权限分配、调用时授权判定与限流见 [permission-rules.md](permission-rules.md)；研发工具（SLS / ARMS）见 [devtool-rules.md](devtool-rules.md)；数据库只读查询见 [datasource-rules.md](datasource-rules.md)；调用审计见 [audit-rules.md](audit-rules.md)；实体字段见 [data.md](data.md)。

---

## 1. 角色与职责边界

| 角色 | 职责 |
| ---- | ---- |
| 令牌使用者（研发、产品等 DevHub 用户） | 自助生成令牌、在本人已分配的权限内勾选授权范围、获取 MCP 配置、续期 / 编辑授权范围 / 吊销本人令牌、查看本人令牌调用记录 |
| 权限管理员（持有分配权限的人员） | 为人员分配 / 收回业务系统、研发工具、数据库权限，设置有效期与分配理由，查看授权变更记录 |
| MCP 管理员 | 维护 MCP 服务目录（登记、工具同步、启停）与研发工具资源目录（同步、业务域归属、开放）；查看全部令牌并可吊销；查看全量调用审计并导出 |
| 数据源管理员 | 登记数据库实例、维护库表开放、行数与超时上限、敏感字段脱敏绑定 |

- 令牌生成为自助操作，不设审批；安全边界由「权限分配」（权限管理员按人分配）与「调用时实时判定」共同保证，见 [permission-rules.md §2](permission-rules.md#2-权限分配) 与 [§3](permission-rules.md#3-调用时授权判定)
- 职责分离：MCP 管理员、数据源管理员决定「什么可以被分配」（启用、开放），权限管理员决定「分配给谁」
- 本模块只负责接入、授权、配置下发与审计；各 MCP 工具背后的业务语义、接口契约以对应系统真源为准，本模块不复述
- 本模块调用记录为令牌级审计明细；研发周报「MCP 工具用量」的统计口径仍以人员产出报告真源为准，两者不互相替代

## 2. 接入领域与服务目录

### 2.1 三大接入领域

| 领域 | 覆盖范围 | 工具性质 |
| ---- | ---- | ---- |
| 业务系统 | 集团各业务系统（商品、采购、营运、门店、客服、系统等）对外能力，按业务系统拆分为独立 MCP 服务 | 以查询类为主；写入类工具须在服务目录中显式标注 |
| 研发工具 | 阿里云 SLS 日志检索、ARMS 应用监控与调用链，以及其他已登记的研发运维工具；资源按业务域划分，规则见 [devtool-rules.md](devtool-rules.md) | 只读查询 |
| 数据库 | 已登记数据库实例的库清单、表清单、表结构查看与只读数据查询 | 只读，规则见 [datasource-rules.md](datasource-rules.md) |

### 2.2 服务登记

- 一个 MCP 服务归属且仅归属一个领域；服务标识全局唯一，登记后不可修改
- 登记项：领域、服务名称、服务标识、服务说明、服务地址、服务负责人、启停
- 数据库领域只有一个内置服务「数据库只读查询」，不可新增或删除，其可分配对象由数据源管理维护
- 研发工具服务（SLS 日志、ARMS 应用监控）的可分配对象为研发工具资源目录中已开放的资源

### 2.3 工具同步与标注

- 服务启用前须执行「同步工具清单」，从服务端拉取当前工具名称与说明；同步结果覆盖工具清单，新出现的工具默认**停用**，需管理员确认后启用
- 服务端已下线的工具在同步后标记「已下线」，已授权该工具的令牌自动失去该工具权限，不影响令牌其余授权
- 每个工具标注操作类型：查询 / 写入；写入类工具在令牌授权勾选时单独分组并提示「写入类工具将以你的身份修改业务数据」
- 研发工具、数据库领域不允许标注写入类工具

### 2.4 启停

- 服务停用：所有令牌立即无法调用该服务，授权关系保留，重新启用后恢复
- 工具停用：同上，仅作用于单个工具
- 停用的服务与工具在生成令牌时不可勾选

## 3. 令牌规则

### 3.1 生成

- 必填：令牌名称（本人未吊销令牌中唯一）、有效期；授权范围可为空，未分配权限也可生成空权限令牌
- 授权范围只能从本人当前已分配且可用的权限中勾选，勾选粒度不细于分配粒度：分配到业务域的可整域勾选或逐个资源勾选，分配到单个资源的只能勾选该资源，见 [permission-rules.md §2](permission-rules.md#2-权限分配)
- 空权限令牌不能调用任何工具；管理员后续分配权限后，使用人员需自行编辑令牌授权范围，权限不会自动加入令牌
- 有效期可选：7 天 / 30 天 / 90 天 / 180 天，默认 90 天；不提供永久有效
- 令牌明文**仅在生成成功时展示一次**，平台只保存不可逆摘要与前 8 位展示前缀；关闭结果弹窗后无法再次查看，遗失只能吊销后重新生成
- 每人同时处于「生效中」的令牌上限 10 个，达到上限时禁止生成并提示先吊销不用的令牌

### 3.2 续期

- 仅「生效中」令牌可续期；续期以当前时间为起点重新计算有效期（同样只能选 7 / 30 / 90 / 180 天），明文不变
- 已过期、已吊销令牌不可续期，需重新生成

### 3.3 编辑授权范围

- 仅「生效中」令牌可编辑授权范围，明文与有效期不变，保存后对下一次调用立即生效
- 授权范围编辑规则与生成时一致；令牌名称可同时修改

### 3.4 吊销与自动失效

- 本人可吊销本人令牌；MCP 管理员可吊销任意令牌，须填写吊销原因
- 以下情况系统自动吊销持有人全部生效中令牌：DevHub 账号停用、人员离职（以用户权限中心账号状态为准）
- 吊销立即生效且不可恢复；状态与触发条件详见 [state-machine.md](state-machine.md)

### 3.5 到期提醒

- 生效中令牌在到期前 7 天、前 1 天各向持有人发送一次企微提醒，内容含令牌名称、到期时间与续期入口
- 管理员吊销他人令牌时，向持有人发送企微通知，内容含令牌名称与吊销原因
- 消息发送走消息通知中心，场景与渠道以其真源为准

### 3.6 使用记录

- 令牌每次被调用（无论成功、拒绝或失败）均刷新「最近使用时间」，并产生一条调用记录，见 [audit-rules.md](audit-rules.md)

## 4. MCP 配置生成

- 配置按令牌**已授权的领域**生成，每个领域对应一个 MCP 服务条目（业务系统 / 研发工具 / 数据库），未授权的领域不出现在配置中；空权限令牌的配置不包含任何服务条目，仍展示一次性令牌明文
- 每个服务条目包含：条目名称、平台网关接入地址、认证方式（令牌）；工具清单由网关按令牌授权范围动态下发，客户端无需逐个配置工具；空权限令牌的工具清单为空
- 配置使用统一标准 MCP 格式，不提供客户端模板切换；服务名称在 devhub-mcp 后拼接当前环境标识（dev / test / pre / prod），接入地址读取当前环境配置，未填写协议时按 HTTPS 生成
- 生成成功弹窗中的配置**已填入令牌明文**，可一键复制或下载配置文件；令牌详情页中的配置以「<请填入令牌>」占位，不再展示明文
- 授权范围编辑后若新增 / 移除了领域，需在令牌详情页重新复制配置；仅领域内工具变化无需更新配置

## 5. 异常场景

| 场景 | 处理 |
| ---- | ---- |
| 生成时本人无任何已分配权限 | 各领域展示未分配提示，仍允许生成空权限令牌；令牌不能调用任何工具，获得分配后可自行编辑授权范围 |
| 授权范围内的服务 / 工具被停用或下线 | 调用该服务 / 工具时拒绝；令牌详情页对应项标「已停用」/「已下线」 |
| 持有人权限被收回或到期 | 令牌授权保留，但调用时按当前分配判定拒绝；令牌详情页对应项标「已超出分配范围」 |
| 令牌明文泄露 | 持有人或管理员立即吊销；吊销后该明文所有调用被拒绝 |
| 同步工具清单失败（服务端不可达） | 保留上次同步结果，提示「同步失败：服务不可达」，可重试 |
| 数据库实例连接失败 | 见 [datasource-rules.md §6](datasource-rules.md#6-异常场景) |
