# MCP接入管理 · 业务规则

> 定义职责、已注册工具目录、令牌与配置生成。授权判定见 [权限规则](permission-rules.md)，观测应用见 [研发工具规则](devtool-rules.md)，数据库见 [数据源规则](datasource-rules.md)，调用记录见 [审计规则](audit-rules.md)，数据语义见 [数据定义](data.md)。

## 1. 角色与职责边界

| 角色 | 职责 |
| ---- | ---- |
| 令牌使用者 | 自助生成令牌，显式选择有效工具范围，获取 MCP 配置，续期、编辑与吊销本人令牌，查看本人调用记录 |
| 权限管理员 | 按人显式分配或收回 SLS/ARMS 工具族及数据库实例、库、表权限，维护有效期与理由，查看授权变更 |
| MCP 管理员 | 查看与同步观测应用及云效仓成员事实，核对项目归属、分组和快照；查看全部令牌并按权限吊销；查看全量审计与导出 |
| 数据源管理员 | 登记只读数据源、同步与开放库表、维护行数超时上限和字段脱敏绑定 |

- 令牌生成为自助操作，不设审批，但至少选择一项有效 scope。SYSTEM 已注册业务工具默认可选，观测与数据库按本人有效分配选择；实际调用仍逐次授权。
- 权限管理员控制观测工具族许可与数据库分配，不人工分配应用；MCP 管理员同步应用和成员事实，不按标签、资源组或名称规则开放资源。
- 数据源管理员仍决定数据库哪些库表可被分配；项目代码服务仓与观测分组由项目真源维护，不在本模块另建归属规则。
- 本模块负责接入、授权、配置与审计，不替代业务工具自身契约。令牌级审计不替代人员产出报告的 MCP 用量统计。

## 2. 接入领域与工具目录

### 2.1 三大接入领域

| 领域 | 覆盖能力 | 权限边界 |
| ---- | ---- | ---- |
| SYSTEM 业务工具 | 当前已注册内置业务工具，包括已接入的业务查询或写入能力 | 默认可选但令牌必须显式勾选，执行遵守工具自身业务权限 |
| DEVTOOL 研发工具 | SLS 日志查询与 ARMS 调用链、诊断、指标 | 管理员显式授予工具族，令牌显式选择，应用范围由有效仓成员事实派生 |
| DATABASE 数据库 | 已登记实例的库表清单、结构查看与只读查询 | 维持实例、库、表分配及开放、脱敏、行数和超时约束 |

### 2.2 已注册工具目录

- 工具目录是当前服务器已注册能力的展示概念，不是可登记第三方服务的数据库实体。
- SYSTEM 可选项由服务器已注册内置工具生成，不能据业务系统名称、云产品接口或旧原型编造服务和工具。
- DEVTOOL 只有 SLS、ARMS 两个授权工具族，分别覆盖已注册的三个日志工具与五个观测工具。应用目录共用完整应用名，不作为令牌勾选资源树。
- 工具是否下发及是否可调用按当前令牌选择、有效许可和目标可用性动态判定。可选不等于已选，已选不等于当前具有应用成员范围或云能力已就绪。
- 不提供任意第三方 MCP 服务登记、地址负责人管理、远程工具同步或独立服务目录页面；不另设服务、工具登记表需求。

### 2.3 观测应用

- 完整应用名是云效代码仓名加环境后缀，每个完整名字独立，一条记录同时承载 SLS/ARMS。
- 项目代码服务仓是真源，harness 不自动成为应用仓；观测分组是服务器内部映射依据，不从 Nacos config 或 discovery 组猜测。
- 云效直接及代码组继承成员经组织资料邮箱唯一映射到启用门户用户，角色至少浏览者且状态、到期有效，才产生应用范围；不会自动产生工具 grant。
- 应用与成员每日 02:00 或手动同步，各自快照 24 小时失效。同步失败保留旧内容与旧日期、不误删；云端成员移除须下一次成功完整同步确认，确认后后续查询立即失效。
- 无项目归属、缺少分组、身份映射无效、重名或冲突默认拒绝。账号停用、工具撤销或已知到期逐次实时拒绝。

## 3. 令牌规则

### 3.1 生成

- 必填令牌名称、有效期及至少一项当前有效 scope；名称 2–32 字，在本人未吊销令牌中唯一，不允许生成空权限令牌。
- SYSTEM 现有已注册业务工具默认可选，无须管理员预分配，但必须主动勾选。观测只选择本人有效 SLS/ARMS 工具族，不选择具体应用、业务域或独立环境；数据库在本人当前分配内选择实例、库或表。
- 仅有仓成员身份不代表拥有观测工具许可；只选工具族不代表当前可访问应用。令牌表单不把动态应用范围固定为授权快照。
- 增加分配不自动加入已有令牌，使用者须自行编辑工具选择。非工具型 DEVTOOL 授权不生效，不能转换为更宽工具许可或扩展已有令牌；须管理员重新显式授工具，用户重新选择令牌范围。数据库分配不变。
- 有效期可选 7、30、90、180 天，默认 90 天，不提供永久有效。
- 明文仅在生成成功时展示一次，平台只保存不可逆摘要与前 8 位展示前缀；关闭后不可再次查看，遗失只能吊销重建。
- 每人同时生效的令牌最多 10 个，达到上限须先吊销不用的令牌。

### 3.2 续期

- 仅生效中令牌可续期，从当前时间重新计算有效期；仍只可选 7、30、90、180 天，明文不变。
- 已过期、已吊销不可续期，需重新生成；续期不扩大工具或应用范围。

### 3.3 编辑授权范围

- 仅本人且具备编辑权限可编辑生效中令牌；管理员管理他人令牌不包括代选工具。
- 编辑与生成采用相同有效 scope 校验，至少保留一项有效选择，可同时修改名称，明文和有效期不变。
- 保存后下一次调用按新选择判定；新增观测工具族仍须已有有效 grant。当前成员应用范围独立动态计算，不随令牌表单存储。

### 3.4 吊销与自动失效

- 本人可吊销本人生效中令牌；具备令牌管理权限的管理员可吊销他人的生效中令牌，须填 2–200 字原因。
- 账号停用、离职按门户状态自动吊销持有人生效中令牌，调用即时拒绝，不等待清理任务。
- 吊销立即生效且不可恢复；生效中、已过期、已吊销的状态与续期吊销边界沿用 [令牌状态机](state-machine.md)。生成和编辑的有效 scope 门槛以本节为准。
- 工具许可撤销或到期、仓成员失效、应用快照失效及数据库关闭开放只改变调用可用性，不自动把令牌变成另一生命周期状态。

### 3.5 到期提醒

- 生效中令牌在到期前 7 天、前 1 天向持有人发送一次企微提醒，包含名称、到期时间与续期入口。
- 管理员吊销他人令牌时通知持有人，包含名称与原因；消息走既有通知能力，通知失败不恢复令牌。

### 3.6 使用记录

- 已识别令牌的调用无论成功、拒绝或失败均刷新最近使用时间，并按 [审计规则](audit-rules.md)产生调用证据。
- 观测审计按工具族与完整 appName 记录目标，不以独立业务域或环境 grant 代替授权证据。

## 4. MCP 配置生成

- 客户端配置使用当前环境的统一 DevHub MCP 网关与令牌认证，工具清单由网关按令牌选择和当前可用范围动态下发，不按每个业务系统登记独立第三方服务。
- 数据库专用入口仅提供数据库能力，仍保持相同令牌、分配、开放与只读校验，不能绕过统一安全边界。
- 条目名称与接入地址按当前部署信息生成，缺协议时按 HTTPS 处理；配置名称不能替代观测服务器的真实生产或非生产身份声明。
- 生成结果可一次性填入令牌明文供复制下载；详情页只提供令牌占位，不再回显明文。配置不包含云密钥、PID、物理资源坐标或逐应用授权。
- 生产与非生产观测连接按完整应用后缀路由；调用前核验服务器声明，不从连接昵称、本地配置或缺少连接反推身份。预发和灰度保持不同完整应用名。
- 仅工具选择变化时网关动态更新；不需要在客户端逐应用配工具，也不能通过客户端配置扩展授权。连接发现与执行遵循公共 [SLS 契约](../../../../busyming-skills-common/agent/MCP/sls/references/mcp-tools.md)和 [ARMS 契约](../../../../busyming-skills-common/agent/MCP/arms/references/mcp-tools.md)。

## 5. 异常场景

| 场景 | 处理 |
| ---- | ---- |
| 未选择有效 scope | 阻止生成或保存，提示至少选择一项当前有效权限；不生成空权限令牌 |
| 无观测或数据库分配 | 可显式选择现有有效 SYSTEM 工具；观测或数据库须取得对应分配 |
| 工具 grant 收回或到期 | 令牌选择可保留为不可用项，后续调用立即拒绝；不会扩大其他权限 |
| 仓成员失效或快照超时 | 当前应用不再可查，不自动授予其他应用；工具族与令牌状态不因此升降 |
| 云端成员同步失败 | 保留旧内容与旧日期，24 小时上限后拒绝，不当作成功移除或刷新 |
| 应用归属、分组或名称冲突 | 拒绝相关目标，不能靠人工开放或切换环境绕过 |
| SLS、Prometheus、PID 的单能力不可用 | 仅影响依赖能力，报告缺项与覆盖限制，不以空值证明健康 |
| 令牌泄露 | 本人或管理员吊销，之后该明文调用全部拒绝 |
| 数据库连接或库表同步异常 | 沿用数据源规则，不改变数据库授权及令牌生命周期 |
