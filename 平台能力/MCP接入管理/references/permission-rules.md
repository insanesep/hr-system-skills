> 本文件为权限点矩阵、权限分配、调用时授权判定、业务系统身份透传与限流的唯一真源。
> 角色职责见 [business-rule.md §1](business-rule.md#1-角色与职责边界)；研发工具资源的业务域归属与开放见 [devtool-rules.md §2](devtool-rules.md#2-业务域与资源目录)；数据库库表开放见 [datasource-rules.md §2](datasource-rules.md#2-库表开放)。

## 2. 权限分配

### 2.1 基本原则

- 使用人员在生成 / 编辑令牌时，**只能选择已分配给本人且当前可用的权限**；未被分配任何权限的人员不能生成令牌
- 权限按人分配；可一次选择多人批量分配
- 权限分配是令牌授权的上限：令牌授权范围 ⊆ 本人当前分配范围；分配收回后令牌中超出部分立即不可调用

### 2.2 分配粒度

| 领域 | 可分配粒度 | 说明 |
| ---- | ---- | ---- |
| 业务系统 | 服务 / 单个工具 | 分配服务即包含该服务下全部已启用的查询类工具；写入类工具必须逐个分配 |
| 研发工具 · SLS 日志 | 业务域（可限定环境）/ 单个日志库 | 分配业务域即包含该域下全部已开放日志库，含之后开放的日志库 |
| 研发工具 · ARMS 应用监控 | 业务域（可限定环境）/ 单个应用 | 同上，单位为 ARMS 应用 |
| 数据库 | 实例 / 库 / 表 | 分配实例或库即包含其下全部已开放的表，含之后开放的表 |

- 业务域限定环境可选：全部环境 / 仅生产 / 仅非生产（预发、测试）
- 只有满足前提的对象才可被分配：服务与工具为启用状态；研发工具资源已归属业务域且为开放状态（见 [devtool-rules.md §2](devtool-rules.md#2-业务域与资源目录)）；库表为开放状态（见 [datasource-rules.md §2](datasource-rules.md#2-库表开放)）
- 研发工具具体可用的操作（日志检索、调用链查询等）由服务目录中对应服务的已启用工具决定，分配只决定可访问的资源范围

### 2.3 分配理由

- 以下高风险分配须填写分配理由（2–200 字）：写入类工具、生产环境数据库的实例 / 库 / 表、生产环境的研发工具资源（含环境限定为全部环境或仅生产的业务域分配）
- 分配理由记入授权变更记录，见 [audit-rules.md §6](audit-rules.md#6-授权变更记录)

### 2.4 有效期与收回

- 每次分配可设置有效期：长期 / 截止日期；到达截止日期次日 00:00 自动收回
- 权限管理员可随时收回任一分配项；收回、到期均立即生效
- 被分配人账号停用或离职时，其全部分配自动收回（与令牌自动吊销同时发生）
- 批量分配只追加不覆盖；同一对象重复分配时以最后一次的有效期与理由为准

### 2.5 通知

- 分配、收回、到期自动收回后，向被分配人发送企微通知，内容为本次变化摘要（新增 / 移除的对象与有效期）
- 分配到期前 3 天向被分配人发送一次到期提醒

## 3. 调用时授权判定

每次调用按以下顺序判定，任一不满足即拒绝并记录对应拒绝原因（拒绝原因枚举见 [audit-rules.md §2](audit-rules.md#2-调用结果与拒绝原因)）：

1. 令牌存在且状态为「生效中」
2. 未超出调用频率上限（见 [§5](#5-限流)）
3. 目标服务、工具均为启用状态
4. 目标对象（服务 / 工具、研发工具资源、库表）在令牌授权范围内
5. 目标对象仍在持有人**当前**权限分配范围内且未到期，研发工具资源与库表仍为开放状态
6. 业务系统领域：业务系统自身的功能与数据权限校验通过（见 [§4](#4-业务系统身份透传)）
7. 研发工具领域：查询条件符合 [devtool-rules.md §3](devtool-rules.md#3-sls-日志检索规则) 与 [§4](devtool-rules.md#4-arms-应用监控查询规则)
8. 数据库领域：语句通过只读约束与库表校验（见 [datasource-rules.md §3](datasource-rules.md#3-只读约束)）

## 4. 业务系统身份透传

- 业务系统工具一律以**令牌持有人身份**调用业务系统，业务系统按持有人的功能权限与数据权限（行权限、列权限）返回结果，本模块不放大任何权限
- 权限分配与令牌授权只能在持有人业务权限之内进一步收窄，不能扩大
- 业务系统返回的权限拒绝按「业务系统拒绝」记录，原因文案原样透传

## 5. 限流

- 单令牌调用频率上限默认每分钟 60 次，超出的调用直接拒绝
- 数据库领域另受单次查询行数与超时上限约束，见 [datasource-rules.md §4](datasource-rules.md#4-行数与超时上限)；研发工具领域另受检索时间跨度与返回条数约束，见 [devtool-rules.md §3](devtool-rules.md#3-sls-日志检索规则)
