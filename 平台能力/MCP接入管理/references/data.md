# MCP接入管理 · 数据定义

> 面向产品视角定义实体、字段语义与实体关系；表结构以代码仓为准，不在此描述。
> 规则真源见 [business-rule.md](business-rule.md)、[permission-rules.md](permission-rules.md)、[devtool-rules.md](devtool-rules.md)、[datasource-rules.md](datasource-rules.md)、[audit-rules.md](audit-rules.md)。

---

## 1. 实体关系

```text
MCP 服务 1 ──── N MCP 工具
用户（用户权限中心，只读引用） 1 ──── N 权限分配项
权限分配项 N ──── 1 分配对象（MCP 服务 / MCP 工具 / 业务域 / 研发工具资源 / 库表对象，按对象类型多选一）
用户 1 ──── N 授权变更记录
用户 1 ──── N 访问令牌
访问令牌 1 ──── 0..N 令牌授权项（令牌授权项须落在持有人权限分配范围内）
访问令牌 1 ──── N 调用记录
研发工具资源 N ──── 1 业务域（由归属规则或手工指定）
归属规则 N ──── 1 业务域
数据源 1 ──── N 库表对象（库 1 ──── N 表 1 ──── N 字段，从属）
字段 1 ──── 0..1 字段脱敏绑定 N ──── 1 脱敏规则（用户权限中心，只读引用）
```

## 2. MCP 服务

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
| ---- | ---- | ---- | ---- | ---- |
| 服务 ID | 主键 | 标识 | 是 | 系统生成 |
| 领域 | 所属接入领域 | 枚举 | 是 | 业务系统 / 研发工具 / 数据库，见 [business-rule.md §2.1](business-rule.md#21-三大接入领域) |
| 服务名称 | 展示名 | 文本 | 是 | ≤32 字，全局唯一 |
| 服务标识 | 服务唯一编码 | 文本 | 是 | 小写字母 / 数字 / 连字符，全局唯一，登记后不可改 |
| 服务说明 | 能力描述 | 文本 | 否 | ≤200 字 |
| 服务地址 | 平台网关转发目标 | 文本 | 是 | 数据库领域内置服务无此项 |
| 服务负责人 | 对接责任人 | 人员 | 是 | 引用用户权限中心用户 |
| 资源类型 | 研发工具服务的资源种类 | 枚举 | 否 | 仅研发工具：SLS 日志库 / ARMS 应用 |
| 启停状态 | 服务启停 | 枚举 | 是 | 启用 / 停用，新登记默认停用 |
| 最近同步时间 | 工具清单最近同步 | 时间 | 否 | 东八区 |
| 最近同步结果 | 同步是否成功 | 枚举 | 否 | 成功 / 失败（附原因） |
| 创建时间 / 更新时间 | 审计字段 | 时间 | 是 | 东八区 |

## 3. MCP 工具

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
| ---- | ---- | ---- | ---- | ---- |
| 工具 ID | 主键 | 标识 | 是 | 系统生成 |
| 服务 ID | 归属服务 | 引用 | 是 | 从属于 MCP 服务 |

| 操作类型 | 查询 / 写入 | 枚举 | 是 | 查询 / 写入；研发工具、数据库领域只能为查询 |
| 状态 | 工具可用性 | 枚举 | 是 | 启用 / 停用 / 已下线；新同步工具默认停用 |

## 4. 访问令牌

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
| ---- | ---- | ---- | ---- | ---- |
| 令牌 ID | 主键 | 标识 | 是 | 系统生成 |
| 令牌名称 | 用途说明 | 文本 | 是 | 2–32 字，持有人未吊销令牌中唯一 |
| 持有人 | 令牌归属用户 | 人员 | 是 | 生成人，不可转移 |
| 令牌前缀 | 识别用展示片段 | 文本 | 是 | 明文前 8 位，其余不保存 |
| 令牌摘要 | 校验依据 | 文本 | 是 | 不可逆，任何页面不展示 |
| 有效期 | 选择的有效期档位 | 枚举 | 是 | 7 / 30 / 90 / 180 天 |
| 生效时间 / 到期时间 | 有效期起止 | 时间 | 是 | 续期时两者均更新 |
| 状态 | 令牌状态 | 枚举 | 是 | 生效中 / 已过期 / 已吊销，见 [state-machine.md](state-machine.md) |
| 吊销方式 | 吊销来源 | 枚举 | 否 | 本人吊销 / 管理员吊销 / 账号停用自动吊销 |
| 吊销原因 | 管理员吊销说明 | 文本 | 否 | 管理员吊销时必填，≤200 字 |
| 吊销人 / 吊销时间 | 吊销审计 | 人员 / 时间 | 否 | 系统自动吊销记「系统」 |
| 最近使用时间 | 最近一次调用 | 时间 | 否 | 每次调用刷新 |
| 创建时间 / 更新时间 | 审计字段 | 时间 | 是 | 东八区 |

## 5. 令牌授权项

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
| ---- | ---- | ---- | ---- | ---- |
| 授权项 ID | 主键 | 标识 | 是 | 系统生成 |
| 令牌 ID | 归属令牌 | 引用 | 是 | 从属于访问令牌 |
| 领域 | 授权对象所属领域 | 枚举 | 是 | 同 MCP 服务领域 |
| 授权对象类型 | 授权粒度 | 枚举 | 是 | 服务 / 工具 / 业务域 / 日志库 / 应用 / 实例 / 库 / 表 |
| 授权对象 | 具体对象 | 引用 | 是 | 按类型引用 MCP 服务、MCP 工具、业务域、研发工具资源或库表对象 |
| 环境限定 | 业务域授权的环境范围 | 枚举 | 否 | 仅业务域：全部环境 / 仅生产 / 仅非生产，不得宽于对应分配 |
| 排除标记 | 服务下排除的工具 | 开关 | 是 | 勾选服务后取消个别工具时为「是」 |
| 包含后续新增 | 是否含之后开放的下级对象 | 开关 | 否 | 业务域、实例、库级授权为「是」；改为逐个勾选下级为「否」 |

- 访问令牌可以不包含令牌授权项；此时令牌不具备任何工具调用权限

## 6. 调用记录

| 字段名 | 业务含义 | 类型（产品语义） | 必填 | 取值规则 |
| ---- | ---- | ---- | ---- | ---- |
| 记录 ID | 主键 | 标识 | 是 | 系统生成 |
| 调用时间 | 请求到达时间 | 时间 | 是 | 东八区，精确到毫秒 |
| 令牌 ID / 令牌名称 / 令牌前缀 | 调用凭证 | 引用 / 文本 | 是 | 令牌无效时仅记前缀 |
| 持有人 | 调用身份 | 人员 | 否 | 令牌无效时为空 |
| 客户端 | 调用来源客户端 | 文本 | 否 | 客户端自报名称 |
| 领域 / 服务 / 工具 | 调用目标 | 枚举 / 引用 | 是 | — |
| 业务域 | 目标所属业务域 | 枚举 | 否 | 研发工具、数据库领域记录 |
| 目标对象 | 日志库 / ARMS 应用 / 实例·库·表 | 文本 | 否 | 研发工具、数据库领域记录 |
| 语句摘要 | 字面量脱敏后的语句或检索条件 | 文本 | 否 | 见 [audit-rules.md §1](audit-rules.md#1-记录范围) |
| 返回行数 | 结果行数 / 日志条数 | 数值 | 否 | 研发工具、数据库领域记录 |
| 是否截断 | 结果是否被截断或不完整 | 开关 | 否 | — |
| 是否命中脱敏 | 结果是否含脱敏内容 | 开关 | 否 | — |
| 调用结果 | 成功 / 拒绝 / 失败 | 枚举 | 是 | 见 [audit-rules.md §2](audit-rules.md#2-调用结果与拒绝原因) |
| 原因 | 拒绝或失败原因 | 枚举 + 文本 | 否 | 结果非成功时必填 |
| 耗时 | 处理耗时 | 数值（毫秒） | 是 | — |

- 记录不可编辑、不可删除，保留 180 天
