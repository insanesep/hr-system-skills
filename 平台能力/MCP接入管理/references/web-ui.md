## 页面清单

### 我的令牌

- **页面路径**：`/mcp-access/tokens`
- **权限编码**：
  - 路由：`devhubMcpToken`
  - 按钮：`devhubMcpTokenAdmin`（范围切换「全部令牌」、吊销他人令牌）
- **页面类型**：`archive-list`
- **区块职责**：
  - 工具栏：范围切换（我的令牌 / 全部令牌，后者仅管理员可见）、状态（全部 / 生效中 / 已过期 / 已吊销）、授权领域（全部 / 业务系统 / 研发工具 / 数据库）、关键词（令牌名称 / 前缀；全部令牌范围下含持有人）、查询 / 重置；右侧「我的权限」按钮与「生成令牌」主按钮，旁注「生效中 N / 10」
  - 主体区：表格列：令牌名称、令牌前缀（前 8 位 + 省略号）、持有人（仅全部令牌范围显示）、授权领域（Tag，多个；未配置时显示「未配置」）、状态（Tag：生效中绿 / 已过期灰 / 已吊销红）、到期时间（7 天内到期橙显并标「即将到期」）、最近使用时间（未使用显示 —）、创建时间、操作（详情 / 续期 / 吊销；按状态可用性见 state-machine.md）
  - 抽屉：**我的权限抽屉**（只读）：已分配权限表格，列：领域、对象（业务域分配显示「SLS 日志 · 门店 · 仅生产」形式）、粒度、有效期（长期 / 日期，7 天内到期橙显「即将到期」）、分配人；下方「最近变更」列表（本人授权变更记录近 20 条：时间、变更类型、对象、操作人）；无分配时 Empty「你还没有被分配 MCP 权限，请联系权限管理员分配」
  - 弹窗：**续期弹窗**：令牌名称（只读）、当前到期时间（只读）、续期时长（单选 7 / 30 / 90 / 180 天，默认 90）、新到期时间（随选择实时计算，只读）
  - 弹窗：**吊销确认**：本人吊销为确认框；管理员吊销他人令牌为表单弹窗，含吊销原因（必填）
  - 空态：Empty「还没有令牌，点击「生成令牌」为你的 AI Agent 接入 MCP」
- **布局引用**：`参见原型 assets/web/token-list.html`（DOM 结构依据：`busyming-skills-design/templates/web/archive-list.html`）

#### 导航关系

- 来源页：研发分组侧边菜单「平台能力 → MCP接入管理 → 我的令牌」；企微到期提醒中的续期入口；企微权限变更通知中的查看入口（直接打开我的权限抽屉）；生成令牌页成功后关闭结果弹窗
- 去向页：「生成令牌」→ 生成令牌页；行「详情」/ 令牌名称 → 令牌详情页；「我的权限」打开我的权限抽屉
- 返回行为：模块入口页，面包屑「MCP接入管理」停留本页
- 面包屑：首页 / 研发 / 平台能力 / MCP接入管理 / 我的令牌

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询 | 否 | 表格 loading | 列表刷新，停留 | Message.error + 按钮恢复 |
| 生成令牌 | 生效中令牌数 < 10（达上限时按钮置灰，Tooltip「生效中令牌已达 10 个上限，请先吊销不用的令牌」） | 否 | — | 跳转生成令牌页 | — |
| 续期 | 行状态为生效中 | 否（弹窗即确认） | 弹窗确定按钮 loading | Message.success「令牌「{名称}」已续期至 {日期}」→ 关弹窗并刷新行 | Message.error（令牌已失效等）+ 弹窗保留、按钮恢复 |
| 吊销（本人） | 行状态为生效中 | MessageBox「吊销后使用该令牌的 Agent 将立即无法调用，且不可恢复，确认吊销？」 | 确认按钮 loading | Message.success「令牌「{名称}」已吊销」→ 刷新列表 | Message.error + 按钮恢复 |
| 吊销（管理员） | 全部令牌范围、行状态为生效中 | 吊销原因弹窗即确认 | 弹窗确定按钮 loading | Message.success「已吊销「{持有人}」的令牌「{名称}」，已通知持有人」→ 关弹窗并刷新列表 | Message.error + 弹窗保留、按钮恢复 |

#### 表单校验（续期弹窗 / 管理员吊销弹窗）

- 初态：续期时长默认 90 天；吊销原因为空

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 续期时长 | 是 | 7 / 30 / 90 / 180 天四选一 | change | 「请选择续期时长」 | 否 |
| 吊销原因 | 是（管理员吊销） | 2–200 字 | blur | 「请填写 2–200 字的吊销原因」 | 否 |

- 提交成功跳转：关闭弹窗并刷新列表，无路由跳转
- 提交失败展示：Message.error 展示服务端错误，弹窗保留已填内容
- 脏数据离开：弹窗场景，关闭即放弃，本场景不需要守卫

### 生成令牌

- **页面路径**：`/mcp-access/tokens/create`；编辑授权范围复用本页：`/mcp-access/tokens/:id/edit`
- **权限编码**：
  - 路由：`devhubMcpToken`
  - 按钮：无独立按钮权限
- **页面类型**：`archive-form`
- **区块职责**：
  - 基本信息分组：令牌名称、有效期（单选 7 / 30 / 90 / 180 天，默认 90；编辑模式隐藏，有效期只能通过续期修改）、到期时间预览（只读）
  - 授权范围分组：领域页签（业务系统 / 研发工具 / 数据库），页签标题带已选数量；三个页签均**只展示本人已分配且当前可用的对象**，页签顶部提示「可选范围来自权限管理员为你分配的权限；授权范围可不选，未配置时令牌不能调用任何工具」
    - 业务系统页签：服务 → 工具两级树形勾选；每个服务节点显示服务说明；写入类工具在服务节点内单独分组、带「写入」Tag 与提示「写入类工具将以你的身份修改业务数据」，默认不勾选；页签顶部另提示「业务系统工具以你的身份调用，返回结果受你在业务系统中的权限约束」
    - 研发工具页签：分「SLS 日志」「ARMS 应用监控」两组，每组为业务域 → 资源两级树；业务域节点显示环境限定 Tag（全部环境 / 仅生产 / 仅非生产）；分配到业务域的可整域勾选，节点旁显示「含后续开放资源」，展开改为逐个勾选后该标记消失；仅分配到单个资源的，业务域节点仅作分组、勾选即勾选其下已分配资源；资源节点显示日志库所属 Project 与保留天数、ARMS 应用所属地域
    - 数据库页签：实例 → 库 → 表三级树形勾选，实例节点显示环境 Tag（生产 / 预发 / 测试 / 开发）与行数、超时上限；勾选实例或库节点时节点旁显示「含后续开放表」，展开改为逐表勾选后该标记消失
    - 某领域无分配时页签内显示 Empty「你还没有被分配{领域}权限，请联系权限管理员分配」；三个领域均无分配时仍展示表单，允许生成空权限令牌
  - 已选汇总（表单底部）：按领域列出已选服务 / 工具 / 库表数量，均未选择时显示「未配置」
  - 底部操作：取消、生成令牌（编辑模式为「保存授权范围」）
  - 弹窗：**生成结果弹窗**（不可点遮罩关闭）：Result 成功图示、令牌明文（可复制）、醒目提示「令牌仅展示这一次，关闭后无法再次查看，请立即复制保存」、MCP 配置区（客户端单选：Qoder / Claude Code / Cursor / 通用；只读配置内容已填入令牌明文；复制配置、下载配置文件）、底部「我已保存，关闭」；空权限令牌额外提示「当前未配置授权范围，不能调用任何工具；获得权限后可编辑授权范围」
- **布局引用**：`参见原型 assets/web/token-form.html`（DOM 结构依据：`busyming-skills-design/templates/web/archive-form.html`）

#### 导航关系

- 来源页：我的令牌页「生成令牌」；令牌详情页「编辑授权范围」（编辑模式）
- 去向页：生成成功 → 生成结果弹窗，关闭后跳转我的令牌页；编辑保存成功 → 令牌详情页
- 返回行为：「取消」及面包屑「我的令牌」返回我的令牌页（编辑模式「取消」返回令牌详情页）
- 面包屑：首页 / 研发 / 平台能力 / MCP接入管理 / 我的令牌 / 生成令牌（编辑模式末级为「编辑授权范围」）

#### 表单校验

- 初态：生成模式有效期默认 90 天、授权范围为空；编辑模式回显令牌名称与当前授权范围，有效期不展示，已不可用的授权项（已停用 / 已下线 / 已删除 / 已超出分配范围）带 Tag 标注且只能取消不能新增

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 令牌名称 | 是 | 2–32 字，本人未吊销令牌中唯一 | blur | 「请输入 2–32 字的令牌名称」/「已有同名令牌」 | 是（唯一性） |
| 有效期 | 是（生成模式） | 7 / 30 / 90 / 180 天四选一 | change | 「请选择有效期」 | 否 |
| 授权范围 | 否 | 可为空；勾选时只能选择本人已分配且当前可用的对象 | 提交时 | — | 否 |

- 提交成功跳转：生成模式见生成结果弹窗关闭后跳转 `/mcp-access/tokens`；编辑模式 1.5s 后跳转 `/mcp-access/tokens/:id`
- 提交失败展示：MessageBox 错误详情，已填内容保留
- 脏数据离开：MessageBox「您有未保存的修改，确认离开？」

### 令牌详情

- **页面路径**：`/mcp-access/tokens/:id`
- **权限编码**：
  - 路由：`devhubMcpToken`（本人令牌）；查看他人令牌需 `devhubMcpTokenAdmin`
  - 按钮：`devhubMcpTokenAdmin`（吊销他人令牌）
- **页面类型**：`archive-detail`
- **区块职责**：
  - 头部：令牌名称、状态 Tag、令牌前缀；操作按钮：编辑授权范围、续期、吊销（按状态可用，见 state-machine.md；查看他人令牌时仅管理员吊销可用）
  - 基本信息（Descriptions）：持有人、有效期档位、生效时间、到期时间、最近使用时间、创建时间；已吊销时追加吊销方式、吊销人、吊销时间、吊销原因
  - 授权范围（BusyTabs 按领域）：业务系统页签为服务 → 工具列表（工具名称、操作类型 Tag、状态）；研发工具页签为 SLS 日志 / ARMS 应用监控两组的业务域或资源列表（对象、环境限定、「含后续开放资源」标记、状态）；数据库页签为实例 / 库 / 表列表（含「含后续开放表」标记）；不可用的授权项带「已停用」「已下线」「已删除」「已超出分配范围」Tag；全部为空时显示 Empty「未配置授权范围，当前不能调用任何工具」
  - MCP 接入配置：客户端单选（Qoder / Claude Code / Cursor / 通用）、只读配置内容（令牌位置以「<请填入令牌>」占位）、复制配置、下载配置文件；说明「仅包含已授权的领域；令牌明文仅在生成时展示」；空权限令牌配置不含服务条目，并提示获得权限后需编辑授权范围
  - 调用记录（近 30 天，本令牌）：筛选（时间范围、领域、调用结果）、表格列：调用时间、领域、服务、工具、目标对象（研发工具资源 / 数据库库表）、调用结果 Tag、原因、耗时
- **布局引用**：`参见原型 assets/web/token-detail.html`（DOM 结构依据：`busyming-skills-design/templates/web/archive-detail.html`）

#### 导航关系

- 来源页：我的令牌页行「详情」或令牌名称；生成令牌页编辑模式保存成功
- 去向页：「编辑授权范围」→ 生成令牌页编辑模式
- 返回行为：面包屑「我的令牌」或页头返回按钮返回我的令牌页
- 面包屑：首页 / 研发 / 平台能力 / MCP接入管理 / 我的令牌 / 令牌详情

### MCP 服务目录

- **页面路径**：`/mcp-access/services`
- **权限编码**：
  - 路由：`devhubMcpService`
  - 按钮：`devhubMcpServiceEdit`（登记服务、编辑、同步工具清单、服务与工具启停）
- **页面类型**：`archive-list`
- **区块职责**：
  - 工具栏：领域（全部 / 业务系统 / 研发工具 / 数据库）、状态（全部 / 启用 / 停用）、关键词（服务名称 / 服务标识）、查询 / 重置；右侧「登记服务」主按钮
  - 主体区：表格列：服务名称、服务标识、领域 Tag（研发工具服务附资源类型：SLS 日志库 / ARMS 应用）、服务负责人、工具数（启用 / 总数）、最近同步（时间 + 结果，失败红显）、启停开关、操作（编辑 / 同步工具清单 / 工具清单）；数据库领域内置服务行不可编辑、不可同步，操作列提示「可分配对象见数据源管理」；研发工具服务行操作列另有「研发工具资源」链接
  - 弹窗：**登记 / 编辑服务弹窗**：领域、资源类型（仅领域为研发工具时显示：SLS 日志库 / ARMS 应用）、服务名称、服务标识（编辑模式只读）、服务说明、服务地址、服务负责人（UserSelector）
