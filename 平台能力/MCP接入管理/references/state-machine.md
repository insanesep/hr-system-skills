# MCP接入管理 · 令牌状态机

> 本文件为令牌状态枚举与流转的唯一真源；生成、续期、吊销等操作规则见 [business-rule.md §3](business-rule.md#3-令牌规则)。

---

## 1. 状态枚举

| 状态 | 含义 | 可调用 | 可续期 | 可编辑授权范围 | 可吊销 |
| ---- | ---- | :---: | :---: | :---: | :---: |
| 生效中 | 在有效期内且未吊销 | 是（仍受实时授权判定） | 是 | 是 | 是 |
| 已过期 | 超过有效期终点 | 否 | 否 | 否 | 否 |
| 已吊销 | 被持有人、管理员或系统吊销 | 否 | 否 | 否 | 否 |

## 2. 流转

| 起始状态 | 触发 | 目标状态 | 说明 |
| ---- | ---- | ---- | ---- |
| （无） | 使用者生成令牌成功 | 生效中 | 明文仅本次展示；允许无授权范围，空权限令牌不能调用工具 |
| 生效中 | 续期 | 生效中 | 有效期终点更新 |
| 生效中 | 到达有效期终点 | 已过期 | 系统按分钟级判定 |
| 生效中 | 持有人吊销 | 已吊销 | 吊销方式记「本人吊销」 |
| 生效中 | 管理员吊销 | 已吊销 | 吊销方式记「管理员吊销」，须填原因并通知持有人 |
| 生效中 | 持有人账号停用 / 离职 | 已吊销 | 吊销方式记「账号停用自动吊销」 |

- 已过期、已吊销为终态，无出口；终态令牌保留在列表中供追溯，不提供删除
- 服务 / 工具停用、权限分配收回或到期不改变令牌状态，仅影响调用判定，见 [permission-rules.md §3](permission-rules.md#3-调用时授权判定)
