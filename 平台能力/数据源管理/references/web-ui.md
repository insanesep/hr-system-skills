### 数据源管理

- **页面路径**：`/mcp-access/datasources`
- **路由编码（name）**：`devhubMcpDatasource`
- **菜单 / 按钮权限码**：查看 `devhubMcpDatasource`；登记、编辑、启停 `devhubMcpDatasourceEdit`；定义见 [共享权限矩阵](../../references/permission-rules.md#1-权限点矩阵)
- **路由权限校验**：`meta.permCode=devhubMcpDatasource`
- **页面类型**：`archive-list`
- **区块职责**：
  - 工具栏：数据库类型（全部 / MySQL / PostgreSQL）、环境（全部 / 生产 / 预发 / 测试 / 开发）、业务域、连通状态（全部 / 正常 / 异常）、关键词（实例名称 / 所属业务系统）、查询 / 重置；右侧「登记数据源」主按钮
  - 主体区：表格列：实例名称、数据库类型、环境 Tag（生产红 / 预发橙 / 测试灰 / 开发灰）、业务域、所属业务系统、负责人、库 / 表数量、开放表数、行数上限、超时上限、连通状态 Tag、最近同步时间、启停开关、操作（详情 / 编辑）
  - 弹窗：**登记 / 编辑数据源弹窗**：实例名称、数据库类型、环境、业务域、连接地址、只读账号、密码（编辑时留空表示不修改）、所属业务系统、负责人（UserSelector）、行数上限（InputNumber，默认 1000）、超时上限（InputNumber，秒，默认 10）；提示「仅接受只读账号，保存时自动检测连通性与权限」；生产环境选中时提示「建议登记只读副本地址」
  - 空态：Empty「暂无数据源，点击「登记数据源」接入」
- **布局引用**：[本功能原型](../assets/web/datasource-list.html)（DOM 结构依据：`busyming-skills-design/templates/web/archive-list.html`）

#### 导航关系

- 来源页：侧边菜单「平台能力 → 数据源管理」（`/mcp-access/datasources`）；本功能数据源详情页返回
- 去向页：行「详情」/ 实例名称 → 本功能非菜单页 `/mcp-access/datasources/:id`；登记成功后进入新数据源详情；登记与编辑弹窗不新增菜单或路由
- 返回行为：菜单入口页，停留本页；切换其它功能使用「平台能力」下的同级菜单，不返回我的令牌
- 菜单归属：平台能力 → 数据源管理；独立运行的当前标题为「数据源管理」

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询 | 否 | 表格 loading | 列表刷新，停留 | Message.error + 按钮恢复 |
| 登记数据源提交 | 弹窗校验通过 | 否 | 确定按钮 loading，文案「检测连接中…」 | Message.success「数据源「{名称}」已登记，正在同步库表」→ 关弹窗并跳转数据源详情页 | MessageBox「连接失败：{原因}」或「该账号具备写入权限，请更换为只读账号」，弹窗保留、按钮恢复 |
| 编辑数据源提交 | 弹窗校验通过 | 否 | 确定按钮 loading | Message.success「数据源「{名称}」已保存」→ 关弹窗并刷新列表 | 同上 |
| 停用 | 数据源为启用 | MessageBox「停用后所有令牌将立即无法查询该实例，确认停用？」 | 开关 loading | Message.success「数据源已停用」，停留刷新 | Message.error + 开关回退 |
| 启用 | 数据源为停用 | 否 | 开关 loading | Message.success「数据源已启用」，停留刷新 | Message.error（如连接失败）+ 开关回退 |

#### 表单校验（登记 / 编辑数据源弹窗）

- 初态：行数上限 1000、超时上限 10 秒；编辑模式密码为空（不回显），数据库类型只读

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 实例名称 | 是 | ≤32 字，全局唯一 | blur | 「请输入实例名称」/「实例名称已存在」 | 是（唯一性） |
| 数据库类型 | 是 | MySQL / PostgreSQL | change | 「请选择数据库类型」 | 否 |
| 环境 | 是 | 生产 / 预发 / 测试 / 开发 | change | 「请选择环境」 | 否 |
| 业务域 | 是 | 业务域枚举单选 | change | 「请选择业务域」 | 否 |
| 连接地址 | 是 | 主机:端口 格式 | blur | 「请输入「主机:端口」格式的连接地址」 | 否 |
| 只读账号 | 是 | ≤64 字 | blur | 「请输入只读账号」 | 否 |
| 密码 | 登记时必填 | 编辑时可留空 | blur | 「请输入密码」 | 否 |
| 负责人 | 是 | 选择一名用户 | change | 「请选择负责人」 | 否 |
| 行数上限 | 是 | 1–5000 整数 | blur | 「行数上限需为 1–5000 的整数」 | 否 |
| 超时上限 | 是 | 1–30 整数（秒） | blur | 「超时上限需为 1–30 秒」 | 否 |

- 提交成功跳转：登记跳转 `/mcp-access/datasources/:id`；编辑关闭弹窗并刷新列表
- 提交失败展示：MessageBox 错误详情，弹窗保留已填内容（密码除外）
- 脏数据离开：关闭有修改的弹窗时 MessageBox「您有未保存的修改，确认关闭？」

### 数据源详情

- **页面路径**：`/mcp-access/datasources/:id`
- **路由编码（name）**：`devhubMcpDatasourceDetail`
- **菜单 / 按钮权限码**：非菜单页；查看 `devhubMcpDatasource`；同步库表、开放配置、脱敏绑定、编辑 `devhubMcpDatasourceEdit`；定义见 [共享权限矩阵](../../references/permission-rules.md#1-权限点矩阵)
- **路由权限校验**：`meta.permCode=devhubMcpDatasource`
- **页面类型**：`archive-detail`
- **区块职责**：
  - 头部：实例名称、环境 Tag、业务域 Tag、连通状态 Tag；操作按钮：编辑（打开数据源管理页同款弹窗）、同步库表
  - 基本信息（Descriptions）：数据库类型、连接地址、只读账号、业务域、所属业务系统、负责人、行数上限、超时上限、最近同步时间
  - 库表开放（左右分栏）：左侧库 → 表树（带搜索，节点显示开放状态 Tag：开放 / 跟随库 / 不开放；已删除对象灰显）；右侧为选中节点的开放配置：对象名称与注释、开放状态（库：开放 / 不开放；表：跟随库 / 开放 / 不开放）、已分配人数（只读，说明「分配给哪些人由权限管理员在权限分配中维护」）、保存
  - 字段与脱敏（选中表节点时显示于右侧下方）：表格列：字段名、字段类型、注释、疑似敏感 Tag、脱敏规则（选择器，选项来自用户权限中心生效脱敏规则；空为不脱敏）
  - 空态：库表树为空时 Empty「尚未同步库表，点击「同步库表」」
- **布局引用**：[本功能原型](../assets/web/datasource-detail.html)（DOM 结构依据：`busyming-skills-design/templates/web/archive-detail.html`）

#### 导航关系

- 来源页：平台能力 → 数据源管理，列表行「详情」/ 实例名称；登记数据源成功跳转
- 去向页：编辑打开本功能数据源弹窗，无新增菜单页
- 返回行为：返回目标为数据源管理 `/mcp-access/datasources`；页头返回交互按本目标验收，不依赖面包屑返回
- 功能归属：平台能力 → 数据源管理；本页为非菜单详情页，当前标题为「数据源详情」

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 同步库表 | 数据源启用且连通 | 否 | 按钮 loading + 库表树 loading | Message.success「同步完成：新增 {N} 张表（默认不开放），{M} 个对象已删除」→ 刷新树 | Message.error「同步失败：{原因}」，保留上次结果，按钮恢复 |
| 保存开放配置 | 已选中库或表节点且有修改 | 由开放改为不开放时 MessageBox「关闭后已分配该对象的 {N} 人将立即无法查询，确认保存？」；否则否 | 保存按钮 loading | Message.success「「{对象名}」开放配置已保存」→ 停留并刷新节点状态 | Message.error + 按钮恢复、保留修改 |
| 绑定 / 解除脱敏 | 字段行选择脱敏规则 | 解除时 MessageBox「解除后该字段将以明文返回，确认解除？」 | 选择器 loading | Message.success「字段「{字段名}」已{绑定/解除}脱敏」，停留 | Message.error + 回退原值 |
| 编辑数据源 | 有编辑权限 | 否 | 同数据源管理页 | 同数据源管理页，成功后刷新基本信息 | 同数据源管理页 |

#### 表单校验（库表开放配置）

- 初态：回显选中节点当前开放状态；新同步对象为「不开放」，表节点默认「跟随库」

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 开放状态 | 是 | 库：开放 / 不开放；表：跟随库 / 开放 / 不开放 | change | — | 否 |

- 提交成功跳转：停留本页并刷新节点状态
- 提交失败展示：Message.error，保留修改
- 脏数据离开：右侧有未保存修改时切换树节点或离开页面，MessageBox「开放配置未保存，确认放弃？」
