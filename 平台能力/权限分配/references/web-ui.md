### 权限分配

- **页面路径**：`/mcp-access/grants`
- **路由编码（name）**：`devhubMcpGrant`
- **菜单 / 按钮权限码**：`devhubMcpGrant` 控制权限分配、单人或批量分配及变更记录；定义见 [共享权限矩阵](../../references/permission-rules.md#1-权限点矩阵)
- **路由权限校验**：`meta.permCode=devhubMcpGrant`
- **页面类型**：`archive-list`
- **区块职责**：
  - 页头操作：「新建分配」主按钮、「批量分配」次按钮（未勾选人员时置灰，Tooltip「请先勾选人员」）
  - 筛选区：人员（UserSelector，按姓名 / 工号搜索）、分配状态（全部 / 已分配 / 未分配 / 7 天内到期）、查询 / 重置
  - 主体区：表格列：勾选、人员、部门、数据库（按粒度计数，形如「实例 1 · 库 2 · 表 3」，含生产时附「生产」Tag）、研发工具权限（当前有效工具族数量及 SLS 日志 / ARMS 应用监控名称）、最近到期（日期，7 天内橙显）、生效令牌数、最近调整（时间）、操作（分配权限 / 变更记录）；研发工具汇总加载中或失败分别显示「加载中」「加载失败」，不误显示为未分配；不统计业务域、应用或环境授权
  - 分配边界：本页管理数据库与 SLS / ARMS 工具族的显式分配；业务工具无需管理员预分配，云效仓成员关系只提供动态应用范围，不计为工具分配
  - 弹窗：**新建权限分配弹窗**：被分配人（单选 UserSelector，可选择本人，展示姓名、工号）、取消、下一步；提示进入表单后可新增或收回该人员权限
  - 抽屉：**变更记录抽屉**：人员姓名；列出授权变更记录（时间、变更类型 Tag：分配 / 收回 / 到期收回 / 停用收回、对象描述、有效期、分配理由、操作人）；观测对象为工具族，不是应用分配记录
  - 空态：Empty「暂无符合条件的人员」
- **布局引用**：[本功能原型](../assets/web/grant-list.html)（编排依据：`busyming-skills-design/shared/page-standards/web-operation-list.md`）

#### 导航关系

- 来源页：侧边菜单「平台能力 → 权限分配」（`/mcp-access/grants`）；本功能分配表单保存成功或从列表进入后取消
- 去向页：「新建分配」打开人员选择弹窗，下一步与行「分配权限」进入本功能单人非菜单页 `/mcp-access/grants/:userId`；「批量分配」进入本功能非菜单页 `/mcp-access/grants/batch` 并携带已选人员；「变更记录」打开本页抽屉
- 返回行为：菜单入口页，停留本页；切换其它功能使用「平台能力」下的同级菜单，不返回我的令牌
- 菜单归属：平台能力 → 权限分配；独立运行的当前标题为「权限分配」

#### 表单校验（新建权限分配弹窗）

- 初态：被分配人为空；人员选项包含当前操作人
- 被分配人必填，点击下一步时校验，未选择提示「请选择被分配人」；关闭弹窗放弃已选内容，无需脏数据守卫

### 分配权限

- **页面路径**：单人 `/mcp-access/grants/:userId`；批量 `/mcp-access/grants/batch?users={人员列表}`
- **路由编码（name）**：单人 `devhubMcpGrantEdit`；批量 `devhubMcpGrantBatch`
- **菜单 / 按钮权限码**：非菜单页；保存分配 `devhubMcpGrant`；定义见 [共享权限矩阵](../../references/permission-rules.md#1-权限点矩阵)
- **路由权限校验**：单人与批量路由均声明 `meta.permCode=devhubMcpGrant`
- **页面类型**：`archive-form`
- **区块职责**：
  - 被分配人分组：单人模式显示姓名与用户 ID；批量模式显示已选人员 Tag（可移除或追加）与提示「批量分配只追加，不会移除这些人员已有的权限」
  - 分配内容分组：不设置业务系统页签；上方平铺 SLS 日志与 ARMS 应用监控两个工具族复选项，下方保留数据库实例 → 库 → 表三级树，只展示当前可分配范围
    - 研发工具：管理员须显式勾选工具族，可按项设置长期或截止日期；仓成员不会自动获得工具分配。工具族不带业务域、环境限定、应用或后续观测资源选择；无可分配工具时显示「暂无可分配的研发工具」
    - 数据库：实例节点显示环境 Tag 与业务域，保留实例 / 库 / 表粒度与库表开放规则；整实例或整库授权的后续开放表覆盖规则不变
  - 已选清单（表单底部表格）：列：对象、粒度（研发工具为工具族；数据库为实例 / 库 / 表）、环境（仅数据库显示，工具族为 —）、有效期（行内可改，留空为长期）、分配理由（数据库生产环境必填 2–200 字，其余选填且不超过 200 字）、状态（新增 / 保持 / 将收回）、操作（新增项可移除、现有项可收回、将收回项可撤销收回）；单人模式回显现有有效分配，取消勾选现有工具族即标记「将收回」
  - 底部操作：取消、保存分配；收回或到期只使对应工具调用拒绝，不吊销令牌、不改变其他有效范围
- **布局引用**：[本功能原型](../assets/web/grant-form.html)（编排依据：`busyming-skills-design/shared/page-standards/web-form.md`）

#### 导航关系

- 来源页：平台能力 → 权限分配，人员选择弹窗下一步或行「分配权限」（单人），「批量分配」（批量）
- 去向页：保存成功 → 权限分配 `/mcp-access/grants`
- 返回行为：「取消」按浏览器历史返回，从权限分配列表进入时回到 `/mcp-access/grants`；页头返回交互的目标为同一列表，按本目标验收，不依赖面包屑
- 功能归属：平台能力 → 权限分配；单人与批量均为本功能非菜单页，当前标题分别为「分配权限」「批量分配」

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 保存分配（单人） | 校验通过且有变化 | 存在「将收回」项时 MessageBox「将收回 {N} 项权限，相关令牌中对应授权将立即失效，确认保存？」；否则否 | 提交按钮 loading，表单禁用 | Message.success「权限分配已保存，已通知本人」→ 1.5s 后跳转权限分配页；令牌状态不变，仅受影响工具或数据库范围失效 | Message.error 错误详情（如对象已不可分配），表单保留、按钮恢复 |
| 保存分配（批量） | 校验通过且至少勾选一项 | MessageBox「将为 {N} 人追加 {M} 项权限，确认分配？」 | 提交按钮 loading，表单禁用 | Message.success「已为 {N} 人追加权限分配，已通知本人」→ 1.5s 后跳转权限分配页 | Message.error 错误详情，表单保留、按钮恢复 |
| 移除已选项 | 已选清单行内 | 否 | 无 | 同步取消工具族或数据库节点勾选；新增项移除，现有分配标记「将收回」，可撤销收回 | — |
| 移除批量人员 | 批量模式人员 Tag 关闭 | 否 | 无 | 人员移除；剩余 0 人时禁止提交并提示「请选择被分配人」 | — |

#### 表单校验

- 初态：单人模式回显现有有效分配（状态「保持」）；新勾选项有效期留空，表示「长期」；批量模式分配内容为空

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 被分配人 | 是 | 至少 1 人，可为当前操作人 | change | 「请选择被分配人」 | 否 |
| 分配内容 | 批量模式必填 | 至少勾选一项数据库范围或研发工具族；单人可只收回已有分配 | 提交时 | 「请至少选择一项要分配的权限」 | 否 |
| 有效期 | 否 | 截止日期不早于明天 | change | 「截止日期需晚于今天」 | 否 |
| 分配理由 | 数据库生产环境必填 | 必填项 2–200 字，其他项选填且不超过 200 字；见 [permission-rules.md §2.3](../../references/permission-rules.md#23-分配理由) | 提交时 | 「「{对象名}」为生产环境分配，请填写 2–200 字的分配理由」/「「{对象名}」的分配理由不能超过 200 字」 | 否 |

- 提交成功跳转：`/mcp-access/grants`，延迟 1.5s
- 提交失败展示：Message.error 错误详情，已填内容保留
- 脏数据离开：MessageBox「您有未保存的修改，确认离开？」
