# 平台能力 · MCP 接入数据定义

> 本文件描述产品对象、事实快照与关系，不定义数据库结构。工具目录仅是已注册能力的展示概念，不构造第三方服务或工具登记实体。规则见 [业务规则](business-rule.md)、[权限规则](permission-rules.md)、[研发工具规则](../研发工具资源/references/devtool-rules.md)、[数据源规则](../数据源管理/references/datasource-rules.md)与 [审计规则](../调用审计/references/audit-rules.md)。

## 1. 对象关系

- 门户用户可持有多个访问令牌，并关联显式权限分配与授权变更记录。
- 令牌包含用户显式选择的授权项，生成与编辑必须至少有一项当前有效 scope；权限撤销后选择可保留，但不代表可调用。
- 权限管理员分配 SLS/ARMS 工具族与数据库实例、库、表。SYSTEM 已注册内置业务工具默认可选，不必生成管理员分配记录。
- 项目维护 harness 工程和代码服务仓列表。harness 是需求与 Skills 真源，不派生研发查询范围；代码服务仓是真源。
- 代码仓快照保存云效仓 ID、精确仓名、所属项目和同步状态；完整应用名由仓名与调用时明确的环境后缀组成，不保存逐应用授权记录。
- 云效仓成员事实通过组织成员邮箱唯一映射到启用门户用户，有效成员派生查询范围，但不产生工具族 grant 或令牌授权项。
- 数据源包含库、表、字段；表归库、字段归表，字段至多绑定一个门户脱敏规则。
- 调用记录关联令牌与工具目标，观测目标是 Skills 识别的 group 与完整 appName；成员快照、代码仓快照、工具许可和令牌选择互不代替。

## 2. 已注册工具目录概念

| 展示信息 | 产品语义 |
| ---- | ---- |
| 接入领域 | SYSTEM 业务工具、DEVTOOL 研发工具、DATABASE 数据库 |
| 工具或工具族标识 | 服务器当前已注册能力的稳定识别，不由页面登记第三方地址生成 |
| 名称与说明 | 由已注册能力提供，不从外部服务同步生成登记对象 |
| 选择粒度 | SYSTEM 已注册内置工具、DEVTOOL 的 SLS/ARMS 工具族、DATABASE 实例或库表范围 |
| 观测工具下发 | 有效用户和令牌认证后，仅按有效工具 grant 与令牌显式选择；不以成员同步成功、快照新鲜、可访问仓或云能力就绪为前提 |
| 实际查询可用性 | 每次查询再严格校验当前成员与两个 24 小时快照、项目仓关系、唯一仓名、group、环境及所需云能力，不以已下发清单代替 |

目录不保存第三方服务地址、负责人、远程工具同步状态或任意服务登记关系。SYSTEM 和 DATABASE 保持各自目录及范围规则；工具定义和执行契约以实际代码及公共能力契约为准。

## 3. 访问令牌

| 字段 | 产品语义 | 规则 |
| ---- | ---- | ---- |
| 令牌 ID | 令牌标识 | 系统生成 |
| 令牌名称 | 用途说明 | 2–32 字，本人未吊销令牌中唯一 |
| 持有人 | 生成令牌的门户用户 | 不可转移 |
| 令牌前缀 | 展示识别片段 | 明文前 8 位，不替代认证 |
| 令牌摘要 | 不可逆校验依据 | 页面不展示，不保存完整明文 |
| 有效期 | 选择档位 | 7、30、90、180 天 |
| 生效与到期时间 | 有效期起止 | 续期以当前时间更新，明文不变 |
| 状态 | 生命周期 | 生效中、已过期、已吊销，沿用令牌状态机 |
| 吊销来源 | 吊销方式 | 本人、管理员、账号停用自动吊销 |
| 吊销原因 | 管理员说明 | 吊销他人生效中令牌时必填 2–200 字 |
| 吊销人及时间 | 吊销事实 | 系统处理记系统身份 |
| 最近使用时间 | 最近一次可识别令牌调用 | 成功、拒绝、失败均记录 |
| 创建与更新时间 | 审计时间 | 东八区 |

## 4. 令牌授权项

| 字段 | 产品语义 | 规则 |
| ---- | ---- | ---- |
| 授权项 ID | 选择记录标识 | 系统生成 |
| 令牌 ID | 所属令牌 | 不独立转移 |
| 领域 | 选择所属能力 | SYSTEM、DEVTOOL、DATABASE |
| 对象类型与对象 | 选择粒度与目标 | SYSTEM 为已注册内置工具；DEVTOOL 仅 SLS/ARMS 工具族；DATABASE 为实例、库、表 |
| 对象名称 | 展示名称 | 工具由已注册目录解析，数据库由当前对象解析 |
| 排除标记 | 不参与有效选择 | 被排除项不赋予调用许可 |
| 包含后续对象 | 数据库层级范围 | 只用于数据库实例、库对应范围；DEVTOOL 不接受包含后续资源 |
| 当前可用性 | 当前许可与对象校验结果 | 已超出分配、停用、删除或可用；工具族可用不证明应用范围或云能力就绪 |

- 生成、编辑必须至少选择一项当前有效 scope；已有令牌因分配或对象变化可以失去所有可调用能力，但不因此自动改变生命周期。
- DEVTOOL 不保存具体应用、日志库、group 或独立环境限定；查询范围逐次从代码仓及成员事实计算。
- 非工具型 DEVTOOL 授权项不生效，不转换成工具许可，不扩展已有令牌选择；数据库层级与有效范围保持原规则。

## 5. 权限分配项

| 字段 | 产品语义 | 规则 |
| ---- | ---- | ---- |
| 分配项 ID | 显式分配标识 | 系统生成 |
| 被分配人 | 门户用户 | 与仓成员身份分开 |
| 领域 | 管理员分配领域 | DEVTOOL 或 DATABASE |
| 对象类型与对象 | 分配粒度 | DEVTOOL 仅 SLS/ARMS 工具族；DATABASE 为实例、库、表 |
| 对象名称 | 分配展示目标 | 工具族由注册目录确定，数据库引用原对象 |
| 截止日期 | 分配有效期 | 空为长期，截止日当天有效，次日失效 |
| 分配理由 | 操作依据 | 生产数据库必填 2–200 字；其他可选且最多 200 字 |
| 分配人及时间 | 最近显式操作 | 与仓成员同步日期无关 |

- 同一人员、领域、对象类型和对象至多一条有效分配，重复分配更新有效期和理由；多人组合锁内原子保存，防止重复或部分人员提交。
- 观测分配不含环境限定、应用资源类型或业务域。仓成员只提供事实，不写人工应用分配记录。
- SYSTEM 默认可选不表示自动写入 grant；token 仍须主动选择已注册工具。

## 6. 研发代码仓快照

| 字段 | 产品语义 | 规则 |
| ---- | ---- | ---- |
| 快照 ID | 代码仓事实标识 | 系统生成 |
| 所属项目 | 项目真源关联 | 查询要求项目启用且未删除 |
| 云效仓 ID | 项目代码服务仓标识 | 必须仍在项目代码服务仓列表中 |
| 仓名称 | appName 的精确基础前缀 | 同名有效仓冲突时拒绝选择 |
| 冲突标记 | 多项目引用或同名仓冲突 | 有冲突默认拒绝，不选首项 |
| 对象状态 | 正常或已移除 | 从启用项目代码服务仓列表移除后失效 |
| 最近同步时间 | 最近成功读取仓资料时间 | 24 小时后失效；仓资料读取失败保留旧日期 |

- 快照不保存 group、完整应用名、SLS Project、地域、日志保留期、SLS 就绪或 PID。同步不访问 SLS/ARMS。
- group 由 Skills 从目标后端 config group 识别；完整 appName 由仓名和环境后缀组成。服务器在查询时验证 group 配置与连接身份。
- 页面展示有效云效研发成员数及门户映射数，仅说明同步事实，不代表工具许可。

## 7. 云效仓成员快照

| 字段 | 产品语义 | 规则 |
| ---- | ---- | ---- |
| 成员记录 ID | 同步事实标识 | 系统生成 |
| 云效仓 ID | 成员所属代码仓 | 范围只覆盖该仓派生的应用 |
| 云效字符串用户身份 | 云效组织成员标识 | 不强转为门户数字用户 ID |
| 门户用户 ID | 唯一邮箱匹配用户 | 缺失、重复、停用映射不获范围；确认移除后清空 |
| 用户名称 | 展示信息 | 不用于身份匹配 |
| 邮箱 | 组织资料中的身份映射依据 | 规范化后唯一匹配启用门户用户 |
| 成员角色 | 仓访问角色 | 至少浏览者才可产生有效范围 |
| 成员状态 | 有效、无效、已移除事实 | 与角色、映射及到期共同判断，不仅凭是否出现在列表 |
| 继承来源 | 直接成员或代码组继承 | 合并有效访问路径，不自动授工具 |
| 成员到期时间 | 云效访问截止事实 | 每次查询即时判断，长期有效与已到期分开 |
| 最近同步时间 | 最近成功完整成员快照日期 | 24 小时后失效；读取失败不刷新 |

- 该仓成功完整同步后，未再出现的成员标记移除、清空门户关联，后续查询立即失效；尚未同步不承诺实时获知云端删除。
- 邮箱映射缺失或重复的明确事实不产生有效范围；异常或无法完整解析的响应不当作空成功，不据此删除旧成员。
- 每仓按事务保存可用的代码仓与成员事实，两个快照分别保留成功时间且查询时均须满足 24 小时新鲜度。成员读取或映射失败保留旧成员快照和旧日期，成功读取的仓资料可以独立刷新；保存失败回滚该仓事务。工具 grant 与令牌选择另行校验，目录结果、PID 缓存或任务进度不能替代成员事实。

### 7.1 同步任务进度（Redis）

| 信息 | 产品语义与规则 |
| ---- | ---- |
| taskId | 同一部署环境内的任务标识，手工重复提交返回当前活动任务标识 |
| 状态与阶段 | QUEUED、RUNNING 和最终结果，阶段含项目读取、仓资料、成员分页与 profile、用户映射、逐仓保存、完成 |
| 当前处理对象 | 当前项目、仓及分页或资料处理位置，仅展示安全定位信息 |
| 进度计数 | 仓总数、已读取仓、已保存仓、成员及已映射人数；失败原因另见清单，未知总数不造完成百分比 |
| 失败列表 | 失败仓、失败阶段和安全原因，partial 不能仅显示成功统计 |
| 时间与中断原因 | 受理、开始、更新和结束时间；重启中断记 FAILED，不自动续跑 |
| 保留与查询 | Redis 最后更新后保留 72 小时，支持最近任务及 taskId 查询，页面刷新据此恢复轮询 |

- 最近查询优先返回活动任务，无活动任务才返回最近一次执行任务。SchedulerX 的 SKIPPED 只记录本次调度跳过及关联活动 taskId，不覆盖活动任务进度。
- 任务进度不新增数据库实体、表或 DDL，不保存原始 profile、完整邮箱或凭据；保留期不是分布式锁时长，也不延长两个 24 小时授权快照。
- 终态或记录过期后页面不继续轮询；记录缺失不能被解释为同步成功。令牌状态、工具清单下发和观测授权均不由任务状态升降。

## 8. 调用记录

| 信息 | 产品语义 |
| ---- | ---- |
| 记录 ID 与调用时间 | 请求到达及追溯标识，东八区时间 |
| 令牌与持有人 | 可识别令牌的关联、名称前缀与门户身份；无效令牌不暴露明文 |
| 客户端 | 调用来源信息 |
| 接入领域与工具 | 具体已注册工具能力，不依赖第三方服务登记实体 |
| 目标对象 | 观测为工具族与完整 appName；数据库为实例、库、表；业务工具按其契约记录 |
| 业务分类或观测 group | 数据库记录其业务域，观测记录调用时经服务器验证并实际采用的 group；该信息不额外授予访问范围 |
| 查询摘要 | 脱敏后的查询条件，不保存凭据原文 |
| 返回数量、截断与脱敏 | 结果覆盖范围，不把未知字段按零值解释 |
| 结果、原因及耗时 | 成功、拒绝、失败及可追溯原因 |

记录不可编辑或删除，保留 180 天，汇总与导出遵循审计规则。授权范围不足、快照过期与单能力不可用须区分，不借空结果掩盖拒绝。

## 9. 数据源

| 字段 | 产品语义 | 规则 |
| ---- | ---- | ---- |
| 数据源 ID | 实例标识 | 系统生成 |
| 实例名称 | 展示名 | 最多 32 字，全局唯一 |
| 数据库类型 | 引擎 | MySQL、PostgreSQL |
| 环境 | 数据库实例环境 | 生产、预发、测试、开发，沿用数据库规则 |
| 业务域 | 数据库业务分类 | 商品、采购、营运、门店、客服、系统、库存、要货、产研、公共 |
| 连接地址 | 主机与端口 | 按数据源规则维护 |
| 只读账号与密码 | 查询凭证 | 密码加密保存不回显，不接受写权限账号 |
| 所属业务系统与负责人 | 归属和责任 | 不作为观测应用映射 |
| 行数上限 | 单次返回上限 | 默认 1000，范围 1–5000 |
| 超时上限 | 查询秒数 | 默认 10，范围 1–30 |
| 连通状态 | 最近探测结果 | 正常或异常 |
| 启停状态 | 实例可用性 | 启用或停用 |
| 最近库表同步时间 | 元数据更新事实 | 不参与观测成员快照续期 |
| 创建与更新时间 | 审计字段 | 东八区 |

## 10. 库表对象与字段脱敏绑定

| 信息 | 产品语义与规则 |
| ---- | ---- |
| 对象 ID 与所属数据源 | 标识库、表、字段所属实例 |
| 对象类型、名称、父对象 | 库包含表、表包含字段；名称来自实例同步 |
| 注释与字段类型 | 实例元数据，字段类型仅用于字段 |
| 开放状态 | 库与表可开放或不开放；表可跟随库，新同步库表默认不开放 |
| 疑似敏感 | 字段名或注释命中敏感词，提示确认绑定，不代替实际脱敏 |
| 对象状态 | 正常或已删除；同步失败不误删 |
| 脱敏绑定 ID 与字段 | 每个字段至多一条绑定 |
| 脱敏规则 | 只读引用门户生效脱敏规则，不另建算法 |
| 绑定人与时间 | 操作审计，东八区 |

实例、库、表分配及令牌选择仍受当前开放状态限制，未分配或未开放的库表完全不可见，保持只读、脱敏、限行限时规则。

## 11. 授权变更记录

| 信息 | 产品语义 |
| ---- | ---- |
| 记录 ID 与时间 | 变更标识及东八区时间 |
| 操作人与被分配人 | 显式授予或收回的双方；系统处理记系统 |
| 变更类型 | 分配、收回、到期收回、停用收回 |
| 对象描述 | 领域、工具族或数据库对象及粒度的变更时快照 |
| 截止日期与理由 | 分配的有效期和依据 |

不可编辑或删除，保留 3 年；数据库环境信息可用于其审计，不构造观测环境 grant。云效成员同步与人工工具分配分开记录，不把同步当成升格授权。
