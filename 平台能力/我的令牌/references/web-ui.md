### 我的令牌

- **页面路径**：`/mcp-access/tokens`
- **路由编码（name）**：`devhubMcpToken`
- **菜单 / 按钮权限码**：功能权限定义见 [共享权限矩阵](../../references/permission-rules.md#1-权限点矩阵)；`devhubMcpTokenAdmin` 控制全部令牌与吊销他人令牌，`devhubMcpTokenEdit` 控制编辑本人有效令牌
- **权限判定**：列表范围与操作按功能权限及服务端规则判定，不以路由 name 代替授权校验
- **页面类型**：`archive-list`
- **区块职责**：
  - 工具栏：范围切换（我的令牌 / 全部令牌，后者仅管理员可见）、状态（全部 / 生效中 / 已过期 / 已吊销）、关键词（令牌名称 / 前缀；全部令牌范围下含持有人）、查询 / 重置；右侧「我的权限」按钮与「生成令牌」主按钮，旁注「生效中 N / 10」
  - 主体区：表格列：令牌名称、令牌前缀（前 8 位）、持有人（仅全部令牌范围显示）、授权领域（Tag，多个）、状态（Tag：生效中绿 / 已过期灰 / 已吊销红）、到期时间（7 天内到期橙显并标「即将到期」）、最近使用时间（未使用显示 —）、操作（详情 / 编辑授权范围 / 续期 / 吊销；按状态可用性见 state-machine.md；编辑本人令牌需 `devhubMcpTokenEdit`）
  - 抽屉：**我的权限抽屉**（只读）：已分配数据库与研发工具权限表格，列：领域、对象、粒度（SLS 日志 / ARMS 应用监控为工具族）、有效期（长期 / 日期，7 天内到期橙显「即将到期」）、分配人、可用性；提示「SLS / ARMS 须由管理员分配工具权限，可查询应用由当前仓成员关系动态决定；业务工具默认可选，在令牌中显式勾选」；下方「最近变更」列表（本人授权变更记录近 20 条：时间、变更类型、对象、操作人）；无分配时 Empty「暂无已分配的数据库或研发工具权限，请联系权限管理员分配」，不据此判定业务工具不可选
  - 弹窗：**续期弹窗**：令牌名称（只读）、当前到期时间（只读）、续期时长（单选 7 / 30 / 90 / 180 天，默认 90）、新到期时间（随选择实时计算，只读）
  - 弹窗：**吊销确认**：本人吊销为确认框；管理员吊销他人令牌为表单弹窗，含吊销原因（必填）
  - 空态：Empty「还没有令牌，点击「生成令牌」为你的 AI Agent 接入 MCP」
- **布局引用**：[本功能原型](../assets/web/token-list.html)（编排依据：`busyming-skills-design/shared/page-standards/web-operation-list.md`）

#### 导航关系

- 来源页：侧边菜单「平台能力 → 我的令牌」（`/mcp-access/tokens`）；企微到期提醒中的续期入口；企微权限变更通知中的查看入口（直接打开我的权限抽屉）；生成令牌成功后关闭结果弹窗
- 去向页：「生成令牌」→ 本功能非菜单页 `/mcp-access/tokens/create`；行「详情」/ 令牌名称 → 本功能非菜单页 `/mcp-access/tokens/:id`；「我的权限」打开本页抽屉
- 返回行为：菜单入口页，停留本页；切换其它功能使用「平台能力」下的同级菜单，不设聚合页返回入口
- 菜单归属：平台能力 → 我的令牌；独立运行的当前标题为「我的令牌」

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 查询 | 点击查询 | 否 | 表格 loading | 列表刷新，停留 | Message.error + 按钮恢复 |
| 生成令牌 | 生效中令牌数 < 10（达上限时按钮置灰，Tooltip「生效中令牌已达 10 个上限，请先吊销不用的令牌」） | 否 | — | 跳转生成令牌页 | — |
| 续期 | 行状态为生效中 | 否（弹窗即确认） | 弹窗确定按钮 loading | Message.success「令牌「{名称}」已续期至 {日期}」→ 关弹窗并刷新行 | Message.error（令牌已失效等）+ 弹窗保留、按钮恢复 |
| 吊销（本人） | 行状态为生效中 | MessageBox「吊销后使用该令牌的 Agent 将立即无法调用，且不可恢复，确认吊销？」 | 确认按钮 loading | Message.success「令牌「{名称}」已吊销」→ 刷新列表 | Message.error + 按钮恢复 |
| 吊销（管理员） | 全部令牌范围、行状态为生效中 | 吊销原因弹窗即确认 | 弹窗确定按钮 loading | Message.success「已吊销「{持有人}」的令牌「{名称}」，已通知持有人」→ 关弹窗并刷新列表 | Message.error + 弹窗保留、按钮恢复 |

#### 表单校验（续期弹窗 / 管理员吊销弹窗）

- 初态：续期时长默认 90 天；吊销原因为空

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 续期时长 | 是 | 7 / 30 / 90 / 180 天四选一 | change | 「请选择续期时长」 | 否 |
| 吊销原因 | 是（管理员吊销） | 2–200 字 | blur | 「请填写 2–200 字的吊销原因」 | 否 |

- 提交成功跳转：关闭弹窗并刷新列表，无路由跳转
- 提交失败展示：Message.error 展示服务端错误，弹窗保留已填内容
- 脏数据离开：弹窗场景，关闭即放弃，本场景不需要守卫

### 生成 / 编辑令牌

- **页面路径**：`/mcp-access/tokens/create`；编辑授权范围复用本页：`/mcp-access/tokens/:id/edit`
- **路由编码（name）**：生成 `devhubMcpTokenCreate`；编辑 `devhubMcpTokenEdit`
- **菜单 / 按钮权限码**：非菜单页；编辑本人有效令牌需 `devhubMcpTokenEdit`，职责与权限定义见 [共享权限矩阵](../../references/permission-rules.md#1-权限点矩阵)
- **权限判定**：生成与编辑均按本人当前可用范围校验；编辑路由的权限码为 `devhubMcpTokenEdit`，name 与权限码分别识别
- **页面类型**：`archive-form`
- **区块职责**：
  - 基本信息分组：令牌名称、有效期（单选 7 / 30 / 90 / 180 天，默认 90；编辑模式隐藏，有效期只能通过续期修改）、到期时间预览（只读）
  - 授权范围分组：领域页签（数据库 / 研发工具 / 业务工具）；数据库与研发工具只展示本人已分配且当前可用的范围，已注册业务工具默认可选，无需管理员为账号预先分配；各类工具均须在令牌中显式勾选，不自动加入已有令牌
    - 数据库页签：实例 → 库 → 表三级树形勾选，实例节点显示环境 Tag（生产 / 预发 / 测试 / 开发）与行数、超时上限；整实例或整库须显式勾选对应节点，并显示「含后续开放表」；仅部分库表已分配的父级只作导航、不可整选，逐表勾选不扩大为整库或整实例范围
    - 研发工具页签：平铺「SLS 日志」「ARMS 应用监控」两个工具族复选项，只可勾选管理员已分配的工具族；提示「可查询应用由当前仓成员关系动态决定，不单独授权环境或应用」；不展示业务域树、逐应用勾选、环境限定或后续观测资源标记
    - 业务工具页签：已注册业务工具平铺勾选，默认均不勾选；提示「已注册业务工具默认可选，无需管理员为账号分配；须在令牌中显式勾选，不会自动加入已有令牌」；业务操作仍按持有人在业务系统中的权限执行
    - 研发工具无分配时显示 Empty「暂无已分配的研发工具，请联系管理员分配 SLS / ARMS 工具权限」；业务工具为空时显示「暂无已注册业务工具」；所有范围均不可选时显示「暂无可选授权范围；数据库和 SLS / ARMS 工具需管理员分配，已注册业务工具默认可选」，不提供空权限令牌生成
  - 已选汇总（表单底部）：实例、库、表、研发工具族、业务工具的已选数量
  - 底部操作：取消、生成令牌（编辑模式为「保存授权范围」）；创建与保存均须至少选择一项当前有效范围
  - 弹窗：**生成结果弹窗**（不可点遮罩关闭）：令牌明文（可复制）、醒目提示「令牌仅展示这一次，关闭后无法再次查看，请立即复制保存」、MCP 配置区（统一标准配置，服务名称带环境标识；只读配置内容已填入令牌明文；复制配置、下载配置文件）、底部「我已保存，关闭」
- **布局引用**：[本功能原型](../assets/web/token-form.html)（编排依据：`busyming-skills-design/shared/page-standards/web-form.md`）

#### 导航关系

- 来源页：平台能力 → 我的令牌，列表「生成令牌」或行「编辑授权范围」；令牌详情「编辑授权范围」进入编辑模式
- 去向页：生成成功 → 本页生成结果弹窗，关闭后返回 `/mcp-access/tokens`；编辑保存成功 → 本功能令牌详情 `/mcp-access/tokens/:id`
- 返回行为：「取消」在生成模式返回 `/mcp-access/tokens`，编辑模式返回 `/mcp-access/tokens/:id`；不依赖面包屑返回
- 功能归属：平台能力 → 我的令牌；生成与编辑均为本功能非菜单页，当前标题分别为「生成令牌」「编辑授权范围」

#### 操作反馈清单

| 操作名 | 触发条件 | 二次确认? | Loading 形式 | 成功反馈+去向 | 失败反馈+重试 |
|--------|---------|----------|-------------|-------------|-------------|
| 生成令牌 | 表单校验通过，至少选择一项当前有效范围 | 否 | 提交按钮 loading，表单禁用 | 打开生成结果弹窗；弹窗「我已保存，关闭」→ 跳转我的令牌页 | Message.error 展示错误详情（如名称重复、已达上限、授权项已不可用），表单保留、按钮恢复 |
| 保存授权范围 | 编辑模式，校验通过，至少选择一项当前有效范围 | 否 | 提交按钮 loading | Message.success「令牌「{名称}」授权范围已更新」→ 1.5s 后跳转令牌详情页；令牌明文与有效期不变，范围对下一次调用生效 | Message.error 错误详情，表单保留、按钮恢复 |
| 复制令牌 / 复制配置 | 生成结果弹窗内 | 否 | 无 | Message.success「已复制到剪贴板」，停留弹窗 | Message.error「复制失败，请手动选择复制」 |
| 下载配置文件 | 生成结果弹窗内 | 否 | 按钮 loading | Message.success「配置文件已下载」，停留弹窗 | Message.error + 按钮恢复 |
| 关闭结果弹窗 | 点击「我已保存，关闭」 | MessageBox「关闭后将无法再次查看令牌明文，确认已保存？」 | 无 | 跳转我的令牌页 | — |

#### 表单校验

- 初态：生成模式有效期默认 90 天、授权范围未勾选；编辑模式回显令牌名称与当前仍可用的授权范围，有效期不展示；已停用、已删除或已超出分配范围的项在令牌详情展示，不作为可选项回填

| 字段名 | 必填 | 校验规则 | 触发时机 | 错误文案 | 异步? |
|--------|-----|---------|---------|---------|------|
| 令牌名称 | 是 | 2–32 字，本人未吊销令牌中唯一 | blur | 「请输入 2–32 字的令牌名称」/「已有同名令牌」 | 是（唯一性） |
| 有效期 | 是（生成模式） | 7 / 30 / 90 / 180 天四选一 | change | 「请选择有效期」 | 否 |
| 授权范围 | 是 | 至少一项当前有效范围；数据库与研发工具须在当前分配内，业务工具须为已注册可选项；全部须显式勾选 | 提交时 | 「请至少选择一项授权范围」 | 否（提交时服务端复核可用性） |

- 提交成功跳转：生成模式见生成结果弹窗关闭后跳转 `/mcp-access/tokens`；编辑模式 1.5s 后跳转 `/mcp-access/tokens/:id`
- 提交失败展示：Message.error 错误详情，已填内容保留
- 脏数据离开：MessageBox「您有未保存的修改，确认离开？」

### 令牌详情

- **页面路径**：`/mcp-access/tokens/:id`
- **路由编码（name）**：`devhubMcpTokenDetail`
- **菜单 / 按钮权限码**：非菜单页；本人编辑需 `devhubMcpTokenEdit`，查看或吊销他人令牌需 `devhubMcpTokenAdmin`，定义见 [共享权限矩阵](../../references/permission-rules.md#1-权限点矩阵)
- **权限判定**：他人详情与管理动作须按功能权限及服务端规则校验，不能仅凭路由可进入判定为有权操作
- **页面类型**：`archive-detail`
- **区块职责**：
  - 头部：令牌名称、状态 Tag、令牌前缀；操作按钮：编辑授权范围、续期、吊销（按状态可用，见 state-machine.md；编辑本人令牌需 `devhubMcpTokenEdit`，查看他人令牌时仅管理员吊销可用）
  - 基本信息（Descriptions）：持有人、有效期档位、生效时间、到期时间、最近使用时间、创建时间；已吊销时追加吊销方式、吊销人、吊销时间、吊销原因
  - 授权范围：统一表格列为领域、对象、粒度、范围、可用性；业务工具为令牌显式勾选的工具；研发工具为 SLS 日志 / ARMS 应用监控工具族，范围显示「当前仓成员应用范围」，不列业务域、环境限定或单应用授权；数据库保留实例 / 库 / 表粒度与「含后续开放表」标记；不可用项带「已停用」「已删除」「已超出分配范围」Tag，失去工具分配后对应工具族不可用。权限收回或到期不吊销令牌本身，仅拒绝受影响工具调用，其他有效范围不变
  - MCP 接入配置：统一标准配置（服务名称带环境标识）、只读配置内容（令牌位置以「<请填入令牌>」占位）、复制配置、下载配置文件；说明「令牌明文仅在生成时展示」；生产 / 非生产连接按完整应用名后缀路由，不是环境授权项；配置可复制不代表失效工具或应用可调用
  - 调用记录（近 30 天，本令牌）：按调用结果筛选；表格列：调用时间、工具、目标对象（观测查询为完整应用，数据库为库表）、调用结果 Tag、原因、耗时
- **布局引用**：[本功能原型](../assets/web/token-detail.html)（编排依据：`busyming-skills-design/shared/page-standards/web-detail.md`）

#### 导航关系

- 来源页：平台能力 → 我的令牌，列表行「详情」或令牌名称；编辑授权范围保存成功；调用审计中的令牌链接（查看范围仍按权限判定）
- 去向页：「编辑授权范围」→ 本功能非菜单页 `/mcp-access/tokens/:id/edit`
- 返回行为：页头「返回列表」返回我的令牌 `/mcp-access/tokens`，不依赖面包屑返回
- 功能归属：平台能力 → 我的令牌；本页为非菜单详情页，当前标题为「令牌详情」
